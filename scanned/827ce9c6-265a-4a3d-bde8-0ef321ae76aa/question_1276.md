# Q1276: resolve-ststx via collateral-add: count one deposit as backing for two simultaneous claims

## Question
Does `collateral-add` (mainnet/contracts/market/v0-4-market.clar:1020) let an unprivileged attacker who controls whether this asset is already collateral (the is-new-collateral branch) reach `resolve-ststx` (mainnet/contracts/market/v0-4-market.clar:339) in a state where it count one deposit as backing for two simultaneous claims?
