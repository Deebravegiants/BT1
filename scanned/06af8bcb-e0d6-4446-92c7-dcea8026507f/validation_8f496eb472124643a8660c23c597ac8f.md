## Finding: Unauthenticated Access to LOOP Plugin Debug/PPROF and Metrics Endpoints

### Title
Unauthenticated exposure of LOOP plugin discovery, metrics, and pprof debug endpoints - (File: `core/web/router.go`)

### Summary
The Chainlink node's `NewRouter` registers the LOOP-plugin routes (`loopRoutes`) on the same top-level `api` route group as all other endpoints, but unlike other sensitive routes (e.g. `/debug/vars`), it never wraps them with the session/token authentication middleware. Any client that can reach the node's HTTP API port can enumerate registered LOOP plugins, pull their Prometheus metrics, and — critically — trigger and retrieve full `pprof` heap/goroutine/CPU profile dumps of plugin processes without any credentials.

### Finding Description
`NewRouter` builds a single `api` group with only rate-limiting and cookie-session middleware attached [1](#0-0) . It then calls `loopRoutes(app, api)`, which registers the discovery, metrics, and pprof-proxy handlers directly on that group with no authentication requirement: [2](#0-1) 

Compare this to `debugRoutes`, which explicitly requires an authenticated session before exposing the standard Go `expvar` debug endpoint: [3](#0-2) 

No equivalent `auth.Authenticate(...)` wrapper exists for `loopRoutes`. The handlers themselves proxy directly to each LOOP plugin's internal pprof server: [4](#0-3) [5](#0-4) 

The `pprofURLVals` helper forwards attacker-controlled `debug`, `gc`, and `seconds` query parameters straight to the plugin's `/debug/pprof/*` handler [6](#0-5) , and `pluginMetricHandler` proxies to the plugin's `/metrics` endpoint [7](#0-6) .

The Chainlink node's HTTP API server listens on `0.0.0.0` by default (`ListenIP = '0.0.0.0'`), so this is reachable by any network client, not just localhost processes [8](#0-7) .

### Impact Explanation
An unauthenticated, unprivileged actor with network access to the node's API port (default `6688`) can:
- Enumerate all registered LOOP plugins via `/discovery`.
- Pull raw Prometheus metrics from any plugin via `/plugins/:name/metrics`.
- Capture full `pprof` heap dumps, goroutine stacks, and CPU profiles from LOOP plugin processes via `/plugins/:name/debug/pprof/*profile`, which can leak sensitive in-memory data (private keys, secrets, credentials) held by the plugin process.
- Trigger long-running CPU profile captures (`seconds` parameter) against plugin processes, causing resource exhaustion / denial of service.

This mirrors the CVE-2021-3626 bug class: a control-plane/debug interface that should require authentication is instead reachable by any unprivileged caller, enabling information disclosure and potential escalation.

### Likelihood Explanation
High — the routes require no credentials, no CSRF token, and no session; they are reachable by any HTTP client that can connect to the node's exposed API port, which is bound to `0.0.0.0` by default.

### Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession, auth.AuthenticateByToken)` middleware used elsewhere (as done for `debugRoutes`), or move these endpoints to a separate internal-only listener/port that is not exposed on the public API interface.

### Proof of Concept
Against a running node with a LOOP plugin registered (e.g. `myplugin`):
```
curl http://<node-host>:6688/discovery
curl http://<node-host>:6688/plugins/myplugin/metrics
curl "http://<node-host>:6688/plugins/myplugin/debug/pprof/heap?debug=1"
curl "http://<node-host>:6688/plugins/myplugin/debug/pprof/profile?seconds=30"
```
No `Cookie`, `X-Chainlink-EA-AccessKey`, or `X-Chainlink-EA-Secret` header is required — all requests succeed for any network caller.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
