## Finding

The Gateway's CORS origin allowlist in `core/services/gateway/network/httpserver.go` performs wildcard-domain matching with a plain string suffix check that doesn't enforce a subdomain (dot) boundary — this is a direct analog of the Discourse Onebox "URL authority boundary" bug class (an allowlist intended to restrict to a specific host/subdomain family is bypassable via a crafted string that merely shares a suffix, not a real subdomain relationship).

### Title
CORS wildcard-origin allowlist bypass via missing subdomain boundary check - (File: core/services/gateway/network/httpserver.go)

### Summary
The gateway user-facing HTTP server's CORS allowlist (`isAllowedOrigin`) supports wildcard entries like `*.remix.com`, intending to allow only genuine subdomains of `remix.com`. It implements this by stripping the `*.` prefix and calling `strings.HasSuffix(originHost, allowedHost)`, which matches any hostname that ends with the string `remix.com` — including non-subdomain look-alike domains such as `evilremix.com` or `notremix.com` — because there is no check that the character preceding the suffix is a `.` (or that the origin ends exactly at a label boundary).

### Finding Description
`isAllowedOrigin` in [1](#0-0)  handles both exact-host and wildcard-host allowlist entries. For wildcard entries it does:
```go
if strings.HasPrefix(allowedHost, "*.") {
    allowedHost = allowedHost[2:]
    if strings.HasSuffix(originHost, allowedHost) {
        return true
    }
}
```
`strings.HasSuffix` treats hostnames as raw strings, not domain labels. Given an allowlist entry `*.ethereum.org` (stripped to `ethereum.org`), an attacker-controlled origin `https://evil-ethereum.org` satisfies `strings.HasSuffix("evil-ethereum.org", "ethereum.org")` and is incorrectly treated as an allowed subdomain of `ethereum.org`, even though it is an entirely unrelated, attacker-registered domain. The same logic is reused by scheme/port-aware `splitURL` at [2](#0-1) , which only isolates scheme/host/port before the vulnerable suffix comparison — it performs no additional boundary validation.

This is invoked from `handleRequest` at [3](#0-2) , which reflects the attacker-supplied `Origin` header value directly into `Access-Control-Allow-Origin` once `isAllowedOrigin` returns true, for every request hitting the gateway's public User HTTP server (used by the CRE/Workflow gateway, e.g. as configured in [4](#0-3) ).

### Impact Explanation
An unprivileged remote actor who registers or controls a domain that merely shares a suffix with an allowlisted wildcard domain (e.g. `notremix.ethereum.org`... more precisely `xethereum.org` for an allowlist of `*.ethereum.org`) can host a page there and have the gateway's response reflect `Access-Control-Allow-Origin: https://xethereum.org`. Browsers on that origin can then read cross-origin gateway API responses that were only intended to be exposed to the legitimate allowlisted subdomains. This is an allowlist/authority-boundary bypass matching the reported bug class, though the practical severity depends on whether responses served by this endpoint contain sensitive, session-bound, or otherwise privileged data and whether credentials (cookies) are involved — the handler here does not set `Access-Control-Allow-Credentials`, which limits (but does not eliminate) impact to non-credentialed response confusion.

### Likelihood Explanation
Exploitation only requires an attacker to control (register) a domain string that shares the intended suffix — this is realistically achievable (e.g., domain name similar in tail characters) and requires no authentication or privileged access; the attacker simply needs to lure a victim to load a page from the crafted origin while the browser sends requests to the gateway.

### Recommendation
Change the wildcard match to enforce a proper subdomain boundary, e.g.:
```go
if strings.HasSuffix(originHost, "."+allowedHost) || originHost == allowedHost {
    return true
}
```
or split `originHost` on `.` and compare the trailing labels against `allowedHost`'s labels exactly, rather than doing a raw string suffix comparison.

### Proof of Concept
1. Configure the gateway with `CORSAllowedOrigins = ["https://*.ethereum.org"]`.
2. Send a request to the gateway user HTTP server with header `Origin: https://evil-ethereum.org` (or any domain ending in `ethereum.org` without a dot separator, e.g. `xethereum.org`).
3. Observe the response contains `Access-Control-Allow-Origin: https://evil-ethereum.org`, confirming the wildcard allowlist accepted a non-subdomain, attacker-controlled origin — see the exact logic at [5](#0-4)  and the reflection point at [6](#0-5) .

func (s *httpServer) splitURL(rawURL string) (string, string, string, error) {
	// lowercase the URL to avoid case sensitivity issues
	parsedURL, err := url.Parse(strings.ToLower(rawURL))
	if err != nil {
		return "", "", "", fmt.Errorf("error parsing URL: %w", err)
	}

	host, port, err := net.SplitHostPort(parsedURL.Host)
	if err != nil {
		// if there's no port, the host itself is returned
		if parsedURL.Host != "" {
			return parsedURL.Scheme, parsedURL.Host, "", nil
		}
		return "", "", "", fmt.Errorf("error splitting host and port: %w", err)
	}

	return parsedURL.Scheme, host, port, nil
}

func (s *httpServer) isAllowedOrigin(origin string) bool {
	originScheme, originHost, originPort, err := s.splitURL(origin)
	if err != nil {
		s.lggr.Debug("error parsing origin URL", err)
		return false
	}
	for _, allowed := range s.config.CORSAllowedOrigins {
		// probably better to do this once when server starts and store it in a map
		// this is an easier solution so we don't have to apply more changes to the code
		// just need to be careful when specifying allowed origins in the config file
		allowedScheme, allowedHost, allowedPort, err := s.splitURL(allowed)
		if err != nil {
			s.lggr.Debug("error parsing allowed origin URL", err)
			continue
		}
		// skip if the scheme doesn't match at all
		if originScheme != allowedScheme {
			continue
		}
		// skip if the port doesn't match at all
		if originPort != allowedPort {
			continue
		}
		// check for exact host match (e.g., remix.com)
		if originHost == allowedHost {
			return true
		}
		// check for wildcard host match (e.g., *.remix.com)
		if strings.HasPrefix(allowedHost, "*.") {
			allowedHost = allowedHost[2:]
			if strings.HasSuffix(originHost, allowedHost) {
				return true
			}
		}
	}
	return false
}

func (s *httpServer) handleRequest(w http.ResponseWriter, r *http.Request) {
	if s.config.CORSEnabled {
		origin := r.Header.Get("Origin")
		if s.isAllowedOrigin(origin) {
			w.Header().Set("Access-Control-Allow-Origin", origin)
			w.Header().Set("Access-Control-Allow-Methods", "GET, POST, OPTIONS")
			w.Header().Set("Access-Control-Allow-Headers", "Content-Type")
		}

		// handle preflight requests
		if r.Method == http.MethodOptions {
			w.WriteHeader(http.StatusNoContent)
			return
		}
	}
