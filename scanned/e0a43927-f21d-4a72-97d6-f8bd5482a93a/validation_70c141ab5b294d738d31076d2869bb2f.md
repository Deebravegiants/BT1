### Title
Unbounded `savedCallbacks` Map Growth in Gateway DummyHandler Enables Unprivileged-User Memory Exhaustion DoS - ([File: core/services/gateway/handlers/handler.dummy.go])

### Summary
The gateway's `dummyHandler` stores one `savedCallback` entry per inbound user request in an in-memory map keyed by message ID, but never expires, caps, or prunes that map. An unauthenticated/unprivileged HTTP client hitting the gateway's public `ProcessRequest` endpoint can trigger unbounded accumulation of entries whenever the paired node response never arrives, eventually exhausting gateway process memory — the same "guest can force out-of-memory allocation via unbounded server-side buffering" root cause described in CVE-2022-42316 (Xenstore).

### Finding Description
`dummyHandler.HandleLegacyUserMessage` / `HandleJSONRPCUserMessage` unconditionally insert a `savedCallback` into `d.savedCallbacks` on every incoming request, keyed by the caller-supplied message ID: [1](#0-0) 

The only removal path is `HandleNodeMessage`, which deletes the entry solely when a node happens to send back a response whose ID matches: [2](#0-1) 

There is no TTL/expiry check, no maximum-size enforcement, and no background reaper goroutine in this handler — contrast this with the sibling `capabilities` handler, which explicitly bounds and periodically prunes its equivalent map: [3](#0-2) 
and the sharded HTTP trigger handler, which reaps expired callbacks on a timer: [4](#0-3) 

The gateway's user-facing entry point `ProcessRequest` accepts requests from unauthenticated/unprivileged HTTP clients, decodes them, and dispatches to whichever handler is configured for the method/service (including `dummy`), then waits on a callback with a timeout — but the timeout only affects the HTTP response; it does not remove the leaked map entry in the handler: [5](#0-4) 

Because `HandleLegacyUserMessage`/`HandleJSONRPCUserMessage` never validate that the request will actually receive a corresponding node reply (e.g. no node is configured for that DON, a node is down, or the node simply never echoes back that specific message ID), each such request permanently leaks one map entry containing the full `Callback` object. A client can trivially generate a fresh message ID (IDs up to 200 characters are permitted) on every request, guaranteeing no collision-based dedup or cache benefit suppresses growth.

### Impact Explanation
Sustained requests from a single unprivileged, unauthenticated actor grow `d.savedCallbacks` without bound, consuming heap memory proportional to the number of requests sent. This is a direct Denial-of-Service against the gateway process — matching CVSS AV:L/... **but the analog here is remotely reachable via the internet-facing gateway HTTP endpoint** rather than local, so the practical severity is worse than the upstream Xenstore case: it does not require any privilege, valid API token, or session — any client that can reach the gateway's `/…` HTTP user endpoint can degrade or crash the gateway service, disrupting all workflows/DONs relying on it.

### Likelihood Explanation
High. No authentication, allowlisting, or rate limiting gates the `dummyHandler` path shown here (unlike the `capabilities`/vault handlers, which apply node-rate-limiters and allowlist-based authorization before touching shared state). Any client capable of sending an HTTP POST to the gateway's public endpoint with a `dummy`-routed method can exploit this with simple, repeated, low-cost requests.

### Recommendation
Add the same bounded, TTL-based lifecycle management to `dummyHandler.savedCallbacks` that other handlers already implement: track `createdAt` per entry, run a periodic pruning/reaper goroutine (as in `capabilities/handler.go:pruneCallbacks` and `v2/http_trigger_handler.go:reapExpiredCallbacks`), and enforce a maximum map size with eviction of the oldest entries. Alternatively, retire/guard the `dummyHandler` from being reachable in production gateway configurations if it is only intended for tests.

### Proof of Concept
1. Configure a gateway service/DON to route a method to the `dummy` handler (as supported by `handler_factory.go` and `sample_config.toml`), where the "node" behind it is slow, offline, or otherwise will never echo back the exact message ID.
2. As an unauthenticated client, repeatedly POST JSON-RPC/legacy requests to the gateway's public endpoint with unique message IDs (`newSignedLegacyRequest`/`newJSONRpcRequest`-style payloads), e.g. in a loop.
3. Each request calls `dummyHandler.HandleLegacyUserMessage`/`HandleJSONRPCUserMessage`, inserting an entry into `savedCallbacks` that is never removed because no matching `HandleNodeMessage` response arrives.
4. Observe gateway process RSS growing unbounded with request volume, eventually leading to OOM/kill of the gateway service.

func (d *dummyHandler) HandleNodeMessage(ctx context.Context, resp *jsonrpc.Response[json.RawMessage], nodeAddr string) error {
	var msg api.Message
	err := json.Unmarshal(*resp.Result, &msg)
	if err != nil {
		return err
	}
	msg.Body.MessageID = resp.ID
	err = msg.Validate()
	if err != nil {
		return err
	}
	if nodeAddr != msg.Body.Sender {
		return fmt.Errorf("node address %s does not match message sender %s", nodeAddr, msg.Body.Sender)
	}
	d.mu.Lock()
	savedCb, found := d.savedCallbacks[msg.Body.MessageID]
	delete(d.savedCallbacks, msg.Body.MessageID)
	d.mu.Unlock()

func (h *handler) pruneCallbacks() {
	h.mu.Lock()
	defer h.mu.Unlock()

	// First, remove expired callbacks.
	maxAge := time.Duration(h.config.CallbackMaxAgeSec) * time.Second
	now := time.Now()
	var expired int
	for id, cb := range h.savedCallbacks {
		if now.Sub(cb.createdAt) > maxAge {
			delete(h.savedCallbacks, id)
			expired++
		}
	}

	// If there are still too many callbacks, sort them by creation time and remove the oldest ones.
	maxSize := h.config.MaxSavedCallbacks
	var evicted int
	if len(h.savedCallbacks) > maxSize {
		type entry struct {
			id        string
			createdAt time.Time
		}
		entries := make([]entry, 0, len(h.savedCallbacks))
		for id, cb := range h.savedCallbacks {
			entries = append(entries, entry{id, cb.createdAt})
		}
		sort.Slice(entries, func(i, j int) bool {
			return entries[i].createdAt.Before(entries[j].createdAt)
		})
		// Trim to maxSize/2 to avoid sorting the list too frequently.
		for _, e := range entries[:len(entries)-maxSize/2] {
			delete(h.savedCallbacks, e.id)
			evicted++
		}
	}

	if expired > 0 || evicted > 0 {
		h.lggr.Infow("Pruned savedCallbacks", "expired", expired, "evicted", evicted, "remaining", len(h.savedCallbacks))
	}

// reapExpiredCallbacks removes callbacks that are older than the maximum age
func (h *httpTriggerHandler) reapExpiredCallbacks(ctx context.Context) {
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()
	now := time.Now()
	var expiredCount int
	for reqID, callback := range h.callbacks {
		if now.Sub(callback.createdAt) > time.Duration(h.config.CleanUpPeriodMs)*time.Millisecond {
			if !callback.processed {
				h.metrics.IncrementRequestErrors(ctx, jsonrpc.ErrInternal, h.lggr)
			}
			h.cleanupCallback(reqID)
			expiredCount++
		}
	}
	if expiredCount > 0 {
		h.metrics.IncrementPendingRequestsCleanUpCount(ctx, int64(expiredCount), h.lggr)
		h.lggr.Infow("Removed expired callbacks", "count", expiredCount, "remaining", len(h.callbacks))
	}
	h.metrics.RecordPendingRequestsCount(ctx, int64(len(h.callbacks)), h.lggr)
}

// Called by the server
func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	isLegacyRequest := false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonID == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonID
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}

	response, err := callback.Wait(ctx)
	duration := time.Since(startTime)
	if err != nil {
		response := api.RequestTimeoutError
		g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.String(), duration)
		g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.String())
		return newError(jsonRequest.ID, response, "handler timeout: "+err.Error())
	}
	g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.ErrorCode.String(), duration)
	g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.ErrorCode.String())

	g.lggr.Debugw("received response from handler", "handler", handlerKey, "response", response, "requestID", jsonRequest.ID)
	promRequest.WithLabelValues(response.ErrorCode.String()).Inc()
	return response.RawResponse, api.ToHTTPErrorCode(response.ErrorCode)
}
