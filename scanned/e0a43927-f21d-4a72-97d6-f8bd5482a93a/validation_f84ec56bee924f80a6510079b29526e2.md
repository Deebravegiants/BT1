### Title
Unauthenticated LOOP registry route group exposes internal plugin metrics and pprof debug/profiling endpoints - (File: core/web/router.go)

### Summary
`core/web/router.go`'s `NewRouter` mounts `loopRoutes` directly on the root `api` router group with no authentication middleware attached, unlike every other functional route group (`debugRoutes`, `sessionRoutes`, `v2Routes`) which wrap their handlers in `auth.Authenticate(...)`. This mirrors the free5GC finding's root cause: an entire route group is mounted without an inbound auth boundary, so any request reaching the node's SBI/API port can hit it with zero credentials.

### Finding Description
In `NewRouter`, the routes are registered as:
```go
debugRoutes(app, api)
healthRoutes(app, api)
sessionRoutes(app, api)
v2Routes(app, api)
loopRoutes(app, api)
``` [1](#0-0) 

`debugRoutes` explicitly wraps its `/debug` group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [2](#0-1) , and `v2Routes`/`sessionRoutes` similarly gate their sensitive endpoints behind `auth.Authenticate(...)` with `auth.AuthenticateByToken`/`auth.AuthenticateBySession` [3](#0-2) .

`loopRoutes`, however, registers its handlers directly on the passed-in `r *gin.RouterGroup` with no `auth.Authenticate` wrapper at all:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
``` [4](#0-3) 

Only the base rate limiter and cookie session middleware from the parent `api` group apply — neither performs authentication. `/plugins/:name/debug/pprof/*profile` and the `/symbol` POST route proxy requests, including attacker-controlled query parameters (`debug`, `gc`, `seconds`) and POST body, straight through to an internal LOOP plugin's pprof endpoint:
```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	...
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	...
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
``` [5](#0-4) 

and `pluginMetricHandler` proxies to `/metrics` on the internal loop host [6](#0-5) .

### Impact Explanation
Any unauthenticated network client that can reach the node's web/API port can:
- Enumerate registered LOOP plugins and their internal Prometheus scrape targets via `/discovery` (information disclosure of internal topology/hostnames).
- Pull internal plugin `/metrics` (potentially containing operational/business-sensitive counters) without credentials.
- Trigger CPU/heap/goroutine/allocs profiling (`/plugins/:name/debug/pprof/*profile`) on internal plugin processes with attacker-controlled `seconds` duration, causing resource consumption / limited denial-of-service, and potentially leaking sensitive memory/stack data through profile dumps that get relayed back in the HTTP response.
- Because this is a route-group-scoped defect (no auth middleware on the group), any future handler added to `loopRoutes` inherits the same missing boundary, matching the structural concern raised in the reference advisory.

This satisfies the "concrete authentication bypass" bar: a route group intended to only be reachable with node-level authorization is fully open, and it returns internal-network data and allows triggering non-trivial internal work (profiling) with no `Authorization`/session/token at all.

### Likelihood Explanation
High. No special conditions are required — any client capable of sending an HTTP GET/POST to the node's web port can hit these routes; they are mounted unconditionally in `NewRouter` (not gated behind dev-only build flags like some other routes, e.g. `build.IsDev()` for `/execute_capability` at `core/web/router.go:304-307`). The only mitigation present is a generic rate limiter shared with the rest of `api`, not authentication.

### Recommendation
Wrap `loopRoutes` registrations with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware pattern used for `authv2`/`debugRoutes`, or otherwise clearly document/limit this group to trusted internal networks (e.g., separate listener/port not exposed externally) and add explicit auth so no future endpoint added under this group inherits an unauthenticated posture by default.

### Proof of Concept
Against a running Chainlink node with LOOP plugins registered, with no `Authorization` header, `Cookie`, or API key headers set:
```
curl -i http://<node-host>:<web-port>/discovery
curl -i http://<node-host>:<web-port>/plugins/<plugin-name>/metrics
curl -i "http://<node-host>:<web-port>/plugins/<plugin-name>/debug/pprof/profile?seconds=30"
```
All three requests are served by `loopRegistry.discoveryHandler`, `pluginMetricHandler`, and `pluginPPROFHandler` respectively without any authentication check being invoked, per the route registrations shown in `core/web/router.go:230-236`.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
