### Title
Bridge and External Initiator outgoing authentication tokens stored and served in plaintext to any authenticated read-level user - ([File: core/bridges/bridge_type.go], [File: core/web/bridge_types_controller.go], [File: core/bridges/external_initiator.go])

### Summary
Chainlink's Bridge (external adapter) and External Initiator features generate an `OutgoingToken`/`OutgoingSecret` that the node uses to authenticate itself when calling out to bridges or notifying external initiators. These tokens are persisted in plaintext in the `bridge_types.outgoing_token` and `external_initiators.outgoing_token`/`outgoing_secret` columns, and are returned in plaintext by the standard read (`Index`/`Show`) API and GraphQL endpoints, not just at creation time.

### Finding Description
`bridges.NewBridgeType` generates an `OutgoingToken` and stores it unencrypted on the `BridgeType` struct persisted via `CreateBridgeType`: [1](#0-0) 

The `BridgeType.OutgoingToken` field has no redaction/hashing (unlike `IncomingTokenHash`, which is hashed with a salt): [2](#0-1) 

`presenters.NewBridgeResource` copies the plaintext `OutgoingToken` directly into the JSON:API response with no redaction: [3](#0-2) 

This resource is served not only on bridge creation, but also on the paginated listing (`Index`) and single lookup (`Show`) endpoints, meaning any authenticated caller who can hit `GET /v2/bridge_types` or `GET /v2/bridge_types/:BridgeName` receives the plaintext outgoing token for every bridge in the node's job pipeline: [4](#0-3) 

The same pattern applies to `ExternalInitiator`: `OutgoingSecret` and `OutgoingToken` are generated as plaintext, persisted unencrypted, and returned unredacted by the `Index` endpoint: [5](#0-4) [6](#0-5) 

A test explicitly confirms the plaintext outgoing token is exposed on the listing endpoint response body: [7](#0-6) 

The Bridge GraphQL schema likewise exposes `outgoingToken: String!` on the `Bridge` type used for read queries, not only for the create mutation: [8](#0-7) 

This differs materially from the general chainlink node "secrets" handling elsewhere in the codebase (TOML `secrets.toml` config, keystore passwords, Mercury credentials, vault secrets), all of which are wrapped in `config.SecretString`/`SecretURL` types that redact values as `xxxxx` when marshalled/logged: [9](#0-8) 
The bridge/external-initiator outgoing credentials were never migrated to this redaction pattern, so any read of the bridge or external-initiator collection discloses live outbound-authentication secrets.

### Impact Explanation
The `OutgoingToken` (and, for external initiators, `OutgoingSecret`) is the credential the Chainlink node itself presents to the external bridge adapter / external initiator when making outbound calls (job-run notifications, adapter callbacks). Any authenticated node user (including lower-privileged "View" role users who only need read access to inspect job/bridge configuration) who can call `GET /v2/bridge_types`, `GET /v2/bridge_types/:name`, `GET /v2/external_initiators`, or the equivalent GraphQL `bridge`/`bridges` queries obtains these plaintext outbound credentials. This is directly analogous to the Jenkins StarTeam issue: credentials meant to be used only for a specific integration are persisted in plaintext and disclosed to a broader set of authenticated users than intended (CWE-522), enabling impersonation of the node toward external adapters/initiators or replay of the token against the bridge's own auth check.

### Likelihood Explanation
Exploitation requires only a valid, authenticated session/API token for the Chainlink Operator UI/API — no special admin privilege is enforced beyond standard authentication for these read routes. Given that "View"-level users are a normal, expected role in multi-operator Chainlink deployments, and that bridge/external-initiator listing is a routine administrative action, this is readily reachable in realistic deployments.

### Recommendation
- Redact `OutgoingToken`/`OutgoingSecret` from `BridgeResource`/`ExternalInitiatorResource` on `Index`/`Show` responses and GraphQL read queries; only return it once at creation time (as is already done for `IncomingToken`).
- Store `OutgoingToken`/`OutgoingSecret` using the existing `config.SecretString` redaction wrapper or otherwise encrypt at rest, consistent with other node secrets.
- Gate any endpoint that must return the raw outgoing token behind a re-authentication/explicit "reveal" action and restrict to admin-level roles, mirroring the OCR key `Export` endpoint's `newpassword`-gated approach.

### Proof of Concept
1. Create a bridge: `POST /v2/bridge_types` with a valid session — response includes `outgoingToken`.
2. As a separate, lower-privileged authenticated user (e.g., "View" role) with only read access, call `GET /v2/bridge_types` or `GET /v2/bridge_types/{name}`.
3. Observe the JSON:API response's `attributes.outgoingToken` field contains the same plaintext token generated at creation, as verified by the existing test asserting `externalInitiators[0].OutgoingToken` equality after an `Index` call: [10](#0-9) 

**Note on verification limits:** I was unable to fully confirm the exact role/permission gate (`requireViewRole`/`requireEditRole`/etc.) applied to the `/v2/bridge_types` and `/v2/external_initiators` routes in `core/web/router.go` within the available search iterations — the grep matched the route registrations but the surrounding role-middleware context wasn't retrieved before the tool budget ran out. If these routes are only reachable by full-admin sessions with no separate "read-only" role tier, the severity should be reassessed downward accordingly (still a plaintext-secret-storage/CWE-522 issue, but with reduced blast radius since it wouldn't cross a privilege boundary). Confirming this would require inspecting the middleware chain applied to these specific routes in `core/web/router.go`.

// Index lists Bridges, one page at a time.
func (btc *BridgeTypesController) Index(c *gin.Context, size, page, offset int) {
	ctx := c.Request.Context()
	bridges, count, err := btc.App.BridgeORM().BridgeTypes(ctx, offset, size)

	resources := make([]presenters.BridgeResource, 0, len(bridges))
	for _, bridge := range bridges {
		resources = append(resources, *presenters.NewBridgeResource(bridge))
	}

	paginatedResponse(c, "Bridges", size, page, resources, count, err)
}

// Show returns the details of a specific Bridge.
func (btc *BridgeTypesController) Show(c *gin.Context) {
	ctx := c.Request.Context()
	name := c.Param("BridgeName")

	taskType, err := bridges.ParseBridgeName(name)
	if err != nil {
		jsonAPIError(c, http.StatusUnprocessableEntity, err)
		return
	}

	bt, err := btc.App.BridgeORM().FindBridge(ctx, taskType)
	if errors.Is(err, sql.ErrNoRows) {
		jsonAPIError(c, http.StatusNotFound, errors.New("bridge not found"))
		return
	}
	if err != nil {
		jsonAPIError(c, http.StatusInternalServerError, err)
		return
	}

	jsonAPIResponse(c, presenters.NewBridgeResource(bt), "bridge")
}

type ExternalInitiator struct {
	ID             int64
	Name           string
	URL            *models.WebURL
	AccessKey      string
	Salt           string
	HashedSecret   string
	OutgoingSecret string
	OutgoingToken  string

	CreatedAt time.Time
	UpdatedAt time.Time
}

// NewExternalInitiator generates an ExternalInitiator from an
// auth.Token, hashing the password for storage
func NewExternalInitiator(
	eia *auth.Token,
	eir *ExternalInitiatorRequest,
) (*ExternalInitiator, error) {
	salt := utils.NewSecret(utils.DefaultSecretSize)
	hashedSecret, err := auth.HashedSecret(eia, salt)
	if err != nil {
		return nil, pkgerrors.Wrap(err, "error hashing secret for external initiator")
	}

	return &ExternalInitiator{
		Name:           strings.ToLower(eir.Name),
		URL:            eir.URL,
		AccessKey:      eia.AccessKey,
		HashedSecret:   hashedSecret,
		Salt:           salt,
		OutgoingToken:  utils.NewSecret(utils.DefaultSecretSize),
		OutgoingSecret: utils.NewSecret(utils.DefaultSecretSize),
	}, nil
}

func TestExternalInitiatorsController_Index(t *testing.T) {
	t.Parallel()

	app := cltest.NewApplicationWithConfig(t,
		configtest.NewGeneralConfig(t, func(c *chainlink.Config, s *chainlink.Secrets) {
			c.JobPipeline.ExternalInitiatorsEnabled = new(true)
		}))
	require.NoError(t, app.Start(t.Context()))

	client := app.NewHTTPClient(nil)

	db := app.GetDB()
	borm := bridges.NewORM(db)

	eiFoo := cltest.MustInsertExternalInitiatorWithOpts(t, borm, cltest.ExternalInitiatorOpts{
		NamePrefix:    "foo",
		URL:           cltest.MustWebURL(t, "http://example.com/foo"),
		OutgoingToken: "outgoing_token",
	})
	eiBar := cltest.MustInsertExternalInitiatorWithOpts(t, borm, cltest.ExternalInitiatorOpts{NamePrefix: "bar"})

	resp, cleanup := client.Get("/v2/external_initiators?size=x")
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusUnprocessableEntity)

	resp, cleanup = client.Get("/v2/external_initiators?size=1")
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusOK)
	body := cltest.ParseResponseBody(t, resp)

	metaCount, err := cltest.ParseJSONAPIResponseMetaCount(body)
	require.NoError(t, err)
	require.Equal(t, 2, metaCount)

	var links jsonapi.Links
	var externalInitiators []presenters.ExternalInitiatorResource
	err = web.ParsePaginatedResponse(body, &externalInitiators, &links)
	require.NoError(t, err)
	assert.NotEmpty(t, links["next"].Href)
	assert.Empty(t, links["prev"].Href)

	assert.Len(t, externalInitiators, 1)
	assert.Equal(t, strconv.FormatInt(eiBar.ID, 10), externalInitiators[0].ID)
	assert.Equal(t, eiBar.Name, externalInitiators[0].Name)
	assert.Nil(t, externalInitiators[0].URL)
	assert.Equal(t, eiBar.AccessKey, externalInitiators[0].AccessKey)
	assert.Equal(t, eiBar.OutgoingToken, externalInitiators[0].OutgoingToken)

	resp, cleanup = client.Get(links["next"].Href)
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusOK)

	externalInitiators = []presenters.ExternalInitiatorResource{}
	err = web.ParsePaginatedResponse(cltest.ParseResponseBody(t, resp), &externalInitiators, &links)
	require.NoError(t, err)
	assert.Empty(t, links["next"])
	assert.NotEmpty(t, links["prev"])

	assert.Len(t, externalInitiators, 1)
	assert.Equal(t, strconv.FormatInt(eiFoo.ID, 10), externalInitiators[0].ID)
	assert.Equal(t, eiFoo.Name, externalInitiators[0].Name)
	assert.Equal(t, eiFoo.URL.String(), externalInitiators[0].URL.String())
	assert.Equal(t, eiFoo.AccessKey, externalInitiators[0].AccessKey)
	assert.Equal(t, eiFoo.OutgoingToken, externalInitiators[0].OutgoingToken)
}
