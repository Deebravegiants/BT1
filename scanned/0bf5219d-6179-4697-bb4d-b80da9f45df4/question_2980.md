# Q2980: total-assets via collateral-remove-redeem: make the per-user ledger and the vault aggregate disagree 

## Question
Does `collateral-remove-redeem` (mainnet/contracts/market/v0-4-market.clar:1211) let an unprivileged attacker who controls `receiver` for the underlying leg reach `total-assets` (mainnet/contracts/vault/v0-vault-stx.clar:334) in a state where it make the per-user ledger and the vault aggregate disagree by a repeatable amount?
