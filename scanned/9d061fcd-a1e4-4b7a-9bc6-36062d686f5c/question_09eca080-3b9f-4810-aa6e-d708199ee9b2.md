Scoped impact: Critical, session fixation/authentication bypass - if the host app trusts current_session_id to look up a persisted Session and load its access_token, an attacker who can set (not just read) that cookie on the victim's browser (e.g. via subdomain cookie scoping in a multi-tenant deployment) forces the victim's next request to resolve to an attacker-supplied session id. Proof idea: minitest constructing cookies={'shopify_app_session' => 'attacker_value'} with Context.embedded? = false, asserting SessionUtils.current_session_id returns 'attacker_value' verbatim with no HMAC validation call recorded (Mocha expects HmacValidator.validate never called).
