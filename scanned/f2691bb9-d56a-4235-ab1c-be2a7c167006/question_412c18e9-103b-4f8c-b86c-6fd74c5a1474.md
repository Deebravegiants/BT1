Target: IntentSignerNEP413.signIntent signer_id fallback (intent.signer_id ?? this.accountId). Attacker input: intent.signer_id set explicitly by the caller (e.g. via IntentPayloadBuilder.setSigner) to an accountId different from this.accountId, while this.signMessageFn is bound to a NEAR key controlling only this.accountId. Preconditions: signIntent never cross-checks intent.signer_id against this.accountId before embedding it in the serialized NEP-413 message; only accountId (not signer_id) is passed into the signing key's context. Call sequence: caller (an ordinary user of their own IntentsSDK instance) constructs an IntentPayload with signer_id = 'victim.near' while the configured IntentSignerNEP413's underlying signMessageFn only holds key material for 'attacker.near', calls signIntent(intent), which serializes {signer_id:'victim.near', deadline, intents} and signs it with attacker's NEAR key, returning public_key = attacker's actual NEAR public key. Equality that breaks: signer_id ('victim.near') in the signed payload == the intents user id derivable from public_key (attacker's key) — false, yet the SDK returns the MultiPayloadNep413 unchanged with no error. Scoped impact: Critical — the returned MultiPayload is internally inconsistent (signer_id names one account, public_key belongs to another), and if publishIntent/relayer or contract-level checks only validate that public_key correctly signed the message (not that public_key is a valid full-access key for the NEAR account named by signer_id), an attacker can produce a validly-signed intent naming an unauthorized signer_id. Whose funds: the account named by signer_id ('victim.near'). Proof idea: vitest test constructing an IntentSignerNEP413 with accountId='attacker.near' and a signMessage stub producing a real ed25519 signature/publicKey for attacker's key, calling signIntent with intent.signer_id='victim.near', then asserting JSON.parse(result.payload.message).signer_id !== accountId-implied identity of result.public_key, demonstrating the SDK never enforces signer_id == owner(public_key).
