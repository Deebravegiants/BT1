Target: `defaultIntentPayloadFactory` (packages/intents-sdk/src/intents/intent-payload-factory.ts), field `deadline`. Attacker input: a solver quote or integrator-forwarded string `params.deadline = 'not-a-real-date'` or an out-of-range value like `'9999-99-99'`. Call sequence: `defaultIntentPayloadFactory` executes `new Date(params.deadline)`, which for an invalid string yields `Invalid Date`; `.toISOString()` on an Invalid Date throws, OR for a parseable-but-attacker-chosen far-future string, `nonceDeadline = new Date(deadline.getTime() + DEFAULT_NONCE_DEADLINE_OFFSET_MS)` is computed from that same string and baked into `VersionedNonceBuilder.encodeNonce`. Equality broken: deadline in the signed payload != any deadline the caller's own application logic computed/displayed if the caller only reviewed a truncated or default value before an integrator-forwarded override reached the factory. Impact: Critical - a nonce with an attacker-influenced deadline far in the future can be encoded and signed, extending the validity window of a signature beyond what the signing UI represented, exposing funds to delayed unauthorized execution.
