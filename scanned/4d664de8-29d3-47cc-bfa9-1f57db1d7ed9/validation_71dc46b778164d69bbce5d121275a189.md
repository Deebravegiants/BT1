## Title
Cross-user response hijack via `MessageID` collision in the WebAPI Trigger capability handler's `savedCallbacks` map - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
The PraisonAI advisory's root cause is that the browser bridge routes a response back to *whichever* connection is currently associated with a session identifier, without verifying that the identifier still belongs to the original requester — allowing an unauthenticated party to overwrite/claim the routing slot and receive another party's automation output. The Chainlink Gateway's `capabilities` handler has the analogous flaw: the map that ties a pending node response back to the calling user's callback is keyed purely by an attacker-supplied `MessageID`, with no check for an existing/in-flight entry before it is overwritten.

### Finding Description
Any request into the Gateway's HTTP endpoint is decoded and dispatched with no session, allowlist, or per-request authentication of "who is entitled to this MessageID" — `handleRequest`/`ProcessRequest` accept any syntactically valid signed message and route it into the handler. [1](#0-0) [2](#0-1) 

`api.Message.Validate()` only checks that the ECDSA signature is well-formed and recovers a signer address — it does not check that the signer is on any allowlist for the DON/handler, nor that `MessageID` is unbiased/unpredictable: [3](#0-2) 

The WebAPI trigger capability handler's `HandleLegacyUserMessage` stores the caller's `callback` in `h.savedCallbacks` keyed only by the caller-controlled `msg.Body.MessageID`, with **no check for an existing in-flight entry** before the write, unlike the newer HTTP trigger handler which explicitly detects and rejects a duplicate ID: [4](#0-3) 
compare to the presence of such a check elsewhere in the codebase: [5](#0-4) 

When a node later responds, the handler looks the response up **solely by `MessageID`** and delivers it to whatever callback currently occupies that map slot: [6](#0-5) 

The legacy `dummyHandler` (also wired for JSON-RPC service dispatch) has the identical pattern — `MessageID` taken straight from the untrusted `jsonRequest.ID`, stored/overwritten without a duplicate check, and the corresponding node response is delivered by ID lookup alone: [7](#0-6) 

Consequently, if a legitimate user's request with `MessageID = X` is in flight (its `savedCallbacks[X]` entry created, awaiting a DON node's asynchronous response), an unprivileged second caller who submits *any* validly-signed message reusing the same `X` before the node responds will overwrite `savedCallbacks[X]` with their own callback. When the DON node later responds for `X`, `handleWebAPITriggerMessage`/`HandleNodeMessage` finds the attacker's callback in the map and delivers the *victim's* response data to the attacker — a direct cross-user response confusion, structurally identical to the PraisonAI flaw where any client could occupy a session's response-forwarding slot by omitting authentication and simply "getting there first."

A code review comment in the corresponding test file explicitly flags that no sender/allowlist validation is enforced at this layer, underscoring the trust gap: [8](#0-7) 

### Impact Explanation
An unauthenticated/unprivileged network caller of the Gateway's public HTTP `/` endpoint (any party able to produce a syntactically valid ECDSA-signed message — no DON membership or allowlist required at this layer) can hijack another in-flight WebAPI-trigger caller's response by colliding on `MessageID`, receiving data intended for someone else's request. This is a concrete cross-user response confusion vulnerability in the internet-facing gateway message envelope/handler path.

### Likelihood Explanation
Exploitation requires only: (1) knowledge or guessability of a target's `MessageID` (often predictable/sequential or observable via shared infrastructure/logs), and (2) winning a race to submit a colliding request before the DON node responds to the original. Both handlers affected (`capabilities/handler.go` and `handler.dummy.go`) impose no rate limiting or allowlist at the point the `savedCallbacks` entry is created, and neither rejects a duplicate/colliding ID, so the race is straightforward to attempt repeatedly.

### Recommendation
Add a duplicate-ID guard to `HandleLegacyUserMessage`/`HandleJSONRPCUserMessage` in both `core/services/gateway/handlers/capabilities/handler.go` and `core/services/gateway/handlers/handler.dummy.go`, mirroring the conflict check already implemented in `core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go` (`setupCallback`), so a second request cannot silently overwrite another caller's pending callback for the same `MessageID`. Additionally, bind `MessageID` (or a derived key) to the requester's signer address when looking up `savedCallbacks`, so a node response can only ever be routed to the callback of the same signer that originated the request.

### Proof of Concept
1. Submit a validly-signed WebAPI trigger `api.Message` with `MessageID = "victim-id"` to the Gateway HTTP endpoint as User A; the handler stores `savedCallbacks["victim-id"] = <User A callback>` and forwards it to DON nodes [9](#0-8) .
2. Before a node responds, submit a second, independently signed message with the same `MessageID = "victim-id"` as User B (any valid signature passes `Validate()`, no sender allowlist is enforced) — this overwrites `savedCallbacks["victim-id"]` with User B's callback.
3. When a DON node responds for `MessageID = "victim-id"`, `handleWebAPITriggerMessage` looks up the map entry and delivers the response to whichever callback is currently stored — User B — even though the response corresponds to User A's original triggered request [10](#0-9) .

func (s *httpServer) handleRequest(w http.ResponseWriter, r *http.Request) {
	if s.config.CORSEnabled {
		origin := r.Header.Get("Origin")
		if s.isAllowedOrigin(origin) {
			w.Header().Set("Access-Control-Allow-Origin", origin)
			w.Header().Set("Access-Control-Allow-Methods", "GET, POST, OPTIONS")
			w.Header().Set("Access-Control-Allow-Headers", "Content-Type")
		}

		// handle preflight requests
		if r.Method == http.MethodOptions {
			w.WriteHeader(http.StatusNoContent)
			return
		}
	}

	maxRequestBytes, err := s.config.MaxRequestBytesLimiter.Limit(r.Context())
	if err != nil {
		msg := "Failed to get request size limit"
		s.lggr.Errorw(msg, "err", err)
		http.Error(w, msg, http.StatusInternalServerError)
		return
	}
	source := http.MaxBytesReader(nil, r.Body, int64(maxRequestBytes))
	rawMessage, err := io.ReadAll(source)
	if err != nil {
		s.lggr.Error("error reading request", err)
		w.WriteHeader(http.StatusBadRequest)
		return
	}

	// Optionally extract jwt token from authorization header
	authHeader := r.Header.Get("Authorization")
	jwtToken := ""
	if authHeader != "" {
		jwtToken = strings.TrimPrefix(authHeader, "Bearer ")
	}

	startTime := time.Now()
	rawResponse, httpStatusCode := s.handler.ProcessRequest(r.Context(), rawMessage, jwtToken)

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	isLegacyRequest := false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonID == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonID
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageID) == 0 || len(m.Body.MessageID) > MessageIDMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageID, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonID) == 0 || len(m.Body.DonID) > MessageDonIDMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonID, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

func (d *dummyHandler) HandleJSONRPCUserMessage(ctx context.Context, jsonRequest jsonrpc.Request[json.RawMessage], callback Callback) error {
	var msg api.Message
	if jsonRequest.Params != nil {
		if err := json.Unmarshal(*jsonRequest.Params, &msg); err != nil {
			return err
		}
	}
	msg.Body.MessageID = jsonRequest.ID
	if msg.Body.Method == "" {
		msg.Body.Method = jsonRequest.Method
	}
	if msg.Body.DonID == "" {
		msg.Body.DonID = d.donConfig.DonID
	}
	return d.HandleLegacyUserMessage(ctx, &msg, callback)
}

func (d *dummyHandler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback Callback) error {
	d.mu.Lock()
	d.savedCallbacks[msg.Body.MessageID] = &savedCallback{msg.Body.MessageID, callback}
	don := d.don
	d.mu.Unlock()
	params, err := json.Marshal(msg)
	if err != nil {
		return err
	}
	rawParams := json.RawMessage(params)
	req := &jsonrpc.Request[json.RawMessage]{
		Version: "2.0",
		ID:      msg.Body.MessageID,
		Method:  msg.Body.Method,
		Params:  &rawParams,
	}
	for _, member := range d.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

func (d *dummyHandler) HandleNodeMessage(ctx context.Context, resp *jsonrpc.Response[json.RawMessage], nodeAddr string) error {
	var msg api.Message
	err := json.Unmarshal(*resp.Result, &msg)
	if err != nil {
		return err
	}
	msg.Body.MessageID = resp.ID
	err = msg.Validate()
	if err != nil {
		return err
	}
	if nodeAddr != msg.Body.Sender {
		return fmt.Errorf("node address %s does not match message sender %s", nodeAddr, msg.Body.Sender)
	}
	d.mu.Lock()
	savedCb, found := d.savedCallbacks[msg.Body.MessageID]
	delete(d.savedCallbacks, msg.Body.MessageID)
	d.mu.Unlock()

	if found {
		// Send first response from a node back to the user, ignore any other ones.
		codec := api.JSONRPCCodec{}
		return savedCb.SendResponse(UserCallbackPayload{RawResponse: codec.EncodeLegacyResponse(&msg), ErrorCode: api.NoError})
	}
	return nil
