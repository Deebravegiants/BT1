# Q2693: myshopify_domain_from_unified_admin — validated value discarded via empty path segment

## Question
Trace `ShopValidator.myshopify_domain_from_unified_admin` from `myshopify_domain_from_unified_admin`, which returns `"#{uri.path.split('/').last}.myshopify.com"` from an unvalidated path segment with a unified-admin URL whose path ends in a slash or is empty, so `path.split('/').last` yields `nil` or the literal store name of another merchant: because the caller validates one string but interpolates a different, unvalidated one into the URL or the session id, does the value that was verified stop being the value that is used?
