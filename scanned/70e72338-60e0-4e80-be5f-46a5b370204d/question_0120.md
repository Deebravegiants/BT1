# Q0120: mask-shift-combine via collateral-add: destroy value through a truncation the opposite operation 

## Question
Does `collateral-add` (mainnet/contracts/market/v0-4-market.clar:1020) let an unprivileged attacker who controls call ordering within the block reach `mask-shift-combine` (mainnet/contracts/market/v0-4-market.clar:422) in a state where it destroy value through a truncation the opposite operation does not restore?
