### Title
Client-controlled JSON-RPC request ID used as sole correlation key for gateway callback routing enables cross-user response hijacking - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
The Agave report describes a bug class where an untrusted external call is allowed to happen mid-operation with state that is later trusted to finalize a transfer to the wrong party. The reachable analog in this codebase is the Chainlink Gateway's legacy WebAPI trigger flow: the correlation key used to route an asynchronous DON node response back to the originating HTTP client (`savedCallbacks[MessageID]`) is derived entirely from the client-supplied JSON-RPC request `ID`, which is only length-checked, not validated for uniqueness or bound to the caller's session/connection. A second unprivileged client can supply the same ID as an in-flight request and overwrite the map entry before the legitimate node response arrives, causing the DON's response to be delivered to the wrong client.

### Finding Description
In `core/services/gateway/gateway.go`, `ProcessRequest` decodes the incoming client JSON-RPC request and only checks that `jsonRequest.ID` is not longer than 200 characters: [1](#0-0) 

For legacy DON-routed requests, `ValidatedMessageFromReq` sets the internal `MessageID` directly equal to this attacker-controlled `req.ID`: [2](#0-1) 

`HandleLegacyUserMessage` then stores the caller's `Callback` in a shared map keyed purely by this `MessageID`, with no per-connection nonce, session binding, or collision check against currently in-flight requests: [3](#0-2) 

When any DON node later responds with that same `MessageID`, `handleWebAPITriggerMessage` looks up the map, deletes the entry, and routes whichever `Callback` object is stored there — not necessarily the one for the request that actually produced that response: [4](#0-3) 

The same unguarded, client-ID-keyed map pattern exists in the `dummyHandler`: [5](#0-4) 

This is structurally the same class of bug as the Agave incident: an operation (`handleWebAPITriggerMessage`) trusts state (`savedCallbacks[MessageID]`) that was populated based on unauthenticated/unvalidated external input (`MessageID` chosen by any unprivileged HTTP client), and that state can be overwritten between the time it is set and the time it is consumed by another untrusted actor picking the same key — a time-of-check/time-of-use race exploitable purely from the internet-facing gateway endpoint.

### Impact Explanation
If an attacker can predict or brute-force (or simply reuse) another concurrent user's `MessageID` and submit their own request with that same ID while the legitimate request is still in flight, the attacker's `savedCallback` entry overwrites the victim's. When the DON node responds for the (attacker's or victim's) trigger, whichever callback currently occupies that map slot receives the payload. This can:
- Deliver another user's workflow trigger response (including any data server-side computed for that user) to the attacker (cross-user response confusion / information disclosure).
- Cause a legitimate user's request to receive no response or an unrelated error, denying/hijacking their workflow trigger.

Given the WebAPI trigger path can be used to invoke workflow executions, response hijacking can leak execution results a workflow owner did not intend to share with the requesting party.

### Likelihood Explanation
Likelihood is moderate: the `MessageID` is fully attacker-controlled (only bounded to ≤200 chars, no format/uniqueness enforcement), the map is process-wide (`h.savedCallbacks`) and shared across all clients hitting the same DON handler, and the race window is the round trip time to all DON members plus node processing time — long enough for an attacker to time a colliding request. No authentication beyond reaching the public gateway HTTP endpoint is required, satisfying the "unprivileged actor" and "internet-facing gateway" scope.

### Recommendation
- Generate the `savedCallbacks` map key server-side (e.g., a gateway-generated UUID/nonce not derived from client input), and map the client-visible request ID to this internal key only for response correlation.
- If the client ID must remain part of the key, bind it to the connection/session (e.g., prefix with a per-connection or per-caller unique token) so collisions across different callers are impossible.
- On insert, detect and reject if an unexpired entry already exists for the same key rather than silently overwriting it.

### Proof of Concept
1. Attacker sends a WebAPI trigger request to the gateway's legacy endpoint with `id: "X"`.
2. Concurrently, a victim's client (or another workflow caller) also sends a request that ends up with the same JSON-RPC ID `"X"` (attacker can simply also choose the same literal string, since IDs are entirely user-supplied and not required to be unique/random).
3. `HandleLegacyUserMessage` for the second request overwrites `h.savedCallbacks["X"]` set by the first, per: [6](#0-5) 
4. When the DON node responds for MessageID `"X"`, `handleWebAPITriggerMessage` delivers the payload to whichever caller's callback is currently stored under that key — potentially the attacker instead of the original requester: [4](#0-3)

		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())

		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")

// ValidatedMessageFromReq validated and extracts a legacy Gateway Message
// from params field of JSON-RPC request
func ValidatedMessageFromReq(req *jsonrpc.Request[json.RawMessage]) (*api.Message, error) {
	if req.Version != "2.0" {
		return nil, errors.New("incorrect jsonrpc version")
	}
	if req.Method == "" {
		return nil, errors.New("empty method field")
	}
	if req.Params == nil {
		return nil, errors.New("missing params attribute")
	}
	var m api.Message
	err := json.Unmarshal(*req.Params, &m)
	if err != nil {
		return nil, fmt.Errorf("failed to unmarshal request params: %w", err)
	}
	m.Body.Method = req.Method
	m.Body.MessageID = req.ID
	err = m.Validate()
	if err != nil {
		return nil, err
	}
	return &m, nil
}

func (h *handler) handleWebAPITriggerMessage(ctx context.Context, msg *api.Message, nodeAddr string) error {
	h.mu.Lock()
	savedCb, found := h.savedCallbacks[msg.Body.MessageID]
	delete(h.savedCallbacks, msg.Body.MessageID)
	h.mu.Unlock()

	if found {
		// Send first response from a node back to the user, ignore any other ones.
		// TODO: in practice, we should wait for at least 2F+1 nodes to respond and then return an aggregated response
		// back to the user.
		codec := api.JSONRPCCodec{}
		return savedCb.SendResponse(handlers.UserCallbackPayload{RawResponse: codec.EncodeLegacyResponse(msg), ErrorCode: api.NoError})
	}
	return nil
}

func (d *dummyHandler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback Callback) error {
	d.mu.Lock()
	d.savedCallbacks[msg.Body.MessageID] = &savedCallback{msg.Body.MessageID, callback}
	don := d.don
	d.mu.Unlock()
	params, err := json.Marshal(msg)
	if err != nil {
		return err
	}
	rawParams := json.RawMessage(params)
	req := &jsonrpc.Request[json.RawMessage]{
		Version: "2.0",
		ID:      msg.Body.MessageID,
		Method:  msg.Body.Method,
		Params:  &rawParams,
	}
	for _, member := range d.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

func (d *dummyHandler) HandleNodeMessage(ctx context.Context, resp *jsonrpc.Response[json.RawMessage], nodeAddr string) error {
	var msg api.Message
	err := json.Unmarshal(*resp.Result, &msg)
	if err != nil {
		return err
	}
	msg.Body.MessageID = resp.ID
	err = msg.Validate()
	if err != nil {
		return err
	}
	if nodeAddr != msg.Body.Sender {
		return fmt.Errorf("node address %s does not match message sender %s", nodeAddr, msg.Body.Sender)
	}
	d.mu.Lock()
	savedCb, found := d.savedCallbacks[msg.Body.MessageID]
	delete(d.savedCallbacks, msg.Body.MessageID)
	d.mu.Unlock()

	if found {
		// Send first response from a node back to the user, ignore any other ones.
		codec := api.JSONRPCCodec{}
		return savedCb.SendResponse(UserCallbackPayload{RawResponse: codec.EncodeLegacyResponse(&msg), ErrorCode: api.NoError})
	}
	return nil
