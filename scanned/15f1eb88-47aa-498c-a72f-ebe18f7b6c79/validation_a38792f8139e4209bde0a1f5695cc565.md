### Title
Unauthenticated Internal Health-Check Disclosure via `/readyz?full=true` - (File: `core/web/health_controller.go`)

### Summary
Chainlink's node HTTP API mounts `/readyz`, `/health`, and `/health.txt` in a route group that has no authentication middleware, and the `Readyz` handler discloses full per-service check names and internal error output whenever the caller supplies a `full` query parameter — exactly the "unauthenticated infrastructure/status disclosure" bug class described in the AVideo report, where a no-auth endpoint reveals internal remote-service state.

### Finding Description
`healthRoutes` registers `Readyz`, `PublicReadyz`, `Health`, and `Health.txt` on the same top-level `api` router group used for the rest of the node's HTTP surface: [1](#0-0) 

That group only applies rate limiting and session middleware — no `auth.Authenticate(...)` gate is attached to it or to the health routes specifically, unlike, e.g., the GraphQL `/query` endpoint a few lines below which explicitly wires `auth.AuthenticateGQL`: [2](#0-1) [3](#0-2) 

`Readyz` (unlike the intentionally-limited `PublicReadyz`) returns detailed per-check names, pass/fail status, and raw error `Output` strings whenever the request includes `?full`: [4](#0-3) 

The code comment on `PublicReadyz` itself acknowledges that `Readyz` is reachable by unauthenticated/public callers and can leak internal service state, which is precisely why `PublicReadyz` was introduced as a "safe" sibling — but the original, more verbose `Readyz` (and `Health`) endpoints remain exposed on the same unauthenticated group: [5](#0-4) 

This mirrors the AVideo bug class: a diagnostic/status endpoint that is reachable without authentication while its sibling endpoints in the same subsystem are properly gated, revealing backend service/reporter internals (service names, failure messages) to an unauthenticated actor.

### Impact Explanation
An unauthenticated remote caller can enumerate all registered health reporters (e.g., internal job spawners, chain-specific reporters, mailbox monitors, RPC pools) and read raw error messages from `IsReady()`/`IsHealthy()` checks. This is reconnaissance-only — it does not by itself grant authentication bypass, secret disclosure, or fund movement — matching the "Medium/Low direct impact, aids targeted attack planning" characterization in the source report.

### Likelihood Explanation
High reachability: `/readyz?full=true` and `/health` are reachable from any unauthenticated network client that can reach the node's web server, with no session or API key required, since the enclosing route group applies only rate limiting, not authentication.

### Recommendation
Require authentication (or restrict to an internal-only network/route) for the verbose `Readyz`/`Health` full-detail responses, or make `full=true` behavior consistent with `PublicReadyz` — i.e., strip per-check names/output for unauthenticated callers and only expose overall pass/fail status publicly.

### Proof of Concept
```bash
curl "https://your-node:6688/readyz?full=true"
curl "https://your-node:6688/health"
```
No session cookie or API key is required to receive the detailed JSON/HTML/text body listing every internal health check and its error output. [6](#0-5)

// PublicReadyz is a minimal readiness endpoint intended for public load balancer health checks.
// Unlike Readyz, it never returns per-check details regardless of query parameters, to avoid
// leaking internal service state on publicly reachable endpoints.
func (hc *HealthController) PublicReadyz(c *gin.Context) {
	ready, _ := hc.App.GetHealthChecker().IsReady()
	if !ready {
		c.Status(http.StatusServiceUnavailable)
		return
	}
	c.Status(http.StatusOK)
}

func (hc *HealthController) Readyz(c *gin.Context) {
	status := http.StatusOK

	checker := hc.App.GetHealthChecker()

	ready, errors := checker.IsReady()

	if !ready {
		status = http.StatusServiceUnavailable
	}

	c.Status(status)

	if _, ok := c.GetQuery("full"); !ok {
		return
	}

	checks := make([]presenters.Check, 0, len(errors))

	for name, err := range errors {
		status := HealthStatusPassing
		var output string

		if err != nil {
			status = HealthStatusFailing
			output = err.Error()
		}

		checks = append(checks, presenters.Check{
			JAID:   presenters.NewJAID(name),
			Name:   name,
			Status: status,
			Output: output,
		})
	}

	// return a json description of all the checks
	jsonAPIResponse(c, checks, "checks")
}

func TestHealthController_PublicReadyz(t *testing.T) {
	t.Parallel()
	var tt = []struct {
		name   string
		ready  bool
		status int
	}{
		{
			name:   "not ready",
			ready:  false,
			status: http.StatusServiceUnavailable,
		},
		{
			name:   "ready",
			ready:  true,
			status: http.StatusOK,
		},
	}
	for _, tc := range tt {
		t.Run(tc.name, func(t *testing.T) {
			t.Parallel()
			app := cltest.NewApplicationWithKey(t)
			healthChecker := new(mocks.Checker)
			healthChecker.On("Start").Return(nil).Once()
			healthChecker.On("IsReady").Return(tc.ready, nil)
			healthChecker.On("Close").Return(nil).Once()

			app.HealthChecker = healthChecker
			require.NoError(t, app.Start(t.Context()))

			client := app.NewHTTPClient(nil)

			// Base path returns status only, no body.
			resp, cleanup := client.Get("/public-readyz")
			t.Cleanup(cleanup)
			assert.Equal(t, tc.status, resp.StatusCode)
			body, err := io.ReadAll(resp.Body)
			require.NoError(t, err)
			assert.Empty(t, body)

			// ?full=true must NOT expose per-check details on this endpoint.
			respFull, cleanupFull := client.Get("/public-readyz?full=true")
			t.Cleanup(cleanupFull)
			assert.Equal(t, tc.status, respFull.StatusCode)
			bodyFull, err := io.ReadAll(respFull.Body)
			require.NoError(t, err)
			assert.Empty(t, bodyFull)
		})
	}
}
