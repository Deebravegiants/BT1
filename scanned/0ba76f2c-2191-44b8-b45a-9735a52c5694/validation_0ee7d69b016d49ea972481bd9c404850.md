Confirmed: `loopRoutes` is mounted with no authentication middleware at all, unlike every other sensitive route group (`debugRoutes`, `sessionRoutes`, `v2Routes`) which explicitly wrap themselves in `auth.Authenticate(...)`.

### Title
Unauthenticated LOOP plugin metrics/pprof proxy allows internal service access via `/plugins/:name/...` - (File: `core/web/router.go`)

### Summary
The Chainlink node's HTTP router mounts `loopRoutes`, which exposes `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol`, directly on the top-level `api` router group with no authentication middleware, while every comparable sensitive route group (`debugRoutes`, `sessionRoutes`, `v2Routes`) is explicitly wrapped with `auth.Authenticate(...)`.

### Finding Description
`NewRouter` registers route groups in sequence: `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, `loopRoutes` [1](#0-0) . `debugRoutes` requires session authentication before exposing `/debug/vars` [2](#0-1) , and `v2Routes`/`sessionRoutes` similarly gate behind `auth.Authenticate` [3](#0-2) . In contrast, `loopRoutes` registers its handlers directly on the passed-in group with no auth wrapper: `r.GET("/discovery", ...)`, `r.GET("/plugins/:name/metrics", ...)`, `r.GET("/plugins/:name/debug/pprof/*profile", ...)`, `r.POST("/plugins/:name/debug/pprof/symbol", ...)` [4](#0-3) .

`pluginMetricHandler` takes the unauthenticated user-supplied `:name` path param, looks it up in the LOOP registry, and if found, proxies a live HTTP GET to an internal-only backend at `http://<loopHostName>:<PrometheusPort>/metrics`, returning the raw response body to the caller [5](#0-4) . `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` do the same for the plugin's internal `/debug/pprof/*` and `/debug/pprof/symbol` endpoints, forwarding query parameters (`debug`, `gc`, `seconds`) and, for the symbol endpoint, the raw POST body, unauthenticated, straight to the internal backend [6](#0-5) . The code comment even acknowledges these are meant to be internal-only: "unlike discovery, this endpoint is internal btw the node and plugin" [7](#0-6) .

This mirrors the root cause of BIT-gitlab-2022-2531: an internet-facing gateway path failed to require authentication before proxying requests to an internal-only monitoring/debug backend (Grafana in GitLab's case, LOOP plugin pprof/metrics servers here), allowing an unauthenticated actor to reach an internal service through the node's public API surface.

### Impact Explanation
An unauthenticated network client that can reach the Chainlink node's HTTP port can enumerate registered LOOP plugins via `/discovery` and then pull live `pprof` profiles (`heap`, `goroutine`, `profile`, `trace`, `allocs`, etc. via `*profile`) and Prometheus `/metrics` output for any plugin process. `pprof` and metrics endpoints on Go services routinely leak runtime memory contents, internal state, configuration values, goroutine stacks, and can be abused for resource-exhaustion (e.g., long-running `profile`/`trace` captures via the `seconds` query param). This is an authentication-bypass exposing internal diagnostic surface to any unprivileged network caller.

### Likelihood Explanation
High. No credentials, session, tokens, or special network position are required — only network reachability to the node's public HTTP listener, which is the same listener serving the operator UI and API. The plugin name is directly attacker-suppliable via the URL path and matched against the live registry, so the only prerequisite is that at least one LOOP plugin is registered (a normal deployment condition for chains implemented as LOOPPs).

### Recommendation
Wrap `loopRoutes` in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or a dedicated admin-role check) middleware used by `debugRoutes` and `v2Routes`, or move these endpoints off the public-facing router entirely onto a separate internal-only listener/port not exposed externally.

### Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered (e.g., an EVM-adjacent chain LOOPP).
2. As an unauthenticated client, send `GET /discovery` to the node's HTTP port; observe the JSON list of registered plugin names and their metrics paths.
3. Send `GET /plugins/<name>/metrics` with no session cookie or auth header; the response returns the plugin's internal Prometheus metrics.
4. Send `GET /plugins/<name>/debug/pprof/heap?debug=1` with no authentication; the response returns a live heap dump forwarded from the plugin's internal debug server.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
