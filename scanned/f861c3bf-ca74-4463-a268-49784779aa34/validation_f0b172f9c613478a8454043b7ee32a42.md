### Title
Unauthenticated Exposure of Internal LOOP Plugin Debug/PPROF and Metrics Endpoints via Router Group Missing Auth Middleware - (File: core/web/router.go)

### Summary
The Spring advisory describes a bug class where routes declared through a router DSL fail to inherit the security filter chain applied to sibling routes, letting unprivileged clients reach handlers that were assumed to be protected. The chainlink node HTTP router exhibits the same structural pattern: in `NewRouter`, `debugRoutes`, `sessionRoutes`, and `v2Routes` each explicitly wrap their route groups with `auth.Authenticate(...)`, but `loopRoutes` is mounted directly on the top-level `api` group with no authentication middleware at all. [1](#0-0) 

### Finding Description
`NewRouter` builds an `api` group that only has rate limiting and cookie-session middleware attached — not user authentication — and then registers several route groups on it: [2](#0-1) 

Each of the other route-registration functions applies its own explicit authentication middleware before exposing sensitive handlers, e.g. `debugRoutes` wraps `/debug` with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`, and `sessionRoutes` similarly gates `/sessions` deletion: [3](#0-2) [4](#0-3) 

`loopRoutes`, however, registers its handlers directly on the passed-in group with no call to `auth.Authenticate`: [5](#0-4) 

The handlers themselves (`discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`) perform no authentication or authorization checks internally — they assume the router has already gated access, exactly as in the Spring DSL bypass where handlers relied on the router's filter chain rather than validating access themselves. [6](#0-5) [7](#0-6) 

Because `loopRoutes(app, api)` is called on the unauthenticated `api` group, any client with network access to the node's HTTP API can reach `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` without any credentials.

### Impact Explanation
An unprivileged client (no session cookie, no API token) that can reach the node's HTTP API can:
- Enumerate registered LOOP plugins and their internal Prometheus discovery targets via `/discovery`.
- Pull raw Prometheus metrics from any named plugin via `/plugins/:name/metrics`, which is proxied straight to the plugin's internal metrics port.
- Trigger and retrieve full Go `pprof` profiles (heap, goroutine, allocs, CPU profile, block, mutex, threadcreate) from internal LOOP plugin processes via `/plugins/:name/debug/pprof/*profile`, which can leak process memory contents, stack traces, and potentially embedded secrets/keys held in memory by the plugin, and can also be used to induce CPU/latency-based DoS by requesting expensive profiles (e.g., `seconds=N` CPU profile) repeatedly.

This matches the advisory's bug class (CWE-284, unprivileged-actor bypass of a security filter due to a router registration gap), scoped here to the node's internet/network-facing API rather than a mocked or operator-only path.

### Likelihood Explanation
High reachability: this is a direct, unauthenticated HTTP endpoint on the node's primary web API, requiring only network access to the configured API port — no credentials, tokens, or session are needed, and no other guard exists in `loop_registry.go` to compensate for the missing router-level `auth.Authenticate` call.

### Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession, auth.AuthenticateByToken)` pattern used by `debugRoutes`/`sessionRoutes`/`v2Routes` (with an appropriate role requirement, e.g. `auth.RequiresAdminRole`, since these are operational/debug endpoints), or explicitly document/verify that this exposure is intentional and restricted at the network layer, and add regression tests analogous to `TestRBAC_Routemap_Admin` in `core/web/auth/auth_test.go` asserting that `/discovery`, `/plugins/:name/metrics`, and the pprof proxy routes return `401/403` without credentials.

### Proof of Concept
Against a running chainlink node with the HTTP API reachable and at least one LOOP plugin registered:
```
curl http://<node-host>:<api-port>/discovery
curl http://<node-host>:<api-port>/plugins/<plugin-name>/metrics
curl "http://<node-host>:<api-port>/plugins/<plugin-name>/debug/pprof/heap"
curl "http://<node-host>:<api-port>/plugins/<plugin-name>/debug/pprof/profile?seconds=30"
```
No `X-API-KEY`/`X-API-SECRET` headers or session cookie are sent, yet the router forwards the request straight to `loopRegistry.discoveryHandler` / `pluginMetricHandler` / `pluginPPROFHandler`, which respond with plugin metadata, metrics, or a full pprof dump, confirming the missing-authentication route registration in `loopRoutes` (`core/web/router.go:230-236`).

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
