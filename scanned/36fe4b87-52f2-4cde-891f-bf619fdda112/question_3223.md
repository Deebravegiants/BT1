# Q3223: calc-multiplier-delta via call-ststx-ratio: count one deposit as backing for two simultaneous claims

## Question

Can an unprivileged caller of `call-ststx-ratio` (mainnet/contracts/market/v0-4-market.clar:1015), by choosing whether the ratio is fetched before or after other state changes in the block, use that to count one deposit as backing for two simultaneous claims, violating the invariant that every round-up has a paired round-down that repetition cannot exploit and producing direct theft of user funds at rest or in motion?
