# Q4326: get-bitmap via collateral-remove: destroy value through a truncation the opposite operation 

## Question

- Invariant to test: `assets` never exceeds the underlying the vault actually holds

- Fast validation: Fuzz whether the position has any enabled debt row (the has-debt branch) across its boundary values through `collateral-remove` in simnet and assert `get-bitmap` never returns a value that breaks the invariant.
