Attacker action: GET /install?shop=evil.attacker.example on the host app's install route, which forwards `shop` straight into `ShopifyAPI::Auth::Oauth.begin_auth(shop:, redirect_path:)` as documented. Impact: High -> SSRF/redirect of the authorize URL (containing api_key/client_id and the one-time `state` nonce) to an attacker-controlled host, enabling forced-OAuth-completion / session fixation against a victim who follows the crafted install link.
