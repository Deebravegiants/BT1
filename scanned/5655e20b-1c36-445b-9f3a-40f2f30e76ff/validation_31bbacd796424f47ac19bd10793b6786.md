### Title
Missing Authentication on LOOP Plugin `/pprof`, `/metrics`, and `/discovery` Endpoints Enables Unauthenticated Denial of Service - (File: core/web/router.go)

### Summary
The Chainlink node's HTTP router registers the LOOP plugin debug and metrics routes (`loopRoutes`) without any authentication middleware, unlike every other debug-capable route in the same file. This mirrors the Chaos Mesh bug class (CWE-306, missing auth on a "critical" debugging function reachable cluster-/network-wide), here allowing any unauthenticated client with network access to the node's HTTP port to trigger CPU/heap/trace profiling and read internal metrics of LOOP plugin processes.

### Finding Description
`NewRouter` mounts `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` on the same `api` group, which is only wrapped by rate limiting and session middleware — not authentication: [1](#0-0) 

`debugRoutes` explicitly requires a valid authenticated session before exposing `/debug/vars`: [2](#0-1) 

The node's own pprof handlers (`metricRoutes`) are likewise only reachable through the authenticated `/v2` group gated by `auth.Authenticate` (confirmed by `core/cmd/shell_remote_test.go` expecting `401 Unauthorized` when unauthenticated): [3](#0-2) 

However, `loopRoutes` registers plugin discovery, metrics, and pprof endpoints directly on the unauthenticated `api` group with **no** `auth.Authenticate` wrapper at all: [4](#0-3) 

These handlers proxy the request straight through to the internal LOOP plugin process's pprof/metrics server: [5](#0-4) [6](#0-5) [7](#0-6) 

`pluginPPROFHandler` accepts an attacker-controlled `seconds` query parameter that is forwarded verbatim to the plugin's `/debug/pprof/{profile}` endpoint (e.g., `profile`, `trace`), letting an unauthenticated caller hold open CPU/goroutine/mutex profiling sessions on internal LOOP processes: [8](#0-7) 

### Impact Explanation
An unauthenticated, unprivileged network client can repeatedly invoke `/plugins/:name/debug/pprof/profile?seconds=<N>` (or `/trace`) against any registered LOOP plugin, forcing sustained CPU sampling/tracing on plugin processes that run core chain-integration logic (EVM/OCR2 LOOPPs, etc.). Concurrent or repeated requests degrade or exhaust plugin CPU/goroutines, causing denial of service to job execution paths dependent on that plugin, comparable in class to the Chaos Mesh advisory's "cluster-wide denial of service" impact, but scoped to node-local plugin availability. The `/plugins/:name/metrics` and `/discovery` endpoints also leak internal plugin names, hostnames, and Prometheus metrics without authentication, an information-disclosure side effect (CWE-306: Missing Authentication for Critical Function).

### Likelihood Explanation
Likelihood is high for any node that runs LOOP plugins and exposes its API port to a network-reachable/unprivileged actor: the route requires no credentials, no CSRF token, and no rate-limiting beyond the generic API rate limiter, and the plugin name is discoverable via the also-unauthenticated `/discovery` endpoint.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof/metrics/discovery sub-routes) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `/v2/debug/pprof/*` and `/debug/vars`, and apply role checks (e.g., `auth.RequiresAdminRole`) consistent with the node's other profiling/debug endpoints.

### Proof of Concept
```
# Discover a running LOOP plugin name (unauthenticated)
curl http://<node>:6688/discovery

# Trigger unauthenticated 60s CPU profiling on the plugin process
curl "http://<node>:6688/plugins/<plugin_name>/debug/pprof/profile?seconds=60"

# Repeat concurrently from multiple clients to sustain CPU load / DoS
```
No `X-Chainlink-EA-AccessKey`/API key, session cookie, or any `Authorization` header is required, in contrast to `/v2/debug/pprof/*`, which returns `401 Unauthorized` without a valid session.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

const PPROFOverheadSeconds = 30

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

		pluginURL += "?" + s
	}

	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
