### Title
Unauthenticated exposure of internal LOOP plugin `pprof` debugging endpoint via `/plugins/:name/debug/pprof/*profile` - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
The Chainlink node's LOOP (Loosely-coupled OCR Plugin) plugin metrics/pprof proxy routes are registered on the node's public API router without any authentication middleware, unlike the equivalent `/debug/pprof` and `/debug/vars` routes which are explicitly wrapped in `auth.Authenticate`.

### Finding Description
`NewRouter` mounts several route groups onto a shared `api` group that only applies rate limiting and session-cookie middleware — not authentication: [1](#0-0) 

`debugRoutes`, which exposes `/debug/vars`, explicitly requires session authentication via `auth.Authenticate(...)`: [2](#0-1) 

The standard `net/http/pprof` handlers registered by `metricRoutes` (`/debug/pprof/*`) are defined but this function is never invoked anywhere in the router setup (confirmed via search — `metricRoutes` only appears in its own definition), so that particular pprof group is dead code and not reachable.

However, `loopRoutes` — which *is* mounted directly on the unauthenticated `api` group with no auth middleware — exposes: [3](#0-2) 

Specifically `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` proxy arbitrary requests to an internal plugin process's `/debug/pprof/<profile>` endpoint (including `heap`, `goroutine`, `trace`, `cmdline`, `profile`, `symbol`), forwarding query parameters (`debug`, `gc`, `seconds`) and POST bodies directly to the plugin's internal HTTP server without checking any session/auth context: [4](#0-3) 

The `doRequest` helper performs the outbound call and returns the raw response body to the caller unmodified: [5](#0-4) 

The comment "unlike discovery, this endpoint is internal btw the node and plugin" indicates the intent was for this to be an internal-only bridge, but no authentication gate enforces that on the inbound side — any client that can reach the node's HTTP API port can invoke it.

### Impact Explanation
An unauthenticated remote client that can reach the Chainlink node's web/API port can pull full `pprof` profiles (`heap`, `goroutine`, `cmdline`, `trace`, `profile`) and symbol data from any registered LOOP plugin process. This can leak internal memory addresses, goroutine stacks, command-line arguments, and potentially sensitive data resident in plugin process memory (e.g. configuration values, keys held by the plugin), and can be used for a denial-of-service by triggering long-running CPU/trace profiles (`?seconds=`) against the plugin, consuming plugin resources — directly analogous to CVE-2019-11248's unauthenticated pprof exposure over Kubelet's healthz port.

### Likelihood Explanation
Likelihood is high if the LOOP plugin architecture is enabled and the node's API port is reachable by an unprivileged actor (e.g., exposed to other services in a k8s cluster, or accessible before/without a valid session). Because the route group itself has no auth middleware and the handler names/comments show the omission is deliberate ("internal btw the node and plugin") rather than defense-in-depth, exploitation only requires knowing/enumerating a valid plugin name (obtainable via the also-unauthenticated `discoveryHandler`/`pluginMetricHandler` at `/discovery` and `/plugins/:name/metrics`).

### Recommendation
Wrap `loopRoutes` (or at minimum the `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` routes) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` middleware used for `debugRoutes`, or restrict the proxy to bind/accept only from localhost/internal network, consistent with the stated intent that these are "internal" endpoints.

### Proof of Concept
1. Deploy a Chainlink node with at least one LOOP plugin registered.
2. Without any session cookie/authentication, send `GET /discovery` to enumerate registered plugin names.
3. Send `GET /plugins/<name>/debug/pprof/heap` (or `/goroutine`, `/trace?seconds=30`, etc.) without any auth token.
4. Observe the node proxies the request to the plugin's internal pprof server and returns the raw profile data with `200 OK`, confirming unauthenticated access to internal debugging data.

**Note on uncertainty:** I could not fully verify at runtime whether any external reverse proxy, firewall, or additional middleware (outside the code I reviewed) restricts access to this route in typical deployments, nor whether `app.AuthenticationProvider().ExtendRouter(api)` (called after `loopRoutes`) adds any retroactive protection to already-registered routes — based on typical gin semantics it would not, since routes are already registered by the time `ExtendRouter` runs, but this should be confirmed by testing the live route table.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
