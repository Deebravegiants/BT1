### Title
Unbounded linear scan + blocking retry loop over the allowlisted-requests slice in Vault gateway authorization enables per-request CPU/latency DoS - (File: core/capabilities/vault/allow_list_based_auth.go)

### Summary
Every Vault gateway request (secrets create/update/delete/list), reachable from any external client via the Gateway → `GatewayHandler.HandleGatewayMessage` → `GatewayVaultRequestProcessor.ProcessRequest` → `allowListBasedAuth.AuthorizeRequest` path, triggers an O(n) linear scan of the full in-memory allowlisted-requests slice, retried synchronously up to 11 times with 3-second sleeps between attempts if the digest is not (yet) found.

### Finding Description
`allowListBasedAuth.findAllowlistedItemWithRetry` fetches the entire allowlist via `r.workflowRegistrySyncer.GetAllowlistedRequests(ctx)` and linearly scans it with `fetchAllowlistedItem` for every incoming request: [1](#0-0) 

The scan itself: [2](#0-1) 

The allowlist size (`w.allowListedRequests`) is populated from on-chain data and is effectively unbounded — any workflow owner can call `AllowlistRequest` on the `WorkflowRegistry` contract to add entries, and expiry-based pruning only happens once every 5 seconds in `syncAllowlistedRequests`: [3](#0-2) 

This handler is reached directly from the internet-facing gateway path for any of the four vault methods, with no allowlist-size cap or pagination check before the scan: [4](#0-3) [5](#0-4) 

Since a non-allowlisted (i.e., unauthorized/attacker-controlled) request digest will never be found, `findAllowlistedItemWithRetry` runs the full `allowedRequestsStrs` string-formatting loop (line 83-86, itself another O(n) allocation-and-format pass building debug strings for every entry) and the `fetchAllowlistedItem` O(n) scan on every one of the `allowListBasedAuthRetryCount + 1` (11) attempts, sleeping `allowListBasedAuthRetryInterval` (3s) between attempts — i.e., up to 33 seconds of blocked processing and 22 full O(n) passes per single unauthorized request: [6](#0-5) 

Note the test `Test_InitialStateSyncV2` explicitly exercises an allowlist that exceeds `MaxResultsPerQuery` (1,000 entries), confirming the codebase itself expects this slice to grow into the thousands: [7](#0-6) 

### Impact Explanation
An unprivileged client can send an arbitrary, non-allowlisted vault request (secrets create/update/delete/list) through the gateway to a node. Each such request forces the node to perform up to 22 full linear scans (plus debug-string builds) of a slice that can grow to thousands of entries, while blocking for up to ~33 seconds per request (sleep + scan time) before returning an authorization failure. Repeated or concurrent submission of such requests by any external party can degrade Vault DON node responsiveness/CPU usage and delay processing of legitimate authorized requests, resulting in a denial-of-service-like impact on Vault gateway request handling — the same bug class as the referenced report (unbounded iteration over an array whose size is controlled/growable by external actors, causing resource exhaustion/availability issues).

### Likelihood Explanation
Likelihood is moderate-to-high: no privileged access is required to trigger this path — any client capable of reaching the gateway endpoint can send unauthorized vault requests repeatedly. The allowlist size grows monotonically with on-chain `AllowlistRequest` calls from any workflow owner and is only pruned every 5 seconds, so during periods of high allowlist churn or with many workflow owners registering requests, the per-request cost rises accordingly. The fixed retry loop (11 attempts × 3s) amplifies the cost of every unauthorized/invalid request rather than failing fast.

### Recommendation
- Replace the linear scan (`fetchAllowlistedItem`) with an indexed lookup (e.g., a `map[[32]byte]WorkflowRegistryOwnerAllowlistedRequest` keyed by digest) maintained by `workflowRegistry` alongside/instead of the slice, so authorization is O(1) instead of O(n).
- Avoid building the full `allowedRequestsStrs` debug-string slice on every attempt/request in production code paths; only compute it when the request is not found, or gate it behind trace-level logging.
- Consider failing fast (skip retries) for requests that are structurally invalid or where the digest can be shown never to be allowlisted, rather than always executing the full retry×scan budget.
- Cap or bound the amount of work per request (e.g., short-circuit after the first non-increasing size check) so a growing on-chain allowlist cannot linearly increase per-request node overhead.

### Proof of Concept
1. On-chain, have many distinct workflow owners call `AllowlistRequest` repeatedly so `w.allowListedRequests` in `workflowRegistry` grows to several thousand entries (test `Test_InitialStateSyncV2` already demonstrates allowlist entries exceeding `MaxResultsPerQuery` = 1,000).
2. As an unprivileged client, send a `secretsList`/`secretsDelete`/`secretsCreate`/`secretsUpdate` JSON-RPC request through the gateway with a digest that is not in the allowlist.
3. Observe that `GatewayHandler.HandleGatewayMessage` → `GatewayVaultRequestProcessor.ProcessRequest` → `allowListBasedAuth.AuthorizeRequest` → `findAllowlistedItemWithRetry` performs 11 retries, each doing a full O(n) scan (`fetchAllowlistedItem`) plus O(n) string formatting (`allowedRequestsStrs`), with 3-second sleeps between attempts, before finally returning "request not allowlisted" — consuming CPU and wall-clock time proportional to the allowlist size on every unauthorized request, repeatable indefinitely by any external caller.

func (r *allowListBasedAuth) findAllowlistedItemWithRetry(ctx context.Context, req jsonrpc.Request[json.RawMessage], requestDigest string, requestDigestBytes32 [32]byte) (*workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest, []string, error) {
	for attempt := 0; attempt <= r.retryCount; attempt++ {
		allowedRequests := r.workflowRegistrySyncer.GetAllowlistedRequests(ctx)
		allowedRequestsStrs := make([]string, 0, len(allowedRequests))
		for _, rr := range allowedRequests {
			allowedReqStr := fmt.Sprintf("AuthorizedOwner: %s, RequestDigest: %s, ExpiryTimestamp: %d", rr.Owner.Hex(), hex.EncodeToString(rr.RequestDigest[:]), rr.ExpiryTimestamp)
			allowedRequestsStrs = append(allowedRequestsStrs, allowedReqStr)
		}
		r.lggr.Debugw("AllowListBasedAuth loaded allowlisted requests", "method", req.Method, "requestID", req.ID, "attempt", attempt+1, "allowedRequests", allowedRequestsStrs)

		allowlistedRequest := r.fetchAllowlistedItem(allowedRequests, requestDigestBytes32)
		if allowlistedRequest != nil {
			return allowlistedRequest, allowedRequestsStrs, nil
		}
		if attempt == r.retryCount {
			return nil, allowedRequestsStrs, nil
		}

		r.lggr.Debugw("AllowListBasedAuth request digest not yet allowlisted, retrying",
			"method", req.Method,
			"requestID", req.ID,
			"digestHexStr", requestDigest,
			"attempt", attempt+1,
			"maxAttempts", r.retryCount+1,
			"retryInterval", r.retryInterval)
		if err := sleepWithContext(ctx, r.retryInterval); err != nil {
			r.lggr.Debugw("AllowListBasedAuth retry canceled", "method", req.Method, "requestID", req.ID, "error", err)
			return nil, nil, err
		}
	}

	return nil, nil, nil // unreachable: loop always returns
}

func (r *allowListBasedAuth) fetchAllowlistedItem(allowListedRequests []workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest, digest [32]byte) *workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest {
	for _, item := range allowListedRequests {
		if item.RequestDigest == digest {
			return &item
		}
	}
	return nil
}

func (w *workflowRegistry) syncAllowlistedRequests(ctx context.Context) {
	ticker := w.getTicker(defaultTickIntervalForAllowlistedRequests)
	w.lggr.Debug("starting syncAllowlistedRequests")
	for {
		select {
		case <-ctx.Done():
			w.lggr.Debug("shutting down syncAllowlistedRequests, %s", ctx.Err())
			return
		case <-ticker:
			newAllowListedRequests, totalAllowlistedRequests, head, err := w.getAllowlistedRequests(ctx, w.contractReader)
			if err != nil {
				w.lggr.Errorw("failed to call getAllowlistedRequests", "err", err)
				continue
			}
			w.allowListedMu.Lock()
			// Prune expired requests
			activeAllowlistedRequests := []workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest{}
			expiredRequestsCount := 0
			for _, request := range w.allowListedRequests {
				if int64(request.ExpiryTimestamp) > time.Now().Unix() {
					activeAllowlistedRequests = append(activeAllowlistedRequests, request)
				} else {
					expiredRequestsCount++
				}
			}

			// Add new requests
			activeAllowlistedRequests = append(activeAllowlistedRequests, newAllowListedRequests...)
			w.allowListedRequests = activeAllowlistedRequests
			w.lastSeenAllowlistedRequestsCount = totalAllowlistedRequests
			w.lggr.Debugw("synced allowlisted requests",
				"newRequestsNum", len(newAllowListedRequests),
				"expiredRequestsNum", expiredRequestsCount,
				"activeRequestsNum", len(w.allowListedRequests),
				"lastSeenOnchainRequestsNum", w.lastSeenAllowlistedRequestsCount,
				"blockHeight", head.Height,
			)
			w.allowListedMu.Unlock()
		}
	}
}

func (h *GatewayHandler) HandleGatewayMessage(ctx context.Context, gatewayID string, req *jsonrpc.Request[json.RawMessage]) (err error) {
	reqLggr := h.requestLogger(req, gatewayID)
	reqLggr.Debugw("received message from gateway", "req", req)

	var response *jsonrpc.Response[json.RawMessage]
	var authResult *AuthResult

	switch req.Method {
	case vaulttypes.MethodSecretsCreate, vaulttypes.MethodSecretsUpdate:
		publicKey, pkErr := h.getMasterPublicKey(ctx)
		if pkErr != nil {
			response = h.gatewayErrorResponse(ctx, gatewayID, req, pkErr)
			break
		}
		authorized, pipelineErr := h.requestProcessor.ProcessRequest(ctx, req, publicKey)
		if pipelineErr != nil {
			response = h.gatewayErrorResponse(ctx, gatewayID, req, pipelineErr)
			break
		}
		authResult = authorized.AuthResult
	case vaulttypes.MethodSecretsDelete, vaulttypes.MethodSecretsList:
		authorized, pipelineErr := h.requestProcessor.ProcessRequest(ctx, req, nil)
		if pipelineErr != nil {
			response = h.gatewayErrorResponse(ctx, gatewayID, req, pipelineErr)
			break
		}
		authResult = authorized.AuthResult
	case vaulttypes.MethodPublicKeyGet:
		response = h.handlePublicKeyGet(ctx, gatewayID, req)
	default:
		response = h.errorResponse(ctx, gatewayID, req, api.UnsupportedMethodError, errors.New("unsupported method: "+req.Method))
	}

	if response == nil {
		switch req.Method {
		case vaulttypes.MethodSecretsCreate:
			response = h.handleSecretsCreate(ctx, gatewayID, req)
		case vaulttypes.MethodSecretsUpdate:
			response = h.handleSecretsUpdate(ctx, gatewayID, req)
		case vaulttypes.MethodSecretsDelete:
			response = h.handleSecretsDelete(ctx, gatewayID, req)
		case vaulttypes.MethodSecretsList:
			response = h.handleSecretsList(ctx, gatewayID, req, authResult)
		}
	}
