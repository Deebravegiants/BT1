Target: IntentSignerViem.signIntent (packages/intents-sdk/src/intents/intent-signer-impl/intent-signer-viem.ts). Attacker input: an IntentPayload whose intent.signer_id is explicitly set to a victim's EVM address (e.g. 'victim.eth' or '0xVictim...') while config.signer is the attacker's own viem Account with a different address. Preconditions: signIntent's payload uses `intent.signer_id ?? this.config.accountId ?? utils.authHandleToIntentsUserId(...)`, prioritizing intent.signer_id unconditionally with no check that it matches the address of config.signer. Call sequence: attacker builds IntentPayload{ signer_id: victimAddress, intents: [ft_withdraw draining victim's intents-near balance] } -> calls intentSignerViem.signIntent(payload) using the attacker's own key -> signRaw signs JSON.stringify({signer_id: victimAddress, ...}) with the attacker's ERC191 signature -> resulting MultiPayloadErc191 has payload.signer_id = victimAddress but signature produced by attacker's key. Equality that breaks: signer_id in the signed payload == the intents user id derived from the public key that produced signature (explicitly violated: signer_id names victim, signature key is attacker's). Impact: Critical - the SDK happily constructs and returns a fully signed MultiPayload claiming to be authorized by the victim's account while cryptographically signed by the attacker; if this payload is submitted and any downstream check (integrator UI, relay pre-check, other bridge logic) trusts signer_id without independently recovering and comparing the ERC191 signer, victim funds could be moved without their consent (on-chain contract signature recovery is the last line of defense, but the SDK itself performs no defense-in-depth check). Proof idea: vitest test constructing an IntentPayload with signer_id = an address unrelated to a mock viem Account, calling signIntent, then using viem's recoverMessageAddress on the resulting payload/signature to show the recovered address != payload.signer_id, proving the SDK emits an internally inconsistent signed artifact.
