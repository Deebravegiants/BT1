### Title
Legacy gateway trigger messages bypass allowlist and rate-limiting checks - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
The `capabilities` gateway handler's legacy JSON-RPC message path (`HandleLegacyUserMessage`) forwards `web_api_trigger` requests to every DON node without applying the allowlist or rate-limiting checks that the code explicitly marks as still-missing, unlike the modern JSON-RPC trigger path used by the same gateway.

### Finding Description
`gateway.ProcessRequest` in `core/services/gateway/gateway.go` routes an incoming, unauthenticated-by-default HTTP request to either the modern JSON-RPC handler or, when the message carries a `DonID`, to the "legacy" code path (`isLegacyRequest = true`), which calls `h.HandleLegacyUserMessage(ctx, msg, callback)` [1](#0-0) .

Inside `HandleLegacyUserMessage` (`core/services/gateway/handlers/capabilities/handler.go`), the request is checked only for payload decodability, a non-zero timestamp, and message staleness before the code reaches an explicit comment: `// TODO: apply allowlist and rate-limiting here`, immediately followed by only a method-name check (`msg.Body.Method != MethodWebAPITrigger`) and structural validation via `common.ValidatedRequestFromMessage`. No caller identity/allowlist check is performed anywhere in this function [2](#0-1) .

If validation passes, the handler unconditionally fans the request out to every member of the DON: `for _, member := range h.donConfig.Members { err = errors.Join(err, don.SendToNode(ctx, member.Address, req)) }` [3](#0-2) .

This mirrors the reported bug class exactly: one entry point into the same trigger functionality (`MethodWebAPITrigger`) is missing the authorization/allowlist check that the maintainers themselves flagged as required, while the parallel, JSON-RPC-based trigger path (e.g. `httpTriggerHandler.validatedTriggerRequest` in `core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go`) performs structured validation of trigger params, request ID, and method before construction of the downstream `MethodWorkflowExecute` request [4](#0-3) . An attacker aware of the two code paths can simply target the legacy DonID-based envelope format to skip the allowlist gate.

### Impact Explanation
Any unprivileged client able to reach the gateway's public HTTP endpoint can submit a legacy-formatted JSON-RPC request with `Body.DonID` set and `Method: "web_api_trigger"`. Because no allowlist/authorization check is applied on this path, the request is forwarded to every node in the target DON, allowing an unauthenticated actor to trigger workflow execution requests against nodes that are supposed to only accept requests from allowlisted callers. This is a concrete allowlist-bypass / unauthorized-trigger-invocation vulnerability in the internet-facing gateway.

### Likelihood Explanation
The vulnerable code path is reachable directly from `gateway.ProcessRequest`, the single top-level entry point for all incoming gateway HTTP requests, simply by including a `DonID` in the message body so `msg.Body.DonID != ""` is true, causing `isLegacyRequest` to be set. No special privileges, prior authentication, or race conditions are required — only knowledge of the legacy message envelope format, which is a stable, documented format still supported by the gateway's decoding logic (`msg.Validate()`).

### Recommendation
Add caller authorization/allowlist enforcement (and rate-limiting) to `HandleLegacyUserMessage` before it forwards `MethodWebAPITrigger` requests to DON members, mirroring the checks performed in the JSON-RPC trigger path. At minimum, resolve the existing `// TODO: apply allowlist and rate-limiting here` comment, and add regression tests asserting that unauthorized/non-allowlisted legacy requests are rejected the same way JSON-RPC requests are.

### Proof of Concept
1. Craft a raw JSON-RPC request whose decoded `api.Message` has `Body.DonID` set to a valid DON ID and `Body.Method = "web_api_trigger"`, with a valid `Timestamp` and a well-formed `webapicap.TriggerRequestPayload` payload.
2. POST it to the gateway's public endpoint without providing any credentials that would satisfy an allowlist for that DON/workflow owner.
3. Observe that `gateway.ProcessRequest` treats it as a legacy request (`msg.Body.DonID != ""`), calls `HandleLegacyUserMessage`, and — absent the TODO'd allowlist check — the request is forwarded via `don.SendToNode` to all DON members, unlike an equivalent request sent through the JSON-RPC v2 trigger path, which enforces additional validation before reaching the DON.

Note: I was not able to directly confirm, within the indexed code, the exact allowlist-enforcement call site used by the modern JSON-RPC trigger path (it may live in a component not fully covered by the search index, e.g. `common.ValidatedRequestFromMessage` internals or a wrapping allowlist middleware). If a Devin session with full repository access shows that allowlisting is also applied later for legacy DON message delivery (e.g., inside `don.SendToNode` or `handlers.DON`), this reduces or eliminates the severity of the finding; this should be verified before treating it as fully confirmed.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageID] = &savedCallback{id: msg.Body.MessageID, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

func (h *httpTriggerHandler) validatedTriggerRequest(ctx context.Context, req *jsonrpc.Request[json.RawMessage], callback handlers.Callback) (*jsonrpc.Request[gateway_common.HTTPTriggerRequest], error) {
	if req.Params == nil {
		h.handleUserError(ctx, "", jsonrpc.ErrInvalidRequest, "'params' field is missing. Include a valid 'params' object", callback)
		return nil, errors.New("request params is nil")
	}

	triggerReq, err := h.parseTriggerRequest(ctx, req, callback)
	if err != nil {
		return nil, err
	}

	if err := h.validateRequestID(ctx, req.ID, callback); err != nil {
		return nil, err
	}

	if err := h.validateMethod(ctx, req.Method, req.ID, callback); err != nil {
		return nil, err
	}

	if err := h.validateTriggerParams(ctx, triggerReq, req.ID, callback); err != nil {
		return nil, err
	}

	return &jsonrpc.Request[gateway_common.HTTPTriggerRequest]{
		Version: req.Version,
		ID:      req.ID,
		Method:  gateway_common.MethodWorkflowExecute,
		Params:  triggerReq,
	}, nil
}
