### Title
Unprivileged "View" role can read outgoing secret tokens for External Initiators via `GET /v2/external_initiators` - (File: core/web/external_initiators_controller.go)

### Summary
The `/v2/external_initiators` list endpoint is reachable by any authenticated user with the lowest privilege role (`UserRoleView`) and returns each External Initiator's `OutgoingToken`, a secret credential used by the Chainlink node to authenticate its outbound webhook calls to the external initiator's service.

### Finding Description
The route is registered without any elevated-role middleware, only the base authentication (session/token) check: [1](#0-0) 

The handler `Index` fetches all external initiators and serializes them via `presenters.NewExternalInitiatorResource`, which includes the `OutgoingToken` field directly in the JSON response: [2](#0-1) [3](#0-2) 

The test suite explicitly documents that this route is `viewOnlyAllowed: true`, meaning even the lowest-privilege authenticated role (View) can call it successfully without a `403 Forbidden`/`401 Unauthorized`: [4](#0-3) 

The integration test for the Index handler confirms the response body contains `OutgoingToken` in plaintext for every listed initiator: [5](#0-4) 

This mirrors the CVE-2018-19109 bug class: a page/list endpoint that should logically be restricted to privileged operators (initiators are created/destroyed only by `RequiresEditRole`) is reachable and discloses sensitive data to a lower-privileged authenticated actor because the list/read path lacks the same role gate as the write paths: [1](#0-0) 

By contrast, similarly-shaped secret material elsewhere in the API (e.g., private keys) is generally not returned in Index/list responses; here the actual outgoing secret token is returned as plain list data.

### Impact Explanation
`OutgoingToken` is the credential the Chainlink node uses to authenticate itself to the configured External Initiator endpoint when delivering job-run callbacks. Disclosure of this token to a "View"-only user (who is not supposed to be able to create/modify/administer initiators, bridges, keys, or transfers) allows that low-privileged user to impersonate the Chainlink node's outbound calls to the initiator's remote service, i.e., request impersonation/secret disclosure across a privilege boundary. This satisfies the "concrete... secret disclosure, request impersonation" bar from the validation criteria.

### Likelihood Explanation
Likelihood is high for any deployment that grants "View" role accounts to less-trusted operators (a supported, intended use of the role per the RBAC model) and that has External Initiators configured. No special conditions are required beyond having a valid View-role session or API token and calling a single unauthenticated-role-gated GET endpoint.

### Recommendation
Gate `GET /v2/external_initiators` (and `GET /v2/external_initiators/:id` if present) behind at least `auth.RequiresEditRole`, matching the Create/Destroy endpoints, or redact `OutgoingToken`/`OutgoingSecret` from the `ExternalInitiatorResource` presenter used for listing, exposing the secret only once at creation time (as already done via `ExternalInitiatorAuthentication` on `Create`).

### Proof of Concept
1. Create a user with `UserRoleView` (the lowest role) and obtain a session cookie or API token for it.
2. As an admin, create an External Initiator: `POST /v2/external_initiators {"name":"foo","url":"http://example.com"}` — note the response contains the one-time `outgoingToken`.
3. Authenticate as the View-role user and call `GET /v2/external_initiators`.
4. Observe the response includes `outgoingToken` for the initiator, confirming a low-privileged user can read a secret meant to be scoped to privileged (Edit/Admin) operators, per: [5](#0-4)

```go
func (eic *ExternalInitiatorsController) Index(c *gin.Context, size, page, offset int) {
	ctx := c.Request.Context()
	externalInitiators, count, err := eic.App.BridgeORM().ExternalInitiators(ctx, offset, size)
	resources := make([]presenters.ExternalInitiatorResource, 0, len(externalInitiators))
	for _, initiator := range externalInitiators {
		resources = append(resources, presenters.NewExternalInitiatorResource(initiator))
	}

	paginatedResponse(c, "externalInitiators", size, page, resources, count, err)
}
```

```go
type ExternalInitiatorResource struct {
	JAID
	Name          string         `json:"name"`
	URL           *models.WebURL `json:"url"`
	AccessKey     string         `json:"accessKey"`
	OutgoingToken string         `json:"outgoingToken"`
	CreatedAt     time.Time      `json:"createdAt"`
	UpdatedAt     time.Time      `json:"updatedAt"`
}

func NewExternalInitiatorResource(ei bridges.ExternalInitiator) ExternalInitiatorResource {
	return ExternalInitiatorResource{
		JAID:          NewJAID(strconv.FormatInt(ei.ID, 10)),
		Name:          ei.Name,
		URL:           ei.URL,
		AccessKey:     ei.AccessKey,
		OutgoingToken: ei.OutgoingToken,
		CreatedAt:     ei.CreatedAt,
		UpdatedAt:     ei.UpdatedAt,
	}
}
```
