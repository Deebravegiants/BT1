# Q0716: normalize-pyth via collateral-remove-redeem: destroy value through a truncation the opposite operation 

## Question
Does `collateral-remove-redeem` (mainnet/contracts/market/v0-4-market.clar:1211) let an unprivileged attacker who controls `amount` used for BOTH the collateral removal and the share redemption reach `normalize-pyth` (mainnet/contracts/market/v0-4-market.clar:297) in a state where it destroy value through a truncation the opposite operation does not restore?
