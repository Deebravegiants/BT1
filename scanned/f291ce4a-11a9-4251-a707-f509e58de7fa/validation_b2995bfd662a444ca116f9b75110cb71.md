### Title
Missing allowlist/authorization check in gateway `web_api_trigger` legacy message handler allows any signed message to be forwarded to all DON nodes - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
The gateway's capabilities `handler.HandleLegacyUserMessage` accepts any message that passes basic structural/signature validation and immediately forwards it to every node in the DON, without ever checking that the sender is allowlisted for the target workflow. The code contains an explicit, unresolved `// TODO: apply allowlist and rate-limiting here` comment marking the gap.

### Finding Description
`handler.HandleLegacyUserMessage` in [1](#0-0)  only performs: payload decoding, a timestamp/staleness check, and a method-name check (`msg.Body.Method != MethodWebAPITrigger`). Immediately after those checks, the code has the comment:

```go
// TODO: apply allowlist and rate-limiting here
if msg.Body.Method != MethodWebAPITrigger {
``` [2](#0-1) 

No verification is performed that `msg.Body.Sender` (the ECDSA-recovered signer) is an authorized/allowlisted workflow owner or that the requested `Receiver`/topic is one the sender is permitted to trigger. The request is then transformed and broadcast to every DON member:

```go
h.mu.Lock()
h.savedCallbacks[msg.Body.MessageID] = &savedCallback{id: msg.Body.MessageID, createdAt: time.Now(), Callback: callback}
don := h.don
h.mu.Unlock()

for _, member := range h.donConfig.Members {
	err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
}
``` [3](#0-2) 

Upstream, `Message.Validate()` only checks field lengths and that the signature is well-formed / recovers to *some* address — it does not verify that address is authorized for anything:

```go
signerBytes, err := m.ExtractSigner()
if err != nil {
	return err
}
m.Body.Sender = utils.StringToHex(string(signerBytes))
return nil
``` [4](#0-3) 

Any external client can generate its own ECDSA keypair, self-sign a well-formed `web_api_trigger` message, and have `gateway.ProcessRequest` route it straight to this handler:

```go
if isLegacyRequest {
	method = msg.Body.Method
	err = h.HandleLegacyUserMessage(ctx, msg, callback)
}
``` [5](#0-4) 

This mirrors the reported bug class (a state-changing / fund/action-relevant operation reachable by any caller because an access-control check that should gate it is missing) — here the missing gate is the sender allowlist for triggering workflow capability actions via the gateway, exactly as the code's own TODO documents.

### Impact Explanation
Because the allowlist/rate-limit check is not implemented, any unauthenticated party who can reach the gateway's HTTP endpoint can craft a self-signed `web_api_trigger` message and have it forwarded to every node in the target DON as if it came from an authorized workflow owner. This can cause unauthorized workflow trigger invocations, node-side resource consumption (since the message is fanned out to all DON members and callbacks are stored per message ID), and potential abuse of capability actions that were intended to be restricted to allowlisted senders/topics.

### Likelihood Explanation
The vulnerable path is directly reachable from any unprivileged network client hitting the gateway's public request endpoint (`gateway.ProcessRequest` → `HandleLegacyUserMessage`); no authentication beyond a self-generated, self-signed message is required, and the missing check is explicitly flagged by the surrounding TODO comment, indicating it was never implemented in this legacy code path.

### Recommendation
Implement the sender allowlist and rate-limiting check called out by the TODO before forwarding the message to nodes: verify `msg.Body.Sender` (and/or `msg.Body.Receiver`/topic) against the DON's configured allowed senders/topics (similar to the `allowedSenders`/`allowedTopics` maps already present in `webapiTrigger`, see [6](#0-5) ) and reject/return an authorization error for any sender not on the list, mirroring the JSON-RPC vault path's `AuthorizeRequest` pattern used elsewhere in the gateway ( [7](#0-6) ).

### Proof of Concept
1. Generate an arbitrary ECDSA keypair (no registration or allowlisting needed).
2. Construct a `Message` with `Body.Method = "web_api_trigger"`, a valid `Body.DonID`, a `TriggerRequestPayload` with a current `Timestamp`, and sign it with the arbitrary key (`msg.Sign(privateKey)`), satisfying `Message.Validate()`.
3. Submit this as a legacy JSON-RPC request to the gateway's public endpoint so it reaches `gateway.ProcessRequest` → `handlers.capabilities.handler.HandleLegacyUserMessage`.
4. Observe that the message passes the timestamp/method checks (no sender/topic allowlist check exists) and is forwarded via `don.SendToNode` to every DON member, despite the sender never having been authorized.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
