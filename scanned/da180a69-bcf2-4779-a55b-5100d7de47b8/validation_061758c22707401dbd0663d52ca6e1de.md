### Title
Unauthenticated Disclosure of Internal Node Info and Full pprof Debug Data via LOOP Registry Routes - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` route group without any authentication middleware, unlike every other sensitive route in the same router (e.g. `/debug/vars`, `/v2/*`). This is the same bug class as the Jenkins CVE-2015-5321 analog: a sidepanel/administrative widget reachable without the page's own permission check, disclosing internal operational data to unauthenticated remote clients.

### Finding Description
In `core/web/router.go`, the top-level `api` group is created with only rate-limiting and session middleware — no authentication: [1](#0-0) 

Compare this to `debugRoutes`, which explicitly wraps `/debug/vars` in `auth.Authenticate(...)`: [2](#0-1) 

and to `v2Routes`, which splits routes into `unauthedv2` (only the `/resume/:runID` webhook callback) and `authv2` (everything else, protected by `auth.Authenticate`): [3](#0-2) 

`loopRoutes`, however, registers all of its handlers directly on the bare `api` group with no auth wrapper at all: [4](#0-3) 

The handlers behind these routes disclose meaningful internal state:
- `discoveryHandler` returns the node's internal Prometheus discovery hostname, exposed port, and the names of every registered LOOP plugin: [5](#0-4) 
- `pluginMetricHandler` proxies to each plugin's internal-only Prometheus `/metrics` endpoint and returns the raw response body to the caller, explicitly noting in a comment that this metrics channel is meant to be internal ("unlike discovery, this endpoint is internal btw the node and plugin"): [6](#0-5) 
- `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` proxy full Go `pprof` debug data (goroutine dumps, heap profiles, CPU traces, symbol resolution) from the plugin process to the requester, again labeled as an "internal" channel in the code comment: [7](#0-6) 

`pprof` output (especially `heap`, `goroutine?debug=2`, and `profile`) can contain in-memory secrets, key material, request payloads, and internal source paths/stack traces — a much more severe disclosure than the Jenkins CLI overview page leak that the report describes, but the same root cause: an operator/administrative surface reachable without the site's normal auth check.

### Impact Explanation
An unauthenticated remote client can enumerate all LOOP plugins running on a Chainlink node, pull their Prometheus metrics, and pull full pprof profiling/goroutine/heap data for any named plugin. This can leak internal topology (hostnames, ports, plugin names), performance/operational metrics that reveal job/queue internals, and potentially sensitive data embedded in process memory via heap/goroutine dumps — all without any session, API token, or role check.

### Likelihood Explanation
High. No authentication, session, or token is required — a single unauthenticated HTTP GET to `/discovery`, `/plugins/:name/metrics`, or `/plugins/:name/debug/pprof/heap` on any node exposing the web server is sufficient. The plugin name can be discovered from `/discovery` itself, requiring no prior knowledge.

### Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token-based) middleware used by `debugRoutes` and `authv2`, or otherwise gate the pprof/metrics proxy behind a dedicated internal-only listener/network boundary rather than the public API router group.

### Proof of Concept
```
# No credentials required
curl http://<node-host>:<web-port>/discovery
curl http://<node-host>:<web-port>/plugins/<plugin-name>/metrics
curl "http://<node-host>:<web-port>/plugins/<plugin-name>/debug/pprof/heap?debug=1"
```
Each request succeeds and returns internal data without any `Authorization` header or session cookie, because `loopRoutes` (unlike `debugRoutes` and `authv2`) is registered without an `auth.Authenticate` wrapper in `core/web/router.go`.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

// pluginMetricHandlers routes from endpoints published in service discovery to the backing LOOP endpoint
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
