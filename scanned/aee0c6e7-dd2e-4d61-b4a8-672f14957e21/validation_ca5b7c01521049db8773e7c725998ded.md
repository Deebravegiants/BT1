## Analysis: Unauthenticated pprof/debug proxy for LOOP plugins

The CVE describes a Node.js debugger listening on all interfaces without authentication, allowing arbitrary remote access to debug functionality. The Chainlink codebase has a directly analogous pattern: an unauthenticated pprof/profiling proxy for LOOP plugins, exposed on the same publicly-bound port as the authenticated API.

### Title
Unauthenticated pprof/debug and metrics proxy for LOOP plugins - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` directly on the top-level `api` router group with no authentication middleware, unlike every comparable debug surface in the same file.

### Finding Description
In `NewRouter`, `loopRoutes(app, api)` is invoked on the bare `api` group [1](#0-0) , while the equivalent core debug endpoints are explicitly wrapped in session authentication (`debugRoutes`) [2](#0-1) , and the standard Go pprof handlers are only mounted under the authenticated `authv2` group via `metricRoutes(authv2)` [3](#0-2) .

However, `loopRoutes` itself does not add any `auth.Authenticate` middleware: [4](#0-3) 

This means `LoopRegistryServer.pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler`, which proxy to the internal LOOP plugin's `/debug/pprof/...` endpoint, are reachable by any client that can reach the node's main HTTP port — no session cookie or API token required: [5](#0-4) 

The `discoveryHandler`, also unauthenticated, enumerates all registered plugin names and their metrics paths, which an attacker can use to discover valid `:name` values for the pprof proxy: [6](#0-5) 

The default `WebServer.ListenIP` is `0.0.0.0` and `HTTPPort` is `6688`, so this proxy is bound to all interfaces by default, matching the "listens on any interface by default" root cause of the CVE: [7](#0-6) 

### Impact Explanation
An unauthenticated remote actor can:
- Enumerate all installed LOOP plugins via `/discovery`.
- Pull `heap`, `goroutine`, `profile`, `trace`, `allocs`, `block`, `mutex`, and `cmdline` pprof output from any discovered plugin process via `/plugins/:name/debug/pprof/*profile`, which can leak process memory contents, in-flight data, internal network topology, and environment/command-line details.
- Trigger CPU-intensive `/profile?seconds=N` or `/trace?seconds=N` calls (bounded by `PPROFOverheadSeconds`) against the internal plugin repeatedly, causing resource exhaustion / denial of service on the plugin process.
- Use `/plugins/:name/debug/pprof/symbol` to resolve internal function symbols, aiding further reconnaissance.

This is comparable in nature (though not identical severity) to CVE-2018-12120: an operationally significant debug interface bound to all interfaces without authentication, allowing unauthenticated introspection/DoS against a production node process.

### Likelihood Explanation
Likelihood is high for any Chainlink node running with LOOP plugins enabled and default `ListenIP = '0.0.0.0'`, since the routes are always registered whenever `NewRouter` builds the engine (no feature flag gates `loopRoutes`), and the endpoint requires no credentials to reach.

### Recommendation
Wrap `loopRoutes` in the same `auth.Authenticate` middleware used by `debugRoutes` and `authv2`'s `metricRoutes`, or otherwise restrict `/discovery`, `/plugins/:name/metrics`, and `/plugins/:name/debug/pprof/*` to authenticated/admin sessions, consistent with how the node's own pprof endpoints require authentication.

### Proof of Concept
```
curl http://<node-ip>:6688/discovery
# enumerate plugin names, then:
curl http://<node-ip>:6688/plugins/<plugin-name>/debug/pprof/heap
curl "http://<node-ip>:6688/plugins/<plugin-name>/debug/pprof/profile?seconds=30"
```
No `X-Chainlink-EA-*`, API token, or session cookie is required for either request.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}
```

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
```
