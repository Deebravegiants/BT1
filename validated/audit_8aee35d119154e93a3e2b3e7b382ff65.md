### Title
Stale `_requestCommitments` fee metadata after GET response delivery enables double-payment via a subsequent timeout claim - ([File: evm/src/core/EvmHost.sol])

### Summary
`EvmHost.dispatchIncoming(GetResponse, address relayer)` pays the relayer the fee stored in `_requestCommitments[commitment]` on successful delivery, but never deletes or zeroes that commitment entry afterward. The same commitment can later be replayed through `dispatchTimeOut(GetRequestTimeout, ...)`, which reads the still-present `FeeMetadata`, deletes it, and refunds the fee a second time to the original requester — draining `feeToken` reserves from the host.

### Finding Description
`dispatch(DispatchGet)` records `_requestCommitments[commitment] = FeeMetadata({sender: msgSender, fee: get.fee})` when a GET request is created [1](#0-0) .

When the response comes back, `HandlerV2.handleGetResponses` verifies the MMR proof and calls `host.dispatchIncoming(leaf.response, _msgSender())` for each response, first checking only that no response receipt already exists locally [2](#0-1) .

`EvmHost.dispatchIncoming(GetResponse, ...)` sets `_responseReceipts[commitment]`, calls `onGetResponse` on the destination module, and — on success — pays the relayer the fee taken from `_requestCommitments[commitment].fee`, but it never deletes `_requestCommitments[commitment]`: [3](#0-2) .

Compare this with the sibling path, `dispatchTimeOut(GetRequestTimeout, ...)`, which is reached from `HandlerV2.handleGetRequestTimeouts`. That handler only checks `meta.sender != address(0)` (true, since the commitment was never cleared) and a non-membership proof of the response receipt in Hyperbridge's own state trie at an arbitrary previously-committed height `message.height` [4](#0-3) . There is no requirement that `message.height` be the *latest* committed height — any previously stored, non-vetoed `_stateCommitments[stateMachineId][height]` remains usable, so a proof anchored to a height *before* Hyperbridge recorded the response can still be supplied even after the response has since been delivered on the destination EVM host.

`dispatchTimeOut(GetRequestTimeout, ...)` deletes `_requestCommitments[commitment]` and, on success of `onGetTimeout`, refunds `meta.fee` to `meta.sender` (the original requester): [5](#0-4) .

Because step 1 (successful GET response delivery) never clears `_requestCommitments[commitment]`, the same fee metadata remains available for step 2 (timeout claim using a stale, pre-response state height), causing the host to pay out the same fee twice: once to the relayer at response-delivery time, and again to the requester at timeout-claim time.

### Impact Explanation
This allows an attacker (any relayer/user submitting a valid but stale non-membership proof) to trigger a second payout of the same request's fee from the `EvmHost` feeToken balance, without any additional deposit. Repeated across many GET requests this drains protocol/relayer fee reserves — a concrete unbacked loss of funds from the host contract, satisfying "concrete theft ... of funds."

### Likelihood Explanation
Exploitability depends on (a) an old, still-valid (non-vetoed) `_stateCommitments` entry existing for a height prior to when the response was recorded on Hyperbridge, and (b) the request's `timeoutTimestamp` having already elapsed relative to that older height's timestamp even though the response was ultimately still accepted and delivered (the comment in `handleGetResponses` explicitly notes timeout is "checked on Hyperbridge," not re-checked here) [6](#0-5) . Old state commitments are not pruned by default (only vetoed via governance/fisherman action), so this stale-proof condition is realistically reachable by any relayer racing a near-timeout GET request.

### Recommendation
Delete `_requestCommitments[commitment]` inside `dispatchIncoming(GetResponse, ...)` immediately after (or instead of) paying the relayer, mirroring the deletion performed in `dispatchTimeOut`. Additionally, consider requiring that timeout proofs be anchored to a state height at or after the height at which the destination-side response window closes, to prevent stale-height non-membership proofs from bypassing an already-delivered response.

### Proof of Concept
1. `dispatch(DispatchGet)` a GET request with `fee = F`, `timeout = T`; `_requestCommitments[commitment] = {sender: user, fee: F}`.
2. Relayer submits `handleGetResponses` with a valid MMR proof shortly after `T` has elapsed but before Hyperbridge finalizes a "timed out" state; `dispatchIncoming(GetResponse,...)` succeeds, pays relayer `F`, and leaves `_requestCommitments[commitment]` intact.
3. A second relayer submits `handleGetRequestTimeouts` using `message.height` pointing at an earlier Hyperbridge state commitment (still stored, not vetoed) that predates the response's inclusion, and a non-membership proof of the response receipt at that height — this proof is legitimately verifiable since the response wasn't yet recorded at that height.
4. `dispatchTimeOut(GetRequestTimeout, meta, commitment)` executes, `onGetTimeout` succeeds on the module, and `feeToken.safeTransfer(meta.sender, F)` pays the user `F` again — total payout `2F` for a single collected fee `F`.

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
