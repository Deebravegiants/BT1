### Title
Stale `TombStone.original_owner` survives ungated `object::transfer`/`transfer_call`/`transfer_raw`, letting a past owner reclaim an object stolen from a later rightful owner - (File: aptos-move/framework/aptos-framework/sources/object.move)

### Summary
`object::burn` performs a "soft burn" that records the caller as `TombStone.original_owner` without moving the object's ownership. `object::unburn` later trusts that same `original_owner` field to restore ownership whenever the object's current owner is `BURN_ADDRESS`. However, ordinary ungated transfers (`transfer`, `transfer_call`, `transfer_raw`) never touch or clear the `TombStone`, only `transfer_with_ref` does. This lets a stale, no-longer-relevant `original_owner` reclaim an object away from whoever legitimately owns it when it is later moved to `BURN_ADDRESS` through a normal transfer.

### Finding Description
`burn` creates a `TombStone` without changing ownership: [1](#0-0) 

Ungated transfer paths (`transfer`, `transfer_call`, `transfer_raw`) route through `transfer_raw_inner`, which only updates `ObjectCore.owner` and emits an event — it never inspects or clears `TombStone`: [2](#0-1) 

By contrast, `transfer_with_ref` (the `TransferRef`/`LinearTransferRef` path) explicitly clears a stale tombstone before transferring: [3](#0-2) 

`unburn` restores ownership to the address stored in the `TombStone` whenever the *current* owner equals `BURN_ADDRESS`, without verifying that this recorded `original_owner` reflects the object's most recent legitimate owner: [4](#0-3) 

Exploit sequence:
1. Owner A calls `object::burn` on the object → `TombStone{original_owner: A}` is created; ownership stays with A.
2. A transfers the object via ordinary `object::transfer`/`transfer_call` (ungated) to B. `TombStone` is untouched (only `transfer_with_ref` clears it), so it still reads `original_owner: A`, even though B is now the real owner.
3. B, the legitimate new owner, later disposes of the object by transferring it (again via ordinary ungated `transfer`/`transfer_call`, not `transfer_with_ref`) to the documented `BURN_ADDRESS` constant. Ownership becomes `BURN_ADDRESS`; the stale `TombStone{original_owner: A}` is still present and unmodified.
4. A calls `unburn(A, object)`. `TombStone` exists, current owner is `BURN_ADDRESS`, and the assertion `original_owner_addr == signer::address_of(original_owner)` passes because it checks against the stale value `A`. `transfer_raw_inner` reassigns ownership back to A.

A is now the owner of an object it no longer had any legitimate claim to; the intermediate/legitimate owner B's custody of the (disposed) object/asset is silently overridden by an unrelated, earlier address purely because of leftover bookkeeping in `TombStone`.

### Impact Explanation
This breaks the object-ownership custody invariant that "the object cannot be reclaimed by anyone other than its true prior owner." Since `object::burn`/`unburn`/`transfer` are generic public/entry functions usable on any `Object<T>` (token objects, NFT objects, and objects that hold fungible-asset stores or resources), this allows an unprivileged former owner to reassign ownership of an object/asset away from its rightful custodian — a direct owner-reassignment / theft-of-object primitive. Any application relying on `object::burn`+`unburn` semantics as a safe "soft delete" (and using plain `transfer`/`transfer_call` for normal transfers, which is the common, documented API) is exposed.

### Likelihood Explanation
The trigger conditions are simple and require no privileged access: any object owner can call `burn` on their own object at any time, and subsequent owners commonly use the standard `transfer`/`transfer_call` entry functions (not `transfer_with_ref`, which is a lower-level API requiring an already-generated `TransferRef`). Transferring an object to the well-known `BURN_ADDRESS` constant via ordinary transfer is a plausible action by users/integrators who are unaware that the "correct" burn API is the soft-burn `object::burn` rather than sending to the burn address directly. No collusion or special privilege is required by the attacker (A) — only that they burned the object at some point in its history before it changed hands.

### Recommendation
- Clear (or update) the `TombStone` resource on every ownership-changing path, not just `transfer_with_ref`/`transfer_raw_inner`'s callers — i.e., also clear it in `transfer_raw_inner` (used by `transfer`, `transfer_call`, `transfer_raw`) whenever the owner changes.
- Alternatively, bind `unburn`'s legacy `BURN_ADDRESS` recovery path to verify the immediately preceding owner (not an arbitrarily old one) by re-validating/refreshing `TombStone.original_owner` on every transfer, or disallow `unburn`'s "old functionality" recovery unless the tombstone was created in the same transfer chain that produced the `BURN_ADDRESS` state.
- Consider disallowing transfers to `BURN_ADDRESS` through the generic ungated transfer functions, forcing burns to only happen via the audited `burn`/`burn_object_with_transfer` functions that manage `TombStone` consistently.

### Proof of Concept
```move
// Pseudocode using object.move public/entry API
// 1. A creates and owns `obj`
object::burn(&a_signer, obj);                 // TombStone{original_owner: A}, owner still A

// 2. A transfers obj to B via ordinary ungated transfer (TombStone untouched)
object::transfer(&a_signer, obj, B_addr);

// 3. B disposes of obj by sending to BURN_ADDRESS via ordinary transfer
object::transfer_call(&b_signer, object::object_address(&obj), BURN_ADDRESS);

// 4. A reclaims the object that was actually last owned/disposed by B
object::unburn(&a_signer, obj);
// object_core.owner == BURN_ADDRESS -> passes;
// TombStone.original_owner == A -> matches caller A;
// ownership transferred back to A, bypassing B's custody entirely.
```

Note: I was unable to fully verify (due to exhausted tool calls) whether `burn_object_with_transfer` referenced in comments/tests is restricted to `#[test_only]` in this repo snapshot, since I could not retrieve its full definition. This does not affect the finding above, which relies solely on the generic, non-test `burn`/`unburn`/`transfer`/`transfer_call`/`transfer_raw` functions.

    /// Transfer to the destination address using a LinearTransferRef.
    public fun transfer_with_ref(self: LinearTransferRef, to: address) {
        assert!(!exists<Untransferable>(self.self), error::permission_denied(EOBJECT_NOT_TRANSFERRABLE));

        // Undo soft burn if present as we don't want the original owner to be able to reclaim by calling unburn later.
        if (exists<TombStone>(self.self)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(self.self);
        };

        let object = borrow_global_mut<ObjectCore>(self.self);
        assert!(
            object.owner == self.owner,
            error::permission_denied(ENOT_OBJECT_OWNER),
        );
        event::emit(
            Transfer {
                object: self.self,
                from: object.owner,
                to,
            },
        );
        object.owner = to;
    }

    inline fun transfer_raw_inner(object: address, to: address) {
        let object_core = borrow_global_mut<ObjectCore>(object);
        if (object_core.owner != to) {
            event::emit(
                Transfer {
                    object,
                    from: object_core.owner,
                    to,
                },
            );
            object_core.owner = to;
        };
    }

    /// Allow origin owners to reclaim any objects they previous burnt.
    public entry fun unburn<T: key>(
        original_owner: &signer,
        object: Object<T>,
    ) {
        let object_addr = object.inner;
        assert!(exists<TombStone>(object_addr), error::invalid_argument(EOBJECT_NOT_BURNT));

        // The new owner of the object can always unburn it, but if it's the burn address, we go to the old functionality
        let object_core = borrow_global<ObjectCore>(object_addr);
        if (object_core.owner == signer::address_of(original_owner)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(object_addr);
        } else if (object_core.owner == BURN_ADDRESS) {
            // The old functionality
            let TombStone { original_owner: original_owner_addr } = move_from<TombStone>(object_addr);
            assert!(
                original_owner_addr == signer::address_of(original_owner),
                error::permission_denied(ENOT_OBJECT_OWNER)
            );
            transfer_raw_inner(object_addr, original_owner_addr);
        } else {
            abort error::permission_denied(ENOT_OBJECT_OWNER);
        };
    }
