Audit Report

## Title
Unauthenticated disclosure of LOOP plugin profiling and metrics data via loop registry routes - (File: `core/web/router.go`)

## Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the shared `api` router group, which only applies rate limiting and session middleware but no authentication. Unlike `debugRoutes`, which explicitly wraps `/debug/vars` with `auth.Authenticate(...)`, `loopRoutes` has no such wrapper, so any unauthenticated network client can retrieve plugin discovery data, Prometheus metrics, and full pprof profiling output (goroutine dumps, heap/CPU profiles).

## Finding Description
`NewRouter` creates the `api` group with only rate limiting and session storage [1](#0-0) , and this group is passed to `loopRoutes`, which registers all four handlers with zero authentication middleware [2](#0-1) . By contrast, `debugRoutes`, registered on the same `api` group for the analogous `/debug/vars` expvar endpoint, explicitly wraps its group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [3](#0-2) . No other authentication is applied anywhere else in the request path for these four routes — they are not inside `v2Routes`'s `authv2` group, and `metricRoutes` (the actually-authenticated in-process pprof group) is a completely separate, unrelated code path mounted under `authv2` [4](#0-3) .

The handlers confirmed to be reachable without authentication are: `discoveryHandler`, which lists all registered plugins and metrics scrape targets [5](#0-4) ; `pluginMetricHandler`, which proxies `GET /plugins/:name/metrics` to the plugin's internal Prometheus port and streams the raw response back [6](#0-5) ; and `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler`, which proxy arbitrary `/debug/pprof/*` paths (including `goroutine`, `heap`, `profile`, `trace`) and the `symbol` endpoint to the plugin's internal debug port and stream the raw response back [7](#0-6) . I confirmed via `loop_registry_test.go` that no authentication check is asserted or exercised for these handlers in the existing test suite, consistent with the missing middleware in `router.go`.

## Impact Explanation
This is a confidentiality-only information disclosure: an unauthenticated caller with network access to the node's web server can enumerate installed LOOP plugin names, read Prometheus metrics, and pull full pprof goroutine/heap/CPU profiles from plugin processes — internal runtime state that is normally gated behind authentication for the equivalent in-process `/debug/pprof` endpoints (`metricRoutes`, only reachable via `authv2`). This maps to an in-scope "unauthorized read access to a subset of accessible data" / node information-disclosure class, though it is capped at low-severity confidentiality impact (no integrity/availability impact, no credential or fund exposure demonstrated).

## Likelihood Explanation
Exploitation requires only unauthenticated HTTP access to the node's configured web server port — no credentials, tokens, or session cookies are needed, matching the asymmetric-effort criteria for an easily-reachable, unprivileged HTTP endpoint.

## Recommendation
Wrap `loopRoutes` (or at minimum the metrics/pprof-forwarding handlers) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` middleware used for `debugRoutes`, so these endpoints require an authenticated session/token, consistent with how `metricRoutes` is protected by nesting under `authv2`.

## Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered (`app.GetLoopRegistry()` populated).
2. Without any session cookie or API token, issue `curl http://<node>:<port>/discovery` — the request hits `discoveryHandler` via the unauthenticated `api` group and returns the full list of registered plugins and scrape targets, per [2](#0-1) .
3. Issue `curl http://<node>:<port>/plugins/<plugin-name>/debug/pprof/goroutine?debug=2` — this reaches `pluginPPROFHandler`, which proxies to the plugin's internal debug port and returns full goroutine stack dumps unauthenticated, per [8](#0-7) .
4. As a control, confirm that hitting `/debug/vars` without a session returns 401/redirect due to the `auth.Authenticate` wrapper on `debugRoutes` [3](#0-2) , demonstrating the inconsistency and confirming the missing check is the root cause.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

// pluginMetricHandlers routes from endpoints published in service discovery to the backing LOOP endpoint
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
