**Reasoning:**

`finish_with_dkg_result` is a private module function (no `public`, no `entry` modifier) in `reconfiguration_with_dkg.move` [1](#0-0) . It cannot be called by any ordinary signed transaction — Move's visibility rules block that entirely. The only caller is the Rust validator-transaction executor, which invokes it via `execute_function_bypass_visibility` [2](#0-1) , a privileged system-transaction mechanism that requires the block to contain a `ValidatorTransaction::DKGResult`, which itself only reaches this call after the Rust-layer verification passes: epoch match, transcript deserialization, and `DefaultDKG::verify_transcript` against the on-chain public parameters [3](#0-2) . There is no unprivileged transaction, entry function, or API surface that reaches `finish_with_dkg_result` or `dkg::finish` directly, so this falls outside the review bounds ("must start from unprivileged transaction... entrypoint").

Even setting that aside, `dkg::finish` is `public(friend)` restricted to `aptos_framework::reconfiguration_with_dkg` and `aptos_framework::block` [4](#0-3) , and it only clears the in-progress session and stores whatever bytes it's given as the `transcript` field — it does not perform the cryptographic transcript verification (that check lives entirely in the Rust harness before the Move call). So there's no separate Move-side guard being "bypassed" by crafted `dkg_result` bytes; the actual gate is the Rust-side `verify_transcript` call, which is not reachable by unprivileged input.

The claimed link to "fungible-asset dispatch hooks that depend on DKG-derived randomness" and "metadata owner" corruption has no supporting code path in `reconfiguration_with_dkg.move`, `dkg.move`, or the DKG validator-transaction pipeline — no custody, ownership, or FA metadata state is touched by `dkg::finish` or `try_finalize_reconfig` [5](#0-4) . This does not meet the Custody Impact Gate — no wrong balance, owner, authority, or recovery right is identified, and no unprivileged entrypoint reaches the code in question.

    fun try_finalize_reconfig(account: &signer) {
        if (!reconfiguration_state::is_in_progress()) { return };

        // Emergency watchdog: force-finalize regardless of DKG state once the
        // grace period has elapsed since reconfiguration started. Equivalent
        // to `now >= last_reconfiguration_time + epoch_interval + grace_period`,
        // since `reconfiguration_state::start_time_secs()` is set when the
        // block prologue triggers reconfig after `epoch_interval` has elapsed.
        let force_end_grace = epoch_timeout_config::force_end_grace_period_secs();
        if (force_end_grace.is_some()) {
            let now_us = timestamp::now_microseconds();
            let deadline_us = reconfiguration_state::start_time_secs() * 1_000_000
                + (*force_end_grace.borrow()) * 1_000_000;
            if (now_us >= deadline_us) {
                let dkg_incomplete = dkg::incomplete_session().is_some();
                let chunky_incomplete = chunky_dkg::incomplete_session().is_some();
                event::emit(ForceEndEpochEvent::V1 {
                    epoch: reconfiguration::current_epoch(),
                    dkg_incomplete,
                    chunky_incomplete,
                    deadline_us,
                    now_us,
                });
                finish(account);
                return
            };
        };

        // DKG must be done.
        if (dkg::incomplete_session().is_some()) { return };

        // Chunky DKG must be done OR its grace period (shadow mode) must have elapsed.
        let chunky_session = chunky_dkg::incomplete_session();
        if (chunky_session.is_some()) {
            let grace_period = chunky_dkg_config::grace_period_secs();
            if (grace_period.is_none()) { return };
            let start_time_us = chunky_dkg::session_start_time(chunky_session.borrow());
            let grace_period_us = (*grace_period.borrow()) * 1_000_000;
            if (timestamp::now_microseconds() - start_time_us < grace_period_us) {
                return
            };
        };

        finish(account);
    }
