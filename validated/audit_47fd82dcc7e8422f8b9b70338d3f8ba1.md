### Title
Missing Access Control on Magic QR-Code Actions Allows Unauthenticated WiFi/Mirror Reconfiguration - ([File: src/plans/qr_scan/operator.rs], [File: src/plans/mod.rs])

### Summary
The Orb's operator QR-code scanning path recognizes special "magic" QR codes (`magic_action:reset_wifi_credentials` and `magic_action:reset_mirror_calibration`) and executes the corresponding privileged hardware-reconfiguration actions immediately upon parsing, with no authorization or backend verification step — unlike ordinary operator QR codes, which are validated against the backend before being trusted.

### Finding Description
`qr_scan::operator::Data::try_parse` matches any scanned text against a hardcoded regex (`MAGIC_QR_CODE`) and, if it matches `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration`, returns `Data::MagicResetWifi` / `Data::MagicResetMirror` directly, bypassing the normal operator QR parsing/validation path entirely: [1](#0-0) 

These magic-action variants are then dispatched in `handle_magic_operator_qr_code`, which performs the privileged action (`reset_mirror_calibration` or `reset_wifi_and_ensure_network`) unconditionally, with no call to `verify_operator_qr_code` (the backend-authenticated check that is otherwise mandatory for `Data::Normal` operator codes) and no other authorization check: [2](#0-1) 

For comparison, a normal operator QR code must pass `verify_operator_qr_code`, which performs a backend request signed with the orb's own bearer token to confirm the operator/distributor identity is valid before being trusted: [3](#0-2) 

The magic-action codes skip this entirely — the mere presence of the exact plaintext string, hard-coded and discoverable in the open-source regex, is sufficient to trigger the privileged action. This is the direct analog of the reported `onlyOwner`-missing bug class: a function that performs administrative/state-changing operations (`updatePoolPrice`) is reachable without any role check, whereas equivalent code paths correctly gate execution behind an authorization check (`onlyOwner` / `verify_operator_qr_code`).

Both `reset_mirror_calibration` and `reset_wifi_and_ensure_network` are called directly from within `scan_initial_qr_codes` / `scan_remaining_qr_codes`, i.e., reachable from the very first QR scan of the idle/signup flow, before any operator identity has been established: [4](#0-3) [5](#0-4) 

### Impact Explanation
Anyone able to present a QR code to the Orb's camera during the idle/operator-scan phase — not necessarily an authorized operator — can force the device to reset its WiFi network configuration and re-enter WiFi-pairing mode (`reset_wifi_and_ensure_network` → `network::reset` + `wifi::Plan.ensure_network_connection`), or reset the mirror calibration. Forcing the Orb onto a WiFi network of the attacker's choosing enables a network position from which to interfere with the orb's backend traffic (operator/user QR validation calls, signup submission, fraud-check polling), which can be leveraged to disrupt or manipulate the signup/fraud pipeline. This is analogous in class and severity to the reported bug: a privileged, state-changing action is executable by an unauthorized/unprivileged party due to a missing access-control check.

### Likelihood Explanation
Likelihood is high: the magic strings are static, embedded in the open-source repository, and require no secret or backend interaction to produce — an attacker only needs to print/display the string `magic_action:reset_wifi_credentials` (or `reset_mirror_calibration`) as a QR code and present it to the orb's camera during normal operator-QR scanning, the default entry point of every signup session.

### Recommendation
Require the same authorization the normal operator flow enforces (backend-verified operator identity via `verify_operator_qr_code`, or a cryptographically signed/short-lived magic code) before executing `MagicResetWifi`/`MagicResetMirror` in `handle_magic_operator_qr_code`. At minimum, gate these actions behind confirmation that a currently-authenticated/valid operator session is active, rather than trusting the raw QR-code text alone.

### Proof of Concept
1. Generate a QR code image encoding the literal text `magic_action:reset_wifi_credentials`.
2. Present it to the Orb's camera during the operator QR-code scanning phase (idle screen / start of a new signup).
3. `qr_scan::operator::Data::try_parse` matches the `MAGIC_QR_CODE` regex and returns `Data::MagicResetWifi`.
4. `handle_magic_operator_qr_code` immediately calls `self.reset_wifi_and_ensure_network(orb)`, wiping the current WiFi configuration and re-entering WiFi pairing — with no operator authentication or backend validation performed at any point in this path. [6](#0-5) [2](#0-1)

//! Operator QR-code scanning.

use super::{user, Schema};
use crate::ui;
use once_cell::sync::Lazy;
use regex::Regex;

/// An opt-in operator qr code for testing purposes.
pub const DUMMY_OPERATOR_QR_CODE: &str = "userid:66ad4897-0ca7-4727-8365-ca808348e3cd:1";

static MAGIC_QR_CODE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")
});

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

        orb: &mut Orb,
        qr_codes: &mut QrCodes,

                        qr_code: operator_qr_code,
                        location_data: operator_location_data,
                        timestamp: Instant::now(),

                };

            }

    }

    async fn scan_remaining_qr_codes(
        &mut self,
        orb: &mut Orb,
        qr_codes: QrCodes,
        operator_qr_expiration_time: Duration,
    ) -> Result<Option<ResolvedQrCodes>> {
        loop {
            match qr_codes {
                QrCodes::Both { operator_data, user_qr_code, user_data, user_qr_code_string }
                    if operator_data.timestamp.elapsed() < operator_qr_expiration_time =>
                {
                    break Ok(Some(ResolvedQrCodes {
                        operator_data,
                        user_qr_code,
                        user_data,
                        user_qr_code_string,
                    }));
                }
                QrCodes::Operator { operator_data }
                    if operator_data.timestamp.elapsed() < operator_qr_expiration_time =>
                {
                    let Some((user_qr_code, user_data, user_qr_code_string)) =
                        self.scan_user_qr_code(orb, &operator_data).await?
                    else {
                        break Ok(None);
                    };
                    break Ok(Some(ResolvedQrCodes {
                        operator_data,
                        user_qr_code,
                        user_data,
                        user_qr_code_string,
                    }));
                }
                _ => {
                    let qr_capture_start = Instant::now();
                    let Some(operator_qr_code) =
                        self.scan_operator_qr_code(orb, Some(self.qr_scan_timeout)).await?
                    else {
                        break Ok(None);
                    };
                    if !check_signup_conditions(orb).await? {
                        continue;
                    }
                    let Some(operator_qr_code) =
                        self.handle_magic_operator_qr_code(orb, operator_qr_code).await?
                    else {
                        break Ok(None);
                    };
                    let Some((duration_since_shot_ms, operator_location_data)) = self
                        .verify_operator_qr_code(orb, &operator_qr_code, qr_capture_start)
                        .await?
                    else {
                        continue;
                    };
                    // a delay following the scan allows for a better user experience & increases the chance of
                    // not reusing any previous RGB frame for the next QR-code scan
                    if let Some(delay) =
                        QR_SCAN_INTERVAL.checked_sub(Duration::from_millis(duration_since_shot_ms))
                    {
                        sleep(delay).await;
                    }
                    let operator_data = OperatorData {
                        qr_code: operator_qr_code,
                        location_data: operator_location_data,
                        timestamp: Instant::now(),
                    };
                    let Some((user_qr_code, user_data, user_qr_code_string)) =
                        self.scan_user_qr_code(orb, &operator_data).await?
                    else {
                        break Ok(None);
                    };
                    break Ok(Some(ResolvedQrCodes {
                        operator_data,
                        user_qr_code,
                        user_data,
                        user_qr_code_string,
                    }));
                }
            }
        }
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

    /// Checks if `qr_code` is a valid operator QR-code through the backend.
    #[allow(clippy::cast_possible_truncation)]
    async fn verify_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: &qr_scan::user::Data,
        qr_capture_start: Instant,
    ) -> Result<Option<(u64, backend::operator_status::LocationData)>> {
        if qr_code.signup_extension() || self.operator_qr_code_override.is_some() {
            return Ok(Some((0, backend::operator_status::LocationData {
                team_operating_country: "DEV".to_string(),
                session_coordinates: Coordinates { latitude: 0.0f64, longitude: 0.0f64 },
                stationary_location_coordinates: None,
            })));
        }
        let http_start = Instant::now();
        match backend::operator_status::request(qr_code).await {
            Ok(backend::operator_status::Status { valid: true, location_data, reason: _ }) => {
                let location_data = location_data
                    .expect("to always have a result from the backend if valid == true");
                orb.ui.qr_scan_success(QrScanSchema::Operator);
                dd_incr!("main.count.global.distr_code_validated");
                tracing::info!("Operator QR-code validated: {qr_code:?}");
                dd_timing!("main.time.signup.distr_qr_code_capture", qr_capture_start);
                return Ok(Some((http_start.elapsed().as_millis() as u64, location_data)));
            }
            Ok(backend::operator_status::Status { valid: false, .. }) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
                dd_incr!("main.count.signup.result.failure.distr_qr_code", "type:invalid_qr");
            }
            Err(_) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
            }
        }
        Ok(None)
    }
