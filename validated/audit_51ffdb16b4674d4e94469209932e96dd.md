### Title
RAY value overflow in interest accrual permanently freezes an oversized market - (File: `common/src/rates/simulate.rs`)

### Summary
An unprivileged user can permanently freeze all operations on a sufficiently large, highly utilized market once interest growth makes `scaled_amount × index` exceed the `i128` RAY domain. Every pool mutation synchronizes interest before applying the requested action, so after this arithmetic cliff is crossed, `update_indexes`, `withdraw`, `repay`, `borrow`, liquidation settlement, flash loans, and recapitalization all panic with `MathOverflow`. [1](#0-0) [2](#0-1) [3](#0-2) 

### Finding Description
`accrue_step` computes utilization by multiplying scaled `borrowed` and `supplied` balances by their respective indexes via `scaled_to_original`. [4](#0-3)  `scaled_to_original` performs a checked fixed-point multiplication and panics when the resulting RAY value cannot fit in `i128`. [5](#0-4) 

The index ceiling does not prevent this condition because the multiplication can overflow before `borrow_index` reaches `MAX_BORROW_INDEX_RAY`; the existing harness proves this explicitly. [6](#0-5)  The pool applies `interest::global_sync` inside `synced_market`, which is used by the ordinary market mutation legs before supply, borrow, withdrawal, repayment, liquidation, flash-loan, strategy, or recapitalization accounting runs. [7](#0-6) [8](#0-7)  `global_sync` always invokes `accrue_step` for elapsed-time chunks, so no later operation can bypass the overflowing utilization calculation. [9](#0-8) 

### Impact Explanation
Once `borrowed × borrow_index` or `supplied × supply_index` exceeds `i128::MAX`, the market cannot accrue, repay debt, withdraw collateral, liquidate unhealthy accounts, or process another mutating settlement. [3](#0-2)  This permanently freezes supplier funds and leaves the pool unable to collect repayment or resolve bad debt through ordinary market operations. [7](#0-6) [10](#0-9) 

### Likelihood Explanation
Triggering the state requires an exceptionally large admitted position and sustained high utilization rather than a single small malformed call. [11](#0-10)  The demonstrated setup supplies one billion 18-decimal whole tokens, borrows 98% of the market, and advances accrual until `update_indexes` fails with `MathOverflow` before the index cap is reached. [12](#0-11)  Because `supply`, `borrow`, and permissionless `update_indexes` are reachable without protocol privileges, the condition can arise from ordinary market use once caps, liquidity, collateralization, and time permit it. [13](#0-12) [14](#0-13) 

### Recommendation
Represent utilization inputs in a widened type or rearrange the utilization calculation to divide before multiplying, so representable scaled balances and capped indexes cannot make an intermediate RAY value overflow. [1](#0-0) [5](#0-4)  Add a market-level guard that rejects new supply or debt when projected accrued values can approach the `i128` RAY ceiling before the index ceiling, and add regression coverage that retries withdraw, repay, liquidation, flash-loan, recapitalize, and `update_indexes` after the boundary. [7](#0-6) [6](#0-5) 

### Proof of Concept
The repository contains a deterministic regression test that creates an 18-decimal market, supplies `1_000_000_000 × 10^18` base units, borrows 98% of it, advances time in yearly intervals, and observes `MathOverflow` from `update_indexes` before `MAX_BORROW_INDEX_RAY` is reached. [15](#0-14)  The same test then proves both withdrawal and repayment fail with `MathOverflow` because they must run accrual first. [16](#0-15)

/// The cliff. A billion whole tokens is `1e36` raw ray; the value ceiling is
/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);

pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}

/// Applies one compound step of `delta_ms` to indexes and protocol revenue.
///
/// The arithmetic lives in [`accrue_step`], shared with the read-only
/// `simulate_update_indexes` so the view and the mutator cannot drift.
fn accrue_chunk(env: &Env, cache: &mut Cache, delta_ms: u64) {
    let step = accrue_step(
        env,
        cache.params(),
        cache.borrowed(),
        cache.supplied(),
        cache.borrow_index(),
        cache.supply_index(),
        delta_ms,
    );
