Audit Report

## Title
View-role users can read External Initiator secrets via `GET /v2/external_initiators` - (File: core/web/router.go)

## Summary
The `/v2/external_initiators` list endpoint is registered with only basic session/token authentication, unlike the `Create` and `Destroy` endpoints for the same resource, which are wrapped in `auth.RequiresEditRole`. This lets a `UserRoleView` (lowest-privilege) session enumerate `OutgoingToken` and `AccessKey` secrets for every configured external initiator, secrets used by the node to authenticate itself when calling out to third-party webhooks.

## Finding Description
In `v2Routes`, the route registrations show the asymmetry directly: `authv2.GET("/external_initiators", paginatedRequest(eia.Index))` has no role guard, while `authv2.POST(...)` and `authv2.DELETE(...)` for the same resource are wrapped in `auth.RequiresEditRole`. [1](#0-0) 

`RequiresEditRole` explicitly blocks `UserRoleView` and `UserRoleRun`, confirming it is the mechanism relied on elsewhere to gate privileged mutations, and its absence on the GET route is the root cause. [2](#0-1) 

`ExternalInitiatorsController.Index` calls `NewExternalInitiatorResource`, which populates `OutgoingToken` (and `AccessKey`) into the JSON response with no role-based redaction. [3](#0-2) [4](#0-3) 

`OutgoingToken` is a per-initiator secret generated at creation time and used to authenticate outbound calls to the initiator's webhook. [5](#0-4) 

The route-role test table explicitly documents/asserts `viewOnlyAllowed: true` for `GET /v2/external_initiators`, while `POST`/`DELETE` on the same resource are marked `false, false, true` (not accessible by view or edit-minimal roles). This is existing, checked-in test behavior confirming the endpoint is reachable by a view-only session without a 401/403. [6](#0-5) 

The functional test `TestExternalInitiatorsController_Index` further confirms that `OutgoingToken` is returned verbatim in the list response for every initiator. [7](#0-6) 

## Impact Explanation
A user provisioned with only the read-only `UserRoleView` role can retrieve `OutgoingToken` (and `AccessKey`) for every external initiator configured on the node, via a single authenticated GET request. This is a genuine authorization inconsistency: the exact same resource's mutating operations (`Create`/`Destroy`) require `edit` role, but the read path that discloses equivalent-or-greater sensitive secret material does not enforce any role check beyond authentication. This maps to the in-scope "node API authentication or role bypass / key-secret exfiltration" impact category, since it directly undermines the RBAC model's intended separation between `view` and `edit` privileges.

## Likelihood Explanation
Likelihood is high wherever a deployment provisions `view`-role API credentials for lower-trust users or automation (a supported, documented role) — no special conditions are required beyond a valid authenticated view-role session, and the request is a single unauthenticated-role GET that succeeds deterministically per the existing test suite's own assertions.

## Recommendation
Require at least `auth.RequiresEditRole` on `GET /v2/external_initiators` (matching `Create`/`Destroy`), or strip `OutgoingToken`/`OutgoingSecret`/`AccessKey` from `ExternalInitiatorResource` for callers below `edit` role, and update `routesRolesMap` in `core/web/auth/auth_test.go` accordingly to prevent regression.

## Proof of Concept
1. As admin, create an external initiator: `POST /v2/external_initiators {"name":"foo","url":"http://example.com"}`; note the returned `outgoingToken`.
2. Create a user with `UserRoleView` and obtain a session/API token (per `cltest.User{Role: sessions.UserRoleView}` pattern used in `TestRBAC_Routemap_ViewOnly`).
3. As the view-role user, call `GET /v2/external_initiators` — per `TestExternalInitiatorsController_Index`, the JSON response includes `outgoingToken` and `accessKey` for `foo`, despite the view role being blocked from `POST`/`DELETE` on the same resource (see `routesRolesMap` entries at `core/web/auth/auth_test.go:224-226`).

// RequiresEditRole extracts the user object from the context, and asserts the user's role is at least
// 'edit'
func RequiresEditRole(handler func(*gin.Context)) func(*gin.Context) {
	return func(c *gin.Context) {
		user, ok := GetAuthenticatedUser(c)
		if !ok {
			c.Abort()
			jsonAPIError(c, http.StatusUnauthorized, errors.New("not a valid session"))
			return
		}
		if user.Role == clsessions.UserRoleView || user.Role == clsessions.UserRoleRun {
			c.Abort()
			jsonAPIError(c, http.StatusUnauthorized, errors.New("Unauthorized"))
			return
		}
		handler(c)
	}
}

func (eic *ExternalInitiatorsController) Index(c *gin.Context, size, page, offset int) {
	ctx := c.Request.Context()
	externalInitiators, count, err := eic.App.BridgeORM().ExternalInitiators(ctx, offset, size)
	resources := make([]presenters.ExternalInitiatorResource, 0, len(externalInitiators))
	for _, initiator := range externalInitiators {
		resources = append(resources, presenters.NewExternalInitiatorResource(initiator))
	}

	paginatedResponse(c, "externalInitiators", size, page, resources, count, err)
}

// ExternalInitiator represents a user that can initiate runs remotely
type ExternalInitiator struct {
	ID             int64
	Name           string
	URL            *models.WebURL
	AccessKey      string
	Salt           string
	HashedSecret   string
	OutgoingSecret string
	OutgoingToken  string

	CreatedAt time.Time
	UpdatedAt time.Time
}

// NewExternalInitiator generates an ExternalInitiator from an
// auth.Token, hashing the password for storage
func NewExternalInitiator(
	eia *auth.Token,
	eir *ExternalInitiatorRequest,
) (*ExternalInitiator, error) {
	salt := utils.NewSecret(utils.DefaultSecretSize)
	hashedSecret, err := auth.HashedSecret(eia, salt)
	if err != nil {
		return nil, pkgerrors.Wrap(err, "error hashing secret for external initiator")
	}

	return &ExternalInitiator{
		Name:           strings.ToLower(eir.Name),
		URL:            eir.URL,
		AccessKey:      eia.AccessKey,
		HashedSecret:   hashedSecret,
		Salt:           salt,
		OutgoingToken:  utils.NewSecret(utils.DefaultSecretSize),
		OutgoingSecret: utils.NewSecret(utils.DefaultSecretSize),
	}, nil

func TestExternalInitiatorsController_Index(t *testing.T) {
	t.Parallel()

	app := cltest.NewApplicationWithConfig(t,
		configtest.NewGeneralConfig(t, func(c *chainlink.Config, s *chainlink.Secrets) {
			c.JobPipeline.ExternalInitiatorsEnabled = new(true)
		}))
	require.NoError(t, app.Start(t.Context()))

	client := app.NewHTTPClient(nil)

	db := app.GetDB()
	borm := bridges.NewORM(db)

	eiFoo := cltest.MustInsertExternalInitiatorWithOpts(t, borm, cltest.ExternalInitiatorOpts{
		NamePrefix:    "foo",
		URL:           cltest.MustWebURL(t, "http://example.com/foo"),
		OutgoingToken: "outgoing_token",
	})
	eiBar := cltest.MustInsertExternalInitiatorWithOpts(t, borm, cltest.ExternalInitiatorOpts{NamePrefix: "bar"})

	resp, cleanup := client.Get("/v2/external_initiators?size=x")
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusUnprocessableEntity)

	resp, cleanup = client.Get("/v2/external_initiators?size=1")
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusOK)
	body := cltest.ParseResponseBody(t, resp)

	metaCount, err := cltest.ParseJSONAPIResponseMetaCount(body)
	require.NoError(t, err)
	require.Equal(t, 2, metaCount)

	var links jsonapi.Links
	var externalInitiators []presenters.ExternalInitiatorResource
	err = web.ParsePaginatedResponse(body, &externalInitiators, &links)
	require.NoError(t, err)
	assert.NotEmpty(t, links["next"].Href)
	assert.Empty(t, links["prev"].Href)

	assert.Len(t, externalInitiators, 1)
	assert.Equal(t, strconv.FormatInt(eiBar.ID, 10), externalInitiators[0].ID)
	assert.Equal(t, eiBar.Name, externalInitiators[0].Name)
	assert.Nil(t, externalInitiators[0].URL)
	assert.Equal(t, eiBar.AccessKey, externalInitiators[0].AccessKey)
	assert.Equal(t, eiBar.OutgoingToken, externalInitiators[0].OutgoingToken)

	resp, cleanup = client.Get(links["next"].Href)
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusOK)

	externalInitiators = []presenters.ExternalInitiatorResource{}
	err = web.ParsePaginatedResponse(cltest.ParseResponseBody(t, resp), &externalInitiators, &links)
	require.NoError(t, err)
	assert.Empty(t, links["next"])
	assert.NotEmpty(t, links["prev"])

	assert.Len(t, externalInitiators, 1)
	assert.Equal(t, strconv.FormatInt(eiFoo.ID, 10), externalInitiators[0].ID)
	assert.Equal(t, eiFoo.Name, externalInitiators[0].Name)
	assert.Equal(t, eiFoo.URL.String(), externalInitiators[0].URL.String())
	assert.Equal(t, eiFoo.AccessKey, externalInitiators[0].AccessKey)
	assert.Equal(t, eiFoo.OutgoingToken, externalInitiators[0].OutgoingToken)
