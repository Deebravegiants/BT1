### Title
Missing `extcodesize` check in `EvmHost.dispatchIncoming(GetResponse)` / `dispatchTimeOut` lets calls to code-less destinations silently "succeed", permanently consuming receipts and misdirecting relayer fees - (File: evm/src/core/EvmHost.sol)

### Summary
`EvmHost.dispatchIncoming(PostRequest, address)` explicitly guards against calling a destination that has no deployed code by checking `extcodesize(destination) == 0` and returning early before making the low-level `.call` [1](#0-0) . This mirrors exactly the bug class in the report: an unconditional call/delegatecall to a resolved address that might be zero (or code-less) will "succeed" trivially without executing any logic. However, the three sibling dispatch entry points in the same contract — `dispatchIncoming(GetResponse, address)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)` — omit this check entirely and go straight to `.call(...)` on `_bytesToAddress(...)` [2](#0-1) [3](#0-2) .

### Finding Description
A low-level `.call` (or `delegatecall`) to an address with no deployed contract code always returns `success = true` on the EVM, regardless of whether the target is `address(0)` or simply a not-yet-deployed / already-destroyed contract. `dispatchIncoming(PostRequest, address)` is written with this exact hazard in mind, guarding against it with an `extcodesize` check and returning early (leaving the request retryable) if the destination has no code:

```solidity
address destination = _bytesToAddress(request.to);
uint256 size;
assembly { size := extcodesize(destination) }
if (size == 0) { return; }
``` [1](#0-0) 

But `dispatchIncoming(GetResponse, address)`:
```solidity
(bool success,) = _bytesToAddress(response.request.from)
    .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));
if (!success) { delete _responseReceipts[commitment]; return; }
uint256 fee = _requestCommitments[commitment].fee;
if (fee != 0) { IERC20(feeToken()).safeTransfer(relayer, fee); }
emit GetRequestHandled(...);
``` [2](#0-1) 

and both `dispatchTimeOut` overloads (`GetRequestTimeout`, `PostRequestTimeout`) [3](#0-2)  perform no such check. If the resolved `from`/target address has no code at delivery time, `success` is `true` and the function proceeds as if the app's `onGetResponse`/`onGetTimeout`/`onPostRequestTimeout` callback had actually run: the response/request commitment is irrevocably deleted (replay protection consumed), the app is treated as having "handled" the message, and — in the `GetResponse` path — the relayer is paid the fee out of `_requestCommitments[commitment].fee` even though the destination app never executed any code.

This is reachable through `HandlerV2.handleGetResponses`, `handlePostRequestTimeouts`, and `handleGetRequestTimeouts`, which are called by any relayer submitting a valid MMR/state proof for a request that was legitimately dispatched earlier [4](#0-3) [5](#0-4) . The `from`/`to` address embedded in the request is fixed at the time the original GET/POST was dispatched and is bound by the commitment hash, so it cannot be forged by the relayer — but nothing prevents the destination address from becoming code-less between dispatch and delivery (e.g., the dispatching contract self-destructs, or is deployed via a CREATE2/factory pattern where a request was in flight before/after redeployment, or an upgradeable proxy pattern is torn down). In that state, this omission causes the message to be permanently marked as delivered/handled and its fee paid out — without the destination app ever running its callback.

### Impact Explanation
This breaks the "at-least-once, retryable-until-delivered" delivery guarantee the codebase clearly designed for (as shown by the explicit `extcodesize` guard in the POST path, whose comment says "instead of reverting the entire batch, early return here" specifically so it can be retried). For `dispatchIncoming(GetResponse)`, this results in the relayer being paid the fee (`IERC20(feeToken()).safeTransfer(relayer, fee)`) for a message that was never actually delivered to the app — a direct, if narrow, fee-theft/misallocation vector. For all three functions, the request/response commitment and receipts are permanently deleted, meaning the message can never be delivered even after the destination contract is redeployed at that address (a permanent freeze/loss of the cross-chain message, matching "a route unable to deliver messages"). Because these functions are protected only by `restrict(_hostParams.handler)` and the handler is called by any permissionless relayer submitting a valid proof, this is reachable without any privileged role.

### Likelihood Explanation
Likelihood is moderate rather than trivial: exploitation requires the destination address (fixed by the original dispatch, not attacker-choosable at delivery time) to have no code at the time the response/timeout is relayed. This can occur naturally with `CREATE2`-predicted/counterfactual deployments, proxies that are upgraded away from having code at that slot, or contracts that `selfdestruct` (still possible pre-dispatch via `SELFDESTRUCT` semantics on some chains/EVM configurations) between dispatch and delivery. It is not a "click a button and drain funds" bug reachable in one arbitrary transaction against an always-deployed contract, but it is a real, silent-failure class bug inconsistently guarded against in the very same contract that already recognizes and fixes it for the POST path.

### Recommendation
Add the same `extcodesize`/non-zero-code check used in `dispatchIncoming(PostRequest, address)` to `dispatchIncoming(GetResponse, address)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)` before performing the low-level `.call`. If the destination has no code, return early without deleting/consuming the response/request commitment (leaving it retryable) and without paying out the relayer fee, exactly mirroring the existing POST-request pattern.

### Proof of Concept
1. App `A` at address `X` dispatches a `GetRequest` (or a `PostRequest`/`GetRequest` destined to time out) via the host; the commitment binds `from = X`.
2. Before the response/timeout is relayed, `X` ceases to have code at that address (e.g., `X` is a `CREATE2` factory-deployed contract that is destroyed, or is a counterfactual address for which the deploying transaction is retried/reverted, or a proxy is torn down).
3. A relayer submits a valid MMR/state proof for the response/timeout to `HandlerV2.handleGetResponses` / `handlePostRequestTimeouts` / `handleGetRequestTimeouts`, which calls `host.dispatchIncoming(response, relayer)` or `host.dispatchTimeOut(...)`.
4. Inside `EvmHost`, `_bytesToAddress(...).call(...)` targets code-less `X`; the EVM returns `success = true` without executing anything.
5. For `dispatchIncoming(GetResponse)`: the relayer is paid `_requestCommitments[commitment].fee` and `GetRequestHandled` is emitted, even though `X.onGetResponse` never ran. For the timeout paths, the request/response receipt is irrevocably deleted, permanently precluding any future delivery of that message to `X` even if `X` is later redeployed at the same address.

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    function handleGetResponses(IHost host, GetResponseMessage calldata message) external notFrozen(host) {
        uint256 timestamp = block.timestamp;
        uint256 delay = timestamp - host.stateMachineCommitmentUpdateTime(message.proof.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        uint256 responsesLength = message.responses.length;
        MerkleMountainRange.Leaf[] memory leaves = new MerkleMountainRange.Leaf[](responsesLength);

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // don't check for timeouts because it's checked on Hyperbridge

            // known request? also serves as source check
            FeeMetadata memory meta = host.requestCommitments(leaf.response.request.hash());
            if (meta.sender == address(0)) revert UnknownMessage();
            leaves[i] = MerkleMountainRange.Leaf(leaf.index, leaf.response.hash());
        }

        bytes32 root = host.stateMachineCommitment(message.proof.height).overlayRoot;
        if (root == bytes32(0)) revert StateCommitmentNotFound();
        bool valid = MerkleMountainRange.VerifyProof(root, message.proof.multiproof, leaves, message.proof.leafCount);
        if (!valid) revert InvalidProof();

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // duplicate response?
            if (host.responseReceipts(leaf.response.request.hash()).relayer != address(0)) revert DuplicateMessage();
            host.dispatchIncoming(leaf.response, _msgSender());
        }
    }

    function handlePostRequestTimeouts(IHost host, PostRequestTimeoutMessage calldata message)
        external
        notFrozen(host)
    {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            PostRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            // known request? also serves as source check
            bytes32 requestCommitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(requestCommitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(REQUEST_RECEIPTS_STORAGE_PREFIX, requestCommitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(PostRequestTimeout(request, _msgSender()), meta, requestCommitment);
        }
    }
