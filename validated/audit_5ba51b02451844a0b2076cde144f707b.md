### Title
Genesis-configured fee rate is silently ignored because `Bank::new_from_genesis()` never propagates it into `FeeStructure` - (File: `runtime/src/bank.rs`)

### Summary
`Bank::process_genesis_config()` copies the genesis `FeeRateGovernor` into `self.fee_rate_governor`, but the value that is actually used everywhere fees are calculated — `self.fee_structure.lamports_per_signature` — is never updated to match it. `fee_structure` is left at `FeeStructure::default()` from `default_with_accounts()` and is only ever corrected in test-only helper code, never in the production genesis-processing path.

### Finding Description
`Bank::default_with_accounts()` initializes `fee_structure: FeeStructure::default()` [1](#0-0) .

`Bank::new_from_genesis()` — the constructor used to build the bank from a `GenesisConfig` on validator startup and in `ledger/src/blockstore_processor.rs` / `runtime/src/snapshot_bank_utils.rs` — calls `process_genesis_config()` but never calls `set_fee_structure()`: [2](#0-1) 

Inside `process_genesis_config()`, only `self.fee_rate_governor` is populated from the genesis config; the `fee_structure` field (a separate struct) is untouched: [3](#0-2) 

Meanwhile, actual fee computation throughout the runtime uses `bank.fee_structure().lamports_per_signature`, not `fee_rate_governor.lamports_per_signature`:
- `get_fee_for_message` [4](#0-3) 
- `calculate_reward_for_transaction` [5](#0-4) 
- `calculate_priority_and_cost` (banking stage prioritization) [6](#0-5) 
- `check_fee_payer_unlocked` (consumer fee-payer balance validation) [7](#0-6) 

Notably, the test-only constructor `new_with_paths_for_tests` explicitly patches this gap with a comment acknowledging it: [8](#0-7) 
and many individual unit tests must call `bank.set_fee_structure(...)` manually to align fee behavior with the genesis config, e.g.: [9](#0-8) [10](#0-9) 

This mirrors the reported bug class exactly: a governor/config value (`FeeRateGovernor.lamports_per_signature`, set via genesis or CLI flags such as `--target-lamports-per-signature` in `genesis/src/main.rs`) is intended to seed a downstream parameter (`FeeStructure.lamports_per_signature`) used for real accounting, but the initialization routine never performs that propagation in production code — only ad hoc test scaffolding does it, exactly as the Optimism report describes `SystemConfig.initialize()` never calling `_setEIP1559Params()`.

### Impact Explanation
Any non-default cluster fee configuration supplied via genesis (or genesis CLI `--target-lamports-per-signature`/`--fee-burn-percentage`) has zero effect on the fees actually charged, the priority computed in banking stage, and the rewards distributed to the leader/burn accounting — all of which use `FeeStructure::default().lamports_per_signature` instead of the operator-intended value. This causes materially mis-priced execution relative to the deployer's declared configuration for any network that is not using the hardcoded default fee schedule, silently defeating the intended fee-rate configuration mechanism.

### Likelihood Explanation
This triggers unconditionally on every bank built from genesis in production (`new_from_genesis` → `process_genesis_config`), with no special conditions required beyond a genesis config specifying a fee rate different from `FeeStructure::default()`. Because all validators run identical code, the misconfiguration is consistent cluster-wide rather than causing cross-node divergence, but it deterministically and silently overrides operator-declared fee-rate parameters in favor of the hardcoded default at genesis.

### Recommendation
In `Bank::new_from_genesis()` (or within `process_genesis_config()`), after setting `self.fee_rate_governor`, also call `self.set_fee_structure(&FeeStructure { lamports_per_signature: genesis_config.fee_rate_governor.lamports_per_signature, ..FeeStructure::default() })` (matching what the test-only constructors already do), so genesis-configured fee parameters are consistently applied in the production initialization path rather than only in test helpers.

### Proof of Concept
1. Build a `GenesisConfig` with `fee_rate_governor.lamports_per_signature` set to a value different from `FeeStructure::default().lamports_per_signature` (e.g. via `genesis/src/main.rs --target-lamports-per-signature`).
2. Start a validator/bank via `Bank::new_from_genesis()` (the non-test production path).
3. Inspect `bank.fee_rate_governor().lamports_per_signature` (reflects the configured value) vs `bank.fee_structure().lamports_per_signature` (remains `FeeStructure::default()`'s value).
4. Submit a transaction and observe that the fee actually deducted (via `get_fee_for_message`/`calculate_reward_for_transaction`) matches `FeeStructure::default()`, not the genesis-configured governor value — confirmed by contrast with `runtime/src/bank/tests.rs` tests (e.g. `test_bank_tx_fee`, `test_status_cache_signature_storage_config`) which must manually call `set_fee_structure` to force alignment for their assertions to hold.

            bank.set_is_alpenglow();

    fn process_genesis_config(
        &mut self,
        genesis_config: &GenesisConfig,
        #[cfg(feature = "dev-context-only-utils")] leader_for_tests: Option<SlotLeader>,
        #[cfg(feature = "dev-context-only-utils")] genesis_hash: Option<Hash>,
    ) {
        // Bootstrap validator collects fees until `new_from_parent` is called.
        self.fee_rate_governor = genesis_config.fee_rate_governor.clone();

        for (pubkey, account) in genesis_config.accounts.iter() {
            assert!(
                self.get_account(pubkey).is_none(),
                "{pubkey} repeated in genesis config"
            );
            let account_shared_data = create_account_shared_data(account);
            self.store_account_without_stakes_cache(pubkey, &account_shared_data);
            self.capitalization.fetch_add(account.lamports(), Relaxed);
            self.accounts_data_size_initial += account.data().len() as u64;
        }

        for (pubkey, account) in genesis_config.rewards_pools.iter() {
            assert!(
                self.get_account(pubkey).is_none(),
                "{pubkey} repeated in genesis config"
            );
            let account_shared_data = create_account_shared_data(account);
            self.store_account_without_stakes_cache(pubkey, &account_shared_data);
            self.accounts_data_size_initial += account.data().len() as u64;
        }

        self.stakes_cache = StakesCache::new(Stakes::new_from_accounts_for_genesis(
            self.new_warmup_cooldown_rate_epoch(),
            genesis_config.accounts.iter(),
            self.use_fixed_point_stake_math(),
        ));

        // After storing genesis accounts, the bank stakes cache will be warmed
        // up and can be used to set the leader id to the highest staked
        // node.
        let leader = self.stakes_cache.stakes().highest_staked_node();
        // If a leader is specified for test purposes, use that and if no leader found, use a random one.
        #[cfg(feature = "dev-context-only-utils")]
        let leader = leader_for_tests
            .or(leader)
            .or(Some(SlotLeader::new_unique()));
        self.leader = leader.expect("genesis processing failed because no staked nodes exist");

        #[cfg(not(feature = "dev-context-only-utils"))]
        let genesis_hash = genesis_config.hash();
        #[cfg(feature = "dev-context-only-utils")]
        let genesis_hash = genesis_hash.unwrap_or(genesis_config.hash());

        self.blockhash_queue.write().unwrap().genesis_hash(
            &genesis_hash,
            genesis_config.fee_rate_governor.lamports_per_signature,
        );

        self.hashes_per_tick = RwLock::new(genesis_config.hashes_per_tick());
        self.ticks_per_slot = genesis_config.ticks_per_slot();
        self.ns_per_slot = genesis_config.ns_per_slot();
        self.genesis_creation_time = genesis_config.creation_time;
        self.max_tick_height = (self.slot + 1) * self.ticks_per_slot;
        self.slots_per_year = genesis_config.slots_per_year();

        self.epoch_schedule = genesis_config.epoch_schedule.clone();
        self.refresh_slot_params_with_baseline(Self::genesis_config_slot_params(
            genesis_config,
            self.partitioned_rewards_stake_account_stores_per_block,
        ));

        self.inflation = Arc::new(RwLock::new(genesis_config.inflation));

        self.rent_collector = RentCollector::new(
            self.epoch,
            self.epoch_schedule().clone(),
            self.slots_per_year,
            genesis_config.rent.clone(),
        );
    }

    pub fn get_fee_for_message(&self, message: &SanitizedMessage) -> Option<u64> {
        {
            let blockhash_queue = self.blockhash_queue.read().unwrap();
            blockhash_queue.get_lamports_per_signature(message.recent_blockhash())
        }
        .or_else(|| {
            self.load_message_nonce_data(message, false)
                .map(|(_nonce_address, nonce_data)| nonce_data.get_lamports_per_signature())
        })?;

        let transaction_configuration =
            TransactionConfiguration::try_from_sanitized_message(message, &self.feature_set)
                .ok()?;
        Some(solana_fee::calculate_fee(
            message,
            self.fee_structure().lamports_per_signature,
            transaction_configuration.priority_fee_lamports,
            self.fee_features(),
        ))
    }
