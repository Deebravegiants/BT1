## Title
Unchecked external call in `EvmHost.dispatchIncoming(GetResponse)` / `dispatchTimeOut` skips the contract-existence check applied to `PostRequest` delivery, causing responses to be silently marked "delivered" and relayer fees paid without any module code executing - (File: `evm/src/core/EvmHost.sol`)

### Summary
`EvmHost.dispatchIncoming(PostRequest, address)` explicitly guards against calling a destination with no code before invoking `IApp.onAccept` [1](#0-0) . The sibling functions `dispatchIncoming(GetResponse, address)`, `dispatchTimeOut(GetRequestTimeout, ...)` and `dispatchTimeOut(PostRequestTimeout, ...)` omit this check and go straight to a low-level `.call()` on the destination extracted from the request/timeout payload [2](#0-1) .

### Finding Description
In Solidity, a low-level `.call()` to an address with no deployed code always returns `success = true` with empty return data — this is a no-op, not a real invocation of any application logic. `dispatchIncoming(GetResponse)` relies entirely on this boolean to decide whether the response was "handled":
```
(bool success,) = _bytesToAddress(response.request.from)
    .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));
if (!success) { delete _responseReceipts[commitment]; return; }
// reward the relayer fee
``` [3](#0-2) 

Because `success` is trivially `true` whenever the destination has no code, the function proceeds past the "so it can be retried" rollback path, permanently records `_responseReceipts[commitment]` as delivered, and unconditionally pays the relayer the protocol fee via `IERC20(feeToken()).safeTransfer(relayer, fee)` — even though `onGetResponse` never actually ran on any application. The exact same pattern exists for `dispatchTimeOut(GetRequestTimeout, ...)` and `dispatchTimeOut(PostRequestTimeout, ...)`, both of which `delete`/finalize the request commitment and pay out the relayer fee based on a `.call()` result that carries no information about whether real code executed [4](#0-3) .

This is the exact bug class in the report: an external call's outcome is trusted (`success == true` is treated as proof of correct execution) without first validating that the target is actually a contract capable of running the intended logic — precisely the `extcodesize`/`isContract` check that `dispatchIncoming(PostRequest)` performs but the GetResponse/timeout paths do not.

### Impact Explanation
Once a GetResponse or timeout lands on a destination with no code (e.g., the requesting module address was never deployed on this chain, or a request references a stale/incorrect `from`), the response/timeout commitment is deleted/finalized as if properly delivered, and the fee escrowed for that message is disbursed to the relayer as a reward. The intended application callback (which may be responsible for releasing escrowed value, unlocking a refund, or otherwise reacting to the response) never runs and there is no remaining commitment or receipt state that would allow it to be retried — the message is dropped forever while still being accounted as a successful delivery. This satisfies "a route unable to deliver messages" / permanent loss of the message's intended effect, paired with relayer fees being paid out for a delivery that never actually reached application code.

### Likelihood Explanation
This path is reached by any relayer submitting a normal, validly-proven `handleGetResponses`/timeout message through `HandlerV2`, which then calls `EvmHost.dispatchIncoming`/`dispatchTimeOut` — no privileged role is required, and no malicious governance/admin/collator action is needed. It is triggered whenever the destination address encoded in the original request has no code at delivery time on the destination chain (a state entirely plausible for cross-chain GET requests whose target module identity is chosen at request time, before code is guaranteed to exist at that address on the responding chain).

### Recommendation
Add the same `extcodesize`/`isContract` guard used in `dispatchIncoming(PostRequest)` to `dispatchIncoming(GetResponse)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)` before making the low-level call, and treat a zero-code destination the same way a `success == false` result is treated today (i.e., preserve the receipt/commitment for retry and withhold the relayer fee) instead of finalizing delivery and paying out.

### Proof of Concept
1. A source-chain app dispatches a `DispatchGet` (or `DispatchPost`) request whose embedded `from`/response-target address currently has no deployed bytecode on the destination chain (e.g., a not-yet-deployed counterpart, or an address that will never host a contract).
2. A relayer obtains a valid state/consensus proof for the corresponding `GetResponse` (or timeout) and calls `HandlerV2.handleGetResponses` (or the timeout equivalent), which invokes `EvmHost.dispatchIncoming(GetResponse, relayer)` / `dispatchTimeOut(...)`.
3. `_bytesToAddress(response.request.from).call(...)` targets the no-code address; Solidity returns `success = true` trivially.
4. `EvmHost` records the response as delivered/finalized (writes/deletes the relevant commitment) and transfers the escrowed fee to the relayer via `IERC20(feeToken()).safeTransfer(relayer, fee)`, even though `onGetResponse`/`onPostRequestTimeout` never executed any code.
5. The intended application logic never runs and the commitment can no longer be retried, permanently losing the message's effect while the relayer is paid as if it succeeded.

        address destination = _bytesToAddress(request.to);
        uint256 size;
        assembly {
            size := extcodesize(destination)
        }
        if (size == 0) {
            // instead of reverting the entire batch, early return here.
            return;

        bytes32 commitment = request.hash();

    /**
     * @dev Dispatch an incoming GET response to source module
     * @param response - get response
     */
    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    /**
     * @dev Dispatch an incoming GET timeout to the source module.
     * @notice Does not refund any protocol fees.
     * @param timeout - timed-out get request bundled with the relayer that submitted the timeout proof
     * @param meta - fee metadata for the original request
     * @param commitment - request commitment
     */
    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }
