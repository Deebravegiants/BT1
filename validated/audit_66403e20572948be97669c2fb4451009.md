## Analog Found

### Title
Zero-value sentinel prevents configuring a genuine 0% destination protocol fee, silently overcharging intent users - (File: `evm/src/apps/IntentGatewayV2.sol`)

### Summary
`IntentGatewayV2.placeOrder` resolves the protocol fee for an order's destination chain by reading `_destinationProtocolFees[destinationHash]` and falling back to the gateway-wide default whenever that value is `0`. This is the same "zero means unset" sentinel bug described in the source report for `UniV3OracleImpl`: there is no way to distinguish "governance explicitly configured 0% for this destination" from "no override was ever set," so a legitimate zero-fee configuration is silently discarded and the (non-zero) default fee is charged instead.

### Finding Description
`_updateParams` in `evm/src/apps/intentsv2/IntentsBase.sol` lets Hyperbridge governance set a per-destination fee override via `DestinationFee.destinationFeeBps`, stored unconditionally into `_destinationProtocolFees[keccak256(chain)]`: [1](#0-0) 

When a user calls `placeOrder`, the fee actually applied is resolved with a bare zero-check: [2](#0-1) 

Because Solidity mappings default every unset key to `0`, and `0` is also a valid, intentional "no protocol fee for this destination" configuration, the two states are indistinguishable. If governance sets `destinationFeeBps = 0` for a destination to grant it a fee-free route (e.g., to incentivize adoption of a new chain), `placeOrder` will instead treat it as "not configured" and fall back to `_params.protocolFeeBps`, charging every order to that destination the default fee.

The excess amount deducted is emitted as `DustCollected` and swept out via `_sweepDust`/governance to the protocol treasury, so it is not a synthetic effect — the reduced input amount is real value taken from the user's escrowed input: [3](#0-2) 

The test suite confirms this exact fallback behavior is by design/expected under current logic (`testPlaceOrderDestinationFeeWithFallback`), which is precisely the ambiguity flagged by the source report: [4](#0-3) 

### Impact Explanation
Every order placed by an ordinary, unprivileged user toward a destination for which governance intended a 0% protocol fee will be overcharged by the full default `protocolFeeBps` amount, taken directly from the user's input tokens and permanently swept to the protocol beneficiary. This is a direct, unintended transfer of value away from intent users on that route — a real loss of user funds caused purely by the sentinel-collision bug, not by any governance misbehavior (governance's chosen value of `0` is a legitimate, in-range configuration per `_validateParams`/`_updateParams`, which only rejects `feeBps >= 10_000`).

### Likelihood Explanation
This triggers automatically and silently on every single `placeOrder` call to the affected destination once governance sets a 0% override — no attacker action is needed, and no user can detect or opt out of the incorrect charge before submission. The only precondition is a normal, in-scope governance action (setting a fee to `0`, which the validation logic explicitly allows), making this a design defect rather than a hypothetical or adversarial-governance scenario.

### Recommendation
Add an explicit "is-set" flag distinguishing a configured 0% override from an unset entry, mirroring the source report's suggested fix:
- Store destination fee overrides in a struct/mapping with a `bool set` (or `bool isDefault`) alongside `feeBps`, e.g. `mapping(bytes32 => DestinationFeeOverride)` where `DestinationFeeOverride { uint256 feeBps; bool isSet; }`.
- In `placeOrder`, only fall back to `_params.protocolFeeBps` when `!isSet`, not when `feeBps == 0`.
- Update `_updateParams` to set `isSet = true` whenever a `DestinationFee` entry is applied.

### Proof of Concept
1. Governance calls `updateParams` with `destinationFees = [{ chain: "ARBITRUM", destinationFeeBps: 0 }]`, intending Arbitrum orders to pay no protocol fee. This is accepted since `0 < 10_000` passes `_updateParams`'s validation.
2. `_destinationProtocolFees[keccak256("ARBITRUM")]` is set to `0`.
3. A user calls `placeOrder` with `order.destination = "ARBITRUM"`.
4. In `placeOrder`, `protocolFeeBps = _destinationProtocolFees[destinationHash]` reads `0`, and the `if (protocolFeeBps == 0) { protocolFeeBps = _params.protocolFeeBps; }` branch overwrites it with the non-zero default (e.g., 100 bps).
5. The user's input is reduced by `originalAmount * 100 / 10_000`, emitted as `DustCollected`, and later swept to the protocol beneficiary — despite governance's intent that this destination be fee-free.

    function testPlaceOrderDestinationFeeWithFallback() public {
        // Test that when destination fee is not set (or is 0), it falls back to default protocol fee
        IntentGatewayV2 customGateway = _deployGatewayProxy();
        Params memory customParams = Params({
            host: address(host),
            dispatcher: address(dispatcher),
            solverSelection: false,
            surplusShareBps: 10000,
            protocolFeeBps: 100, // 1% default
            priceOracle: address(0)
        });
        customGateway.initialize(customParams, new bytes[](0), address(0));

        // Place order to destination without specific fee set
        uint256 inputAmount = 1000 * 1e6; // 1000 USDC
        uint256 expectedDefaultFee = (inputAmount * 100) / 10000; // 10 USDC (1% default)

        deal(address(usdc), user, inputAmount);

        bytes memory unknownDestination = bytes("UNKNOWN_CHAIN");

        Order memory order = Order({
            user: bytes32(0),
            source: bytes(""),
            destination: unknownDestination,
            deadline: block.timestamp + 1 hours,
            nonce: 0,
            fees: 0,
            session: address(0),
            predispatch: DispatchInfo({assets: new TokenInfo[](0), call: ""}),
            inputs: new TokenInfo[](1),
            output: PaymentInfo({beneficiary: bytes32(uint256(uint160(user))), assets: new TokenInfo[](1), call: ""})
        });

        order.inputs[0] = TokenInfo({token: bytes32(uint256(uint160(address(usdc)))), amount: inputAmount});
        order.output.assets[0] = TokenInfo({token: bytes32(uint256(uint160(address(dai)))), amount: 2000 * 1e18});

        vm.startPrank(user);
        usdc.approve(address(customGateway), inputAmount);

        vm.recordLogs();
        customGateway.placeOrder(order, bytes32(0));
        vm.stopPrank();

        // Verify DustCollected event was emitted with default fee (1%)
        Vm.Log[] memory entries = vm.getRecordedLogs();
        uint256 collectedFee = 0;

        for (uint256 i = 0; i < entries.length; i++) {
            if (entries[i].topics[0] == keccak256("DustCollected(address,uint256)")) {
                (address token, uint256 amount) = abi.decode(entries[i].data, (address, uint256));
                if (token == address(usdc)) {
                    collectedFee = amount;
                }
            }
        }

        assertEq(collectedFee, expectedDefaultFee, "Should use default protocol fee when destination fee not set");
    }
