### Title
Deprecated-TokenGateway blocklist is missing from the Kusama/Gargantua runtime, letting compromised TokenGateway addresses forge accepted requests into `pallet-hyper-fungible-token` - (File: `parachain/runtimes/gargantua/src/ismp.rs`)

### Summary
The `nexus` (Polkadot-coprocessor) runtime hard-rejects any incoming ISMP `PostRequest` whose `from` field matches one of three deprecated `TokenGateway` contract addresses, via `is_deprecated_token_gateway` in `ProxyModule::on_accept`/`on_timeout`. The sibling `gargantua` (Kusama-coprocessor) runtime runs the structurally identical `ProxyModule` dispatch path but has no such check at all, so the same forged/compromised-address messages that are blocked on Nexus are freely accepted and routed to `pallet_hyper_fungible_token` on Gargantua. This is the same bug class as the pyLoad report: a restriction fix ("block this specific known-bad source") was added to one code path but not propagated to every reachable equivalent path, leaving the security boundary incomplete.

### Finding Description
`parachain/runtimes/nexus/src/ismp.rs` defines a hardcoded blocklist and enforces it at the very top of the module's request handling: [1](#0-0) 

and applies it unconditionally before any other processing in both `on_accept` and `on_timeout`: [2](#0-1) [3](#0-2) 

The comment on the constant states explicitly that "Any `PostRequest` whose `from` field matches any of these 20-byte addresses is rejected in `ProxyModule::on_accept` before any other processing — the message is neither dispatched locally nor forwarded onwards" — indicating this is a deliberate security control against these specific (deprecated/compromised) `TokenGateway` deployments across every EVM chain in the mainnet address book (Ethereum/Arbitrum/Optimism/Base/BSC/Gnosis/Polygon/Soneium), as also documented in the contract-address tables.

`parachain/runtimes/gargantua/src/ismp.rs` implements the same `ProxyModule` trait for the Kusama-coprocessor deployment, and it also routes requests to `pallet_hyper_fungible_token` and forwards non-local-destination requests exactly like Nexus: [4](#0-3) 

but it contains no `is_deprecated_token_gateway` call, no `DEPRECATED_TOKEN_GATEWAY_ADDRESSES` constant, and no equivalent rejection in `on_timeout`. The `ProxyModule::on_accept` on Gargantua forwards or locally dispatches every `PostRequest`, including one whose `from` is a deprecated TokenGateway address, straight into `pallet_hyper_fungible_token::Pallet::<Runtime>::on_accept(request)` (matched via `pallet_hyper_fungible_token::PALLET_ID`) or forwards it on to another chain via `Ismp::dispatch_request`.

Because both runtimes share the same coprocessor role, the same EVM state-machine clients, and the same set of connected EVM `TokenGateway`/`HyperFungibleToken` deployments, a message that is provably dangerous enough to warrant a hard reject on Nexus is accepted and processed as legitimate on Gargantua. This is precisely CWE-706 (Use of Incorrectly-Resolved Name or Reference resulting in an incomplete restriction) — the same class of bug as the pyLoad `storage_folder` fix that blocked `PKGDIR`/`userdir` but missed the Flask session directory.

### Impact Explanation
If the deprecated TokenGateway addresses were blocklisted because they are known to be exploitable/compromised (e.g., an attacker can trigger arbitrary or spoofed cross-chain messages appearing to originate "from" that contract on the source EVM chain), then any attacker able to produce a valid ISMP delivery proof "from" one of those addresses can submit it to the Gargantua/Kusama coprocessor and have it processed by `pallet_hyper_fungible_token` (a mint/burn token-bridge application) as if it came from a trusted TokenGateway deployment. This can result in unauthorized mint/burn actions or forged message delivery reaching a live fund-moving pallet — satisfying the "forged message delivery" / "unauthorized app action" impact bar, and it is reachable by any relayer/attacker who can submit a `PostRequest` delivery through the standard ISMP message-handling path (no privileged role required).

### Likelihood Explanation
High likelihood of reachability: the vulnerable path (`ProxyModule::on_accept` in `parachain/runtimes/gargantua/src/ismp.rs`) is the default entry point for every incoming ISMP `PostRequest` destined for, or routed through, the Gargantua/Kusama coprocessor — exactly the same entry point that Nexus protects. Any unprivileged party who can relay a message with `from` equal to one of the three known deprecated addresses (these addresses are public, published in the docs) reaches this code with zero additional preconditions beyond normal message delivery/proof verification, which is unaffected by this bug.

### Recommendation
Add the same `DEPRECATED_TOKEN_GATEWAY_ADDRESSES` constant and `is_deprecated_token_gateway` check (or a shared helper used by both runtimes) to `parachain/runtimes/gargantua/src/ismp.rs`, applied at the top of both `ProxyModule::on_accept` and `ProxyModule::on_timeout`, mirroring exactly what `parachain/runtimes/nexus/src/ismp.rs` does. Ideally, factor the blocklist and check into a shared crate/module consumed by both runtimes so future updates to the list cannot silently diverge again between deployments.

### Proof of Concept
1. An attacker (or compromised/legacy TokenGateway contract) on any EVM chain connected to the Gargantua/Kusama coprocessor constructs (or otherwise obtains) a valid ISMP delivery for a `PostRequest` with `from = 0xFd413e3AFe560182C4471F4d143A96d3e259B6dE` (one of the addresses in `DEPRECATED_TOKEN_GATEWAY_ADDRESSES`), `to` set to `pallet_hyper_fungible_token::PALLET_ID`, `dest = HostStateMachine::get()` (Kusama parachain id), and a body crafted to trigger a mint/unlock action.
2. This request is relayed and delivered to the Gargantua runtime's `pallet-ismp` message handler, which calls `ProxyModule::on_accept(request)` (`parachain/runtimes/gargantua/src/ismp.rs:375-422`).
3. Because Gargantua has no `is_deprecated_token_gateway` check, execution proceeds past the bandwidth gate straight into `pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request)`.
4. The identical request replayed against `parachain/runtimes/nexus/src/ismp.rs:362-373` is rejected immediately with `"rejecting request from deprecated TokenGateway address..."`, confirming the check exists and is intentionally enforced on one runtime but omitted on the other — demonstrating the incomplete fix / bypass.

/// Deprecated TokenGateway contract addresses whose incoming ISMP Post requests
/// must be rejected unconditionally by the nexus runtime.
/// Any [`PostRequest`] whose `from` field matches any of these 20-byte addresses
/// is rejected in [`ProxyModule::on_accept`] before any other processing — the
/// message is neither dispatched locally nor forwarded onwards.
pub const DEPRECATED_TOKEN_GATEWAY_ADDRESSES: &[[u8; 20]] = &[
	// Ethereum / Arbitrum / Optimism / Base / BSC / Gnosis TokenGateway
	hex_literal::hex!("Fd413e3AFe560182C4471F4d143A96d3e259B6dE"),
	// Polygon / Unichain TokenGateway
	hex_literal::hex!("8b536105b6Fae2aE9199f5146D3C57Dfe53b614E"),
	// Soneium TokenGateway
	hex_literal::hex!("Ce304770236f39F9911BfCC51afBdfF3b8635718"),
];

/// Returns `true` if `from` is exactly one of the deprecated TokenGateway
/// contract addresses in [`DEPRECATED_TOKEN_GATEWAY_ADDRESSES`].
fn is_deprecated_token_gateway(from: &[u8]) -> bool {
	DEPRECATED_TOKEN_GATEWAY_ADDRESSES.iter().any(|deprecated| deprecated == from)
}

impl IsmpModule for ProxyModule {
	fn on_accept(&self, request: PostRequest) -> Result<Weight, anyhow::Error> {
		// Permanently reject any request originating from a deprecated TokenGateway
		// deployment, regardless of destination. This short-circuits both the
		// forwarding path (dest != host) and the locally-dispatched path below.
		if is_deprecated_token_gateway(&request.from) {
			return Err(anyhow!(
				"rejecting request from deprecated TokenGateway address {:?} on {:?}",
				request.from,
				request.source,
			));
		}

		// Bandwidth gate. Always-enforce; skipped for purchase messages so the
		// recharge flow itself doesn't need bandwidth.
		if !pallet_bandwidth::Pallet::<Runtime>::is_purchase_message(&request) {
			let bytes = ismp::abi::encode_post_request(&request).len() as u32;
			<pallet_bandwidth::Pallet<Runtime> as pallet_bandwidth::BandwidthGate>::try_consume(
				&request.source,
				&request.from,
				bytes,
			)
			.map_err(|err| {
				anyhow!(
					"bandwidth gate: {err} (source={:?}, from={:x?})",
					request.source,
					request.from
				)
			})?;
		}

		if request.dest != HostStateMachine::get() {
			Ismp::dispatch_request(
				Request::Post(request),
				FeeMetadata::<Runtime> { payer: [0u8; 32].into(), fee: Default::default() },
			)?;
			return Ok(Weight::from_parts(0, 0));
		}

		let pallet_id =
			ModuleId::from_bytes(&request.to).map_err(|err| Error::Custom(err.to_string()))?;

		match pallet_id {
			id if id == ModuleId::Pallet(pallet_bandwidth::pallet::PALLET_BANDWIDTH) =>
				pallet_bandwidth::Pallet::<Runtime>::default().on_accept(request),
			pallet_hyper_fungible_token::PALLET_ID =>
				pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request),
			_ => Err(anyhow!("Destination module not found")),
		}
	}

	fn on_timeout(&self, timeout: Request) -> Result<Weight, anyhow::Error> {
		// Permanently reject Post-request timeouts whose originating module is a
		// deprecated TokenGateway deployment, before any other handling runs. Only
		// Post requests are subject to this — Get requests and Response timeouts
		// are untouched.
		if let Request::Post(post) = &timeout {
			if is_deprecated_token_gateway(&post.from) {
				return Err(anyhow!(
					"rejecting Post-request timeout from deprecated TokenGateway address {:?}",
					post.from,
				));
			}
		}

		let (from, source) = match &timeout {
			Request::Post(post) => (&post.from, post.source.clone()),
			Request::Get(get) => (&get.from, get.source.clone()),
		};

		if source != HostStateMachine::get() {
			return Ok(Weight::from_parts(0, 0));
		}

		let pallet_id = ModuleId::from_bytes(from).map_err(|err| Error::Custom(err.to_string()))?;
		match pallet_id {
			pallet_hyper_fungible_token::PALLET_ID =>
				pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_timeout(timeout),
			_ => Ok(Weight::from_parts(300_000_000, 0)),
		}
	}

		// itself doesn't need bandwidth. With the flag on the gate is a

					"bandwidth gate: {err} (source={:?}, from={:x?})",
					request.source,
					request.from
				)
			})?;
		}

		if request.dest != HostStateMachine::get() {
			Ismp::dispatch_request(
				Request::Post(request),
				FeeMetadata::<Runtime> { payer: [0u8; 32].into(), fee: Default::default() },
