### Title
Unauthenticated exposure of LOOP plugin metrics and pprof debug endpoints - (File: core/web/router.go)

### Summary
The `loopRoutes` handler group, which exposes Prometheus service discovery, plugin metrics, and Go `pprof` debug endpoints for Chainlink LOOP plugins, is registered directly on the top-level `api` router group without any authentication middleware, making it reachable by any unauthenticated client — directly analogous to the GLPI SCCM plugin's publicly accessible, read-only configuration page (CVE-2021-39190).

### Finding Description
In `NewRouter`, the `api` group is created with only rate limiting and session middleware — no authentication is attached at this level: [1](#0-0) 

Compare this to every other route group in the same function (`debugRoutes`, `sessionRoutes`, `v2Routes`), which explicitly wraps their routes with `auth.Authenticate(...)`: [2](#0-1) [3](#0-2) [4](#0-3) 

`loopRoutes`, however, is invoked as `loopRoutes(app, api)` and registers its handlers directly on the unauthenticated `api` group: [5](#0-4) 

This exposes:
- `GET /discovery` — dumps Prometheus service-discovery target groups, including the node's internal hostname, exposed metrics port, and the names of all registered LOOP plugins, via `discoveryHandler`. [6](#0-5) 
- `GET /plugins/:name/metrics` — proxies and returns the raw Prometheus metrics of any named internal LOOP plugin. [7](#0-6) 
- `GET /plugins/:name/debug/pprof/*profile` and `POST /plugins/:name/debug/pprof/symbol` — proxy full Go `pprof` debug data (heap, goroutine, CPU profile, trace, symbol resolution) of the internal plugin process to the caller. [8](#0-7) 

These handlers were clearly intended to be internal-only (the code comments even say "this endpoint is internal btw the node and plugin"), yet they are mounted with no `auth.Authenticate` wrapper, unlike the near-identical `/debug/pprof/*` routes under `metricRoutes`, which are correctly nested inside the authenticated `authv2` group. [9](#0-8) [10](#0-9) 

### Impact Explanation
An unauthenticated remote client can read Prometheus metrics and full `pprof` profiling/debug data (heap dumps, goroutine stacks, CPU profiles) of internal LOOP plugin processes, and enumerate plugin names/topology via `/discovery`. This is an information-disclosure vulnerability that can leak internal architecture, running goroutine/stack details, and potentially sensitive in-memory data captured in heap/goroutine dumps — without any credential, mirroring the read-only unauthenticated configuration exposure in the reference CVE.

### Likelihood Explanation
High: these routes require no authentication token, session, or role check whatsoever — a plain unauthenticated HTTP GET/POST to the node's exposed web port reaches the handler directly, and the routes are always registered as part of `loopRoutes(app, api)` in `NewRouter`.

### Recommendation
Wrap the `loopRoutes` group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` (or move it inside the existing `authv2` group alongside `metricRoutes`) so that `/discovery`, `/plugins/:name/metrics`, and `/plugins/:name/debug/pprof/*` all require a valid session/API token before being served, consistent with the rest of the debug/pprof surface in the router.

### Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered (e.g. a Solana/EVM LOOPP relayer) and the web server listening on its default port (e.g. 6688).
2. Without any authentication (no cookie, no API token), issue:
   - `curl http://<node>:6688/discovery` — returns JSON with the plugin names and node hostname/port for Prometheus scraping.
   - `curl http://<node>:6688/plugins/<plugin-name>/metrics` — returns the raw internal plugin's Prometheus metrics.
   - `curl http://<node>:6688/plugins/<plugin-name>/debug/pprof/heap` — returns a full heap profile of the internal plugin process.
3. All three requests succeed with `200 OK` and return the internal diagnostic data with zero authentication, confirming the unauthenticated read-only exposure.

func sessionRoutes(app chainlink.Application, r *gin.RouterGroup) {
	config := app.GetConfig()
	rl := config.WebServer().RateLimit()
	unauth := r.Group("/", rateLimiter(
		rl.UnauthenticatedPeriod(),
		rl.Unauthenticated(),
	))
	sc := NewSessionsController(app)
	unauth.POST("/sessions", sc.Create)
	auth := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
	auth.DELETE("/sessions", sc.Destroy)
}

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

// pluginMetricHandlers routes from endpoints published in service discovery to the backing LOOP endpoint
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
