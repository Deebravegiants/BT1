### No vulnerability found for this question.

**Reasoning:** `IntentSignerNEP413` is instantiated and used entirely by the integrator/user themselves — they supply both `signMessageFn` (their own signing callback) and the `signer_id` argument to `signIntent`; there is no path where an unprivileged counterparty controls `signMessageFn` while a victim's `signIntent` call embeds `signer_id: 'victim.near'`. The scenario described requires the calling application itself to misuse its own signer object, which is outside the attacker model (an ordinary user attacking their own integration, not a third party).

More importantly, even if a mismatched `signer_id`/`public_key` payload were produced, the actual authorization check happens on-chain: the `intents.near` contract verifies that the `public_key` used for the NEP-413 signature is actually associated with the named `signer_id` account (either as its implicit key or a registered access key) before executing any intent [1](#0-0) . The SDK code shown only constructs and signs a payload locally via `signRaw`/`hashNEP413Message` [2](#0-1) ; it does not perform or bypass any on-chain authorization. A payload whose `signer_id` doesn't match the actual owner of the signing key would simply be rejected by the intents contract's own signature verification — this is exactly the class of guard the audit rules instruct to check for and defer to ("the intents contract's own signature and nonce verification already prevent the divergence").

Since no funds move, no intent executes, and no on-chain effect occurs without the contract independently validating signer/key correspondence, there is no reachable Critical/High impact through this repository's code.

	async signRaw(input: Nep413RawPayload): Promise<MultiPayloadNep413> {
		const nep413Payload: NEP413Payload = {
			message: input.payload.message,
			nonce: Array.from(base64.decode(input.payload.nonce)),
			recipient: input.payload.recipient,
			callback_url: input.payload.callbackUrl,
		};

		const nep413Hash = await hashNEP413Message(nep413Payload);

		const { publicKey, signature } = await this.signMessageFn(
			nep413Payload,
			nep413Hash,
		);

		const signatureFormatted = signature.startsWith("ed25519:")
			? signature
			: `ed25519:${base58.encode(base64.decode(signature))}`;

		return {
			standard: "nep413",
			payload: input.payload,
			public_key: publicKey,
			signature: signatureFormatted,
		};
	}

	/** Builds payload from IntentPayload and signs it via signRaw() */
	async signIntent(intent: IntentPayload): Promise<MultiPayloadNep413> {
		return this.signRaw({
			payload: {
				message: JSON.stringify({
					deadline: intent.deadline,
					intents: intent.intents,
					signer_id: intent.signer_id ?? this.accountId,
				}),
				nonce: intent.nonce,
				recipient: intent.verifying_contract,
			},
		});
	}
