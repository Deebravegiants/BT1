### Title
Content-Moderation Bypass: `is_deprecated_token_gateway` Rejection Guard Present in Nexus Runtime's `ProxyModule` but Missing in Gargantua Runtime's `ProxyModule` - (File: `parachain/runtimes/gargantua/src/ismp.rs`)

### Summary
The `nexus` runtime's ISMP `ProxyModule::on_accept` and `on_timeout` were hardened to permanently reject any `PostRequest` (or its timeout) originating from a deprecated `TokenGateway` deployment via an `is_deprecated_token_gateway(&request.from)` check. The `gargantua` runtime implements a structurally identical `ProxyModule` with the same bandwidth-gate and destination-forwarding logic, but the deprecated-gateway rejection check was never added to it — exactly the pattern in the reported FastChat CVE, where a moderation fix (`add_text`) was applied to one handler file (`gradio_block_arena_named.py`) but missed in sibling files implementing the same logic.

### Finding Description
`parachain/runtimes/nexus/src/ismp.rs` guards both entry points that route messages to `pallet_hyper_fungible_token`: [1](#0-0) [2](#0-1) 

The equivalent `gargantua` runtime's `ProxyModule::on_accept` and `on_timeout` implement the same dispatch/bandwidth/forwarding flow to `pallet_hyper_fungible_token`, but contain no analogous `is_deprecated_token_gateway` check anywhere in `on_accept`, `on_response`, or `on_timeout`: [3](#0-2) 

Both modules are reachable the same way: an unprivileged relayer submits a `PostRequest` proof (via `handle`/`handle_unsigned` in pallet-ismp), which after consensus/state verification is dispatched to `IsmpModule::on_accept`, routed by `ModuleId` to `pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request)` on both chains: [4](#0-3) [5](#0-4) 

Because the `gargantua` `ProxyModule` never checks `request.from` against the deprecated `TokenGateway` list, a message crafted (or forwarded/relayed) from a deprecated/decommissioned `TokenGateway` address that would be rejected on `nexus` is instead accepted, unpacked by `ModuleId`, and delivered straight to `pallet_hyper_fungible_token::on_accept` on `gargantua`.

### Impact Explanation
`pallet_hyper_fungible_token::on_accept` performs mint/burn/transfer logic keyed on the sending module's identity encoded in `request.from`/`request.to`. The deprecated-gateway guard exists specifically to stop such a sender from being trusted by the token pallet (e.g. after a migration, key compromise, or known-vulnerable version of `TokenGateway` was retired). Its absence on `gargantua` allows a forged/legacy message path to reach the token pallet's privileged callback unauthorized, which can result in unauthorized app action (unbacked mint or accounting corruption) via `pallet_hyper_fungible_token`, satisfying the "unauthorized app action" / "forged message delivery" acceptance criteria.

### Likelihood Explanation
Any relayer can submit a `PostRequest` whose `from` field is the deprecated `TokenGateway` address; the request will pass identical consensus/state-proof verification on `gargantua` as it would on `nexus` since both runtimes share the same underlying pallet-ismp/`ConsensusClients` verification path — only the moderation guard in the `ProxyModule` differs. No privileged role is required; a single crafted incoming message reaching `on_accept` is sufficient to trigger the bypass.

### Recommendation
Add the same `is_deprecated_token_gateway(&request.from)` rejection check (and the equivalent check in `on_timeout`) to `gargantua/src/ismp.rs`'s `ProxyModule::on_accept`/`on_timeout`, mirroring `nexus/src/ismp.rs` exactly, and add a shared helper/test asserting parity between all runtime `ProxyModule` implementations so future security fixes cannot be applied to only one runtime.

### Proof of Concept
1. On `gargantua`, construct a `PostRequest` with `from` set to a known deprecated `TokenGateway` contract address and `to` set to `pallet_hyper_fungible_token::PALLET_ID`.
2. Submit it via `pallet_ismp`'s `handle`/`handle_unsigned` extrinsic with a valid consensus/state proof for the (attacker-controlled or otherwise legitimate) source chain.
3. Observe that `ProxyModule::on_accept` in `parachain/runtimes/gargantua/src/ismp.rs` proceeds past the bandwidth gate straight to `pallet_hyper_fungible_token::on_accept` with no rejection, whereas submitting the identical message on `nexus` is rejected at `is_deprecated_token_gateway` in `parachain/runtimes/nexus/src/ismp.rs`, lines 367-373.

impl IsmpModule for ProxyModule {
	fn on_accept(&self, request: PostRequest) -> Result<Weight, anyhow::Error> {
		// Bandwidth gate. Always-enforce unless the `no-bandwidth` flag
		// is set; skipped for purchase messages so the recharge flow
		// itself doesn't need bandwidth. With the flag on the gate is a
		// no-op and this block is compiled out entirely.
		#[cfg(not(feature = "no-bandwidth"))]
		if !pallet_bandwidth::Pallet::<Runtime>::is_purchase_message(&request) {
			let bytes = ismp::abi::encode_post_request(&request).len() as u32;
			<pallet_bandwidth::Pallet<Runtime> as pallet_bandwidth::BandwidthGate>::try_consume(
				&request.source,
				&request.from,
				bytes,
			)
			.map_err(|err| {
				anyhow!(
					"bandwidth gate: {err} (source={:?}, from={:x?})",
					request.source,
					request.from
				)
			})?;
		}

		if request.dest != HostStateMachine::get() {
			Ismp::dispatch_request(
				Request::Post(request),
				FeeMetadata::<Runtime> { payer: [0u8; 32].into(), fee: Default::default() },
			)?;
			return Ok(Weight::from_parts(0, 0));
		}

		let pallet_id =
			ModuleId::from_bytes(&request.to).map_err(|err| Error::Custom(err.to_string()))?;

		match pallet_id {
			pallet_ismp_demo::PALLET_ID =>
				pallet_ismp_demo::IsmpModuleCallback::<Runtime>::default().on_accept(request),

			#[cfg(not(feature = "no-bandwidth"))]
			id if id == ModuleId::Pallet(pallet_bandwidth::pallet::PALLET_BANDWIDTH) =>
				pallet_bandwidth::Pallet::<Runtime>::default().on_accept(request),

			pallet_hyper_fungible_token::PALLET_ID =>
				pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request),

			_ => Err(anyhow!("Destination module not found")),
		}
	}

	fn on_response(&self, response: GetResponse) -> Result<Weight, anyhow::Error> {
		// Bandwidth gate. Mirrors the request path in `on_accept`: the chain
		// and module that produced the response pay for the bytes they
		// deliver. Compiled out when the `no-bandwidth` flag is on.
		if response.dest_chain() != HostStateMachine::get() {
			return Ok(Weight::from_parts(0, 0));
		}

		let dest = &response.get.from;

		let pallet_id = ModuleId::from_bytes(dest).map_err(|err| Error::Custom(err.to_string()))?;

		match pallet_id {
			pallet_ismp_demo::PALLET_ID =>
				pallet_ismp_demo::IsmpModuleCallback::<Runtime>::default().on_response(response),
			_ => Err(anyhow!("Destination module not found")),
		}
	}

	fn on_timeout(&self, timeout: Request) -> Result<Weight, anyhow::Error> {
		let (from, source) = match &timeout {
			Request::Post(post) => (&post.from, post.source.clone()),
			Request::Get(get) => (&get.from, get.source.clone()),
		};

		if source != HostStateMachine::get() {
			return Ok(Weight::from_parts(0, 0));
		}

		let pallet_id = ModuleId::from_bytes(from).map_err(|err| Error::Custom(err.to_string()))?;
		match pallet_id {
			pallet_ismp_demo::PALLET_ID =>
				pallet_ismp_demo::IsmpModuleCallback::<Runtime>::default().on_timeout(timeout),
			pallet_hyper_fungible_token::PALLET_ID =>
				pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_timeout(timeout),
			// instead of returning an error, do nothing. The timeout is for a connected chain.
			_ => Ok(Weight::from_parts(0, 0)),
		}
	}
}
