### Title
Unauthenticated "magic" QR-code action can permanently freeze the Orb's WiFi/signup loop with no recovery override - ([File: src/plans/qr_scan/operator.rs])

### Summary
The Orb accepts an unauthenticated, unsigned QR-code literal (`magic_action:reset_wifi_credentials`) as a privileged "operator" command that resets WiFi and forces the orb into a network-reconnection loop that has no timeout and no override mechanism, exactly mirroring the rogue-plugin freeze pattern in the referenced report: an untrusted/unauthenticated input can put a core, gating component into a state that never resolves and that has no "force" escape hatch, halting all subsequent Orb operations (signups) for every other user.

### Finding Description
Operator QR-code data is parsed by first trying to parse it as a normal, backend-validated user code, and — if that fails — falling back to a bare regex match against a "magic" action string with **no cryptographic signature, no backend validation, and no operator authentication whatsoever**: [1](#0-0) 

Crucially, the magic action is executed *before* any backend verification of the "operator" QR code takes place: `handle_magic_operator_qr_code` runs immediately after the raw QR scan/parse, ahead of `verify_operator_qr_code`: [2](#0-1) [3](#0-2) 

When the `MagicResetWifi` variant is matched, the Orb calls `reset_wifi_and_ensure_network`, which resets the WiFi state and then blocks inside `wifi::Plan::ensure_network_connection`: [4](#0-3) [5](#0-4) 

`ensure_network_connection` runs an unbounded `loop` that, once disconnected, calls `qr_scan::Plan::new(None, false).run(orb)` — a QR scan with `timeout = None`, i.e. it blocks **indefinitely** until *some* well-formed WiFi MECARD QR code is presented. There is no fallback, no maximum retry count, and no way to abort or "force" past this state: [6](#0-5) 

This is structurally identical to the reported vulnerability class: a piece of attacker-controllable/untrusted input (the rogue plugin in the original report; here, an unauthenticated magic QR code) drives a subsystem into a state gated by a condition (`deactivated()` in the original; `network::Status::Connected{has_internet:true}` here) that the attacker fully controls and can simply never satisfy, and there is no privileged "force" path to recover — exactly the missing capability the original report's fix (`force` parameter on `removePlugin`) was meant to add.

### Impact Explanation
Because `scan_initial_qr_codes`/`handle_magic_operator_qr_code` are invoked from the top-level `MasterPlan::run` loop before any user signup can proceed, an unprivileged individual (in self-serve deployments there is no attendant operator validating what is shown to the camera) can print and present a single throwaway QR code to:
1. Force the orb to disconnect from its legitimate, working WiFi network (`network::reset()`).
2. Trap the orb in an unbounded loop waiting for a new WiFi-credentials QR code that the attacker never needs to supply.

Since this loop has no timeout and no bypass, the Orb is left permanently offline/unresponsive — unable to serve any legitimate user's signup — until a physical operator manually intervenes with correct WiFi credentials. This is a full denial-of-service of the Orb for all subsequent users, directly analogous to the "freeze of funds for all stakers" impact called out in the source report — here it is "freeze of service for all future signups" caused by a single unauthenticated action.

### Likelihood Explanation
Likelihood is high: no signature, secret, or backend round-trip is required to trigger the magic action — only knowledge of a publicly documented literal string (`magic_action:reset_wifi_credentials`) that must be printed as a QR code and shown to the camera during the operator QR-scan phase, which in self-serve mode is exposed to any member of the public interacting with the Orb.

### Recommendation
- Require the same backend-authenticated/signed validation path for magic operator actions as is used for normal operator/user QR codes, instead of accepting a bare, unauthenticated regex match.
- Bound `ensure_network_connection`'s WiFi re-scan loop with a maximum timeout/retry count, after which the Orb restores its previous working network configuration (or otherwise fails safe) rather than blocking forever.
- Add an operational "force"/abort path (analogous to the `force` parameter recommended in the source report) that lets the system recover from an indefinitely blocked WiFi-reset state without requiring the exact attacker-controlled condition (a new valid WiFi QR) to be satisfied.

### Proof of Concept
1. Deploy/operate the Orb in self-serve mode.
2. Print a QR code encoding the literal string `magic_action:reset_wifi_credentials`.
3. Present it to the Orb's camera during the operator QR-scan phase (`scan_initial_qr_codes`/`scan_operator_qr_code`).
4. Observe `Data::try_parse` match `MagicResetWifi` via `MAGIC_QR_CODE` with no authentication (`src/plans/qr_scan/operator.rs`), triggering `handle_magic_operator_qr_code` → `reset_wifi_and_ensure_network` → `network::reset()` followed by `wifi::Plan::ensure_network_connection`.
5. Do not present any further QR code (or present none matching the WiFi MECARD schema). The Orb remains stuck inside the unbounded loop in `ensure_network_connection` (`src/plans/wifi/mod.rs`), unable to reconnect to a network or serve any subsequent signup, with no timeout or override to recover.

    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

impl Plan {
    /// Checks whether connected to a WiFi network, if not connected scan the
    /// hotspot QR code.
    pub async fn ensure_network_connection(&self, orb: &mut Orb) -> Result<()> {
        let mut in_progress_start = Instant::now();
        let mut has_requested_qr_code = false;
        let success = |orb: &mut Orb, has_requested_qr_code| {
            if has_requested_qr_code {
                orb.ui.network_connection_success();
            }
            tracing::debug!("Network is connected");
            Ok::<(), Error>(())
        };
        loop {
            match network::status().await? {
                network::Status::Connected { has_internet: true } => {
                    success(orb, has_requested_qr_code)?;
                    break;
                }
                network::Status::InProgress
                | network::Status::Connected { has_internet: false }
                    if in_progress_start.elapsed() < NETWORK_CONNECTION_TIMEOUT =>
                {
                    tracing::debug!("Network connection in progress");
                    sleep(Duration::from_millis(250)).await;
                }
                network::Status::Connected { has_internet: false }
                | network::Status::Disconnected
                | network::Status::InProgress => {
                    tracing::debug!("Network is disconnected, or has no connection to the backend");
                    if has_requested_qr_code {
                        orb.ui.qr_scan_fail(QrScanSchema::Wifi);
                    }
                    has_requested_qr_code = true;
                    match qr_scan::Plan::new(None, false).run(orb).await? {
                        Ok((credentials, _)) => {
                            tracing::info!(
                                "Read WiFi credentials from hotspot QR: {:?}",
                                credentials
                            );
                            network::join(credentials).await?;
                            in_progress_start = Instant::now();
                        }
                        Err(qr_scan::ScanError::Invalid) => {
                            orb.ui.qr_scan_unexpected(
                                QrScanSchema::Wifi,
                                QrScanUnexpectedReason::WrongFormat,
                            );
                        }
                        Err(qr_scan::ScanError::Timeout) => {}
                    }
                    orb.reset_rgb_camera().await?;
                }
            }
        }
        Ok(())
    }
}
