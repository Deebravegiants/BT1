Audit Report

## Title
Unbounded `activeRequests` map in confidential-relay gateway handler enables unprivileged DoS via unbounded fan-out - (File: `core/services/gateway/handlers/confidentialrelay/handler.go`)

## Summary
The confidential-relay gateway handler's `HandleJSONRPCUserMessage` accepts any JSON-RPC request from an unprivileged client and inserts it into an in-memory `activeRequests` map with no maximum size limit and no per-client/global rate limiting on the ingestion path, unlike the sibling `RequestCache` type (`core/services/gateway/handlers/common/requestcache.go`) and the v2 HTTP capability handler, both of which enforce explicit caps/limiters on client-facing paths.

## Finding Description
`newActiveRequest` at `core/services/gateway/handlers/confidentialrelay/handler.go:414-430` only rejects a request if its ID already exists in the map; it never checks the map's total size before inserting. `HandleJSONRPCUserMessage` (`core/services/gateway/handlers/confidentialrelay/handler.go:394-411`), the entry point for this path, only validates that `req.ID` is non-empty and under 200 characters — no authentication or size/rate check is applied on this path. The handler defines `globalNodeRateLimiter` and `perNodeRateLimiters`, but these are consulted only inside `HandleNodeMessage` (node → gateway traffic, lines 442-453), not on the client-facing ingestion path.

I traced the call path from the outer gateway dispatcher: `gateway.ProcessRequest` (`core/services/gateway/gateway.go:221-295`) decodes the incoming raw request, validates only ID length (≤200 chars) and decodability, resolves the handler by service name/DON ID, and then directly calls `h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)` with no rate limiting or size gating applied at the gateway layer before dispatch. This confirms there is no upstream mitigation outside the file inspected — the claim's caveat about a possible external limiter does not hold; `ProcessRequest` is the only path into this handler and it performs no rate limiting.

Each accepted request also triggers `fanOutToNodes` (lines 686-708), which sends the request to every member of `donConfig.Members`, so unbounded acceptance also unboundedly amplifies outbound load to the DON. Each `activeRequest` stays alive until quorum, grace-window expiry, or `removeExpiredRequests` sweeps it after `requestTimeout` (default 30s, lines 337-370), so sustained submission of distinct-ID requests grows the map without bound for the duration of the timeout window.

## Impact Explanation
This is a resource-exhaustion / availability issue: an unauthenticated, unprivileged client reachable at the gateway's user-facing JSON-RPC endpoint can grow `activeRequests` (each holding a request payload, mutex, and growing `responses` map) without bound for up to `requestTimeout` per wave, consuming gateway memory/CPU, and forcing a full fan-out send to every DON node per bogus request — degrading service for legitimate relay requests and burdening the workflow DON with pointless traffic. This maps to a gateway-level denial-of-service impact category.

## Likelihood Explanation
Likelihood is realistic: any client able to reach the gateway's `ProcessRequest`/user-message endpoint (this is the standard external ingress point, confirmed to have no rate limiter or cap gating this handler) can trigger this by sending a rapid burst of requests with unique, valid IDs — no special credentials, timing, or race conditions are required, and the attack is trivially repeatable.

## Recommendation
- Add an explicit maximum size to `activeRequests` (mirroring `RequestCache.maxCacheSize` in `core/services/gateway/handlers/common/requestcache.go:46-66`) and reject new requests once the cap is reached.
- Apply a rate limiter (global and/or per-client/per-sender) on the `HandleJSONRPCUserMessage` ingestion path, consistent with the pattern already used for `HandleNodeMessage` and the v2 HTTP handler's `userRateLimiter`.
- Consider bounding `fanOutToNodes` amplification by rejecting requests early once resource limits are hit, instead of always fanning out first.

## Proof of Concept
1. An unprivileged client connects to the gateway's user-facing endpoint that routes (via `gateway.ProcessRequest`) to the confidential-relay handler for a known DON/service name.
2. The client issues a rapid burst of JSON-RPC requests (method `MethodSecretsGet` or `MethodCapabilityExec`), each with a distinct, valid `req.ID` (any string ≤200 chars) and arbitrary/garbage params.
3. Each request passes the ID-uniqueness check in `newActiveRequest` and is added to `activeRequests`, then fanned out to every DON member via `fanOutToNodes`.
4. Because there is no cap or rate limit on this path (verified by tracing `gateway.ProcessRequest` → `HandleJSONRPCUserMessage` → `newActiveRequest`), the attacker can submit requests faster than the 30s timeout sweep retires old entries, growing the map unboundedly and repeatedly fanning out to the entire DON.
5. A Go unit test can instantiate the handler with a mock `DON`/`clockwork.FakeClock`, call `HandleJSONRPCUserMessage` in a loop with unique IDs without advancing the clock, and assert `len(h.activeRequests)` grows without bound and that `SendToNode` is invoked once per node per call. func (h *handler) HandleJSONRPCUserMessage(ctx context.Context, req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) error {
	if req.ID == "" {
		return errors.New("request ID cannot be empty")
	}
	if len(req.ID) > 200 {
		return errors.New("request ID is too long: " + strconv.Itoa(len(req.ID)) + ". max is 200 characters")
	}

	labels := h.extractRequestLabels(req)
	l := h.requestLogger(req, labels)
	l.Debugw("handling confidential relay request", "nodes", len(h.donConfig.Members), "f", h.donConfig.F)

	ar, err := h.newActiveRequest(req, labels, callback)
	if err != nil {
		return err
	}

	return h.fanOutToNodes(ctx, l, ar)
}

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], labels requestLabels, callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID, "executionID", labels.ExecutionID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		labels:    labels,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

func (h *handler) fanOutToNodes(ctx context.Context, l logger.Logger, ar *activeRequest) error {
	var (
		group      errgroup.Group
		nodeErrors atomic.Uint32
	)

	// Each send is bounded independently. A node whose websocket accepts no writes blocks
	// until its context is cancelled, and because the caller only reads the response callback
	// after this function returns, an unbounded send would hold the request open until the
	// client gives up, discarding a bundle that already reached quorum.
	sendCtx, cancel := context.WithTimeout(ctx, h.nodeSendTimeout)
	defer cancel()

	for _, node := range h.donConfig.Members {
		group.Go(func() error {
			err := h.don.SendToNode(sendCtx, node.Address, &ar.req)
			if err != nil {
				nodeErrors.Add(1)
				l.Errorw("error sending request to node", "node", node.Address, "error", err)
			}
			return nil
		})
	}

func (c *requestCache[T]) NewRequest(lggr logger.Logger, request *api.Message, callback handlers.Callback, responseData *T) error {
	if request == nil {
		return errors.New("request is nil")
	}
	if responseData == nil {
		return errors.New("responseData is nil")
	}
	key := globalID{request.Body.Sender, request.Body.MessageID}
	c.mu.Lock()
	defer c.mu.Unlock()
	_, ok := c.cache[key]
	if ok {
		return errors.New("request already exists")
	}
	if len(c.cache) >= int(c.maxCacheSize) {
		return errors.New("request cache is full")
	}

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	isLegacyRequest := false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonID == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonID
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}

	response, err := callback.Wait(ctx)
	duration := time.Since(startTime)
	if err != nil {
		response := api.RequestTimeoutError
		g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.String(), duration)
		g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.String())
		return newError(jsonRequest.ID, response, "handler timeout: "+err.Error())
	}
	g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.ErrorCode.String(), duration)
	g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.ErrorCode.String())

	g.lggr.Debugw("received response from handler", "handler", handlerKey, "response", response, "requestID", jsonRequest.ID)
	promRequest.WithLabelValues(response.ErrorCode.String()).Inc()
	return response.RawResponse, api.ToHTTPErrorCode(response.ErrorCode)
}
