The gas-griefing/DoS report is about ETH transfers to multiple recipients inside a `for` loop, where one malicious `receive()` can grief the whole batch payout. Alt.fun's in-scope contracts have no analogous shape.

All value transfers in the scoped contracts are ERC20 (`safeTransfer`/`safeTransferFrom`) — there is no raw `.call{value: ...}` or `SafeTransferLib.safeTransferETH` usage anywhere in `packages/contracts/src`. `FeeVault.claim()`, `FeeVault.claimProtocol()`, and `FeeVault.sweepDonations()` each move USDC to exactly one recipient per call (`msg.sender` or `feeTo`) [1](#0-0) , and `sweepDonations` similarly pays a single address [2](#0-1) . Graduation's fund movements (`Router.graduate`, `Bonding._sweepLTToOwner`, `_routerDepositAndDispose`, `LPLock.recordLock`) are also each single-recipient ERC20 transfers, not loops over an attacker-controlled batch of recipients [3](#0-2) [4](#0-3) [5](#0-4) .

Since there is no batch/loop distribution to multiple untrusted recipients in a single transaction, and no native ETH transfer path at all in the reachable surface (Zap, Bonding, FeeVault, Pair), there's no code path where one recipient's malicious fallback/`receive()` can DoS payouts to other, unrelated users — the specific mechanism the report describes.

    function recordLock(
        address token,
        address lpPair,
        uint256 amount
    ) external {
        LPLockStorage storage $ = _s();
        if (!$.isLocker[msg.sender]) revert NotAuthorized();
        if (lpPair == address(0)) revert ZeroAddress();
        if (amount == 0) revert ZeroAmount();
        // `lockedAt` is the one-shot sentinel: it is always set to a non-zero
        // timestamp on the first lock, so the guard holds for any `amount`.
        if ($.locks[token].lockedAt != 0) revert AlreadyLocked();
        if (IERC20(lpPair).balanceOf(address(this)) < amount) revert InsufficientLPBalance();
        $.locks[token] = LockInfo({lpPair: lpPair, amount: amount, lockedAt: block.timestamp});
        emit LPLocked(token, lpPair, amount);
    }
