### Title
`payRelayFees` sends the wallet owner's relay fee to an attacker-chosen `circomData.relay` because `EMPORIUM_SIGNATURE_TYPEHASH` never binds `relay` - ([File: contracts/external-actions/emporium/upgradeable/EmporiumUpgradeable.sol])

### Summary
`verifyWallet` recovers the `EmporiumStack` signer over `EMPORIUM_SIGNATURE_TYPEHASH(emporiumMessage, opsHash, maxFee, deadline)`, which never includes `circomData.relay`. `payRelayFees`/`payRelay` nonetheless pay `circomData.relay` out of the signer's wallet funds whenever `signerAddress != address(0)`, so an attacker who reuses a harvested, still-valid `(v,r,s,signerAddress,ops,maxFee,deadline)` tuple with their own `relay` address will get the flat fee routed to themselves, provided they win the race for the still-unused `emporiumMessage`.

### Finding Description
The equality that must hold is: **relay address paid in `payRelay` == relay address the wallet owner intended when signing**. This is broken because `relay` is outside the signed digest.

Code path:
- Signature verification: [1](#0-0)  defines `EMPORIUM_SIGNATURE_TYPEHASH` covering only `message, ops, maxFee, deadline` — no `relay` field.
- `verifyWallet` hashes exactly those fields via `_hashTypedDataV4(...)` and recovers the signer, checking `usedMessages[circomData.emporiumMessage]` and marking it used: [2](#0-1) . `circomData.relay` is never referenced here.
- `runAction` calls `verifyWallet(stack, circomData)` and then `payRelayFees(circomData, stack.signerAddress, deltaAmountChanges)`: [3](#0-2) .
- `payRelayFees` computes `relayFee` (the flat fee when `signerAddress != address(0)`) and calls `payRelay(circomData.relay, signerAddress, relayFee, erc20TokenAddress)`: [4](#0-3) .
- `payRelay` → `sendToRelayFromWallet` invokes `IHinkalWallet(signerAddress).doSendToRelay(relay, relayFee, feeToken)`, moving the wallet owner's funds to whatever `relay` address is supplied in the calling transaction's `circomData`, not the signer's chosen relay: [5](#0-4) .

Root cause: the EIP-712 typed digest for `EmporiumStack` omits `relay`, so any party holding a copy of `(v,r,s,signerAddress,ops,maxFee,deadline)` — obtainable by observing it in the public mempool inside another party's pending `Hinkal.transact` calldata — can re-embed those exact bytes as `externalActionData.externalActionMetadata` in their own `transact` call, substituting their own `circomData.relay`. Because the signature check only validates the four typehash fields, it still passes.

The remaining gate is the `usedMessages[circomData.emporiumMessage]` single-use check, which is a race: whichever transaction lands first consumes the `emporiumMessage`. Since `emporiumMessage` is a plain public value passed through to the circuit as `input[index++] = circomData.emporiumMessage` (`formInputEmporiumMin`/`formBasicInput` in `CircomDataBuilder.sol`) and also folded into `getSignedMessageHash` alongside the attacker's own `calldataHash`, nullifiers and commitments, the attacker only needs to reuse the same numeric value in their own proof's public inputs — it is not cryptographically bound to the original submitter's identity or witness, so an attacker generating a valid proof over their own UTXOs/commitments can freely set this public input to match the harvested value. This lets the attacker's transaction front-run the original and consume the `emporiumMessage`, executing the *victim's signed `ops`* (harmless/unchanged) but redirecting the *relay fee payment* to an address the signer never authorized.

None of the existing guards catch this: `verifyProof`/circuit constraints validate the attacker's own balance/nullifier arithmetic, not the relay address; `performHinkalChecks`/`dimensionsCheck` don't constrain `relay` against the `EmporiumStack` signature; `onlyAllowedRecipient` only checks the external action registration, not fee routing.

### Impact Explanation
The wallet owner's relay fee (the flat fee taken out of `IHinkalWallet.doSendToRelay`) is redirected from the intended/whitelisted relay to an attacker-controlled address. This is theft of protocol/relay fee funds from the signer's Hinkal wallet, matching the **High** severity category ("theft ... of protocol/relay fees" / "executing calls or moving assets a wallet owner ... never authorised"). It is repeatable for every `EmporiumStack` transaction the attacker can observe in the mempool before it is mined, as long as the attacker can win the race to be included first.

### Likelihood Explanation
Preconditions are realistic: any public mempool observer can see a pending `Hinkal.transact` with `externalActionData.externalActionMetadata` decoding to an `EmporiumStack` for the Emporium action, since this is calldata, not a private input. Winning the front-run race only requires a higher gas bid, a standard MEV technique, no privileged role or victim key required. Attacker cost is limited to their own proof generation (self-funded UTXOs) and gas. This is repeatable per victim `EmporiumStack` submission.

### Recommendation
Include `relay` (and ideally `feeStructure`) inside the EIP-712 struct that `EmporiumStack` signs, e.g. extend `EMPORIUM_SIGNATURE_TYPEHASH` to `EmporiumSignature(uint256 message,EmporiumOperation[] ops,uint256 maxFee,uint256 deadline,address relay)` and pass `circomData.relay` into the hash computed in `verifyWallet`. This binds the fee recipient to the signer's explicit intent and makes any relay substitution invalidate the signature.

### Proof of Concept
Hardhat fork test:
1. Deploy `EmporiumUpgradeable` behind proxy, set up a Hinkal wallet for `signer`, fund it with the fee token.
2. `signer` builds an `EmporiumStack{ops: [...], maxFee, deadline}` and signs it under `EMPORIUM_SIGNATURE_TYPEHASH` with `relayIntended` conceptually chosen off-chain (not encoded).
3. Craft `circomData` A: `relay = relayIntended`, embed the signed stack bytes, generate a valid proof for `signer`'s own transaction; do NOT broadcast/mine it yet (simulate "in mempool").
4. Attacker copies the exact `(v,r,s,signerAddress,ops,maxFee,deadline)` bytes, builds their own `circomData` B with `relay = attackerAddress`, same `emporiumMessage`, and a self-generated valid proof over attacker's own UTXOs; submits and mines it first.
5. Assert: `payRelay` sends `relayFee` to `attackerAddress`, not `relayIntended` — i.e., assert `IERC20(feeToken).balanceOf(attackerAddress)` increased by `flatFee` while `relayIntended`'s balance is unchanged.
6. Assert original transaction A now reverts with `UsedMessage()` when finally mined, proving the front-run consumed the signer's `emporiumMessage`.

    function sendToRelayFromWallet(
        address relay,
        address signerAddress,
        uint256 relayFee,
        address feeToken
    ) internal {
        if (relayFee > 0) {
            IHinkalWallet(signerAddress).doSendToRelay(
                relay,
                relayFee,
                feeToken
            );
        }
    }

    function payRelayFees(
        CircomData calldata circomData,
        address signerAddress,
        int256[] calldata deltaAmountChanges
    ) internal {
        FeeStructure calldata feeStructure = circomData.feeStructure;

        bool foundToken = false;

        for (uint256 i = 0; i < circomData.erc20TokenAddresses.length; i++) {
            // tokens deposited into Emporium are not charged
            if (deltaAmountChanges[i] >= 0) {
                continue;
            }

            address erc20TokenAddress = circomData.erc20TokenAddresses[i];
            bool isFeeToken = erc20TokenAddress == feeStructure.feeToken;

            if (isFeeToken) {
                foundToken = true;
            }

            uint256 relayFee = 0;
            uint256 flatFee = isFeeToken ? feeStructure.flatFee : 0;

            if (signerAddress == address(0)) {
                uint256 sumAbs = uint256(-deltaAmountChanges[i]);

                EmporiumStorageVars storage $ = _getEmporiumStorage();
                relayFee = $._hinkalHelper.calculateRelayFee(
                    sumAbs,
                    flatFee,
                    feeStructure.variableRate
                );
            } else {
                relayFee = flatFee;
            }

            payRelay(
                circomData.relay,
                signerAddress,
                relayFee,
                erc20TokenAddress
            );
        }

        if (!foundToken && feeStructure.flatFee != 0) {
            require(
                signerAddress != address(0),
                "Gas Token in Emporium is not found"
            );

            payRelay(
                circomData.relay,
                signerAddress,
                feeStructure.flatFee,
                feeStructure.feeToken
            );
        }
    }

    function payRelay(
        address relay,
        address signerAddress,
        uint256 relayFee,
        address erc20TokenAddress
    ) internal {
        if (relay == address(0) || relayFee == 0) {
            return;
        }

        if (signerAddress == address(0)) {
            sendToRelay(relay, relayFee, erc20TokenAddress);
        } else {
            sendToRelayFromWallet(
                relay,
                signerAddress,
                relayFee,
                erc20TokenAddress
            );
        }
    }

    function verifyWallet(
        EmporiumStack memory stack,
        CircomData calldata circomData
    ) internal {
        EmporiumStorageVars storage $ = _getEmporiumStorage();

        if ($.usedMessages[circomData.emporiumMessage]) {
            revert UsedMessage();
        }

        $.usedMessages[circomData.emporiumMessage] = true;

        if (stack.signerAddress == address(0)) {
            return;
        }

        bytes32 hashedMessage = _hashTypedDataV4(
            keccak256(
                abi.encode(
                    EMPORIUM_SIGNATURE_TYPEHASH,
                    circomData.emporiumMessage,
                    _hashEmporiumOps(stack.ops),
                    stack.maxFee,
                    stack.deadline
                )
            )
        );

        (address recoveredAddress, ECDSA.RecoverError err) = ECDSA.tryRecover(
            hashedMessage,
            stack.v,
            stack.r,
            stack.s
        );
        bool verified = err == ECDSA.RecoverError.NoError &&
            recoveredAddress == stack.signerAddress;
        if (!verified) {
            revert InvalidSignature();
        }

        if (block.timestamp > stack.deadline) {
            revert SignatureExpired();
        }

        if (circomData.feeStructure.flatFee > stack.maxFee) {
            revert FeeExceedsSignedMax();
        }
    }
