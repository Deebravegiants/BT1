I found a concrete analog in `src/plans/qr_scan/operator.rs` and `src/plans/mod.rs`: the "magic" operator QR-code actions (`reset_wifi_credentials`, `reset_mirror_calibration`) are accepted purely based on regex pattern matching, with no authentication or backend authorization check — unlike a normal operator QR-code (which is subsequently validated against the backend via `verify_operator_qr_code`).

### Title
Unauthenticated privileged action execution via magic operator QR-codes - (File: `src/plans/qr_scan/operator.rs`, `src/plans/mod.rs`)

### Summary
`qr_scan::operator::Data::try_parse` recognizes special "magic" QR-code payloads (`magic_action:reset_wifi_credentials`, `magic_action:reset_mirror_calibration`) purely via regex, and `MasterPlan::handle_magic_operator_qr_code` executes the corresponding privileged hardware actions immediately, without ever calling the backend operator-authorization check (`verify_operator_qr_code`/`backend::operator_status::request`) that is otherwise required for every normal operator QR-code. [1](#0-0) [2](#0-1) 

### Finding Description
For a normal operator QR-code, the flow is: parse → `verify_operator_qr_code` (an authenticated backend call using `ORB_TOKEN`/`ORB_ID` that confirms the scanned code belongs to a valid, registered operator) → only then is the code trusted. [3](#0-2) 

However, for the two "magic" variants, `handle_magic_operator_qr_code` branches before that verification step and directly invokes `self.reset_mirror_calibration(orb)` or `self.reset_wifi_and_ensure_network(orb)`: [2](#0-1) 

These are reached from `scan_initial_qr_codes`/`scan_remaining_qr_codes`, which call `handle_magic_operator_qr_code` right after `scan_operator_qr_code`, before any call to `verify_operator_qr_code`: [4](#0-3) [5](#0-4) 

The only "authorization" is a regex match on the string content of a QR code shown to the orb's camera: [6](#0-5)  — a piece of paper with `magic_action:reset_wifi_credentials` printed on it is sufficient. This mirrors the reported bug class exactly: a state-mutating, privileged action (here, device reconfiguration rather than token minting) is reachable by anyone with zero credentials, because the code path that should require authorization (the backend operator-status check) is bypassed entirely for this special input class.

### Impact Explanation
- `reset_wifi_credentials` tears down the current network connection and forces the orb into Wi-Fi (re)provisioning mode (`reset_wifi_and_ensure_network` → `network::reset()` then re-scans for Wi-Fi credentials QR), which can be used to disrupt/deny orb operation or, combined with `plans::wifi::Plan::ensure_network_connection` accepting a new hotspot QR, potentially redirect the orb onto an attacker-controlled network. [7](#0-6) [8](#0-7) 
- `reset_mirror_calibration` resets and rewrites the persisted mirror calibration file, degrading biometric capture accuracy/quality for subsequent legitimate signups (an integrity/availability impact on the signup pipeline). [9](#0-8) 

This does not directly leak biometric data or forge a signup, but it is an unauthenticated, unprivileged-user-triggerable action that alters device/network state — a genuine access-control gap in the QR trust boundary, distinct from the intentionally-stripped FOSS fraud checks (`src/plans/fraud_check.rs`) or the build-time-gated `allow-plan-mods`/`skip-user-qr-validation` features, which are excluded by the rules as non-reachable-by-attacker.

### Likelihood Explanation
High: any person able to present a QR code to the orb's camera during the idle/operator-scan phase (i.e., anyone standing in front of the device, no registered operator credentials, no backend token) can trigger this. It requires no special build flags — the magic-QR regex and dispatch are compiled unconditionally into the production code path.

### Recommendation
Require the same backend authorization (`verify_operator_qr_code`) for magic QR-codes as for normal operator codes before executing `reset_mirror_calibration`/`reset_wifi_and_ensure_network`, or otherwise cryptographically sign/verify magic-action payloads so they can't be trivially forged by printing arbitrary text as a QR code.

### Proof of Concept
1. Print/display a QR code containing the literal text `magic_action:reset_wifi_credentials`.
2. Present it to the orb during operator QR-code scanning (`scan_initial_qr_codes`/`scan_remaining_qr_codes`).
3. `qr_scan::operator::Data::try_parse` matches `MAGIC_QR_CODE` regex and returns `Data::MagicResetWifi`. [10](#0-9) 
4. `handle_magic_operator_qr_code` executes `reset_wifi_and_ensure_network` immediately — no backend call, no operator authentication. [11](#0-10) 
5. The orb's network is reset and it enters Wi-Fi re-provisioning, controllable by the same unauthenticated actor who can also present a hotspot-credentials QR code next.

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    /// Checks if `qr_code` is a valid operator QR-code through the backend.
    #[allow(clippy::cast_possible_truncation)]
    async fn verify_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: &qr_scan::user::Data,
        qr_capture_start: Instant,
    ) -> Result<Option<(u64, backend::operator_status::LocationData)>> {
        if qr_code.signup_extension() || self.operator_qr_code_override.is_some() {
            return Ok(Some((0, backend::operator_status::LocationData {
                team_operating_country: "DEV".to_string(),
                session_coordinates: Coordinates { latitude: 0.0f64, longitude: 0.0f64 },
                stationary_location_coordinates: None,
            })));
        }
        let http_start = Instant::now();
        match backend::operator_status::request(qr_code).await {
            Ok(backend::operator_status::Status { valid: true, location_data, reason: _ }) => {
                let location_data = location_data
                    .expect("to always have a result from the backend if valid == true");
                orb.ui.qr_scan_success(QrScanSchema::Operator);
                dd_incr!("main.count.global.distr_code_validated");
                tracing::info!("Operator QR-code validated: {qr_code:?}");
                dd_timing!("main.time.signup.distr_qr_code_capture", qr_capture_start);
                return Ok(Some((http_start.elapsed().as_millis() as u64, location_data)));
            }
            Ok(backend::operator_status::Status { valid: false, .. }) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
                dd_incr!("main.count.signup.result.failure.distr_qr_code", "type:invalid_qr");
            }
            Err(_) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
            }
        }
        Ok(None)
    }

impl Plan {
    /// Checks whether connected to a WiFi network, if not connected scan the
    /// hotspot QR code.
    pub async fn ensure_network_connection(&self, orb: &mut Orb) -> Result<()> {
        let mut in_progress_start = Instant::now();
        let mut has_requested_qr_code = false;
        let success = |orb: &mut Orb, has_requested_qr_code| {
            if has_requested_qr_code {
                orb.ui.network_connection_success();
            }
            tracing::debug!("Network is connected");
            Ok::<(), Error>(())
        };
        loop {
            match network::status().await? {
                network::Status::Connected { has_internet: true } => {
                    success(orb, has_requested_qr_code)?;
                    break;
                }
                network::Status::InProgress
                | network::Status::Connected { has_internet: false }
                    if in_progress_start.elapsed() < NETWORK_CONNECTION_TIMEOUT =>
                {
                    tracing::debug!("Network connection in progress");
                    sleep(Duration::from_millis(250)).await;
                }
                network::Status::Connected { has_internet: false }
                | network::Status::Disconnected
                | network::Status::InProgress => {
                    tracing::debug!("Network is disconnected, or has no connection to the backend");
                    if has_requested_qr_code {
                        orb.ui.qr_scan_fail(QrScanSchema::Wifi);
                    }
                    has_requested_qr_code = true;
                    match qr_scan::Plan::new(None, false).run(orb).await? {
                        Ok((credentials, _)) => {
                            tracing::info!(
                                "Read WiFi credentials from hotspot QR: {:?}",
                                credentials
                            );
                            network::join(credentials).await?;
                            in_progress_start = Instant::now();
                        }
                        Err(qr_scan::ScanError::Invalid) => {
                            orb.ui.qr_scan_unexpected(
                                QrScanSchema::Wifi,
                                QrScanUnexpectedReason::WrongFormat,
                            );
                        }
                        Err(qr_scan::ScanError::Timeout) => {}
                    }
                    orb.reset_rgb_camera().await?;
                }
            }
        }
        Ok(())
    }
