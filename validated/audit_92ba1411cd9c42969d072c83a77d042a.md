### Title
Unbounded memory allocation in `Codec.DecodeHeader` digest array from attacker-controlled length field - (File: evm/src/consensus/Codec.sol)

### Summary
`Codec.DecodeHeader` reads a SCALE compact-encoded digest count directly from relayer-supplied header bytes and immediately allocates an array of that size, with no upper bound check against the remaining buffer length or any sane maximum. This mirrors the ImageMagick `ReadEPTImage` CVE-2017-11530 bug class: a length field taken from untrusted input is used to drive a memory allocation before the input is validated to actually contain that much data, enabling a memory/gas exhaustion denial of service.

### Finding Description
`Codec.DecodeHeader` decodes a Substrate parachain header supplied inside a BEEFY consensus proof: [1](#0-0) 

```
uint256 length = ScaleCodec.decodeUintCompact(slice);
Digest[] memory digests = new Digest[](length);

for (uint256 i = 0; i < length; i++) { ... digests[i] = digest; }
```

`length` is fully attacker-controlled (a SCALE compact integer can encode values up to `u32`/`u64`-scale, i.e. up to billions) and is used directly as the size of a dynamically-allocated `Digest[] memory` array *before* any check that the remaining slice actually contains `length` digest items. Each loop iteration then calls `Bytes.readByte(slice)` / `decodeDigestItem`, which does bound-check reads with `require(self.offset + len <= self.data.length)`, so the loop will eventually revert on genuinely malformed data — but the `new Digest[](length)` allocation happens unconditionally up front, at whatever size the attacker names.

This function is reached from `EcdsaBeefy.verifyParachainHeaderProof`, called once per parachain header inside `EcdsaBeefy.verify`, which is the top-level, permissionless `IConsensusV2.verify` entry point invoked whenever anyone submits a BEEFY consensus proof (via the handler/relayer path) to update Hyperbridge's trusted state on an EVM chain: [2](#0-1) 

Any relayer can submit a `RelayChainProof`/`ParachainProof` containing a `Parachain.header` byte string whose SCALE-encoded digest-count field claims an enormous number of digests, forcing the EVM to attempt allocating a correspondingly huge `Digest[] memory` array during `Codec.DecodeHeader` before the subsequent bounded reads can fail.

### Impact Explanation
On the EVM (unlike native memory in ImageMagick's C code), an out-of-bounds/huge memory allocation is bounded by gas rather than causing unbounded host memory consumption — Solidity memory expansion cost grows quadratically, so an attacker-chosen `length` large enough will simply cause the transaction to run out of gas and revert, rather than silently succeeding. This still constitutes a real, reachable denial-of-service vector: it wastes the submitter's/relayer's gas on every malicious proof, and more importantly it means well-formed (or slightly malformed) headers with maliciously large declared digest counts can be crafted so that gas cost scales quadratically with an attacker-chosen field, making it cheap for an attacker to force expensive-to-revert transactions and complicating gas estimation/DoS-resistance for the consensus-proof-processing path, degrading availability of parachain-header verification (the mechanism used to deliver ISMP messages) without requiring any special privilege.

### Likelihood Explanation
Reachable directly from a single, unsigned/unprivileged EVM transaction calling the BEEFY consensus client's `verify` entry point with a crafted `ParachainProof.parachains[i].header`; no consensus threshold or governance action is needed to trigger the bad allocation path — only to succeed the full proof (bounded reads still fail on genuinely truncated data, but the allocation cost is paid regardless of that later failure).

### Recommendation
Bound `length` in `Codec.DecodeHeader` before allocating: require `length <= (self.data.length - self.offset)` (or some sane per-header digest maximum) prior to `new Digest[](length)`, mirroring the "reject up-front" pattern already used elsewhere in this codebase (e.g. `call-decompressor`'s explicit pre-allocation size gate, and the `MAX_VALIDATORS`/`MAX_PROOF_DEPTH` guards in the Pharos verifier) rather than relying solely on later bounded-read reverts to fail safely.

### Proof of Concept
1. Construct a parachain header byte string where the SCALE compact-encoded digest-count field (located after `parentHash`, `blockNumber` compact, `stateRoot`, `extrinsicsRoot`) encodes a very large value (e.g. close to `2^32`), followed by only a few actual bytes.
2. Wrap this header inside a `Parachain` entry of a `ParachainProof`, itself inside a `BeefyConsensusProof`/`RelayChainProof` structure passed to `EcdsaBeefy.verify(previousState, proof)`.
3. Submit as a normal consensus-update call; `verifyParachainHeaderProof` calls `Codec.DecodeHeader(para.header)`, which executes `new Digest[](length)` with the attacker-chosen huge `length` before the loop's bounded `Bytes.readByte`/`Bytes.read` checks can fail, consuming gas proportional to the attacker-chosen size and reverting with out-of-gas rather than a clean, cheap decode error.

    // @dev Deserializes a substrate header
    function DecodeHeader(bytes memory encoded) internal pure returns (Header memory) {
        ByteSlice memory slice = ByteSlice(encoded, 0);
        bytes32 parentHash = Bytes.toBytes32(Bytes.read(slice, 32));
        uint256 blockNumber = ScaleCodec.decodeUintCompact(slice);
        bytes32 stateRoot = Bytes.toBytes32(Bytes.read(slice, 32));
        bytes32 extrinsicsRoot = Bytes.toBytes32(Bytes.read(slice, 32));

        uint256 length = ScaleCodec.decodeUintCompact(slice);
        Digest[] memory digests = new Digest[](length);

        for (uint256 i = 0; i < length; i++) {
            uint8 kind = Bytes.readByte(slice);
            Digest memory digest;
            if (kind == DIGEST_ITEM_OTHER) {
                digest.isOther = true;
            } else if (kind == DIGEST_ITEM_CONSENSUS) {
                digest.isConsensus = true;
                digest.consensus = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_SEAL) {
                digest.isSeal = true;
                digest.seal = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_PRERUNTIME) {
                digest.isPreRuntime = true;
                digest.preruntime = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_RUNTIME_ENVIRONMENT_UPDATED) {
                digest.isRuntimeEnvironmentUpdated = true;
            }
            digests[i] = digest;
        }

        return Header(parentHash, blockNumber, stateRoot, extrinsicsRoot, digests);
    }
