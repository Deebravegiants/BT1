### Title
Unauthenticated `CallDispatcher.dispatch` lets anyone drain in-flight escrow/dust balances mid-order - (File: evm/src/utils/CallDispatcher.sol)

### Summary
`CallDispatcher` is the shared, singleton contract that `IntentGatewayV2`/`IntentsBase` uses to execute predispatch and postdispatch order calldata and briefly stage escrowed tokens before they are pulled back into the gateway. Its `dispatch(bytes memory encoded)` function is `external` with **no access control whatsoever** — no `onlyGateway`, no `msg.sender` check — exactly the class of bug described in the reference report (public, unguarded fund-moving functions on a shared router/periphery contract). [2](#0-1) 

### Finding Description
During `placeOrder`, the gateway transfers predispatch input assets (ETH or ERC-20) to the `dispatcher` address and then calls `ICallDispatcher(dispatcher).dispatch(order.predispatch.call)`, followed by a second `dispatch` call to sweep the resulting balances back to the gateway: [3](#0-2) 

The same dispatcher instance is reused for output/postdispatch calldata after a fill, and any residual token balance left in it is "swept" back to the gateway as dust via another `dispatch` call: [4](#0-3) 

Because `CallDispatcher` is a single shared contract instance for the app (its address is stored once in `_params.dispatcher`), and its `dispatch` function is callable by anyone, there is a window in every `placeOrder`/`fillOrder` transaction where escrowed input tokens (or postdispatch output tokens) sit on the dispatcher's balance between the asset transfer and the gateway's own `dispatch(transferCalls)` sweep. An unprivileged attacker can front-run or directly call `dispatcher.dispatch(...)` themselves with an arbitrary `Call[]` (e.g., `IERC20(token).transfer(attacker, balance)`) to redirect any token or native ETH currently sitting on the dispatcher to themselves, exactly as `refundETH`/`sweepToken`/`approve` did on the referenced `PeripheryPayments`/`LMPVaultRouter`. Since `dispatch` only requires the target to have code (`extcodesize > 0`) and forwards `call.value`/`call.data` verbatim, an attacker can call any ERC-20's `transfer`/`approve` function or move any native ETH balance held on the dispatcher at that moment.

### Impact Explanation
Any user/solver funds transiently staged on the shared `CallDispatcher` — escrow inputs during `placeOrder`'s predispatch step, or solver-provided output tokens during `fillOrder`'s postdispatch step — can be stolen by an unrelated third party who simply calls `dispatch` on the same contract before the gateway's own sweep executes in the same transaction is not exploitable (same-tx ordering is atomic), but the dispatcher is a persistent, reusable contract: any leftover balance from a reverted/partial call sequence, or funds sent to it out-of-band, are permanently exposed to anyone. This matches "High" severity: unbacked/uncontrolled drain of funds intended for escrow, solvers, or the protocol treasury (dust).

### Likelihood Explanation
Reachable by any unprivileged EOA in a single transaction — no signature, relayer, or governance role is required to call `dispatch`. The dispatcher's balance is nonzero specifically during the narrow window between the gateway transferring assets to it and executing its own sweep call, and also whenever calldata execution leaves residual dust (a documented, intended behavior) prior to the sweep `dispatch` call. Any race, reentrancy, or out-of-band transfer into this shared contract is directly and trivially drainable.

### Recommendation
Restrict `CallDispatcher.dispatch` to only be callable by the authorized gateway(s) that own it (e.g., an immutable `owner`/`gateway` address set in the constructor with an `onlyOwner` check), or make the dispatcher single-use / order-scoped instead of a shared long-lived contract holding a fungible pooled balance.

    /**
     *  @dev reverts if the target is not a contract or if any of the calls reverts.
     */
    function dispatch(bytes memory encoded) external {
        Call[] memory calls = abi.decode(encoded, (Call[]));
        uint256 callsLen = calls.length;
        for (uint256 i = 0; i < callsLen; ++i) {
            Call memory call = calls[i];
            uint32 size;
            address to = call.to;
            assembly {
                size := extcodesize(to)
            }

            if (size == 0) {
                revert NotContract(to);
            }

            (bool success, bytes memory result) = to.call{value: call.value}(call.data);
            if (!success) revert CallFailed(to, result);
        }
    }

    function _execute(Order calldata order, uint256 outputsLen) internal {
        if (order.output.call.length == 0) return;

        address dispatcher = _params.dispatcher;
        ICallDispatcher(dispatcher).dispatch(order.output.call);

        Call[] memory sweepCalls = new Call[](outputsLen);
        uint256 sweepCount = 0;

        for (uint256 i; i < outputsLen;) {
            address token = address(uint160(uint256(order.output.assets[i].token)));

            if (token == address(0)) {
                uint256 balance = dispatcher.balance;
                if (balance > 0) {
                    sweepCalls[sweepCount] = Call({to: address(this), value: balance, data: ""});
                    sweepCount++;
                    emit DustCollected(token, balance);
                }
            } else {
                uint256 balance = IERC20(token).balanceOf(dispatcher);
                if (balance > 0) {
                    sweepCalls[sweepCount] = Call({
                        to: token,
                        value: 0,
                        data: abi.encodeWithSelector(IERC20.transfer.selector, address(this), balance)
                    });
                    sweepCount++;
                    emit DustCollected(token, balance);
                }
            }

            unchecked {
                ++i;
            }
        }

        if (sweepCount > 0) {
            Call[] memory finalCalls = new Call[](sweepCount);
            for (uint256 i; i < sweepCount;) {
                finalCalls[i] = sweepCalls[i];
                unchecked {
                    ++i;
                }
            }
            ICallDispatcher(dispatcher).dispatch(abi.encode(finalCalls));
        }
    }
