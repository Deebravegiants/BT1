Audit Report

## Title
Read-only ("View" role) authenticated user can retrieve External Initiator `OutgoingToken` secret via `GET /v2/external_initiators` - (File: `core/web/external_initiators_controller.go`)

## Summary
The `GET /v2/external_initiators` route is registered without any `auth.RequiresEditRole`/`RequiresAdminRole` wrapper, unlike the `POST`/`DELETE` routes on the same resource, and its handler returns each External Initiator's `OutgoingToken` secret in the JSON response via `NewExternalInitiatorResource`. This allows the lowest-privilege authenticated role (`UserRoleView`) to read a secret meant to authenticate the node's outbound calls to the external initiator webhook.

## Finding Description
`core/web/router.go` registers the index route unprotected while its siblings are gated:
```go
authv2.GET("/external_initiators", paginatedRequest(eia.Index))
authv2.POST("/external_initiators", auth.RequiresEditRole(eia.Create))
authv2.DELETE("/external_initiators/:Name", auth.RequiresEditRole(eia.Destroy))
```
`ExternalInitiatorsController.Index` in `core/web/external_initiators_controller.go` (lines 50-59) fetches every `bridges.ExternalInitiator` row and converts it via `presenters.NewExternalInitiatorResource`, which explicitly copies `ei.OutgoingToken` into the `ExternalInitiatorResource.OutgoingToken` JSON field (`core/web/presenters/external_initiators.go`, lines 57-77). `OutgoingToken` is generated as a real secret (`utils.NewSecret(utils.DefaultSecretSize)`) at creation time in `core/bridges/external_initiator.go` and is intended to remain confidential — the `Create` handler already treats it as sensitive by only returning it once through the separate `ExternalInitiatorAuthentication` presenter. The repo's own RBAC test table in `core/web/auth/auth_test.go` line 224 (`{"GET", "/v2/external_initiators", true, true, true}`) confirms this endpoint is intentionally reachable by `viewOnlyAllowed` — the weakest role — and no other auth/redaction mechanism intercepts the secret before serialization.

## Impact Explanation
Any authenticated node user holding only `UserRoleView` — the role intended for read-only/dashboard access — can enumerate all configured external initiators and obtain their `OutgoingToken`. This is a secret-exfiltration issue: a credential intended to be scoped to Edit/Admin-level operators managing external initiators is disclosed to a lower-privileged principal, potentially enabling misuse depending on how the receiving external initiator validates the token on inbound requests.

## Likelihood Explanation
Likelihood is high: exploitation requires only a valid low-privilege View-role session/API token and a simple unauthenticated-by-role `GET` request; no special conditions, timing, or additional access are needed beyond what the RBAC test table already documents as reachable.

## Recommendation
Wrap `GET /v2/external_initiators` with at least `auth.RequiresEditRole` to match the `POST`/`DELETE` routes, and/or remove `OutgoingToken` from `ExternalInitiatorResource`, exposing it only once at creation via `ExternalInitiatorAuthentication` as already done in `Create`.

## Proof of Concept
1. As an Edit/Admin user, create an External Initiator via `POST /v2/external_initiators`, generating an `OutgoingToken`.
2. Create/log in as a user with `UserRoleView`.
3. As the View-role user, call `GET /v2/external_initiators` with a valid session/API token.
4. Observe the JSON response includes each initiator's `outgoingToken` field in cleartext, per `NewExternalInitiatorResource` (`core/web/presenters/external_initiators.go` lines 67-77). [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3) [5](#0-4)

```go
func (eic *ExternalInitiatorsController) Index(c *gin.Context, size, page, offset int) {
	ctx := c.Request.Context()
	externalInitiators, count, err := eic.App.BridgeORM().ExternalInitiators(ctx, offset, size)
	resources := make([]presenters.ExternalInitiatorResource, 0, len(externalInitiators))
	for _, initiator := range externalInitiators {
		resources = append(resources, presenters.NewExternalInitiatorResource(initiator))
	}

	paginatedResponse(c, "externalInitiators", size, page, resources, count, err)
}
```

```go
func NewExternalInitiatorResource(ei bridges.ExternalInitiator) ExternalInitiatorResource {
	return ExternalInitiatorResource{
		JAID:          NewJAID(strconv.FormatInt(ei.ID, 10)),
		Name:          ei.Name,
		URL:           ei.URL,
		AccessKey:     ei.AccessKey,
		OutgoingToken: ei.OutgoingToken,
		CreatedAt:     ei.CreatedAt,
		UpdatedAt:     ei.UpdatedAt,
	}
}
```

```go
// ExternalInitiator represents a user that can initiate runs remotely
type ExternalInitiator struct {
	ID             int64
	Name           string
	URL            *models.WebURL
	AccessKey      string
	Salt           string
	HashedSecret   string
	OutgoingSecret string
	OutgoingToken  string

	CreatedAt time.Time
	UpdatedAt time.Time
}

// NewExternalInitiator generates an ExternalInitiator from an
// auth.Token, hashing the password for storage
func NewExternalInitiator(
	eia *auth.Token,
	eir *ExternalInitiatorRequest,
) (*ExternalInitiator, error) {
	salt := utils.NewSecret(utils.DefaultSecretSize)
	hashedSecret, err := auth.HashedSecret(eia, salt)
	if err != nil {
		return nil, pkgerrors.Wrap(err, "error hashing secret for external initiator")
	}

	return &ExternalInitiator{
		Name:           strings.ToLower(eir.Name),
		URL:            eir.URL,
		AccessKey:      eia.AccessKey,
		HashedSecret:   hashedSecret,
		Salt:           salt,
		OutgoingToken:  utils.NewSecret(utils.DefaultSecretSize),
		OutgoingSecret: utils.NewSecret(utils.DefaultSecretSize),
	}, nil
```
