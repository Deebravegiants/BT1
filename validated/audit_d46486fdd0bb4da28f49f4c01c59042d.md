### Title
Unauthenticated "Magic QR-code" Actions Bypass Operator Authorization - ([File: src/plans/mod.rs])

### Summary
`handle_magic_operator_qr_code()` executes privileged device-reconfiguration actions (`reset_mirror_calibration()`, `reset_wifi_and_ensure_network()`) immediately upon detecting a "magic" QR-code string, before the scanned code is ever validated against the backend as belonging to an authorized operator. Any person who can present a printed/displayed QR-code to the Orb's camera — with no operator credential, session, or backend check — can trigger these privileged actions, mirroring the reported pattern of a state-mutating function with no caller restriction.

### Finding Description
The operator QR-code parser recognizes two "magic" action strings via a simple regex, independent of any operator identity: `magic_action:reset_wifi_credentials` and `magic_action:reset_mirror_calibration`. [1](#0-0) 

These are dispatched in `handle_magic_operator_qr_code()`, which runs directly after the raw QR scan and *before* `verify_operator_qr_code()` (the function that calls the backend to confirm the QR-code belongs to a valid, authorized operator): [2](#0-1) 

Both call sites in the signup flow scan the operator QR-code, then call `handle_magic_operator_qr_code()` unconditionally, and only call `verify_operator_qr_code()` afterward for non-magic codes: [3](#0-2) [4](#0-3) 

So the "magic" branch never reaches the authorization check at all — it short-circuits straight into privileged action execution: [5](#0-4) 

This is the direct analog of "anyone can call `notifyStrategyRemoved()`": here, "anyone" is any party who can print/display a QR-code and hold it up to the Orb's camera during the operator-QR-code scanning phase (which happens on every idle Orb, not just mid-signup), and the "removed strategy" analog is triggering an unauthorized state-mutating action (mirror recalibration or network/WiFi reset) on production hardware without any operator authentication.

### Impact Explanation
- `reset_wifi_and_ensure_network()` calls `network::reset()` and forces the Orb to drop and re-establish its network connection — an unauthenticated party can repeatedly trigger this to disrupt signups in progress or as a persistent denial-of-service against the Orb's connectivity, which gates every backend-dependent step of signup (operator/user QR validation, biometric pipeline, PCP upload).
- `reset_mirror_calibration()` overwrites the on-disk mirror calibration file and re-triggers mirror auto-calibration, an operation intended to be operator-gated maintenance. Forcing recalibration at will, without operator authorization, can degrade or disrupt the eye-camera aiming pipeline that biometric capture depends on, undermining trust that only authorized operators can alter capture-affecting hardware state.
- Because the check happens before any backend authorization call, the flaw is unconditionally reachable by physical presentation of a QR-code, with no operator credential, PIN, or backend session required — exactly the "no restriction on who can call this" class of bug from the report.

### Likelihood Explanation
High. The magic-action strings are static, publicly derivable from the open-source regex/parsing logic (`magic_action:reset_wifi_credentials`, `magic_action:reset_mirror_calibration`), require no secret, and are reachable during the same physical-proximity QR-scanning step every operator/user already performs, requiring no special access beyond standing in front of the device.

### Recommendation
Move the magic-action dispatch to occur only after the scanned code has been authenticated as belonging to a legitimate operator (i.e., only invoke `handle_magic_operator_qr_code`'s side-effecting branches after `verify_operator_qr_code` succeeds), or otherwise require operator authentication/authorization before executing `reset_mirror_calibration()` or `reset_wifi_and_ensure_network()`.

### Proof of Concept
1. Generate a QR-code containing the literal string `magic_action:reset_wifi_credentials` (or `magic_action:reset_mirror_calibration`).
2. Present it to an idle or signup-flow Orb during operator QR-code scanning.
3. Observe `Data::try_parse` classify it as `Data::MagicResetWifi`/`Data::MagicResetMirror` [6](#0-5) , and `handle_magic_operator_qr_code` immediately execute `reset_wifi_and_ensure_network`/`reset_mirror_calibration` without any prior call to `verify_operator_qr_code` [7](#0-6) .

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    /// Resets the mirror calibration.
    pub async fn reset_mirror_calibration(&self, orb: &mut Orb) -> Result<()> {
        let calibration: Calibration = (&*orb.config.lock().await).into();
        calibration.store(CALIBRATION_FILE_PATH).await?;
        orb.enable_mirror()?;
        orb.recalibrate(calibration).await?;
        orb.disable_mirror();
        Ok(())
    }

    /// Resets the network and requests a new one.
    pub async fn reset_wifi_and_ensure_network(&self, orb: &mut Orb) -> Result<()> {
        network::reset().await?;
        wifi::Plan.ensure_network_connection(orb).await?;
        orb.reset_rgb_camera().await?;
        Ok(())
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }
