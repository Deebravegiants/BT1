### Title
Denial of Service via requestID front-running in the HTTP Trigger gateway handler - (File: core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go)

### Summary
The HTTP trigger gateway handler stores in-flight requests in a single global map keyed by the JSON-RPC `req.ID` value, which is entirely chosen by the calling client and is only checked against a single, non-namespaced map. This mirrors the reported Folks Finance bug class: a check-then-set on an attacker-controllable identifier with no per-tenant isolation, allowing any unprivileged caller to block another caller's operation by "claiming" the same ID first.

### Finding Description
`setupCallback` performs the classic check-then-act race on `h.callbacks[requestID]`:

```go
if _, found := h.callbacks[requestID]; found {
    h.handleUserError(ctx, requestID, jsonrpc.ErrConflict, ...)
    return nil, fmt.Errorf("in-flight request ID: %s", requestID)
}
...
h.callbacks[requestID] = savedCallback{...}
``` [2](#0-1) 

The `requestID` originates directly from the JSON-RPC request's `ID` field supplied by whoever calls the gateway's `HandleUserTriggerRequest` entrypoint (reachable from the internet-facing gateway's `ProcessRequest`, which decodes the raw JSON-RPC request and dispatches it to the handler without ever rewriting or namespacing the ID before this check). [3](#0-2) 

Critically, `h.callbacks` is a single map shared across **all** workflows served by this handler instance — it is not partitioned by `workflowID` or by the authenticated owner. The authorization step (`authorizeRequest`) verifies that the caller holds a valid signed JWT for *some* registered workflow, but it does not bind or scope the chosen `req.ID` to that workflow/owner; any authenticated workflow owner (which, in a permissionless-registration DON, can be any external actor who has registered a workflow) can pick an arbitrary `req.ID` string. This is confirmed by the existing test `TestHttpTriggerHandler_HandleUserTriggerRequest/"duplicate request ID"`, which shows a second, differently-authenticated request using the same `req.ID` is rejected with `"in-flight request ID"` rather than being isolated per-workflow. [4](#0-3) 

Consequently, an attacker who can predict or guess a victim's forthcoming `requestID` (e.g., sequential IDs, well-known IDs, or IDs observed in a prior failed/retried call) can pre-register that ID for their own (unrelated) workflow just before the victim's legitimate request arrives. The victim's genuine trigger call then fails with `ErrConflict`/"has already been used", exactly analogous to the `LoanManager.createUserLoan` front-running DoS where `isUserLoanActive(loanId)` blocks the legitimate creator after an attacker races in with the same `loanId`.

### Impact Explanation
Any unprivileged, authenticated workflow owner on the gateway (not a privileged operator) can deny service to another tenant's HTTP-triggered workflow execution by squatting on the shared `requestID` namespace. Because the map has no cross-tenant isolation, this is a griefing/DoS vector reachable purely from client-supplied request data through the public gateway entrypoint, without needing to compromise a node or the network layer.

### Likelihood Explanation
Exploitability depends on the attacker's ability to predict or learn the victim's `requestID` before it is submitted. If callers use client-generated, low-entropy, or otherwise guessable/observable IDs (e.g., sequence numbers, timestamps, or IDs echoed back in error responses/logs), the race is straightforward to win by submitting slightly ahead of the legitimate caller. If all callers strictly use high-entropy random UUIDs, the practical likelihood is lower, but the underlying design flaw (global keyspace, no tenant scoping, no defense-in-depth) remains a bug regardless of caller ID hygiene, since the map ought to be scoped by `(workflowID/owner, requestID)` rather than by `requestID` alone.

### Recommendation
Namespace the `callbacks` map key by workflow identity (e.g., `(workflowOwner, workflowID, requestID)` or a hash thereof) instead of the raw client-supplied `requestID` alone, so that one tenant cannot collide with or block another tenant's in-flight requests. Additionally consider deriving the internal dedup key deterministically from authenticated request/signature bytes rather than trusting only the un-scoped `req.ID` string.

### Proof of Concept
1. Attacker registers/owns a legitimate workflow A and obtains a valid signing key for it.
2. Attacker learns/guesses that victim (owner of workflow B) will submit an HTTP trigger request with `req.ID = "X"` (e.g., because the victim's client uses predictable/sequential IDs, or the attacker observed ID "X" in a prior interaction).
3. Attacker sends `HandleUserTriggerRequest` for workflow A with `req.ID = "X"`, signed with A's valid key — this succeeds and inserts `h.callbacks["X"]`.
4. Victim's genuine request for workflow B with `req.ID = "X"` now hits `setupCallback`, finds `"X"` already present, and is rejected with `jsonrpc.ErrConflict` / "has already been used" — reproducing the same check-then-act collision demonstrated by the existing `"duplicate request ID"` unit test, but between two unrelated, independently-authorized workflows rather than a genuine retry of the same request. [4](#0-3)

func (h *httpTriggerHandler) setupCallback(ctx context.Context, requestID string, callback handlers.Callback, requestStartTime time.Time, workflowID string) (<-chan struct{}, error) {
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()

	if _, found := h.callbacks[requestID]; found {
		h.handleUserError(ctx, requestID, jsonrpc.ErrConflict, fmt.Sprintf("requestID: %s has already been used. Ensure the requestID is unique for each request.", requestID), callback)
		return nil, fmt.Errorf("in-flight request ID: %s", requestID)
	}

	// Build one response aggregator per shard the workflow is assigned to.
	assigned := h.workflowMetadataHandler.WorkflowShards(workflowID)
	if len(assigned) == 0 {
		// this shouldn't happen because we checked it in authorizeRequest()
		h.handleUserError(ctx, requestID, jsonrpc.ErrInternal, fmt.Sprintf("Workflow %s is not assigned to any DONs", workflowID), callback)
		return nil, errors.New("workflow is not assigned to any shards")
	}

	aggregators := make(map[string]*aggregation.IdenticalNodeResponseAggregator, len(assigned))
	for _, shard := range assigned {
		// (N+F)//2 + 1 threshold where N = number of nodes, F = number of faulty nodes
		threshold := (len(shard.members)+shard.f)/2 + 1
		agg, err := aggregation.NewIdenticalNodeResponseAggregator(threshold)
		if err != nil {
			return nil, errors.New("failed to create response aggregator: " + err.Error())
		}
		aggregators[shard.donID] = agg
	}

	doneCh := make(chan struct{})
	h.callbacks[requestID] = savedCallback{
		Callback:            callback,
		requestStartTime:    requestStartTime,
		createdAt:           time.Now(),
		responseAggregators: aggregators,
		doneCh:              doneCh,
	}
	return doneCh, nil
```

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	isLegacyRequest := false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonID == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonID
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}
