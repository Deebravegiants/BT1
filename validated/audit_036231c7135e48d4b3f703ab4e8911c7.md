Audit Report

## Title
Unauthenticated exposure of internal pprof profiling/debug data via LOOP plugin routes - (File: core/web/router.go, core/web/loop_registry.go)

## Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` on the top-level `api` router group in `NewRouter`, which only applies rate limiting and session middleware, with no `auth.Authenticate` call. [1](#0-0)  This is inconsistent with the analogous internal debug/pprof route `metricRoutes`, which is deliberately nested inside the `authv2` group requiring `auth.Authenticate(..., auth.AuthenticateByToken, auth.AuthenticateBySession)`. [2](#0-1) [3](#0-2) 

## Finding Description
`loopRoutes` wires the `LoopRegistryServer` handlers with no authentication middleware at all: [4](#0-3) 

`pluginPPROFHandler` forwards caller-supplied `debug`, `gc`, `seconds` query parameters and the full `profile` path segment to the internal per-plugin pprof server without any authorization check: [5](#0-4) 

`pluginPPROFPOSTSymbolHandler` similarly proxies POST bodies unauthenticated: [6](#0-5) 

`discoveryHandler` and `pluginMetricHandler` are likewise reachable without credentials, and `discoveryHandler` enumerates all registered plugin names via `LabelMetaPluginName`: [7](#0-6) 

The root cause is a genuine inconsistency: the router intentionally guards `/v2/debug/pprof` behind `authv2` ("Debug routes accessible via authentication") but mounts the functionally equivalent LOOP-plugin pprof proxy routes directly on the unauthenticated `api` group. No existing middleware (rate limiter, session cookie handling) performs any authentication or authorization check for these routes — a session cookie is only stored/read, not required to be valid, on the plain `api` group.

## Impact Explanation
This exposes internal pprof introspection (goroutine dumps, heap/block/mutex profiles, CPU profiles via `seconds`, `cmdline`) and plugin/service topology (via `/discovery`) for any named LOOP plugin, to any actor able to reach the node's web server, without credentials. This is an information-disclosure class issue (CWE-862/863, missing authorization) consistent with the "node API authentication or role bypass" impact category recognized by the Chainlink bounty program, since a supposedly-protected debug surface is reachable without the authentication the router's own design requires for its equivalent core route.

## Likelihood Explanation
Exploitability is high wherever the node's HTTP web server port is reachable by an untrusted caller (the same network exposure any unauthenticated actor could reach `/health` or `/sessions` on), since no token, session, or role check gates these handlers — confirmed directly from the router wiring and handler code with no intervening middleware.

## Recommendation
Require authentication on the `loopRoutes` group in `core/web/router.go`, mirroring the `authv2` protection applied to `metricRoutes` (e.g., wrap `loopRoutes(app, api)` registration to use an authenticated sub-group, or gate the pprof/discovery handlers behind `auth.Authenticate` plus an appropriate role check such as `auth.RequiresAdminRole`), or restrict these plugin discovery/pprof proxy routes to loopback/internal-only network access.

## Proof of Concept
1. Start a Chainlink node with a LOOP plugin registered and its web server port reachable.
2. Without any authentication headers or session cookie, issue `GET /discovery` — confirm plugin names are enumerated via `LabelMetaPluginName` in `discoveryHandler`.
3. For a discovered plugin name `X`, issue `GET /plugins/X/debug/pprof/goroutine?debug=2` or `GET /plugins/X/debug/pprof/profile?seconds=30` with no credentials — per `pluginPPROFHandler`, the request is forwarded to the internal plugin pprof server and returned with `200 OK`.
4. Compare against `GET /v2/debug/pprof/goroutine`, which is behind `auth.Authenticate` in the `authv2` group and returns `401 Unauthorized` without a valid session/token, confirming the asymmetric/missing authorization on the LOOP routes.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}
```

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
