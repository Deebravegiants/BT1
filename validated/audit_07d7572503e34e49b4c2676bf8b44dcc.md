Confirmed vulnerability: in `process_swap_base_out`, `Calculator::swap_token_amount_base_out` is called at [1](#0-0)  with `swap.amount_out` — an attacker-controlled value from the instruction data — **before** any check that `swap.amount_out` is less than the pool's available liquidity. The check that `swap.amount_out < total_pc_without_take_pnl` (or `total_coin_without_take_pnl`) only happens later, at [2](#0-1)  for `Coin2PC` and [3](#0-2)  for `PC2Coin` — well after the math has already run.

### Title
Unchecked user-supplied `amount_out` causes division-by-zero panic in `swap_token_amount_base_out` - (File: program/src/math.rs)

### Summary
`process_swap_base_out` computes the required input amount via `Calculator::swap_token_amount_base_out` using the caller-supplied `swap.amount_out` before validating that `amount_out` is strictly less than the pool's opposite-side reserve. Inside that math function, the denominator is `total_pc_without_take_pnl.checked_sub(amount_out)` (or the coin equivalent) followed by `checked_ceil_div`, which internally does `checked_div` and then `.unwrap()`. If `amount_out` equals the pool reserve, the denominator is zero and the ceil-div returns `None`, causing an `unwrap()` panic.

### Finding Description
In `Calculator::swap_token_amount_base_out` [4](#0-3) , for `SwapDirection::Coin2PC`:
```
let denominator = total_pc_without_take_pnl.checked_sub(amount_out).unwrap();
amount_in = total_coin_without_take_pnl.checked_mul(amount_out).unwrap().checked_ceil_div(denominator).unwrap();
```
and the reverse for `PC2Coin`. `checked_ceil_div` [5](#0-4)  internally calls `self.checked_div(rhs)?`, which returns `None` when `rhs == 0`. The outer `.unwrap()` in `swap_token_amount_base_out` then panics.

The caller, `process_swap_base_out` [1](#0-0) , passes `swap.amount_out` — fully attacker-controlled instruction data — directly into this function without first checking it against `total_pc_without_take_pnl` / `total_coin_without_take_pnl`. The equivalent bound check (`swap.amount_out >= total_pc_without_take_pnl` / `total_coin_without_take_pnl`) only exists further down the function [6](#0-5) , after the vulnerable computation has already executed.

### Impact Explanation
A single unprivileged transaction calling the `SwapBaseOut` instruction with `amount_out` set exactly equal to the pool's current opposite-side reserve (`total_pc_without_take_pnl` for `Coin2PC`, or `total_coin_without_take_pnl` for `PC2Coin`) triggers an arithmetic panic. On Solana, an unhandled panic aborts the transaction with an unrecoverable runtime error rather than a clean program error, which can be used to deny service on this specific instruction path against a given pool by any user who can read the pool's reserve amounts (which are public on-chain data readily obtainable from the token vault accounts).

### Likelihood Explanation
High. The reserve amounts (`amm_coin_vault.amount`, `amm_pc_vault.amount`) are public account data, so an attacker can trivially compute the exact `amount_out` value needed to zero the denominator, then submit one `SwapBaseOut` transaction with attacker-chosen accounts/data. No privileged role or special timing is required.

### Recommendation
Move the bound checks (`swap.amount_out < total_pc_without_take_pnl` / `< total_coin_without_take_pnl`) to occur before calling `Calculator::swap_token_amount_base_out`, and/or replace the `.unwrap()` calls in `swap_token_amount_base_out` (and `CheckedCeilDiv` impls) with proper error propagation (`ok_or(AmmError::...)?`) so a zero or negative denominator returns a program error instead of panicking.

### Proof of Concept
1. Attacker reads `amm_pc_vault.amount` and `amm.state_data.need_take_pnl_pc` to compute `total_pc_without_take_pnl` (public data).
2. Attacker submits a `SwapBaseOut` instruction with `swap_direction = Coin2PC` and `swap.amount_out == total_pc_without_take_pnl`.
3. Execution reaches `Calculator::swap_token_amount_base_out` at [1](#0-0) ; inside, `denominator = total_pc_without_take_pnl.checked_sub(amount_out) = 0`.
4. `checked_ceil_div(0)` returns `None` at [7](#0-6) , and the subsequent `.unwrap()` panics, aborting the transaction with a runtime panic rather than a graceful `AmmError`.

```rust
    pub fn swap_token_amount_base_out(
        amount_out: U128,
        total_pc_without_take_pnl: U128,
        total_coin_without_take_pnl: U128,
        swap_direction: SwapDirection,
    ) -> U128 {
        let amount_in;
        match swap_direction {
            SwapDirection::Coin2PC => {
                // (x + delta_x) * (y + delta_y) = x * y
                // (coin + amount_in) * (pc - amount_out) = coin * pc
                // => amount_in = coin * pc / (pc - amount_out) - coin
                // => amount_in = (coin * pc - pc * coin + amount_out * coin) / (pc - amount_out)
                // => amount_in = (amount_out * coin) / (pc - amount_out)
                let denominator = total_pc_without_take_pnl.checked_sub(amount_out).unwrap();
                amount_in = total_coin_without_take_pnl
                    .checked_mul(amount_out)
                    .unwrap()
                    .checked_ceil_div(denominator)
                    .unwrap()
            }
            SwapDirection::PC2Coin => {
                // (x + delta_x) * (y + delta_y) = x * y
                // (pc + amount_in) * (coin - amount_out) = coin * pc
                // => amount_out = coin - coin * pc / (pc + amount_in)
                // => amount_out = (coin * pc + coin * amount_in - coin * pc) / (pc + amount_in)
                // => amount_out = coin * amount_in / (pc + amount_in)

                // => amount_in = coin * pc / (coin - amount_out) - pc
                // => amount_in = (coin * pc - pc * coin + pc * amount_out) / (coin - amount_out)
                // => amount_in = (pc * amount_out) / (coin - amount_out)
                let denominator = total_coin_without_take_pnl.checked_sub(amount_out).unwrap();
                amount_in = total_pc_without_take_pnl
                    .checked_mul(amount_out)
                    .unwrap()
                    .checked_ceil_div(denominator)
                    .unwrap()
            }
        }
        return amount_in;
    }
```

```rust
impl CheckedCeilDiv for U128 {
    fn checked_ceil_div(&self, rhs: Self) -> Option<Self> {
        let mut quotient = self.checked_div(rhs)?;
        let remainder = self.checked_rem(rhs)?;
        if remainder != U128::zero() {
            quotient = quotient.checked_add(U128::one())?;
        }
        Some(quotient)
    }
}
```
