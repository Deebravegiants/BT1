Audit Report

## Title
Unauthenticated access to LOOP plugin metrics/pprof proxy routes allows internal-network SSRF-style path forwarding - ([File: core/web/router.go])

## Summary
`loopRoutes` is registered directly on the base `api` router group in `NewRouter`, which only applies rate-limiting and session middleware, with no authentication check applied before dispatching to `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol`. This is inconsistent with every other sensitive route group in the same file (`debugRoutes`, and `metricRoutes` mounted only inside the authenticated `authv2` group), allowing any unauthenticated client that can reach the node's HTTP port to enumerate LOOP plugins and proxy requests into their internal Prometheus/pprof listeners.

## Finding Description
`NewRouter` builds the `api` group with only `rateLimiter` and `sessions.Sessions` middleware and calls `loopRoutes(app, api)` directly, without any `auth.Authenticate` wrapper: [1](#0-0) 

`loopRoutes` registers its four routes on that unauthenticated group: [2](#0-1) 

By contrast, `debugRoutes` explicitly wraps its `/debug/vars` route with `auth.Authenticate(...)`, and the node's own `metricRoutes` (pprof) is invoked only inside the authenticated `authv2` group: [3](#0-2) [4](#0-3) 

The handlers themselves build forwarding URLs to an internal LOOP-plugin process using caller-controlled input with no additional access check. `pluginPPROFHandler` concatenates the `*profile` wildcard parameter directly into the forwarded URL and passes through `debug`/`gc`/`seconds` query parameters: [5](#0-4) [6](#0-5)  `pluginMetricHandler` and `pluginPPROFPOSTSymbolHandler` proxy GET/POST requests to the plugin's internal port similarly without any caller authentication check: [7](#0-6) [8](#0-7) 

## Impact Explanation
Any unauthenticated client reaching the node's HTTP port can enumerate registered LOOP plugins and their internal Prometheus ports via `/discovery`, pull raw internal metrics via `/plugins/:name/metrics`, and trigger CPU/heap/goroutine profiling with attacker-chosen `seconds`/`debug`/`gc` values via `/plugins/:name/debug/pprof/*profile`. This breaks the node's authentication boundary for internal operational surfaces, consistent with CWE-306 missing authentication, and constitutes an authentication bypass on node API surface (an in-scope impact class). The `profile` wildcard being concatenated verbatim into the forwarded path also broadens the reachable internal path space beyond the intended `/debug/pprof/*` namespace on the plugin's listener.

## Likelihood Explanation
Any actor able to reach the node's web server port (the same reachability required to hit `/v2/ping` or `/health`) can trigger this without any credentials or session, since the affected routes are mounted on the base `api` group before any authentication middleware is attached. This requires no operator/admin privileges, no host access, and no social engineering — a plain HTTP GET/POST is sufficient.

## Recommendation
Wrap `loopRoutes` registration with the same authentication middleware used for `metricRoutes`/`debugRoutes` (`auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`), or restrict these endpoints to loopback/internal-network callers only, consistent with the design intent noted in the code comments ("this endpoint is internal btw the node and plugin").

## Proof of Concept
```
GET /discovery HTTP/1.1
Host: <node-host>:6688

GET /plugins/<name>/metrics HTTP/1.1
Host: <node-host>:6688

GET /plugins/<name>/debug/pprof/profile?seconds=60 HTTP/1.1
Host: <node-host>:6688
```
No session cookie or API token is required for any of the above requests, as verified in `loopRoutes` registration at [2](#0-1) , which is called before any authentication middleware is applied at [9](#0-8) .

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
