### Title
`SimplexPaymaster` prices gas-fee tokens from raw Chainlink `latestRoundData()` without validating against the feed's min/max circuit-breaker bounds - (File: evm/src/utils/SimplexPaymaster.sol)

### Summary
`SimplexPaymaster._getOraclePrice()` reads `latestRoundData()` from both the native/USD oracle and each registered token/USD oracle, and only validates that the answer is positive and not stale. [1](#0-0)  It never checks the aggregator's `minAnswer`/`maxAnswer` circuit-breaker bounds, so if a registered fee token (e.g., a stablecoin) depegs sharply downward and its Chainlink feed clamps to `minAnswer`, the paymaster will keep pricing that token as if it were still worth its pre-crash value.

### Finding Description
`_tokenPrice()` computes how many token units a UserOp sender must pay per unit of gas by dividing the native/USD price by the token/USD price:
```
(nativeUsd * 10**tokenDecimals * (10000+markupBps)) / (tokenUsd * 10000)
``` [2](#0-1)  Both `nativeUsd` and `tokenUsd` come from `_getOraclePrice`, which only guards against a non-positive answer and staleness (`updatedAt` vs `maxOracleAge`):
```solidity
function _getOraclePrice(AggregatorV3Interface oracle, uint8 oracleDecimals) internal view returns (uint256) {
    (, int256 answer,, uint256 updatedAt,) = oracle.latestRoundData();
    if (answer <= 0) revert InvalidOraclePrice(address(oracle), answer);
    if (block.timestamp - updatedAt > maxOracleAge) {
        revert StaleOraclePrice(address(oracle), updatedAt);
    }
    ...
}
``` [3](#0-2)  As in the original JOJO report, a legacy Chainlink aggregator with a `minAnswer` circuit breaker keeps emitting fresh, "live" rounds pinned at the floor price once the real market price crashes below it. This passes both the staleness and positivity checks in `_getOraclePrice`, so the paymaster keeps treating a depegged/crashed token as if it still traded at (or above) the floor price.

This function is reached from the fully permissionless ERC-4337 validation/execution path: any UserOp sender selecting a registered fee token triggers `_tokenPrice` → `_getOraclePrice` through `validatePaymasterUserOp`/`fetchDetails` (inherited `PaymasterERC20` flow) and through the public view `getTokenPrice`/`estimateTokenCost`. [4](#0-3) 

### Impact Explanation
If a registered stablecoin's price crashes below the aggregator's `minAnswer`, `tokenUsd` stays pinned at the (now inflated relative to reality) floor while `nativeUsd` reflects the real, unaffected native price. Since `tokenUsd` sits in the denominator of `_tokenPrice`, any UserOp sender can pay gas with the crashed token at the stale floor valuation, paying far less real economic value than the ETH/BNB the paymaster actually spends sponsoring the UserOp. This directly drains the paymaster's EntryPoint deposit/treasury value over time - a permissionless, single-transaction path to extracting value from protocol-held funds, matching the "bad debt/insolvency" impact class described in the source report. `swapAndDeposit` (treasury-gated) uses the same unvalidated price for `amountOutMin`, compounding the risk if triggered during the same market dislocation.

### Likelihood Explanation
Exploitation requires only a UserOp submitted through the standard EntryPoint flow while one of the registered token oracles is in circuit-breaker clamp (a real, historically observed market condition, e.g., depegging or crash events). No special privilege, governance action, or malicious insider is needed - only a live market dislocation and a permissionless UserOp, which any actor can construct and submit as soon as the condition arises.

### Recommendation
In `_getOraclePrice`, fetch and enforce the aggregator's `minAnswer`/`maxAnswer` bounds (or equivalent sanity bounds configured by governance per feed) and revert if `answer` is at or outside those bounds, mirroring the fix recommended in the source report. Where the specific aggregator no longer exposes `minAnswer`/`maxAnswer` (deprecated on newer feeds), add a governance-configurable sanity band per token/native oracle and revert outside it, plus consider a secondary oracle or TWAP fallback for critical fee tokens.

### Proof of Concept
1. Governance registers `TokenA` with a Chainlink feed that has `minAnswer = $1`.
2. Market crash drives `TokenA`'s real price to $0.10; the aggregator continues emitting fresh rounds pinned at `$1` (passes both `answer > 0` and staleness checks).
3. Any user submits a UserOp using `TokenA` as the fee token; `_tokenPrice()`/`estimateTokenCost()` price gas as if `TokenA` were still worth `$1`.
4. The paymaster accepts `TokenA` at 10x its real value, subsidizing the UserOp's real ETH/BNB gas cost while receiving tokens worth a fraction of that cost, permissionlessly draining paymaster treasury value with every subsequent UserOp until governance intervenes via `DeactivateToken`.

    function _getOraclePrice(AggregatorV3Interface oracle, uint8 oracleDecimals) internal view returns (uint256) {
        (, int256 answer,, uint256 updatedAt,) = oracle.latestRoundData();

        if (answer <= 0) revert InvalidOraclePrice(address(oracle), answer);
        if (block.timestamp - updatedAt > maxOracleAge) {
            revert StaleOraclePrice(address(oracle), updatedAt);
        }

        if (oracleDecimals < 8) {
            return uint256(answer) * (10 ** (8 - oracleDecimals));
        } else if (oracleDecimals > 8) {
            return uint256(answer) / (10 ** (oracleDecimals - 8));
        }
        return uint256(answer);
    }
```

    /// @notice Current price in token base units per wei of gas (scaled by 1e18),
    ///         markup included. For offchain gas estimation.
    function getTokenPrice(address token) external view returns (uint256) {
        TokenConfig memory cfg = tokenConfigs[token];
        if (address(cfg.tokenOracle) == address(0)) revert TokenNotRegistered(token);

        return _tokenPrice(cfg);
    }

    /// @notice Estimate the token cost for a given gas amount and fee, mirroring
    ///         PaymasterERC20._erc20Cost (including its postOp gas cushion).
    function estimateTokenCost(address token, uint256 gasAmount, uint256 maxFeePerGas) external view returns (uint256) {
        TokenConfig memory cfg = tokenConfigs[token];
        if (address(cfg.tokenOracle) == address(0)) revert TokenNotRegistered(token);

        uint256 weiCost = gasAmount * maxFeePerGas + _postOpCost() * maxFeePerGas;
        return (weiCost * _tokenPrice(cfg)) / _tokenPriceDenominator();
    }
