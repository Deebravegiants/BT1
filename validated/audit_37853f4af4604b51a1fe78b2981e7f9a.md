### No vulnerability found for this question.

**Reasoning:** The documented, non-bypassable orchestration in `IntentsSDK.createWithdrawalIntents` passes a single `args.feeEstimation` object to both `bridge.validateWithdrawal(...)` and `bridge.createWithdrawalIntents(...)` in the same call, guaranteeing the two computations use identical UTXO fee fields. [1](#0-0) 

The scenario in the question requires a caller to bypass this orchestration entirely and invoke `OmniBridge.validateWithdrawal` and `OmniBridge.createWithdrawalIntents` directly as two independent calls, deliberately supplying a mutated `feeEstimation` with different `utxoMaxGasFee`/`utxoProtocolFee` values between the two calls. [2](#0-1) [3](#0-2) 

Per the audit rules, findings that require "the integrator to deliberately misuse a documented escape hatch" are explicitly out of scope. Directly invoking the two lower-level bridge methods with inconsistent fee data — rather than going through the SDK's `createWithdrawalIntents` (which enforces a single shared `feeEstimation` for both validation and intent construction) — is exactly this kind of deliberate API misuse, not an exploit reachable from an unprivileged attacker's normal inputs (`assetId`, `destinationAddress`, `routeConfig`, etc.) through the documented flow. There is no code path in this repo where an ordinary user's inputs alone cause `validateWithdrawal` and `createWithdrawalIntents` to be invoked with differing `feeEstimation` objects.

	async createWithdrawalIntents(args: {
		withdrawalParams: WithdrawalParams;
		feeEstimation: FeeEstimation;
		referral?: string;

			args.withdrawalParams.assetId,
			args.withdrawalParams.routeConfig,

		assert(
			assetInfo !== null,
			`Asset ${args.withdrawalParams.assetId} is not supported by Omni Bridge`,
		);
		const omniChainKind = caip2ToChainKind(assetInfo.blockchain);
		assert(
			omniChainKind !== null,
			`Chain ${assetInfo.blockchain} is not supported by Omni Bridge`,
		);

		const intents: IntentPrimitive[] = [];

		if (args.feeEstimation.quote !== null) {
			intents.push({
				intent: "token_diff",
				diff: {
					[args.feeEstimation.quote.defuse_asset_identifier_in]:
						`-${args.feeEstimation.quote.amount_in}`,
					[args.feeEstimation.quote.defuse_asset_identifier_out]:
						args.feeEstimation.quote.amount_out,
				},
				referral: args.referral,
			});
		}
		intents.push(
			...createWithdrawIntentsPrimitive(
				deriveOmniWithdrawIntentParams({
					assetId: args.withdrawalParams.assetId,
					destinationAddress: args.withdrawalParams.destinationAddress,
					actualAmount: args.withdrawalParams.amount,
					omniChainKind,
					intentsContract: this.envConfig.contractID,
					feeEstimation: args.feeEstimation,
				}),
			),
		);

		return Promise.resolve(intents);
	}
