### Title
Unauthenticated "Magic" Operator QR-Code Triggers Privileged Device Reconfiguration (WiFi Credential Reset / Mirror Calibration Reset) - (File: src/plans/qr_scan/operator.rs, src/plans/mod.rs)

### Summary
The Orb accepts a special "magic" QR-code format (`magic_action:reset_wifi_credentials` / `magic_action:reset_mirror_calibration`) during the operator QR-code scanning step and executes privileged device-reconfiguration actions immediately, without any authentication, backend verification, or operator-authorization check.

### Finding Description
During QR scanning, an operator QR-code is parsed by `qr_scan::operator::Data::try_parse`, which recognizes a `MAGIC_QR_CODE` regex pattern (`magic_action:<action>`) in addition to normal operator QR-codes, resolving to `Data::MagicResetWifi` or `Data::MagicResetMirror`: [1](#0-0) 

The result is dispatched in `handle_magic_operator_qr_code`, which — for the two magic variants — directly invokes `reset_mirror_calibration` or `reset_wifi_and_ensure_network` and returns `Ok(None)`, **before** `verify_operator_qr_code` (the function that calls the backend to validate that the scanned code belongs to a legitimate, authorized operator) is ever invoked: [2](#0-1) 

Compare this to the normal operator QR-code path, where `Data::Normal(qr_code)` is only accepted after backend validation via `verify_operator_qr_code`, which checks `Status.valid` and location data returned from the backend: [3](#0-2) [4](#0-3) 

This asymmetry means the "magic" actions — which reconfigure device state — bypass the very authorization mechanism ("who is calling") that legitimate operator actions must pass through. Both call sites in `scan_initial_qr_codes` and `scan_remaining_qr_codes` invoke `handle_magic_operator_qr_code` on **any** scanned code before backend verification: [5](#0-4) [6](#0-5) 

The privileged actions themselves are non-trivial: `reset_mirror_calibration` overwrites the on-disk calibration file and mirror actuator configuration, [7](#0-6)  and `reset_wifi_and_ensure_network` tears down the current network connection and re-triggers WiFi (re-)provisioning via QR: [8](#0-7) 

This directly parallels the reported bug class: a state-mutating "initialization"/configuration function that lacks a check on who is permitted to invoke it, allowing any party who can present input (here, a QR code to the camera, analogous to any transaction sender calling an unprotected `initialize()`) to trigger privileged reconfiguration.

### Impact Explanation
Anyone able to present a QR code to the Orb's camera during the operator-scan phase (which precedes any authentication of the operator) can force a WiFi credential/network reset or wipe the mirror calibration, without being a registered/authorized operator. Repeatedly triggering `MagicResetWifi` can be used to disrupt orb availability (denial of service by forcing repeated network drops/reprovisioning) or, combined with a malicious WiFi QR-code, to redirect the Orb onto an attacker-controlled network mid-operation. Forcing `MagicResetMirror` degrades the Orb's calibration and can impair biometric capture. This does not on its own leak biometric data or forge attestation, but it violates the intended trust boundary in which only an operator-verified QR-code should be able to mutate persistent device configuration state.

### Likelihood Explanation
High: no secret, signature, or backend check gates the magic QR-code parsing or dispatch; the regex accepts a fixed, publicly-known string format (`magic_action:reset_wifi_credentials`, `magic_action:reset_mirror_calibration`), so any person capable of generating a QR code and presenting it to the orb's camera during the idle/operator-scan loop can trigger these actions repeatedly.

### Recommendation
Require the same backend-verified operator authorization for magic QR-code actions as for normal operator QR-codes before executing `reset_mirror_calibration` / `reset_wifi_and_ensure_network` — i.e., move the `MagicResetWifi`/`MagicResetMirror` handling to occur only after `verify_operator_qr_code` succeeds (or embed a signed/backend-checked token in the magic QR payload), and add rate-limiting/audit logging for these state-mutating actions to reduce the impact of DoS-style abuse in the interim.

### Proof of Concept
1. Generate a QR code containing the plaintext string `magic_action:reset_wifi_credentials` (or `magic_action:reset_mirror_calibration`).
2. Present it to the Orb during idle/operator QR-scan phase (`scan_initial_qr_codes` or `scan_remaining_qr_codes`).
3. `qr_scan::operator::Data::try_parse` matches the `MAGIC_QR_CODE` regex and returns `Data::MagicResetWifi`/`Data::MagicResetMirror`.
4. `handle_magic_operator_qr_code` executes `reset_wifi_and_ensure_network`/`reset_mirror_calibration` immediately and returns `Ok(None)` — no backend call to `operator_status::request` (i.e., no operator authentication) ever occurs for this branch.
5. The device's network state or mirror calibration is mutated by an unauthenticated party.

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)

                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }

    /// Checks if `qr_code` is a valid operator QR-code through the backend.
    #[allow(clippy::cast_possible_truncation)]
    async fn verify_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: &qr_scan::user::Data,
        qr_capture_start: Instant,
    ) -> Result<Option<(u64, backend::operator_status::LocationData)>> {
        if qr_code.signup_extension() || self.operator_qr_code_override.is_some() {
            return Ok(Some((0, backend::operator_status::LocationData {
                team_operating_country: "DEV".to_string(),
                session_coordinates: Coordinates { latitude: 0.0f64, longitude: 0.0f64 },
                stationary_location_coordinates: None,
            })));
        }
        let http_start = Instant::now();
        match backend::operator_status::request(qr_code).await {
            Ok(backend::operator_status::Status { valid: true, location_data, reason: _ }) => {
                let location_data = location_data
                    .expect("to always have a result from the backend if valid == true");
                orb.ui.qr_scan_success(QrScanSchema::Operator);
                dd_incr!("main.count.global.distr_code_validated");
                tracing::info!("Operator QR-code validated: {qr_code:?}");
                dd_timing!("main.time.signup.distr_qr_code_capture", qr_capture_start);
                return Ok(Some((http_start.elapsed().as_millis() as u64, location_data)));
            }
            Ok(backend::operator_status::Status { valid: false, .. }) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
                dd_incr!("main.count.signup.result.failure.distr_qr_code", "type:invalid_qr");
            }
            Err(_) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
            }
        }
        Ok(None)
    }

/// Makes a validation request.
pub async fn request(qr_code: &qr_scan::user::Data) -> Result<Status> {
    let request = super::client()?
        .get(format!(
            "{}/api/v1/distributor/{}/orb/{}/status",
            *SIGNUP_BACKEND_URL, qr_code.user_id, *ORB_ID
        ))
        .basic_auth(&*ORB_ID, Some(get_orb_token()?));
    let status: Status = match request.send().await?.error_for_status() {
        Ok(response) => response.json().await?,
        Err(err) => {
            tracing::error!("Received error response {err:?}");
            return Err(err.into());
        }
    };
    if !status.valid {
        tracing::info!(
            "Operator QR-code invalid: {qr_code:?}, reason: {:?}",
            status.reason.as_deref().unwrap_or("<empty>")
        );
        return Ok(status);
    }
    if status.location_data.is_none() {
        tracing::error!("Operator location data are missing");
        return Ok(Status {
            valid: false,
            location_data: None,
            reason: Some("Operator location data are missing".to_string()),
        });
    }
    Ok(status)
}
