### No vulnerability found for this question.

**Reasoning:** `deriveOmniWithdrawIntentParams` (and `OmniBridge.createWithdrawalIntents`) do not re-fetch fee data from `omniBridgeAPI.getFee` at all — they consume the `feeEstimation` object passed in by the caller directly, deriving both `amount` (`amount += utxoMaxGasFee + utxoProtocolFee`) and `msg` (`JSON.stringify({MaxGasFee: utxoMaxGasFee.toString()})`) from the same single object instance in the same function call. [1](#0-0) 

There is no internal timing window or second network fetch between "what the user was shown" and "what gets signed" inside the SDK: `IntentsSDK.createWithdrawalIntents` and `OmniBridge.createWithdrawalIntents` both simply forward the caller-supplied `args.feeEstimation` straight into `deriveOmniWithdrawIntentParams`. [2](#0-1) [3](#0-2) 

The documented contract of `deriveOmniWithdrawIntentParams`/`estimateWithdrawalFee` is explicit: `estimateWithdrawalFee` computes a `FeeEstimation` once, and the caller must pass that exact object back into `createWithdrawalIntents` to sign consistent numbers. [4](#0-3) 

For the divergence the question describes to occur, the same caller (the party invoking both `estimateWithdrawalFee` and `createWithdrawalIntents`) would have to construct or substitute a different `feeEstimation` object for the second call than the one it displayed from the first — i.e., deliberately misuse the documented API contract of passing through the same estimation object. This is not an unprivileged remote attacker manipulating a victim's transaction; it's the same account acting on its own funds and its own displayed values, which falls under "deliberately misuse a documented escape hatch" and out-of-scope self-inflicted mismatches per the rules. `validateWithdrawal`'s separate `getFee` call is used only for UTXO-availability/min-amount checks, not to derive the signed `amount`/`msg`, so it introduces no exploitable divergence either. [5](#0-4)

	async createWithdrawalIntents(args: {
		withdrawalParams: WithdrawalParams;
		feeEstimation: FeeEstimation;
		referral?: string;
	}): Promise<IntentPrimitive[]> {
		const assetInfo = this.makeAssetInfo(
			args.withdrawalParams.assetId,
			args.withdrawalParams.routeConfig,
		);
		assert(
			assetInfo !== null,
			`Asset ${args.withdrawalParams.assetId} is not supported by Omni Bridge`,
		);
		const omniChainKind = caip2ToChainKind(assetInfo.blockchain);
		assert(
			omniChainKind !== null,
			`Chain ${assetInfo.blockchain} is not supported by Omni Bridge`,
		);

		const intents: IntentPrimitive[] = [];

		if (args.feeEstimation.quote !== null) {
			intents.push({
				intent: "token_diff",
				diff: {
					[args.feeEstimation.quote.defuse_asset_identifier_in]:
						`-${args.feeEstimation.quote.amount_in}`,
					[args.feeEstimation.quote.defuse_asset_identifier_out]:
						args.feeEstimation.quote.amount_out,
				},
				referral: args.referral,
			});
		}
		intents.push(
			...createWithdrawIntentsPrimitive(
				deriveOmniWithdrawIntentParams({
					assetId: args.withdrawalParams.assetId,
					destinationAddress: args.withdrawalParams.destinationAddress,
					actualAmount: args.withdrawalParams.amount,
					omniChainKind,
					intentsContract: this.envConfig.contractID,
					feeEstimation: args.feeEstimation,
				}),
			),
		);

		return Promise.resolve(intents);
	}
