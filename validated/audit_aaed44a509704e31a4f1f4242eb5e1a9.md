### Title
Unauthenticated "magic" QR code allows WiFi credential reset and mirror recalibration without operator verification - (File: src/plans/qr_scan/operator.rs)

### Summary
`Data::try_parse` in `src/plans/qr_scan/operator.rs` accepts any locally-matching `magic_action:reset_wifi_credentials` / `magic_action:reset_mirror_calibration` string and yields `Data::MagicResetWifi` / `Data::MagicResetMirror`. In `src/plans/mod.rs`, `handle_magic_operator_qr_code` executes `reset_wifi_and_ensure_network` (calling `network::reset()`) or `reset_mirror_calibration` immediately upon detecting these variants, and critically this happens *before* `verify_operator_qr_code` is ever invoked, meaning no backend authorization of the presenter occurs.

### Finding Description
The QR-code parsing for the operator schema is purely local/regex-based: `MAGIC_QR_CODE` matches `magic_action:<action>` and maps known actions to `Data::MagicResetWifi`/`Data::MagicResetMirror` with no signature, token, or backend check [1](#0-0) .

Both call sites that scan for an operator QR code — `scan_initial_qr_codes` (self-serve mode, run at the very start of the flow, before any operator identity is established) and the fallback branch of `scan_remaining_qr_codes` (triggered whenever the previous operator QR has expired or none is cached) — invoke `handle_magic_operator_qr_code` *before* calling `verify_operator_qr_code`, which is the function that actually performs backend authorization of a legitimate operator badge [2](#0-1) [3](#0-2) .

`handle_magic_operator_qr_code` executes the reset action unconditionally as soon as the magic variant is detected, with no operator authentication gate: for `MagicResetMirror` it calls `self.reset_mirror_calibration(orb)`, and for `MagicResetWifi` it calls `self.reset_wifi_and_ensure_network(orb)` [4](#0-3) . `reset_wifi_and_ensure_network` calls `network::reset()`, which shells out to `wpa-supplicant-interface restore-default-config` followed by `reconfigure`, wiping stored WiFi credentials and forcing a reconnect [5](#0-4) . `reset_mirror_calibration` overwrites the calibration file and re-applies default mirror calibration to hardware [6](#0-5) .

Because these actions are dispatched purely from the locally-parsed QR string with no round-trip to the backend to confirm the presenter is an authorized operator (unlike `Data::Normal`, which is passed on to `verify_operator_qr_code` for backend validation), any person able to place a QR code in front of the camera at a point where the Orb is waiting for an operator QR code can trigger these privileged resets.

### Impact Explanation
An unprivileged bystander can force a WiFi credential wipe (denial of service / requiring the Orb to obtain new network configuration, potentially interruptable to redirect the device to an attacker-controlled network via a subsequently presented WiFi QR code) or force a mirror recalibration, without ever being authenticated as an operator. This is a scoped availability/configuration-integrity impact on the physical device rather than a direct biometric data disclosure or forged-enrollment path, but it does violate the intended invariant that operator actions require backend-verified operator identity, and could be used to degrade device availability or manipulate network configuration ahead of a MITM-style follow-up.

### Likelihood Explanation
Highly feasible and repeatable: the trigger is a static, publicly-known/derivable text string encoded as a QR code (`magic_action:reset_wifi_credentials`), requiring no secrets, tokens, or operator credentials. It is reachable at the very start of the self-serve flow and whenever the cached operator QR has expired mid-flow (`scan_remaining_qr_codes`), which occurs regularly during normal kiosk operation.

### Recommendation
Gate `MagicResetWifi`/`MagicResetMirror` handling behind the same backend operator verification path used for `Data::Normal` (i.e., only accept magic actions when embedded within, or accompanying, an already backend-verified operator QR code/session), or require an additional out-of-band authenticated signal (e.g., signed magic-action payload verified against a backend-issued key) before executing `network::reset()` or `reset_mirror_calibration`.

### Proof of Concept
Integration test plan:
1. In a test harness that stubs `orb.ui`, `network::reset()`, and `Orb::recalibrate`, call `Plan::handle_magic_operator_qr_code` directly with `qr_scan::operator::Data::MagicResetWifi` without any prior call to `verify_operator_qr_code`.
2. Assert that `network::reset()` (or a mockable equivalent) is invoked and returns success — demonstrating the reset happens with zero backend authorization calls.
3. Repeat for `Data::MagicResetMirror`, asserting `reset_mirror_calibration` runs and overwrites `CALIBRATION_FILE_PATH`.
4. Expected (fixed) behavior: the call should be rejected or queued pending a subsequent `verify_operator_qr_code`/backend authorization success; currently it is unconditionally executed as shown at `src/plans/mod.rs:988-1007`.

static MAGIC_QR_CODE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")
});

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
