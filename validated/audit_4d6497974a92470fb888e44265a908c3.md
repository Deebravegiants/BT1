### Title
`ShopifyAPI::Auth::TokenExchange.exchange_token` sends the app's `client_secret` to an unsanitized shop host derived from the JWT `dest` claim - ([File: lib/shopify_api/auth/token_exchange.rb])

### Summary
Every other credential-exchange helper in this gem (`ClientCredentials.client_credentials`, `RefreshToken.refresh_access_token`, `TokenExchange.migrate_to_expiring_token`) passes the caller-supplied `shop` string through `Utils::ShopValidator.sanitize!` before using it to build the HTTPS host that receives `client_secret`. `TokenExchange.exchange_token` is the one exception: it takes `dest_shop = jwt_payload.shop` straight from the JWT and never runs it through `ShopValidator`, then uses it verbatim as the request host that receives the app's `client_id`/`client_secret`.

### Finding Description
`JwtPayload#shop` is computed as `@dest.gsub("https://", "")` with no format or domain-membership check [1](#0-0) . `TokenExchange.exchange_token` uses this raw value directly to build `shop_session = ShopifyAPI::Auth::Session.new(shop: dest_shop)` and then constructs an `HttpClient` from that session [2](#0-1) . Inside `HttpClient#initialize`, the session's `shop` field is interpolated directly into the request base URI: `@base_uri = "https://#{api_host || session.shop}"` [3](#0-2) , and the POST body sent to that URI includes `client_secret: ShopifyAPI::Context.api_secret_key` [4](#0-3) .

Compare this to the three sibling flows, which all sanitize the shop first: `Utils::ShopValidator.sanitize!(shop)` in `ClientCredentials.client_credentials` [5](#0-4) , in `RefreshToken.refresh_access_token` [6](#0-5) , and in `TokenExchange.migrate_to_expiring_token` [7](#0-6) . `ShopValidator.sanitize!` enforces that the host resolves to one of the `TRUSTED_SHOPIFY_DOMAINS` (`myshopify.com`, `shopify.com`, `myshopify.io`, `spin.dev`, `shop.dev`) via `Addressable::URI` parsing [8](#0-7) .

The identity binding that breaks is: `host verified as legitimate merchant domain` should equal `host that receives the app's client_secret`. In `exchange_token`, the left-hand side check simply doesn't exist — the raw `dest` string, after only a literal `"https://"` string strip, is trusted as the host and handed to `HttpClient`, which builds a URI by naive string interpolation rather than structured URI parsing. A `dest` value that is not a clean bare hostname (e.g. containing userinfo syntax like `legit-shop.myshopify.com@evil.example`, or an `http://` scheme that the `gsub` doesn't strip, or path/query artifacts) is used verbatim as `https://<dest_shop>/admin/oauth/access_token`, which the interpolation-based `@base_uri` does not validate as a well-formed single host the way `ShopValidator.sanitize!` + `Addressable::URI` would.

### Impact Explanation
If `dest_shop` can ever contain anything other than a clean `*.myshopify.com`-style hostname when reaching `exchange_token` (e.g. via non-standard identity providers, proxy/CDN normalization quirks, or any component upstream that forwards a session token whose `dest` claim is not a strictly-formed bare host), the gem will POST the app's `client_id` and `client_secret` to a host that was never checked against `TRUSTED_SHOPIFY_DOMAINS`. This is credential leakage of the app's `client_secret` to an unintended host — the same class of impact the recommendations list as High (credential leakage / SSRF carrying the app's credentials).

### Likelihood Explanation
This code path runs on every call to `TokenExchange.exchange_token`, which is the primary, documented entry point for Shopify's token-exchange authentication flow for embedded apps [9](#0-8) . The missing sanitization is deterministic and not a race condition — it fires on every invocation, unlike the three sibling methods that all correctly call `ShopValidator.sanitize!` first, showing the intended pattern was simply omitted here.

### Recommendation
Sanitize `dest_shop` the same way the other three OAuth/token-exchange helpers do, before it is used to build the session/HTTP client:

```ruby
jwt_payload = ShopifyAPI::Auth::JwtPayload.new(session_token)
dest_shop = Utils::ShopValidator.sanitize!(jwt_payload.shop)
...
shop_session = ShopifyAPI::Auth::Session.new(shop: dest_shop)
```

### Proof of Concept
1. Obtain/craft a session token whose decoded `dest` claim is not a clean bare hostname, e.g. `dest: "https://legit-shop.myshopify.com@evil.example"`.
2. Call `ShopifyAPI::Auth::TokenExchange.exchange_token(session_token: token, requested_token_type: ...)`.
3. `JwtPayload#shop` strips only the literal `"https://"` prefix, yielding `dest_shop = "legit-shop.myshopify.com@evil.example"` [1](#0-0) .
4. `HttpClient` builds `@base_uri_and_path = "https://legit-shop.myshopify.com@evil.example/admin/oauth" ...` and the POST request (containing `client_id`/`client_secret`) is issued against this URI via `HTTParty` [10](#0-9) , in contrast to `ClientCredentials`/`RefreshToken`/`migrate_to_expiring_token`, which would reject this same value at `ShopValidator.sanitize!` before ever reaching `HttpClient`.

          end

          client = Clients::HttpClient.new(session: shop_session, base_path: "/admin/oauth")

        [
          "shopify.com",
          "myshopify.io",
          "myshopify.com",
          "spin.dev",
          "shop.dev",
        ].freeze,
        T::Array[String],

      class << self
        extend T::Sig

        sig do
          params(
            shop_domain: String,
            myshopify_domain: T.nilable(String),
          ).returns(T.nilable(String))
        end
        def sanitize_shop_domain(shop_domain, myshopify_domain: nil)
          uri = uri_from_shop_domain(shop_domain, myshopify_domain)
          return nil if uri.nil? || uri.host.nil? || uri.host.empty?

          trusted_domains(myshopify_domain).each do |trusted_domain|
            host = T.cast(uri.host, String)
            uri_domain = uri.domain
            next if uri_domain.nil?

            no_shop_name_in_subdomain = host == trusted_domain
            from_trusted_domain = trusted_domain == uri_domain

            if unified_admin?(uri) && from_trusted_domain
              return myshopify_domain_from_unified_admin(uri)
            end
            return nil if no_shop_name_in_subdomain || host.empty?
            return host if from_trusted_domain
          end
          nil
        end
