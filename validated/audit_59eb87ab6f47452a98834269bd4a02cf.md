Audit Report

## Title
Unauthenticated access to LOOP plugin pprof/metrics proxy endpoints allows unprivileged remote profiling and DoS - ([File: core/web/router.go])

## Summary
The `loopRoutes` handlers, which proxy pprof and Prometheus metrics requests to LOOP plugin subprocesses, are registered on the base API router group without any authentication middleware, unlike the functionally similar `debugRoutes` which explicitly requires `auth.Authenticate`. This allows any unauthenticated network client reaching the node's HTTP API to enumerate plugins and trigger expensive profiling operations on internal plugin processes.

## Finding Description
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` router group with no `auth.Authenticate` wrapper, called alongside other route registration functions in `NewRouter` [1](#0-0) . In contrast, `debugRoutes` — serving the comparable `/debug/vars` capability — is explicitly wrapped with session authentication [2](#0-1) . The `loopRoutes` definition itself confirms no auth group is applied: [3](#0-2) . The handlers forward attacker-controlled query parameters (`debug`, `gc`, `seconds`) and POST bodies to an internal plugin's `/debug/pprof/*` endpoints and return the raw response, with the `seconds` value directly setting the request timeout/profiling duration [7](#0-6) . The `pluginPPROFPOSTSymbolHandler` similarly forwards raw unauthenticated request bodies to the plugin [6](#0-5) . Only the `/query` GraphQL endpoint and `v2Routes`/`AuthenticationProvider().ExtendRouter` paths receive explicit auth wrapping in `NewRouter`; `loopRoutes` is not one of them [8](#0-7) .

## Impact Explanation
An unauthenticated client reaching the node's HTTP API port can enumerate registered LOOP plugins via `/discovery` and `/plugins/:name/metrics` (information disclosure of internal plugin topology), and can trigger CPU/goroutine/heap profiling via `/plugins/:name/debug/pprof/*` with an attacker-controlled `seconds` duration, causing sustained load on the plugin process without any session or token. This is a genuine authentication-bypass-class issue (missing auth middleware on a sensitive route inconsistent with the equivalent `debugRoutes` protection), mapping to the "node API authentication bypass" impact category, with a secondary availability/DoS effect from repeated profiling requests.

## Likelihood Explanation
No credentials, session, or API token are required; any client capable of sending HTTP requests to the node's WebServer port can invoke these routes. Likelihood is dependent on network exposure of the node's API port, which is a supported/common deployment configuration, and the request is trivially repeatable.

## Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token-based) middleware used for `debugRoutes`, and/or gate access via `auth.RequiresAdminRole` given the sensitivity of profiling/metrics-proxying to internal plugin processes. Additionally validate/bound the `seconds` parameter and apply stricter rate limiting to this route group.

## Proof of Concept
```
# No cookie, no API token/secret required
curl -s "http://<node-host>:6688/discovery"
curl -s "http://<node-host>:6688/plugins/<plugin-name>/metrics"
curl -s "http://<node-host>:6688/plugins/<plugin-name>/debug/pprof/profile?seconds=60"
```
These requests succeed without authentication because `loopRoutes` (`core/web/router.go:230-236`) is mounted on the unauthenticated `api` group in `NewRouter` (`core/web/router.go:87-91`), unlike `debugRoutes` (`core/web/router.go:180-183`), which is the direct comparable route requiring session authentication.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
