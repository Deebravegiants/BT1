The strongest analog I found in `orb-core--013` is the operator "magic QR-code" handling, which executes privileged reset actions with no authentication of the QR-code's origin — directly analogous to the "no entry check" pattern in the report (unprivileged caller can trigger an administrative action just by supplying the right input value).

### Title
Unauthenticated "magic" QR-codes can trigger WiFi and mirror-calibration resets before operator verification - (File: `src/plans/mod.rs`, `src/plans/qr_scan/operator.rs`)

### Summary
The operator QR-code schema recognizes two "magic" actions, `magic_action:reset_wifi_credentials` and `magic_action:reset_mirror_calibration`, matched purely by a regex against the scanned string [1](#0-0) . `handle_magic_operator_qr_code` executes `reset_mirror_calibration` or `reset_wifi_and_ensure_network` for these variants immediately, without ever calling the backend-based `verify_operator_qr_code` check that normal operator QR-codes go through [2](#0-1) .

### Finding Description
In both call sites, `scan_initial_qr_codes` and `scan_remaining_qr_codes`, the flow is: scan operator QR-code → `handle_magic_operator_qr_code` → (only for `Normal` variant) `verify_operator_qr_code`. For the magic variants, the function returns `Ok(None)` right after running the reset action, so `verify_operator_qr_code` — the only step that calls the backend to confirm the scanned code belongs to a legitimate, registered operator — is never reached [3](#0-2) [4](#0-3) . This means any string matching `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration`, shown to the orb's camera by anyone (not just a vetted operator), is sufficient to trigger these administrative actions — there is effectively no entry check tying the action to an authorized operator identity, matching the report's "no entry check / trivial entry check" bug class.

### Impact Explanation
- `MagicResetWifi` calls `network::reset()` (restores default wpa_supplicant config, forces disconnection) and then re-enters the WiFi-provisioning flow which subsequently accepts a new WiFi QR-code (MECARD credentials) [5](#0-4) [6](#0-5) . An unauthorized person could force the orb offline and, depending on operational deployment, potentially get the orb to join a network of their choosing via a follow-up crafted MECARD QR-code — a network-level trust/availability issue.
- `MagicResetMirror` invalidates the current mirror calibration and forces recalibration [7](#0-6) , which can degrade signup/biometric capture quality (denial of service against biometric enrollment, and analogous to the report's "giving wrong rates" concern).
- Both are triggerable purely by regex match on a scanned string, with no cryptographic signature or backend authorization check comparable to the checks applied for normal operator/user QR-codes.

### Likelihood Explanation
Likelihood is moderate: it requires physical/camera proximity to the orb (same threat model as any QR-scan-based attack against this device), but no credentials, no backend access, and no special privileges — any bystander who knows the magic string can trigger it. This is a lower bar than the normal operator flow, which requires backend-side validation of a real operator identity.

### Recommendation
Route magic QR-code actions through the same operator-verification step (`verify_operator_qr_code`) used for normal operator codes before executing `reset_mirror_calibration` or `reset_wifi_and_ensure_network`, or otherwise cryptographically bind the magic action to an authenticated operator session so an arbitrary bystander cannot trigger administrative resets.

### Proof of Concept
Source-review PoC: present a QR-code encoding the literal string `magic_action:reset_wifi_credentials` (or `magic_action:reset_mirror_calibration`) to the orb's camera during the idle/operator-scan phase. `qr_scan::operator::Data::try_parse` matches it via `MAGIC_QR_CODE` regex [8](#0-7) , and `handle_magic_operator_qr_code` executes the reset immediately, with no operator-identity verification performed at any point in that code path [9](#0-8) .

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }
