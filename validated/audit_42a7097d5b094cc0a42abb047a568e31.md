### Title
Permissionless "relayer" path in `pallet-whitelist` permanently consumes a deferred governance call even when the inner dispatch fails, allowing an unprivileged account to grief an approved-but-not-yet-executed governance action - (File: `substrate/frame/whitelist/src/lib.rs`)

### Summary
This repository's `pallet-whitelist` has been extended with a `DeferredDispatch` mechanism that is not present in the upstream Substrate whitelist pallet. It lets a privileged origin (`DispatchWhitelistedOrigin`, typically root/governance) defer a call, and then lets **any signed account** relay/execute it once it is separately whitelisted. The relay path (`clean_and_dispatch`) unconditionally removes the whitelist entry, the preimage request, and the deferred-dispatch entry **before** checking whether the inner call actually succeeded, exactly mirroring the root cause pattern of the referenced report ([H-27]): a caller that does not gate cleanup/state-finalization on the inner call's success, so a failed inner call still leaves the operation permanently "consumed" with no path to retry it.

### Finding Description
`dispatch_whitelisted_call` and `dispatch_whitelisted_call_with_preimage` both delegate to `Self::clean_and_dispatch`: [1](#0-0) 

`clean_and_dispatch` removes `WhitelistedCall`, un-requests the preimage, and removes the `DeferredDispatch` entry unconditionally, then dispatches the call and only records the `Result` in an event - it never reverts, retries, or re-adds any of the removed state if `call.dispatch(...)` returns `Err`: [2](#0-1) 

The entry point that allows an **unprivileged, signed** account to trigger this cleanup+dispatch is `ensure_signed_deferred_dispatch`, reached via the `Err(dispatch_origin)` branch of `dispatch_whitelisted_call`/`dispatch_whitelisted_call_with_preimage`: [3](#0-2) [4](#0-3) 

The only guards on the signed "relayer" are (a) a deferred entry must exist, (b) it must not have expired, and (c) the call hash must still be whitelisted - there is no check that the inner call will actually succeed, and the relayer pays no fee (`Pays::No`): [5](#0-4) 

The pallet's own test suite documents this exact behavior - the deferred entry is consumed and the whitelist/preimage state is cleaned up **regardless of whether the inner call succeeds**: [6](#0-5) 

This is the same root-cause shape as [H-27]: a component that performs an inner call/dispatch and does not gate "mark as done / clean up state" on the inner call's success, so a failed execution still permanently forecloses future retries.

### Impact Explanation
Once `WhitelistOrigin` (e.g. a Fellowship/whitelisted-caller track) whitelists a deferred call hash, **any signed account** — not just the intended relayer — can call `dispatch_whitelisted_call`/`dispatch_whitelisted_call_with_preimage` with that hash. If the call is executed at a time/state where it would fail (for example a call whose success depends on preconditions not yet met, or is misconfigured such that `Root` origin cannot satisfy it, as the pallet's own `test_deferred_dispatch_failed_inner_call` demonstrates with `remark_with_event`), the relay still:
- permanently removes the `WhitelistedCall` entry,
- un-requests/potentially destroys the preimage record,
- removes the `DeferredDispatch` entry,
- and pays the relayer nothing (no economic disincentive).

The net effect is that a governance-approved action is silently discarded rather than executed, and cannot be retried without redoing the entire governance approval flow (`WhitelistOrigin::whitelist_call` + `DispatchWhitelistedOrigin::dispatch_whitelisted_call` to re-defer). This is a griefing/DoS on approved governance actions rather than a direct loss of user funds (unlike the Arbitrum bridge-agent bug where user deposits were locked); the impact severity here is best understood as denial-of-service against on-chain governance execution, confirmed by the pallet's own tests to be current, intended-but-unsafe behavior.

`pallet_whitelist` is wired into real, in-scope runtimes, not just test mocks, which makes this a live surface: `polkadot/runtime/rococo/src/governance/mod.rs`, `cumulus/parachains/runtimes/assets/asset-hub-westend/src/governance/mod.rs`, `substrate/bin/node/runtime/src/lib.rs`, and the staking-async runtimes.

### Likelihood Explanation
Moderate-to-low. Exploitation requires:
1. Governance to have already deferred a call (`Root`/`DispatchWhitelistedOrigin`) and separately whitelisted it (`WhitelistOrigin`) — both are normal governance operations, not an attacker action.
2. The attacker to know the call's hash, encoded length, and weight witness (or the encoded call itself for the preimage variant) — these are public since the deferred call's hash is emitted in `DispatchDeferred`, and the preimage must be noted publicly (via `pallet-preimage::note`, itself permissionless) for anyone to relay it at all.
3. A window where the call would fail if executed early/at the wrong time, or is simply structurally guaranteed to fail once dispatched as `Root` (as the pallet's `remark_with_event` test case shows can happen even without malice).

Because the relay call is completely open to any signed account and costs the relayer nothing (`Pays::No`), any attacker who is simply monitoring on-chain events for whitelisted deferred calls can race legitimate relayers to submit the relay transaction at a moment they know (or suspect) will cause failure, at zero cost and with no penalty for being wrong.

### Recommendation
- In `clean_and_dispatch`, only remove `WhitelistedCall`/un-request the preimage/remove `DeferredDispatch` after confirming the inner call dispatched successfully, or provide an explicit re-arm/retry path (analogous to `retryDeposit`/`retrieveDeposit` in the referenced bridge) so a failed relay does not permanently destroy the governance-approved action.
- Consider restricting who can act as the "relayer" (e.g. requiring the relayer to also be `DispatchWhitelistedOrigin`-approved, or requiring a bond/fee on relay that is only refunded on success) to remove the zero-cost griefing vector introduced by allowing any signed account to trigger consumption of a deferred, whitelisted call.
- At minimum, gate cleanup of `WhitelistedCall`/`DeferredDispatch` on `result.is_ok()` so a failed dispatch leaves the entry available for another relay attempt within the expiration window.

### Proof of Concept
The pallet's own existing test already demonstrates the unsafe behavior end-to-end (state cleaned up despite `Err(BadOrigin)` on the inner dispatch): [7](#0-6) 

To demonstrate the griefing angle specifically, a background engineer should extend this test so that:
1. `WhitelistOrigin` whitelists a call that would succeed only under a specific precondition (e.g. a `pallet_balances::force_transfer` that requires a minimum source balance set by a *separate*, not-yet-executed governance call).
2. Before that precondition is satisfied, an unprivileged `signed` account (not the intended relayer) calls `dispatch_whitelisted_call`/`dispatch_whitelisted_call_with_preimage` with the known hash/len/weight, causing the inner call to fail.
3. Assert that `WhitelistedCall`/`DeferredDispatch`/preimage request are all gone afterward, and that the legitimate relayer's subsequent attempt now fails with `DeferredDispatchNotFound`/`CallIsNotWhitelisted`, proving the governance action was permanently discarded by an unprivileged party at no cost.

		pub fn dispatch_whitelisted_call(
			origin: OriginFor<T>,
			call_hash: T::Hash,
			call_encoded_len: u32,
			call_weight_witness: Weight,
		) -> DispatchResultWithPostInfo {
			let relayer = match T::DispatchWhitelistedOrigin::try_origin(origin) {
				Ok(_) if WhitelistedCall::<T>::contains_key(call_hash) => None,
				Ok(_) => {
					Self::defer_dispatch(call_hash)?;
					return Ok(Some(T::WeightInfo::defer_dispatch(0)).into());
				},
				Err(dispatch_origin) => {
					Some(Self::ensure_signed_deferred_dispatch(dispatch_origin, call_hash)?)
				},
			};

			let call_data = T::Preimages::fetch(&call_hash, Some(call_encoded_len))
				.map_err(|_| Error::<T>::UnavailablePreImage)?;

			let call = <T as Config>::RuntimeCall::decode_all_with_depth_limit(
				frame::deps::frame_support::MAX_EXTRINSIC_DEPTH,
				&mut &call_data[..],
			)
			.map_err(|_| Error::<T>::UndecodableCall)?;

			ensure!(
				call.get_dispatch_info().call_weight.all_lte(call_weight_witness),
				Error::<T>::InvalidCallWeightWitness
			);

			// Relayer isn't charged; the privileged direct path still pays.
			let pays_fee = if relayer.is_some() { Pays::No } else { Pays::Yes };

			let call_actual_weight = Self::clean_and_dispatch(call_hash, call);
			if let Some(who) = relayer {
				Self::deposit_event(Event::<T>::DeferredDispatchExecuted { call_hash, who });
			}

			let actual_weight = call_actual_weight.map(|w| {
				w.saturating_add(T::WeightInfo::dispatch_whitelisted_call(call_encoded_len))
			});
			Ok(PostDispatchInfo { actual_weight, pays_fee })
		}

	fn ensure_signed_deferred_dispatch(
		origin: T::RuntimeOrigin,
		call_hash: T::Hash,
	) -> Result<T::AccountId, DispatchError> {
		let who = ensure_signed(origin)?;

		let expire_at =
			DeferredDispatch::<T>::get(call_hash).ok_or(Error::<T>::DeferredDispatchNotFound)?;

		ensure!(
			T::BlockNumberProvider::current_block_number() < expire_at,
			Error::<T>::DeferredDispatchExpired
		);

		ensure!(WhitelistedCall::<T>::contains_key(call_hash), Error::<T>::CallIsNotWhitelisted);

		Ok(who)
	}

	/// Clean whitelisting/preimage and dispatch call.
	///
	/// Returns the inner call's actual weight.
	fn clean_and_dispatch(call_hash: T::Hash, call: <T as Config>::RuntimeCall) -> Option<Weight> {
		WhitelistedCall::<T>::remove(call_hash);
		T::Preimages::unrequest(&call_hash);
		DeferredDispatch::<T>::remove(call_hash);

		let result = call.dispatch(frame_system::Origin::<T>::Root.into());

		let call_actual_weight = match result {
			Ok(call_post_info) => call_post_info.actual_weight,
			Err(call_err) => call_err.post_info.actual_weight,
		};
		Self::deposit_event(Event::<T>::WhitelistedCallDispatched { call_hash, result });

		call_actual_weight
	}

#[test]
fn test_deferred_dispatch_failed_inner_call() {
	new_test_ext().execute_with(|| {
		// This call requires a signed origin, whitelisting dispatches calls with root.
		let call = RuntimeCall::System(frame_system::Call::remark_with_event { remark: vec![1] });
		let call_hash = <Test as frame_system::Config>::Hashing::hash_of(&call);
		let call_len = call.encoded_size() as u32;
		let encoded_call = call.encode();
		let call_weight = call.get_dispatch_info().call_weight;

		run_to_block(1);

		// Defer dispatch (no preimage yet)
		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::root(),
			call_hash,
			call_len,
			call_weight
		));

		assert!(events().iter().any(|event| {
			match event {
				Event::<Test>::DispatchDeferred { call_hash: hash } => hash == &call_hash,
				_ => false,
			}
		}));

		assert_ok!(Whitelist::whitelist_call(RuntimeOrigin::root(), call_hash));

		assert_ok!(Preimage::note(encoded_call.into()));

		assert!(Preimage::is_requested(&call_hash));

		// Try to dispatch with signed origin
		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::signed(1),
			call_hash,
			call_len,
			call_weight,
		));

		let emitted_events = events();

		assert!(emitted_events.iter().any(|event| {
			matches!(event, Event::<Test>::CallWhitelisted { call_hash: hash } if hash == &call_hash)
		}));

		// Dispatches with Root when executing whitelisted calls. However,
		// remark_with_event requires RawOrigin::Signed(_)
		assert!(emitted_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::WhitelistedCallDispatched {
					call_hash: hash,
					result: Err(DispatchErrorWithPostInfo { error: DispatchError::BadOrigin, .. })
				} if hash == &call_hash
			)
		}));

		// Even though the inner call failed, the deferred entry was still consumed by the relayer,
		// so `DeferredDispatchExecuted` is emitted regardless of the inner call's outcome.
		assert!(emitted_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::DeferredDispatchExecuted { call_hash: hash, who: 1 }
				if hash == &call_hash
			)
		}));
		assert!(!Preimage::is_requested(&call_hash));
	});
