### Title
Permanent market freeze: `accrue_step` panics on `i128` RAY-value overflow before the borrow-index cap engages - ([File: contracts/pool/src/interest.rs](contracts/pool/src/interest.rs))

### Summary
The binutils CVE-2020-35507 class is *crafted input → unhandled crash → denial of service*. In XOXNO Lending the analog is a state an unprivileged user can drive a market into where every subsequent call panics inside `accrue_step`: `scaled_to_original(borrowed, borrow_index)` overflows `i128` before `update_borrow_index` reaches its `MAX_BORROW_INDEX_RAY` clamp. Since every market verb accrues first via `interest::global_sync`, the panic permanently bricks the market — no withdraw, repay, borrow, or liquidation can ever execute again, trapping all supplier cash.

### Finding Description
`global_sync` runs `accrue_chunk` unconditionally at the top of every mutating pool operation [1](#0-0) . Each chunk computes `scaled_to_original(env, borrowed, borrow_index)` — a half-up `mul_div` that panics with `MathOverflow` when `borrowed * borrow_index` exceeds the `i128` domain [2](#0-1) . The safety clamp `MAX_BORROW_INDEX_RAY` (10^36) lives inside `update_borrow_index`, which runs *after* that multiplication — so for a sufficiently large `borrowed`, the RAY-value product overflows at a borrow index well below the cap. The protocol's own harness documents this: at ~98% utilization on the steep XLM curve with a whale-scale market, `update_indexes` starts failing after a few years and "the market freezes: no repay, no withdraw, no liquidation" [3](#0-2) . Index caps can be lifted and `max_utilization` permits such utilization on the steep segment; the panic is `MathOverflow` raised from `mul_div_*` on an unrepresentable product [4](#0-3) .

### Impact Explanation
Permanent freezing of funds: once `borrowed * borrow_index` crosses the `i128` representable bound, every entrypoint that loads the market's cache and accrues (`supply`, `withdraw`, `borrow`, `repay`, `seize`/`liquidate`, `update_indexes`, `claim_revenue`, `recapitalize`) reverts identically. Suppliers' cash and borrowers' collateral in that market are unrecoverable; liquidators cannot clear bad debt, so the market also drifts to insolvency.

### Likelihood Explanation
A single unprivileged address can set up the precondition: supply a very large amount (caps are governance-adjustable and can be lifted), have any account borrow to sustained high utilization on a steep rate curve, then call the permissionless `update_indexes`/`accrue` path over time. No privileged role, leaked key, or off-chain component is required; only a large token position and time. The protocol test suite reproduces the cliff at ~98% utilization within a 40-year horizon — sooner at higher sustained rates. Severity: High (permanent freeze reachable by unprivileged actor).

### Recommendation
Bound the accrual step's value domain, not just the index: when `borrowed * new_borrow_index` would exceed `i128`, clamp accrual (treat the step as at-cap and stop growing indexes) instead of letting `scaled_to_original` panic. Alternatively compute utilization via a saturating/`I256` path so `accrue_step` degrades gracefully, keeping `global_sync` non-panicking for any committed state.

### Proof of Concept
See `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap` in `tests/test-harness/tests/controller/large_positions_and_long_horizons.rs:321-361`: with caps lifted, supply ~`BILLION * 10^18` of an 18-decimal asset, borrow ~98% of it, advance time in yearly steps — `update_indexes` eventually returns `MathOverflow` while `borrow_index < MAX_BORROW_INDEX_RAY`, and subsequent `withdraw` and `repay` fail with the same error, demonstrating the freeze.

pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}

/// Applies one compound step of `delta_ms` to indexes and protocol revenue.
///
/// The arithmetic lives in [`accrue_step`], shared with the read-only
/// `simulate_update_indexes` so the view and the mutator cannot drift.
fn accrue_chunk(env: &Env, cache: &mut Cache, delta_ms: u64) {
    let step = accrue_step(
        env,
        cache.params(),
        cache.borrowed(),
        cache.supplied(),
        cache.borrow_index(),
        cache.supply_index(),
        delta_ms,
    );

    cache.set_borrow_index(step.borrow_index);
    cache.set_supply_index(step.supply_index);
    cache.accrue_revenue(step.revenue_shares);
}

/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);

/// Computes `floor(x * y / d)`, rounding toward negative infinity for a negative quotient.
/// Panics with `GenericError::DivisionByZero` if `d == 0`, or with
/// `GenericError::MathOverflow` if the result does not fit in `i128`.
pub fn mul_div_floor(env: &Env, x: i128, y: i128, d: i128) -> i128 {
    require_nonzero_divisor(env, d);
    if let Some(quotient) = x
        .checked_mul(y)
        .and_then(|product| div_floor_i128(product, d))
    {
        return quotient;
    }
    let (x256, y256, d256) = to_i256_operands(env, x, y, d);
    let nonneg = quotient_is_nonnegative(x, y, d);
    to_i128(env, &div_floor_i256(env, &x256.mul(&y256), &d256, nonneg))
}
