### Title
Unauthenticated LOOP Plugin Discovery, Metrics, and pprof Endpoints Expose Internal Debug Data - ([File: core/web/router.go])

### Summary
The Chainlink node web router registers the LOOP (Local Out Of Process) plugin discovery, metrics-proxy, and pprof-proxy endpoints (`/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) directly on the base `api` router group, which enforces only rate limiting and session-cookie parsing — no authentication is required to reach them. This mirrors the CVE-2017-4952 root cause: internal/utility endpoints lacking access controls, reachable by any unprivileged network client, resulting in information disclosure.

### Finding Description
In `NewRouter`, the `api` group is created with only a rate limiter and gin session middleware — it does not require an authenticated session or token: [1](#0-0) 

`loopRoutes(app, api)` is called directly against this unauthenticated `api` group: [2](#0-1) 

By contrast, the near-identical `metricRoutes` function (exposing native Go `net/http/pprof` for the node process itself) is deliberately wired only under the authenticated `authv2` group, with an explicit comment noting the intent: [3](#0-2) 

This shows the developers were aware that pprof/debug endpoints must be gated behind authentication, but the equivalent proxy handlers for LOOP plugins registered via `loopRoutes` were left on the unauthenticated group. The handlers themselves perform no additional authentication/authorization check of their own:
- `discoveryHandler` returns internal Prometheus service-discovery target groups, including internal hostnames/ports and the names of all registered LOOP plugins: [4](#0-3) 
- `pluginMetricHandler` proxies to the plugin's internal `/metrics` endpoint and returns the raw response body to the caller: [5](#0-4) 
- `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` proxy arbitrary `debug/pprof/*` paths (profile, heap, goroutine, trace, symbol) of the internal plugin process to the caller, including forwarding query parameters like `seconds` and `debug`: [6](#0-5) 

Because none of these handlers check `webauth.GetAuthenticatedUser` or otherwise validate a session/token, and the group they are mounted on performs no such check either, an unauthenticated remote caller can hit these endpoints directly.

### Impact Explanation
An unauthenticated attacker with network access to the node's web server can:
- Enumerate all installed LOOP plugins and their internal Prometheus target configuration via `/discovery`.
- Pull full Prometheus metrics for any named plugin via `/plugins/:name/metrics`, which can include internal counters/labels revealing operational and configuration details.
- Pull pprof profiling data (heap dumps, goroutine stacks, CPU profiles, full symbol tables) from internal LOOP plugin processes via `/plugins/:name/debug/pprof/*`, which is a well-known source of memory-content disclosure (heap dumps can contain secrets/keys held in process memory) and internal topology information.

This is an information-disclosure class of vulnerability from missing access control on utility/debug endpoints, matching the CVE-2017-4952 bug class.

### Likelihood Explanation
The routes are registered unconditionally whenever the node's HTTP API is started (`loopRoutes(app, api)` runs in every `NewRouter` call), and are reachable by any client that can send an HTTP request to the node's API port — no credentials, token, or session are required. Exploitation only requires knowing/guessing a plugin name (which can itself be enumerated via the unauthenticated `/discovery` endpoint).

### Recommendation
Move `loopRoutes` registration to run under the authenticated route group (the same pattern already used for `metricRoutes(authv2)`), or add explicit `auth.Authenticate(...)` middleware (and appropriate role check, e.g. `auth.RequiresAdminRole`) to the `/discovery`, `/plugins/:name/metrics`, and `/plugins/:name/debug/pprof/*` routes before they reach `LoopRegistryServer` handlers.

### Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered (e.g. an EVM/Solana relayer plugin).
2. Without any session cookie or API token, send:
   - `GET /discovery` — returns JSON listing internal plugin names, hostnames, and metrics paths.
   - `GET /plugins/<plugin_name>/metrics` — returns the raw Prometheus metrics text for that plugin.
   - `GET /plugins/<plugin_name>/debug/pprof/heap?debug=1` — returns a full heap profile dump from the plugin process.
3. All three requests succeed with `200 OK` and no `401 Unauthorized`, confirming the endpoints are reachable without authentication, unlike `/v2/debug/pprof/*` (via `metricRoutes`) which requires an authenticated session/token.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {

	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

// pluginMetricHandlers routes from endpoints published in service discovery to the backing LOOP endpoint
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
