Audit Report

## Title
Unauthenticated disclosure of internal plugin names and Go runtime debug/pprof data via `/discovery` and `/plugins/:name/*` - (File: `core/web/loop_registry.go`)

## Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` on the top-level `api` router group, which is built with only a rate limiter and session-cookie middleware and carries no authentication check, unlike the structurally identical `debugRoutes` (session-authenticated) and `metricRoutes` (registered under the token/session-authenticated `authv2` group). This lets any network-reachable, unauthenticated client enumerate LOOP plugin names and pull heap/goroutine/CPU profiling data and metrics from plugin processes proxied through the node.

## Finding Description
`NewRouter` builds `api` with only `rateLimiter(...)` and `sessions.Sessions(...)` middleware, then calls `loopRoutes(app, api)` directly, with no `auth.Authenticate(...)` wrapper. [1](#0-0) 

In contrast, `debugRoutes` explicitly wraps its `/debug` group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` before exposing `/vars`, [2](#0-1)  and `metricRoutes` (which exposes the node's own `/debug/pprof/*` handlers) is only ever invoked from within the `authv2` group that requires token or session authentication. [3](#0-2) 

`loopRoutes` itself registers all four LOOP-related endpoints with no auth middleware in the chain. [4](#0-3) 

`discoveryHandler` iterates `l.registry.List()` and returns every registered plugin's name and metrics path as JSON to any caller. [5](#0-4) 

`pluginMetricHandler` and `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` only check plugin existence via `l.registry.Get(pluginName)` — there is no session/token check — before proxying the request to the plugin's internal `/metrics` or `/debug/pprof/...` endpoint and returning the raw response body. [6](#0-5) [7](#0-6) 

The code comments ("unlike discovery, this endpoint is internal btw the node and plugin") reveal an assumption of network-level isolation that is not actually enforced at the HTTP routing layer, since these handlers are reachable on the same public-facing listener as the rest of the `api` group.

## Impact Explanation
An unauthenticated client can retrieve full plugin names via `/discovery`, then pull heap dumps, goroutine stack traces, and CPU profiles (`/plugins/:name/debug/pprof/*`) from LOOP plugin processes without any credential, exposing internal runtime state, memory contents, and configuration data (e.g., `PrometheusPort`). This is a genuine information-disclosure vulnerability distinct from the SECURITY.md exclusion for "non-confidential information disclosure such as IPs, server names, and most stack traces" — pprof heap/goroutine data can reveal substantially more than IPs/server names (in-memory state, potentially secrets held in memory, code structure). The repeated-CPU-profile angle is a DoS vector, which alone would be out of scope per SECURITY.md, but the core finding is unauthenticated data disclosure, which is in scope as a node API authentication bypass (missing auth gate on a sibling route family that is authenticated everywhere else in the same router).

## Likelihood Explanation
High. The routes sit on the same listener and top-level `api` group as the rest of the authenticated web API, requiring only network reachability to the node's HTTP port — no credentials, no guessing beyond an optional discovery call which itself is unauthenticated. The request pattern is trivially repeatable via plain `GET`/`POST` HTTP calls.

## Recommendation
Wrap `loopRoutes` registration in an authenticated group consistent with `debugRoutes`/`metricRoutes`, e.g.:
```go
loopAuth := api.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))
loopRoutes(app, loopAuth)
```
or move plugin discovery/metrics/pprof routes under the existing `authv2` group.

## Proof of Concept
1. Without any session/token: `GET http://<node>/discovery` → returns JSON listing every registered LOOP plugin name and metrics path (confirmed via `discoveryHandler`, `core/web/loop_registry.go:53-65`).
2. `GET http://<node>/plugins/<name>/debug/pprof/heap?debug=1` (no credentials) → proxied through `pluginPPROFHandler` (`core/web/loop_registry.go:150-166`) with only an existence check (`l.registry.Get`), returning the plugin's full heap profile.
3. `GET http://<node>/plugins/<name>/debug/pprof/profile?seconds=30` (no credentials) → forces a 30-second CPU profile capture on the plugin process, repeatable without rate/credential limits beyond the generic rate limiter.

```go
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}
```

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
```
