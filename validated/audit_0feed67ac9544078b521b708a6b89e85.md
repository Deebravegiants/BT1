**No vulnerability found for this question.**

The `deposit_dispatch_function` is not something an unprivileged attacker can register on an arbitrary victim's store. It is set once, at asset-type creation time, via `register_dispatch_functions`, which requires the `ConstructorRef` of the underlying object — a capability only the creator of that specific fungible-asset `Metadata` object holds [1](#0-0) .

The `deposit` function simply looks up whatever hook was registered for that asset's metadata and invokes it; if none was registered it falls through to the plain `unchecked_deposit` path [2](#0-1) . A custom deposit hook that "drops" or redirects the incoming `FungibleAsset` only affects deposits made *into stores of that particular dispatchable asset type*, and only because the asset issuer chose to program that behavior — this is precisely the intended extensibility mechanism described in the module doc comment and AIP-73 (deflation tokens, transfer allowlists, loyalty tokens, etc. are explicitly called out as intended use cases) [3](#0-2) .

This does not satisfy the review's validity bar: the exploit requires the attacker to already control the `ConstructorRef`/issuer role for the asset (a pre-existing privilege), not an unprivileged transaction reaching into someone else's custody boundary. A victim who deposits into a store belonging to an asset type whose issuer wrote a malicious hook is trusting that issuer's code by construction — this is the documented trust model of dispatchable fungible assets, not a framework-level custody bypass. There is no path here where an unprivileged caller, without controlling the asset's dispatch configuration, can hijack deposits into an arbitrary victim's store of a normal (non-dispatchable or honestly-configured) fungible asset.

    public fun deposit<T: key>(store: Object<T>, fa: FungibleAsset) acquires TransferRefStore {
        fungible_asset::deposit_sanity_check(store, false);

        if (func_opt.is_some()) {

            if (features::is_function_value_dispatch_enabled()) {

                    fa,
                    borrow_transfer_ref(store),
                    func

            }
        } else {

        }
    }
