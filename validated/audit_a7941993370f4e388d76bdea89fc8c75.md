Audit Report

## Title
Missing allowlist and rate-limiting enforcement in `HandleLegacyUserMessage` allows unrestricted broadcast to entire DON - (File: `core/services/gateway/handlers/capabilities/handler.go`)

## Summary
`handler.HandleLegacyUserMessage` decodes and validates the payload's structure/freshness but skips the allowlist/rate-limiting step explicitly marked by a `// TODO: apply allowlist and rate-limiting here` comment, then unconditionally forwards the request to every DON member via `don.SendToNode` in a loop over `h.donConfig.Members`. [1](#0-0) [2](#0-1)  The `nodeRateLimiter` field on the handler is only invoked in `handleWebAPIOutgoingMessage` (node→external HTTP path), confirming it is not consulted on this inbound path. [3](#0-2) 

## Finding Description
The code matches the claim exactly: after decoding the payload and checking `payload.Timestamp` for staleness, the function reaches the TODO comment and proceeds directly to the method check, request transformation, and fan-out to all DON members with no allowlist or rate-limit gate applied at this layer. [4](#0-3)  The per-workflow sender allowlist and rate limiter (`trigger.allowedSenders`, `trigger.rateLimiter`) are only applied later, inside `triggerConnectorHandler.processTrigger` on the node side, after the gateway has already broadcast the message to every DON member — so the gateway itself performs no ingress-level throttling or filtering before consuming resources (`h.savedCallbacks` entries, per-node message sends) for each incoming message.

## Impact Explanation
This is a legitimate quota/resource-exhaustion gap at the gateway ingress tier: any caller able to reach the legacy user-message endpoint can cause the gateway to persist a `savedCallback` entry and broadcast to every DON member for each message, with no allowlist or rate-limiting check enforced by the gateway itself before that fan-out. This maps to a valid in-scope concern (gateway request handling / resource exhaustion via missing rate-limiting), independent of the downstream per-workflow authorization that exists but is reached too late to prevent the broadcast.

## Likelihood Explanation
Reaching `HandleLegacyUserMessage` requires only a message with `Method = MethodWebAPITrigger`, a decodable `TriggerRequestPayload`, and a non-stale `Timestamp` — the code shows no gateway-level authentication/allowlist check gating this specific function. I was unable to fully trace within the available tool budget whether the message must be signed and pass signature/sender validation earlier in the gateway pipeline (e.g., in `network/wsserver.go`, `connectionmanager.go`, or `common.ValidatedRequestFromMessage`) before `HandleLegacyUserMessage` is invoked, since `HandleLegacyUserMessage` is dispatched via the `handlers.DON`/`multihandler.go` path rather than directly from `httpserver.go`. This is a limitation of my investigation, not evidence against the claim — the TODO comment and the unconditional fan-out loop are confirmed present in the code as cited.

## Recommendation
Implement the allowlist and rate-limiting check indicated by the TODO in `HandleLegacyUserMessage`, before the message is persisted in `h.savedCallbacks` and before the fan-out loop over `h.donConfig.Members`, mirroring the existing `h.nodeRateLimiter.Allow(...)` pattern used in `handleWebAPIOutgoingMessage`.

## Proof of Concept
1. Send a message with `Body.Method = MethodWebAPITrigger`, a valid `TriggerRequestPayload` with a fresh `Timestamp`, through whatever ingress ultimately calls `handler.HandleLegacyUserMessage`.
2. Repeat step 1 at high volume from the same or varying senders.
3. Observe (via code inspection, confirmed above) that no allowlist or rate-limit check rejects any of these calls inside `HandleLegacyUserMessage` prior to the `don.SendToNode` loop — each call adds an entry to `h.savedCallbacks` and dispatches to every member in `h.donConfig.Members`, exercisable as a Go unit test against `handler.HandleLegacyUserMessage` directly with a mock `handlers.DON` to assert `SendToNode` call counts scale linearly with request volume with no rejection.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageID] = &savedCallback{id: msg.Body.MessageID, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
