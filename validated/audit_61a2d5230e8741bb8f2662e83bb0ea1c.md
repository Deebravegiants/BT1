### Title
Unsigned `handle_unsigned` extrinsic performs full, unbounded ISMP message execution (hashing + Merkle multi-proof verification + module dispatch) inside `validate_unsigned`, enabling free CPU-exhaustion DoS analogous to the aiohttp chunked-message bug - (File: `modules/pallets/ismp/src/lib.rs`)

### Summary
`pallet_ismp::Call::handle_unsigned` is a free, unsigned, permissionless extrinsic (`ensure_none`) whose `ValidateUnsigned::validate_unsigned` implementation does not merely sanity-check the call — it calls `Self::execute(messages.clone())`, which runs the *entire* message-handling pipeline (dedup, receipt checks, hashing of every request/response, Merkle multi-proof membership verification, and module `on_accept`/`on_response` dispatch) before the transaction is even admitted to the pool. This mirrors the aiohttp CWE-770 pattern: a large "batch" (of messages/requests, analogous to chunks) forces excessive blocking CPU work in a code path an unprivileged actor can trigger for free and can be re-triggered on every peer's mempool via transaction gossip and pool re-validation. ### Finding Description
`handle_unsigned` accepts an unbounded `Vec<Message>`, and each `Message::Request`/`Message::Response`/`Message::Timeout` variant itself carries an unbounded `Vec<PostRequest>`/`Vec<GetRequest>`: [3](#0-2) 

The pallet's `ValidateUnsigned::validate_unsigned` runs `Self::execute(messages.clone())` directly — i.e., the full state-transition logic — merely to compute a `provides` tag for the pool: [2](#0-1) 

`execute()` maps every message through `handle_incoming_message`, which for `Message::Request` calls `request::handle`. That handler:
- dedups requests (`dedup_requests`)
- iterates the entire batch checking receipts/timeouts/proxy rules
- hashes every request (`hash_request`)
- calls `state_machine.verify_membership(...)` — a Merkle multi-proof verification whose cost scales with the number of leaves supplied
- then iterates again to actually invoke `router.module_for_id(...).on_accept(...)` for every request [4](#0-3) [5](#0-4) [6](#0-5) 

None of this work is gated by any size/count bound before the expensive computation begins — there is no `MaxRequests`, `MaxMessages`, or per-request-count cap analogous to the size checks the project *does* apply elsewhere (e.g. `pallet_call_decompressor`'s `MaxCallSize` gate, explicitly added because "the unsigned `validate_unsigned` mempool path called `decompress` directly with no bound, so a fee-less attacker could ... have a tiny zstd 'bomb' expanded ... during transaction-pool validation, before any size check"): [7](#0-6) 

That comment shows the team is aware of, and has previously fixed, exactly this class of "cheap-input, expensive-mempool-validation" bug for the decompressor pallet — but `pallet_ismp::handle_unsigned` itself contains no equivalent bound on `messages.len()` or on the number of `requests`/`responses` inside a single message before `execute()` runs the full verification/dispatch pipeline in `validate_unsigned`.

Because `validate_unsigned` executes at multiple points — initial submission, propagation/gossip validation on every receiving peer, and pool re-validation against each new block — a single crafted extrinsic (packed with the maximum number of minimally-sized `PostRequest`/`GetRequest` entries that fit within the block/extrinsic length limit) forces every node's mempool to redo this full hashing + multi-proof verification + dispatch-callback work repeatedly, for free (`ensure_none`, no fee charged), and the `#[pallet::weight(weight())]` annotation used for the dispatchable does not protect the mempool-validation cost since `validate_unsigned` runs independent of dispatch weight metering.

### Impact Explanation
An unprivileged party can submit `Ismp::handle_unsigned` extrinsics whose `messages` field is packed with many `PostRequest`/`GetRequest`/`Response`/`Timeout` entries (or garbage proofs) sized to fit the runtime's max extrinsic length. Every node's transaction pool that receives this extrinsic (via RPC submission or p2p gossip) must run `validate_unsigned`, which fully hashes and Merkle-verifies the whole batch and invokes downstream module callbacks before rejecting or accepting the transaction, and this cost is paid repeatedly (on receipt, on gossip forwarding, and on pool re-validation each block) at zero cost to the attacker. This can degrade block production and RPC responsiveness across the network — a Medium-severity availability/DoS impact matching CWE-770, consistent with the reachable class of "a route unable to deliver messages" under sustained CPU starvation of validating nodes.

### Likelihood Explanation
`handle_unsigned` is explicitly designed to be callable by anyone with no fee and no prior authorization (`ensure_none`), and is the intended entry point for relayers, making it directly reachable by any unprivileged actor as required by the analog rules. The only real friction is block/extrinsic length limits (e.g., 5–8MB depending on the runtime), which still permit thousands of small requests packed into a single call. No signature, staking, or reputation gating currently limits the number of messages/requests inspected during `validate_unsigned`.

### Recommendation
Bound the work done in `ValidateUnsigned::validate_unsigned` for `handle_unsigned` before invoking `Self::execute`: enforce a maximum number of `messages` and a maximum number of requests/responses per message (mirroring the `MaxCallSize` pattern already used in `pallet_call_decompressor`), and/or perform cheap, size-based rejection prior to hashing/proof verification. Consider separating "cheap validity pre-check" logic from full execution so `validate_unsigned` does not redundantly perform the entire expensive state-transition merely to derive a pool tag.

### Proof of Concept
1. Construct a `Message::Request(RequestMessage { requests, proof, signer })` where `requests` contains the maximum number of minimally-sized `PostRequest` entries (empty/short `body`, `from`, `to`) that fit under the runtime's `RuntimeBlockLength` extrinsic-size ratio (e.g. up to 85% of 5–8 MB per `docs/content/developers/polkadot/solochains.mdx`).
2. Submit this as an unsigned `Ismp::handle_unsigned` extrinsic to a full node's RPC.
3. Observe that `validate_unsigned` (via `Self::execute`) performs `hash_request` for every entry and a Merkle multi-proof `verify_membership` pass over the entire leaf set before returning an error for the (deliberately invalid) proof — repeatable at zero cost and re-triggered by gossip propagation to every peer, causing sustained CPU load network-wide. pub fn handle<H>(host: &H, msg: RequestMessage) -> Result<MessageResult, anyhow::Error>
where
	H: IsmpHost,
{
	if msg.requests.is_empty() {
		Err(Error::EmptyBatch)?
	}

	let state_machine = validate_state_machine(host, msg.proof.height)?;
	let consensus_clients = host.consensus_clients();
	let check_state_machine_client = |state_machine: StateMachine| {
		consensus_clients
			.iter()
			.find_map(|client| client.state_machine(state_machine).ok())
			.is_none()
	};

	let router = host.ismp_router();

	// Reject duplicate requests within the batch. Wire format is `Vec`,
	// so this is the line of defence against an attacker padding a
	// batch with identical requests.
	let wrapped: Vec<Request> = msg.requests.iter().cloned().map(Request::Post).collect();
	dedup_requests::<H>(&wrapped)?;

	for req in msg.requests.iter() {
		let req = Request::Post(req.clone());
		// If a receipt exists for any request then it's a duplicate and it is not dispatched
		if host.request_receipt(&req).is_some() {
			Err(Error::DuplicateRequest { meta: req.clone().into() })?
		}

		// can't dispatch timed out requests
		if req.timed_out(host.timestamp()) {
			Err(Error::RequestTimeout { meta: req.clone().into() })?
		}

		// either the host is a router and can accept requests on behalf of any chain
		// or the request must be intended for this chain
		if req.dest_chain() != host.host_state_machine() && !host.is_router() {
			Err(Error::InvalidRequestDestination { meta: req.clone().into() })?
		}

		let source_chain = req.source_chain();

		// in order to allow proxies, the host must configure the given state machine
		// as it's proxy and must not have a state machine client for the source chain
		let allow_proxy = host.is_allowed_proxy(&msg.proof.height.id.state_id) &&
			check_state_machine_client(source_chain);

		// check if the request is allowed to be proxied
		if source_chain != msg.proof.height.id.state_id && !allow_proxy {
			Err(Error::RequestProxyProhibited { meta: req.clone().into() })?
		}
	}

	// Verify membership proof
	let state = host.state_machine_commitment(msg.proof.height)?;
	let commitments = msg
		.requests
		.iter()
		.map(|post| hash_request::<H>(&Request::Post(post.clone())))
		.collect();
	state_machine.verify_membership(host, commitments, state, &msg.proof)?;

	let mut total_weights = Weight::zero();
	let result = msg

/// This function serves as an entry point to handle the message types provided by the ISMP protocol
pub fn handle_incoming_message<H>(
	host: &H,
	message: Message,
) -> Result<MessageResult, anyhow::Error>
where
	H: IsmpHost,
{
	match message {
		Message::Consensus(consensus_message) => consensus::update_client(host, consensus_message),
		Message::FraudProof(fraud_proof) => consensus::freeze_client(host, fraud_proof),
		Message::Request(req) => request::handle(host, req),
		Message::Response(resp) => response::handle(host, resp),
		Message::Timeout(timeout) => timeout::handle(host, timeout),
	}
}

impl<T: Config> Pallet<T> {
	/// Execute the provided ISMP datagrams, this will short circuit if any messages are invalid.
	/// This also charges fee on valid message delivery
	pub fn execute(messages: Vec<Message>) -> Result<Vec<events::Event>, Error<T>> {
		let host = Pallet::<T>::default();

		let message_results = messages
			.iter()
			.map(|msg| handle_incoming_message(&host, msg.clone()))
			.collect::<Result<Vec<_>, _>>()
			.map_err(|err| {
				log::debug!(target: "ismp", "Handling Error {:#?}", err);
				Pallet::<T>::deposit_event(Event::<T>::Errors { errors: vec![err.into()] });
				Error::<T>::InvalidMessage
			})?;

		let messages_with_weights = message_results
			.iter()
			.zip(messages)
			.map(|(result, message)| MessageWithWeight { message, weight: result.weight() })
			.collect::<Vec<_>>();

		let events = message_results
			.into_iter()
			// check that requests will be successfully dispatched
			// so we can not be spammed with failing txs
			.map(|result| match result {
				MessageResult::Request { events, .. } |
				MessageResult::Response { events, .. } |
				MessageResult::Timeout { events, .. } => events,
				MessageResult::ConsensusMessage(events) => events.into_iter().map(Ok).collect(),
				MessageResult::FrozenClient(_) => vec![],
			})
			.flatten()
			.collect::<Result<Vec<_>, _>>()
			.map_err(|err| {
				log::debug!(target: "ismp", "Handling Error {:#?}", err);
				Pallet::<T>::deposit_event(Event::<T>::Errors { errors: vec![err.into()] });
				Error::<T>::InvalidMessage
			})?;

		T::FeeHandler::on_executed(messages_with_weights, events.clone())
			.map_err(|_| Error::<T>::ErrorChargingFee)?;

		for event in events.clone() {
			// deposit any relevant events
			Pallet::<T>::deposit_event(event.into());
		}

		Ok(events)
	}

	pub fn decompress(
		compressed_bytes: Vec<u8>,
		encoded_call_size: u32,
	) -> Result<Vec<u8>, DispatchError> {
		// Bound the claimed decompressed size against the configured maximum here,
		// at the single choke point every caller flows through. Previously this
		// gate lived only in `decompress_call` (the dispatch path); the unsigned
		// `validate_unsigned` mempool path called `decompress` directly with no
		// bound, so a fee-less attacker could claim `encoded_call_size = u32::MAX`
		// and have a tiny zstd "bomb" expanded to gigabytes during transaction-pool
		// validation, before any size check. Enforcing it here protects both paths.
		ensure!(encoded_call_size < T::MaxCallSize::get() * ONE_MB, Error::<T>::CallSizeOutOfBound);

		let mut decoder = StreamingDecoder::new(compressed_bytes.as_slice())
			.map_err(|_| Error::<T>::DecompressionFailed)?;

		let claimed = encoded_call_size as usize;
		let mut result = Vec::new();
		let mut chunk = vec![0u8; 4096];

		loop {
			let n = decoder.read(&mut chunk).map_err(|_| Error::<T>::DecompressionFailed)?;
			if n == 0 {
				break;
			}
			if result.len() + n > claimed {
				return Err(Error::<T>::DecompressionFailed.into());
			}
			result.extend_from_slice(&chunk[..n]);
		}

		ensure!(result.len() == claimed, Error::<T>::DecompressionFailed);

		Ok(result)
	}
