### Title
Unauthenticated exposure of LOOP plugin `/debug/pprof` endpoints leaks process memory/address information - (File: core/web/loop_registry.go, core/web/router.go)

### Summary
The Chainlink node's HTTP router mounts `loopRoutes`, which proxies to each registered LOOP plugin's pprof debug endpoints, on the unauthenticated base router group. Any unprivileged network client that can reach the node's HTTP API can retrieve full pprof profiles (goroutine stacks, heap dumps, memory allocation profiles, CPU/execution traces) for every running LOOP plugin without any credentials — directly analogous to the CVE's debugfs disclosure of sensitive internal addresses to an unprivileged reader, except here the attacker doesn't even need local/authenticated access.

### Finding Description
`NewRouter` builds a base `api` gin group with only rate limiting and a session-cookie middleware attached, then calls `loopRoutes(app, api)` directly on it: [6](#0-5) . This is in contrast to every other sensitive surface in the same file, which explicitly requires `auth.Authenticate(...)` (e.g. `debugRoutes` for `/debug/vars`, `sessionRoutes`, and `v2Routes`'s `authv2` group). The developers were clearly aware pprof needs gating for the node's own profile — they only call `metricRoutes(authv2)` from within the authenticated `v2` group with an explicit comment "Debug routes accessible via authentication": [7](#0-6) . However, `loopRoutes` — which exposes the *plugins'* pprof/metrics endpoints — is registered on the unauthenticated group and its handlers perform no authorization check of their own: [8](#0-7) .

`pluginPPROFHandler` builds a URL to the plugin's `/debug/pprof/<profile>` endpoint using attacker-controlled query parameters (`debug`, `gc`, `seconds`) via `pprofURLVals`, and streams the raw response back to the caller unmodified: [9](#0-8) . `pprof` output (heap profiles, goroutine dumps, symbol resolution) contains raw memory addresses, function pointers, and stack traces of the running plugin process — precisely the class of information the CVE analog describes as being leaked ("callback=" address lines) to an actor who should not have that visibility.

### Impact Explanation
An unauthenticated attacker with network access to the Chainlink node's HTTP port can enumerate registered LOOP plugins (via `/discovery`, also unauthenticated) and then pull heap/goroutine/CPU profiles for each. This discloses internal memory layout, pointer/address values, and potentially sensitive data embedded in memory (e.g. transient key material, secrets, or business logic state) that would otherwise require authenticated admin access. It also creates a DoS vector, since CPU/trace profiles (`/profile`, `/trace`) can be requested with attacker-controlled `seconds` values, consuming plugin CPU time.

### Likelihood Explanation
Likelihood is high wherever the node's web server is reachable by untrusted clients (e.g., LOOP-based deployments where plugins are registered) since no credentials, tokens, or session are required — the request only needs to hit `/plugins/:name/debug/pprof/*` or `/plugins/:name/metrics` on the exposed port.

### Recommendation
Move `loopRoutes` registration to an authenticated router group (mirroring how `metricRoutes(authv2)` is gated), or add an explicit `auth.Authenticate(...)` middleware to the group returned by `loopRoutes` in `core/web/router.go`, and enforce equivalent role checks (e.g., admin-only) consistent with the node's own pprof endpoints.

### Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered.
2. Without any session cookie or API token, send: `GET http://<node>/plugins/<pluginName>/debug/pprof/goroutine?debug=2`
3. Observe the full goroutine dump (including memory addresses and stack traces) returned with HTTP 200, with no authentication challenge, proving the analog to CVE-2018-20449's unauthorized disclosure of sensitive address information via a debug interface.

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
