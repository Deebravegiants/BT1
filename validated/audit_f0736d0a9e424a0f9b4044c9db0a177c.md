## Title
Webhook shop-domain header is not covered by the HMAC signature, enabling cross-tenant webhook shop-spoofing - (`lib/shopify_api/webhooks/request.rb`)

### Summary
`ShopifyAPI::Webhooks::Request` computes its HMAC signature only over the raw request body, while the `shop`, `topic`, and `webhook-id` values are read directly from unauthenticated HTTP headers. `ShopifyAPI::Webhooks::Registry.process` accepts the request once the body HMAC checks out and then hands the *header-derived* `shop` value to the handler as the trusted tenant identifier, without that value ever being part of the signed payload.

### Finding Description
`Utils::VerifiableQuery#to_signable_string` is the only thing HMAC-validated by `Utils::HmacValidator.validate`. For `Webhooks::Request`, that method returns solely the raw body: [1](#0-0) 

Meanwhile `shop`, `topic`, `api_version` and `webhook_id` are pulled straight out of HTTP headers with no cryptographic binding to the signed body: [2](#0-1)
