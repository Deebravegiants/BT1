### Title
Fee-token pricing for native-token dispatch relies on manipulable single-block AMM spot price with no slippage bound - ([File: evm/src/utils/uniswapv2/UniV3UniswapV2Wrapper.sol], [File: evm/src/utils/uniswapv2/UniV4UniswapV2Wrapper.sol], [File: sdk/packages/core/contracts/apps/HyperApp.sol])

### Summary
The reported bug class is "critical pricing logic reads a manipulable, single-block AMM state (`slot0`) instead of a TWAP." The equivalent pattern exists in Hyperbridge's fee-token pricing path: when a user dispatches an ISMP request paying in native token, `EvmHost`/`HyperApp` price the swap of native token → fee token through pluggable Uniswap wrappers that read the pool's *current* price/tick (V3 `slot0`-equivalent tick and V4 `StateView` `getSlot0`) via `QuoterV2`/`IV4Quoter`, passing `sqrtPriceLimitX96: 0` (i.e., unbounded — no execution-price protection) and no TWAP.

### Finding Description
`HyperApp.quote()` and the Host's native-fee path convert `request.fee` (feeToken units) to native-token cost using `IUniswapV2Router02.getAmountsIn`, which for V3/V4 pools is implemented by `UniV3UniswapV2Wrapper.getAmountsIn` and `UniV4UniswapV2Wrapper.getAmountsIn`: [1](#0-0) [2](#0-1) [3](#0-2) 

These quoter calls price against the pool's instantaneous tick/`sqrtPriceX96`, and are invoked with `sqrtPriceLimitX96: 0`, meaning the quote (and, per the documentation, the actual swap performed by the Host during dispatch) accepts whatever price the pool is at when the call executes, with no deviation bound and no TWAP: [4](#0-3) [5](#0-4) 

The docs explicitly flag `quote()` itself as unsafe for on-chain use because it is "vulnerable to sandwich attacks," but the underlying dispatch flow ("the Host will swap native → feeToken via Uniswap") performs the analogous conversion on-chain when a user pays with native value, and the fork test confirms the quoter must run via a `CALL` (not `STATICCALL`) because it writes/reverts state to compute price — i.e., it is a live, single-block AMM read, not a time-weighted one: [6](#0-5) 

The tesseract relayer gas oracle independently derives native/fee-token exchange rate the same way, from a single `getAmountsIn` call against current router reserves, with no TWAP or outlier rejection: [7](#0-6) 

### Impact Explanation
Any unprivileged user (message dispatcher) who pays the relayer fee in native token triggers an on-chain swap priced off the pool's current tick/reserves. Because there is no slippage bound (`sqrtPriceLimitX96: 0`) or TWAP check, an attacker with flash-loan capital can sandwich the dispatch transaction to move the pool price immediately before it executes and restore it after, causing the Host to either (a) receive far less feeToken than the fee actually required for delivery — under-funding the relayer fee and leaving the dispatched request unable to be delivered/relayed (a stuck message, i.e., a "route unable to deliver messages"), or (b) take an inflated amount of the user's native token for the same feeToken output, directly extracting value from the dispatcher. This mirrors the reported class: reliance on `slot0`-style live AMM state for a security-relevant on-chain price feeds directly into fund movement.

### Likelihood Explanation
Any account that calls `dispatch{value: ...}` (or `HyperFungibleToken.bridge`) with native-token payment reaches this path with a single transaction; MEV bots/flashbots routinely sandwich swaps with no slippage protection, making exploitation practical whenever the configured Uniswap pool has thin liquidity relative to attacker capital (a normal condition for less-liquid fee-token/WETH pairs).

### Recommendation
- Require a caller-supplied `amountInMaximum`/`amountOutMinimum` (slippage bound) on the native↔feeToken swap performed during dispatch, and set a bounded `sqrtPriceLimitX96` rather than `0`.
- Price the conversion from a TWAP (Uniswap V3 `observe`/`OracleLibrary`, or V4 truncated oracle) rather than the raw instantaneous tick/`slot0`/reserves, with a maximum deviation guard similar to the `maxDeviationBps` pattern already used in Simplex's venue pricing.
- Keep the on-chain swap unreachable for security-critical accounting; if `quote()`/dispatch pricing must remain on-chain, gate it with a reference-price sanity check that reverts on excessive deviation from an off-chain/TWAP oracle.

### Proof of Concept
1. Attacker identifies an `EvmHost` configured with a thin fee-token/WETH Uniswap V3/V4 pool (`UniV3UniswapV2Wrapper`/`UniV4UniswapV2Wrapper` as `uniswapV2Router`).
2. Attacker front-runs a victim's `dispatch{value: nativeCost}(post)` (or `HyperFungibleToken.bridge`) call with a large swap that pushes the pool's `slot0`/tick so the subsequent quoter call (`sqrtPriceLimitX96: 0`, no bound) returns a favorable-to-attacker exchange rate.
3. The victim's dispatch executes at the manipulated price — the Host either swaps too little native token into feeToken (under-funding the relayer fee needed to actually incentivize delivery) or the victim overpays native token for the same fee.
4. Attacker back-runs to restore the pool price and pockets the discrepancy extracted from the sandwiched swap, while the victim's dispatched request may sit undelivered due to insufficient relayer fee.

    function getAmountsIn(uint256 amountOut, address[] calldata path) external returns (uint256[] memory) {
        IQuoterV2.QuoteExactOutputSingleParams memory params = IQuoterV2.QuoteExactOutputSingleParams({
            tokenIn: path[0], tokenOut: path[1], amount: amountOut, fee: _params.maxFee, sqrtPriceLimitX96: 0
        });
        (uint256 amountIn,,,) = IQuoterV2(_params.quoter).quoteExactOutputSingle(params);
        uint256[] memory amounts = new uint256[](2);
        amounts[0] = amountIn;
        amounts[1] = amountOut;
        return amounts;
    }

    function getAmountsIn(uint256 amountOut, address[] calldata path) external returns (uint256[] memory amounts) {
        address tokenOut = _isNativeToken(path[0]) ? path[1] : path[0];
        bool zeroForOne = _isNativeToken(path[0]);
        PoolKey memory poolKey = _createPoolKey(tokenOut);

        (uint256 amountIn,) = IV4Quoter(_params.quoter)
            .quoteExactOutputSingle(
                IV4Quoter.QuoteExactSingleParams(poolKey, zeroForOne, uint128(amountOut), bytes(""))
            );

        amounts = new uint256[](2);
        amounts[0] = amountIn;
        amounts[1] = amountOut;
    }

async fn get_price_from_uniswap_router(
	ismp_host: H160,
	client: Arc<AlloyProvider>,
) -> Result<U256, Error> {
	let host = EvmHostInstance::new(Address::from_slice(&ismp_host.0), client.clone());
	let params = host.hostParams().block(BlockId::latest()).call().await?;

	// There are no uniswap pool on testnet, return 1 usd as native token value
	if params.hyperbridge.0.starts_with(b"KUSAMA") {
		return Ok(U256::from(10).pow(U256::from(27)));
	}

	let uniswap_v2 = H160::from_slice(params.uniswapV2.as_slice());
	let fee_token = Address::from_slice(params.feeToken.as_slice());

	if uniswap_v2 == H160::zero() {
		return Err(anyhow!("Uniswap V2 Router not configured in Host Params"));
	}

	let router = IUniswapV2Router::IUniswapV2RouterInstance::new(params.uniswapV2, client.clone());
	let native_token = router.WETH().block(BlockId::latest()).call().await?;

	let fee_token_contract = IERC20::IERC20Instance::new(fee_token, client.clone());
	let fee_token_decimals = fee_token_contract.decimals().block(BlockId::latest()).call().await?;

	let native_token_contract = IERC20::IERC20Instance::new(native_token, client.clone());
	let native_decimals = native_token_contract.decimals().block(BlockId::latest()).call().await?;

	let path = vec![fee_token, native_token];
	let amount_out = primitive_to_alloy_u256(U256::from(10).pow(U256::from(native_decimals)));

	let amounts = router.getAmountsIn(amount_out, path).block(BlockId::latest()).call().await?;

	if amounts.is_empty() {
		return Err(anyhow!("Invalid amounts returned from Uniswap V2 Router"));
	}

	let amount_stable = alloy_u256_to_primitive(amounts[0]);

	let target_decimals = 27;
	Ok(amount_stable * U256::from(10).pow(U256::from(target_decimals - fee_token_decimals as u32)))
}
