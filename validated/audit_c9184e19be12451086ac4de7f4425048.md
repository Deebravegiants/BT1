## Finding

### Title
Stale `TombStone.original_owner` lets a former owner reclaim a burned object from a later legitimate owner - (File: `aptos-move/framework/aptos-framework/sources/object.move`)

### Summary
`object::burn`/`object::unburn` implement a "soft burn" marker (`TombStone`) that records the owner who burned the object so that owner can later reclaim it if the object ends up parked at `BURN_ADDRESS`. The ordinary transfer path (`transfer_raw_inner`, used by `object::transfer`, `object::transfer_to_object`, `object::transfer_call`) never clears this `TombStone` when ownership legitimately changes hands, whereas the `TransferRef`-based path (`transfer_with_ref`) explicitly does. This asymmetry mirrors the Prime.sol bug pattern: a security-relevant field is reset on one code path but forgotten on a sibling path, letting a stale value be replayed later to bypass the intended authority check.

### Finding Description
`TombStone` is created in `burn()`: [1](#0-0) 

Note that `burn()` does **not** move the object to `BURN_ADDRESS` anymore (it's a "soft burn" for indexers) - `ObjectCore.owner` stays unchanged, and `TombStone.original_owner` is simply set to the current owner.

`unburn()` later trusts `TombStone.original_owner` to decide who may reclaim the object once it is actually sitting at `BURN_ADDRESS`: [2](#0-1) 

The normal transfer path that moves ownership from one account to another never touches `TombStone`: [3](#0-2) 

By contrast, `transfer_with_ref` (the `TransferRef`/`LinearTransferRef` path) explicitly clears a stale `TombStone` before allowing a new owner to take control, precisely to prevent the very issue described here: [4](#0-3) 

Because `transfer_raw_inner` (reached by the public `transfer`, `transfer_to_object`, and `transfer_call` entry points) does not perform this same cleanup, a `TombStone` created by a former owner survives across subsequent, fully legitimate ownership changes.

### Impact Explanation
Exploit sequence:
1. Alice owns object `O`. She calls `object::burn(alice, O)`. This creates `TombStone{original_owner: alice}` at `O`'s address; `ObjectCore.owner` remains `alice`.
2. Alice legitimately transfers `O` to Bob using the ordinary `object::transfer(alice, O, bob)` entry function (allowed since burning does not disable `allow_ungated_transfer`). `transfer_raw_inner` updates `owner = bob` but leaves the stale `TombStone{original_owner: alice}` in place.
3. Bob (or any subsequent legitimate owner) later decides to permanently destroy the object using the framework's own documented convention - sending it to the module's `BURN_ADDRESS` via a plain `object::transfer(bob, O, BURN_ADDRESS)` call (`BURN_ADDRESS` is a public constant explicitly documented as "Address where unwanted objects can be forcefully transferred to" [5](#0-4) ).
4. Alice, who no longer owns or has any rights to `O`, calls `unburn(alice, O)`. Since `ObjectCore.owner == BURN_ADDRESS` and the stale `TombStone.original_owner == alice`, the assertion passes and `transfer_raw_inner(object_addr, alice)` restores full ownership of `O` to Alice - `object::unburn` doc: "Allow origin owners to reclaim any objects they previous burnt."

This lets a former owner steal an object/asset (and, by extension, any fungible-asset or token-object value keyed to that object's address, e.g. via `primary_fungible_store`, `aptos_token`, etc.) away from its rightful current holder, and it defeats the "burn = permanent destruction" guarantee the framework itself documents for `BURN_ADDRESS`. This is a theft / owner-reassignment / broken-burn-finality issue directly tied to custody of object-held value.

### Likelihood Explanation
`BURN_ADDRESS` transfers via the plain `transfer`/`transfer_call` entry function are a normal, expected user action (it is the framework's documented mechanism, and third-party contracts/wallets built on `aptos_framework::object` commonly implement "burn" this way rather than calling the internal `object::burn` function). No special privileges are required by the attacker (Alice) beyond having been a past legitimate owner who called `burn()` at some point before selling/transferring the object - a normal, permissionless action available to any owner. The only precondition for the victim is that they (or anyone downstream) eventually send the object to `BURN_ADDRESS` via ordinary transfer instead of via `transfer_with_ref`, which is plausible and even encouraged by the framework's own `BURN_ADDRESS` semantics.

### Recommendation
Clear any existing `TombStone` on every ownership change, not just in `transfer_with_ref`. Specifically, `transfer_raw_inner` should remove `TombStone` from the object whenever `object_core.owner` changes (mirroring the comment/fix already applied in `transfer_with_ref`), so that a stale `original_owner` can never outlive a legitimate change of custody.

### Proof of Concept
```
// Alice owns O
object::burn(&alice, O);                       // TombStone{original_owner: alice}, owner stays alice
object::transfer(&alice, O, bob_addr);          // owner -> bob; TombStone NOT cleared (transfer_raw_inner)
// ... time passes, Bob is the legitimate owner ...
object::transfer(&bob, O, BURN_ADDRESS);        // owner -> BURN_ADDRESS via plain transfer
object::unburn(&alice, O);                      // TombStone.original_owner == alice (stale) matches signer
                                                 // => transfer_raw_inner(O, alice) reclaims the object for Alice
assert!(object::owner(O) == alice_addr, 0);     // Alice stole the object from Bob's burn
```

```text
    public fun transfer_with_ref(self: LinearTransferRef, to: address) {
        assert!(!exists<Untransferable>(self.self), error::permission_denied(EOBJECT_NOT_TRANSFERRABLE));

        // Undo soft burn if present as we don't want the original owner to be able to reclaim by calling unburn later.
        if (exists<TombStone>(self.self)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(self.self);
        };

        let object = borrow_global_mut<ObjectCore>(self.self);
        assert!(
            object.owner == self.owner,
            error::permission_denied(ENOT_OBJECT_OWNER),
        );
        event::emit(
            Transfer {
                object: self.self,
                from: object.owner,
                to,
            },
        );
        object.owner = to;
    }
```

```text
    /// Add a TombStone to the object.  The object will then be interpreted as hidden via indexers.
    /// This only works for objects directly owned and for simplicity does not apply to indirectly owned objects.
    /// Original owners can reclaim burnt objects any time in the future by calling unburn.
    /// Please use the test only [`object::burn_object_with_transfer`] for testing with previously burned objects.
    public entry fun burn<T: key>(owner: &signer, object: Object<T>) {
        let original_owner = signer::address_of(owner);
        assert!(is_owner(object, original_owner), error::permission_denied(ENOT_OBJECT_OWNER));
        let object_addr = object.inner;
        assert!(!exists<TombStone>(object_addr), EOBJECT_ALREADY_BURNT);
        move_to(&create_signer(object_addr), TombStone { original_owner });
    }
```

```text
    /// Allow origin owners to reclaim any objects they previous burnt.
    public entry fun unburn<T: key>(
        original_owner: &signer,
        object: Object<T>,
    ) {
        let object_addr = object.inner;
        assert!(exists<TombStone>(object_addr), error::invalid_argument(EOBJECT_NOT_BURNT));

        // The new owner of the object can always unburn it, but if it's the burn address, we go to the old functionality
        let object_core = borrow_global<ObjectCore>(object_addr);
        if (object_core.owner == signer::address_of(original_owner)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(object_addr);
        } else if (object_core.owner == BURN_ADDRESS) {
            // The old functionality
            let TombStone { original_owner: original_owner_addr } = move_from<TombStone>(object_addr);
            assert!(
                original_owner_addr == signer::address_of(original_owner),
                error::permission_denied(ENOT_OBJECT_OWNER)
            );
            transfer_raw_inner(object_addr, original_owner_addr);
        } else {
            abort error::permission_denied(ENOT_OBJECT_OWNER);
        };
    }
```
