## Finding: Unauthenticated LOOP-plugin pprof/metrics proxy bypasses node authentication

### Title
Unauthenticated forwarding of `/plugins/:name/debug/pprof/*` and `/plugins/:name/metrics` requests to internal LOOP-plugin debug servers, bypassing session/token authentication - (File: `core/web/loop_registry.go`, `core/web/router.go`)

### Summary
The Chainlink node's Gin router mounts `loopRoutes` directly on the base, unauthenticated route group, while the functionally equivalent node-owned `pprof` endpoints are explicitly wrapped in authentication. This lets any unauthenticated client that can reach the node's HTTP port pull full Go `pprof` profiling data (heap, goroutine, profile, symbol) and Prometheus metrics from any registered LOOP plugin.

### Finding Description
`NewRouter` builds a base `api` group with only rate limiting and session middleware, no authentication: [1](#0-0) 

`loopRoutes` is registered on this unauthenticated group with no `auth.Authenticate(...)` wrapper at all: [2](#0-1) 

Contrast this with the node's own equivalent debug endpoints. `metricRoutes` (which registers the standard `net/http/pprof` handlers for the node process itself) is only ever called from inside `authv2`, a group explicitly protected by `auth.Authenticate(..., auth.AuthenticateByToken, auth.AuthenticateBySession)`: [3](#0-2) [4](#0-3) 

Similarly `/debug/vars` (expvar) is explicitly session-authenticated: [5](#0-4) 

But the LOOP-plugin variants of these same capabilities — `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler` — are exposed with zero authentication check and forward the caller's request (including query parameters and, for the symbol endpoint, the POST body) to the plugin's internal debug/metrics HTTP server, returning the raw upstream response to the caller: [6](#0-5) [7](#0-6) 

The target host/port are derived from the internal `LoopRegistry` (`l.loopHostName`, `p.EnvCfg.PrometheusPort`) rather than being fully attacker-controlled like the Kubeflow SSRF, so this is not a general SSRF to arbitrary hosts. However, it is a concrete **authentication-bypass analog**: an unprivileged, unauthenticated network client can reach internal `/debug/pprof/*` capability of every registered LOOP plugin (heap/goroutine dumps, CPU profiling, symbol resolution) that the same codebase deliberately gates behind session/token auth when exposed for the node itself.

### Impact Explanation
Go's `pprof` heap and goroutine dumps frequently capture in-memory secrets (private keys, API tokens, decrypted config) held by the plugin process. Exposing this unauthenticated allows any network-reachable, unauthenticated attacker to exfiltrate plugin memory contents or trigger CPU-bound `/debug/pprof/profile` and `seconds=`-controlled long-running requests against the plugin without any credentials, directly undermining `ENABLE_AUTHZ`/session protections that guard the equivalent node-native endpoint.

### Likelihood Explanation
Any client capable of sending HTTP requests to the Chainlink node's web server can trigger this with no authentication token, cookie, or role — a single unauthenticated GET/POST request is sufficient, and the plugin name/registry lookup is the only "check" performed.

### Recommendation
Wrap `loopRoutes`' plugin metric/pprof handlers with the same `auth.Authenticate(...)` middleware (and appropriate role requirement, e.g. `auth.RequiresAdminRole`) used for `metricRoutes`/`debugRoutes`, or otherwise restrict them to trusted internal callers (e.g., mTLS-only listener) so they are not reachable from the general unauthenticated API surface.

### Proof of Concept
Given a running node with a registered LOOP plugin `name`, an unauthenticated client can run:
```
curl http://<node-host>:<port>/plugins/<name>/metrics
curl "http://<node-host>:<port>/plugins/<name>/debug/pprof/heap"
curl "http://<node-host>:<port>/plugins/<name>/debug/pprof/profile?seconds=30"
```
No `Authorization`, API key, or session cookie is required, unlike the node's own `/v2/debug/pprof/*` routes which return `401 Unauthorized` without valid credentials.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
