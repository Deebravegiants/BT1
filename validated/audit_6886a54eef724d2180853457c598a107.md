Audit Report

## Title
Unauthenticated exposure of internal plugin metrics and pprof debug endpoints via LOOP registry routes - (File: core/web/router.go)

## Summary
The `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` routes are registered directly on the top-level `api` gin route group in `NewRouter`, which applies only rate-limiting and session-cookie middleware and no authentication check [1](#0-0) . This allows any network caller who can reach the node's primary web API port to enumerate LOOP plugins and pull their raw pprof profiles (heap, goroutine, CPU, symbol tables) and Prometheus metrics without any credentials.

## Finding Description
`loopRoutes` registers its handlers on the `api` group with no additional auth wrapper [2](#0-1) , unlike the functionally identical node-local pprof routes (`metricRoutes`), which are deliberately nested only inside the authenticated `authv2` group with the comment "Debug routes accessible via authentication" [3](#0-2) , and unlike `/debug/vars`, which is wrapped in `auth.Authenticate(...)` [4](#0-3) .

The handlers `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler` perform no authorization check themselves; they simply look up the plugin by name and forward the request — including caller-controlled `debug`, `gc`, `seconds` query parameters and `profile` path value — to `http://<loopHostName>:<PrometheusPort>/debug/pprof/...` or `/metrics`, then return the raw response body to the caller [5](#0-4) [6](#0-5) . The `exposedPromPort` used for discovery is explicitly the node's main `WebServer().HTTPPort()` [7](#0-6) , confirming these routes sit on the same publicly-reachable listener as the rest of the unauthenticated `api` group, not a separate internal-only metrics port enforced in code.

The codebase's own documentation acknowledges pprof heap dumps "may potentially expose sensitive data e.g. private key components" [8](#0-7) , which elevates this beyond the SECURITY.md-excluded category of "non-confidential information disclosure, such as IPs, server names, and most stack traces."

## Impact Explanation
An unauthenticated caller reaching the node's HTTP API can enumerate registered LOOP plugins via `/discovery` and then retrieve full pprof heap/goroutine/CPU profiles and metrics from each plugin without any session, token, or role check. This is an authentication-bypass class information-disclosure bug on the node's public API surface, matching the "node API authentication bypass" impact category, since a route that should require the same authentication as its sibling debug routes (`/debug/vars`, `/debug/pprof/*` under `authv2`) has none.

## Likelihood Explanation
High for any deployment where the node's web server port is reachable by unprivileged/unauthenticated clients — no credentials or session are required, only network reachability to routes already mounted on the default, most commonly exposed `api` group alongside login and health endpoints.

## Recommendation
Move `loopRoutes(app, api)` registration to require authentication, mirroring `metricRoutes`'s placement under `authv2` or by wrapping the group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (and consider `auth.RequiresAdminRole` for the pprof/metrics forwarding handlers specifically), before exposing `/discovery`, `/plugins/:name/metrics`, and `/plugins/:name/debug/pprof/*`.

## Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered.
2. Without any session cookie or API token, send `GET /discovery` to enumerate plugin names and Prometheus ports via `discoveryHandler` [9](#0-8) .
3. Send `GET /plugins/<name>/debug/pprof/heap?debug=1` without authentication; `pluginPPROFHandler` forwards the request unauthenticated and returns the plugin's raw pprof heap profile [5](#0-4) .

func NewLoopRegistryServer(app chainlink.Application) *LoopRegistryServer {
	discoveryHostName, loopHostName := initHostNames()
	return &LoopRegistryServer{
		exposedPromPort:   int(app.GetConfig().WebServer().HTTPPort()),
		registry:          app.GetLoopRegistry(),
		logger:            app.GetLogger(),
		jsonMarshalFn:     json.Marshal,
		discoveryHostName: discoveryHostName,
		loopHostName:      loopHostName,
		promClient:        &http.Client{Timeout: 1 * time.Second}, // some value much less than the prometheus poll interval will do there
	}
}

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

// pluginMetricHandlers routes from endpoints published in service discovery to the backing LOOP endpoint
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
