### Title
`deposit` mints zero `zft` shares while crediting full underlying amount to `assets` when `total-assets-preview` is zero and supply is non-zero, permanently destroying the depositor's principal - (`mainnet/contracts/vault/v0-vault-stx.clar`)

### Summary
`deposit` computes `inkind` via `convert-to-shares-preview`, which returns `u0` whenever `total-supply-preview` (`ts`) is non-zero but `total-assets-preview` (`ta`) is zero, and then proceeds to mint that zero amount and unconditionally record the caller's `amount` into `assets`. Unlike `redeem`, which has `(asserts! (> inkind u0) ERR-OUTPUT-ZERO)`, `deposit` has no equivalent floor check, so a `min-out=u0` deposit silently succeeds while shares minted are `u0`.

### Finding Description
Broken identity: `assets == sum(zft_i) * (total-assets-preview / total-supply-preview)` for all holders `i`. Before the exploit call: `assets_before = 0`, `ts_before = S > 0` (residual `zft` circulating, e.g. the `MINIMUM-LIQUIDITY` minted to `NULL-ADDRESS` in `initialize` at [1](#0-0) , plus any other LP holdings). After the victim calls `deposit(1_000_000, u0, victim)`: `assets_after = assets_before + 1_000_000`, but `zft_supply_after = zft_supply_before` (unchanged), because `inkind = u0`.

Code path:
1. `socialize-debt`, callable only by an authorized market contract via `check-caller-auth`, can drive `assets` to `u0` while leaving `principal-scaled`/`total-borrowed` such that `total-debt <= total-borrowed`: [2](#0-1) 
2. `total-assets-preview` then evaluates to `0 + interest` where `interest = 0` when `debt <= borrowed`: [3](#0-2) 
3. `convert-to-shares-preview` checks `ts` first; since `ts != u0` it falls into the `ta == u0` branch and returns `u0`: [4](#0-3) 
4. `deposit` computes `inkind = u0`, and its only guard is `(asserts! (>= inkind min-out) ERR-SLIPPAGE)`, which passes trivially when `min-out=u0`: [5](#0-4) 
5. `ft-mint? zft u0 recipient` succeeds (Clarity permits minting a zero amount), and `(var-set assets (+ current-assets amount))` unconditionally records the full deposit.

Contrast with `redeem`, which explicitly guards the symmetric case: [6](#0-5) . No analogous `(asserts! (> inkind u0) ...)` exists in `deposit`. Existing guards (`min-out`, `CAP-SUPPLY`, pause states, `ERR-AMOUNT-ZERO` on the input `amount`) do not check the *output* share amount, so none of them prevent the divergence.

### Impact Explanation
Per call, the victim's entire deposited `amount` (e.g. `1_000_000` micro-units) is transferred into the vault and added to `assets`, backing the existing `zft` supply, while the victim receives `u0` shares — a 100% loss of principal for that depositor, absorbed pro-rata by every other existing `zft` holder (residual LPs and `.dao-treasury` reserve-fee shares). This is repeatable for every deposit made while `total-assets-preview` remains `u0` and `ts > 0`, and matches Immunefi Critical severity as a permanent loss of user principal / protocol insolvency-adjacent share-pricing corruption.

### Likelihood Explanation
The precondition (`total-assets-preview == 0` with `ts > 0`) requires an authorized market to have driven the vault into a fully-socialized-debt state via `socialize-debt`, which is a legitimate, reachable protocol operation following a large borrower default (not an attacker privilege). Once that state exists, the victim-side call is fully unprivileged — any ordinary principal calling `deposit(amount, u0, recipient)` triggers the loss, with zero special setup or capital beyond the deposit amount itself, and it is repeatable for every subsequent deposit until `total-assets-preview` recovers above zero.

### Recommendation
Add an explicit output-floor check to `deposit`, mirroring `redeem`'s `ERR-OUTPUT-ZERO` guard, e.g. `(asserts! (> inkind u0) ERR-OUTPUT-ZERO)` before minting, so that a deposit computing zero shares reverts instead of silently absorbing the depositor's funds into `assets`.

### Proof of Concept
Clarinet simnet test plan:
1. Deploy and `initialize` the vault (mints `MINIMUM-LIQUIDITY` `zft` to `NULL-ADDRESS`), then have a second LP deposit normally so `ts > MINIMUM-LIQUIDITY`.
2. As the authorized market principal, call `system-borrow` to create debt, then call `socialize-debt` with a `scaled-amount` sized so that `(var-set assets ...)` lands at `u0` and `total-borrowed`/`principal-scaled` leave `total-debt <= total-borrowed` (interest term `u0`).
3. Assert `(contract-call? .v0-vault-stx get-total-assets)` returns `(ok u0)` and `(contract-call? .v0-vault-stx get-total-supply)` returns `(ok S)` with `S > u0`.
4. As the victim, call `(contract-call? .v0-vault-stx deposit u1000000 u0 victim)`.
5. Assert the call succeeds with `(ok u0)`, `(ft-get-balance zft victim)` (via `get-balance`) is `u0`, and `(contract-call? .v0-vault-stx get-assets)` increased by exactly `u1000000` — proving `assets_after - assets_before = 1000000` while `total-supply_after - total-supply_before = 0`, violating the share-backing identity.

(define-public (socialize-debt (scaled-amount uint))
  (let ((scaled-principal (var-get principal-scaled))
        (borrowed (var-get total-borrowed))
        (idx (var-get index))
        (current-assets (var-get assets))
        (current-lindex (var-get lindex))
        (old-total-assets (total-assets))
        (debt-reduction (mul-div-down scaled-amount idx INDEX-PRECISION))
        (principal-reduction (if (> scaled-principal u0)
                                (mul-div-down scaled-amount borrowed scaled-principal)
                                u0))
        ;; Write down lindex proportionally to loss in total-assets
        (new-lindex (if (and (> old-total-assets u0) (> old-total-assets debt-reduction))
                       (mul-div-down current-lindex (- old-total-assets debt-reduction) old-total-assets)
                       u0)))

    (try! (check-caller-auth))
    (asserts! (> scaled-amount u0) ERR-AMOUNT-ZERO)

    (var-set lindex new-lindex)
    (var-set principal-scaled (if (> scaled-principal scaled-amount) (- scaled-principal scaled-amount) u0))
    (var-set total-borrowed (if (> borrowed principal-reduction) (- borrowed principal-reduction) u0))
    (var-set assets (if (> current-assets principal-reduction) (- current-assets principal-reduction) u0))

    (print {
      action: "socialize-debt",
      caller: contract-caller,
      data: {
        scaled-amount: scaled-amount,
        debt-reduction: debt-reduction,
        principal-reduction: principal-reduction,
        old-lindex: current-lindex,
        new-lindex: new-lindex,
        old-total-assets: old-total-assets,
        principal-scaled: (if (> scaled-principal scaled-amount) (- scaled-principal scaled-amount) u0),
        total-borrowed: (if (> borrowed principal-reduction) (- borrowed principal-reduction) u0),
        index: idx
      }
    })

    (ok true)))
