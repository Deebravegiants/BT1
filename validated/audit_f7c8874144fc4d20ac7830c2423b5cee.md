### Title
Bad-debt wipeout clamps a zero supply index upward, resurrecting supplier claims - (File: contracts/pool/src/interest.rs)

### Summary
`apply_bad_debt_to_supply_index` computes a zero reduction factor when bad debt consumes the full supplied value, but then raises the resulting supply index to `SUPPLY_INDEX_FLOOR_RAW` instead of zeroing the market's outstanding supply shares. [1](#0-0)  The unchanged `supplied` share balance therefore retains a nonzero claim after complete socialization. [2](#0-1)  A subsequent deposit can be withdrawn by the supposedly wiped-out shares, leaving the new supplier undercollateralized. [3](#0-2) 

### Finding Description
After capping `bad_debt` at `total_supplied_value`, the function derives `remaining / total_supplied_value`, which is zero on a full write-down. [4](#0-3)  It then applies `.max(Ray::from(SUPPLY_INDEX_FLOOR_RAW))`, restoring the index to `RAY / 1000` without burning or otherwise reducing `cache.supplied()`. [5](#0-4)  Consequently, `scaled_amount * floored_supply_index` still produces a positive claim for all pre-write-down suppliers. [6](#0-5) 

The included regression test demonstrates the exact failure: after a full bad-debt write-down hits the floor, `resolve_withdrawal(i128::MAX, scaled_a)` returns positive gross proceeds and drains a fresh deposit exactly. [3](#0-2) 

### Impact Explanation
This can cause protocol insolvency and theft of later suppliers' funds. [7](#0-6)  Once fresh cash enters the market, stale pre-write-down supply shares can withdraw real tokens even though their economic claim should have been fully socialized away. [3](#0-2)  The pool is left unable to cover the fresh supplier's claim. [7](#0-6) 

### Likelihood Explanation
The vulnerable helper is used by bad-debt socialization when unpaid debt is written down against the market's suppliers. [8](#0-7)  Permissionless cleanup is intended for accounts whose debt exceeds collateral while collateral is at or below the bad-debt threshold. [9](#0-8)  The exploit additionally requires the affected market's unpaid debt to reach its total supplied value, after which any future deposit can be consumed by the residual floor-indexed shares. [2](#0-1) 

### Recommendation
When `bad_debt >= total_supplied_value`, atomically clear or reconcile the corresponding `supplied` shares rather than preserving them under a nonzero index. [2](#0-1)  Alternatively, track wiped-out shares separately and prevent them from resolving withdrawals after the index-floor clamp. [3](#0-2) 

### Proof of Concept
```rust
// Existing supplier: scaled_a > 0, supply_index = RAY.
apply_bad_debt_to_supply_index(
    &mut cache,
    cache.supplied().mul(env, cache.supply_index()),
);

// Full write-down leaves:
//   supply_index == SUPPLY_INDEX_FLOOR_RAW
//   supplied       == scaled_a
// while `scaled_a * floor` still unscales to a positive claim.

// Victim supplies `fresh_cash`.
let scaled_b = cache.calculate_scaled_supply(fresh_cash);
cache.mint_supply(scaled_b);
cache.credit_cash(fresh_cash);

// Stale supplier withdraws the resurrected claim.
let (burn, gross) = cache.resolve_withdrawal(i128::MAX, scaled_a);
cache.require_reserves(gross);
cache.burn_supply(burn);
cache.debit_cash(gross);

// `gross > 0`, the pool is emptied, and the fresh supplier's claim is unbacked.
```

```rust
/// Socializes `bad_debt` by reducing the supply index (capped at total supply value).
///
/// Used when seizing unpaid debt: remaining supplier claims shrink pro-rata.
/// No-op when total supplied value is zero. Floors the resulting index at
/// [`SUPPLY_INDEX_FLOOR_RAW`] to avoid a zero index.
pub(crate) fn apply_bad_debt_to_supply_index(cache: &mut Cache, bad_debt: Ray) {
    let total_supplied_value = cache.supplied().mul(cache.env(), cache.supply_index());

    if total_supplied_value == Ray::ZERO {
        return;
    }

    let capped = bad_debt.min(total_supplied_value);
    let remaining = total_supplied_value.checked_sub(cache.env(), capped);

    let reduction_factor = remaining.div_floor(cache.env(), total_supplied_value);
    let new_supply_index = cache
        .supply_index()
        .mul_floor(cache.env(), reduction_factor);

    cache.set_supply_index(new_supply_index.max(Ray::from(SUPPLY_INDEX_FLOOR_RAW)));
```
