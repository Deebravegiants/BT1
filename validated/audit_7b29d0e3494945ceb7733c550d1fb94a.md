- `merge_msm_inputs` samples `beta` via `sample_field_element(rng)` internally and derives `scales` as `[1, beta, beta^2, ...]` [1](#0-0) .
- Direct calls to `merge_msm_inputs_with_scales` in `shplonked.rs` and the `weighted_transcript*.rs` files pass scales derived from Fiat-Shamir challenges (`c`, `c_n`) or from `sample_field_element_with_powers`/verifier RNG (`powers_of_gamma`, `beta`), e.g. [2](#0-1)  and [3](#0-2) .

An attacker submitting a proof cannot control these scale values since they are computed by the verifier's own randomness/challenge derivation, not deserialized from the proof itself. Even if an attacker could influence one input's scalar to be structured such that the aggregated term happens to zero out for a random `beta`, that would only occur with negligible probability (the random linear combination is exactly the standard batching technique used to make such cancellation infeasible except with soundness-error probability, which is the intended cryptographic design, not a bug).

/// Merges multiple `MsmInput`s into one by scaling the i-th input by `scales[i]` and aggregating.
/// Same base across inputs is combined (scalars summed). Terms with zero scalar are dropped.
///
/// Returns an error if `inputs.len() != scales.len()` or if the merged MSM input is invalid.
pub fn merge_msm_inputs_with_scales<A: AffineRepr>(
    inputs: &[MsmInput<A, A::ScalarField>],
    scales: &[A::ScalarField],
) -> Result<MsmInput<A, A::ScalarField>> {
    if inputs.len() != scales.len() {
        bail!(
            "inputs and scales length mismatch: {} inputs, {} scales",
            inputs.len(),
            scales.len(),
        );
    }
    let mut agg: HashMap<A, A::ScalarField> = HashMap::new();
    for (input, scale) in inputs.iter().zip(scales.iter()) {
        for (base, scalar) in input.bases().iter().zip(input.scalars().iter()) {
            let s = *scalar * scale;
            agg.entry(*base).and_modify(|s0| *s0 += s).or_insert(s);
        }
    }
    let (bases, scalars): (Vec<_>, Vec<_>) = agg.into_iter().filter(|(_, s)| !s.is_zero()).unzip();
    MsmInput::new(bases, scalars)
}
