### Title
Accrual overflow in `scaled_to_original`/`update_supply_index` permanently freezes a pool market — every verb panics before `MAX_BORROW_INDEX_RAY` cap engages - ([File: common/src/rates/index.rs])

### Summary
The borrow/supply index math is checked against `i128` bounds but the *value* multiplication `scaled * index` inside `Ray::mul` panics with `MathOverflow` when the product overflows before the index cap (`MAX_BORROW_INDEX_RAY` / `MAX_SUPPLY_INDEX_RAY`) can engage. Because `global_sync` accrues first inside every pool entrypoint, once a market's `borrowed * borrow_index` (or `supplied * supply_index`) crosses the `i128` ceiling, every subsequent call — `supply`, `borrow`, `withdraw`, `repay`, `liquidate`-driven burns, `clean_bad_debt`, `claim_revenue`, `recapitalize` — reverts. The market is frozen permanently with no recovery path.

### Finding Description
`update_borrow_index` caps the index at `MAX_BORROW_INDEX_RAY`, and `update_supply_index` caps at `MAX_SUPPLY_INDEX_RAY` — but those caps guard the *index*, not the *value* (`shares × index`) it is multiplied against. `scaled_to_original` computes `scaled.mul(env, index)` via `fp_core::mul_div_half_up`, which traps `MathOverflow` on `i128` overflow [1](#0-0) [2](#0-1) . Likewise `update_supply_index` computes `supplied.mul(env, old_index)` and `supply_index_reward_shortfall` computes `supplied.mul(env, new_index)`, both unchecked against the value ceiling [3](#0-2) [4](#0-3) . `accrue_chunk`/`global_sync` run before any mutation [5](#0-4) . The test `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap` demonstrates the freeze concretely: `MathOverflow`, `borrow_index < MAX_BORROW_INDEX_RAY`, and `withdraw`/`repay` both failing [6](#0-5) .

### Impact Explanation
Permanent freezing of funds for every supplier and borrower of that `(hub, token)` market, plus guaranteed insolvency-adjacent damage: liquidations cannot run (they accrue first), bad debt cannot be cleaned, and protocol revenue cannot be claimed. No privileged remediation exists because params views/mutations also load the cache and accrue.

### Likelihood Explanation
Reachable by a single unprivileged address via `supply` + `borrow` (or self-liquidating positions), but requires whale-scale capital in a high-decimal asset (the PoC uses ~1e9 units of an 18-decimal token at 98% utilization on a steep rate curve) and sustained accrual before the cliff. The failure is deterministic once crossed — likelihood is gated by market size and time, not by attacker cleverness. Medium.

### Recommendation
In `accrue_step`/`update_supply_index`, clamp the scaled totals (`borrowed`, `supplied`) or use the saturating `mul_div_floor_saturating` path for the value products so the index caps engage before `i128` overflows; alternatively, treat index saturation as a terminal accrual state that still permits repay/withdraw legs to execute.

### Proof of Concept
See `tests/test-harness/tests/controller/large_positions_and_long_horizons.rs` `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap`: an 18-decimal market with ~1e27 raw supply and ~98% borrowed advances time until `try_update_indexes` returns `MATH_OVERFLOW` with `borrow_index < MAX_BORROW_INDEX_RAY`; subsequent `try_withdraw_raw` and `try_repay` both fail with `MATH_OVERFLOW`, proving repay, withdraw, and liquidation paths are permanently bricked [7](#0-6) .

pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}

#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
