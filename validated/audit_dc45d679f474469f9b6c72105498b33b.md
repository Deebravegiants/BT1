### Title
Path traversal in `newHTTPFetcher` allows workflow-controlled URL to escape configured base path - (File: `core/services/workflows/syncer/v2/fetcher.go`)

### Summary
The gateway-bypass HTTP fetcher used to retrieve workflow binary/config artifacts cleans the caller-supplied path but never verifies that the final joined path still resides under the configured base path, unlike its sibling `newFileFetcher`, which explicitly enforces a base-path prefix check.

### Finding Description
`NewFetcherFunc` builds either a file-based or HTTP-based fetcher from a fixed, operator-configured `baseURL` [1](#0-0) . The `newFileFetcher` implementation is traversal-safe: after joining the request path with `basePath`, it rejects any resolved path that does not have `basePath + separator` as a prefix [2](#0-1) .

`newHTTPFetcher` has no equivalent check. It only calls `filepath.Clean` on the raw `req.URL` and then joins it onto the base URL's path via `filepath.Join`, which itself re-cleans the combined string and can collapse `..` segments past the intended base path:
```go
cleanPath := strings.TrimPrefix(filepath.Clean(req.URL), "/")
u, err := url.Parse(baseURL)
u.Path = filepath.Join(u.Path, cleanPath)
fetchURL := u.String()
``` [3](#0-2) 

Because `filepath.Clean("../secret")` does not strip a leading relative `..` (there is nothing to cancel it against until it is joined to an absolute path), and `filepath.Join` performs its own `Clean` on the concatenation, a value such as `req.URL = "../secret"` combined with `baseURL` path `/workflows` resolves to `/secret` — outside the `/workflows` sub-path the operator intended to expose. The inline comment ("Clean the path to prevent directory traversal") is misleading: cleaning alone does not confine the result to the base path; only an explicit post-join prefix check (as done in `newFileFetcher`) does that.

`req.URL` in this flow ultimately originates from the on-chain `WorkflowRegisteredEvent.BinaryURL` / `ConfigURL` fields, which are populated by whichever account registers the workflow (an unprivileged workflow owner relative to the node operator) [4](#0-3) . `FetchWorkflowArtifacts` only overrides the owner-supplied URL with a signed retrieval URL when the URL host matches the configured `ArtifactStorageHost`; for any other host the owner-controlled URL/path segment is used as-is and handed to the configured `fetchFn`, which can be `newHTTPFetcher` [5](#0-4) , [6](#0-5) .

### Impact Explanation
When the gateway is configured with `NewFetcherFunc("https://host/sub/path", ...)` to expose only a specific sub-path of an internal or partner host for artifact retrieval, an unprivileged workflow owner can supply a `BinaryURL`/`ConfigURL` fragment containing `..` segments that cause the node to issue outbound GET requests to arbitrary sibling paths on that same host, bypassing the intended path-based access restriction. Depending on what else is reachable on that host, this could disclose unrelated resources or reach internal endpoints not meant to be exposed through the artifact-fetch proxy path. This is a request-path confusion / restriction-bypass issue rather than raw local file disclosure (the `os` file path variant is already protected).

### Likelihood Explanation
The vulnerable code path is only exercised when the deployment is configured to use the direct HTTP fetcher bypass (`NewFetcherFunc` with an `http`/`https` `baseURL`) rather than routing artifact fetches exclusively through the gateway/signed-URL flow. Where this configuration is used, any actor able to register a workflow (an unprivileged, external actor from the node's perspective) can trigger it by supplying a crafted `BinaryURL`/`ConfigURL` whose host does not match `ArtifactStorageHost`.

### Recommendation
Add the same base-path confinement check used in `newFileFetcher` to `newHTTPFetcher`: after joining and cleaning, verify the resulting `u.Path` still has the original base path as a prefix (with a path-separator boundary), and reject the request otherwise. Alternatively, reject any `req.URL` containing `..` path segments before joining, mirroring the archive-extraction Zip-Slip guard already used elsewhere in the codebase [7](#0-6) .

### Proof of Concept
```go
fetcher := newHTTPFetcher("https://internal-host.example.com/workflows", lggr)
// workflow owner supplies BinaryURL (used as req.URL) = "../admin/secret"
_, _ = fetcher(ctx, "msg-id", ghcapabilities.Request{
    URL:        "../admin/secret",
    WorkflowID: "attacker-workflow",
})
// resulting outbound request goes to
// https://internal-host.example.com/admin/secret
// instead of being confined to https://internal-host.example.com/workflows/*
```

// NewFetcher creates a new FetcherFunc based on the provided URL configuration
// The implementation supports both file and HTTP(S) URLs and bypasses the gateway
func NewFetcherFunc(baseURL string, lggr logger.Logger) (types.FetcherFunc, error) {
	if baseURL == "" {
		return nil, errors.New("baseURL cannot be empty")
	}

	u, err := url.Parse(baseURL)
	if err != nil {
		return nil, fmt.Errorf("invalid URL: %w", err)
	}

	switch u.Scheme {
	case "file":
		// Ensure the basePath is absolute
		if !filepath.IsAbs(u.Path) {
			return nil, fmt.Errorf("basePath must be an absolute path, got: %s", u.Path)
		}
		return newFileFetcher(u.Path, lggr), nil
	case "http", "https":
		return newHTTPFetcher(baseURL, lggr), nil
	default:
		return nil, fmt.Errorf("unsupported URL scheme: %s", u.Scheme)
	}
}

func (h *Store) FetchWorkflowArtifacts(ctx context.Context, workflowID, binaryURL, configURL string) ([]byte, []byte, error) {
	// Check if the workflow spec is already stored in the database.
	// A row whose binary payload is empty is a pause tombstone - don't use it.
	if spec, err := h.orm.GetWorkflowSpec(ctx, workflowID); err == nil && spec.Workflow != "" {
		// there is no update in the BinaryURL or ConfigURL, lets decode the stored artifacts
		decodedBinary, err := hex.DecodeString(spec.Workflow)
		if err != nil {
			return nil, nil, fmt.Errorf("failed to decode stored workflow spec: %w", err)
		}
		return decodedBinary, []byte(spec.Config), nil
	}

	// Determine which URL to retrieve workflow binary artifacts from
	parsedBinaryURL, err := url.Parse(binaryURL)
	if err != nil {
		return nil, nil, fmt.Errorf("invalid binary URL: %w", err)
	}

	// If the binary URL points to the artifact storage host, use the retrieve function to get the signed URL.
	// NOTE: retrieveFunc may be nil if the fetcherFunc was overridden.
	// TODO CRE-632: retrieverFunc should enforced made to always be set, once local CRE can support it.
	if h.retrieveFunc != nil && parsedBinaryURL.Host == h.config.ArtifactStorageHost {
		signedBinaryURL, err2 := h.retrieveFunc(ctx, &storage_service.DownloadArtifactRequest{
			Id:   workflowID,
			Type: storage_service.ArtifactType_ARTIFACT_TYPE_BINARY,
		})
		if err2 != nil {
			return nil, nil, fmt.Errorf("failed to get binary artifact URL: %w", err2)
		}
		binaryURL = signedBinaryURL
	}

	// Fetch the binary files from the specified URLs.
	var (
		binary, decodedBinary, config []byte

		return nil, nil, fmt.Errorf("failed to get binary size limit: %w", err)

		maxBinarySize = 0
	}

		URL:              binaryURL,
		Method:           http.MethodGet,
		MaxResponseBytes: safeUint32(uint64(maxBinarySize)),
		WorkflowID:       workflowID,
	}
	binary, err = h.fetchFn(ctx, messageID(binaryURL, workflowID), req)

		return nil, nil, &types.ArtifactFetchError{ArtifactType: "binary", URL: binaryURL, Err: err}

func newFetcherServiceV2(
	opts Opts,
	capCfg config.Capabilities,
	lggr logger.Logger,
	gatewayConnectorWrapper *gatewayconnector.ServiceWrapper,
) (wftypes.FetcherFunc, wftypes.LocationRetrieverFunc, []commonsrv.Service, error) {
	if opts.FetcherFunc != nil {
		return opts.FetcherFunc, nil, []commonsrv.Service{}, nil
	}

	if gatewayConnectorWrapper == nil {
		return nil, nil, nil, errors.New("unable to create workflow registry syncer without gateway connector")
	}

	wfStorage := capCfg.WorkflowRegistry().WorkflowStorage()
	storageClient := opts.StorageClient
	if wfStorage.URL() != "" {
		workflowOpts := []storage.WorkflowClientOpt{
			storage.WithJWTGenerator(opts.JWTGenerator),
		}
		if wfStorage.TLSEnabled() {
			workflowOpts = append(workflowOpts, storage.WithWorkflowTransportCredentials(credentials.NewClientTLSFromCert(nil, "")))
		}

		sc, err := storage.NewWorkflowClient(lggr, wfStorage.URL(), workflowOpts...)
		if err != nil {
			return nil, nil, nil, fmt.Errorf("failed to create storage client: %w", err)
		}

		storageClient = sc
	}

	if storageClient == nil {
		return nil, nil, nil, errors.New("must have a storage client")
	}

	fetcher := syncerV2.NewFetcherService(lggr, gatewayConnectorWrapper, storageClient)
	return fetcher.Fetch, fetcher.RetrieveURL, []commonsrv.Service{fetcher}, nil
}
