### Title
Stale delegate grants can regain account authority after an NFT transfer round trip - (File: contracts/controller/src/storage/account.rs)

### Summary
`Delegates(account_id)` records the grant’s original owner, but changing NFT ownership does not automatically delete or epoch-invalidate that grant. While another address owns the account, the stale grant is ignored because `get_delegates` is evaluated against the current owner. If the NFT later returns to the original owner, the unchanged `granted_by` value matches again and the former delegate becomes authorized without a fresh delegation from the owner. This is analogous to the missing `deinit()` bug class: lifecycle teardown does not unregister an authority created for the previous ownership epoch.

### Finding Description
`is_owner_or_delegate` accepts a caller when the caller is an active position manager listed in `storage::get_delegates(env, account_id, owner)` [1](#0-0) . `add_delegate` stores a `DelegateGrant` stamped with the granting owner [2](#0-1) . `remove_delegate` deletes a stale grant only when the current owner explicitly calls it; otherwise it merely returns `false` for an absent grant [3](#0-2) . No NFT transfer path clears the grant, and account deletion is the only lifecycle path shown deleting `Delegates(account_id)` [4](#0-3) . The regression test confirms that the stale grant must be explicitly purged by the intermediate owner to prevent resurrection after the NFT returns [5](#0-4) .

The strongest unprivileged path is `Controller::withdraw`. After the round trip, the reactivated delegate calls `withdraw(caller=delegate, account_id, withdrawals=[(hub_asset, 0)], to=Some(delegate))`; `process_withdraw` accepts delegates and permits an arbitrary external recipient [6](#0-5) . A zero amount is the withdraw-all sentinel [7](#0-6) .

### Impact Explanation
A formerly authorized position manager can withdraw the victim’s collateral to itself after the account NFT is transferred back to the victim. For a collateral-only account, post-withdrawal solvency does not prevent draining the supply. For indebted accounts, the delegate can still execute owner-equivalent actions such as `borrow`, `withdraw`, `swap_collateral`, `swap_debt`, `repay_debt_with_collateral`, `multiply`, and `flash_position`, subject to the normal risk gates; direct theft is clearest through withdrawal or borrowing proceeds to the delegate.

### Likelihood Explanation
The victim must previously delegate to an active position manager, transfer the account NFT, and later receive the same NFT back while that manager remains active. NFT sale, temporary transfer, custody handoff, or return can produce that sequence. The former delegate then needs no new victim authorization because the stored `granted_by` still names the victim.

### Recommendation
Invalidate delegate grants on every ownership transition rather than only on explicit removal. Store an owner epoch or NFT transfer counter in `DelegateGrant`, or have the NFT/controller ownership synchronization clear `Delegates(account_id)` before new ownership can be used. At minimum, expose and atomically execute a transfer cleanup path that removes all grants whenever `account_owner` changes, including when the NFT returns to a prior owner.

### Proof of Concept
1. Alice supplies collateral and calls `add_delegate(Alice, account_id, MalloryManager)` while `MalloryManager` is active.
2. Alice calls `PositionNft::transfer(Alice, Bob, account_id)`. The controller’s `Delegates(account_id)` entry remains stamped `granted_by=Alice`.
3. Bob does not call `remove_delegate` and transfers the NFT back to Alice.
4. `is_owner_or_delegate(account_id, MalloryManager, Alice)` again resolves `get_delegates(account_id, Alice)`, finds `MalloryManager`, and accepts it.
5. MalloryManager calls `withdraw(caller=MalloryManager, account_id, withdrawals=[(collateral_key, 0)], to=Some(MalloryManager))`, draining Alice’s collateral.

/// Accepts the owner or a registered, active manager delegated by that owner.
pub(crate) fn is_owner_or_delegate(
    env: &Env,
    account_id: u64,
    caller: &Address,
    owner: &Address,
) -> bool {
    if caller == owner {
        return true;
    }
    let active_manager =
        storage::get_position_manager(env, caller).is_some_and(|config| config.is_active);
    active_manager && storage::get_delegates(env, account_id, owner).contains(caller)
}

/// Adds a delegate, enforcing `MAX_DELEGATES`; returns false for duplicates.
/// Overwrites stale grants with a list stamped by the current owner.
pub(crate) fn add_delegate(
    env: &Env,
    account_id: u64,
    owner: &Address,
    delegate: &Address,
) -> bool {
    let mut delegates = get_delegates(env, account_id, owner);
    if delegates.contains(delegate) {
        return false;
    }
    assert_with_error!(
        env,
        delegates.len() < MAX_DELEGATES,
        GenericError::RegistryCapReached
    );
    delegates.push_back(delegate.clone());
    set_delegates(env, account_id, owner, &delegates);
    true
```

pub(crate) fn remove_delegate(
    env: &Env,
    account_id: u64,
    owner: &Address,
    delegate: &Address,
) -> bool {
    let key = ControllerKey::Delegates(account_id);
    let Some(grant) = get_user::<DelegateGrant>(env, &key) else {
        return false;
    };
    if grant.granted_by != *owner {
        env.storage().persistent().remove(&key);
        return false;
    }
    let mut delegates = grant.delegates;
    let Some(index) = delegates.first_index_of(delegate) else {
        return false;
    };
    delegates.remove(index);
    set_delegates(env, account_id, owner, &delegates);
```

/// Enforces exit flags and withdraws the batch, treating zero as withdraw-all.
/// Returns each asset's actual pool payout.
fn settle_withdraw(
    env: &Env,
    account: &mut Account,
    recipient: &Address,
    aggregated: &AggregatedPayments,
    cache: &mut Context,
) -> Vec<HubPayment> {
    let mut entries: Vec<PoolWithdrawEntry> = Vec::new(env);
    for (hub_asset, amount) in aggregated.iter() {
        enforce_spoke_asset_flags(
            env,
            cache,
            account.spoke_id,
            &hub_asset,
            FreezePolicy::AllowOnExit,
        );
        let position = get_supply_position_or_panic(env, account, &hub_asset);
        let requested = if amount == 0 {
            WITHDRAW_ALL_SENTINEL
        } else {
            amount
        };
        entries.push_back(PoolWithdrawEntry {
            action: make_pool_action(&position, requested, hub_asset.clone()),
            protocol_fee: 0,
        });
