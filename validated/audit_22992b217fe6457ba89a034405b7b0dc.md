### Title
Missing `extcodesize` check on GET-response/timeout delivery lets a relayer collect fees for callbacks that never execute - ([File: evm/src/core/EvmHost.sol])

### Summary
`EvmHost.dispatchIncoming` for POST requests explicitly guards against delivering to a non-existent contract with an `extcodesize` check, but the sibling delivery paths — `dispatchIncoming(GetResponse memory, address)` and both `dispatchTimeOut` overloads — perform a raw low-level `.call()` to the request's `from` address with no such check. A low-level `call` to an address with no deployed code always returns `success == true` in the EVM, so if that address is codeless (a self-destructed module, a bricked/rug-pulled proxy, or any account that never had a contract), the Host treats the delivery as successful: it commits the response/timeout receipt and — in the GET-response path — pays the relayer fee out of the Host's balance, even though the target application's `onGetResponse`/`onGetTimeout`/`onPostRequestTimeout` handler never actually ran.

### Finding Description
`EvmHost.dispatchIncoming(PostRequest memory request, address relayer)` correctly hardens against calling a codeless destination: [1](#0-0) 

But the GET-response delivery function immediately below it skips this check entirely and calls `.call()` directly on the request's originating module (`response.request.from`), then unconditionally trusts `success`: [2](#0-1) 

The two `dispatchTimeOut` overloads (for `GetRequestTimeout` and `PostRequestTimeout`) have the identical pattern — a bare `.call()` on `_bytesToAddress(timeout.request.from)` with no code-existence guard: [3](#0-2) 

`request.from` / `timeout.request.from` for GET requests is simply `abi.encodePacked(_msgSender())` captured at dispatch time in `dispatch(DispatchGet memory get)`, with no restriction that the caller must be (or remain) a contract: [4](#0-3) 

Because Solidity's low-level `call` to a codeless address is a no-op that reports `success = true` (this is the exact EVM semantics the original NuCypher `Dispatcher` bug exploits), any relayer who is first to submit a valid consensus/state-membership proof for a response or timeout whose originating module has since become codeless (self-destructed, or a proxy whose implementation was removed/bricked, or any address that was never actually deployed) causes the Host to:
1. Permanently record the response/timeout as delivered (module never gets a retry — the actual callback logic never executed), and
2. In the GET-response case, transfer the accrued relayer fee to the relayer for a "delivery" that produced no effect at the destination.

This mirrors the reported `Dispatcher` bug class precisely: the difference between "the call succeeded" and "the callee actually exists and ran its logic" is silently erased, and one sibling code path in the same contract (`dispatchIncoming(PostRequest)`) already demonstrates the fix (`extcodesize`) was known and applied — just not consistently to the GET-response and timeout paths.

### Impact Explanation
This breaks two protocol guarantees:
- **Relayer fee accounting integrity**: relayer fees for GET responses are paid out even when the destination module cannot possibly process the callback, effectively letting a relayer claim rewards for undelivered/void deliveries whenever the target address happens to be (or becomes) codeless.
- **Message delivery soundness**: once `_responseReceipts`/`_requestCommitments` bookkeeping marks the response/timeout as processed, it can never be retried, permanently and silently dropping the message for the destination application — a route that is unable to deliver its message, matching the "unable to deliver messages" impact bucket.

Both are reachable purely from a relayer submitting an otherwise-legitimate proof for a real, previously dispatched GET request/timeout — no privileged or malicious-admin action is required on Hyperbridge's side; only the target module becoming codeless (a realistic and observable on-chain event, e.g., `SELFDESTRUCT`, a bricked proxy, or a counterfactual address) is needed.

### Likelihood Explanation
Likelihood is moderate: it requires a scenario where the module that originally called `dispatch(DispatchGet)` (or whose POST request later times out) no longer has code at delivery time. This is plausible in an ecosystem with upgradeable/proxy modules, self-destructible contracts, or integrations that dispatch from smart-contract wallets/counterfactual addresses. Any relayer — an unprivileged, permissionless role by design (`IHandlerV2` is explicitly "permissionless — anyone can call") — can trigger the faulty branch simply by delivering the proof once such a condition exists.

### Recommendation
Add the same `extcodesize` (or `<address>.code.length`) guard used in `dispatchIncoming(PostRequest)` to `dispatchIncoming(GetResponse)` and to both `dispatchTimeOut` overloads before performing the low-level `.call()`, returning early (without committing the receipt or paying relayer fees) when the destination has no code — exactly mirroring the existing POST-request path.

### Proof of Concept
1. A module `M` calls `EvmHost.dispatch(DispatchGet{...})`, becoming `request.from = M`.
2. Before the response is relayed back, `M` executes `SELFDESTRUCT` (or is a proxy whose implementation is cleared/bricked), so `M` is now a codeless address.
3. A relayer submits a valid state-proof to `HandlerV2.handleGetResponses`, which calls `EvmHost.dispatchIncoming(GetResponse, relayer)`.
4. Inside `dispatchIncoming`, `_bytesToAddress(response.request.from).call(...)` targets `M` (codeless) and returns `success = true` per EVM semantics, even though no `onGetResponse` logic ran.
5. The Host records the response receipt as delivered (permanent, no retry possible) and pays the accrued relayer fee out of `feeToken()` to the relayer — despite the response never having been processed by any real contract logic.

    function dispatchIncoming(PostRequest memory request, address relayer) external restrict(_hostParams.handler) {
        address destination = _bytesToAddress(request.to);
        uint256 size;
        assembly {
            size := extcodesize(destination)
        }
        if (size == 0) {
            // instead of reverting the entire batch, early return here.
            return;
        }

        // replay protection
        bytes32 commitment = request.hash();
        _requestReceipts[commitment] = relayer;

        (bool success,) = address(destination)
            .call(abi.encodeWithSelector(IApp.onAccept.selector, IncomingPostRequest(request, relayer)));

        if (!success) {
            // so that it can be retried
            delete _requestReceipts[commitment];
            return;
        }
        emit PostRequestHandled({commitment: commitment, relayer: relayer});

     * @dev Dispatch an incoming GET response to source module
     * @param response - get response

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }
