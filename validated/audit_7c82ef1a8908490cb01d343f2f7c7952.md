### Title
Unauthenticated magic-QR DoS forces WiFi/mirror reset with no operator authorization - (File: src/plans/mod.rs)

### Summary
The `magic_action:reset_wifi_credentials` and `magic_action:reset_mirror_calibration` QR-code strings are parsed by `qr_scan::operator::Data::try_parse` with zero authentication, and `MasterPlan::handle_magic_operator_qr_code` executes the corresponding privileged action (`reset_wifi_and_ensure_network` / `reset_mirror_calibration`) immediately upon detection. Since these strings are hard-coded in the open-source repository, any person with a printed QR code and physical proximity to an idle orb can trigger a WiFi de-provisioning or mirror recalibration reset without any operator QR-code, backend validation, or credential check.

### Finding Description
`qr_scan::operator::Data::try_parse` first attempts to parse the code as a normal operator QR (which requires a valid `userid:...` format and, downstream, backend validation via `backend::operator_status::request`), but falls back to matching the unauthenticated `MAGIC_QR_CODE` regex if that fails: [1](#0-0) 

`scan_initial_qr_codes` and `scan_remaining_qr_codes` call `handle_magic_operator_qr_code` directly after scanning the operator QR code, *before* any call to `verify_operator_qr_code` (the function that performs backend/location validation for normal operator codes): [2](#0-1) [3](#0-2) 

`handle_magic_operator_qr_code` executes the privileged action unconditionally on match, with no operator session, PIN, or backend check gating it: [4](#0-3) 

The wifi-reset path forcibly restores default wpa_supplicant config and reconfigures the interface, then blocks in `wifi::Plan::ensure_network_connection` waiting for a new WiFi-credential QR to be scanned: [5](#0-4) [6](#0-5) [7](#0-6) 

The mirror-reset path resets calibration to config defaults and writes it to disk immediately: [8](#0-7) 

No invariant enforces that these magic actions require an authenticated operator session; the string values themselves are visible in the public source tree, so no secret knowledge is needed to construct the trigger QR code.

### Impact Explanation
An unprivileged person who merely presents a QR code to the orb's camera during the idle loop can:
1. Force `network::reset()`, wiping the configured WiFi credentials and leaving the orb stuck in `wifi::Plan::ensure_network_connection`'s scan-loop until someone provides new WiFi credentials — a signup-availability denial-of-service that requires operator intervention to recover.
2. Force `reset_mirror_calibration`, silently degrading eye-tracking/capture quality for all subsequent signups until it is manually recalibrated.

Both are reachable repeatedly (loop back to `scan_initial_qr_codes`/`scan_remaining_qr_codes` on every presentation), matching the "signup-state wedge" / availability-impact category, since the orb cannot serve signups while re-provisioning WiFi.

### Likelihood Explanation
Feasibility is high: the magic strings are static and public (visible in this open-source repository), require no operator credentials, no backend interaction, and no hardware tampering — only printing/displaying the QR string to the RGB camera during the idle "waiting for operator QR" phase. It's fully repeatable since the idle loop re-enters `scan_initial_qr_codes`/`scan_remaining_qr_codes` after every failed/completed magic action.

### Recommendation
Gate `Data::MagicResetWifi` / `Data::MagicResetMirror` behind the same authorization path as `Data::Normal` operator codes (e.g., require a valid, backend-verified operator QR/session token before honoring `magic_action:*` codes), or require a locally-provisioned secret/PIN not derivable from public source, and add rate-limiting/cool-down for magic actions.

### Proof of Concept
Integration test plan (extending existing tests in `src/plans/mod.rs`'s `mod tests`):
1. Build a `MasterPlan` with no operator authentication configured.
2. Feed `qr_scan::operator::Data::try_parse("magic_action:reset_wifi_credentials")` into `handle_magic_operator_qr_code` directly (bypassing `verify_operator_qr_code`), and assert that `reset_wifi_and_ensure_network` (mocked to record invocation) is called despite no operator session/backend validation having occurred.
3. Loop the call N times and assert `network::reset()` (mocked) is invoked N times with no fraud/authorization gate ever consulted, demonstrating unrestricted repeatable invocation.
4. Assert equivalent behavior for `magic_action:reset_mirror_calibration` invoking `reset_mirror_calibration` unconditionally.
Expected assertion: privileged reset actions execute without any authenticated-operator marker being present in the `MasterPlan`/`OperatorData` state, proving the invariant "no unauthorized state transitions from unprivileged QR input" is violated for magic QR actions.

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}

impl Plan {
    /// Checks whether connected to a WiFi network, if not connected scan the
    /// hotspot QR code.
    pub async fn ensure_network_connection(&self, orb: &mut Orb) -> Result<()> {
        let mut in_progress_start = Instant::now();
        let mut has_requested_qr_code = false;
        let success = |orb: &mut Orb, has_requested_qr_code| {
            if has_requested_qr_code {
                orb.ui.network_connection_success();
            }
            tracing::debug!("Network is connected");
            Ok::<(), Error>(())
        };
        loop {
            match network::status().await? {
                network::Status::Connected { has_internet: true } => {
                    success(orb, has_requested_qr_code)?;
                    break;
                }
                network::Status::InProgress
                | network::Status::Connected { has_internet: false }
                    if in_progress_start.elapsed() < NETWORK_CONNECTION_TIMEOUT =>
                {
                    tracing::debug!("Network connection in progress");
                    sleep(Duration::from_millis(250)).await;
                }
                network::Status::Connected { has_internet: false }
                | network::Status::Disconnected
                | network::Status::InProgress => {
                    tracing::debug!("Network is disconnected, or has no connection to the backend");
                    if has_requested_qr_code {
                        orb.ui.qr_scan_fail(QrScanSchema::Wifi);
                    }
                    has_requested_qr_code = true;
                    match qr_scan::Plan::new(None, false).run(orb).await? {
                        Ok((credentials, _)) => {
                            tracing::info!(
                                "Read WiFi credentials from hotspot QR: {:?}",
                                credentials
                            );
                            network::join(credentials).await?;
                            in_progress_start = Instant::now();
                        }
                        Err(qr_scan::ScanError::Invalid) => {
                            orb.ui.qr_scan_unexpected(
                                QrScanSchema::Wifi,
                                QrScanUnexpectedReason::WrongFormat,
                            );
                        }
                        Err(qr_scan::ScanError::Timeout) => {}
                    }
                    orb.reset_rgb_camera().await?;
                }
            }
        }
        Ok(())
    }
