The bug class in the report (a custom index mapping like `voucherIndexes` that isn't updated when an entry is removed from a swap-and-pop array, leaving a stale index pointing at a different owner's entry) has no reachable analog in alt.fun's in-scope contracts.

The only indexed/removable collections in `packages/contracts/src` are `Bonding._routers` and `FeeVault.depositors`, both `EnumerableSet.AddressSet` from OpenZeppelin, whose `_remove` correctly updates `_positions[lastValue]` on swap-and-pop [1](#0-0) . So the underlying index-staleness bug class simply isn't present in the library used.

Additionally, mutation of these sets (`addRouter`/`removeRouter`, `addDepositor`/`removeDepositor`) is owner-only [2](#0-1) , which falls outside the allowed unprivileged-caller surface (Zap buy/sell, Bonding triggerGraduation/finalizeGraduation/transferCreator, FeeVault claim/claimProtocol/sweepDonations, direct token transfers). No other list/array-with-index data structure exists in `Bonding.sol`, `Zap.sol`, `Pair.sol`, `Router.sol`, `Factory.sol`, or `LPLock.sol` that an unprivileged trader, creator, or LP could corrupt into a stale-index state.

    function _remove(Set storage set, bytes32 value) private returns (bool) {
        // We cache the value's position to prevent multiple reads from the same storage slot
        uint256 position = set._positions[value];

        if (position != 0) {
            // Equivalent to contains(set, value)
            // To delete an element from the _values array in O(1), we swap the element to delete with the last one in
            // the array, and then remove the last element (sometimes called as 'swap and pop').
            // This modifies the order of the array, as noted in {at}.

            uint256 valueIndex = position - 1;
            uint256 lastIndex = set._values.length - 1;

            if (valueIndex != lastIndex) {
                bytes32 lastValue = set._values[lastIndex];

                // Move the lastValue to the index where the value to delete is
                set._values[valueIndex] = lastValue;
                // Update the tracked position of the lastValue (that was just moved)
                set._positions[lastValue] = position;
            }

            // Delete the slot where the moved value was stored
            set._values.pop();

            // Delete the tracked position for the deleted slot
            delete set._positions[value];

            return true;
        } else {
            return false;
        }
    }
