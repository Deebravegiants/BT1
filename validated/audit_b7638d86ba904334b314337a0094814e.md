## Title
Unauthenticated Disclosure of Internal LOOP Plugin Metrics and pprof Debug Data via `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*` - (File: `core/web/router.go`, `core/web/loop_registry.go`)

### Summary
The LOOP (Local Out Of Process) registry HTTP routes are mounted on chainlink's node router without any authentication middleware, unlike essentially every other operational/administrative endpoint in the same router. These routes proxy Prometheus metrics and full Go `pprof` debug data (heap, goroutine, profile, trace, symbol) from internal plugin processes to any unauthenticated network caller who can reach the node's HTTP port, mirroring the class of bug in the reported AVideo CVE-2026-86727: an unauthenticated endpoint that discloses internal/sensitive operational data by simply hitting the right path.

### Finding Description
`NewRouter` builds an `api` route group that only applies rate limiting, CORS, and session middleware — it does **not** require authentication: [1](#0-0) 

`loopRoutes(app, api)` registers its handlers directly on this unauthenticated `api` group, in contrast to `v2Routes`, whose sensitive endpoints are wrapped in `auth.Authenticate(...)`-protected `authv2` groups: [2](#0-1) 

The registered handlers are:
- `GET /discovery` — enumerates all registered LOOP plugin names via `l.registry.List()`, revealing internal plugin topology.
- `GET /plugins/:name/metrics` — proxies to `http://<loopHostName>:<PrometheusPort>/metrics` on the internal plugin process and returns the raw body to the caller.
- `GET /plugins/:name/debug/pprof/*profile` and `POST /plugins/:name/debug/pprof/symbol` — proxy directly to the internal plugin's `/debug/pprof/...` endpoints (heap, goroutine, profile, trace, symbol) and return the raw response. [3](#0-2) [4](#0-3) [5](#0-4) 

None of these handler functions perform any authentication or role check themselves — they only validate that the named plugin exists via `l.registry.Get(pluginName)`, and then forward the request/response bytes verbatim.

### Impact Explanation
An unauthenticated attacker who can reach the node's web port can:
- Enumerate internal LOOP plugin names and their metrics scrape paths via `/discovery`.
- Pull raw Prometheus `/metrics` output for each plugin (internal counters, labels, potentially chain/job identifiers) via `/plugins/:name/metrics`.
- Pull full Go `pprof` `heap`, `goroutine`, `profile`, and `trace` dumps via `/plugins/:name/debug/pprof/*profile`, which can reveal in-memory data (including strings/keys held in memory), internal call graphs, environment details, and process internals — a materially more severe information-disclosure primitive than the referenced AVideo bug, which leaked stream keys/URLs.
- Trigger CPU/goroutine profiling with attacker-controlled `seconds` parameter (`pprofURLVals`), causing sustained load against the internal plugin process (secondary availability concern) without any credentials.

This matches the "unauthenticated request discloses sensitive internal data" bug class from the report, mapped onto chainlink's node-facing HTTP API surface rather than a gateway/peer path, and is a concrete internet-facing authentication bypass for endpoints that should require session/API-key auth like their `authv2` siblings (e.g., `BuildInfoController`, `ConfigController`).

### Likelihood Explanation
High for any deployment where the node's HTTP API port is reachable by unauthenticated clients (default chainlink web server binds a port intended to be reached by operators, but the routes here carry no auth check at all, unlike every comparable admin/debug route registered under `authv2`). No credentials, tokens, or special network position are required — a plain HTTP GET/POST suffices.

### Recommendation
Move `loopRoutes(app, api)` under an authenticated group (e.g., register it alongside `metricRoutes(authv2)` inside `authv2`, requiring `auth.Authenticate` + an appropriate role such as `auth.RequiresAdminRole`), consistent with how `BuildInfoController`, `ConfigController`, and other operational endpoints are protected in `core/web/router.go`. At minimum the pprof proxy endpoints (`pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`) should require authentication given the sensitivity of heap/goroutine dumps.

### Proof of Concept
Against a running chainlink node with LOOP plugins registered, without any Authorization header or session cookie:
```
GET /discovery HTTP/1.1
Host: <node-host>:<port>
```
returns JSON listing all registered plugin names and their metrics paths, and:
```
GET /plugins/<pluginName>/debug/pprof/heap HTTP/1.1
Host: <node-host>:<port>
```
returns a raw heap profile dump from the internal plugin process — all without authentication, analogous to the unauthenticated `stats.json.php` disclosure in the reported CVE.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

// pluginMetricHandlers routes from endpoints published in service discovery to the backing LOOP endpoint
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
