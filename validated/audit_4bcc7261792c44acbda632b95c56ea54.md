### Title
Unauthenticated "magic" QR codes let anyone trigger privileged operator-only device actions (WiFi reset, mirror recalibration) before operator authorization is verified - (File: `src/plans/mod.rs`)

### Summary
The reported bug class is "privileged rescue functions callable by anyone because the caller-authorization check is bypassed by a legitimate-looking flow." The orb-core analog is `handle_magic_operator_qr_code`, which executes privileged, operator-only device actions (Wi-Fi credential reset and mirror-calibration reset) as soon as a QR code is scanned, but *before* the scanned code's operator identity/authorization is checked against the backend via `verify_operator_qr_code`.

### Finding Description
In the normal signup flow (`scan_remaining_qr_codes`) and the self-serve flow (`scan_initial_qr_codes`), the sequence is:

1. `scan_operator_qr_code` reads whatever QR code is shown to the camera.
2. `handle_magic_operator_qr_code` is called immediately and, if the QR text matches `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration`, unconditionally performs `reset_wifi_and_ensure_network` or `reset_mirror_calibration` — with no operator/backend authentication at all.
3. Only *afterwards*, and only for the "Normal" (non-magic) QR branch, is `verify_operator_qr_code` called to validate the code against the signup backend. [1](#0-0) [2](#0-1) 

The magic QR codes are parsed purely by regex client-side, with no signature, no operator-ID lookup, and no backend round trip: [3](#0-2) 

Because the magic-action branch returns `Ok(None)` and never reaches `verify_operator_qr_code`, there is no code path in which these actions are gated on operator authorization — exactly analogous to the LooksRare finding where `_returnETHIfAny`/`_returnERC20TokensIfAny` handed funds to `msg.sender` without checking that the caller was the contract owner. Here, the orb hands privileged device control ("reset the Wi-Fi network", "invalidate/reset physical mirror calibration") to whoever can present the magic text to the camera, without checking they are an authorized operator.

### Impact Explanation
Any person able to display the string `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration` to the orb's camera (e.g., printed on paper, phone screen) can force the device to drop/reset its network connection or invalidate its mirror calibration, with no operator authentication step. Repeated/scripted triggering can be used as a persistent denial-of-service against the orb (breaking connectivity or re-triggering calibration procedures) by anyone with brief physical access to the device's camera, not just the intended field operator. This undermines the operator-authorization model that the rest of the QR flow (`verify_operator_qr_code`) is built to enforce.

### Likelihood Explanation
High. No secret, signature, or backend validation is required — the attacker only needs the fixed magic string, which is visible in this open-source client code and in the regex `MAGIC_QR_CODE` pattern itself. It requires only camera-visible access, which is the same trust level as an ordinary unprivileged bystander showing a QR code to the device.

### Recommendation
Move `handle_magic_operator_qr_code`'s privileged branches to run only after `verify_operator_qr_code` succeeds (i.e., only allow magic actions once the scanned QR has been authenticated against the backend as belonging to an authorized operator/distributor), or require an explicit signed/authenticated magic-action payload instead of a bare, unauthenticated regex match.

### Proof of Concept
1. Print or display a QR code containing exactly `magic_action:reset_wifi_credentials`.
2. Present it to the orb's camera during idle/signup QR scanning.
3. `scan_operator_qr_code` returns `qr_scan::operator::Data::MagicResetWifi` after regex match in `try_parse` (no backend call). [4](#0-3) 
4. `handle_magic_operator_qr_code` is invoked and unconditionally calls `reset_wifi_and_ensure_network`, tearing down and re-establishing the orb's network connection, before any `verify_operator_qr_code` call occurs. [5](#0-4) 
5. No operator credential, backend session, or authorization check was ever performed.

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

static MAGIC_QR_CODE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")
});

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }
