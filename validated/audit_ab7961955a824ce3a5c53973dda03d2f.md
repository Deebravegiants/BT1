**Rationale:**

The premise requires an attacker to publish or "shadow" a module at `TOKEN_ADDRESS` (`0x3`), which is a reserved framework address. Publishing or upgrading modules at `0x3` requires framework/governance-level privileges (multi-sig/governance upgrade authority), not unprivileged transaction access. This violates the review bounds requirement that "the path must start from unprivileged transaction" and the decision standard to "reject anything that needs pre-existing permissions." [1](#0-0) 

Additionally, `DEFAULT_PROPERTY_MUTATE_EVENT_TYPE`'s `TypeTag` is derived directly from `StructTag { address: TOKEN_ADDRESS, module: "token_event_store", name: "DefaultPropertyMutateEvent" }`, and event data (`ContractEventV2`) is only ever produced by the actual VM executing the real, deployed `token_event_store` module's bytecode — the VM enforces that a struct's `TypeTag` address matches the module's actual on-chain address (this is fundamental to Move's type system and cannot be forged by unprivileged callers via bytecode or transaction input). [2](#0-1)  There is no code path in `event_v2_translator.rs` where an unprivileged transaction can inject an arbitrary `ContractEventV2` with a forged `TypeTag` for translation — the translator only processes events that the VM already validated and stored in the ledger. [3](#0-2) 

Finally, even in the hypothetical scenario, the `event_v2_translator.rs` component is part of the **indexer** subsystem — it translates V2 events to V1 format for indexing/query consumption, and does not gate any custody operation (deposit, withdraw, transfer, mint, burn, freeze, or upgrade). [4](#0-3)  Property-map mutation events reflect state that is separately computed and stored in `TokenEventStoreV1Resource`/`property_map` on-chain state; the event itself does not authorize any state mutation — it is a side-effect log of an already-completed authorized mutation. There is no consumer described that relies solely on `TypeTag` equality to authorize a custody-relevant action (ownership, mint, burn, freeze, upgrade). This fails the Custody Impact Gate, which requires impacts "tied to asset and ownership control," and the finding is explicitly event-level/cosmetic, which the decision standard instructs to reject.

struct DefaultPropertyMutateTranslator;
impl EventV2Translator for DefaultPropertyMutateTranslator {
    fn translate_event_v2_to_v1(
        &self,
        v2: &ContractEventV2,
        engine: &EventV2TranslationEngine,
    ) -> Result<ContractEventV1> {
        let default_property_mutate = DefaultPropertyMutate::try_from_bytes(v2.event_data())?;
        let struct_tag = StructTag::from_str("0x3::token_event_store::TokenEventStoreV1")?;
        let (key, sequence_number) = if let Some(state_value_bytes) = engine
            .get_state_value_bytes_for_resource(default_property_mutate.creator(), &struct_tag)?
        {
            let object_resource: TokenEventStoreV1Resource = bcs::from_bytes(&state_value_bytes)?;
            let key = *object_resource.default_property_mutate_events().key();
            let sequence_number = engine.get_next_sequence_number(
                &key,
                object_resource.default_property_mutate_events().count(),
            )?;
            (key, sequence_number)
        } else {
            // If the TokenEventStoreV1 resource is not found, we skip the event translation to
            // avoid panic because the creation number cannot be decided.
            return Err(AptosDbError::from(anyhow::format_err!(
                "TokenEventStoreV1 resource not found"
            )));
        };
        let default_property_mutate_event = DefaultPropertyMutateEvent::new(
            *default_property_mutate.creator(),
            default_property_mutate.collection().clone(),
            default_property_mutate.token().clone(),
            default_property_mutate.keys().clone(),
            default_property_mutate.old_values().clone(),
            default_property_mutate.new_values().clone(),
        );
        Ok(ContractEventV1::new(
            key,
            sequence_number,
            DEFAULT_PROPERTY_MUTATE_EVENT_TYPE.clone(),
            bcs::to_bytes(&default_property_mutate_event)?,
        )?)
    }
}
