### Title
`limitSecretReferences` only validates Secret-typed volumes and container env/envFrom, missing all other volume-source secret references, allowing an unauthorized Secret to be mounted despite `enforce-mountable-secrets` - ([File: plugin/pkg/admission/serviceaccount/admission.go])

### Summary
`Plugin.limitSecretReferences` re-implements secret-reference discovery instead of reusing `podutil.VisitPodSecretNames`, and only checks `pod.Spec.Volumes[*].VolumeSource.Secret`, container `Env`/`EnvFrom`, and `ImagePullSecrets`. It does not check the many other volume-source fields that can reference a Secret by name (`Projected.Sources[*].Secret`, `AzureFile.SecretName`, `CephFS/Cinder/FlexVolume/RBD/ScaleIO/ISCSI/StorageOS.SecretRef`, `CSI.NodePublishSecretRef`) even though `podutil.VisitPodSecretNames` (used elsewhere in this same file for mirror-pod checks) explicitly visits all of these.

### Finding Description
`Plugin.Validate` calls `s.limitSecretReferences(serviceAccount, pod)` when `enforceMountableSecrets(serviceAccount)` is true [1](#0-0) . `limitSecretReferences` builds a `mountableSecrets` set from `serviceAccount.Secrets` and then validates only three reference sources: plain `Secret` volume sources, `InitContainers`/`Containers` `Env.ValueFrom.SecretKeyRef` and `EnvFrom.SecretRef`, and `pod.Spec.ImagePullSecrets` [2](#0-1) .

By contrast, the generic secret-reference visitor `podutil.VisitPodSecretNames`, used elsewhere in the very same admission plugin for the mirror-pod secret check [3](#0-2) , walks a much larger set of fields: `ImagePullSecrets`, container env/envFrom, and volume sources `AzureFile.SecretName`, `CephFS.SecretRef`, `Cinder.SecretRef`, `FlexVolume.SecretRef`, `Projected.Sources[*].Secret`, `RBD.SecretRef`, `Secret.SecretName`, `ScaleIO.SecretRef`, `ISCSI.SecretRef`, `StorageOS.SecretRef`, and `CSI.NodePublishSecretRef` [4](#0-3) .

`limitSecretReferences` implements none of the volume-source cases other than plain `Secret`. Consequently, a pod that references an unlisted secret through, e.g., a `Projected` volume's `Secret` source, or a `CSI` volume's `NodePublishSecretRef`, or `CephFS`/`ISCSI`/`StorageOS`/`ScaleIO`/`RBD`/`Cinder`/`FlexVolume`/`AzureFile` `SecretRef`/`SecretName` fields, will pass `limitSecretReferences` unrejected even when `EnforceMountableSecrets` (via the SA annotation `kubernetes.io/enforce-mountable-secrets`) is enabled, because none of these fields are checked against `mountableSecrets`.

The attacker's request path is a plain namespaced `pods` create call (`a.GetOperation() == admission.Create`), which reaches `Plugin.Validate` → `limitSecretReferences` with a pod spec they fully control. No additional RBAC beyond "create pods in own namespace" is required, and the check is a pure admission-time validation gap — nothing else in the chain (`Admit`, `shouldIgnore`, `enforceMountableSecrets`) closes it.

### Impact Explanation
This is a validation-totality bypass in an admission controller that enforces Secret-mount tenant isolation between ServiceAccounts (`enforce-mountable-secrets`). An attacker who can only create Pods (using a ServiceAccount they do not control the `.secrets`/`.imagePullSecrets` list of) can still cause the kubelet to fetch and mount an arbitrary Secret in the same namespace by referencing it through a `Projected` volume's `Secret` source or another unvalidated volume-secret field, defeating the intended isolation control and gaining read access to another workload's credentials/Secret data within the namespace. This matches the "Admission bypass leading to unauthorized Secret exposure / cross-workload credential access" bounty class.

### Likelihood Explanation
Preconditions are minimal: the target namespace must have a ServiceAccount with `enforce-mountable-secrets` (or the cluster-wide `LimitSecretReferences` flag) enabled, and the attacker only needs `create` permission on `pods` in that namespace (a common, low-privilege RBAC grant). The exploit requires no special timing or race condition — a single `Pod` create request with a `Projected` volume referencing an arbitrary secret name is sufficient and fully deterministic/repeatable.

### Recommendation
Rewrite `limitSecretReferences` (and `limitEphemeralContainerSecretReferences`) to use `podutil.VisitPodSecretNames(pod, visitor, podutil.AllContainers)` against `mountableSecrets` (still separately validating `ImagePullSecrets` against the SA's `ImagePullSecrets`), ensuring every volume-source and container secret-reference field is covered, matching the total set already used for the mirror-pod check in this file.

### Proof of Concept
Table test in `plugin/pkg/admission/serviceaccount/admission_test.go`:
1. Create a `ServiceAccount` with annotation `kubernetes.io/enforce-mountable-secrets: "true"` and `Secrets: []` (no secrets referenced).
2. For each volume-source variant that can carry a secret name (`Projected.Sources[*].Secret`, `AzureFile`, `CephFS`, `Cinder`, `FlexVolume`, `RBD`, `ScaleIO`, `ISCSI`, `StorageOS`, `CSI.NodePublishSecretRef`), construct a Pod using that ServiceAccount with a volume referencing an unlisted secret name (e.g., `"forbidden-secret"`).
3. Call `Plugin.Admit`/`Plugin.Validate` with `admission.Create` for each pod variant.
4. Assert that admission is rejected with a forbidden error (mirroring the existing assertions for the `Secret` volume-source case and container env/envFrom cases).
5. Expected current (buggy) result: all non-`Secret` volume-source variants are admitted (no error), demonstrating the gap; after the fix, all variants should return `admission.NewForbidden`.

```go
func (s *Plugin) limitSecretReferences(serviceAccount *corev1.ServiceAccount, pod *api.Pod) error {
	// Ensure all secrets the pod references are allowed by the service account
	mountableSecrets := sets.NewString()
	for _, s := range serviceAccount.Secrets {
		mountableSecrets.Insert(s.Name)
	}
	for _, volume := range pod.Spec.Volumes {
		source := volume.VolumeSource
		if source.Secret == nil {
			continue
		}
		secretName := source.Secret.SecretName
		if !mountableSecrets.Has(secretName) {
			return fmt.Errorf("volume with secret.secretName=\"%s\" is not allowed because service account %s does not reference that secret", secretName, serviceAccount.Name)
		}
	}

	for _, container := range pod.Spec.InitContainers {
		for _, env := range container.Env {
			if env.ValueFrom != nil && env.ValueFrom.SecretKeyRef != nil {
				if !mountableSecrets.Has(env.ValueFrom.SecretKeyRef.Name) {
					return fmt.Errorf("init container %s with envVar %s referencing secret.secretName=\"%s\" is not allowed because service account %s does not reference that secret", container.Name, env.Name, env.ValueFrom.SecretKeyRef.Name, serviceAccount.Name)
				}
			}
		}
		for _, envFrom := range container.EnvFrom {
			if envFrom.SecretRef != nil {
				if !mountableSecrets.Has(envFrom.SecretRef.Name) {
					return fmt.Errorf("init container %s with envFrom referencing secret.secretName=\"%s\" is not allowed because service account %s does not reference that secret", container.Name, envFrom.SecretRef.Name, serviceAccount.Name)
				}
			}
		}
	}

	for _, container := range pod.Spec.Containers {
		for _, env := range container.Env {
			if env.ValueFrom != nil && env.ValueFrom.SecretKeyRef != nil {
				if !mountableSecrets.Has(env.ValueFrom.SecretKeyRef.Name) {
					return fmt.Errorf("container %s with envVar %s referencing secret.secretName=\"%s\" is not allowed because service account %s does not reference that secret", container.Name, env.Name, env.ValueFrom.SecretKeyRef.Name, serviceAccount.Name)
				}
			}
		}
		for _, envFrom := range container.EnvFrom {
			if envFrom.SecretRef != nil {
				if !mountableSecrets.Has(envFrom.SecretRef.Name) {
					return fmt.Errorf("container %s with envFrom referencing secret.secretName=\"%s\" is not allowed because service account %s does not reference that secret", container.Name, envFrom.SecretRef.Name, serviceAccount.Name)
				}
			}
		}
	}

	// limit pull secret references as well
	pullSecrets := sets.NewString()
	for _, s := range serviceAccount.ImagePullSecrets {
		pullSecrets.Insert(s.Name)
	}
	for i, pullSecretRef := range pod.Spec.ImagePullSecrets {
		if !pullSecrets.Has(pullSecretRef.Name) {
			return fmt.Errorf(`imagePullSecrets[%d].name="%s" is not allowed because service account %s does not reference that imagePullSecret`, i, pullSecretRef.Name, serviceAccount.Name)
		}
	}
	return nil
```

```go
func VisitPodSecretNames(pod *api.Pod, visitor Visitor, containerType ContainerType) bool {
	visitor = skipEmptyNames(visitor)
	for _, reference := range pod.Spec.ImagePullSecrets {
		if !visitor(reference.Name) {
			return false
		}
	}
	VisitContainers(&pod.Spec, containerType, func(c *api.Container, containerType ContainerType) bool {
		return visitContainerSecretNames(c, visitor)
	})
	var source *api.VolumeSource
	for i := range pod.Spec.Volumes {
		source = &pod.Spec.Volumes[i].VolumeSource
		switch {
		case source.AzureFile != nil:
			if len(source.AzureFile.SecretName) > 0 && !visitor(source.AzureFile.SecretName) {
				return false
			}
		case source.CephFS != nil:
			if source.CephFS.SecretRef != nil && !visitor(source.CephFS.SecretRef.Name) {
				return false
			}
		case source.Cinder != nil:
			if source.Cinder.SecretRef != nil && !visitor(source.Cinder.SecretRef.Name) {
				return false
			}
		case source.FlexVolume != nil:
			if source.FlexVolume.SecretRef != nil && !visitor(source.FlexVolume.SecretRef.Name) {
				return false
			}
		case source.Projected != nil:
			for j := range source.Projected.Sources {
				if source.Projected.Sources[j].Secret != nil {
					if !visitor(source.Projected.Sources[j].Secret.Name) {
						return false
					}
				}
			}
		case source.RBD != nil:
			if source.RBD.SecretRef != nil && !visitor(source.RBD.SecretRef.Name) {
				return false
			}
		case source.Secret != nil:
			if !visitor(source.Secret.SecretName) {
				return false
			}
		case source.ScaleIO != nil:
			if source.ScaleIO.SecretRef != nil && !visitor(source.ScaleIO.SecretRef.Name) {
				return false
			}
		case source.ISCSI != nil:
			if source.ISCSI.SecretRef != nil && !visitor(source.ISCSI.SecretRef.Name) {
				return false
			}
		case source.StorageOS != nil:
			if source.StorageOS.SecretRef != nil && !visitor(source.StorageOS.SecretRef.Name) {
				return false
			}
		case source.CSI != nil:
			if source.CSI.NodePublishSecretRef != nil && !visitor(source.CSI.NodePublishSecretRef.Name) {
				return false
			}
		}
	}
	return true
}
```
