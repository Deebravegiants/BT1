### Title
Unauthenticated "magic" QR-code text triggers privileged Wi-Fi/network reconfiguration and mirror-calibration reset before any operator authorization check - (File: `src/plans/qr_scan/operator.rs`, `src/plans/mod.rs`, `src/plans/wifi/mod.rs`)

### Summary
The orb's operator-QR-code scanner recognizes a special, purely textual `magic_action:...` pattern and executes privileged local actions — resetting Wi‑Fi credentials/network and forcing a new network join, or resetting mirror calibration — before the scanned code is ever validated against the backend. Because the trigger is just plain text matched by a regex with no signature, authentication, or backend verification, any person able to present a QR code to the orb's camera (the same "unprivileged" interaction used for ordinary signups) can force the device into an attacker-chosen network or invalidate its calibration state, mirroring the Connext `Executor.sol` root cause: attacker-controlled input drives a privileged action with no authorization boundary.

### Finding Description
`qr_scan::operator::Data::try_parse` first tries to parse the code as a normal signed/backend-checked operator QR (`user::Data::try_parse`), but if that fails it falls back to a bare regex match on `magic_action:<word>`, producing `Data::MagicResetWifi` or `Data::MagicResetMirror` with no cryptographic or backend check whatsoever: [1](#0-0) 

This unauthenticated result is consumed directly by `handle_magic_operator_qr_code`, which is invoked immediately after `scan_operator_qr_code` and — critically — *before* `verify_operator_qr_code`, the function that actually authenticates the operator against the backend: [2](#0-1) 

`handle_magic_operator_qr_code` executes the privileged action unconditionally on match: [3](#0-2) 

`MagicResetWifi` calls `reset_wifi_and_ensure_network`, which tears down the current network and then blocks on scanning a *second*, equally unauthenticated QR code — this time a WiFi MECARD QR — and joins whatever network it decodes: [4](#0-3) [5](#0-4) 

The MECARD credentials parser itself performs no origin validation - it only checks syntax - and `network::join` writes the resulting SSID/PSK straight into `wpa_supplicant.conf` and reconnects: [6](#0-5) 

This is the same bug class as the reported `Executor.sol` issue: an entity with no privileged role supplies arbitrary "destination/data" (here, a magic-action string, then arbitrary Wi‑Fi SSID/PSK) that is executed as a trusted, privileged operation, because the enforcement/authorization check (`verify_operator_qr_code`'s backend call) happens too late, and the QR/MECARD parsers never differentiate an authenticated operator from an anonymous passer-by.

### Impact Explanation
- An unprivileged person can force the orb off its legitimate network and onto an attacker-controlled access point (`MagicResetWifi` → `network::reset` → `wifi::Plan::ensure_network_connection` → attacker-supplied MECARD QR → `network::join`). Once the orb is on an attacker-controlled network, further network-level tampering (deferred pinning gaps, downgrade, availability denial) is possible.
- `MagicResetMirror` lets an unprivileged person invalidate/reset the orb's mirror calibration at will, at any point in the idle/scanning loop, which affects iris/eye camera targeting used for biometric capture and liveness assurance — directly touching the fraud/liveness enforcement surface in scope.
- Both actions require no admin/operator credentials, no leaked secrets, and no physical/hardware access beyond the normal act of presenting a QR code to the camera — the exact same access level as a legitimate customer during signup.

### Likelihood Explanation
High. The trigger is a plain string (`magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration`) that can be printed on any QR code and shown to the orb's camera during the idle/operator-scan phase (`scan_initial_qr_codes` / `scan_remaining_qr_codes`), which is reachable by any passer-by, with no rate limiting, backend check, or physical tamper protection preventing repeated abuse.

### Recommendation
Perform backend/operator authentication (`verify_operator_qr_code` or equivalent signed-token check) before dispatching any magic action, and require that "magic" QR codes be cryptographically signed/authorized rather than recognized purely by regex text. Additionally, do not allow an unauthenticated QR scan to select the Wi‑Fi network the orb joins; require the same operator-authentication gate before `reset_wifi_and_ensure_network`/`network::join` is reachable, and rate-limit or gate magic-action attempts.

### Proof of Concept
1. Print a QR code containing exactly `magic_action:reset_wifi_credentials`.
2. During the orb's idle/operator-QR-scan phase, present this QR code to the camera. `qr_scan::operator::Data::try_parse` matches `MAGIC_QR_CODE` and returns `Data::MagicResetWifi` with no backend call.
3. `handle_magic_operator_qr_code` immediately calls `reset_wifi_and_ensure_network`, which drops the orb's current network (`network::reset`) and starts `wifi::Plan::ensure_network_connection`.
4. Present a second QR code encoding `WIFI:T:WPA;S:attacker_ap;P:attacker_pass;;` (valid MECARD syntax). `qr_scan::Plan::<Credentials>::run` accepts it with no source authentication, and `network::join` writes it to `wpa_supplicant.conf` and connects the orb to the attacker's access point.
5. Analogous attack with `magic_action:reset_mirror_calibration` invalidates mirror calibration state via `reset_mirror_calibration`, again with zero authentication.

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

impl Plan {
    /// Checks whether connected to a WiFi network, if not connected scan the
    /// hotspot QR code.
    pub async fn ensure_network_connection(&self, orb: &mut Orb) -> Result<()> {
        let mut in_progress_start = Instant::now();
        let mut has_requested_qr_code = false;
        let success = |orb: &mut Orb, has_requested_qr_code| {
            if has_requested_qr_code {
                orb.ui.network_connection_success();
            }
            tracing::debug!("Network is connected");
            Ok::<(), Error>(())
        };
        loop {
            match network::status().await? {
                network::Status::Connected { has_internet: true } => {
                    success(orb, has_requested_qr_code)?;
                    break;
                }
                network::Status::InProgress
                | network::Status::Connected { has_internet: false }
                    if in_progress_start.elapsed() < NETWORK_CONNECTION_TIMEOUT =>
                {
                    tracing::debug!("Network connection in progress");
                    sleep(Duration::from_millis(250)).await;
                }
                network::Status::Connected { has_internet: false }
                | network::Status::Disconnected
                | network::Status::InProgress => {
                    tracing::debug!("Network is disconnected, or has no connection to the backend");
                    if has_requested_qr_code {
                        orb.ui.qr_scan_fail(QrScanSchema::Wifi);
                    }
                    has_requested_qr_code = true;
                    match qr_scan::Plan::new(None, false).run(orb).await? {
                        Ok((credentials, _)) => {
                            tracing::info!(
                                "Read WiFi credentials from hotspot QR: {:?}",
                                credentials
                            );
                            network::join(credentials).await?;
                            in_progress_start = Instant::now();
                        }
                        Err(qr_scan::ScanError::Invalid) => {
                            orb.ui.qr_scan_unexpected(
                                QrScanSchema::Wifi,
                                QrScanUnexpectedReason::WrongFormat,
                            );
                        }
                        Err(qr_scan::ScanError::Timeout) => {}
                    }
                    orb.reset_rgb_camera().await?;
                }
            }
        }
        Ok(())
    }

/// Joins WiFi network using the given `credentials`.
pub async fn join(credentials: Credentials) -> Result<()> {
    spawn_blocking(move || {
        let mut cmd = Command::new(WPA_SUPPLICANT_INTERFACE_BIN);
        cmd.arg("join");
        match credentials.auth_type {
            AuthType::Wep | AuthType::Nopass => {
                cmd.arg("--auth").arg("NONE");
            }
            AuthType::Wpa | AuthType::Sae => {
                cmd.arg("--auth").arg("WPA-PSK");
            }
        }
        cmd.arg("--ssid").arg(hex_string(credentials.ssid.as_bytes()));
        if let Some(password) = &credentials.password {
            cmd.arg("--password").arg(wpa_passphrase(&credentials.ssid, password));
        }
        cmd.status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;
        Ok(())
    })
    .await?
}
