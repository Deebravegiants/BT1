### Title
Emporium Min-proof path lets any unprivileged caller execute unauthenticated, unaccounted external calls as Emporium - (File: `contracts/external-actions/emporium/upgradeable/EmporiumUpgradeable.sol`, `contracts/CircomDataBuilder.sol`)

### Summary
When `externalActionId == HINKAL_EMPORIUM_ACTION_ID` and `erc20TokenAddresses.length == 0`, `formInputForCircom` routes the proof through `formInputEmporiumMin`, which only constrains `message == Poseidon(messageSeed)` — nothing about ownership, root membership semantics, or the op payload. Combined with `EmporiumUpgradeable.verifyWallet` skipping the EIP-712 signature check entirely when `EmporiumStack.signerAddress == address(0)`, and `runAction`'s balance accounting loop iterating zero times (because `circomData.erc20TokenAddresses` is empty), an attacker can make Emporium execute an arbitrary `op.endpoint.call{value: op.value}(op.callData)` with `msg.sender == Emporium` and receive/attribute nothing back into the balance-diff checks.

### Finding Description
The broken equality is: **assets Emporium can move in a transaction == assets accounted for in `balancesBefore`/`balancesAfter`**.

Path:
1. `contracts/CircomDataBuilder.sol:134-148` — `formInputForCircom` selects `formInputEmporiumMin` whenever `externalActionId == HINKAL_EMPORIUM_ACTION_ID && erc20TokenAddresses.length == 0`.
2. `formInputEmporiumMin` (`CircomDataBuilder.sol:150-161`) builds public input from only `emporiumMessage`, `timeStamp`, `calldataHash`. The corresponding circuit `circuits/MainEVMCircuitMin.circom:1-18` only proves `message <== Poseidon(1)([messageSeed])` — a statement any attacker can trivially satisfy with a self-chosen `messageSeed`. No nullifier, no root-membership Merkle proof, no amount constraint exists in this circuit.
3. `HinkalHelper.dimensionsCheck` (`contracts/HinkalHelper.sol:64-171`) is satisfied trivially with `dimensions.tokenNumber == 0` (all length-0 arrays), requiring only cosmetic non-zero values like `H0x != 0` and a non-empty `onChainEncryptedOutput`. `checkOnchainCreation` is a no-op over zero-length arrays.
4. `Hinkal.transact` (`contracts/Hinkal.sol:57-64`) still requires `rootHashExists(circomData.rootHashHinkal, circomData.rootHashHinkalIndex)`, but `rootHashHinkal` is not part of the Min circuit's public input at all, so any historically valid (public) root/index pair works — no real UTXO ownership is required (`contracts/MerkleBase.sol:53-64`).
5. `_externalTransact` (`contracts/Hinkal.sol:234-260`) builds `deltaAmountChanges` of length 0 (matching `erc20TokenAddresses.length`) and calls `EmporiumUpgradeable.runAction`.
6. In `runAction` (`contracts/external-actions/emporium/upgradeable/EmporiumUpgradeable.sol:76-160`):
   - `EmporiumStack` is fully attacker-controlled via `externalActionData.externalActionMetadata`.
   - `balancesBefore = getBalancesForArray(circomData.erc20TokenAddresses)` is empty.
   - `verifyWallet(stack, circomData)` (`EmporiumUpgradeable.sol:302-349`) returns immediately with **no signature check whatsoever** when `stack.signerAddress == address(0)` (line 314-316), only marking `emporiumMessage` used.
   - The ops loop (`EmporiumUpgradeable.sol:91-118`): since `signerAddress == address(0)`, the `invokeWallet` branch condition (`op.invokeWallet && stack.signerAddress != address(0)`) is always false, forcing CASE 2 — an unrestricted `op.endpoint.call{value: op.value}(op.callData)` from Emporium's own address, blocked only from directly invoking `callHinkalWallet`/`doSendToRelay` selectors. Any other call — e.g., an ERC20 `transfer` moving tokens Emporium is holding, or a call into `HinkalHelper`/any router function that trusts `msg.sender == Emporium` — succeeds unrestricted.
   - `balancesAfter` is again computed over the empty array, so the `BalanceChangeShouldBePositive` guard (`EmporiumUpgradeable.sol:142-144`) and `handleOut` never execute for whatever asset was actually moved by the op.
7. Back in `Hinkal.transact`, the balance-diff/slippage loop (`contracts/Hinkal.sol:97-146`) also iterates over `circomData.erc20TokenAddresses` (length 0), so nothing enforces that Emporium's balance change matches any `amountChanges`/UTXO accounting.

Root cause: the Min-proof shortcut and the `signerAddress == 0` shortcut are each individually reasonable-looking, but together they remove every layer of authorization (ZK proof, EIP-712 signature, and on-chain balance accounting) from the arbitrary call executed by `Emporium`.

### Impact Explanation
Any funds sitting in the `Emporium` contract at call time (ETH via its `receive()`, or ERC20 tokens left over from partially completed multi-step swaps/fees) can be drained directly to an attacker-controlled address, and any privileged function on `HinkalHelper` or another integrated router that authorizes based on `msg.sender == Emporium` can be invoked by an unprivileged attacker. This is direct theft of protocol/in-flight user funds — Critical severity. The attack is fully repeatable: each call only burns one `emporiumMessage` value, and the attacker can pick a fresh `messageSeed`/`message` for free on every transaction.

### Likelihood Explanation
No privileged role, deposit, or real UTXO is required — the attacker only needs: (a) a verifier registered for `buildVerifierId(dimensions={0,0,0}, HINKAL_EMPORIUM_ACTION_ID)` (implied to exist given `MainEVMCircuitMin.circom` is shipped specifically for this scenario), and (b) any historically valid root/index pair (public chain data). Cost is one trivial Groth16 proof generation plus gas. This makes the attack cheap and immediately exploitable whenever Emporium holds any balance or is trusted as `msg.sender` by another contract.

### Recommendation
- Require `stack.signerAddress != address(0)` whenever `stack.ops.length > 0` in `verifyWallet`, i.e., never allow unauthenticated ops execution — either require a valid EIP-712 signature or require the ops list to be empty when `signerAddress == 0`.
- Do not let `erc20TokenAddresses.length == 0` bypass balance accounting for the Emporium action: either forbid the Min-path proof from carrying any `EmporiumStack.ops`, or require `dimensions.tokenNumber > 0` (i.e., at least one tracked token) whenever `ops.length > 0`.
- Bind `EmporiumStack`/`ops` into the Min circuit's public inputs (e.g., include a hash of `externalActionMetadata` in `calldataHash`'s circuit-checked commitment) so that the "minimal" proof cannot authorize arbitrary calls.

### Proof of Concept

2. Fund `Emporium` with e.g. 10 ERC20 tokens (simulate leftover in-flight balance) via direct transfer.
3. Craft `circomData`: `externalActionId = HINKAL_EMPORIUM_ACTION_ID`, `erc20TokenAddresses = []`, `amountChanges = []`, `onChainCreation = []`, `slippageValues = []`, `inputNullifiers = []`, `outCommitments = []`, valid `rootHashHinkal`/`rootHashHinkalIndex` from the current tree, `externalActionData.externalActionMetadata = abi.encode(EmporiumStack{signerAddress: address(0), ops: [EmporiumOperation({endpoint: token, invokeWallet: false, value: 0, callData: abi.encodeCall(IERC20.transfer, (attacker, 10e18))})], maxFee: 0, deadline: type(uint256).max})`.

    function runAction(
        CircomData calldata circomData,
        int256[] calldata deltaAmountChanges
    ) external override onlyAllowedRecipient returns (UTXO[] memory) {
        EmporiumStack memory stack = abi.decode(
            circomData.externalActionData.externalActionMetadata,
            (EmporiumStack)
        );

        uint256[] memory balancesBefore = getBalancesForArray(
            circomData.erc20TokenAddresses
        );

        verifyWallet(stack, circomData);

        for (uint256 i = 0; i < stack.ops.length; i++) {
            EmporiumOperation memory op = stack.ops[i];

            bool success;
            bytes memory err;

            // CASE 1: Stateful Interaction
            if (op.invokeWallet && stack.signerAddress != address(0)) {
                (success, err) = IHinkalWallet(stack.signerAddress)
                    .callHinkalWallet(op.endpoint, op.callData, op.value);
            }
            // CASE 2: Stateless Interaction
            else {
                bytes4 selector = bytes4(op.callData);
                if (
                    selector == IHinkalWallet.callHinkalWallet.selector ||
                    selector == IHinkalWallet.doSendToRelay.selector
                ) {
                    revert UnauthorizedWalletCall();
                }

                (success, err) = op.endpoint.call{value: op.value}(op.callData);
            }

            if (!success) {
                revert CallFailed(err);
            }
        }

        payRelayFees(circomData, stack.signerAddress, deltaAmountChanges);

        uint256[] memory balancesAfter = getBalancesForArray(
            circomData.erc20TokenAddresses
        );

        UTXO[] memory utxoSet = new UTXO[](
            circomData.erc20TokenAddresses.length
        );

        uint256 utxoSetLength;

        for (uint256 i = 0; i < circomData.erc20TokenAddresses.length; i++) {
            int256 balanceChange = int256(balancesAfter[i]) -
                int256(balancesBefore[i]);

            if (deltaAmountChanges[i] < 0) {
                balanceChange -= deltaAmountChanges[i];
                // this equation reads: total change of emporium balance = what was moved to emporium (-deltaAmountChange) + how emporium balance changed through tx (balanceChange)
            }

            // the only case when balanceChange can be < 0, when there were some funds on emporium before the call
            if (balanceChange < 0) {
                revert BalanceChangeShouldBePositive();
            }

            UTXO memory utxoOut = handleOut(balanceChange, circomData, i);

            if (utxoOut.amount > 0) {
                utxoSet[utxoSetLength++] = utxoOut;
            }
        }

        if (utxoSetLength < circomData.erc20TokenAddresses.length) {
            utxoSet.skipLast(
                circomData.erc20TokenAddresses.length - utxoSetLength
            );
        }

        return utxoSet;
    }

    function verifyWallet(
        EmporiumStack memory stack,
        CircomData calldata circomData
    ) internal {
        EmporiumStorageVars storage $ = _getEmporiumStorage();

        if ($.usedMessages[circomData.emporiumMessage]) {
            revert UsedMessage();
        }

        $.usedMessages[circomData.emporiumMessage] = true;

        if (stack.signerAddress == address(0)) {
            return;
        }

        bytes32 hashedMessage = _hashTypedDataV4(
            keccak256(
                abi.encode(
                    EMPORIUM_SIGNATURE_TYPEHASH,
                    circomData.emporiumMessage,
                    _hashEmporiumOps(stack.ops),
                    stack.maxFee,
                    stack.deadline
                )
            )
        );

        (address recoveredAddress, ECDSA.RecoverError err) = ECDSA.tryRecover(
            hashedMessage,
            stack.v,
            stack.r,
            stack.s
        );
        bool verified = err == ECDSA.RecoverError.NoError &&
            recoveredAddress == stack.signerAddress;
        if (!verified) {
            revert InvalidSignature();
        }

        if (block.timestamp > stack.deadline) {
            revert SignatureExpired();
        }

        if (circomData.feeStructure.flatFee > stack.maxFee) {
            revert FeeExceedsSignedMax();
        }
    }
