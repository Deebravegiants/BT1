**Analysis:**

The premise that "onlyEmporium binds to an immutable emporium set at construction" and could be bypassed by "an implementation swap" doesn't hold up. `EmporiumUpgradeable` is deployed as an upgradeable proxy, and `HinkalWallet.emporium` stores the proxy's address, not an implementation address [1](#0-0) . An implementation swap behind a proxy does not change the proxy's own address — calls still arrive at `msg.sender == emporium` (the proxy address), so `onlyEmporium` continues to hold correctly regardless of which logic contract is currently wired up [2](#0-1) . Additionally, swapping the implementation is a privileged action (requires upgrade-admin access), which per the rules puts it out of scope for an unprivileged attacker.

The `callHinkalWallet`/`doSendToRelay` functions take a plain `uint value`/`uint256 actualAmount` with no modular (CIRCOM_P) encoding or reduction performed on-chain [3](#0-2) , so there is no field-boundary/CIRCOM_P wraparound logic in this code path to exploit — that concept applies to the circuit's public-input encoding, not to this Solidity function's raw integer parameters. The only way to reach `callHinkalWallet` for a given wallet is through `EmporiumUpgradeable.runAction`, which requires either `stack.signerAddress == address(0)` (no wallet call happens then) or a valid EIP-712/EIP-1271 signature from the wallet's owner via `verifyWallet` [4](#0-3) , so an attacker cannot forge an op that the wallet owner never signed.

No exploitable divergence between the claimed and actual invariant was found in this code path.

    function verifyWallet(
        EmporiumStack memory stack,
        CircomData calldata circomData
    ) internal {
        EmporiumStorageVars storage $ = _getEmporiumStorage();

        if ($.usedMessages[circomData.emporiumMessage]) {
            revert UsedMessage();
        }

        $.usedMessages[circomData.emporiumMessage] = true;

        if (stack.signerAddress == address(0)) {
            return;
        }

        bytes32 hashedMessage = _hashTypedDataV4(
            keccak256(
                abi.encode(
                    EMPORIUM_SIGNATURE_TYPEHASH,
                    circomData.emporiumMessage,
                    _hashEmporiumOps(stack.ops),
                    stack.maxFee,
                    stack.deadline
                )
            )
        );

        (address recoveredAddress, ECDSA.RecoverError err) = ECDSA.tryRecover(
            hashedMessage,
            stack.v,
            stack.r,
            stack.s
        );
        bool verified = err == ECDSA.RecoverError.NoError &&
            recoveredAddress == stack.signerAddress;
        if (!verified) {
            revert InvalidSignature();
        }

        if (block.timestamp > stack.deadline) {
            revert SignatureExpired();
        }

        if (circomData.feeStructure.flatFee > stack.maxFee) {
            revert FeeExceedsSignedMax();
        }
    }
