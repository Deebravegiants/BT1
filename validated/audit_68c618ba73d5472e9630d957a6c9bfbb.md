**Reasoning:**

`CORE_CODE_ADDRESS` is a compile-time constant (`0x1`) defined in `move-core-types`, not something that varies per-process or per-network configuration read at runtime — it cannot be "redefined inconsistently between the indexer process and validator" through any unprivileged input path (transaction, package, view, authenticator, API, or proof). Changing it would require recompiling the binary itself, which is outside the review bounds (local tooling/build config, not an on-chain custody surface). [1](#0-0) 

More importantly, the actual translation logic in the indexer does not rely on loose/fuzzy address matching. `EventV2TranslationEngine` builds a `HashMap<TypeTag, Box<dyn EventV2Translator>>` and looks up the translator by exact `TypeTag` equality from the raw on-chain event's type tag (`v2.type_tag()`), which is itself derived by the Move VM from the actual emitting module's address in the transaction's write set — not something an unprivileged caller can spoof to equal `0x1::account::KeyRotationEvent` without actually being module `0x1::account`. [2](#0-1) [3](#0-2) 

If a non-canonical event were emitted with a struct tag from a different address, it simply would not match any key in the `translators` map, so `translate_event_v2_to_v1` returns `Ok(None)` — the event is not merged into or presented as a canonical `KeyRotationEvent`, so there is no "identical surfacing" of forged events as authoritative framework events. There is no custody-relevant impact here: no balance, ownership, authority, or recovery right changes as a result of event-tag mismatches, and the proposed attack requires an environment-level (build/config) inconsistency that is explicitly out of scope, not an unprivileged transaction-level exploit.

    pub fn translate_event_v2_to_v1(
        &self,
        v2: &ContractEventV2,
    ) -> Result<Option<ContractEventV1>> {
        let _timer = TIMER.timer_with(&["translate_event_v2_to_v1"]);
        if let Some(translator) = self
            .event_v2_translation_engine
            .translators
            .get(v2.type_tag())
        {
            let result = translator.translate_event_v2_to_v1(v2, &self.event_v2_translation_engine);
            match result {
                Ok(v1) => Ok(Some(v1)),
                Err(e) => {
                    // If the token object collection uses ConcurrentSupply, skip the translation and ignore the error.
                    // This is expected, as the event handle won't be found in either FixedSupply or UnlimitedSupply.
                    let is_ignored_error = (v2.type_tag() == &*MINT_TYPE
                        || v2.type_tag() == &*BURN_TYPE)
                        && e.to_string().contains("resource not found");
                    if !is_ignored_error {
                        warn!(
                            "Failed to translate event: {:?}. Error: {}",
                            v2,
                            e.to_string()
                        );
                    }
                    Ok(None)
                },
            }
        } else {
            Ok(None)
        }
