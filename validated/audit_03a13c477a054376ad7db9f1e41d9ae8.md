[1](#0-0)  A repo-wide search for actual call sites of `.valid()` found no usage in any owner-set/multisig-controller construction logic — the only match in the entire codebase besides the crypto crate itself is an unrelated `storage/schemadb/src/iterator.rs` iterator validity check.
