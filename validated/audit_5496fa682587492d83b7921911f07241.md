### Title
Legacy web_api_trigger gateway messages bypass allowlist and rate-limiting checks - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
The `handler.HandleLegacyUserMessage` function in the gateway's capabilities handler processes legacy (`DonID`-addressed) user requests, but skips the allowlist and rate-limiting enforcement that its own code comment says should be applied. This is analogous to the GovNFT `maxBridge` finding: a protective configuration/mechanism (`setMaxBridge`) that is declared and intended to constrain behavior but is never actually consulted at the enforcement point, letting the underlying operation proceed unconstrained.

### Finding Description
`HandleLegacyUserMessage` validates payload structure, decoding, and message staleness, then explicitly notes the missing control: [1](#0-0) 

Right before dispatching the request to all DON member nodes, the comment `// TODO: apply allowlist and rate-limiting here` sits directly above the method-name check — no allowlist or rate limiter call is present at all in this code path: [2](#0-1) 

This request path is reachable from `gateway.ProcessRequest`, the entry point serving raw HTTP requests from external, unprivileged clients. When the incoming message carries a non-empty `DonID`, it is treated as a "legacy request" and routed via `HandleLegacyUserMessage` instead of `HandleJSONRPCUserMessage` (which explicitly returns an error and isn't used here): [3](#0-2) [4](#0-3) 

The `handler` struct does define a `nodeRateLimiter`, but that limiter is only used for node-originated traffic (`HandleNodeMessage` / outgoing message flows), not for the incoming legacy `web_api_trigger` request path exercised here: [5](#0-4) 

By contrast, the newer v2 gateway handler and the vault/confidentialrelay handlers do enforce allowlist and rate-limit checks consistently before forwarding requests to nodes, underscoring that the legacy path is missing equivalent controls, just like `maxBridge` was declared but never checked in `GovNFT`'s bridge functions.

### Impact Explanation
Without allowlist enforcement, any external caller able to reach the gateway's HTTP endpoint can submit a legacy `web_api_trigger` message with an arbitrary `DonID`, and it will be broadcast to every member node of that DON — bypassing the intended access control that restricts which senders/workflows may trigger DON-side actions. Without rate limiting on this path, a client can flood the DON with trigger messages, causing excessive `SendToNode` calls and downstream load on all DON members, a denial-of-service vector against the node fleet.

### Likelihood Explanation
Likelihood is high: this is the default legacy path (triggered whenever `msg.Body.DonID != ""`), requires no privileged credentials, and only needs a client capable of sending a well-formed JSON-RPC gateway request. The comment left in the code (`// TODO: apply allowlist and rate-limiting here`) confirms the omission is a known, unresolved gap rather than a deliberate design choice with a substitute control elsewhere in this handler.

### Recommendation
Add explicit allowlist authorization (workflow/sender allowlist, matching what other handlers such as the vault and v2 http_trigger_handler perform) and apply the existing `nodeRateLimiter` (or an equivalent incoming-request limiter) at the top of `HandleLegacyUserMessage`, before the message is forwarded to `don.SendToNode`. Reject unauthorized or rate-limited requests with the same style of structured error response used elsewhere in this function.

### Proof of Concept
1. Send an HTTP JSON-RPC request to the gateway with `Body.DonID` set to a valid DON ID and `Body.Method = "web_api_trigger"`, with a valid (non-stale) `Timestamp` in the payload.
2. Observe in `gateway.ProcessRequest` that `isLegacyRequest` becomes true and the message is routed to `h.HandleLegacyUserMessage` — [3](#0-2) .
3. Trace through `HandleLegacyUserMessage`: no allowlist or rate-limit check exists before `don.SendToNode` is called for every DON member — [6](#0-5) .
4. Repeating the request rapidly, or from a non-allowlisted sender, still reaches all DON nodes, demonstrating the missing enforcement.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageID] = &savedCallback{id: msg.Body.MessageID, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}
