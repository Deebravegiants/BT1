### Title
Non-atomic ISMP batch execution via `pallet-call-decompressor` bypasses `pallet-ismp`'s transactional guarantee, silently skipping relayer fee accounting and event emission for delivered messages - ([File: modules/pallets/call-decompressor/src/lib.rs])

### Summary
`pallet_call_decompressor::decompress_call` is a permissionless, fee-less (`ensure_none`) extrinsic that decompresses and executes a compressed `RuntimeCall`, but only for two allow-listed inner calls: `pallet_ismp::Call::handle_unsigned` and `pallet_ismp_relayer::Call::accumulate_fees`. For the ISMP case, instead of dispatching the normal `pallet_ismp::Call::handle_unsigned` extrinsic (which is wrapped in `#[frame_support::transactional]`), it calls `<pallet_ismp::Pallet<T>>::execute(messages)` directly, losing that atomicity guarantee.

### Finding Description
`Pallet::<T>::execute` in [1](#0-0)  processes a `Vec<Message>` by mapping each message through `handle_incoming_message` (the real message-router logic that verifies proofs and produces state-mutating side effects such as writing request/response receipts and invoking destination modules) and collecting into a `Result`. Because `.map(...).collect::<Result<Vec<_>, _>>()` is lazily short-circuiting, `handle_incoming_message` is actually *executed* (with real storage side effects) for every message up to and including the first one that fails; only the failing message's error propagates. `T::FeeHandler::on_executed(...)` (relayer fee crediting) and the event-deposit loop only run *after* the full `collect()` succeeds, so on any failure both are skipped entirely — even though prior messages in the batch already produced durable state changes.

When invoked through `pallet_ismp::Call::handle_unsigned` directly, [2](#0-1)  shows the dispatchable is annotated `#[frame_support::transactional]`, so a failure anywhere in `execute()` rolls back *all* storage changes from that call, restoring the all-or-nothing guarantee that Substrate's transaction-pool validation logic and downstream relayers rely on.

`pallet_call_decompressor`'s `decode_and_execute`, however, calls `execute()` directly and is not itself transactional: [3](#0-2) . Its outer dispatchable `decompress_call` also has no `#[frame_support::transactional]` attribute: [4](#0-3) . Consequently, a batch submitted through this pallet that contains N valid messages followed by one invalid/malformed message will durably apply the side effects of the first N messages (state commitments, request/response receipts, and any module dispatch such as token mints triggered by `on_accept`) while the extrinsic as a whole reports `ErrorExecutingCall`, and — critically — never reaches `T::FeeHandler::on_executed(...)` or the event-deposit loop for any of the messages in that batch, including the ones that were actually delivered.

### Impact Explanation
This breaks the relayer fee/reward accounting invariant that `pallet-ismp` is designed to enforce atomically: messages can be delivered (with real state effects like minting tokens or crediting escrow via a module's `on_accept`) without the corresponding relayer fee ever being charged or paid, and without the corresponding `Event`s (e.g. `Event::Errors`, request/response delivery events) being emitted. This is a relayer fee/reward accounting bypass and a break of the atomic-batch guarantee central to ISMP's permissionless-but-fee-tracked message delivery model — an unprivileged, fee-less submitter can force asymmetric outcomes (state mutated, but no fee accrual, no event trail) that off-chain relayer/monitoring tooling (which watches extrinsic success/failure and event streams) is not designed to detect.

### Likelihood Explanation
The `decompress_call` extrinsic is intentionally `ensure_none` (unsigned, permissionless, free) so any actor able to submit a transaction to the network can reach this path with zero cost beyond crafting a compressed batch containing one deliberately invalid trailing message. No special privilege, governance action, or off-chain component compromise is required — only a validly-decodable batch of ISMP messages whose last entry fails `handle_incoming_message` (e.g., a bad/duplicate proof) after N-1 legitimate ones succeed.

### Recommendation
Wrap `pallet_call_decompressor::decompress_call` (or at minimum the ISMP branch of `decode_and_execute`) in `#[frame_support::transactional]` so that a failure anywhere in the decoded/executed batch rolls back all storage changes, matching the atomicity that `pallet_ismp::Call::handle_unsigned` provides when called directly. Alternatively, have `decode_and_execute` invoke the `handle_unsigned` *dispatchable* (via full dispatch) rather than the internal `execute()` helper, so the existing transactional wrapper is inherited.

### Proof of Concept
1. Construct `messages = [valid_msg_1, ..., valid_msg_N, invalid_msg]` where `valid_msg_i` are legitimate ISMP `Request`/`Response` messages with valid proofs (e.g., ones that trigger token minting through a receiving module's `on_accept`), and `invalid_msg` is crafted to fail `handle_incoming_message` (e.g., malformed proof or already-consumed nonce).
2. Encode `RuntimeCall::Ismp(pallet_ismp::Call::handle_unsigned { messages })`, compress it with zstd, and submit via `pallet_call_decompressor::decompress_call(RuntimeOrigin::none(), compressed, encoded_call_size)` — mirroring the harness in [5](#0-4) .
3. Observe: the extrinsic returns `Err(ErrorExecutingCall)`, yet the destination module's mint/escrow-release side effects for `valid_msg_1..N` are present in storage, no `FeeHandler::on_executed` credit was recorded for the relayer, and no `pallet_ismp::Event` was deposited for the delivered messages — demonstrating the atomicity break relative to calling `pallet_ismp::Call::handle_unsigned` directly with the same batch (which would roll back everything).

	pub fn execute(messages: Vec<Message>) -> Result<Vec<events::Event>, Error<T>> {
		let host = Pallet::<T>::default();

		let message_results = messages
			.iter()
			.map(|msg| handle_incoming_message(&host, msg.clone()))
			.collect::<Result<Vec<_>, _>>()
			.map_err(|err| {
				log::debug!(target: "ismp", "Handling Error {:#?}", err);
				Pallet::<T>::deposit_event(Event::<T>::Errors { errors: vec![err.into()] });
				Error::<T>::InvalidMessage
			})?;

		let messages_with_weights = message_results
			.iter()
			.zip(messages)
			.map(|(result, message)| MessageWithWeight { message, weight: result.weight() })
			.collect::<Vec<_>>();

		let events = message_results
			.into_iter()
			// check that requests will be successfully dispatched
			// so we can not be spammed with failing txs
			.map(|result| match result {
				MessageResult::Request { events, .. } |
				MessageResult::Response { events, .. } |
				MessageResult::Timeout { events, .. } => events,
				MessageResult::ConsensusMessage(events) => events.into_iter().map(Ok).collect(),
				MessageResult::FrozenClient(_) => vec![],
			})
			.flatten()
			.collect::<Result<Vec<_>, _>>()
			.map_err(|err| {
				log::debug!(target: "ismp", "Handling Error {:#?}", err);
				Pallet::<T>::deposit_event(Event::<T>::Errors { errors: vec![err.into()] });
				Error::<T>::InvalidMessage
			})?;

		T::FeeHandler::on_executed(messages_with_weights, events.clone())
			.map_err(|_| Error::<T>::ErrorChargingFee)?;

		for event in events.clone() {
			// deposit any relevant events
			Pallet::<T>::deposit_event(event.into());
		}

		Ok(events)
	}

	pub fn decode_and_execute(call_bytes: Vec<u8>) -> DispatchResult {
		let runtime_call = <T as frame_system::Config>::RuntimeCall::decode_all_with_depth_limit(
			MAX_EXTRINSIC_DECODE_DEPTH_LIMIT,
			&mut &call_bytes[..],
		)
		.map_err(|_| Error::<T>::ErrorDecodingCall)?;

		// use call filter to filter out unwanted calls
		if !<T as frame_system::Config>::BaseCallFilter::contains(&runtime_call) {
			return Err(Error::<T>::CallNotSupported.into());
		}

		if let Some(call) = IsSubType::<pallet_ismp::Call<T>>::is_sub_type(&runtime_call).cloned() {
			match call {
				pallet_ismp::Call::handle_unsigned { messages } =>
					<pallet_ismp::Pallet<T>>::execute(messages)
						.map_err(|_| Error::<T>::ErrorExecutingCall)?,
				_ => Err(Error::<T>::CallNotSupported)?,
			};
		} else if let Some(call) =
			IsSubType::<pallet_ismp_relayer::Call<T>>::is_sub_type(&runtime_call).cloned()
		{
			match call {
				pallet_ismp_relayer::Call::accumulate_fees { withdrawal_proof } =>
					<pallet_ismp_relayer::Pallet<T>>::accumulate_fees(
						frame_system::RawOrigin::None.into(),
						withdrawal_proof,
					)?,
				_ => Err(Error::<T>::CallNotSupported)?,
			};
		} else {
			return Err(Error::<T>::CallNotSupported)?;
		}

		Ok(())
	}

#[test]
fn should_decompress_and_execute_pallet_ismp_post_request_calls_correctly() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		let host = Ismp::default();
		let requests = (0..1000)
			.into_iter()
			.map(|i| {
				let post = ismp::router::PostRequest {
					source: host.host_state_machine(),
					dest: StateMachine::Evm(1),
					nonce: i,
					from: H256::random().0.to_vec(),
					to: H256::random().0.to_vec(),
					timeout_timestamp: Duration::from_millis(Timestamp::now()).as_secs() +
						2_000_000_000,
					body: H512::random().0.to_vec(),
				};
				post
			})
			.collect::<Vec<_>>();

		let msg = RequestMessage {
			requests,
			proof: Proof {
				height: StateMachineHeight {
					id: StateMachineId {
						state_id: StateMachine::Evm(1),
						consensus_state_id: MOCK_CONSENSUS_STATE_ID,
					},
					height: 3,
				},
				proof: H512::random().0.to_vec(),
			},
			signer: H512::random().0.to_vec(),
		};

		let call = RuntimeCall::Ismp(pallet_ismp::Call::handle_unsigned {
			messages: vec![Message::Request(msg)],
		})
		.encode();
		let mut buffer = vec![0u8; 1_000_000];
		let compressed = zstd_safe::compress(&mut buffer[..], &call, 3).unwrap();
		let final_compressed_call = buffer[..compressed].to_vec();

		let res = pallet_call_decompressor::Pallet::<Test>::decompress_call(
			RuntimeOrigin::none(),
			final_compressed_call.to_vec(),
			call.len() as u32,
		)
		.err()
		.unwrap();

		// Decoding the call was completed without errors
		assert_eq!(
			res,
			DispatchError::Module(ModuleError {
				index: 10,
				error: [1, 0, 0, 0],
				message: Some("ErrorExecutingCall")
			})
		);
	})
}
