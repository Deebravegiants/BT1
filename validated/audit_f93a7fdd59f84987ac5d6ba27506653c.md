### Title
Accrual multiplication overflow permanently freezes a large high-utilization market - (File: contracts/pool/src/interest.rs)

### Summary
The DXA demuxer bug class is an integer overflow producing a denial of service. The direct analog lives in the RAY index accrual: every pool mutation first calls `global_sync` → `accrue_chunk` → `accrue_step`, which computes `borrowed_shares × borrow_index` inside `scaled_to_original`/`Ray::mul`. That multiply raises `MathOverflow` on i128 overflow. Because all exit verbs (repay, withdraw, liquidate) accrue before acting, once the debt value crosses the i128 ceiling the market is permanently bricked — the index cap never engages first. The test suite itself proves this freeze.

### Finding Description
`accrue_chunk` recomputes indexes via `accrue_step`, whose interest term is `half_up(borrowed × borrow_index' / RAY) − half_up(borrowed × borrow_index / RAY)`. The product `borrowed × borrow_index` is evaluated in fixed point through `Ray::mul` → `fp_core::mul_div_half_up`, which traps on overflow rather than saturating. `docs/reference/formulas.md` explicitly admits: "Value overflow can occur before the index ceiling and block repayment/withdrawal because those operations accrue first… No dedicated ceiling alarm is emitted." The harness test `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap` drives a 18-decimals market at 98% utilization on the steep curve segment and asserts `MathOverflow` on `update_indexes`, `withdraw`, and `repay` — with `borrow_index < MAX_BORROW_INDEX_RAY`, i.e. the safety cap is unreachable before the panic. ### Impact Explanation
Permanent freezing of funds: once the market crosses the RAY-value cliff, `repay`, `withdraw`, and `liquidate` all revert inside accrual, so suppliers cannot exit, borrowers cannot close debt, liquidators cannot act, and collateral plus supplied principal are locked indefinitely. A single unprivileged address can create this state through ordinary `supply`/`borrow` calls — no privilege, oracle manipulation, or upgrade required.

### Likelihood Explanation
Low-to-moderate. The attacker must push the market to very large RAY debt value (on the order of hundreds of billions of whole tokens at an index of ~170×) and sustain high utilization for a prolonged accrual horizon while caps are lifted or permissive. The capital requirement is enormous and growth is time-bounded by `MAX_COMPOUND_DELTA_MS` chunking. However, no protocol mechanism detects or halts the approach, and once reached it is irreversible — the index cap, `clean_bad_debt`, and `recapitalize` cannot rescue a market whose accrual traps on its own totals.

### Recommendation
Bound the inputs, not just the index: enforce a RAY-domain debt/supply value ceiling at borrow/supply entry (e.g. `borrowed_scaled * index` must fit i128 with headroom for the index cap of 10³⁶), so no single market can grow its scaled totals into the overflow region. Alternatively, make accrual saturate rather than trap — clamp `borrow_index` at `MAX_BORROW_INDEX_RAY` and cap the computed debt value instead of multiplying unchecked, so exits remain reachable even if accounting saturates.

### Proof of Concept
`tests/test-harness/tests/controller/large_positions_and_long_horizons.rs:320` already implements the exploit: `supply_raw(BOB, "BIG18", 1e9 * 1e18)`, borrow 98% of it via `borrow_raw`, advance time yearly in a loop until `try_update_indexes_for` returns `MathOverflow`, then confirm `try_withdraw_raw` and `try_repay` both revert with `MathOverflow` while `borrow_index < MAX_BORROW_INDEX_RAY`. Reached entirely through the unprivileged `supply`/`borrow`/`update_indexes` entrypoints.

```rust
pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}

/// Applies one compound step of `delta_ms` to indexes and protocol revenue.
///
/// The arithmetic lives in [`accrue_step`], shared with the read-only
/// `simulate_update_indexes` so the view and the mutator cannot drift.
fn accrue_chunk(env: &Env, cache: &mut Cache, delta_ms: u64) {
    let step = accrue_step(
        env,
        cache.params(),
        cache.borrowed(),
        cache.supplied(),
        cache.borrow_index(),
        cache.supply_index(),
        delta_ms,
    );

    cache.set_borrow_index(step.borrow_index);
    cache.set_supply_index(step.supply_index);
    cache.accrue_revenue(step.revenue_shares);
}
```

```rust
/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
    std::println!(
        "ray-value cliff reached after {years} years at 98 percent utilization on the XLM curve; last index x{:.1}",
        last.borrow_index as f64 / RAY as f64
    );
```
