Audit Report

## Title
Gateway `ProcessRequest` leaks raw internal JSON parsing error details to unauthenticated remote clients - ([File: core/services/gateway/gateway.go])

## Summary
`ProcessRequest` in `core/services/gateway/gateway.go` returns the raw Go `error.Error()` string from `jsonrpc2.DecodeRequest` and `g.codec.DecodeJSONRequest` directly in the JSON-RPC error response's `Message` field, without sanitization. This is reachable by any unauthenticated client hitting the gateway's public HTTP port, since `httpserver.go`'s `handleRequest` calls `ProcessRequest` before any auth validation occurs.

## Finding Description
`ProcessRequest` decodes the raw request bytes via `jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)`, and on failure calls `newError("", api.UserMessageParseError, err.Error())`, embedding the raw decode error verbatim [1](#0-0) . Similarly, if `g.codec.DecodeJSONRequest(jsonRequest)` fails (which internally performs `json.Unmarshal(*request.Params, &msg)` with no error wrapping/sanitization), the raw unmarshal error is passed to `newError` [2](#0-1) [3](#0-2) . `newError` places this string directly into the `Message` field of the JSON-RPC `WireError` response, which is JSON-marshalled and returned as the raw response bytes [4](#0-3) .

In `httpserver.go`'s `handleRequest`, the JWT/Authorization header is extracted as a raw string without any validation, and `ProcessRequest` is invoked immediately afterward — no authentication or allowlist check occurs before the parse errors can be triggered and returned [5](#0-4) . The response bytes are written straight to the HTTP response body with `w.Write(rawResponse)`, so the raw Go decoder/unmarshal error text reaches the client verbatim.

## Impact Explanation
The disclosed information is limited to Go's standard `encoding/json`/`jsonrpc2` library error strings (e.g., byte offsets, syntax error descriptions). This can aid an attacker's reconnaissance of internal library versions/behavior but does not itself grant authentication bypass, secret/key exfiltration, unauthorized job execution, fund movement, or allowlist bypass — it is an information disclosure of internal error text rather than a concrete state-changing or credential-exposing vulnerability. Chainlink's bounty scope for the gateway targets impacts like authentication/role bypass, request impersonation, allowlist bypass, and unauthorized actions; verbose parser error messages alone fall short of those categories and represent, at most, a low-severity information disclosure/hardening issue.

## Likelihood Explanation
Triggering the bug requires no authentication and is deterministic — any client sending malformed JSON or malformed `params` to the gateway's public HTTP port will reliably receive the raw parser error text back, consistent with the described PoC.

## Recommendation
Replace raw `err.Error()` values passed into `newError(...)` for decode/unmarshal failures with a static, generic message (e.g., `"invalid request format"`), and log the detailed error server-side only, matching the existing pattern used in `core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go`.

## Proof of Concept
Send `POST` to the gateway's public HTTP endpoint with a malformed JSON body, e.g. `{"jsonrpc":"2.0","id":"1","method":"x","params":{}}n`; the response body will contain the raw Go JSON decoder error string (e.g., `invalid character 'n' after top-level value`) in the `error.message` field, confirming the leak as described, though the resulting impact is limited to internal error-string disclosure rather than any higher-severity in-scope impact.

```go
func newError(id string, errCode api.ErrorCode, errMsg string) ([]byte, int) {
	response := jsonrpc2.Response[json.RawMessage]{
		Version: jsonrpc2.JsonRpcVersion,
		ID:      id,
		Error: &jsonrpc2.WireError{
			Code:    api.ToJSONRPCErrorCode(errCode),
			Message: errMsg,
			Data:    nil,
		},
	}
	rawResponse, err := json.Marshal(response)
	if err != nil {
		rawResponse = []byte("fatal error" + err.Error())
	}
	promRequest.WithLabelValues(errCode.String()).Inc()
	return rawResponse, api.ToHTTPErrorCode(errCode)
}
```

```go
func (*JSONRPCCodec) DecodeJSONRequest(request jsonrpc2.Request[json.RawMessage]) (*Message, error) {
	var msg Message
	err := json.Unmarshal(*request.Params, &msg)
	if err != nil {
		return nil, err
	}
	msg.Body.MessageID = request.ID
	msg.Body.Method = request.Method
	return &msg, nil
}
```
