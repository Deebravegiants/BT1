Audit Report

## Title
Missing authentication on LOOP plugin pprof/metrics proxy endpoints - (File: core/web/router.go)

## Summary
`NewRouter` registers `loopRoutes(app, api)` on the outer `api` route group, which only has rate limiting and session-cookie middleware attached — not authentication. [1](#0-0)  This exposes `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` to any unauthenticated client that can reach the node's HTTP port, in contrast to the node's own pprof/debug surface (`metricRoutes`), which is intentionally nested inside the authenticated `authv2` group. [2](#0-1) 

## Finding Description
`loopRoutes` defines the handlers with no auth middleware applied at either the group or route level: [3](#0-2)  These routes are mounted directly on `api`, the top-level group that carries only `rateLimiter` and `sessions.Sessions` middleware: [4](#0-3)  By contrast, `metricRoutes`, which exposes the node's own `/debug/pprof/*` endpoints, is deliberately wrapped inside `authv2`, which requires `auth.AuthenticateByToken` or `auth.AuthenticateBySession`: [5](#0-4) [2](#0-1)  This is a genuine inconsistency: the same class of sensitive debug/profiling surface is protected in one place and not in the other.

The handler implementations confirm the proxying behavior is unauthenticated end-to-end. `pluginMetricHandler` forwards to the internal LOOP plugin's `/metrics` endpoint with no credential check: [6](#0-5)  `pluginPPROFHandler` forwards client-supplied `debug`, `gc`, and `seconds` query parameters directly to the plugin's `/debug/pprof/*` endpoint, including CPU profile capture whose duration is attacker-controlled via `seconds`: [7](#0-6)  `pluginPPROFPOSTSymbolHandler` similarly proxies POST requests to `/debug/pprof/symbol` unauthenticated: [8](#0-7) 

No other middleware in the chain (rate limiting, session cookie handling, CORS, helmet) performs any identity/credential verification — those are orthogonal to authentication and don't gate on token/session validity. [9](#0-8) 

## Impact Explanation
An unauthenticated actor with network access to the node's web port can retrieve internal LOOP plugin metrics and pprof profiling data (goroutine stacks, heap samples, potential in-memory state leakage) without any session cookie or API token — a clear information-disclosure gap relative to the equivalent, authenticated node-pprof surface (`metricRoutes`). This qualifies as a node API authentication bypass on a sensitive debug/introspection surface, consistent with the in-scope "node API authentication or role bypass" impact class. The CPU-profile-duration angle (`seconds` parameter) is a resource-consumption concern but is separately excluded from scope by `SECURITY.md`'s "Impacts that only require DDoS" exclusion, so that portion of the original report should not be counted toward severity — the core, in-scope impact is the unauthenticated disclosure itself.

## Likelihood Explanation
High. The routes are registered unconditionally with no build tag or dev-only gating (`/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) and are reachable on any node running LOOP plugins with its web server exposed, exactly like all other production `/v2`-era routes registered on `api`. No special privilege, credential, or role is required — a plain unauthenticated HTTP GET reaches the handler.

## Recommendation
Move `loopRoutes(app, api)` under an authenticated group (e.g., wrap with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`, or register it under `authv2` similarly to how `metricRoutes` is nested), so that plugin metrics/pprof endpoints require the same authentication as the node's own debug surface. If external Prometheus scraping without session/token auth is a hard requirement for `/discovery` and `/plugins/:name/metrics`, consider a separate, explicitly-documented bearer-token scheme (similar to `prometheusHandler`'s token check) rather than leaving them fully open.

## Proof of Concept
1. Start a chainlink node with at least one LOOP plugin registered and its web server exposed on the default port.
2. Without any session cookie or token header, issue `GET /plugins/<plugin-name>/metrics` and `GET /plugins/<plugin-name>/debug/pprof/goroutine` (or `?debug=1`).
3. Observe both requests succeed (HTTP 200 with plugin metrics/profile data), whereas the equivalent authenticated request `GET /v2/debug/pprof/goroutine` returns `401 Unauthorized` without valid credentials — demonstrating the router-level authentication gap in `loopRoutes` versus `metricRoutes`.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {

	}
	body, err := io.ReadAll(gc.Request.Body)

	}
