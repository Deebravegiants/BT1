The `store_element!` macro in `mod.rs` computes `new_size` and performs the limit check *before* any mutation occurs: [1](#0-0) 

If `new_size > MEMORY_LIMIT_IN_BYTES`, the macro returns `Err(...)` immediately, without touching `context.bytes_used` or `context.objs` at all. The mutation of `bytes_used` and the `push` into `objs` only happen together in the `else` branch, both under a single mutable borrow of `context`. There is no intermediate state where one is updated and not the other — the operation is atomic from the perspective of `AlgebraContext`, so `bytes_used` cannot desynchronize from `objs.len()` via this abort path.

Additionally:
- `AlgebraContext` is a native-extension struct that is explicitly reset via `SessionListener::start`, which clears both `bytes_used` and `objs` at the start of each session: [2](#0-1) . Its `abort()` hook is a no-op precisely because any transaction abort discards the whole VM effect, and the next session's `start()` clears the context anyway — so there is no mechanism for "leaking" state across a batch of transactions.

There is no shared handle/index space between this cryptography native extension and object/FA custody state.

Since (1) the abort path cannot desynchronize `bytes_used` from `objs.len()`, and (2) there is no code-level linkage between the algebra native's internal handle vector and any fungible-asset freeze-status or ownership check, the described exploit chain does not exist in this codebase. macro_rules! store_element {
    ($context:expr, $obj:expr) => {{
        let context = &mut $context.extensions_mut().get_mut::<AlgebraContext>();
        let new_size = context.bytes_used + std::mem::size_of_val(&$obj);
        if new_size > MEMORY_LIMIT_IN_BYTES {
            Err(SafeNativeError::abort_with_message(
                E_TOO_MUCH_MEMORY_USED,
                format!(
                    "Algebra context memory {}-byte limit exceeded: currently using {} bytes; was asked for {} bytes",
                    MEMORY_LIMIT_IN_BYTES, context.bytes_used, new_size,
                ),
            ))
        } else {
            let target_vec = &mut context.objs;
            context.bytes_used = new_size;
            let ret = target_vec.len();
            target_vec.push(Rc::new($obj));
            Ok(ret)
        }
    }};
}
