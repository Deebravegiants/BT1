## Analysis

`loopRoutes` registers the LOOP plugin discovery, metrics, and pprof-forwarding endpoints directly on the top-level `api` group, which only has rate-limiting and session-loading middleware — no authentication is enforced, unlike every other route group in the router (`debugRoutes`, `sessionRoutes`, `v2Routes`) which explicitly wrap themselves with `auth.Authenticate(...)`. The registered handlers forward requests to internal LOOP plugin `/metrics` and `/debug/pprof/*` endpoints without any check that the caller is an authenticated node operator: [4](#0-3) [5](#0-4) 

### Title
Unauthenticated Access to Node's LOOP Plugin Debug/PPROF and Metrics Endpoints - (File: core/web/router.go)

### Summary
The `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` routes are registered on the unauthenticated `api` router group. Unlike all other sensitive route groups in the Chainlink node web server, `loopRoutes` is never wrapped in `auth.Authenticate(...)`, so any unprivileged network client that can reach the node's HTTP port can invoke these debug/metrics-forwarding handlers.

### Finding Description
`NewRouter` builds an `api` group with only rate-limiting and cookie-session middleware, then calls `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` on it. Each of the other functions internally creates a sub-`Group` protected by `auth.Authenticate(app.AuthenticationProvider(), ...)` (see `debugRoutes` gating `/debug/vars`, and `v2Routes` gating most of `/v2/*`, including `metricRoutes` for the node's own pprof under `authv2`). `loopRoutes`, however, registers its four routes directly on the raw `api` group with no additional authentication middleware:

```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```

`pluginPPROFHandler` takes the attacker-controlled `:profile` wildcard and `debug`/`gc`/`seconds` query parameters and forwards them verbatim to the internal LOOP plugin's `/debug/pprof/<profile>` endpoint, then relays the raw response body back to the caller. This mirrors the CVE-2013-4766 pattern: an internal "gather" service intended only for operators/trusted internal callers is reachable by unauthenticated remote clients, exposing internal diagnostic data (goroutine stacks, heap dumps, cmdline, profiling traces) that can contain sensitive runtime state.

### Impact Explanation
An unauthenticated remote attacker who can reach the node's HTTP listener can pull goroutine dumps, heap profiles, and other pprof data from any registered LOOP plugin (e.g., `/plugins/<name>/debug/pprof/goroutine?debug=2`, `/plugins/<name>/debug/pprof/heap`). These profiles can leak internal state such as stack traces with file paths, memory contents, and potentially sensitive data held in plugin memory, aiding further attacks on a production Chainlink node. This is a CWE-200 (information exposure) issue matching the report's bug class of unauthorized access to internal diagnostic/log-gathering interfaces by an unprivileged actor.

### Likelihood Explanation
The routes are exposed on the node's main web server port with no authentication requirement and no allowlist restriction beyond generic rate limiting, so any client with network access to the API port can exploit this immediately, requiring no credentials.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/metrics` and `/plugins/:name/debug/pprof/*` routes) in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for the node's own `/v2/*` and `/debug/vars` routes, consistent with how `metricRoutes` is gated under `authv2` for the node's own pprof endpoints.

### Proof of Concept
Against a running node with a registered LOOP plugin `medianpoc`, with no session cookie or API token:
```
GET /plugins/medianpoc/debug/pprof/goroutine?debug=2 HTTP/1.1
Host: node-host:6688
```
The request is forwarded unauthenticated by `pluginPPROFHandler` to the internal plugin's pprof endpoint and the full goroutine dump is returned to the caller.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
