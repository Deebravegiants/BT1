### Title
Relayer can collect consensus-incentive rewards for a backlogged height span at a newly-increased `cost_per_block` rate - (File: `modules/pallets/consensus-incentives/src/impls.rs`)

### Summary
`pallet-consensus-incentives` pays relayers for delivering `ConsensusMessage`s that advance a state machine's known height, using the formula `reward = (latest_height - watermark) * cost_per_block`. The watermark (`LastRewardedHeight`) is only advanced when a non-zero reward is actually paid, exactly mirroring the Popcorn `Vault.feesUpdatedAt` bug: the "rate" (`cost_per_block`) can change between the last paid height and the next submission, and the entire un-rewarded backlog of blocks is retroactively paid out at whatever rate is current at submission time, rather than the rate(s) that were actually in effect while those blocks accrued.

### Finding Description
The reward calculation lives in `calculate_reward()` and `process_message()`: [1](#0-0) 

`calculate_reward` computes `blocks = latest_height - baseline`, where `baseline` is `LastRewardedHeight::get(state_machine_id).unwrap_or(previous_height)`, and multiplies that whole span by the `cost_per_block` value that is current *at the moment of this call*: [2](#0-1) 

`cost_per_block` is a single governance-configurable rate per state machine, updated in place with no time-scoping: [3](#0-2) [4](#0-3) 

Just like `feesUpdatedAt` in the Popcorn `Vault`, the watermark `LastRewardedHeight` is only moved forward inside the `if reward.is_zero() { return Ok(()); }` early-return branch of `process_message` — i.e., only when a payout actually happens: [5](#0-4) 

This creates the same accrual/rate-mismatch flaw as M-19: nothing forces a relayer to deliver a `ConsensusMessage` immediately after every height advance. A relayer (an unprivileged message dispatcher/relayer, one of the explicitly in-scope reachable roles) can simply withhold submission of consensus proofs for a state machine while `cost_per_block` is low (or the height keeps advancing on-chain via other relayers/consensus updates without this relayer claiming a reward — `LastRewardedHeight` stays frozen at the old watermark). Once governance raises `cost_per_block` (a routine, non-malicious rate adjustment, exactly like the Vault owner calling `changeFees()`), the relayer submits a single consensus message spanning the entire backlog of blocks. `calculate_reward` then pays `(latest_height - old_watermark) * new_cost_per_block` — collecting the new, higher rate for a span of blocks that mostly elapsed under the old, lower rate.

### Impact Explanation
This directly drains the `TreasuryAccount` funds beyond what governance intended to pay for that period, analogous to the Popcorn owner being able to "collect as much management fee as it wants for an already passed time period." Any relayer can amplify their payout by timing delivery around scheduled `cost_per_block` increases, extracting treasury funds that were meant to reward blocks delivered under the previous (lower) rate. Because rewards are minted 1:1 as a `ReputationAsset` as well, the relayer also gets an inflated reputation credit for the same backlog. This is a concrete theft-of-funds vector against the shared incentives treasury, reachable by any relayer without needing any admin/governance collusion.

### Likelihood Explanation
Likelihood is high: no special privileges are needed by the exploiting party (only a relayer capable of holding back a `ConsensusMessage` submission, which is normal usage, not privileged); the only external dependency is that `cost_per_block` for a state machine is raised at some point (an ordinary, expected governance operation, not an attack), and the relayer can simply observe upcoming/on-chain rate changes and time their next submission accordingly to sweep the whole backlog at the higher rate.

### Recommendation
Update `LastRewardedHeight` (the watermark) every time a `StateMachineUpdated` event advances the height, even when `cost_per_block` is `None`/reward is zero, so the watermark always reflects the height that governance's rate applied "as of." Alternatively, snapshot `cost_per_block` at the time each height was reached (e.g., store a rate-effective-height checkpoint on `update_cost_per_block`) and split the reward calculation across each rate segment between the old watermark and the current height, so blocks are always paid at the rate that was actually in effect when they occurred — mirroring the correct fix recommended for the Popcorn Vault (`feesUpdatedAt` must always advance to prevent retroactive rate application).

### Proof of Concept
1. Governance sets `cost_per_block(state_machine_id) = 1` via `update_cost_per_block`.
2. The remote state machine's height advances (via other consensus messages/relaying) from height `H0` to `H0+1000`, but the targeted relayer withholds submitting any `ConsensusMessage` for it (or `on_executed` doesn't hit the `FeeHandler` path for that relayer), so `LastRewardedHeight` stays at `H0` (or `unwrap_or(previous_height)` never advances because no reward-worthy call succeeded).
3. Governance later raises `cost_per_block(state_machine_id) = 1000` (a routine incentive-tuning parameter change, comparable to `changeFees()`).
4. The relayer now submits a single `ConsensusMessage` proving the height has advanced to `H0+1000`.
5. `calculate_reward` computes `blocks = 1000`, `reward = 1000 * 1000 = 1_000_000`, even though 999 of those blocks accrued while `cost_per_block` was `1`. The relayer is paid ~1000x more than intended for that backlog, and `LastRewardedHeight` is set to `H0+1000` — see `test_incentivize_relayer` / `reward_covers_only_unpaid_heights_after_rollback` in `modules/pallets/testsuite/src/tests/pallet_consensus_incentives.rs` for the existing (rate-static) reward-accrual mechanics that this timing attack builds on. 	fn process_message(
		state_machine_height: StateMachineHeight,
		state_machine_id: StateMachineId,
		relayer_account: T::AccountId,
	) -> Result<(), Error<T>> {
		if let Some(block_cost) = StateMachinesCostPerBlock::<T>::get(state_machine_id) {
			let reward = Self::calculate_reward(&state_machine_id, block_cost)?;

			if reward.is_zero() {
				return Ok(());
			}

			T::Currency::transfer(
				&T::TreasuryAccount::get().into_account_truncating(),
				&relayer_account,
				reward,
				Preservation::Expendable,
			)
			.map_err(|_| Error::<T>::RewardTransferFailed)?;

			Self::deposit_event(Event::<T>::RelayerRewarded {
				relayer: relayer_account.clone(),
				amount: reward,
				state_machine_height,
			});

			T::ReputationAsset::mint_into(&relayer_account, reward.saturated_into())
				.map_err(|_| Error::<T>::ReputationMintFailed)?;

			LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
				*watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
			});
		}
		Ok(())
	}

		#[pallet::weight(T::WeightInfo::update_cost_per_block())]

			origin: OriginFor<T>,
			state_machine_id: StateMachineId,

		) -> DispatchResult {

			});

				state_machine_id,
				cost_per_block,
			});

			Ok(())

#[test]
fn reward_covers_only_unpaid_heights_after_rollback() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		const BLOCK_COST: u128 = 100;
		let host = Ismp::default();
		let state_machine_id = setup_state_machine();
		let treasury_account: AccountId32 = PalletId(*b"treasury").into_account_truncating();

		pallet_consensus_incentives::Pallet::<Test>::update_cost_per_block(
			RuntimeOrigin::root(),
			state_machine_id,
			BLOCK_COST,
		)
		.unwrap();

		let (consensus_message, relayer_account) = setup_host_and_message(&host);
		let message = MessageWithWeight { message: consensus_message, weight: Weight::zero() };
		let updated = |height: u64| {
			vec![IsmpEvent::StateMachineUpdated(StateMachineUpdated {
				state_machine_id,
				latest_height: height,
			})]
		};

		// The chain has already advanced to 1025 and every block up to it has been rewarded once.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1024 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1024,
		})
		.unwrap();
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1025 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1025,
		})
		.unwrap();

		let treasury_before_first = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message.clone()],
			updated(1025),
		)
		.unwrap();

		assert_eq!(Balances::balance(&treasury_account), treasury_before_first - BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1025)
		);

		// The previous-height pointer references an older height whose commitment is no longer
		// retained in the bounded map.
		pallet_ismp::PreviousStateMachineHeight::<Test>::insert(state_machine_id, 1);

		// Deleting the latest commitment rolls the latest height back to that previous pointer.
		host.delete_state_commitment(StateMachineHeight { id: state_machine_id, height: 1025 })
			.unwrap();
		assert_eq!(host.latest_commitment_height(state_machine_id).unwrap(), 1);

		// The next honest consensus update advances to 1030, carrying the stale pointer forward as
		// the new previous height.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1030 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1030,
		})
		.unwrap();
		assert_eq!(host.previous_commitment_height(state_machine_id), Some(1));

		let treasury_before_second = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message],
			updated(1030),
		)
		.unwrap();

		// The real advance is 1025 -> 1030, so only the 5 new blocks are paid rather than the full
		// span back to the previous pointer.
		assert_eq!(Balances::balance(&treasury_account), treasury_before_second - 5 * BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1030)
		);
	})
}
