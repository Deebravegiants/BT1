Audit Report

## Title
Sensitive DKG key material export accessible via default `Edit` role instead of `Admin` role - (File: core/web/router.go)

## Summary
The `/v2/vault/dkg_results/export` route is registered with `auth.RequiresEditRole`, while every other secret/key-export endpoint in the same router file (`csakc.Export`, `ekc.Export`, `vrfkc.Export`, and analogous OCR/OCR2/P2P key exports) is registered with `auth.RequiresAdminRole`. This inconsistency allows a lower-privileged `Edit`-role user to retrieve the raw `ReportWithResultPackage` for a DKG instance, which is the material used to derive the node's TDH2 private key share for the Vault OCR plugin.

## Finding Description
`core/web/router.go` wires the vault export route behind `auth.RequiresEditRole`: [1](#0-0) . Every comparable `.../export/...` route in the same file uses `auth.RequiresAdminRole` instead, e.g. CSA, ETH, and VRF key exports: [2](#0-1) .

`RequiresEditRole` only blocks `UserRoleView` and `UserRoleRun`, letting `UserRoleEdit` (and `UserRoleAdmin`) through, whereas `RequiresAdminRole` requires the `admin` role specifically: [3](#0-2) . The four-tier role hierarchy (`admin` > `edit` > `run` > `view`) is defined in [4](#0-3) , confirming `edit` is a distinct, lower-privileged role than `admin`.

The handler itself performs no additional authorization check beyond the route middleware — it decodes the request, looks up the result package by `instanceId`, and returns it hex-encoded: [5](#0-4) . The lookup in `ReadResultPackage` is keyed solely by `instance_id` with no per-user/ownership scoping at the SQL layer: [6](#0-5) , and the `dkg_results` table has no ownership column: [7](#0-6) .

This exported package is exactly the material from which the Vault OCR plugin derives the node's TDH2 public key and, critically, its private key share via `TDH2PrivateShareFromDKGResult`: [8](#0-7) .

## Impact Explanation
An `Edit`-role user — a role explicitly used for routine job/bridge management rather than owner/admin-level trust — can pull the raw DKG result package for any known/guessed `instanceId`. This is sensitive key derivation material for the Vault threshold-decryption scheme, and its exposure to a non-admin actor is a legitimate key/secret-material access-control weakness that maps to the in-scope "key/secret exfiltration" impact category. Full compromise of the vault (decrypting arbitrary secrets) would still require collecting enough shares to reach the threshold `T`, so standalone impact is disclosure of one node's private key share material rather than immediate full secret decryption — but the access-control gap itself is real and inconsistent with the codebase's own established pattern for every other key-export endpoint.

## Likelihood Explanation
Exploitation requires only an existing `Edit`-role session/API token — a role that is commonly granted to non-admin operators for day-to-day job/bridge configuration — plus knowledge of a valid `instanceId`, which is not access-controlled at the ORM layer. No admin credentials, host access, or additional privilege escalation is required, making this readily exploitable once an `Edit`-role credential exists, which is a realistic and lower-trust bar than `Admin`.

## Recommendation
Change the route guards for `/v2/vault/dkg_results/export` (and evaluate `/vault/dkg_results/verify`) from `auth.RequiresEditRole` to `auth.RequiresAdminRole`, consistent with every other key/secret export endpoint registered in `core/web/router.go`. Additionally, consider adding an explicit access-control check within `ReadResultPackage`/`ExportDKGResult` rather than relying solely on route-level middleware.

## Proof of Concept
1. Provision an API token for a user with role `Edit` (via `POST /v2/users` by an admin, or an OIDC/LDAP mapping to the edit group).
2. Authenticate as that user and send:
   ```
   POST /v2/vault/dkg_results/export
   Content-Type: application/json

   {"instanceId": "<known-instance-id>"}
   ```
3. Observe the response returns `hexDKGResultPackage` and its SHA-256 with HTTP 200, as exercised (without any admin-role assertion) by the existing test [9](#0-8) . Modify this test to authenticate with an `Edit`-role client (instead of the default admin test client) to directly demonstrate the privilege gap.

func RequiresEditRole(handler func(*gin.Context)) func(*gin.Context) {
	return func(c *gin.Context) {
		user, ok := GetAuthenticatedUser(c)
		if !ok {
			c.Abort()
			jsonAPIError(c, http.StatusUnauthorized, errors.New("not a valid session"))
			return
		}
		if user.Role == clsessions.UserRoleView || user.Role == clsessions.UserRoleRun {
			c.Abort()
			jsonAPIError(c, http.StatusUnauthorized, errors.New("Unauthorized"))
			return
		}
		handler(c)
	}
}

// ExportDKGResult returns the DKGResult corresponding to the given instance ID
// "POST <application>/vault/dkg_results/export"
func (vc *VaultController) ExportDKGResult(c *gin.Context) {
	var req ExportDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId is required"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

	hexPackage := hex.EncodeToString(v.ReportWithResultPackage)
	sha := sha256.Sum256(v.ReportWithResultPackage)
	shaStr := hex.EncodeToString(sha[:])
	jsonAPIResponse(c, presenters.NewExportDKGResultResource(hexPackage, shaStr), "exportDKGResult")
}

func (o *orm) ReadResultPackage(ctx context.Context, iid dkgocrtypes.InstanceID) (*dkgocrtypes.ResultPackageDatabaseValue, error) {
	var configDigest []byte
	var seqNr uint64
	var reportWithResultPackage []byte
	var signatures pq.ByteaArray
	var signerOracleIDs []byte

	query := `SELECT config_digest, seq_nr, report_with_result_package, signatures, signer_oracle_ids FROM dkg_results WHERE instance_id = $1;`
	row := o.ds.QueryRowxContext(ctx, query, iid)
	err := row.Scan(&configDigest, &seqNr, &reportWithResultPackage, &signatures, &signerOracleIDs)
	if errors.Is(err, sql.ErrNoRows) {
		return nil, nil
	}
	if err != nil {
		return nil, errors.Wrap(err, "failed to read dkg result")
	}

func (r *ReportingPluginFactory) getKeyMaterial(ctx context.Context, instanceID string) (publicKey *tdh2easy.PublicKey, privateKeyShare *tdh2easy.PrivateShare, err error) {
	pack, err := r.db.ReadResultPackage(ctx, dkgocrtypes.InstanceID(instanceID))
	if err != nil {
		return nil, nil, fmt.Errorf("could not read result package from db: %w", err)
	}
	if pack == nil {
		return nil, nil, fmt.Errorf("no result package found in db for instance ID %s", instanceID)
	}
	rP := dkgocr.NewResultPackage()
	err = rP.UnmarshalBinary(pack.ReportWithResultPackage)
	if err != nil {
		return nil, nil, fmt.Errorf("could not unmarshal result package: %w", err)
	}

	tdh2PubKey, err := tdh2shim.TDH2PublicKeyFromDKGResult(rP)
	if err != nil {
		return nil, nil, fmt.Errorf("could not get tdh2 public key from DKG result: %w", err)
	}
	publicKey, err = tdh2ToTDH2EasyPK(tdh2PubKey)
	if err != nil {
		return nil, nil, fmt.Errorf("could not convert to tdh2easy public key: %w", err)
	}

	tdh2PrivateKeyShare, err := tdh2shim.TDH2PrivateShareFromDKGResult(rP, r.recipientKey)
	if err != nil {
		return nil, nil, fmt.Errorf("could not get tdh2 private key share from DKG result: %w", err)
	}
	privateKeyShare, err = tdh2ToTDH2EasyKS(tdh2PrivateKeyShare)
	if err != nil {
		return nil, nil, fmt.Errorf("could not convert to tdh2easy private key share: %w", err)
	}

	return publicKey, privateKeyShare, nil
}
