### Title
Signed `maxFee` bound in Emporium is bypassed by repeating the fee token in `erc20TokenAddresses`, letting the prover drain a signer's `HinkalWallet` beyond the authorized amount - (File: contracts/external-actions/emporium/upgradeable/EmporiumUpgradeable.sol)

### Summary
`EmporiumUpgradeable.verifyWallet` only checks that the *single* value `circomData.feeStructure.flatFee` does not exceed the EIP-712 signed `stack.maxFee` [1](#0-0) . However, `payRelayFees` charges `flatFee` from the signer's wallet **once per matching token index** in `circomData.erc20TokenAddresses`, not once per transaction [2](#0-1) . Because `erc20TokenAddresses` is caller-supplied data with no uniqueness constraint enforced anywhere in `dimensionsCheck` [3](#0-2) , a submitter (prover/relayer) who holds a legitimately signed `EmporiumStack` (with a genuine `maxFee`) can repeat the fee-token address N times, each paired with a separate real, negative `amountChange`/nullifier the submitter owns, and cause `sendToRelayFromWallet`→`IHinkalWallet.doSendToRelay` to pull `flatFee` from the signer's wallet N times, i.e. `N × flatFee`, which the signer never authorized.

### Finding Description
`verifyWallet` binds the EIP-712 signature to `stack.ops`, `stack.maxFee`, and `stack.deadline` [4](#0-3) , and enforces `feeStructure.flatFee <= stack.maxFee`. This gives the signer the reasonable expectation that at most `maxFee` will be taken from their `HinkalWallet` for the transaction.

`payRelayFees` iterates over `circomData.erc20TokenAddresses` and, for **every** index `i` where `deltaAmountChanges[i] < 0` and the token equals `feeStructure.feeToken`, computes `flatFee` and calls `payRelay`, which (since `signerAddress != address(0)`) calls `sendToRelayFromWallet` → `IHinkalWallet(signerAddress).doSendToRelay(...)` [5](#0-4) . Neither `payRelayFees` nor `dimensionsCheck`/`performHinkalChecks` [6](#0-5)  guarantee that a token address appears at most once, so nothing stops the fee-token address from occupying multiple slots.

`HinkalWallet.doSendToRelay` has no per-tx limit; it is only gated by `onlyEmporium` [7](#0-6) , so each call from `EmporiumUpgradeable` unconditionally moves `flatFee` out of the wallet.

The equality that is broken: `total value debited from signer's HinkalWallet == stack.maxFee (signed, once)`. In reality the code enforces `flatFee <= maxFee` per matching index, but lets the number of matching indices be attacker-controlled, so the true debit is `count(matching indices) × flatFee`, which can exceed `maxFee` by an arbitrary multiple, entirely outside anything the signer approved.

### Impact Explanation
This is theft of funds from a user's `HinkalWallet` beyond what that user's EIP-712 signature authorized (`maxFee`). Since the wallet is a per-user contract holding real ERC20/ETH balances used to pay relay fees for Emporium operations, an attacker who obtains one valid signed message (e.g. via a legitimate dApp flow) can drain the wallet in a single transaction by repeating the fee token entry as many times as the dimensions/circuit configuration allows, each backed by a small real withdrawal from the attacker's own shielded balance. This meets the "theft ... of protocol/relay fees" / "unauthorised asset movement" criteria, and in the worst case (large flatFee, many repeats) can amount to full wallet drainage, which is closer to "temporary or permanent freezing/theft of user funds."

### Likelihood Explanation
Requires the attacker to possess a validly signed `EmporiumStack` for the target wallet (obtainable through the normal relay/dApp flow that a real user would use) and enough of their own valid nullifiers/UTXOs of the fee token to populate the duplicate indices — both fully within reach of an ordinary, unprivileged transaction submitter. No admin/relay/oracle privilege is needed; the vulnerable code path (`payRelayFees`) is reached on every `runAction` call for Emporium.

### Recommendation
Compute and charge the wallet-side flat fee at most once per transaction (not per erc20TokenAddresses index), e.g., track a boolean "fee already charged" flag, or sum required fee first and validate `sum <= stack.maxFee` before performing any transfer. Additionally, enforce uniqueness of `erc20TokenAddresses` in `dimensionsCheck`/`performHinkalChecks`, or otherwise bind the exact per-token fee schedule into the EIP-712 signed payload instead of trusting the caller-provided token list.

### Proof of Concept
1. Attacker legitimately obtains a signed `EmporiumStack` from victim's wallet, with `signerAddress = victimWallet`, `maxFee = F`, some benign `ops`.
2. Attacker crafts `circomData` for `Hinkal.transact` with `erc20TokenAddresses = [feeToken, feeToken, feeToken, ...]` (N copies), each index backed by a distinct real nullifier/UTXO the attacker owns for `feeToken`, with `amountChanges[i] < 0` for each (a legitimate small withdrawal by the attacker of their own funds), and `feeStructure.feeToken = feeToken`, `feeStructure.flatFee = F` (≤ signed `maxFee`).
3. Proof passes since `calldataHash`/`getSignedMessageHash` bind exactly this metadata, and `verifyWallet` only checks `flatFee(F) <= maxFee(F)` — passes.
4. `_externalTransact` → `EmporiumUpgradeable.runAction` → `payRelayFees` loops over the N matching indices, calling `payRelay` → `sendToRelayFromWallet` → `victimWallet.doSendToRelay(relay, F, feeToken)` N times.
5. Victim's wallet is debited `N × F` total, even though the signature only authorized `F`.

    function payRelayFees(
        CircomData calldata circomData,
        address signerAddress,
        int256[] calldata deltaAmountChanges
    ) internal {
        FeeStructure calldata feeStructure = circomData.feeStructure;

        bool foundToken = false;

        for (uint256 i = 0; i < circomData.erc20TokenAddresses.length; i++) {
            // tokens deposited into Emporium are not charged
            if (deltaAmountChanges[i] >= 0) {
                continue;
            }

            address erc20TokenAddress = circomData.erc20TokenAddresses[i];
            bool isFeeToken = erc20TokenAddress == feeStructure.feeToken;

            if (isFeeToken) {
                foundToken = true;
            }

            uint256 relayFee = 0;
            uint256 flatFee = isFeeToken ? feeStructure.flatFee : 0;

            if (signerAddress == address(0)) {
                uint256 sumAbs = uint256(-deltaAmountChanges[i]);

                EmporiumStorageVars storage $ = _getEmporiumStorage();
                relayFee = $._hinkalHelper.calculateRelayFee(
                    sumAbs,
                    flatFee,
                    feeStructure.variableRate
                );
            } else {
                relayFee = flatFee;
            }

            payRelay(
                circomData.relay,
                signerAddress,
                relayFee,
                erc20TokenAddress
            );
        }

        if (!foundToken && feeStructure.flatFee != 0) {
            require(
                signerAddress != address(0),
                "Gas Token in Emporium is not found"
            );

            payRelay(
                circomData.relay,
                signerAddress,
                feeStructure.flatFee,
                feeStructure.feeToken
            );
        }
    }

    function verifyWallet(
        EmporiumStack memory stack,
        CircomData calldata circomData
    ) internal {
        EmporiumStorageVars storage $ = _getEmporiumStorage();

        if ($.usedMessages[circomData.emporiumMessage]) {
            revert UsedMessage();
        }

        $.usedMessages[circomData.emporiumMessage] = true;

        if (stack.signerAddress == address(0)) {
            return;
        }

        bytes32 hashedMessage = _hashTypedDataV4(
            keccak256(
                abi.encode(
                    EMPORIUM_SIGNATURE_TYPEHASH,
                    circomData.emporiumMessage,
                    _hashEmporiumOps(stack.ops),
                    stack.maxFee,
                    stack.deadline
                )
            )
        );

        (address recoveredAddress, ECDSA.RecoverError err) = ECDSA.tryRecover(
            hashedMessage,
            stack.v,
            stack.r,
            stack.s
        );
        bool verified = err == ECDSA.RecoverError.NoError &&
            recoveredAddress == stack.signerAddress;
        if (!verified) {
            revert InvalidSignature();
        }

        if (block.timestamp > stack.deadline) {
            revert SignatureExpired();
        }

        if (circomData.feeStructure.flatFee > stack.maxFee) {
            revert FeeExceedsSignedMax();
        }
    }
