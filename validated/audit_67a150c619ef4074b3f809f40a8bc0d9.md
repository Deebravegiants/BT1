## Title
`triggerGraduation` reads live, seller-manipulable curve reserves to price the graduation LP, letting a trader sell-then-trigger-then-buy-cheap to sandwich the HyperSwap LP seed - (`packages/contracts/src/Bonding.sol`)

### Summary
The external report's bug class is: a permissionless function executes an AMM-price-moving action using state that a caller can manipulate immediately beforehand, letting the caller sandwich it for profit. Alt.fun's analog is `Bonding.triggerGraduation`, a fully permissionless function that locks in the exact price at which the graduation LP will later be seeded on HyperSwap, using the curve pair's *live* reserves at call time.

### Finding Description
`triggerGraduation` is `external` with no access control beyond `canGraduate(tokenAddress)` being true, and calls `_enterGraduating` inline: [1](#0-0) 

`_enterGraduating` calls `_prepareGraduationLiquidity`, which reads the pair's **current** reserves and derives the exact ratio the graduation LP will open at: [2](#0-1) 

That ratio (`tokensForLP` / `ltFromPair`) is cached and later deposited **verbatim** into the HyperSwap pool by `finalizeGraduation`, by design intended to make the LP open at "the exact curve-close ratio": [3](#0-2) [4](#0-3) 

The protocol's own documentation confirms the LP is meant to open at "precisely the last curve price," and that `triggerGraduation` is a standalone, permissionless entry point that "reads pair reserves ... only," independent of any actual buy: [5](#0-4) 

Crucially, "curve close price" is whatever the pair's reserves say *at the instant `triggerGraduation` is called* - and a normal `sell()` on the curve moves those reserves down before that instant. `Bonding.sell` routes through the AMM with no curve fee (per the repo's own AGENTS.md framing of the AMM math), so a large sell right before `triggerGraduation` depresses the token's marginal LT-price on the curve, and that depressed marginal price is exactly what gets baked into the HyperSwap LP a moment later via `finalizeGraduation` (also permissionless, callable by the same address or a bot immediately after).

An attacker can then buy tokens back on the freshly-seeded, comparatively shallow HyperSwap LP (`tokensForLP`/`ltFromPair` is a bounded fraction of total curve depth) at this artificially depressed opening price, extracting the classic AMM sandwich profit: sell into a deep pool (paying an average execution price above the final marginal tick), then buy back at/near that final marginal tick on a second, price-linked venue that just opened at that tick.

The attack is bounded by `canGraduate` staying true through the sell — the docs note a sell alone can never *newly satisfy* either graduation trigger — so the exploit window is a token that is already comfortably past the USD threshold (or fully sold out on the supply trigger) such that a sizeable sell still leaves `canGraduate()` true, or the sell is sized to stay just above the threshold.

### Impact Explanation
This lets an unprivileged trader extract value that should belong to the protocol/LP holders at graduation: the token's real backing (LT) is skewed by a self-inflicted, temporary price depression on the curve, and that depressed price is permanently and irreversibly locked into the HyperSwap LP (`LPLock.recordLock` is one-shot, no re-pricing). Any buy-back profit realized on the shallow post-graduation pool comes at the expense of the LP (i.e., future buyers/holders of the graduated token), which is a form of value extraction/permanent mispricing of a locked LP position — matching the "LP seeded away from the curve close price" impact class called out in scope.

### Likelihood Explanation
`triggerGraduation` and `finalizeGraduation` are both explicitly `external`/permissionless and require no special role, no delay, and no keeper cooperation — "anyone can call to rescue a stuck token" per the natspec. An attacker only needs: (1) a token already near/above the graduation threshold, (2) enough capital to sell a slug of tokens on the curve without dropping `canGraduate()` back to false, and (3) capital to buy back on the newly seeded HyperSwap pool. All three steps are composable in a single attacker-controlled bundle/transaction sequence with no permission checks blocking any of them.

### Recommendation
Do not let a bare `sell()` immediately followed by a permissionless `triggerGraduation()` set the graduation LP price. Options: require `triggerGraduation` to use a TWAP/checkpointed reserve snapshot rather than the instantaneous spot reserves, add a cooldown between the last trade and eligibility to call `triggerGraduation`, or restrict `triggerGraduation` to be driven only by the exchange-rate-only ripening case it was designed for (LT appreciation with no intervening curve trade) rather than any state that a sell can move.

### Proof of Concept
1. Token X is trading on the curve, comfortably above the $9K USD graduation threshold (`canGraduate(X) == true` with margin).
2. Attacker sells a large slug of X into the curve via `Bonding.sell`/`Zap.sell`, receiving LT out and depressing the curve's marginal LT/token price, while keeping `canGraduate(X)` true.
3. Same transaction (or immediately after), attacker calls `Bonding.triggerGraduation(X)` — permissionless, no cooldown — which calls `_enterGraduating` → `_prepareGraduationLiquidity`, caching `tokensForLP`/`ltFromPair` at the now-depressed ratio.
4. Attacker (or anyone) calls `Bonding.finalizeGraduation(X)`, seeding the HyperSwap TOKEN/LT pool at exactly this depressed ratio.
5. Attacker buys X back on the freshly-seeded, shallow HyperSwap pool near the depressed opening tick, recovering more X per LT spent than the effective rate they sold at, net of the round trip.

    function triggerGraduation(
        address tokenAddress
    ) external nonReentrant {
        TokenInfo storage info = _s().tokenInfo[tokenAddress];
        if (info.creator == address(0)) revert TokenNotTrading();
        if (info.lifecycle == Lifecycle.Graduating) revert TokenIsGraduating();
        if (info.lifecycle != Lifecycle.Curve) revert TokenNotTrading();
        if (!canGraduate(tokenAddress)) revert NotGraduatable();
        _enterGraduating(tokenAddress);
    }

    function finalizeGraduation(
        address tokenAddress
    ) external nonReentrant {
        BondingStorage storage $ = _s();
        TokenInfo storage info = $.tokenInfo[tokenAddress];
        if (info.lifecycle != Lifecycle.Graduating) revert NotGraduating();

        address lt = info.ltAddress;
        PendingGraduation memory p = $.pendingGraduation[tokenAddress];

        // Anything in this contract beyond `p.ltFromPair` belongs to a
        // concurrent graduation on the same LT (Phase 1 transferred it
        // via `Router.graduate`) or to stray dust. Either way it is
        // off-limits to this graduation's deposit and sweep — see
        // `_routerDepositAndDispose` and `_sweepLTToOwner`.
        // Saturating subtract: a balance below `p.ltFromPair` shouldn't
        // be reachable in normal operation, but we keep finalize from
        // bricking on a Panic if any future code path or non-canonical
        // LT briefly violates the invariant.
        uint256 ltBalance = IERC20(lt).balanceOf(address(this));
        uint256 protectedLT = ltBalance > p.ltFromPair ? ltBalance - p.ltFromPair : 0;

        address lpPair = _ensureUniswapV2Pair(tokenAddress, lt);
        uint256 liquidity = _seedUniswapV2Direct(tokenAddress, lt, lpPair, p.tokensForLP, p.ltFromPair, protectedLT);

        _sweepLTToOwner(lt, protectedLT);

        info.lifecycle = Lifecycle.Graduated;
        $.graduatedPair[tokenAddress] = lpPair;
        delete $.pendingGraduation[tokenAddress];

        LPLock($.lpLock).recordLock(tokenAddress, lpPair, liquidity);

        emit TokenGraduated(tokenAddress, lpPair, liquidity, p.tokensForLP, p.lpBurned, p.unsoldBurned);
    }
