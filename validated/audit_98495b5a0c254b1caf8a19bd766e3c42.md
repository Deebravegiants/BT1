`SECURITY.md` does not exclude this class of issue — it excludes things like leaked-credential-based attacks, DoS-only impacts, and non-sensitive info disclosure, but this finding is unauthenticated access to functional endpoints (pprof profiling/symbol resolution and metrics/topology disclosure) reachable by any network client with zero credentials, which is a legitimate node API authentication bypass, not merely "server-side non-confidential information disclosure" (pprof heap/goroutine dumps can leak process memory contents, which is more than IPs/server names/stack traces). Audit Report

## Title
Unauthenticated LOOP-plugin debug/pprof and metrics endpoints exposed to unprivileged HTTP clients - (File: `core/web/router.go`, `core/web/loop_registry.go`)

## Summary
`loopRoutes` in `core/web/router.go` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` on the router's base `api` group with no `auth.Authenticate*` middleware, unlike every other functional route group (`debugRoutes`, `sessionRoutes`, `v2Routes`). This allows any unauthenticated network client to enumerate LOOP plugin topology, scrape internal plugin metrics, and trigger arbitrary `net/http/pprof` profiling/symbol operations against internal plugin processes.

## Finding Description
`NewRouter` builds the `api` group with only rate limiting and session middleware, then mounts `loopRoutes(app, api)` alongside authenticated groups like `debugRoutes` and `v2Routes`. `debugRoutes` and the `authv2`/`userOrEI` groups explicitly wrap handlers in `auth.Authenticate(app.AuthenticationProvider(), ...)` plus role checks (`auth.RequiresAdminRole`, `auth.RequiresRunRole`, `auth.RequiresEditRole`). `loopRoutes`, however, registers its handlers (`discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`) directly on the unauthenticated group with no session/token/role check anywhere in the call chain. The handlers in `loop_registry.go` forward request bodies and query parameters (`debug`, `gc`, `seconds`) verbatim to the internal plugin's `/debug/pprof/*` and `/metrics` HTTP endpoints and return the raw response to the caller.

## Impact Explanation
Any unprivileged client reaching the node's HTTP interface can enumerate registered LOOP plugins and topology via `/discovery`, scrape plugin `/metrics`, and trigger CPU/heap/goroutine profiling and `debug/pprof/symbol` resolution on internal plugin processes with attacker-controlled duration (`seconds` parameter, extended further by `PPROFOverheadSeconds`). This is an authentication-bypass on a functional node API surface (not just header/metadata leakage), enabling information disclosure (profile/heap contents can reveal internal memory state) and sustained CPU/resource consumption on the plugin process. This maps to the in-scope "node API authentication bypass" impact category, though it does not enable direct fund movement or job/run manipulation, making it lower severity than fund-impacting bypasses.

## Likelihood Explanation
High likelihood of reachability: `loopRoutes` is registered unconditionally in `NewRouter` for every node with LOOP plugins configured, on the same listener/port as the rest of the public `/v2` API, requiring no credentials, cookies, or tokens — only network access to the node's web server.

## Recommendation
Wrap `loopRoutes` (or at minimum the pprof/symbol/metrics handlers) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` middleware (and consider `auth.RequiresAdminRole`) used by `debugRoutes`, or move these debug/metrics endpoints to a separate internal-only listener not exposed on the primary API interface.

## Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered so `l.registry.List()` is non-empty.
2. As an unauthenticated client (no session cookie, no API token), issue `GET /discovery` and observe a `200 OK` JSON response listing plugin names/metrics targets, with no `auth.Authenticate` middleware in the route registration chain (`core/web/router.go:230-236`).
3. Issue `GET /plugins/<pluginName>/debug/pprof/profile?seconds=30` and observe the request is proxied to the internal plugin's pprof endpoint and a 30-second CPU profile is returned, again with no credentials required, confirmed by `pluginPPROFHandler` (`core/web/loop_registry.go:150-165`) having no auth gate anywhere in its call path.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}
