### Title
Overcapture window allows a bystander's face to silently overwrite `self_custody_candidate_rgb`, binding a different identity's face to another user's signup - ([File: src/plans/biometric_capture/overcapture.rs] / [File: src/plans/biometric_capture/mod.rs])

### Summary
During `overcapture::Plan::perform_overcapture`, `ir_net`, `mirror`, `eye_tracker`, and `eye_pid_controller` are disabled while `rgb_net` and `face_identifier` remain active and continue to feed the shared `biometric_capture::Plan::handle_face_identifier`/`handle_rgb_net` handlers. Because those handlers select the "best" self-custody frame purely by comparing `face_identifier::Output::IsValidImage.score` with no cross-frame identity/embedding continuity check, a bystander who steps into frame during this window can have their face silently replace the previously captured subject's face in `self_custody_candidate_rgb` (and even `left_rgb`/`right_rgb`).

### Finding Description
`overcapture::Plan` delegates `handle_ir_net`/`handle_rgb_net` to the wrapped `biometric_capture::Plan` [1](#0-0) , and `perform_overcapture` explicitly disables `ir_net`, mirror, eye tracker, and eye PID controller while leaving RGB-Net/face-identifier (driven via `mega_agent_two`) enabled for the configured `overcapture_duration` [2](#0-1) .

During this window, any valid RGB-Net+face-identifier detection - from any face in the camera FOV, not necessarily the QR-scanning subject - is processed by `biometric_capture::Plan::handle_face_identifier`, which unconditionally overwrites `self_custody_candidate_rgb` whenever the new score exceeds the previous best, with no check that the new frame's face matches the identity of previously stored frames (e.g., `left_ir`/`right_ir`, or the earlier `left_rgb`/`right_rgb`): [3](#0-2) . `handle_rgb_net` similarly overwrites `left_rgb`/`right_rgb` purely based on presence of a valid bbox estimate, with no identity check [4](#0-3) .

Since `ir_net` is disabled during overcapture, there is no concurrent iris signal to cross-validate that the RGB face being scored still belongs to the person whose iris was already captured in `left_ir`/`right_ir` for that objective. Disabling `mirror`/`eye_tracker`/`eye_pid_controller` also removes the active-alignment constraint that normally keeps the RGB/IR cameras centered on one tracked subject, making it easier for an untracked bystander's face to register a qualifying `IsValidImage` estimate.

The resulting `self_custody_candidate_rgb` frame is carried into `into_capture()` as `face_self_custody_candidate` [5](#0-4) , and later sent to the downstream face-identifier pipeline alongside `face_left`/`face_right` for fraud-check estimation [6](#0-5) . The actual cross-check logic that would compare `face_left`/`face_right` against `face_self_custody_candidate` for identity consistency (`FraudChecks`) is not present in this FOSS-stripped repository - the visible `estimate()` implementation unconditionally returns `FraudChecks::default()` without any embedding comparison [7](#0-6) , so this codebase provides no evidence that such a mismatch is caught before the capture is accepted.

### Impact Explanation
If exploited, a signup's iris data (bound to person A via `left_ir`/`right_ir`) could be paired with a bystander's (person B's) face in `face_self_custody_candidate`, which is used for self-custody/face-image-based account recovery/thumbnail purposes tied to person A's `signup_id`/`user_id`. This is a wrong-identity-binding condition matching a "signup completes bound to a user identity/data-policy that is not the presented QR's true bearer" bounty impact category.

### Likelihood Explanation
Exploitation requires: (1) knowledge/observation of a live signup using `SignupMode::Overcapture` (an operator- or backend-configured extension, not attacker-controlled by default), and (2) physical presence to step into the camera FOV during the ~1 second (default) `perform_overcapture` window per eye, with a higher face-identifier score than the legitimate subject's face at that instant. This is a narrow, timing-dependent physical-proximity attack, and its real-world success also depends on unverified downstream `FraudChecks` behavior not visible in this repository, so likelihood is moderate/uncertain rather than trivially reliable.

### Recommendation
Add identity-continuity enforcement inside `biometric_capture::Plan::handle_face_identifier`/`handle_rgb_net` (e.g., embedding similarity or bbox/IoU continuity check against previously accepted frames for the same objective) before accepting a new best-score `self_custody_candidate_rgb`/`left_rgb`/`right_rgb`, and ensure this check is active during `perform_overcapture`, not only relying on downstream `FraudChecks` in the biometric pipeline.

### Proof of Concept
Integration test plan: drive `overcapture::Plan::perform_overcapture` (or the underlying `handle_face_identifier` handler directly) with a sequence of synthetic `face_identifier::Output::IsValidImage` outputs carrying two different embeddings/frames (simulating subject A then bystander B with a higher score), then call `into_capture()` and assert `face_self_custody_candidate.rgb_frame` still matches subject A's originally captured frame rather than B's higher-scoring frame - expected current behavior (bug) is that it matches B's frame, since `mod.rs:301-317` only compares `output.score`, not identity.

    async fn perform_overcapture(&mut self, orb: &mut Orb) -> Result<()> {
        tracing::info!("Overcapture extension: Beginning capture");
        self.state = State::Overcapturing { start_time: Instant::now() };

        orb.main_mcu.send(mcu::main::Input::FrameRate(CAPTURE_FPS)).await?;
        orb.disable_ir_net();
        orb.disable_ir_auto_focus();
        orb.disable_mirror();
        orb.disable_eye_tracker();
        orb.disable_eye_pid_controller();
        orb.ir_eye_save_fps_override = Some(f32::INFINITY);
        orb.ir_face_save_fps_override = Some(f32::INFINITY);
        orb.thermal_save_fps_override = Some(f32::INFINITY);

        orb.run(self).await?;

        orb.main_mcu.send(mcu::main::Input::FrameRate(IR_CAMERA_FRAME_RATE)).await?;
        orb.enable_ir_net().await?;
        orb.enable_ir_auto_focus()?;
        orb.enable_mirror()?;
        orb.enable_eye_tracker()?;
        orb.enable_eye_pid_controller()?;
        orb.ir_eye_save_fps_override = None;
        orb.ir_face_save_fps_override = None;
        orb.thermal_save_fps_override = None;

        Ok(())
    }

    fn handle_rgb_net(

        output: port::Output<rgb_net::Model>,

    ) -> Result<BrokerFlow> {
        if let rgb_net::Output::Estimate(estimate) = output.value {
            if let Some(prediction) = estimate.primary() {
                if prediction.bbox.coordinates.is_correct() {
                    let frame = frame.expect("frame must be set for an estimate output");
                    let slot =
                        if self.target_left_eye { &mut self.left_rgb } else { &mut self.right_rgb };
                    *slot = Some(FrameInfoRgb::new(estimate, frame));
                }
            }
        }
        Ok(BrokerFlow::Continue)
    }

    fn handle_face_identifier(
        &mut self,
        orb: &mut Orb,
        output: port::Output<face_identifier::Model>,
        frame: Option<camera::rgb::Frame>,
    ) -> Result<BrokerFlow> {
        if let face_identifier::Output::IsValidImage(output) = output.value {
            tracing::debug!("Face self-custody frame score: {:?}", output.score);
            if output.error.is_some() {
                tracing::error!("Face self-custody frame error: {:?}", output);
            }

            if output.is_valid.map_or(false, |v| v) {
                let highest = self
                    .self_custody_candidate_rgb
                    .as_ref()
                    .map_or(0.0, |p| p.estimate.score.unwrap_or_default());
                if output.score.is_some_and(|s| s > highest) {
                    tracing::info!(
                        "New face self-custody frame captured with score: {:?}",
                        output.score
                    );
                    self.self_custody_candidate_rgb = Some(FrameInfoSelfCustodyCandidate::new(
                        output,
                        frame.expect("frame must be set for FaceIdentifier::IsValidImage"),
                    ));
                    self.face_ir = self.last_face_ir.take();
                    self.thermal = self.last_thermal.take();
                }

                orb.only_rgb_net_frames = true;
            }
        }
        Ok(BrokerFlow::Continue)
    }
