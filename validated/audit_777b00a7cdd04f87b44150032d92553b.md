### Title
Unauthenticated "magic" operator QR codes allow any bystander to force repeated WiFi and mirror-calibration resets, causing signup denial-of-service - (File: `src/plans/mod.rs`, `src/plans/qr_scan/operator.rs`)

### Summary
The Orb's operator QR-code flow parses a special "magic" QR code format (`magic_action:reset_wifi_credentials` / `magic_action:reset_mirror_calibration`) and executes a disruptive reset action **before** the operator QR code is validated against the backend. Anyone who can present a printed/displayed QR code to the Orb's camera — no operator credential, badge, or backend authorization required — can trigger these resets, repeatedly, at will. This mirrors the TRST-M-9 pattern: a state-mutating action reachable without privilege that a malicious actor can spam to disrupt normal operation ("withdraw() called every block" → "magic QR shown every signup attempt").

### Finding Description
`qr_scan::operator::Data::try_parse` recognizes two "magic" variants via a permissive regex that only checks for the literal string pattern `magic_action:<name>`, with no cryptographic signature, operator authentication, or backend check: [1](#0-0) 

In the signup flow, `scan_operator_qr_code` captures the raw QR code, and `handle_magic_operator_qr_code` is invoked and acts on `MagicResetWifi`/`MagicResetMirror` **before** `verify_operator_qr_code` (the only step that talks to the backend to check whether the QR is a legitimate, valid operator code): [2](#0-1) [3](#0-2) 

The same unauthenticated ordering exists in the self-serve initial QR scan loop: [4](#0-3) 

`MagicResetWifi` calls `reset_wifi_and_ensure_network`, which tears down the current WiFi connection (restores default `wpa_supplicant.conf` and disconnects) and only then attempts to reconnect: [5](#0-4) [6](#0-5) 

`MagicResetMirror` calls `reset_mirror_calibration`, which re-triggers a full mirror auto-calibration sequence: [7](#0-6) 

Both branches call `orb.ui.magic_qr_action_completed(...)` and then return `Ok(None)`, aborting the in-progress signup attempt regardless of outcome: [8](#0-7) 

The root cause parallels TRST-M-9: a state-mutating action (there, `withdraw()`; here, network/mirror reset) is exposed on a path reachable by an untrusted party with no access control, and the fix scope did not consider that the action itself can be repeatedly abused as a denial-of-service primitive.

### Impact Explanation
Any person able to present a QR code to the Orb's camera during a signup attempt (i.e., anyone in front of the device — no operator badge, backend account, or credential needed) can:
- Force the Orb to drop its current WiFi connection and force a fresh reconnection cycle on demand (`reset_wifi_and_ensure_network`), and
- Force a full mirror recalibration cycle (`reset_mirror_calibration`),

and can abort any operator's in-progress signup session by doing so, since both magic branches short-circuit the QR loop with `Ok(None)`. Repeating this on every scan attempt makes it impossible for legitimate operators/users to complete a signup, denying service to the device — directly analogous to the reported "attacker calls `withdraw()` every block to make the system unusable."

### Likelihood Explanation
High. The trigger requires only physical presence in front of the Orb camera with a printed/displayed QR code containing a fixed, publicly-visible string pattern (`magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration`) — this is documented in-repo test code itself, showing the exact strings are trivial to discover and reproduce: [9](#0-8) 
No rate limiting, cooldown, or authentication gate exists on this path before the disruptive action executes.

### Recommendation
- Require backend/operator authentication (i.e., run `verify_operator_qr_code`-equivalent validation) before executing any magic/administrative action, not just before proceeding with a normal operator QR code.
- Add rate limiting/cooldown and audit logging for magic QR actions, and require signed or otherwise cryptographically verifiable magic codes rather than a plain-text pattern.
- Consider requiring these actions to originate from a physically distinct, privileged maintenance flow instead of the general-purpose signup QR scanner reachable by any bystander.

### Proof of Concept
1. Print or display a QR code containing the exact text `magic_action:reset_wifi_credentials`.
2. Present it to the Orb's camera during the operator QR-code scan phase of a signup attempt (`scan_operator_qr_code`).
3. Observe that `qr_scan::operator::Data::try_parse` matches `MagicResetWifi` via the regex with no backend/operator validation, and `handle_magic_operator_qr_code` immediately calls `reset_wifi_and_ensure_network`, dropping and re-establishing the WiFi connection and aborting the current signup (`Ok(None)`).
4. Repeat on every subsequent signup attempt (or with `magic_action:reset_mirror_calibration`) to keep disrupting the device indefinitely, since there is no cooldown or authentication check gating this action.

static MAGIC_QR_CODE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")
});

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
