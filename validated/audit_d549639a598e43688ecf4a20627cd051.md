### Title
Undersized graduation LP amounts permanently brick `finalizeGraduation`, freezing curve-raised LT and reserved tokens - (`File: packages/contracts/src/Bonding.sol`)

### Summary
`Bonding._prepareGraduationLiquidity` computes the exact `(tokensForLP, ltFromPair)` amounts to seed the post-graduation HyperSwap V2 pool from the curve's closing reserves, with no floor on their absolute size [1](#0-0) . These values are cached once in `pendingGraduation` and consumed unchanged by `finalizeGraduation` in phase 2, which seeds the pool via `_seedUniswapV2Direct` → `_seedDirectMint`, calling the external HyperSwap V2 pair's `mint()` directly [2](#0-1) . UniswapV2-style pairs unconditionally revert an empty-pool `mint()` when `sqrt(amount0*amount1) <= MINIMUM_LIQUIDITY (1000)`. If the cached amounts are small enough to trip that floor, `finalizeGraduation` reverts every time it is called, and because `_prepareGraduationLiquidity` already ran (irreversibly transferring the real raised LT out of the curve pair via `Router.graduate` and burning curve tokens) inside `_enterGraduating`/phase 1, there is no retry path that produces different amounts — the token is permanently stuck in `Lifecycle.Graduating`.

### Finding Description
Graduation has two independent triggers computed in `canGraduate`: the USD-value trigger (`realLtRaised * exchangeRate() >= graduationThresholdUsd`) and the curve-sellout trigger (`tokenBalance() == 0`) [3](#0-2) . `exchangeRate()` is read live from the external, rebasing-priced BounceTech LT. Because the curve's `virtualLtReserve` (and hence its LT-denominated depth) is fixed permanently at launch time off a *snapshot* of `exchangeRate()` [4](#0-3) , a subsequent large upward move in the LT's `exchangeRate()` means the fixed USD threshold (`graduationThresholdUsd`, e.g. $9,000) can be crossed by an arbitrarily small amount of *real* LT raised on the curve. `triggerGraduation` is fully permissionless and only checks `canGraduate` [5](#0-4) , so any address can fire phase 1 (`_enterGraduating`) the instant the USD trigger crosses, locking in `ltFromPair` (and the proportional `tokensForLP = ltFromPair * tokenReserve / assetReserve`) at whatever tiny value the exchange-rate spike produced [6](#0-5) .

Phase 2 (`finalizeGraduation`) is also permissionless and reuses these frozen amounts unconditionally [7](#0-6) . On the (~99%-common) empty-pair path it calls `_seedDirectMint`, which transfers exactly `(tokensForLP, ltFromPair)` to the pair and calls `IUniswapV2Pair(pair).mint(lpLock)` with no size floor [2](#0-1) . If `sqrt(tokensForLP * ltFromPair) <= 1000` (the standard UniswapV2 `MINIMUM_LIQUIDITY`), the external pair's `mint()` reverts with `INSUFFICIENT_LIQUIDITY_MINTED`, and since none of `_prepareGraduationLiquidity`'s effects (the LT already pulled out of the curve `Pair` via `Router.graduate`, the curve tokens already burned) are redone or adjustable on retry, every future call to `finalizeGraduation(tokenAddress)` fails identically. The contract has no owner or permissionless recovery path to top up, resize, or cancel a stuck graduation — `Bonding` never exposes a way to move funds out of `Lifecycle.Graduating` other than `finalizeGraduation`, and `Bonding.buy`/`sell` explicitly reject trades once `lifecycle == Lifecycle.Graduating` [8](#0-7) [9](#0-8) .

This is the Solidity analog of CVE-2017-6849: a code path that assumes internal state will always be "well-formed enough" for a downstream operation (there, a non-null color object consumed by a destructor; here, LP amounts large enough for a downstream pool's non-zero-liquidity invariant) and unconditionally crashes/reverts when a crafted or naturally-arising edge-case value reaches it, permanently denying the operation.

### Impact Explanation
All real LT ever raised by the curve for that token, plus up to `LP_RESERVE` (250,000,000 tokens, 25% of `TOTAL_SUPPLY`) reserved for LP, become permanently locked inside `Bonding` with no path to trading, graduation, or recovery. This is a permanent freezing of creator/trader funds tied to that launch, satisfying the Medium-severity DoS class of the source CVE.

### Likelihood Explanation
Reachable purely through permissionless calls (`Zap.buy`/curve buys to move the price, then `Bonding.triggerGraduation`, then `Bonding.finalizeGraduation`) with no privileged role required. It depends on the paired LT's `exchangeRate()` moving sharply upward relative to its launch-time snapshot — plausible given the LT is explicitly described as an externally rebasing-priced reserve asset whose rate is read live and can drift significantly from the launch snapshot, and any holder/attacker can time `triggerGraduation` to fire the instant the USD threshold is crossed with the smallest possible real-LT amount, minimizing `ltFromPair`/`tokensForLP`.

### Recommendation
Add a floor check in `_prepareGraduationLiquidity` (or before `_seedDirectMint`'s `mint()` call) ensuring `tokensForLP` and `ltFromPair` exceed the downstream V2 pool's minimum-liquidity requirement before committing phase 1, or provide an owner/permissionless recovery mechanism (e.g., allow topping up the LP-bound amounts, or redirecting stuck LT/tokens) so a token whose closing amounts round below `MINIMUM_LIQUIDITY` is not bricked indefinitely.

### Proof of Concept
1. Token launches paired with LT `L` at `exchangeRate() = R0`; `virtualLtReserve` and curve `k` are fixed off `R0` per `_deployAndSeed`.
2. `L.exchangeRate()` subsequently spikes (e.g., due to legitimate rebasing appreciation) to `R1 >> R0`.
3. Any address places one small curve buy via `Zap.buy` so a few wei of real LT enter the curve, just enough that `realLtRaised * R1 / 1e18 >= graduationThresholdUsd` in `canGraduate`.
4. Any address calls `Bonding.triggerGraduation(token)`; `_enterGraduating` computes and caches a `ltFromPair`/`tokensForLP` on the order of a few wei/units in `pendingGraduation`.
5. Any address calls `Bonding.finalizeGraduation(token)`; `_seedDirectMint` transfers the tiny amounts to the fresh HyperSwap V2 pair and calls `mint(lpLock)`, which reverts with `INSUFFICIENT_LIQUIDITY_MINTED` because `sqrt(tokensForLP * ltFromPair) <= 1000`.
6. Every subsequent call to `finalizeGraduation(token)` reverts identically forever; the token is stuck in `Lifecycle.Graduating`, and its raised LT plus reserved LP tokens are permanently unrecoverable.

    function canGraduate(
        address token_
    ) public view returns (bool) {
        BondingStorage storage $ = _s();
        TokenInfo storage info = $.tokenInfo[token_];
        if (info.creator == address(0)) return false;
        if (info.lifecycle != Lifecycle.Curve) return false;

        address pair = info.pair;
        if (IPair(pair).tokenBalance() == 0) return true;

        (, uint256 assetReserve) = IPair(pair).getReserves();
        uint256 realLtRaised = assetReserve - _launchTimeVirtualLtReserve(token_, pair);
        uint256 valueUsd = (realLtRaised * IBounceLeveragedToken(info.ltAddress).exchangeRate()) / 1e18;
        return valueUsd >= $.graduationThresholdUsd;
    }

    function finalizeGraduation(
        address tokenAddress
    ) external nonReentrant {
        BondingStorage storage $ = _s();
        TokenInfo storage info = $.tokenInfo[tokenAddress];
        if (info.lifecycle != Lifecycle.Graduating) revert NotGraduating();

        address lt = info.ltAddress;
        PendingGraduation memory p = $.pendingGraduation[tokenAddress];

        // Anything in this contract beyond `p.ltFromPair` belongs to a
        // concurrent graduation on the same LT (Phase 1 transferred it
        // via `Router.graduate`) or to stray dust. Either way it is
        // off-limits to this graduation's deposit and sweep — see
        // `_routerDepositAndDispose` and `_sweepLTToOwner`.
        // Saturating subtract: a balance below `p.ltFromPair` shouldn't
        // be reachable in normal operation, but we keep finalize from
        // bricking on a Panic if any future code path or non-canonical
        // LT briefly violates the invariant.
        uint256 ltBalance = IERC20(lt).balanceOf(address(this));
        uint256 protectedLT = ltBalance > p.ltFromPair ? ltBalance - p.ltFromPair : 0;

        address lpPair = _ensureUniswapV2Pair(tokenAddress, lt);
        uint256 liquidity = _seedUniswapV2Direct(tokenAddress, lt, lpPair, p.tokensForLP, p.ltFromPair, protectedLT);

        _sweepLTToOwner(lt, protectedLT);

        info.lifecycle = Lifecycle.Graduated;
        $.graduatedPair[tokenAddress] = lpPair;
        delete $.pendingGraduation[tokenAddress];

        LPLock($.lpLock).recordLock(tokenAddress, lpPair, liquidity);

        emit TokenGraduated(tokenAddress, lpPair, liquidity, p.tokensForLP, p.lpBurned, p.unsoldBurned);
    }

    function _prepareGraduationLiquidity(
        address tokenAddress
    ) internal returns (uint256 tokensForLP, uint256 ltFromPair, uint256 lpBurned, uint256 unsoldBurned) {
        address pairAddr = _s().tokenInfo[tokenAddress].pair;
        (uint256 tokenReserve, uint256 assetReserve) = IPair(pairAddr).getReserves();

        unsoldBurned = IPair(pairAddr).tokenBalance();
        if (unsoldBurned > 0) {
            Token(tokenAddress).burn(pairAddr, unsoldBurned);
        }

        ltFromPair = assetReserve - _launchTimeVirtualLtReserve(tokenAddress, pairAddr);
        if (ltFromPair > 0) {
            _s().router.graduate(tokenAddress, ltFromPair);
        }

        tokensForLP = assetReserve == 0 ? 0 : (ltFromPair * tokenReserve) / assetReserve;
        if (tokensForLP > LP_RESERVE) tokensForLP = LP_RESERVE;

        lpBurned = LP_RESERVE - tokensForLP;
        if (lpBurned > 0) {
            Token(tokenAddress).burn(address(this), lpBurned);
        }
    }
