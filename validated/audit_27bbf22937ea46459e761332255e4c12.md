### Title
Unbounded digest count allows out-of-gas DoS when decoding parachain headers before proof verification - ([File: evm/src/consensus/Codec.sol])

### Summary
`EcdsaBeefy.verify` first verifies the relay-chain BEEFY commitment and MMR leaf proof (`verifyMmrUpdateProof`), then calls `verifyParachainHeaderProof`, which SCALE-decodes every `para.header` via `Codec.DecodeHeader` **before** the parachain headers are checked against `headsRoot` with `MerkleMultiProof.VerifyProof`. `DecodeHeader` reads an attacker-controlled compact-encoded digest count and immediately allocates `new Digest[](length)` with no upper bound, size relative to the actual remaining bytes, or gas-aware validation. [1](#0-0) [2](#0-1) 

### Finding Description
In `EcdsaBeefy.verifyParachainHeaderProof`, each `Parachain` entry's raw header bytes is decoded with `Codec.DecodeHeader(para.header)` inside the loop that builds the merkle-multi-proof leaves — this decode runs unconditionally for every submitted header, and only *after* the full loop completes does the code call `MerkleMultiProof.VerifyProof(headsRoot, proof.proof, leaves, proof.leafCount)` to confirm those headers were actually part of the finalized parachain-heads root: [3](#0-2) 

Inside `Codec.DecodeHeader`, the digest count is a fully attacker-supplied SCALE compact integer (`ScaleCodec.decodeUintCompact`, mode 3 supports values up to ~4.5×10^15), and is used directly to size a dynamic memory array with no sanity bound against the remaining slice length: [4](#0-3) [5](#0-4) 

Because the header bytes are decoded before their inclusion in `headsRoot` is proven, an attacker does not need a valid parachain header or a valid merkle-multi-proof for the digest-DoS to trigger — they only need to satisfy the BEEFY authority signature/threshold checks in `verifyMmrUpdateProof` (which is separate and unrelated to the header content) and supply an arbitrarily crafted `para.header` byte string that decodes a huge digest length. This is directly analogous to CVE-2015-8901's pattern: a decoder reading an attacker-controlled length field from a crafted file and looping/allocating without validating it against the actual available data, causing resource exhaustion.

### Impact Explanation
A crafted `para.header` with a small number of bytes (32+compact+32+32 + a maliciously large compact-encoded digest count) forces Solidity to attempt allocating and zero-initializing a `Digest[]` array of up to ~4.5 quadrillion elements. This exhausts the block gas limit and reverts the entire `verify()` call, DoS-ing that specific consensus-proof submission. Because `verify()` is the entry point used to advance Hyperbridge's stored consensus state and deliver state-commitment updates for the parachain route (used by `HandlerV2`/`EvmHost` consensus updates that gate message delivery), a malicious or careless proof submitter can force reverts on well-formed BEEFY commitments bundled with a poisoned parachain header, wasting relayer gas and potentially stalling delivery of legitimate cross-chain messages that depend on that state update until a clean proof is resubmitted.

### Likelihood Explanation
Medium. The attacker must still assemble a valid signed BEEFY commitment/MMR-leaf proof (satisfying supermajority signatures) to get past `verifyMmrUpdateProof`, so this is not exploitable by a completely unauthenticated party with zero cost — but any relayer (an unprivileged role by design) submitting a real, otherwise-valid BEEFY update can pair it with an arbitrary/corrupted `para.header` blob, since header content is not verified against `headsRoot` until after the decode. No special privileges beyond "any relayer submitting a consensus proof" are required.

### Recommendation
- Verify `MerkleMultiProof.VerifyProof(headsRoot, proof.proof, leaves, proof.leafCount)` for the parachain headers **before** calling `Codec.DecodeHeader` on their raw bytes, so unverified header bytes are never decoded.
- In `Codec.DecodeHeader`, bound the digest `length` against the remaining bytes in `slice` (e.g., `length <= (slice.data.length - slice.offset)`, since each digest consumes at least 1 byte) before allocating `new Digest[](length)`, rejecting the header early instead of allocating unboundedly.

### Proof of Concept
1. Attacker (any relayer) obtains or fabricates a valid signed BEEFY commitment + MMR proof for an already-known finalized relay block (satisfying `verifyMmrUpdateProof`).
2. Attacker crafts a `ParachainProof.parachains[0].header` byte string: `parentHash(32 bytes) || blockNumber(compact) || stateRoot(32) || extrinsicsRoot(32) || digestCount` where `digestCount` is SCALE-compact-encoded as mode-3 with the maximum representable value (~4.5×10^15).
3. Attacker calls `EcdsaBeefy.verify(previousState, proof)` with this crafted `parachain` payload.
4. `verifyMmrUpdateProof` succeeds (valid commitment/signatures); `verifyParachainHeaderProof` then calls `Codec.DecodeHeader`, which executes `Digest[] memory digests = new Digest[](length)` with `length` ≈ 4.5×10^15, causing an out-of-gas revert well before the subsequent `MerkleMultiProof.VerifyProof` check ever runs — regardless of whether the header actually belongs to `headsRoot`.

    function verifyParachainHeaderProof(bytes32 headsRoot, ParachainProof memory proof)
        internal
        pure
        returns (IntermediateState[] memory)
    {
        uint256 len = proof.parachains.length;
        MerkleMultiProof.Leaf[] memory leaves = new MerkleMultiProof.Leaf[](len);
        IntermediateState[] memory intermediates = new IntermediateState[](len);

        for (uint256 i = 0; i < len; i++) {
            Parachain memory para = proof.parachains[i];
            Header memory header = Codec.DecodeHeader(para.header);
            if (header.number == 0) revert IllegalGenesisBlock();

            leaves[i] = MerkleMultiProof.Leaf(
                para.index,
                keccak256(bytes.concat(ScaleCodec.encode32(uint32(para.id)), ScaleCodec.encodeBytes(para.header)))
            );

            StateCommitment memory commitment = header.stateCommitment();
            intermediates[i] =
                IntermediateState({stateMachineId: para.id, height: header.number, commitment: commitment});
        }

        if (len > 0) {
            bool valid = MerkleMultiProof.VerifyProof(headsRoot, proof.proof, leaves, proof.leafCount);
            if (!valid) revert InvalidMmrProof();
        }

        return intermediates;
    }

    // @dev Deserializes a substrate header
    function DecodeHeader(bytes memory encoded) internal pure returns (Header memory) {
        ByteSlice memory slice = ByteSlice(encoded, 0);
        bytes32 parentHash = Bytes.toBytes32(Bytes.read(slice, 32));
        uint256 blockNumber = ScaleCodec.decodeUintCompact(slice);
        bytes32 stateRoot = Bytes.toBytes32(Bytes.read(slice, 32));
        bytes32 extrinsicsRoot = Bytes.toBytes32(Bytes.read(slice, 32));

        uint256 length = ScaleCodec.decodeUintCompact(slice);
        Digest[] memory digests = new Digest[](length);

        for (uint256 i = 0; i < length; i++) {
            uint8 kind = Bytes.readByte(slice);
            Digest memory digest;
            if (kind == DIGEST_ITEM_OTHER) {
                digest.isOther = true;
            } else if (kind == DIGEST_ITEM_CONSENSUS) {
                digest.isConsensus = true;
                digest.consensus = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_SEAL) {
                digest.isSeal = true;
                digest.seal = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_PRERUNTIME) {
                digest.isPreRuntime = true;
                digest.preruntime = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_RUNTIME_ENVIRONMENT_UPDATED) {
                digest.isRuntimeEnvironmentUpdated = true;
            }
            digests[i] = digest;
        }

        return Header(parentHash, blockNumber, stateRoot, extrinsicsRoot, digests);
    }

    // @dev Decodes a SCALE encoded compact unsigned integer
    function decodeUintCompact(ByteSlice memory data) internal pure returns (uint256 v) {
        uint8 b = readByte(data); // read the first byte
        uint8 mode = b & 3; // bitwise operation

        uint256 value;
        if (mode == 0) {
            // [0, 63]
            value = b >> 2; // right shift to remove mode bits
        } else if (mode == 1) {
            // [64, 16383]
            uint8 bb = readByte(data); // read the second byte
            uint64 r = bb; // convert to uint64
            r <<= 6; // multiply by * 2^6
            r += b >> 2; // right shift to remove mode bits
            value = r;
        } else if (mode == 2) {
            // [16384, 1073741823]
            uint8 b2 = readByte(data); // read the next 3 bytes
            uint8 b3 = readByte(data);
            uint8 b4 = readByte(data);

            uint32 x1 = uint32(b) | (uint32(b2) << 8); // convert to little endian
            uint32 x2 = x1 | (uint32(b3) << 16);
            uint32 x3 = x2 | (uint32(b4) << 24);

            x3 >>= 2; // remove the last 2 mode bits
            value = uint256(x3);
        } else if (mode == 3) {
            // [1073741824, 4503599627370496]
            uint8 l = (b >> 2) + 4; // remove mode bits
            require(l <= 8, "unexpected prefix decoding Compact<Uint>");
            return ScaleCodec.decodeUint256(read(data, l));
        } else {
            revert("Code should be unreachable");
        }
        return (value);
    }
