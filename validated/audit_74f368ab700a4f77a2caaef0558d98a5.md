## Title
Missing local response-receipt check lets a GET request be timed-out after it has already been answered - ([File: evm/src/core/HandlerV2.sol])

## Summary
`HandlerV2.handleGetRequestTimeouts` and `EvmHost.dispatchTimeOut(GetRequestTimeout,...)` never check the source chain's own `_responseReceipts[commitment]` before firing `onGetTimeout` on the requesting app. Any GET request whose response has already been delivered locally via `handleGetResponses` can subsequently be "timed out" with a stale non-membership proof, invoking `onGetTimeout` on a request the app already consumed via `onGetResponse`. This is the same class of bug as the Chrome Skia UAF: a resource (the GET request/commitment) that should be considered "freed"/finalized once answered is still reachable and re-processed through a second code path, corrupting whatever state the app keyed off that commitment.

## Finding Description
`EvmHost.dispatchIncoming(GetResponse memory response, address relayer)` sets `_responseReceipts[commitment]`, calls `onGetResponse` on the app, and pays the relayer fee — but it never deletes `_requestCommitments[commitment]`: [1](#0-0) 

Later, `HandlerV2.handleGetRequestTimeouts` verifies only a *remote* non-membership proof (against Hyperbridge/coprocessor state at `message.height`) that no response-receipt exists there, and then unconditionally dispatches the timeout: [2](#0-1) 

`EvmHost.dispatchTimeOut(GetRequestTimeout,...)` likewise performs no local check of `_responseReceipts[commitment]` before invoking `onGetTimeout`: [3](#0-2) 

Contrast this with the Substrate/Rust reference implementation, which explicitly guards against exactly this race by checking the local response receipt before allowing a GET timeout: [4](#0-3) 

Because the EVM non-membership proof is anchored to `message.height` (a specific historical Hyperbridge state height, not "now"), an attacker/relayer can supply a proof taken from a height *before* Hyperbridge recorded the response commitment, even though `handleGetResponses` has already been executed and settled locally on this EVM host. The `challengePeriod`/delay checks only bound how recent the *proof height* itself must be relative to when it was committed — they do nothing to prevent using an old height whose non-membership proof predates the actual response.

## Impact Explanation
An application built on `IApp.onGetResponse`/`onGetTimeout` (e.g. any state-query consumer, the intent-gateway cancellation flow which relies on GET responses/timeouts to decide fund release, or a custom app) can receive both a successful response callback and a timeout callback for the same request. Since these two callbacks typically encode mutually exclusive outcomes (data received vs. "give up and refund/retry"), a double-invocation can cause double refunds, unauthorized state transitions, or unsound accounting in any downstream app — a concrete "unauthorized app action" per app-level state assumptions, reachable purely by a relayer submitting a legally-proof-backed but stale message.

## Likelihood Explanation
Any permissionless relayer can call `handleGetRequestTimeouts` with a proof from an older Hyperbridge height once such a height's commitment is still retrievable (heights are retained per the consensus client's configured window), after the corresponding `handleGetResponses` has already succeeded on the source EvmHost. No privileged role or governance action is required — only a normal GET dispatch, a delivered response, and a subsequently submitted timeout proof from an earlier height.

## Recommendation
Before dispatching a GET timeout, check the source host's own `_responseReceipts[commitment]` (or equivalently pass it through `HandlerV2.handleGetRequestTimeouts`) and revert (e.g. `DuplicateMessage`/`ResponseAlreadyReceived`) if a response has already been recorded locally — mirroring the check already present in `modules/ismp/core/src/handlers/timeout.rs`. This should be enforced in `EvmHost.dispatchTimeOut(GetRequestTimeout,...)` so it cannot be bypassed even if `HandlerV2` is upgraded independently.

## Proof of Concept
1. User dispatches a `GetRequest` via `EvmHost.dispatch(DispatchGet)`, storing `_requestCommitments[commitment]`.
2. Hyperbridge processes the query; a relayer calls `HandlerV2.handleGetResponses` with a valid MMR proof at height H1 — `EvmHost.dispatchIncoming(GetResponse,...)` runs, sets `_responseReceipts[commitment]`, invokes `onGetResponse` on the app, pays the relayer fee. `_requestCommitments[commitment]` is left intact (not deleted).
3. A relayer (or attacker) obtains an older Hyperbridge state height H0 < H1 (before the response receipt was recorded on Hyperbridge) together with a non-membership proof of `RESPONSE_RECEIPTS_STORAGE_PREFIX‖commitment` at H0.
4. Relayer calls `HandlerV2.handleGetRequestTimeouts` with `message.height = H0` and this stale proof. All checks pass (`request.timeout() > state.timestamp` at H0 is satisfied if the request's timeout occurred before H0; `meta.sender != 0`; non-membership proof verifies at H0).
5. `EvmHost.dispatchTimeOut(GetRequestTimeout,...)` executes, invoking `onGetTimeout` on the same app that already processed `onGetResponse` for this commitment — with no check preventing this dual delivery.

    /**
     * @dev Dispatch an incoming GET response to source module
     * @param response - get response
     */
    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
