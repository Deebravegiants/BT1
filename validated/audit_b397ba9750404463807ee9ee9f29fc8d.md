### Title
Dogecoin address validation skips base58 checksum verification, allowing withdrawals to be authorized for unspendable/invalid addresses - ([File: packages/intents-sdk/src/lib/validateAddress.ts])

### Summary
`validateDogeAddress` only checks the address against a regex `/^[DA][1-9A-HJ-NP-Za-km-z]{25,33}$/` and never decodes the base58 payload or verifies its 4-byte double-SHA256 checksum, unlike `validateBtcBase58Address` and `validateLitecoinBase58Address` in the same file which do. `PoaBridge.validateWithdrawal` relies solely on this function to gate Dogecoin destination addresses before encoding them into the signed `ft_withdraw` memo.

### Finding Description
The broken equality: **the destination address accepted by `validateAddress(address, Chains.Dogecoin)`** != **a real, checksum-valid, spendable Dogecoin address**.

`validateDogeAddress` at [1](#0-0)  does:
```
function validateDogeAddress(address: string) {
	return /^[DA][1-9A-HJ-NP-Za-km-z]{25,33}$/.test(address);
}
```
This is purely a regex/charset/length check. Contrast with the Bitcoin/Litecoin base58 validators in the same file, which decode the base58 string and verify the checksum bytes against a fresh double-SHA256 hash: [2](#0-1)  and [3](#0-2) .

`PoaBridge.validateWithdrawal` calls `validateAddress` and throws `InvalidDestinationAddressForWithdrawalError` only if it returns `false`: [4](#0-3) . Since a checksum-corrupted (but regex-matching) Doge address returns `true`, this guard passes silently.

The accepted address is then passed unmodified into `createWithdrawIntentPrimitive` → `createWithdrawMemo`, which simply joins `"WITHDRAW_TO"` and the raw address string into the intent's `memo` field with no further validation: [5](#0-4) . This memo is embedded in the signed `ft_withdraw` intent, which the user signs and the relayer executes based on the memo content, attempting a payout to an address whose checksum doesn't validate — likely unspendable/undeliverable on the Dogecoin network, with no on-chain recovery path since the intent was signed and funds already debited from the user's intents balance.

No other guard in `validateWithdrawal` catches this: `compareAddresses` only checks equality against `tokenInfo.origin_chain_address` (self-send prevention), and `supports()` / min-amount checks are unrelated to address correctness.

### Impact Explanation
Funds are debited from the user's NEAR Intents balance via a validly signed `ft_withdraw` intent, and the relayer will attempt to deliver to a Dogecoin address that fails checksum validation — i.e., not a real, controllable destination. This matches the Critical category: "funds delivered to a wrong address/chain/contract with no recovery." This is repeatable for every Doge withdrawal call where the caller supplies a checksum-invalid but regex-matching address (attacker cost: none beyond constructing a malformed string; each call risks that specific withdrawal amount).

### Likelihood Explanation
Preconditions are minimal: PoA route, `assetId: "nep141:doge.omft.near"`, and any caller (an ordinary user or an integrator forwarding a user-supplied string) able to call `PoaBridge.validateWithdrawal`/withdrawal flow with a crafted `destinationAddress`. No privileged access or contract compromise needed — this is directly reachable through the public SDK withdrawal API with attacker-controlled `destinationAddress`. Constructing a checksum-invalid but regex-valid Doge address is trivial (flip one base58 character while preserving length/charset/prefix).

### Recommendation
Implement full base58Check decoding and double-SHA256 checksum verification in `validateDogeAddress`, mirroring `validateBtcBase58Address`/`validateLitecoinBase58Address`: decode with `base58.decode`, verify total length (25 bytes: 1 version + 20 hash160 + 4 checksum), verify the version byte matches Dogecoin's P2PKH (0x1E) / P2SH (0x16) prefixes, and verify the last 4 bytes match `sha256(sha256(payload)).subarray(0,4)`.

function validateBtcBase58Address(address: string): boolean {
	const decoded: Uint8Array = base58.decode(address);

	// version (1) + hash160 (20) + checksum (4) = 25 bytes
	if (decoded.length !== 25) return false;

	const version = decoded[0];
	// 0x00 = P2PKH mainnet, 0x05 = P2SH mainnet
	if (version !== 0x00 && version !== 0x05) return false;

	const payload = decoded.subarray(0, 21);
	const checksum = decoded.subarray(21, 25);
	const expectedChecksum = sha256(sha256(payload)).subarray(0, 4);

	for (let i = 0; i < 4; i++) {
		if (checksum[i] !== expectedChecksum[i]) return false;
	}
	return true;
}

function validateLitecoinBase58Address(
	address: string,
	expectedVersion: number,
): boolean {
	let decoded: Uint8Array;

	try {
		decoded = base58.decode(address);
	} catch {
		return false;
	}

	// version (1) + payload (20) + checksum (4)
	if (decoded.length !== 25) return false;

	const version = decoded[0];
	if (version !== expectedVersion) return false;

	const payload = decoded.subarray(0, 21); // version + hash160
	const checksum = decoded.subarray(21, 25);

	const hash1 = sha256(payload);
	const hash2 = sha256(hash1);
	const expectedChecksum = hash2.subarray(0, 4);

	for (let i = 0; i < 4; i++) {
		if (checksum[i] !== expectedChecksum[i]) return false;
	}

	return true;
}

export function createWithdrawIntentPrimitive(params: {
	assetId: string;
	destinationAddress: string;
	destinationMemo: string | undefined;
	amount: bigint;
}): Extract<IntentPrimitive, { intent: "ft_withdraw" }> {
	const { contractId: tokenAccountId } = utils.parseDefuseAssetId(
		params.assetId,
	);
	return {
		intent: "ft_withdraw",
		token: tokenAccountId,
		receiver_id: tokenAccountId,
		amount: params.amount.toString(),
		memo: createWithdrawMemo({
			receiverAddress: params.destinationAddress,
			xrpMemo: params.destinationMemo,
		}),
		min_gas: MIN_GAS_AMOUNT,
	};
}

function createWithdrawMemo({
	receiverAddress,
	xrpMemo,
}: {
	receiverAddress: string;
	xrpMemo: string | undefined;
}) {
	// Strip "bitcoincash:" prefix from BCH CashAddr addresses
	const normalizedAddress = receiverAddress
		.toLowerCase()
		.startsWith("bitcoincash:")
		? receiverAddress.slice("bitcoincash:".length)
		: receiverAddress;

	const memo = ["WITHDRAW_TO", normalizedAddress];

	if (xrpMemo != null && xrpMemo !== "") {
		memo.push(xrpMemo);
	}

	return memo.join(":");
}
