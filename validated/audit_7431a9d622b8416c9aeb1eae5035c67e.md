Audit Report

## Title
Unauthenticated exposure of LOOP plugin `pprof` debug/profiling and metrics proxy endpoints - (File: `core/web/router.go`, `core/web/loop_registry.go`)

## Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` router group, which carries only rate-limiting and session middleware — no `auth.Authenticate(...)` wrapper is applied, unlike every other sensitive route family (`debugRoutes`, `metricRoutes`) in the same file. This allows any unauthenticated network client to pull full Go `pprof` profiles (heap, goroutine, trace, CPU profile) from any registered LOOP plugin process via the node's public HTTP API.

## Finding Description
`NewRouter` builds the `api` group with only rate limiting and session middleware, then calls `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` on it. `debugRoutes` explicitly gates `/debug/vars` behind `auth.Authenticate(...)`, and `metricRoutes` (which exposes the same standard-library `pprof` handlers) is only ever mounted inside the authenticated `authv2` group. In contrast, `loopRoutes` registers `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler` with zero authentication middleware. These handlers proxy the request to an internal plugin process's pprof/metrics HTTP server, selecting the target purely from the unauthenticated `:name` path parameter, with no session/token check performed anywhere in the call chain.

## Impact Explanation
An unauthenticated client that can reach the node's web server can retrieve full heap/goroutine dumps and CPU profiles/traces from any registered LOOP plugin (e.g., `median`, `solana`, `starknet`) by hitting `GET /plugins/<name>/debug/pprof/heap` or similar. Such dumps can expose sensitive in-process data handled by the plugin, and repeated profile/trace requests (with attacker-controlled `seconds`/`debug` parameters) can degrade plugin availability. This is an internal debug/introspection surface reachable without credentials, which is a legitimate authentication-bypass/information-disclosure class finding.

## Likelihood Explanation
Any client able to reach the node's HTTP listener can issue these requests without credentials since the routes sit outside all authenticated route groups; plugin names are a small, discoverable/guessable set. The request is trivially repeatable.

## Recommendation
Wrap the pprof-proxying routes (`/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) in the same `auth.Authenticate(...)` middleware used by `debugRoutes`/`metricRoutes`, reserving unauthenticated access only for `/discovery` and `/plugins/:name/metrics`, which are intended for Prometheus scraping.

## Proof of Concept
1. Start a chainlink node with a LOOP plugin registered (e.g., `median`).
2. As an unauthenticated client, issue: `curl http://<node-host>:6688/plugins/median/debug/pprof/heap?debug=1`.
3. Observe the full heap profile returned without any authentication, per the route registration in `loopRoutes` (`core/web/router.go:230-236`) and the forwarding logic in `pluginPPROFHandler` (`core/web/loop_registry.go:150-166`).

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
