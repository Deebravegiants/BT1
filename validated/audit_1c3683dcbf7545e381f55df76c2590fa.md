### Title
Fee-less `handle_unsigned` batches let an unprivileged relayer force every full node to repeat full ISMP message verification for free, with no cap on aggregate batch size - (File: modules/pallets/ismp/src/lib.rs, modules/pallets/ismp/src/impls.rs)

### Summary
`pallet_ismp::Call::handle_unsigned` is a permissionless, unsigned (fee-less) extrinsic that accepts `messages: Vec<Message>`, where each `Message` (`RequestMessage`, `ResponseMessage`, `TimeoutMessage`, etc.) itself carries a `Vec<PostRequest>` / `Vec<GetRequest>` (and `GetRequest` further nests a `Vec<Vec<u8>>` of storage keys). There is no visible aggregate cap on the number of messages, the number of requests per message, or the number of keys per request before the pallet performs full membership/non-membership proof verification and state-machine commitment lookups. Because this call is unsigned, `ValidateUnsigned::validate_unsigned` runs `Self::execute(messages.clone())` — i.e. the *entire* proof-verification and dispatch pipeline — on every node that receives the transaction via gossip, not just once at inclusion. This mirrors the OpenTelemetry `baggage` bug class: per-item limits exist deep inside individual verification steps, but nothing bounds the aggregate amount of parsing/verification work a single submitted "request" (extrinsic) can trigger, so a fee-less submission can be repeated cheaply to amplify CPU/allocation cost network-wide.

### Finding Description
`handle_unsigned` is declared as an unsigned extrinsic: [1](#0-0) 

Its `ValidateUnsigned::validate_unsigned` implementation does not merely check signatures/replay — it calls `Self::execute(messages.clone())`, fully running proof verification and dispatch, on *every node validating the transaction in the pool* (i.e., on gossip propagation across the network, before the transaction is even included in a block): [2](#0-1) 

`Self::execute` maps over the full `Vec<Message>` and, for each message, calls `handle_incoming_message`, which for `RequestMessage`/`ResponseMessage` runs full merkle/state proof verification across every request/key contained in that message: [3](#0-2) 

The message types themselves are unbounded collections — `RequestMessage.requests: Vec<PostRequest>`, `ResponseMessage.requests: Vec<GetRequest>` — with each `GetRequest` additionally carrying an unbounded `keys: Vec<Vec<u8>>` (as seen used in `handle_get_requests`'s `verify_state_proof(&host, req.keys.clone(), ...)`): [4](#0-3) [5](#0-4) 

No aggregate size/count gate on `messages.len()`, `requests.len()`, or `keys.len()` is applied before this verification work executes — only per-request semantic checks (timeout, duplicate, destination) run inline with the O(n) loop, exactly like the CVE's per-value 8192-byte cap that does nothing to bound the number of values. Because the outer call is unsigned/fee-less, an attacker pays nothing to have every full node on the network repeat this full verification pass (in `validate_unsigned`) for each submitted extrinsic, and can submit many such extrinsics or large single ones with many nested requests/keys.

### Impact Explanation
This allows an unprivileged relayer/attacker to cheaply (for free, since the extrinsic is unsigned) force disproportionate CPU and memory allocation on every Hyperbridge/parachain full node reachable by gossip, by submitting `handle_unsigned` calls with large `Vec<Message>` / nested `Vec<PostRequest>`/`Vec<GetRequest>`/`Vec<Vec<u8>>` payloads. Sustained abuse degrades transaction-pool validation and block-production capacity network-wide, which can delay or prevent legitimate relayers from getting their messages included — i.e., a route becomes unable to reliably deliver messages, satisfying the "no-cost remote DoS amplification" bug class from the report, scoped to a High-severity availability impact on message delivery.

### Likelihood Explanation
The call is explicitly permissionless and unsigned/free by design (`ensure_none(origin)` and free-tx `ValidateUnsigned`), documented as "allows users execute ISMP datagrams for free. Use with caution." — meaning any network participant, including a bandwidth purchaser/relayer/intent solver with no special privileges, can submit crafted batches at essentially zero cost: [6](#0-5) 
Combined with `validate_unsigned` re-running full verification on every node during gossip (not amortized to a single execution), this makes exploitation both cheap and network-amplifying, closely matching the reachability and remote-triggerability of the original advisory.

### Recommendation
Introduce and enforce hard aggregate limits before any proof verification work begins in `handle_unsigned`/`validate_unsigned`: cap `messages.len()`, the total number of requests/responses across all messages in the batch, and the total number of keys across all `GetRequest`s, similar to how `MaxCallSize`/`MAX_EXTRINSIC_DECODE_DEPTH_LIMIT` bound the call-decompressor pallet. Reject batches exceeding these bounds in `validate_unsigned` prior to calling `execute`, so the per-node verification cost incurred during gossip validation stays proportional to a bounded budget rather than to attacker-chosen batch size.

### Proof of Concept
Construct a `pallet_ismp::Call::handle_unsigned` extrinsic whose `messages: Vec<Message>` contains a single `Message::Response(ResponseMessage)` with a very large `requests: Vec<GetRequest>`, each `GetRequest` carrying hundreds of storage `keys` (as already exercised structurally, without a size cap, in the pallet's own test fixtures which build 100 `GetRequest`s each with 256 keys): [7](#0-6) 
Submit this as an unsigned extrinsic to the network. `validate_unsigned` on every receiving node will invoke `Self::execute`, which iterates and attempts full membership-proof verification across the entire nested structure at zero fee cost to the sender, before any inclusion/rejection decision — this can be repeated indefinitely and cheaply by any actor, amplifying network-wide validation cost disproportionate to the (zero) cost paid.

	pub fn execute(messages: Vec<Message>) -> Result<Vec<events::Event>, Error<T>> {
		let host = Pallet::<T>::default();

		let message_results = messages
			.iter()
			.map(|msg| handle_incoming_message(&host, msg.clone()))
			.collect::<Result<Vec<_>, _>>()
			.map_err(|err| {
				log::debug!(target: "ismp", "Handling Error {:#?}", err);
				Pallet::<T>::deposit_event(Event::<T>::Errors { errors: vec![err.into()] });
				Error::<T>::InvalidMessage
			})?;

		let messages_with_weights = message_results
			.iter()
			.zip(messages)
			.map(|(result, message)| MessageWithWeight { message, weight: result.weight() })
			.collect::<Vec<_>>();

	pub fn handle_get_requests(
		GetRequestsWithProof { requests, source, response, address }: GetRequestsWithProof,
	) -> Result<(), Error> {
		// 1. Verify source proofs
		// 2. Extract fees
		// 3. Verify response proof
		// 4. insert GetResponse into mmr and request receipts
		// 5. emit Response events
		let host = <<T as Config>::IsmpHost>::default();

		// Reject duplicate requests within the batch.
		let wrapped: Vec<Request> = requests.iter().cloned().map(Request::Get).collect();
		dedup_requests::<<T as Config>::IsmpHost>(&wrapped)?;

		for req in requests.iter() {
			let full = Request::Get(req.clone());

			// Get requests time out are relative to Hyperbridge
			if full.timed_out(host.timestamp()) {
				Err(Error::RequestTimeout { meta: full.clone().into() })?
			}

			// Source of the request must match the proof
			if full.source_chain() != source.height.id.state_id {
				Err(Error::RequestProofMetadataNotValid { meta: full.clone().into() })?
			}

			// Proof must come from the requested chain
			if full.dest_chain() != response.height.id.state_id {
				Err(Error::RequestProofMetadataNotValid { meta: full.clone().into() })?
			}

			// This request has already been responded to. Mirror `handlers/response.rs:61`:
			// dedup against `response_receipt`, which the dispatch path writes for this exact
			// GetRequest hash after producing a response. The receipt also binds the response
			// commitment, so external auditors can attest "Hyperbridge produced response X for
			// request Y" from one map.
			let probe = GetResponse { get: req.clone(), values: Default::default() };
			if host.response_receipt(&probe).is_some() {
				Err(Error::DuplicateResponse { meta: (&probe).into() })?
			}
		}

		// Ensure the proof height is equal to each retrieval height specified in the Get
		// requests
		if !requests.iter().all(|get| get.height == response.height.height) {
			Err(Error::InsufficientProofHeight)?
		}

		// Verify source proof
		let source_state_machine = validate_state_machine(&host, source.height)?;
		let state_root = host.state_machine_commitment(source.height)?;

		// Verify membership proof to ensure that requests where committed on source chain
		let commitments = requests
			.iter()
			.map(|get| hash_request::<<T as Config>::IsmpHost>(&Request::Get(get.clone())))
			.collect();
		source_state_machine.verify_membership(&host, commitments, state_root, &source)?;
