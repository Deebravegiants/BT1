Audit Report

## Title
Cross-user response confusion via sender-unscoped `savedCallbacks` map keyed only by client-supplied `MessageID` - (File: core/services/gateway/handlers/capabilities/handler.go)

## Summary
`handler.HandleLegacyUserMessage` stores per-request callbacks in `h.savedCallbacks` keyed solely by `msg.Body.MessageID`, a value fully controlled by the requester and never bound to the requester's sender address. When a DON node later responds, `handleWebAPITriggerMessage` resolves delivery purely via lookup on `msg.Body.MessageID`, so if two different authenticated callers submit colliding `MessageID`s while both requests are in flight, the second caller's callback overwrites the first's, causing the first (or second) caller's response to be misdelivered to the wrong caller.

## Finding Description
`MessageBody.MessageID` is client-chosen (an arbitrary string up to 128 bytes) and is part of the signed message body, but the signature only proves the sender signed that specific ID — it does not prevent a different sender from independently choosing the same ID string [7](#0-6) . The gateway routes legacy requests to `HandleLegacyUserMessage(ctx, msg, callback)` without any additional per-user isolation of the ID space [1](#0-0) . Inside the handler, the callback is registered in a global map keyed only by `msg.Body.MessageID`: [2](#0-1) 

When a node's response arrives, delivery is resolved by the same unscoped key, with the entry deleted and returned regardless of which sender originated the current entry: [4](#0-3) 

This is unlike `common.RequestCache`, which explicitly keys on `globalID{sender, id}` to avoid exactly this collision [6](#0-5) . `HandleLegacyUserMessage` has an explicit `// TODO: apply allowlist and rate-limiting here` comment and performs no sender-based namespacing, deduplication, or collision detection of `MessageID` before insertion [8](#0-7) . No existing auth/validation layer (message `Validate()`, timestamp staleness check, method check) prevents two distinct signers from choosing the same `MessageID` string.

## Impact Explanation
An authenticated but unprivileged client can cause a webAPI trigger response intended for a different, concurrently-requesting user to be delivered to itself (or vice versa), an information-disclosure / cross-user response-confusion issue. This is an in-scope "cross-user response corruption" class impact, since it can expose HTTP action output or workflow trigger response data to a party not authorized to see it.

## Likelihood Explanation
Exploitation only requires the attacker to be able to sign and send a legacy `web_api_trigger` request to the gateway's user port with a `MessageID` matching an in-flight victim request. `MessageID` is entirely attacker-chosen and unconstrained beyond length/format, so an attacker who can predict or brute-force/guess a victim's `MessageID` (or coordinate timing to win a race with a chosen, colliding ID) within the `CallbackMaxAgeSec` window (default 120s, `pruneCallbacks`) can trigger the misdelivery deterministically. This is a realistic race/ID-collision bug in a legacy but still-reachable code path, not requiring operator/admin privileges, malicious DON nodes, or host access.

## Recommendation
Key `savedCallbacks` (and any analogous callback maps in the confidentialrelay/dummy handlers) by `(sender, MessageID)` rather than `MessageID` alone, mirroring the `globalID{sender, id}` pattern in `common.RequestCache`. Additionally, when a node's response is received, verify that the response corresponds to the same requester (sender) that registered the callback before delivering it, rejecting on mismatch.

## Proof of Concept
1. As user A, sign and submit a legacy `web_api_trigger` request to the gateway with `MessageID = "X"`; this registers `savedCallbacks["X"] = callbackA` via `HandleLegacyUserMessage`.
2. Before the DON responds, as user B, sign and submit a colliding legacy `web_api_trigger` request with the same `MessageID = "X"`; this overwrites `savedCallbacks["X"] = callbackB`.
3. When the DON node returns its response correlated with the original `MessageID = "X"` (destined for A), `handleWebAPITriggerMessage` looks up `savedCallbacks["X"]`, finds `callbackB`, and delivers A's response payload to B's HTTP connection.
4. A Go unit/integration test constructing two `handlers.Callback` instances and calling `HandleLegacyUserMessage` twice with identical `MessageID`s from different signers, followed by a single `HandleNodeMessage` invocation for method `web_api_trigger`, demonstrates the second callback receiving the response instead of the first.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageID] = &savedCallback{id: msg.Body.MessageID, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}
