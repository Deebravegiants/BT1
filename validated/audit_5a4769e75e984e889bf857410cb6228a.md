### Title
Debt-value overflow during interest accrual permanently freezes a market - ([File: common/src/rates/scaling.rs])

### Summary
A sufficiently large market can reach an `i128` value overflow before the configured borrow-index ceiling. Because every state-changing market operation synchronizes interest before execution, the overflow prevents withdrawals, repayments, liquidations, and subsequent index updates for that market. The repository’s own long-horizon test demonstrates this permanent market freeze using reachable `supply`, `borrow`, and `update_indexes` calls. [1](#0-0) 

### Finding Description
`global_sync` accrues every elapsed interval before the requested pool operation proceeds. Each chunk calls `accrue_step` with the market’s aggregate scaled debt, supply, and indexes, then writes the resulting indexes. [2](#0-1) 

At large values, converting scaled debt back to its underlying RAY value can exceed `i128::MAX` and raise `MathOverflow`. The documented invariant bounds the borrow index at `10^36` raw RAY, but explicitly notes that debt-value overflow can revert accrual before that ceiling is reached. [3](#0-2) 

The harness constructs a valid market containing one billion 18-decimal supplied units, a borrower with sufficient separate collateral, and 98% utilization. Repeated permissionless `update_indexes` calls eventually fail with `MathOverflow`; afterward, both `withdraw` and `repay` fail with the same error because they must accrue first. [4](#0-3) 

### Impact Explanation
The market becomes permanently unable to process risk-reducing and exit operations. Suppliers cannot withdraw, borrowers cannot repay, liquidators cannot resolve the debt through normal market paths, and `update_indexes` remains a reverting entry point. This is a permanent freezing of user funds for the affected market, not merely a failed attacker transaction. [5](#0-4) 

### Likelihood Explanation
The condition requires extreme aggregate debt and sustained high utilization for enough accrual time to push the debt value beyond the representable range. An unprivileged actor can create the required positions through `supply` and `borrow` when configured caps and collateral permit it, then trigger the failure through the public `update_indexes` entry point. The economic requirement is substantial, but the resulting failure is deterministic once the market reaches the unsafe state. [6](#0-5) [7](#0-6) 

### Recommendation
Compute debt growth using saturating, widening, or short-circuiting arithmetic that enforces `MAX_BORROW_INDEX_RAY` before scaled-value multiplication can overflow. Add a regression test asserting that accrual reaches the index cap without reverting and that repayment, withdrawal, and liquidation remain callable at the cap. [8](#0-7) 

### Proof of Concept
1. Create an 18-decimal market using the steep XLM-style rate curve and disable the maximum-utilization guard.
2. Supply `1_000_000_000 * 10^18` units of the borrowable asset.
3. Supply sufficient separate collateral and borrow 98% of the supplied market.
4. Advance time and repeatedly call `update_indexes` on the borrowable market.
5. The call eventually returns `MathOverflow` while the stored borrow index remains below `MAX_BORROW_INDEX_RAY`.
6. Subsequent `withdraw` and `repay` calls also return `MathOverflow`, demonstrating that the market is frozen.

This sequence is implemented by `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap`. [4](#0-3)

```rust
/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
```

```rust
pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}

/// Applies one compound step of `delta_ms` to indexes and protocol revenue.
///
/// The arithmetic lives in [`accrue_step`], shared with the read-only
/// `simulate_update_indexes` so the view and the mutator cannot drift.
fn accrue_chunk(env: &Env, cache: &mut Cache, delta_ms: u64) {
    let step = accrue_step(
        env,
        cache.params(),
        cache.borrowed(),
        cache.supplied(),
        cache.borrow_index(),
        cache.supply_index(),
        delta_ms,
    );

    cache.set_borrow_index(step.borrow_index);
    cache.set_supply_index(step.supply_index);
    cache.accrue_revenue(step.revenue_shares);
```

```markdown
Both indexes start at one RAY. Successful accrual with validated rate parameters
```
