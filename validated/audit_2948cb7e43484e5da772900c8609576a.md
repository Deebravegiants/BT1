## Analog Vulnerability Found

### Title
Unauthenticated exposure of LOOP plugin debug/profiling and metrics proxy endpoints - (File: `core/web/router.go`, `core/web/loop_registry.go`)

### Summary
The Chainlink node's HTTP API mounts `loopRoutes` on the same top-level router group as the authenticated `/v2` API, but — unlike every other debug-capable route in the file — never wraps it with the `auth.Authenticate` middleware. This leaves `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` reachable by any unauthenticated client that can reach the node's web server, analogous to an unsecured Spring Boot Actuator endpoint exposing internal diagnostics/administration surface to the network.

### Finding Description
`NewRouter` builds the top level `api` group with only rate-limiting and session middleware, then calls each route-registration function in turn: [1](#0-0) 

Compare `debugRoutes`, which explicitly creates a sub-group protected by `auth.Authenticate(...)` before exposing `expvar`: [2](#0-1) 

`loopRoutes`, however, registers its handlers directly on the passed-in (unauthenticated) group with no equivalent wrapping: [3](#0-2) 

The handlers themselves proxy requests to internal per-plugin Prometheus/pprof HTTP servers based on a client-supplied `name` path parameter: [4](#0-3) [5](#0-4) 

`metricRoutes`, which registers Go's `net/http/pprof` handlers (`/debug/pprof/profile`, `/heap`, `/trace`, etc.) directly on the node process, is only reached through the authenticated `authv2` group inside `v2Routes`: [6](#0-5) 
but the *LOOP-plugin-proxied* variants of the same pprof surface, served via `loopRoutes`, bypass that authentication entirely.

### Impact Explanation
An unauthenticated network client that can reach the node's web server can:
- Enumerate all registered LOOP plugins and their internal Prometheus scrape targets via `/discovery`.
- Pull raw Prometheus metrics for any plugin via `/plugins/:name/metrics`, which may include internal operational/labels data.
- Trigger CPU/heap/goroutine profiling and long-running `pprof` operations (`seconds` query param controls duration) against internal plugin processes via `/plugins/:name/debug/pprof/*profile`, which can be used for denial-of-service (holding CPU profiles open) or to exfiltrate sensitive in-memory data (goroutine stacks, heap contents) from LOOP plugin processes — the same class of impact the Spring Cloud Gateway Actuator CVE describes (an unauthenticated actuator/diagnostic surface leaking internal state and enabling attacker-controlled operations).
- The proxy forwards to `http://<loopHostName>:<PrometheusPort>/...` constructed from registry data, so the acceptable target set is limited to registered plugins, but the request path/query values (`profile`, `debug`, `gc`, `seconds`) are attacker-controlled and forwarded unauthenticated.

This does not achieve remote code execution like the Spring Cloud Gateway CVE, but it is a legitimate node-API authentication bypass exposing internal diagnostic/administrative functionality without any session or token check, unlike every comparable route in the same file.

### Likelihood Explanation
High for any deployment where the node's web server port is reachable by the attacker (the same precondition the original advisory requires — "exposed and unsecured"). No credentials, tokens, or special network position are needed; a plain HTTP GET/POST to the documented paths is sufficient, and the routes are registered unconditionally whenever LOOP plugins are configured.

### Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware (and an appropriate role check, e.g. `RequiresAdminRole`) used elsewhere in `core/web/router.go`, consistent with `debugRoutes` and the authenticated `metricRoutes` usage inside `v2Routes`.

### Proof of Concept
Against a running node with LOOP plugins configured, without any session cookie or API token:
```
GET /discovery HTTP/1.1
Host: <node>

GET /plugins/<plugin-name>/metrics HTTP/1.1
Host: <node>

GET /plugins/<plugin-name>/debug/pprof/heap?seconds=30 HTTP/1.1
Host: <node>
```
All three requests succeed and return internal plugin data / profiling output without authentication, whereas the functionally equivalent `/v2/debug/pprof/...` and `/debug/vars` routes correctly require an authenticated session/token.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
