### Title
Consensus-reward backlog is paid in full to whichever relayer resubmits first after `StateMachinesCostPerBlock` is re-enabled - (File: `modules/pallets/consensus-incentives/src/impls.rs`)

### Summary
`pallet-consensus-incentives::calculate_reward` computes a relayer's consensus reward as `(latest_height - baseline) * cost_per_block`, where `baseline` falls back to a stale `LastRewardedHeight` watermark whenever it exists, with no attempt to bound the reward to the work actually performed by the caller. When rewards for a state machine are disabled (`remove_incentives`) and later re-enabled (`update_cost_per_block`), any number of blocks/heights that advanced during the disabled window are never subtracted from the watermark, so the very next relayer to submit a consensus message after re-enabling collects the entire backlog reward in one transfer — including for blocks relayed for free by other parties while incentives were off. This is the same root cause class as the referenced xETH finding: a time/height-delta based accrual whose "last checkpoint" state is not updated when the accrual mechanism transitions from disabled/empty to enabled/active, letting a single caller sweep the entire accumulated pool.

### Finding Description
`calculate_reward` in [1](#0-0)  reads:
```
let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);
let blocks = latest_height.saturating_sub(baseline);
let reward = blocks_as_balance.saturating_mul(block_cost);
```
`LastRewardedHeight` is only ever advanced inside `process_message`, and only when `StateMachinesCostPerBlock` is `Some` for that state machine, as shown in [2](#0-1) . `remove_incentives` clears `StateMachinesCostPerBlock` but never touches `LastRewardedHeight`, and `update_cost_per_block` never resets it either, per [3](#0-2) .

Consequently, while `StateMachinesCostPerBlock` is unset for a state machine, `on_executed` (invoked automatically for every dispatched `ConsensusMessage`, per the `FeeHandler` hook in [4](#0-3) ) still lets consensus updates and `StateMachineUpdated` events flow through the chain via `handle_unsigned`/`IsmpHost`, advancing `latest_commitment_height`, but `LastRewardedHeight` is frozen at whatever it was before disabling — because `process_message` early-returns without touching it (the `if let Some(block_cost) = ...` guard at line 46). When an operator later calls `update_cost_per_block` to re-enable rewards, the very next relayer to submit any consensus message for that state machine triggers `calculate_reward` with `baseline` still pointing at the pre-disable watermark, so `blocks = latest_height - baseline` spans the entire disabled window. That single relayer receives the full backlog reward (`blocks * cost_per_block`) from the treasury and mints the matching reputation asset, even though the intervening height advances were relayed by other parties (for free) while the feature was off.

### Impact Explanation
This is a reachable, unprivileged-relayer path: any account can dispatch a `ConsensusMessage` via `pallet_ismp::Pallet::handle_unsigned` (see the existing test flow in [5](#0-4) ). The impact is a disproportionate, one-shot drain of the `TreasuryAccount` (and matching reputation-asset over-mint) to whichever relayer happens to be first past the post after a re-enable, rather than to the relayers who actually performed the consensus-relaying work — a concrete misallocation/theft of protocol treasury funds, structurally identical to the "first staker claims the whole drip" pattern in the referenced report.

### Likelihood Explanation
Disabling and re-enabling `StateMachinesCostPerBlock` for a given state machine (e.g. during incident response, cost re-pricing, or temporary suspension) is an intended, documented admin operation (`remove_incentives` / `update_cost_per_block`, see [6](#0-5) ). The consensus relay traffic for a state machine does not stop just because incentives are off, so a backlog will typically accumulate over any nontrivial disabled window, and any relayer racing to submit first after re-enable can capture it — this only requires normal, permissionless message submission, with no attacker preconditions beyond timing.

### Recommendation
When rewards are disabled (`remove_incentives`) or the state-machine is newly onboarded, snapshot/reset `LastRewardedHeight` to the current `latest_commitment_height` (mirroring the report's suggested fix of updating `lastReport` on the 0→nonzero transition), so that re-enabling rewards starts the reward clock from "now" instead of silently paying out the entire disabled-window backlog to one caller. Alternatively, explicitly zero out or delete `LastRewardedHeight` on `remove_incentives` and re-baseline it to `previous_height`/`latest_height` at the point `update_cost_per_block` is called.

### Proof of Concept
1. Admin calls `update_cost_per_block(sm, cost)`; relayer A submits a consensus message advancing `latest_commitment_height` to `H1`; `LastRewardedHeight[sm] = H1` (per [7](#0-6) ).
2. Admin calls `remove_incentives(sm)`. `StateMachinesCostPerBlock[sm]` is removed; `LastRewardedHeight[sm]` remains `H1`.
3. Over the next `N` blocks, relayers B, C, D... submit consensus messages that advance `latest_commitment_height` to `H1+N`; `process_message` early-returns each time (no `block_cost`), so no rewards are paid and `LastRewardedHeight` stays at `H1`.
4. Admin calls `update_cost_per_block(sm, cost)` again to resume incentives.
5. Relayer E (who did none of the work in step 3) submits the next consensus message. `calculate_reward` computes `baseline = LastRewardedHeight = H1`, `blocks = (H1+N) - H1 = N`, and pays E `N * cost` from the treasury plus `N * cost` reputation tokens — the entire backlog that should have been split among B, C, D.

	/// Calculate the reward for a message based on the state machine id
	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)
	}

	fn on_executed(
		messages: Vec<MessageWithWeight>,
		events: Vec<IsmpEvent>,
	) -> DispatchResultWithPostInfo {
		let maybe_relayer_account = messages.get(0).and_then(|first_message| {
			if let Message::Consensus(consensus_msg) = &first_message.message {
				let data = sp_io::hashing::keccak_256(&consensus_msg.consensus_proof);
				Signature::decode(&mut &consensus_msg.signer[..])
					.ok()
					.and_then(|sig| sig.verify_and_get_sr25519_pubkey(&data, None).ok())
					.map(|pub_key| pub_key.into())
			} else {
				None::<[u8; 32]>
			}
		});

		if let Some(relayer_account) = maybe_relayer_account {
			// When a batch contains multiple `StateMachineUpdated` events for the
			// same `state_machine_id` (sequential consensus updates for the same
			// chain), `calculate_reward` reads the same persisted
			// `(latest_commitment_height, previous_commitment_height)` pair on
			// every iteration and pays the same block-span reward N times.
			// Collapse the per-state-machine event stream to the single highest
			// `latest_height` so each state machine receives one reward per
			// batch, sized by the actual span of its commitment advance.
			let mut highest_per_state_machine: BTreeMap<StateMachineId, u64> = BTreeMap::new();
			for event in events {
				if let IsmpEvent::StateMachineUpdated(update) = event {
					highest_per_state_machine
						.entry(update.state_machine_id)
						.and_modify(|h| {
							if update.latest_height > *h {
								*h = update.latest_height;
							}
						})
						.or_insert(update.latest_height);
				}
			}

			for (state_machine_id, latest_height) in highest_per_state_machine {
				let state_machine_height =
					StateMachineHeight { id: state_machine_id.clone(), height: latest_height };

				let _ = Self::process_message(
					state_machine_height,
					state_machine_id,
					relayer_account.clone().into(),
				);
			}
		}

		// Return with actual weight information
		// We use Pays::No to indicate that someone (the message sender) doesn't pay for this
		// operation, though we're using this mechanism to reward relayers rather than charge fees
		Ok(PostDispatchInfo { actual_weight: None, pays_fee: Pays::No })
	}

	#[pallet::call]
	impl<T: Config> Pallet<T> {
		/// Update cost per block for a state machine
		#[pallet::call_index(0)]
		#[pallet::weight(T::WeightInfo::update_cost_per_block())]
		pub fn update_cost_per_block(
			origin: OriginFor<T>,
			state_machine_id: StateMachineId,
			cost_per_block: <T as pallet_ismp::Config>::Balance,
		) -> DispatchResult {
			T::IncentivesOrigin::ensure_origin(origin)?;

			StateMachinesCostPerBlock::<T>::mutate(state_machine_id.clone(), |maybe_cost| {
				*maybe_cost = Some(cost_per_block);
			});

			Self::deposit_event(Event::<T>::StateMachineCostPerBlockUpdated {
				state_machine_id,
				cost_per_block,
			});

			Ok(())
		}

		/// Update cost per block for a state machine
		#[pallet::call_index(1)]
		#[pallet::weight(T::WeightInfo::update_cost_per_block())]
		pub fn remove_incentives(
			origin: OriginFor<T>,
			state_machine_id: StateMachineId,
		) -> DispatchResult {
			T::IncentivesOrigin::ensure_origin(origin)?;

			StateMachinesCostPerBlock::<T>::remove(state_machine_id.clone());

			Self::deposit_event(Event::<T>::StateMachineCostPerBlockRemoved { state_machine_id });

			Ok(())
		}
	}
