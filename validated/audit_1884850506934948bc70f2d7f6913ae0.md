### Title
Sub-3-decimal collateral seizure values whole units in base units × whole-token price, suppressing `unseized_usd` and leaving repayment unbacked - (File: contracts/controller/src/positions/liquidation/math.rs)

### Summary
`calculate_seized_collateral` floors partial seizures on assets below `MIN_BORROWABLE_ASSET_DECIMALS` to whole units, then re-values the floored seizure with `seizure_ray.to_wad(env).mul(env, feed.price)`. That expression multiplies WAD-scaled **base units** by a USD price quoted **per whole token**, inflating `whole_usd` by `10^asset_decimals`. The dropped-fraction shortfall (`unseized_usd`) is therefore never booked, so `release_unbacked_repayment` keeps repayment that the seizure no longer backs — a unit-confusion write past the intended bound, directly analogous to a byte offset applied to a `__le32` pointer.

### Finding Description
For a partial (non-`seize_all`, non-`repays_all_debt`) seizure leg on an asset with `asset_decimals < MIN_BORROWABLE_ASSET_DECIMALS`, the code snaps the seizure down to whole units:

- `seizure_ray` is a RAY-scaled **base-unit** quantity (`whole × 10^(27-d)`, built via `Ray::from_asset`).
- `seizure_ray.to_wad(env)` yields `whole × 10^(18-d)` — WAD *base units*.
- `feed.price` is WAD USD per *whole token* (math.md: "price_wad is USD per whole token"; correct usage elsewhere is `Wad::from_token(amount, decimals).mul(price)`, e.g., `usd_value_wad` at line 149 and `one_unit_per_leg_usd` at lines 331–338).
- So `whole_usd = whole × 10^(18-d) × price_wad` is `10^d` times the true USD value.

The check `if seizure_for_asset_usd > whole_usd` compares a true WAD USD quote against this inflated number; for `d ∈ {1,2}` it is essentially never true, so `unseized_usd` is not accumulated. The function's own contract — documented at lines 361–362 — is to return "the repayment USD that the dropped fractions no longer back", which `plan.rs` passes to `release_unbacked_repayment` to trim the liquidator's kept repayment.

Two consequences:
1. When `whole > 0` but the fraction is dropped, the leg still under-seizes relative to the kept repayment, yet no repayment is released.
2. When `whole == 0` (seizure below one unit, e.g., a 0.9-unit seizure on a 2-decimal asset), `seizure_ray` becomes zero and the leg `continue`s — no collateral is seized at all, while the unbacked repayment is still kept because `unseized_usd` was never credited.

### Impact Explanation
A permissionless `liquidate` caller supplies debt-token payments and receives seized collateral. Because the shortfall is never returned, the kept repayment stays sized to the pre-floor USD quote while the seizure delivers only the floored whole-unit amount — or nothing, when the leg is skipped. The liquidator's tokens are burned against the borrower's debt without the pro-rata collateral the quote promised: direct, deterministic loss of the liquidator's repayment funds (or, equivalently, an unbacked windfall to the liquidated account at the liquidator's expense). Magnitude scales with the dropped fraction and leg size.

### Likelihood Explanation
Requires only a liquidatable account whose collateral asset has `asset_decimals < MIN_BORROWABLE_ASSET_DECIMALS` (0–2 decimals) and a partial quote landing on a fractional unit — realistic for low-decimal hub assets and common for small accounts. The liquidator invokes the public `liquidate` entrypoint with a payment sized near the quote; no privileged role, oracle manipulation, or reentrancy is needed.

### Recommendation
Compute `whole_usd` from whole-token units, matching every other site: `Wad::from_token(env, whole, feed.asset_decimals).mul(env, feed.price)` (or equivalently `Ray::from_asset(...).div by 10^(27-d)` rescaled to WAD of whole tokens). Then `seizure_for_asset_usd > whole_usd` correctly credits `unseized_usd` with the dropped fraction, including the `whole == 0` skip case.

### Proof of Concept
1. Hub lists collateral asset with `asset_decimals = 2`. Borrower holds supply in that asset and a small debt; price/HF make the account liquidatable.
2. Liquidator submits a `liquidate` payment whose quote maps to, e.g., 0.9 whole units of the collateral (below one unit) on a non-`seize_all`, non-`repays_all_debt` partial plan.
3. `calculate_seized_collateral`: `whole = floor(0.9) = 0` → `seizure_ray = 0` → leg `continue`s; `unseized_usd += 0` because `whole_usd` was inflated by `10^2` (and even a true-zero leg would have skipped the comparison path correctly only if computed in whole tokens).
4. Returned unseized ≈ 0 → `release_unbacked_repayment` is a no-op → `repay_usd` keeps backing that no seizure delivered.
5. Liquidator's tokens repay debt; no collateral is seized for that leg. Repeat for `whole > 0` fractional cases to extract the dropped fraction per liquidation.

Uncertain: the exact wiring of the returned `unseized_usd` into `release_unbacked_repayment` inside `plan.rs` was confirmed only by the function's documented contract and grep hits, not by reading the call site in full; the accounting consequence follows directly from that contract.
