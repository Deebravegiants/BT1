## Title
Stale `TombStone` allows a previous owner to reclaim an object a later legitimate owner intentionally sent to `BURN_ADDRESS` - (File: `aptos-move/framework/aptos-framework/sources/object.move`)

### Summary
`object::burn` implements a "soft burn": it does **not** move ownership, it only attaches a `TombStone{original_owner}` marker to the object [1](#0-0) . Ordinary (ungated) transfers via `object::transfer`/`transfer_raw` never inspect or clear this `TombStone` [2](#0-1) , while only the ref-based `transfer_with_ref` path explicitly clears it [3](#0-2) . Because of this asymmetry, a stale `TombStone` recorded by an old owner can survive an ordinary transfer to a new owner, and later be used to hijack the object away from the new owner when that new owner sends it to the framework's well-known `BURN_ADDRESS`.

### Finding Description
1. Owner A calls `object::burn(A, object)`. This only requires `is_owner(object, A)` and attaches `TombStone{original_owner: A}`; ownership stays with A (no address change) [4](#0-3) .
2. A transfers the (still tombstoned) object to B via the normal, ungated `object::transfer`/`transfer_raw`/`transfer_call` entry points. `transfer_raw_inner` only updates `ObjectCore.owner` and emits an event — it never touches `TombStone` [5](#0-4) . Only `transfer_with_ref` (LinearTransferRef path) removes a `TombStone` during transfer [6](#0-5) . After this step, `ObjectCore.owner == B` while `TombStone{original_owner: A}` is still present.
3. B, the legitimate new owner, later decides to permanently discard the object by sending it to the framework's `BURN_ADDRESS` constant using an ordinary `object::transfer(B, object, BURN_ADDRESS)` call — a natural convention since `BURN_ADDRESS` is a public constant meant for "unwanted objects" [7](#0-6) . `transfer_raw_inner` sets `owner = BURN_ADDRESS`, again leaving the old `TombStone{original_owner: A}` untouched.
4. A now calls `object::unburn(A, object)`. Because `ObjectCore.owner == BURN_ADDRESS`, the "old functionality" branch executes: it extracts the stale `TombStone`, checks `original_owner_addr (A) == signer::address_of(caller) (A)` — which passes — and calls `transfer_raw_inner(object_addr, A)`, handing the object back to A [8](#0-7) .

The root cause is that `TombStone` state is not invalidated on ordinary ownership transfer, only on `TransferRef`-based transfer. `unburn`'s reclaim branch trusts `TombStone.original_owner` as an authority proof without verifying it corresponds to the owner who actually performed the burn-to-`BURN_ADDRESS` transfer that is being reclaimed.

### Impact Explanation
This breaks the custody invariant that "object creation, transfer, burn, and ownership refs must preserve the intended controller." A party (A) who no longer owns an object can resurrect a stale claim and steal it back from `BURN_ADDRESS` after the legitimate current owner (B) intentionally and irrevocably discarded it. This applies to any transferable object with ungated transfer enabled that has ever been through a soft `burn()` call and subsequently changed hands — e.g., NFTs/token objects, or any object-held asset using the standard `object::burn`/`object::unburn` API. It results in theft/unauthorized reassignment of custody of the object and its associated value away from the party (B) who exercised its legitimate burn right, and corrupts the recovery-rights model (recovery should only ever belong to the party that performed the disposal action, not an unrelated prior owner).

### Likelihood Explanation
The trigger sequence uses only public, unprivileged entry functions (`object::burn`, `object::transfer`/`transfer_call`, `object::unburn`) with no special permissions, and relies on the framework's own published `BURN_ADDRESS` constant as the natural sink for discarding objects. Any object that has at some point been burned by a past owner and later resold/transferred through ordinary means (common for tradable NFTs/token objects) is exposed. The only precondition is that the object retain `allow_ungated_transfer = true` (the default) so ordinary transfers work.

### Recommendation
Either:
- Remove/invalidate any existing `TombStone` in `transfer_raw_inner` on every ownership change (mirroring what `transfer_with_ref` already does), so a `TombStone` can never survive across an ownership change, or
- Change `unburn`'s reclaim branch to also verify that the current burn was performed by the same address recorded as `original_owner` (e.g., by re-checking `is_owner` immediately prior to the transfer that set `owner = BURN_ADDRESS`, or by clearing/refreshing the `TombStone.original_owner` on any ownership change instead of only on `transfer_with_ref`).

### Proof of Concept
```
// 1. A owns `obj` (ungated transfer allowed, e.g. a Token/NFT object)
object::burn(&A, obj);                       // TombStone{original_owner: A}, owner stays A

// 2. A sells/transfers obj normally to B
object::transfer(&A, obj, address_of(&B));   // owner = B, TombStone{original_owner: A} still present (uncleared)

// 3. B intentionally burns/discards obj by sending to the framework BURN_ADDRESS
object::transfer_call(&B, object_address(obj), BURN_ADDRESS); // owner = BURN_ADDRESS

// 4. A reclaims the object B just discarded, using the stale TombStone from step 1
object::unburn(&A, obj);
// -> owner_core.owner == BURN_ADDRESS branch taken
// -> original_owner_addr (A) == signer::address_of(A) passes
// -> transfer_raw_inner(obj, A) executes: A now owns `obj` again, stealing it from B's intended burn.
```

    /// Transfer to the destination address using a LinearTransferRef.
    public fun transfer_with_ref(self: LinearTransferRef, to: address) {
        assert!(!exists<Untransferable>(self.self), error::permission_denied(EOBJECT_NOT_TRANSFERRABLE));

        // Undo soft burn if present as we don't want the original owner to be able to reclaim by calling unburn later.
        if (exists<TombStone>(self.self)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(self.self);
        };

        let object = borrow_global_mut<ObjectCore>(self.self);
        assert!(
            object.owner == self.owner,
            error::permission_denied(ENOT_OBJECT_OWNER),
        );
        event::emit(
            Transfer {
                object: self.self,
                from: object.owner,
                to,
            },
        );
        object.owner = to;
    }

                    to,

    /// Add a TombStone to the object.  The object will then be interpreted as hidden via indexers.
    /// This only works for objects directly owned and for simplicity does not apply to indirectly owned objects.
    /// Original owners can reclaim burnt objects any time in the future by calling unburn.
    /// Please use the test only [`object::burn_object_with_transfer`] for testing with previously burned objects.
    public entry fun burn<T: key>(owner: &signer, object: Object<T>) {
        let original_owner = signer::address_of(owner);
        assert!(is_owner(object, original_owner), error::permission_denied(ENOT_OBJECT_OWNER));
        let object_addr = object.inner;
        assert!(!exists<TombStone>(object_addr), EOBJECT_ALREADY_BURNT);
        move_to(&create_signer(object_addr), TombStone { original_owner });
    }

    /// Allow origin owners to reclaim any objects they previous burnt.
    public entry fun unburn<T: key>(
        original_owner: &signer,
        object: Object<T>,
    ) {
        let object_addr = object.inner;
        assert!(exists<TombStone>(object_addr), error::invalid_argument(EOBJECT_NOT_BURNT));

        // The new owner of the object can always unburn it, but if it's the burn address, we go to the old functionality
        let object_core = borrow_global<ObjectCore>(object_addr);
        if (object_core.owner == signer::address_of(original_owner)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(object_addr);
        } else if (object_core.owner == BURN_ADDRESS) {
            // The old functionality
            let TombStone { original_owner: original_owner_addr } = move_from<TombStone>(object_addr);
            assert!(
                original_owner_addr == signer::address_of(original_owner),
                error::permission_denied(ENOT_OBJECT_OWNER)
            );
            transfer_raw_inner(object_addr, original_owner_addr);
        } else {
            abort error::permission_denied(ENOT_OBJECT_OWNER);
        };
    }
