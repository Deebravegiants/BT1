Audit Report

## Title
CORS wildcard-origin allowlist bypass via unanchored suffix match - (File: core/services/gateway/network/httpserver.go)

## Summary
The gateway's CORS origin validation in `isAllowedOrigin` uses `strings.HasSuffix` to match wildcard-configured allowed origins against the incoming `Origin` header, but never verifies that the suffix match is anchored on a domain-label boundary (preceded by a `.`). This allows an attacker who registers a lookalike domain (e.g., `evilethereum.org`) to bypass a wildcard allowlist entry intended only for genuine subdomains (e.g., `*.ethereum.org`).

## Finding Description
`isAllowedOrigin` splits both the request's `Origin` header and each configured `CORSAllowedOrigins` entry into scheme/host/port. For wildcard entries (`*.example.com`), it strips the `*.` prefix and performs a bare suffix comparison:
```go
if strings.HasPrefix(allowedHost, "*.") {
    allowedHost = allowedHost[2:]
    if strings.HasSuffix(originHost, allowedHost) {
        return true
    }
}
```
There is no check that `originHost` equals `allowedHost` or ends with `"."+allowedHost`. Consequently `strings.HasSuffix("evilethereum.org", "ethereum.org")` returns `true`, even though `evilethereum.org` is an unrelated domain, not a subdomain of `ethereum.org`. This function directly gates `handleRequest`, which reflects the raw `Origin` value into `Access-Control-Allow-Origin` along with permissive methods/headers whenever `isAllowedOrigin` returns true. No other authentication or validation layer re-checks the origin relationship. [1](#0-0) [2](#0-1) 

## Impact Explanation
An operator configuring a wildcard CORS entry like `https://*.ethereum.org` intends to trust only genuine subdomains. Due to the missing boundary check, any attacker-registered domain ending in the same suffix is treated as fully trusted, causing the gateway to set `Access-Control-Allow-Origin` to the attacker's origin. This enables cross-origin browser requests from the attacker's page to be authorized against the gateway, allowing exposure of JSON-RPC responses to an untrusted origin — a cross-user response exposure / allowlist bypass at the gateway boundary.

## Likelihood Explanation
Exploitation only requires (1) an operator using the documented wildcard CORS feature, and (2) an attacker registering/controlling a domain ending in the same suffix and getting a victim's browser to issue a cross-origin request to the gateway with that `Origin`. No credentials, admin access, or host access are needed; the request is a standard unprivileged HTTP request with a spoofable `Origin` header.

## Recommendation
Anchor the wildcard match on a label boundary, e.g.:
```go
if strings.HasPrefix(allowedHost, "*.") {
    suffix := allowedHost[1:] // ".example.com"
    if originHost == allowedHost[2:] || strings.HasSuffix(originHost, suffix) {
        return true
    }
}
```

## Proof of Concept
1. Configure `CORSEnabled: true` and `CORSAllowedOrigins: []string{"https://*.ethereum.org"}`.
2. Send an HTTP request to the gateway with header `Origin: https://evilethereum.org`.
3. Observe `isAllowedOrigin` returns `true` and the response includes `Access-Control-Allow-Origin: https://evilethereum.org`, confirming the bypass. This can be verified as a Go unit test analogous to `TestHTTPServer_HandleRequest_CORSEnabled_FromAllowedOriginWildcards` in `core/services/gateway/network/httpserver_test.go`, substituting `evilethereum.org` for a legitimate subdomain. func (s *httpServer) isAllowedOrigin(origin string) bool {
	originScheme, originHost, originPort, err := s.splitURL(origin)
	if err != nil {
		s.lggr.Debug("error parsing origin URL", err)
		return false
	}
	for _, allowed := range s.config.CORSAllowedOrigins {
		// probably better to do this once when server starts and store it in a map
		// this is an easier solution so we don't have to apply more changes to the code
		// just need to be careful when specifying allowed origins in the config file
		allowedScheme, allowedHost, allowedPort, err := s.splitURL(allowed)
		if err != nil {
			s.lggr.Debug("error parsing allowed origin URL", err)
			continue
		}
		// skip if the scheme doesn't match at all
		if originScheme != allowedScheme {
			continue
		}
		// skip if the port doesn't match at all
		if originPort != allowedPort {
			continue
		}
		// check for exact host match (e.g., remix.com)
		if originHost == allowedHost {
			return true
		}
		// check for wildcard host match (e.g., *.remix.com)
		if strings.HasPrefix(allowedHost, "*.") {
			allowedHost = allowedHost[2:]
			if strings.HasSuffix(originHost, allowedHost) {
				return true
			}
		}
	}
	return false
}
