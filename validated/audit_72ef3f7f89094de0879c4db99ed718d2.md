### Title
Unauthenticated Magic QR Code Triggers WiFi Credential Reset, Causing Persistent Loss of Backend Connectivity for All Future Signups - (File: `src/plans/mod.rs`)

### Summary
The Orb's operator QR-code scanning flow accepts a special "magic action" QR code (`magic_action:reset_wifi_credentials`) that immediately wipes the Orb's WiFi configuration, **without any operator authentication or backend verification**. Because the reset overwrites the persisted `wpa_supplicant` configuration file entirely, and reconnection depends on a follow-up successful WiFi-credentials QR scan, any unauthenticated bystander who shows this QR string to the Orb's camera can strand the device without network access — blocking every subsequent signup attempt until a technician manually re-provisions WiFi. This mirrors the reported bug class: an ordinary, reachable user action against a shared/critical piece of state (network credentials, analogous to the pool token allowance) triggers a revocation side-effect that was only intended for a privileged/controlled scenario, permanently breaking the system for all future legitimate users.

### Finding Description
`qr_scan::operator::Data::try_parse` recognizes a "magic" QR-code format matched by `MAGIC_QR_CODE` and maps it to `Data::MagicResetWifi` with no cryptographic binding to an authorized operator: [1](#0-0) 

This value is produced purely from the QR-code text (`magic_action:reset_wifi_credentials`) and is completely disjoint from the normal operator-identity path, which requires backend verification via `verify_operator_qr_code`.

Crucially, `handle_magic_operator_qr_code` executes the reset **before** any operator verification occurs in the signup flow (`scan_initial_qr_codes` / `scan_remaining_qr_codes` call `handle_magic_operator_qr_code` immediately after a raw QR scan, and only call `verify_operator_qr_code` for the `Normal` variant, never for magic actions): [2](#0-1) [3](#0-2) 

`reset_wifi_and_ensure_network` calls `network::reset()`, which unconditionally overwrites the live `wpa_supplicant` configuration with the default (blank) config and forces a disconnect: [4](#0-3) [5](#0-4) 

Recovery then depends on `wifi::Plan::ensure_network_connection`, which loops waiting for a new WiFi-credentials QR code to be scanned: [6](#0-5) 

If no correct WiFi QR is subsequently provided (attacker only needs to show the reset QR and leave, or show an invalid/garbage WiFi QR), the Orb is left in a disconnected state. The underlying `wpa-supplicant-interface join` helper also **fully truncates and rewrites** the persisted config file for any single join, so even a legitimate-looking but incorrect WiFi QR permanently discards the previously working configuration with no fallback: [7](#0-6) 

This is analogous to the reported DeFi bug: a routine, unprivileged, user-selectable operation (choosing a redemption pool that collides with the strategy's own pool / here, presenting a specific QR string) triggers a cleanup/reset side effect on shared persistent state (token allowance / here, WiFi credentials) that the system assumed would only be touched by a trusted, narrowly-scoped flow — permanently breaking normal operation for everyone who depends on that shared resource afterward (deposits / here, signups requiring backend connectivity).

### Impact Explanation
Once WiFi credentials are wiped and no valid reconnection QR is supplied, the Orb cannot reach the Worldcoin backend. Every subsequent signup attempt by any legitimate user will fail (operator/user QR verification, signup submission, and biometric pipeline all require backend connectivity). This is a device-wide denial of service that persists until a technician physically re-provisions WiFi credentials — a permanent block of legitimate identity-verification operations for all users of that Orb, directly matching the "Impact" criteria of permanently blocked, reachable-by-unprivileged-user state corruption.

### Likelihood Explanation
The attack requires no credentials, no physical tampering, and no privileged access — only the ability to display a QR code (`magic_action:reset_wifi_credentials`) to the Orb's camera during the normal operator QR-scanning phase of the idle/signup loop, which is explicitly reachable by any bystander in front of the device. The magic-action codes are simple fixed strings with no signature or authorization check, making this trivially and repeatedly exploitable.

### Recommendation
Require cryptographic/backend authorization (equivalent to `verify_operator_qr_code`) before executing any magic action (`MagicResetWifi`, `MagicResetMirror`). At minimum, gate WiFi-reset execution behind verified-operator status, and avoid destructively truncating the entire `wpa_supplicant` configuration on `join`/`reset` without a safe fallback/rollback path so a single bad or malicious QR scan cannot permanently strand connectivity.

### Proof of Concept
1. Approach an idle Orb waiting for the operator QR-code scan.
2. Display a QR code encoding the literal string `magic_action:reset_wifi_credentials`.
3. Observe `handle_magic_operator_qr_code` immediately invokes `reset_wifi_and_ensure_network` with no authentication, wiping the persisted WiFi config (`network::reset()` → `RestoreDefaultConfig` + `reconfigure`).
4. Walk away, or present an invalid/garbage WiFi-credentials QR code when prompted.
5. The Orb remains disconnected from the backend; all subsequent operator/user QR verification and signup submissions fail until staff manually re-provision WiFi via physical/administrative access.

    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}

impl Plan {
    /// Checks whether connected to a WiFi network, if not connected scan the
    /// hotspot QR code.
    pub async fn ensure_network_connection(&self, orb: &mut Orb) -> Result<()> {
        let mut in_progress_start = Instant::now();
        let mut has_requested_qr_code = false;
        let success = |orb: &mut Orb, has_requested_qr_code| {
            if has_requested_qr_code {
                orb.ui.network_connection_success();
            }
            tracing::debug!("Network is connected");
            Ok::<(), Error>(())
        };
        loop {
            match network::status().await? {
                network::Status::Connected { has_internet: true } => {
                    success(orb, has_requested_qr_code)?;
                    break;
                }
                network::Status::InProgress
                | network::Status::Connected { has_internet: false }
                    if in_progress_start.elapsed() < NETWORK_CONNECTION_TIMEOUT =>
                {
                    tracing::debug!("Network connection in progress");
                    sleep(Duration::from_millis(250)).await;
                }
                network::Status::Connected { has_internet: false }
                | network::Status::Disconnected
                | network::Status::InProgress => {
                    tracing::debug!("Network is disconnected, or has no connection to the backend");
                    if has_requested_qr_code {
                        orb.ui.qr_scan_fail(QrScanSchema::Wifi);
                    }
                    has_requested_qr_code = true;
                    match qr_scan::Plan::new(None, false).run(orb).await? {
                        Ok((credentials, _)) => {
                            tracing::info!(
                                "Read WiFi credentials from hotspot QR: {:?}",
                                credentials
                            );
                            network::join(credentials).await?;
                            in_progress_start = Instant::now();
                        }
                        Err(qr_scan::ScanError::Invalid) => {
                            orb.ui.qr_scan_unexpected(
                                QrScanSchema::Wifi,
                                QrScanUnexpectedReason::WrongFormat,
                            );
                        }
                        Err(qr_scan::ScanError::Timeout) => {}
                    }
                    orb.reset_rgb_camera().await?;
                }
            }
        }
        Ok(())
    }

/// Joins a new WiFi network.
pub fn run(auth: Option<&str>, ssid: &str, password: Option<&str>) -> Result<()> {
    if Path::new(CONFIG_PATH).is_symlink() {
        bail!("Unexpected symbolic link in place of {}", CONFIG_PATH);
    }
    {
        let mut file = File::options()
            .write(true)
            .truncate(true)
            .create(true)
            .open(CONFIG_PATH)
            .wrap_err("opening wpa_supplicant config")?;
        render_conf(&mut file, auth, ssid, password).wrap_err("writing wpa_supplicant config")?;
    }
    reconfigure::run()?;
    Ok(())
}
