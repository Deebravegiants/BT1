The premise doesn't hold against the actual code. `StateUpdateRefs` is not a long-lived, mutably-reused object shared across chunks — every chunk commit constructs a brand-new `StateUpdateRefs` via `StateUpdateRefs::index`/`index_write_sets`, which freshly computes `for_last_checkpoint` and `for_latest` purely from that call's `updates_by_version` input and `all_checkpoint_indices`. [1](#0-0) 

`for_latest_batched()` simply returns a reference into the `for_latest` field that was populated once during that single `index()` call — there's no mutation, caching, or cross-call state, and no static/shared borrow that would let one `ChunkToCommit`'s batched updates leak into another's. [2](#0-1) [3](#0-2) 

The `'a` lifetime on `state_update_refs: &'a StateUpdateRefs<'a>` in `ChunkToCommit` is a standard borrow-checker constraint on the caller-owned data (write sets, transactions) used to build that specific `StateUpdateRefs`; Rust's borrow checker prevents the same `&'a StateUpdateRefs` from being reused for a second chunk's commit unless the caller explicitly re-borrows the exact same already-built object (which would just be reusing identical, not stale, data). There is no code path in the executor/commit pipeline that reuses a `StateUpdateRefs` instance across two sequential chunks — each chunk goes through its own `StateUpdateRefs::index_write_sets` call. This scenario is a hypothetical misuse of an internal storage API, not a demonstrable vulnerability reachable from unprivileged transaction/API input, and it does not identify an actual custody-boundary crossing in the existing code.

    pub fn index<
        UpdateIter: IntoIterator<Item = (&'kv StateKey, &'kv BaseStateOp)>,
        VersionIter: IntoIterator<Item = UpdateIter>,
    >(
        first_version: Version,
        updates_by_version: VersionIter,
        num_versions: usize,
        all_checkpoint_indices: Vec<usize>,
    ) -> Self {
        if num_versions == 0 {
            return Self {
                per_version: PerVersionStateUpdateRefs::new_empty(first_version),
                all_checkpoint_versions: vec![],
                for_last_checkpoint: None,
                for_latest: None,
            };
        }

        let mut updates_by_version = updates_by_version.into_iter();
        let mut num_versions_for_last_checkpoint = 0;
        let last_checkpoint_index = all_checkpoint_indices.last().copied();

        let for_last_checkpoint = last_checkpoint_index.map(|index| {
            num_versions_for_last_checkpoint = index + 1;
            let per_version = PerVersionStateUpdateRefs::index(
                first_version,
                updates_by_version
                    .by_ref()
                    .take(num_versions_for_last_checkpoint),
                num_versions_for_last_checkpoint,
            );
            let batched = Self::batch_updates(&per_version);
            (per_version, batched)
        });

        let for_latest = match last_checkpoint_index {
            Some(index) if index + 1 == num_versions => None,
            _ => {
                assert!(num_versions_for_last_checkpoint < num_versions);
                let per_version = PerVersionStateUpdateRefs::index(
                    first_version + num_versions_for_last_checkpoint as Version,
                    updates_by_version,
                    num_versions - num_versions_for_last_checkpoint,
                );
                let batched = Self::batch_updates(&per_version);
                Some((per_version, batched))
            },
        };

        Self {
            per_version: Self::concat_per_version_updates(
                for_last_checkpoint.as_ref().map(|x| &x.0),
                for_latest.as_ref().map(|x| &x.0),
            ),
            all_checkpoint_versions: all_checkpoint_indices
                .into_iter()
                .map(|index| first_version + index as Version)
                .collect(),
            for_last_checkpoint,
            for_latest,
        }
    }
