## Title
Unchecked ERC20 transfer return value in escrow withdrawal permanently freezes user/solver funds - (File: `evm/tron/contracts/apps/IntentGatewayV2.sol`)

### Summary
`IntentGatewayV2.withdraw()` (Tron variant) releases escrowed input tokens and accumulated transaction fees using a raw low-level `.call()` to the ERC20 `transfer` selector, checking only that the *call* did not revert — not that the token's own boolean success return value was `true`. It then unconditionally decrements the escrow accounting and marks the order `_filled`, exactly mirroring the report's root cause where a cached balance is updated without confirming the outcome of the preceding asynchronous transfer. For any non-standard ERC20 that returns `false` on a failed transfer instead of reverting, the escrow is zeroed out and the order marked settled while the beneficiary receives nothing, permanently freezing the funds with no path to retry or recover them.
