Audit Report

## Title
Unauthenticated exposure of LOOP plugin pprof/metrics proxy endpoints - (File: core/web/router.go)

## Summary
`NewRouter` in `core/web/router.go` mounts the top-level `api` route group with only rate-limiting and session-cookie middleware (no authentication check), and `loopRoutes(app, api)` is invoked directly on that unauthenticated group. This registers `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` without any `auth.Authenticate` wrapper, unlike the sibling `/debug/vars` route which is explicitly protected.

## Finding Description
`NewRouter` builds `api` from `engine.Group("/", rateLimiter(...), sessions.Sessions(...))` with no authentication middleware attached to the group itself. [1](#0-0) 
`debugRoutes` wraps `/debug/vars` in `r.Group("/debug", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))`, requiring a valid session before serving `expvar.Handler()`. [2](#0-1) 
By contrast, `loopRoutes` registers its routes directly on the raw `r` group passed to it with no `auth.Authenticate` call anywhere in the function body. [3](#0-2) 
The handler `pluginPPROFHandler` looks up the named plugin and forwards the request — including the `profile` path segment and query parameters (`debug`, `gc`, `seconds`) — to the plugin's internal `http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>` endpoint, returning the raw response body to the caller. [4](#0-3) 
`pluginMetricHandler` similarly proxies to the plugin's internal `/metrics` endpoint without any authentication check. [5](#0-4) 
I confirmed via `grep_search` that `metricRoutes` (which defines the node's own `pprof.Cmdline`/`pprof.Profile`/etc. handlers) is defined but never called anywhere in the codebase — it is dead code and not part of the reachable attack surface. The reachable, exploitable gap is specifically the `loopRoutes` call at router.go line 91, which is wired into the live router with no auth wrapper, in contrast to `debugRoutes`, `sessionRoutes`, and `v2Routes`' authenticated sub-groups defined in the same file.

## Impact Explanation
This is an unauthenticated information-disclosure endpoint reachable by any network client that can reach the node's web API port. Via `pluginPPROFHandler`, an attacker can retrieve `cmdline`, `heap`, `goroutine`, `profile` (CPU), and `trace` pprof data, and via `pluginMetricHandler` can retrieve Prometheus metrics for any named LOOP plugin — all without any session cookie or API token. This falls under CWE-209/debug information exposure. It does not directly grant fund movement, job-run manipulation, or authentication bypass on its own, so it should be scoped as an information-disclosure finding rather than a critical/high-impact vulnerability class like key exfiltration or unauthorized fund movement; the actual sensitivity of the disclosed data (e.g., whether secrets appear in plugin subprocess argv or heap) could not be fully confirmed since LOOP subprocess invocation was not inspected.

## Likelihood Explanation
High for any deployment where the node's web API port is reachable by an unauthenticated client, since no credential or role is required to hit these routes — the bypass is unconditional given the code path, not dependent on misconfiguration beyond normal network reachability of the web server (which is the same threat model assumed for all other authenticated routes like `/debug/vars` in this file).

## Recommendation
Wrap `loopRoutes(app, api)` with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` middleware applied to `/debug/vars` in `debugRoutes`, or move the plugin pprof/metrics proxy routes to a separate internal-only listener not exposed on the public API port.

## Proof of Concept
Against a running node with an active LOOP plugin `<plugin-name>`, without any session cookie or `Authorization` header:
1. `GET /plugins/<plugin-name>/debug/pprof/cmdline` — the request reaches `pluginPPROFHandler` and is proxied unauthenticated per [4](#0-3) .
2. `GET /plugins/<plugin-name>/metrics` — reaches `pluginMetricHandler` and is proxied unauthenticated per [5](#0-4) .
3. Compare with `GET /debug/vars`, which returns `401`/redirect without a valid session due to the `auth.Authenticate` wrapper in `debugRoutes` [2](#0-1) , demonstrating the inconsistency and confirming the missing auth check on the plugin routes.

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```
