## Title
`fundRequest()` lets any third-party fee top-up be silently reclaimed by the original request payer on timeout — ([File: evm/src/core/EvmHost.sol])

### Summary
This is a structural analog of the reported "liquidation bonus stolen through repay() after takeOverDebt()" bug class: a second, unprivileged party contributes funds toward an existing obligation, but when that obligation is later "settled" (here: a timed-out ISMP request), the entire accumulated balance — including the second party's contribution — is returned only to the *original* obligor, not to the party who actually funded the top-up.

### Finding Description
`EvmHost.fundRequest()` is a fully permissionless function that lets **any account** increase the relayer fee escrowed for a pending POST/GET request: [1](#0-0) 

The function pulls `amount` of `feeToken` (or native, auto-swapped) from `msg.sender`, but it never records who actually supplied the top-up. It only merges the new amount into the existing `FeeMetadata` for the commitment:

```solidity
FeeMetadata memory metadata = _requestCommitments[commitment];
if (metadata.sender == address(0)) revert UnknownRequest();
metadata.fee += amount;
_requestCommitments[commitment] = metadata;
```

`metadata.sender` still points at whoever originally dispatched the request (`post.payer` / `_msgSender()` set in `dispatch()`): [2](#0-1) 

When the request subsequently times out, `dispatchTimeOut` refunds the **entire** `meta.fee` — original fee plus every third-party top-up — to `meta.sender` alone: [3](#0-2) 

The project's own test suite documents this as intended behavior — `testFundRequest` shows "someone else can fund your request" with no tracking of that separate funder: [4](#0-3) 

This is exactly the shape of the reported bug: a party (the original "borrower"/payer) is the sole beneficiary of a refund/settlement path even though a different, unprivileged party ("new borrower"/funder) contributed real value expecting delivery to occur. If the request never gets relayed and instead times out, the funder's tokens are transferred to the original payer with no on-chain mechanism to recover them — a concrete, single-transaction-reachable fund misappropriation.

### Impact Explanation
Any account (a relayer trying to expedite delivery, an application, or an end user helping someone else's stuck request) that calls `fundRequest()` on a request it does not own risks total loss of the funded amount: if the request ultimately times out, `dispatchTimeOut` sends 100% of the accumulated fee (including the third party's contribution) to the original `payer`, who did nothing to earn it beyond having dispatched the original request. This is a direct, permanent misappropriation of funds — meeting the "concrete theft of funds" bar — and requires no privilege beyond calling a public function.

### Likelihood Explanation
`fundRequest` is explicitly designed and documented to be callable by "someone else" (see doc comments and tests), so third-party top-ups are an expected usage pattern (e.g., relayers or dApps bumping stuck request fees to guarantee delivery). Any request that is topped up by a third party and later legitimately times out (congestion, relayer failure, or a malicious original payer who deliberately lets it stall) results in the funder's contribution being swept to the original payer. No collusion or special conditions are needed beyond a normal timeout, making this readily triggerable in practice.

### Recommendation
Track fee contributions per-funder (e.g., a mapping from commitment to a list of `(funder, amount)` or store the most recent funder separately), and on timeout, refund each contributor their own portion rather than crediting the entire accumulated fee to `metadata.sender`. Alternatively, disallow third-party funding of another payer's `payer` and require `fundRequest` to record `msg.sender` as a new/blended payer entitled to a pro-rata refund share.

### Proof of Concept
1. Alice dispatches a POST request via `EvmHost.dispatch()` with `payer = alice`, `fee = 1` (feeToken), and a non-zero timeout.
2. Bob observes the request is under-funded and likely to stall; he calls `EvmHost.fundRequest(commitment, 100)` and approves/pays 100 feeToken, intending to incentivize a relayer to deliver it quickly (per the documented public "top-up" pattern in `evm/tests/foundry/EvmHostTest.sol:183-185`).
3. No relayer delivers the message before the timeout elapses (this can happen naturally, or Alice can grief by never allowing on-chain conditions relayers monitor to be favorable, or simply because no relayer is currently profitable at the lower base rate before Bob's top-up posts).
4. Once expired, anyone submits the timeout proof; `EvmHost.dispatchTimeOut(PostRequestTimeout, meta, commitment)` executes `onPostRequestTimeout` on Alice's app and then refunds `meta.fee` (1 + 100 = 101 feeToken) entirely to `meta.sender = alice`.
5. Bob's 100 feeToken top-up is irrecoverably transferred to Alice, even though Alice never contributed it and Bob never authorized handing it to Alice.

```text
    function dispatchTimeOut(
        PostRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onPostRequestTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit PostRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }
```

```text
    function dispatch(DispatchPost memory post) external payable notFrozen returns (bytes32 commitment) {
        if (msg.value > 0) {
            address[] memory path = new address[](2);
            address uniswapV2 = _hostParams.uniswapV2;
            path[0] = IUniswapV2Router02(uniswapV2).WETH();
            path[1] = feeToken();
            IUniswapV2Router02(uniswapV2).swapETHForExactTokens{value: msg.value}(
                post.fee, path, address(this), block.timestamp
            );
        } else if (post.fee > 0) {
            IERC20(feeToken()).safeTransferFrom(_msgSender(), address(this), post.fee);
        }

        // adjust the timeout
        uint64 timeoutTimestamp = post.timeout == 0 ? 0 : uint64(block.timestamp) + uint64(post.timeout);
        PostRequest memory request = PostRequest({
            source: host(),
            dest: post.dest,
            nonce: uint64(_nextNonce()),
            from: abi.encodePacked(_msgSender()),
            to: post.to,
            timeoutTimestamp: timeoutTimestamp,
            body: post.body
        });

        // make the commitment
        commitment = request.hash();
        _requestCommitments[commitment] = FeeMetadata({sender: post.payer, fee: post.fee});
        emit PostRequestEvent({
            source: string(request.source),
            dest: string(request.dest),
            from: _msgSender(),
            to: abi.encodePacked(request.to),
            nonce: request.nonce,
            timeoutTimestamp: request.timeoutTimestamp,
            body: request.body,
            fee: post.fee
        });
    }
```

```text
    function fundRequest(bytes32 commitment, uint256 amount) external payable notFrozen {
        if (msg.value > 0) {
            address[] memory path = new address[](2);
            address uniswapV2 = _hostParams.uniswapV2;
            path[0] = IUniswapV2Router02(uniswapV2).WETH();
            path[1] = feeToken();
            IUniswapV2Router02(uniswapV2).swapETHForExactTokens{value: msg.value}(
                amount, path, address(this), block.timestamp
            );
        } else {
            IERC20(feeToken()).safeTransferFrom(_msgSender(), address(this), amount);
        }

        FeeMetadata memory metadata = _requestCommitments[commitment];
        if (metadata.sender == address(0)) revert UnknownRequest();

        metadata.fee += amount;
        _requestCommitments[commitment] = metadata;

        emit RequestFunded({commitment: commitment, newFee: metadata.fee});
    }
```

```text
    function testFundRequest() public {
        // dispatch request
        vm.prank(tx.origin);
        bytes32 commitment = host.dispatch(
            DispatchPost({
                body: new bytes(0),
                payer: tx.origin,
                fee: 0,
                dest: StateMachine.evm(421614),
                timeout: 0,
                to: new bytes(0)
            })
        );
        assert(host.requestCommitments(commitment).fee == 0);

        // fund request
        vm.prank(tx.origin);
        host.fundRequest(commitment, 10 * 1e18);
        assert(host.requestCommitments(commitment).fee == 10 * 1e18);

        // can't fund unknown requests
        vm.expectRevert(EvmHost.UnknownRequest.selector);
        vm.prank(tx.origin);
        host.fundRequest(keccak256(hex"dead"), 10 * 1e18);

        // someone else can fund your request
        feeToken.mint(address(this), 10 * 1e18);
        host.fundRequest(commitment, 10 * 1e18);
    }
```
