### Title
Unauthenticated "Magic" Operator QR-Code Triggers Privileged WiFi/Mirror Reset Before Backend Authorization Check - (File: src/plans/mod.rs)

### Summary
The external report describes insufficient validation of immutable, security-relevant initialization parameters (`royaltyFraction`, `vendor`, etc.) that are trusted without verifying they satisfy safe bounds or actor-distinction invariants before being locked in, letting an unvalidated value corrupt the system's economics/logic. The orb-core analog is in the operator QR-code handling pipeline: a "magic" QR code payload (`magic_action:reset_wifi_credentials` / `magic_action:reset_mirror_calibration`) is accepted and *acted upon immediately*, before the orb ever validates with the backend that the scanned code belongs to an authorized operator.

### Finding Description
`qr_scan::operator::Data::try_parse` recognizes two special "magic" values purely by regex pattern matching, with no cryptographic or backend-based authentication: [1](#0-0) 

These values are consumed by `handle_magic_operator_qr_code`, which — for `MagicResetMirror` and `MagicResetWifi` — immediately calls `reset_mirror_calibration`/`reset_wifi_and_ensure_network` and reports the action as completed, all without any prior call to the backend operator-validation endpoint: [2](#0-1) 

Critically, in the main signup QR-scanning loop, `handle_magic_operator_qr_code` is invoked *before* `verify_operator_qr_code`, which is the function that actually calls the backend (`backend::operator_status::request`) to confirm the scanned operator is legitimate: [3](#0-2) 

The same ordering (magic-action handling prior to backend verification) is present in the self-serve initial scan path as well: [4](#0-3) 

This mirrors the report's root cause: a value that materially changes system state/behavior (here, "reset WiFi network" or "reset mirror calibration," there, `royaltyFraction`/`vendor`) is accepted and acted upon without validating it against the invariant that actually matters — in the Solidity case, a numeric bound; here, actor authorization via the backend. The regex match alone is treated as sufficient "proof" of operator identity/authority.

### Impact Explanation
Any unprivileged person who can present a QR code to the orb's camera (no physical access to internals, no operator credentials, no backend account) can force the orb to:
- Disconnect and reset its configured WiFi network (`reset_wifi_and_ensure_network`), potentially causing denial of service for legitimate signups until an operator manually reconfigures WiFi;
- Reset the orb's mirror calibration (`reset_mirror_calibration`), degrading or halting biometric capture accuracy until recalibrated.

Both actions bypass the operator-authorization check that governs every other operator-initiated action in the signup flow, so the "insufficient input validation" here directly translates into an authorization bypass affecting orb availability and signup integrity — a legitimate misattributed/unauthorized-action analog to the reported bug class.

### Likelihood Explanation
The trigger is trivial: showing a printed or displayed QR code containing the literal string `magic_action:reset_wifi_credentials` (or `reset_mirror_calibration`) to the orb's camera during normal QR-code scanning phases. No authentication, token, or backend round-trip is required to reach the vulnerable code path, and the check happens unconditionally whenever an "operator" QR-code scan occurs.

### Recommendation
Move the backend authorization check (`verify_operator_qr_code`) ahead of `handle_magic_operator_qr_code`, or otherwise require that magic actions only execute for a QR code that has already been validated as belonging to a registered operator. Consider also binding these magic actions to signed/backend-issued tokens rather than static string patterns.

### Proof of Concept
1. Generate a QR code with payload `magic_action:reset_wifi_credentials`.
2. Present it to the orb during idle/operator QR scanning.
3. Observe `handle_magic_operator_qr_code` match `Data::MagicResetWifi` and call `reset_wifi_and_ensure_network`, resetting the orb's network connection — with no backend validation of the presenter's operator status ever performed. [5](#0-4)

static MAGIC_QR_CODE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")
});

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }
