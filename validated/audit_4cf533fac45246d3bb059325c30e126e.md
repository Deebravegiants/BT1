### Title
Double payment of escrowed relayer fee via stale timeout proof after GetResponse already settled — (File: evm/src/core/EvmHost.sol)

### Summary
`EvmHost.dispatchIncoming(GetResponse ...)` pays the relayer fee held in `_requestCommitments[commitment]` when a GET response is delivered, but never deletes that escrow entry. `HandlerV2.handleGetRequestTimeouts` / `EvmHost.dispatchTimeOut(GetRequestTimeout...)` independently refund the very same `_requestCommitments[commitment].fee` to the original sender once a non-membership proof for the response receipt is supplied at *any* previously-verified Hyperbridge height. Because `_stateCommitments` on `EvmHost` retains every historical height indefinitely (no pruning/expiry beyond an optional veto), any relayer can submit a timeout proof anchored at an old height that predates the height at which the response receipt was actually recorded on Hyperbridge, even though the response has already been delivered and paid for on the destination chain. This is analogous to the CVE's use-after-free: a resource (the fee escrow) is "consumed" once but the reference to it is never invalidated, so a second, independent code path can consume it again.

### Finding Description
The GET-response delivery path pays the escrowed fee without clearing the escrow: [1](#0-0) 

The escrow lookup used to authorize timeouts: [2](#0-1) 

`meta.sender == address(0)` is used as the only "already consumed" guard, but since `_requestCommitments[commitment]` is never deleted by `dispatchIncoming(GetResponse)`, `meta.sender` still resolves to the original payer after a response has been delivered and its fee already paid out. The only other gate is a non-membership proof of the `ResponseReceipts` key against `host.stateMachineCommitment(message.height)` — a *caller-chosen* historical height, since: [3](#0-2) 
old entries in `_stateCommitments`/`_latestStateMachineHeight` are never pruned on the EVM host except by explicit veto. A relayer can therefore pick an older, still-verifiable height `h1` (before Hyperbridge's own state recorded the response receipt) at which the non-membership proof is legitimately valid, submit it after a later height `h2` has already delivered and paid the response, and pass `handleGetRequestTimeouts`'s checks: [4](#0-3) 

`dispatchTimeOut` then deletes the commitment and, on a successful module callback, refunds `meta.fee` a second time: [5](#0-4) 

### Impact Explanation
The `feeToken` balance held in `EvmHost` for a single GET request is paid out twice: once to the relayer that delivered the genuine `GetResponse`, and once as a refund to the original sender via the stale timeout. This is a direct, unbacked disbursement of protocol/user escrowed funds reachable with two ordinary, non-forged relayer submissions — no consensus break or forged proof is required, only reuse of an already-verified older state commitment. This qualifies as concrete theft/drain of escrowed funds (High severity).

### Likelihood Explanation
Both code paths (`handleGetResponses` and `handleGetRequestTimeouts`) are explicitly permissionless and reachable by any relayer submitting a single dispatched GET request/response/timeout, as documented: [6](#0-5) 
`EvmHost` keeps unbounded history of `_stateCommitments` (no automatic pruning), so an eligible stale height is routinely available for any GET request whose timeout is close to (or crosses) the block at which its response is delivered — a common, not adversarial-only, timing condition.

### Recommendation
Delete (or otherwise invalidate) `_requestCommitments[commitment]` as soon as a `GetResponse` is successfully delivered in `dispatchIncoming(GetResponse ...)`, mirroring the receipt-based replay protection already used elsewhere, and/or require the timeout height to be no earlier than the latest verified state machine height so a stale non-membership proof cannot be used once a response has since landed.

### Proof of Concept
1. App dispatches a `DispatchGet` request `r` from `EvmHost`, escrowing fee `F` in `_requestCommitments[commitment]`.
2. Relayer submits a valid `GetResponse` for `r` at Hyperbridge height `h2`; `EvmHost.dispatchIncoming(GetResponse, relayer)` pays `F` to `relayer` from `_requestCommitments[commitment].fee`, but leaves `_requestCommitments[commitment]` populated.
3. The same or another relayer submits `handleGetRequestTimeouts` for `r` using a still-available, honestly verified older Hyperbridge height `h1 < h2` (before the response receipt existed in Hyperbridge's trie), satisfying `request.timeout() <= state(h1).timestamp` and the non-membership proof of `ResponseReceipts` at `h1`.
4. `EvmHost.dispatchTimeOut(GetRequestTimeout, meta, commitment)` deletes the commitment and refunds `F` again to the original sender.
5. Net result: `2F` paid out of `EvmHost`'s fee-token balance for a request that only escrowed `F`.

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
