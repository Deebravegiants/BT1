### Title
FXFiller venue-priced legs pay out unbounded amounts derived from a manipulable live Uniswap V4 spot price, with the overfill clamp disabled - ([File: sdk/packages/simplex/src/strategies/fx.ts])

### Summary
Simplex's `FXFiller` prices "venue-priced" pairs (no static bid/ask curves) directly from the live Uniswap V4 pool's `sqrtPriceX96` via `UniswapV4FundingPlanner.getExoticTokenPrice` → `computeDirectPoolPriceUsd`, and this pool-derived rate is then used both to size the order (`sizeOrder`/`referenceRate`) and to compute the actual payout (`computeLegPolicyOutput`, `calculateProfitability`). The only defense against a manipulated pool price is an optional, per-chain `checkPriceGuard` that compares the quote to a static `referencePrice` within `maxDeviationBps` — and it is not required (returns `true`/pass when unconfigured). Compounding this, the per-leg overfill ceiling that used to bound loss from "a manipulated venue price" has been explicitly disabled: `calculateProfitability` computes `overfillCeiling` but only logs a warning and fills the full, unclamped `policyMaxOutput` regardless of how far it exceeds the user's requested amount.

### Finding Description
For a curveless ("venue-priced") pair, `resolveLegRates` in [1](#0-0)  calls `getVenueUsdPrice(chain, token1)`, which resolves to `UniswapV4FundingPlanner.getExoticTokenPrice`. That function reads the current pool state (`state.refresh()`) and computes the USD price directly from the pool's live mid, `sdkPool.token0Price`/`token1Price` (derived from `sqrtPriceX96`), as shown in [2](#0-1) . There is no TWAP, no fee-tier adjustment, and no size/impact term — the raw spot mid is extended linearly across the whole priced quantity.

The only protection is `checkPriceGuard`, defined in [3](#0-2) , which passes through unconditionally when no guard is configured for the chain (`if (!guard || guard.reference.lte(0)) return true`), and otherwise only bounds deviation from a static `referencePrice`, not manipulation within that band or execution-cost impact.

This spot-derived rate feeds both:
1. `sizeOrder`/`referenceRate` (`fx.ts:1339-1364`), which determines per-leg notionals and pair budget allocation, and
2. `computeLegPolicyOutput` (`fx.ts:1397-1434`), which converts the rate directly into the actual `policyMaxOutput` token amount the solver pays out on-chain.

Critically, `calculateProfitability` computes an `overfillCeiling` meant to bound how far the payout can exceed what the user requested, but the enforcement is deliberately disabled — the code comment states this removes "the per-leg loss bound that previously protected against a bug / stale cache / manipulated venue price," and the unclamped amount is filled regardless: [4](#0-3) .

The attack path mirrors the external report's structure exactly: an MEV actor sandwiches the Uniswap V4 pool (source of price truth) around the solver's fill transaction to push `sqrtPriceX96` to a favorable extreme, causing `computeDirectPoolPriceUsd` to return a skewed rate at the moment the solver sizes and executes the fill, with no clamp left to bound the resulting overpayment.

### Impact Explanation
Since `computeLegPolicyOutput`'s output is paid directly out of the solver's wallet/LP position via `IntentGateway.fillOrder` (per `sdk/packages/simplex/docs/ai/flows/filling-how-a-fill-amount-is-sized-and-who-else-spends-the-same.md`), a manipulated spot price at fill time directly inflates the tokens the intent solver hands over relative to fair value, with the disabled overfill clamp removing the only bound on that loss. This is concrete value extraction from the solver (an in-scope "intent solver" actor) driven purely by a permissionless, manipulable input (the DexV2-equivalent pool spot price), matching the report's root cause class — reliance on live pool spot state for value-critical decisions without manipulation resistance.

### Likelihood Explanation
`maxOrderSize` caps do not prevent this — they bound notional, not price — and `checkPriceGuard` is optional per chain and only catches deviation outside a static band, not manipulation inside it. Because the clamp is explicitly disabled by design (per the code comment), any curveless/venue-priced pair funded by Uniswap V4 LP positions is exposed on every fill; the only operational mitigation is manually configuring `referencePrice`/`maxDeviationBps` tightly, which is optional and not enforced by validation.

### Recommendation
Re-enable and enforce the overfill ceiling for venue-priced legs (or at minimum require it when `priceSource === "venue"`), and/or require `referencePrice`/`maxDeviationBps` to be mandatory for any Uniswap V4-funded pair, replacing pure spot pricing with a manipulation-resistant source (e.g., a short TWAP) for value-critical sizing and payout computation.

### Proof of Concept
Not applicable (report-driven analog); the deterministic path is: attacker swaps in the configured Uniswap V4 pool to move `sqrtPriceX96` → solver's `resolveLegRates`/`computeDirectPoolPriceUsd` reads the skewed spot price → `computeLegPolicyOutput` computes an inflated `policyMaxOutput` → `calculateProfitability`'s disabled overfill clamp lets the full unclamped amount be paid out via `fillOrder`.

	 * Validates a live venue quote against the static reference price for the chain.
	 * Returns true (pass) when no guard is configured, or no reference exists for the
	 * chain. Returns false when the quote (token1 per USD) deviates from the reference
	 * by more than `maxDeviationBps`, in which case the order must not be filled.
	 */
	private checkPriceGuard(orderId: string | undefined, chain: string, venueToken1PerUsd: Decimal): boolean {
		const guard = this.priceGuard?.get(chain)
		if (!guard || guard.reference.lte(0)) return true

		const deviationBps = venueToken1PerUsd.minus(guard.reference).abs().div(guard.reference).mul(10000)
		if (deviationBps.gt(guard.maxDeviationBps)) {
			this.logger.warn(
				{
					orderId,
					chain,
					venuePrice: venueToken1PerUsd.toString(),
					referencePrice: guard.reference.toString(),
					deviationBps: deviationBps.toFixed(2),
					maxDeviationBps: guard.maxDeviationBps,
				},
				"Rejecting order: Uniswap venue quote outside price-guard band",
			)
			return false
		}
		return true
	}

	async getExoticTokenPrice(chain: string, exoticToken: string): Promise<Decimal | null> {
		const state = this.stateByChain.get(chain)
		if (!state || !state.isHydrated()) return null

		try {
			await state.refresh()
		} catch (err) {
			this.logger.error({ err, chain }, "Failed to refresh state for price query")
			return null
		}

		const tokenLower = exoticToken.toLowerCase()
		let bestPrice: Decimal | null = null
		let bestLiquidity = 0n

		for (const pos of state.allPositions()) {
			if (pos.currency0.toLowerCase() !== tokenLower && pos.currency1.toLowerCase() !== tokenLower) continue
			const sdkPool = state.getSdkPool(pos.tokenId)
			if (!sdkPool) continue

			const result = this.computeDirectPoolPriceUsd(pos, sdkPool, chain)
			if (result && result.exoticToken.toLowerCase() === tokenLower) {
				const poolLiquidity = state.getPoolLiquidity(pos.tokenId)
				if (poolLiquidity > bestLiquidity) {
					bestPrice = result.priceUsd
					bestLiquidity = poolLiquidity
				}
			}
		}

		if (bestPrice) {
			this.logger.debug({ chain, token: tokenLower, priceUsd: bestPrice.toString() }, "Exotic token price computed")
		}
		return bestPrice
	}

	/**
	 * Computes the USD price of the non-stable token in a pool.
	 * Returns null if neither currency is USDC/USDT on this chain.
	 */
	private computeDirectPoolPriceUsd(
		pos: HydratedV4Position,
		sdkPool: V4Pool,
		chain: string,
	): { exoticToken: string; priceUsd: Decimal } | null {
		const usdc = this.configService.getUsdcAsset(chain).toLowerCase()
		const usdt = this.configService.getUsdtAsset(chain).toLowerCase()
		const c0 = pos.currency0.toLowerCase()
		const c1 = pos.currency1.toLowerCase()

		if (c0 === usdc || c0 === usdt) {
			// currency0 is stable → exotic is currency1
			// token1Price = "token0 per token1" = USD per exotic
			return {
				exoticToken: c1,
				priceUsd: new Decimal(sdkPool.token1Price.toFixed(18)),
			}
		}

		if (c1 === usdc || c1 === usdt) {
			// currency1 is stable → exotic is currency0
			// token0Price = "token1 per token0" = USD per exotic
			return {
				exoticToken: c0,
				priceUsd: new Decimal(sdkPool.token0Price.toFixed(18)),
			}
		}

		return null
	}
