### Title
OAuth authorization code disclosed in plaintext node logs via global request-body logging middleware - ([File: core/web/router.go])

### Summary
Chainlink's HTTP router logs every request body at Debug level through a global gin middleware. The sanitization applied to that body only redacts fields matching a hard-coded `password`-related blacklist. The OIDC token-exchange endpoint accepts the OAuth `code` (and `state`) as a JSON body field, which is not covered by the blacklist, so it is written to the node's logs in cleartext. This mirrors the root cause of CVE-2022-32217 (OAuth token/code leaked in plaintext in Rocket.Chat logs): a legitimate, non-malicious client's authentication material is captured by generic request logging without token-specific redaction.

### Finding Description
`NewRouter` attaches `loggerFunc(app.GetLogger())` as a global middleware for the entire gin engine [1](#0-0) . `loggerFunc` reads the raw request body, restores it for downstream handlers, and after the handler runs, unconditionally logs it via `lggr.Debugw(..., "body", readBody(rdr, lggr), ...)` [2](#0-1) . `readBody` parses the body as JSON and calls `readSanitizedJSON`, which redacts only keys found in the `blacklist` map (or containing the substring "password") [3](#0-2) . The blacklist is limited to `password`, `newpassword`, `oldpassword`, `current_password`, and `new_account_password` [4](#0-3) .

The OIDC authentication flow's token-exchange handler binds an `ExchangeTokenRequest{Code, State}` from the JSON request body, where `Code` is the OAuth authorization code returned by the identity provider [5](#0-4) [6](#0-5) . This handler is registered on the router (via `oi.config...` / `ExtendRouter`, wired through `app.AuthenticationProvider().ExtendRouter(api)` in `NewRouter`) under the same `api` group that inherits the top-level `engine.Use(...)` middleware stack, including `loggerFunc` [7](#0-6) . Because `code` is not in the redaction blacklist, the OAuth authorization code sent by any client (browser callback) exchanging for a session is written verbatim into the node's Debug-level log output.

The code itself is a single-use bearer credential for completing the OAuth flow (`oi.oauth2Config.Exchange(ctx, req.Code)` [8](#0-7) ); disclosure through logs (which are frequently shipped to centralized logging systems, retained for longer periods, or accessible to a broader set of operators than the API surface) is the same class of "cleartext storage of sensitive information" as the referenced CVE.

### Impact Explanation
An attacker or party with read access to node logs (log aggregation systems, support tickets, debug bundles) can recover the raw OAuth authorization `code`. If the code is still valid (not yet exchanged, or provider allows replay in some misconfigurations) it could be replayed to obtain the identity provider's OAuth token themselves, or at minimum leaks sensitive linkage information about the OIDC login flow. This is a real information-disclosure risk in the node's authentication/session-establishment path, matching the "cleartext storage of sensitive information" characterization of the referenced CVE, though the resulting practical impact is bounded by the single-use nature of the OAuth code and the requirement for log access.

### Likelihood Explanation
Any user (including unprivileged actors) initiating the standard OIDC login flow will trigger this logging, since `handleTokenExchange` is invoked as a normal part of sign-in and the logging middleware applies to all requests unconditionally at Debug level. No special privileges or malicious node are required to cause the log entry to be written — the only precondition is that node operators run with Debug (or more verbose) logging enabled and that an attacker later gains access to those logs.

### Recommendation
Extend the redaction blacklist in `isBlacklisted` (`core/web/router.go`) to cover OAuth/session-related fields such as `code`, `token`, `access_token`, `id_token`, `refresh_token`, `secret`, and `accessKey`/similar API-token fields, or switch to an allowlist-based redaction approach for known-sensitive endpoints. Alternatively, exempt the OIDC callback/token-exchange route from full-body request logging, or move to structured field-level redaction driven by request struct tags instead of a static keyword blacklist.

### Proof of Concept
1. Configure the node with OIDC authentication enabled and `Log.Level = debug`.
2. Complete a normal OIDC login: browser hits `/oidc-callback` type route that POSTs `{"code": "<oauth-code>", "state": "<state>"}` to the token-exchange endpoint handled by `handleTokenExchange`.
3. Because this request passes through the global `loggerFunc` middleware, observe the node's Debug log output — the `body` field of the request log entry contains the raw JSON, including the unredacted `code` value, since `code` is absent from the `blacklist` map used by `isBlacklisted`.
4. Any party with access to that log stream can extract the OAuth authorization code in plaintext.

func loggerFunc(lggr logger.Logger) gin.HandlerFunc {
	return func(c *gin.Context) {
		buf, err := io.ReadAll(c.Request.Body)
		if err != nil {
			lggr.Error("Web request log error: ", err.Error())
			// Implicitly relies on limits.RequestSizeLimiter
			// overriding of c.Request.Body to abort gin's Context
			// inside io.ReadAll.
			// Functions as we would like, but horrible from an architecture
			// and design pattern perspective.
			if !c.IsAborted() {
				c.AbortWithStatus(http.StatusBadRequest)
			}
			return
		}
		rdr := bytes.NewBuffer(buf)
		c.Request.Body = io.NopCloser(bytes.NewBuffer(buf))

		start := time.Now()
		c.Next()
		end := time.Now()

		lggr.Debugw(fmt.Sprintf("%s %s", c.Request.Method, c.Request.URL.Path),
			"method", c.Request.Method,
			"status", c.Writer.Status(),
			"path", c.Request.URL.Path,
			"ginPath", c.FullPath(),
			"query", redact(c.Request.URL.Query()),
			"body", readBody(rdr, lggr),
			"clientIP", c.ClientIP(),
			"errors", c.Errors.String(),
			"servedAt", end.Format("2006-01-02 15:04:05"),
			"latency", fmt.Sprintf("%v", end.Sub(start)),
		)
	}

func readSanitizedJSON(buf *bytes.Buffer) (string, error) {
	var dst map[string]any
	err := json.Unmarshal(buf.Bytes(), &dst)
	if err != nil {
		return "", err
	}

	cleaned := map[string]any{}
	for k, v := range dst {
		if isBlacklisted(k) {
			cleaned[k] = "*REDACTED*"
			continue
		}
		cleaned[k] = v
	}

	b, err := json.Marshal(cleaned)
	if err != nil {
		return "", err
	}
	return string(b), err
}

func redact(values url.Values) string {
	cleaned := url.Values{}
	for k, v := range values {
		if isBlacklisted(k) {
			cleaned[k] = []string{"REDACTED"}
			continue
		}
		cleaned[k] = v
	}
	return cleaned.Encode()
}

// NOTE: keys must be in lowercase for case insensitive match
var blacklist = map[string]struct{}{
	"password":             {},
	"newpassword":          {},
	"oldpassword":          {},
	"current_password":     {},
	"new_account_password": {},
}

func isBlacklisted(k string) bool {
	lk := strings.ToLower(k)
	if _, ok := blacklist[lk]; ok || strings.Contains(lk, "password") {
		return true
	}
	return false
}

func (oi *oidcAuthenticator) handleTokenExchange(c *gin.Context) {
	// parse and validate the incoming JSON request
	var req ExchangeTokenRequest
	if err := c.ShouldBindJSON(&req); err != nil {
		c.JSON(http.StatusBadRequest, ExchangeTokenResponse{
			Success: false,
			Message: "Invalid request: " + err.Error(),
		})
		return
	}

	// check state matches stored value on the session
	ginSession := sessions.Default(c)
	storedState := ginSession.Get("state")
	if storedState == nil || req.State != storedState.(string) {
		c.JSON(http.StatusBadRequest, ExchangeTokenResponse{
			Success: false,
			Message: "Invalid state parameter",
		})
		return
	}
	ginSession.Delete("state")

	// Begin token exchange to retrieve attested claims of authenticated user
	ctx := context.Background()
	oauth2Token, err := oi.oauth2Config.Exchange(ctx, req.Code)
	if err != nil {
		oi.lggr.Errorf("Failed to exchange token: %v", err)
		c.JSON(http.StatusInternalServerError, ExchangeTokenResponse{
			Success: false,
			Message: "OIDC exchange failed",
		})
		return
	}
