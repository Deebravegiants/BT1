Based on my analysis, orb-core's operator-QR authorization caching mirrors the reported bug class: an authorization decision fetched once from an authoritative backend is cached and reused for a long window without re-validation, so if the backend revokes/changes that authorization mid-window, the orb keeps acting on the stale decision.

### Title
Stale cached operator-QR authorization reused for up to 23 hours without re-validating with the backend, allowing signups to continue after operator is revoked - (File: src/plans/mod.rs)

### Summary
In self-serve mode, `MasterPlan` caches the result of a one-time backend authorization check (`backend::operator_status::request`) for an operator QR code, together with a `timestamp`, and reuses that cached "valid" verdict for subsequent signups as long as `Instant::elapsed() < operator_qr_expiration_time` (default ~23 hours). This is analogous to `PhiNFT1155` caching `protocolFeeDestination` at `initialize()` time and never re-querying the factory: once a privileged value/decision is fetched, it is trusted for an extended period even if the authoritative source (the backend) changes it in the meantime.

### Finding Description
`scan_initial_qr_codes` only re-scans and re-verifies the operator QR code with the backend when the cached `operator_data` is absent or has expired (`ts.elapsed() > operator_qr_expiration_time`): [1](#0-0) 

`scan_remaining_qr_codes` similarly reuses the cached `operator_data` for the next signup as long as `operator_data.timestamp.elapsed() < operator_qr_expiration_time`, bypassing a fresh call to `verify_operator_qr_code`/`backend::operator_status::request`: [2](#0-1) 

The actual backend authorization check (`valid`/`location_data`) only happens once, in `verify_operator_qr_code`, which calls `backend::operator_status::request`: [3](#0-2) [4](#0-3) 

The expiration window itself defaults to 23 hours: [5](#0-4) 

Because this cached `OperatorData { qr_code, location_data, timestamp }` is treated as a durable authorization token for the whole window, and is used to gate `idle_wait_for_signup_request`/`do_signup` for every subsequent signup performed in that window: [6](#0-5) 
the orb never re-confirms with the backend that the operator is still `valid` for any of those later signups. This is the direct structural analogue of the reported bug: a privileged/authoritative value (here, an authorization verdict instead of a fee-destination address) is fetched once from the authoritative source (the backend, analogous to `PhiFactory`) and then cached and reused by the "instance" (the in-memory `MasterPlan`/`QrCodes` state, analogous to a `PhiNFT1155` instance) without dynamically re-checking the source, even though the source can change the value/decision at any time.

### Impact Explanation
If an operator's QR code/ID is revoked, banned, or found fraudulent by the backend after the initial validation (e.g. due to compromise or policy violation — the same "destination is later found bad" scenario in the original report), orb-core will continue to accept that operator as valid for every self-serve signup that occurs within the remaining `operator_qr_expiration_time` window (up to 23 hours), because `scan_initial_qr_codes`/`scan_remaining_qr_codes` never re-invoke `backend::operator_status::request` until the cached timestamp expires. This allows an unauthorized/misattributed signup flow to be authorized by a since-revoked operator identity for an extended period, i.e., unauthorized signup gating driven by stale data — matching the accepted impact category for this analog.

### Likelihood Explanation
This requires the backend to change/revoke the operator's authorization while the orb is mid-window (self-serve mode enabled and the operator's cached QR data has not yet expired) — a legitimate, foreseeable operational event (compromised operator, fraud detection, deactivation), not a contrived precondition. It requires no attacker privilege beyond normal operator-QR possession from before revocation, matching the "low likelihood precondition + real impact" profile that made the original finding Medium severity.

### Recommendation
Re-validate operator authorization with the backend (`backend::operator_status::request`) on every signup attempt, or shorten/make configurable a much smaller re-validation interval, rather than trusting a single cached validity verdict for up to `operator_qr_expiration_time` (23 hours). At minimum, invalidate the cached `OperatorData` immediately when any backend signal (e.g., a failed status/config call) suggests operator or orb state has changed.

### Proof of Concept
1. Enable self-serve mode (`self_serve = true`) with default `operator_qr_expiration_time` (23 hours).
2. Operator scans a valid operator QR code; `verify_operator_qr_code` succeeds and `OperatorData { timestamp: Instant::now(), .. }` is cached in `QrCodes::Operator`/`ResolvedQrCodes` (src/plans/mod.rs:775-781, 849-853).
3. Backend operator's authorization is revoked (e.g., `Status.valid` would now return `false` if queried).
4. Within the next 23 hours, further signups reuse the cached `operator_data` via `scan_remaining_qr_codes`'s branch that checks only `operator_data.timestamp.elapsed() < operator_qr_expiration_time` (src/plans/mod.rs:796-820), never calling `backend::operator_status::request` again.
5. Signups proceed under the now-revoked operator authorization until the cache naturally expires.

    async fn scan_initial_qr_codes(
        &mut self,
        orb: &mut Orb,
        qr_codes: &mut QrCodes,
        self_serve: bool,
        operator_qr_expiration_time: Duration,
    ) -> Result<()> {
        if self_serve
            && qr_codes
                .operator_timestamp()
                .map_or(true, |ts| ts.elapsed() > operator_qr_expiration_time)
        {
            loop {
                let qr_capture_start = Instant::now();
                let operator_qr_code =
                    self.scan_operator_qr_code(orb, None).await?.expect("to never timeout");
                let Some(operator_qr_code) =
                    self.handle_magic_operator_qr_code(orb, operator_qr_code).await?
                else {
                    continue;
                };
                let Some((_, operator_location_data)) =
                    self.verify_operator_qr_code(orb, &operator_qr_code, qr_capture_start).await?
                else {
                    continue;
                };
                *qr_codes = QrCodes::Operator {
                    operator_data: OperatorData {
                        qr_code: operator_qr_code,
                        location_data: operator_location_data,
                        timestamp: Instant::now(),
                    },
                };
                break;
            }
        }
        Ok(())
    }

    async fn scan_remaining_qr_codes(
        &mut self,
        orb: &mut Orb,
        qr_codes: QrCodes,
        operator_qr_expiration_time: Duration,
    ) -> Result<Option<ResolvedQrCodes>> {
        loop {
            match qr_codes {
                QrCodes::Both { operator_data, user_qr_code, user_data, user_qr_code_string }
                    if operator_data.timestamp.elapsed() < operator_qr_expiration_time =>
                {
                    break Ok(Some(ResolvedQrCodes {
                        operator_data,
                        user_qr_code,
                        user_data,
                        user_qr_code_string,
                    }));
                }
                QrCodes::Operator { operator_data }
                    if operator_data.timestamp.elapsed() < operator_qr_expiration_time =>
                {
                    let Some((user_qr_code, user_data, user_qr_code_string)) =
                        self.scan_user_qr_code(orb, &operator_data).await?
                    else {
                        break Ok(None);
                    };
                    break Ok(Some(ResolvedQrCodes {
                        operator_data,
                        user_qr_code,
                        user_data,
                        user_qr_code_string,
                    }));
                }
                _ => {
                    let qr_capture_start = Instant::now();
                    let Some(operator_qr_code) =
                        self.scan_operator_qr_code(orb, Some(self.qr_scan_timeout)).await?
                    else {
                        break Ok(None);
                    };
                    if !check_signup_conditions(orb).await? {
                        continue;
                    }
                    let Some(operator_qr_code) =
                        self.handle_magic_operator_qr_code(orb, operator_qr_code).await?
                    else {
                        break Ok(None);
                    };
                    let Some((duration_since_shot_ms, operator_location_data)) = self
                        .verify_operator_qr_code(orb, &operator_qr_code, qr_capture_start)
                        .await?
                    else {
                        continue;
                    };
                    // a delay following the scan allows for a better user experience & increases the chance of
                    // not reusing any previous RGB frame for the next QR-code scan
                    if let Some(delay) =
                        QR_SCAN_INTERVAL.checked_sub(Duration::from_millis(duration_since_shot_ms))
                    {
                        sleep(delay).await;
                    }
                    let operator_data = OperatorData {
                        qr_code: operator_qr_code,
                        location_data: operator_location_data,
                        timestamp: Instant::now(),
                    };
                    let Some((user_qr_code, user_data, user_qr_code_string)) =
                        self.scan_user_qr_code(orb, &operator_data).await?
                    else {
                        break Ok(None);
                    };
                    break Ok(Some(ResolvedQrCodes {
                        operator_data,
                        user_qr_code,
                        user_data,
                        user_qr_code_string,
                    }));
                }
            }
        }
    }

    async fn verify_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: &qr_scan::user::Data,
        qr_capture_start: Instant,
    ) -> Result<Option<(u64, backend::operator_status::LocationData)>> {
        if qr_code.signup_extension() || self.operator_qr_code_override.is_some() {
            return Ok(Some((0, backend::operator_status::LocationData {
                team_operating_country: "DEV".to_string(),
                session_coordinates: Coordinates { latitude: 0.0f64, longitude: 0.0f64 },
                stationary_location_coordinates: None,
            })));
        }
        let http_start = Instant::now();
        match backend::operator_status::request(qr_code).await {
            Ok(backend::operator_status::Status { valid: true, location_data, reason: _ }) => {
                let location_data = location_data
                    .expect("to always have a result from the backend if valid == true");
                orb.ui.qr_scan_success(QrScanSchema::Operator);
                dd_incr!("main.count.global.distr_code_validated");
                tracing::info!("Operator QR-code validated: {qr_code:?}");
                dd_timing!("main.time.signup.distr_qr_code_capture", qr_capture_start);
                return Ok(Some((http_start.elapsed().as_millis() as u64, location_data)));
            }
            Ok(backend::operator_status::Status { valid: false, .. }) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
                dd_incr!("main.count.signup.result.failure.distr_qr_code", "type:invalid_qr");
            }
            Err(_) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
            }
        }
        Ok(None)
    }

/// Makes a validation request.
pub async fn request(qr_code: &qr_scan::user::Data) -> Result<Status> {
    let request = super::client()?
        .get(format!(
            "{}/api/v1/distributor/{}/orb/{}/status",
            *SIGNUP_BACKEND_URL, qr_code.user_id, *ORB_ID
        ))
        .basic_auth(&*ORB_ID, Some(get_orb_token()?));
    let status: Status = match request.send().await?.error_for_status() {
        Ok(response) => response.json().await?,
        Err(err) => {
            tracing::error!("Received error response {err:?}");
            return Err(err.into());
        }
    };
    if !status.valid {
        tracing::info!(
            "Operator QR-code invalid: {qr_code:?}, reason: {:?}",
            status.reason.as_deref().unwrap_or("<empty>")
        );
        return Ok(status);
    }
    if status.location_data.is_none() {
        tracing::error!("Operator location data are missing");
        return Ok(Status {
            valid: false,
            location_data: None,
            reason: Some("Operator location data are missing".to_string()),
        });
    }
    Ok(status)
}
