### Title
Hardcoded $1 stablecoin pricing in `BidManager.sortAllStables` lets a solver's bid win with de-pegged tokens - ([File: sdk/packages/sdk/src/protocols/intents/BidManager.ts])

### Summary
The IntentGateway SDK's bid-ranking logic assumes USDC/USDT are always worth exactly $1 when comparing competing solver bids for an order whose outputs are all "stable" tokens. This mirrors the Scream incident, where a lending protocol quoted de-pegged stablecoins at a fixed $1 instead of their real market price, letting an attacker exploit the mispricing to drain the protocol of healthier assets. In Hyperbridge's Intent Gateway, any unprivileged solver can submit a bid denominated in a de-pegged "stable" token; the SDK's auction-selection logic will value it at full par and can select/execute it as the "best" bid over a genuinely par-valued bid, causing the user to receive economically inferior tokens while believing they got the best price.

### Finding Description
`BidManager.sortBids` routes an order to `sortAllStables` whenever every output asset is classified as a stable token via `isStableToken`/`USD_STABLE_SYMBOLS` (USDC/USDT/DAI-style tokens): [1](#0-0) 

`sortAllStables` and its helper `computeStablesUsdValue` value every stable output at exactly $1 regardless of its actual trading price: [2](#0-1) [3](#0-2) 

Because the peg assumption is hardcoded, a solver whose bid offers a larger nominal amount of a de-pegged stablecoin (e.g., a token trading at $0.60) is scored identically to $1-per-token real value, and will rank above a competing solver offering a smaller nominal amount of a fully-pegged stablecoin that is actually worth more. This selection feeds `selectAndExecuteBest`, the SDK's autopilot path that automatically signs and submits the highest-ranked bid on behalf of the user without further economic sanity checking of the chosen tokens' real value. The same hardcoded-$1 assumption recurs in the mixed-output path (`isStableToken` branch of `computeOutputsUsdValue`) and in fee/gas conversion fallbacks (`convertGasToFeeToken`/`convertFeeTokenToWei`), all of which treat "stable" == "$1" without any live price check or deviation guard, unlike the Chainlink-based `SimplexPaymaster._getOraclePrice` which explicitly checks for staleness and non-positive answers.

### Impact Explanation
This is directly reachable by any unprivileged intent solver — no special privileges are required to submit a fill bid with attacker-chosen output tokens/amounts. Since the ranking (and, via autopilot, execution) logic treats a de-pegged stablecoin as par value, a solver can win an auction and have the user's escrowed input tokens released to it while delivering real economic value below what a competing, honest bid would have delivered. This is an economic-loss ("theft of value") vector against ordinary users of the Intent Gateway during any period a widely-used stablecoin de-pegs, directly analogous to the Scream incident's root cause (stale $1 pricing of a de-pegged asset enabling value extraction).

### Likelihood Explanation
The precondition is simply that a supported "stable" token (USDC/USDT/DAI or any symbol placed in `USD_STABLE_SYMBOLS`) trades below/above peg, which has occurred multiple times historically (USDC/USDT depegs, DAI depegs during collateral stress). No governance or protocol changes are needed on the attacker's side; a solver only needs to construct a bid using the de-pegged token. The autopilot `selectAndExecuteBest` path increases likelihood of unnoticed exploitation since users relying on it get no independent live-price check.

### Recommendation
Replace the hardcoded $1 assumption for "stable" tokens in `computeStablesUsdValue`/`computeOutputsUsdValue`/`getTokenUsdPriceWithFx` with a live price source (on-chain DEX quote or oracle with staleness/deviation checks, similar to `SimplexPaymaster._getOraclePrice`), or at minimum bound the assumed peg with a maximum-deviation guard that falls back to raw-amount comparison (as already exists for pricing failures) when a stable's live price deviates materially from $1.

### Proof of Concept
1. Stablecoin `X` (classified as stable via `USD_STABLE_SYMBOLS`/`isStableToken`) de-pegs to $0.60 on the open market.
2. User places an order requesting output in stable tokens; two solvers bid: Solver A offers 1000 units of `X` (real value ≈ $600), Solver B offers 700 units of fully-pegged `USDC` (real value = $700).
3. `sortAllStables`/`computeStablesUsdValue` values Solver A's bid at $1000 and Solver B's at $700, ranking Solver A first. [3](#0-2) 
4. `selectAndExecuteBest` (or a manual caller trusting `sortBids`) executes Solver A's bid, releasing the user's escrowed input to Solver A for tokens worth $300 less than the alternative bid — an economic loss directly caused by the hardcoded peg assumption.

	private sortAllStables(bids: Bid[], orderOutputs: TokenInfo[], chainId: string): Bid[] {
		const requiredUsd = this.computeStablesUsdValue(orderOutputs, chainId)
		console.log(`[BidManager] sortAllStables: required USD value=${requiredUsd.toString()}`)

		const validBids: { bid: Bid; usdValue: Decimal }[] = []

		for (const bid of bids) {
			const bidUsd = this.computeStablesUsdValue(bid.outputs, chainId)

			if (bidUsd === null) {
				console.warn(`[BidManager] Bid from solver=${bid.solverAddress} REJECTED: unable to compute USD value`)
				continue
			}

			if (bidUsd.lt(requiredUsd)) {
				console.log(
					`[BidManager] Bid from solver=${bid.solverAddress}: partial fill candidate ` +
						`(bid=${bidUsd.toString()}, required=${requiredUsd.toString()}, ` +
						`covers=${bidUsd.div(requiredUsd).mul(100).toFixed(2)}%)`,
				)
			} else {
				console.log(`[BidManager] Bid from solver=${bid.solverAddress} ACCEPTED: USD value=${bidUsd.toString()}`)
			}

			validBids.push({ bid, usdValue: bidUsd })
		}

		validBids.sort((a, b) => b.usdValue.comparedTo(a.usdValue))
		return validBids.map(({ bid }) => bid)
	}

	/**
	 * Sums the USD value of a basket of stable tokens (USDC/USDT only),
	 * normalising each amount by its decimal count and treating each token as $1.
	 *
	 * @param outputs - List of token/amount pairs where every token is a stable.
	 * @param chainId - State-machine ID used to look up decimals.
	 * @returns Total USD value as a `Decimal`.
	 */
	private computeStablesUsdValue(outputs: TokenInfo[], chainId: string): Decimal {
		let total = new Decimal(0)
		for (const output of outputs) {
			const tokenAddr = bytes32ToBytes20(output.token)
			const decimals = this.getStableDecimals(tokenAddr, chainId)
			total = total.plus(new Decimal(output.amount.toString()).div(new Decimal(10).pow(decimals)))
		}
		return total
	}
