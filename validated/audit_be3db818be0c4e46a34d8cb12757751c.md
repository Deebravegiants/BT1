Audit Report

## Title
Unauthenticated LOOP plugin proxy routes allow path-confinement bypass to forward requests within the internal loop host - (File: core/web/router.go)

## Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` group, which applies only rate limiting and session middleware, not `auth.Authenticate` — unlike every sibling route group (`debugRoutes`, `sessionRoutes`, `v2Routes`/`authv2`) which explicitly wraps its group in `auth.Authenticate(...)`. `pluginPPROFHandler` additionally builds the forwarded request URL by concatenating the unsanitized `profile` wildcard parameter directly into a `fmt.Sprintf` string with no `path.Clean` or allowlist check, then issues that request via `http.DefaultClient` and streams the response back to the caller.

## Finding Description
`NewRouter` mounts `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` on the same `api` group [1](#0-0) . `debugRoutes` wraps its subgroup in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [2](#0-1) , and `v2Routes`'s `authv2` subgroup (which gates `metricRoutes`/pprof) is likewise wrapped in `auth.Authenticate` [3](#0-2) . In contrast, `loopRoutes` registers its handlers straight on `r` (the unauthenticated-by-default `api` group) with no `auth.Authenticate` wrapper at all [4](#0-3) .

`pluginPPROFHandler` then builds the forwarded internal URL as `fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)`, directly splicing the raw wildcard `profile` parameter into the format string with no `path.Clean`, prefix check, or allowlist, before dispatching it via `doRequest`/`http.DefaultClient.Do` and streaming the response body back verbatim [5](#0-4) [6](#0-5) . `discoveryHandler`, which enumerates registered plugin names needed to hit these endpoints, is also unauthenticated [7](#0-6) .

## Impact Explanation
This is a genuine authentication-boundary inconsistency: every functional route group besides `loopRoutes` explicitly requires session or token authentication, while the LOOP plugin proxy handlers do not, allowing an unauthenticated network caller to trigger the node to make outbound HTTP requests to the plugin's pprof/metrics endpoint and to influence the requested path via string concatenation. However, the forwarded host and port (`l.loopHostName`, `p.EnvCfg.PrometheusPort`) are fixed by server-side config — `loopHostName` defaults to `"localhost"` [8](#0-7)  — so the attacker cannot redirect the request to an arbitrary external host; the exploitable surface is limited to path manipulation within the fixed loop host:port (i.e., accessing other endpoints served by that local plugin process, not a general SSRF pivot into an arbitrary internal network as originally framed). This still constitutes unauthorized/unauthenticated disclosure of internal diagnostic (pprof/metrics) data that should require authentication like its sibling endpoints, which maps to an in-scope "node API authentication bypass" impact class, though its severity is narrower than a full SSRF into arbitrary internal targets.

## Likelihood Explanation
High reachability: no session, token, or role check is required to invoke `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, or `/plugins/:name/debug/pprof/symbol`; only network access to the node's HTTP listener and a valid registered plugin name (itself discoverable via the equally unauthenticated `/discovery` endpoint) are needed. Exploitation of the path-concatenation issue requires only crafting the wildcard segment of the URL, with no additional privilege escalation needed.

## Recommendation
1. Wrap `loopRoutes` (or at minimum `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`, and `pluginMetricHandler`) with `auth.Authenticate(app.AuthenticationProvider(), ...)`, consistent with `debugRoutes` and `authv2`.
2. In `pluginPPROFHandler`, validate `gc.Param("profile")` against an explicit allowlist of pprof sub-paths (`cmdline`, `profile`, `symbol`, `trace`, `allocs`, `block`, `goroutine`, `heap`, `mutex`, `threadcreate`) or apply `path.Clean` plus a strict prefix/equality check before constructing `pluginURL`.

## Proof of Concept
```
# Enumerate a registered plugin name (unauthenticated)
curl http://<node>:<port>/discovery

# Unauthenticated pprof proxy request, no session cookie/API token supplied
curl "http://<node>:<port>/plugins/<plugin-name>/debug/pprof/heap"

# Path-manipulation attempt against the fixed loop host:port
curl "http://<node>:<port>/plugins/<plugin-name>/debug/pprof/../../some/other/endpoint"
```
Both requests succeed without authentication because `loopRoutes` is mounted on `api` without `auth.Authenticate`, confirmed by comparing to `debugRoutes`/`authv2`'s explicit `auth.Authenticate` wrapping in `core/web/router.go`.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
