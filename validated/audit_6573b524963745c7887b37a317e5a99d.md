Audit Report

## Title
CORS Origin Allowlist Bypass via Unanchored Suffix Matching in Gateway Wildcard Origin Check - (File: core/services/gateway/network/httpserver.go)

## Summary
The gateway's `isAllowedOrigin` function in `core/services/gateway/network/httpserver.go` validates wildcard CORS entries (e.g., `*.ethereum.org`) by stripping the `*.` prefix and then using `strings.HasSuffix(originHost, allowedHost)` without requiring a `.` boundary before the match. This allows an attacker controlling a domain like `evilethereum.org` to satisfy the allowlist check intended only for subdomains of `ethereum.org`.

## Finding Description
`isAllowedOrigin` parses the untrusted `Origin` header via `splitURL` [1](#0-0) . For wildcard entries, the code strips `*.` and performs an unanchored suffix check [2](#0-1) . This is invoked directly on every request from `handleRequest`, using the client-supplied `Origin` header, and if allowed, the server reflects that exact origin back in `Access-Control-Allow-Origin` [3](#0-2) . Given `CORSAllowedOrigins = ["https://*.ethereum.org"]`, the allowed host becomes `ethereum.org`. An `Origin: https://evilethereum.org` header satisfies `strings.HasSuffix("evilethereum.org", "ethereum.org")` since there is no dot-boundary requirement before the matched suffix, causing the server to reflect `Access-Control-Allow-Origin: https://evilethereum.org`. No existing check enforces boundary correctness — the scheme/port checks and the exact-match check do not prevent this suffix confusion.

## Impact Explanation
This is a legitimate CWE-20 improper input validation bug that breaks the intended CORS trust boundary: an origin that is not actually a subdomain of the allowlisted domain is treated as trusted. Any browser-based client hosted at a look-alike domain (e.g., an attacker who registers `evilethereum.org`) can issue credentialed cross-origin requests to the gateway's user-facing HTTP endpoint and have responses reflected back with permissive CORS headers, enabling cross-user response exposure for whatever the gateway's API returns to browser-based clients. This maps to the in-scope "allowlist bypass / cross-user response corruption" impact category for the gateway.

## Likelihood Explanation
Exploitation requires only that the operator configure a wildcard `CORSAllowedOrigins` entry (a supported and documented configuration pattern, not a misconfiguration) and that an attacker register or control a domain sharing the unanchored suffix — no authentication, no operator/admin privileges, and no host-level access needed. The gateway's HTTP endpoint is directly reachable, and the check runs on every incoming request via `handleRequest`, making this reliably and repeatably triggerable via a simple crafted `Origin` header in a normal cross-origin browser request.

## Recommendation
Anchor the wildcard suffix match on a subdomain boundary, e.g., replace `strings.HasSuffix(originHost, allowedHost)` with a check that `originHost == allowedHost || strings.HasSuffix(originHost, "."+allowedHost)`, so that `evilethereum.org` cannot match an allowlist entry intended for `*.ethereum.org`.

## Proof of Concept
1. Start the gateway with `CORSEnabled: true` and `CORSAllowedOrigins: ["https://*.ethereum.org"]`.
2. Send an HTTP request to the gateway's configured `Path` endpoint with header `Origin: https://evilethereum.org` (matching scheme/port with the allowed entry).
3. Observe the response contains `Access-Control-Allow-Origin: https://evilethereum.org`, confirming `isAllowedOrigin` incorrectly returns `true` for a non-subdomain look-alike origin — verifiable via a Go unit test directly calling `isAllowedOrigin("https://evilethereum.org")` with the above config and asserting it returns `true`.

func (s *httpServer) splitURL(rawURL string) (string, string, string, error) {
	// lowercase the URL to avoid case sensitivity issues
	parsedURL, err := url.Parse(strings.ToLower(rawURL))
	if err != nil {
		return "", "", "", fmt.Errorf("error parsing URL: %w", err)
	}

	host, port, err := net.SplitHostPort(parsedURL.Host)
	if err != nil {
		// if there's no port, the host itself is returned
		if parsedURL.Host != "" {
			return parsedURL.Scheme, parsedURL.Host, "", nil
		}
		return "", "", "", fmt.Errorf("error splitting host and port: %w", err)
	}

	return parsedURL.Scheme, host, port, nil
}

	if s.config.CORSEnabled {

			w.Header().Set("Access-Control-Allow-Origin", origin)

		}
