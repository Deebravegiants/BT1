Audit Report

## Title
Missing authorization on `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` HTTP endpoints exposes live LOOP plugin runtime data - (File: core/web/router.go, core/web/loop_registry.go)

## Summary
`loopRoutes` is registered directly on the unauthenticated `api` route group in `NewRouter`, unlike every other sensitive debug-class route in the same file (`debugRoutes`, `sessionRoutes`, and the node's own `metricRoutes` under `authv2`), which explicitly wrap their handlers with `auth.Authenticate(...)`. This lets any unauthenticated client reach `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`, and `pluginMetricHandler`, which forward requests to the LOOP plugin's internal `/debug/pprof/*` and `/metrics` HTTP endpoints and stream the raw response back with no access check.

## Finding Description
`NewRouter` builds the `api` group with only rate limiting and session middleware and no authentication requirement, then calls `loopRoutes(app, api)` directly on that bare group, in contrast to `debugRoutes(app, api)` (wraps `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`), `sessionRoutes(app, api)` (wraps `DELETE /sessions` in session auth), and `metricRoutes(authv2)` (registered under the `authv2` group requiring token or session auth). [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3) 

`pluginPPROFHandler` forwards to the plugin's own `http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>` and streams the response back via `doRequest`, with zero access check; `pluginPPROFPOSTSymbolHandler` does the same for `/debug/pprof/symbol`; `pluginMetricHandler` forwards to the plugin's `/metrics` endpoint identically. [5](#0-4) [6](#0-5) 

The existing test `TestLoopRegistry` confirms `/discovery` and `/plugins/mockLoopImpl/metrics` are reachable via a plain `app.NewHTTPClient(nil)` (no auth headers) and return `200 OK`, corroborating that the entire `loopRoutes` group, including the pprof forwarding endpoints registered the same way, is unauthenticated. [7](#0-6) 

## Impact Explanation
`pprof` heap/goroutine/profile/trace/cmdline captures of a LOOP plugin process can contain resident secrets (private keys, decrypted job configs, OCR keys, DB connection strings), and an unauthenticated client can pull this data or trigger repeated CPU/heap profiling via `?seconds=N` for resource exhaustion. This maps to the in-scope "key/secret exfiltration" impact category via missing node API authorization (CWE-862), analogous to the referenced vttablet advisory.

## Likelihood Explanation
High: the affected routes sit on the same engine/port as all other node API routes (GraphQL, sessions, etc.) that are normally exposed for legitimate remote operator access, requiring no special network position, host access, or credentials — only the ability to send an HTTP GET/POST to the node's web port. This is corroborated directly by `TestLoopRegistry`, which reaches sibling endpoints in the same unauthenticated `loopRoutes` group without any credentials and receives `200 OK`.

## Recommendation
Wrap `loopRoutes` registration in the same authentication middleware used for `authv2` (`auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`), or at minimum require an admin/operator role given the sensitivity of pprof heap/goroutine dumps, mirroring how `debugRoutes`, `sessionRoutes`, and `metricRoutes` are protected in `core/web/router.go`. Update `TestLoopRegistry` and any monitoring/scraping clients (e.g., Prometheus service discovery) to authenticate before calling `/discovery`, `/plugins/:name/metrics`, and the pprof forwarding endpoints.

## Proof of Concept
1. Start a chainlink node with a LOOP plugin registered (as in `TestLoopRegistry`).
2. Without any session cookie or API token, send `GET /plugins/<name>/debug/pprof/heap` — this hits `pluginPPROFHandler`, which forwards to the plugin's internal `/debug/pprof/heap` and streams the raw heap dump back with no auth check.
3. Compare with `GET /v2/debug/pprof/heap` (the node's own pprof, registered under the authenticated `authv2` group), which requires credentials — demonstrating the inconsistency confirmed in `core/web/router.go` lines 78-91, 230-236, and 245-248, and in `core/web/loop_registry.go` lines 150-215.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
