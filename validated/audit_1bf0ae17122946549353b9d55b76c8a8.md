## Custody Analog Found: Stale `TombStone` Enables Ownership Hijack on `object::unburn`

### Title
Unauthorized object ownership reassignment via stale `TombStone.original_owner` surviving ungated transfers - (File: `aptos-move/framework/aptos-framework/sources/object.move`)

### Summary
The external report's core custody invariant is: *a stored control/accounting value can update or persist independently of the real underlying state it is supposed to track, letting a party who no longer has a legitimate claim exert control anyway*. In Aptos's `object` module, the `TombStone` resource (used for the "soft burn"/reclaim mechanism) is not cleared when an object is transferred through the ordinary ungated-transfer path (`transfer`, `transfer_call`, `transfer_raw`, `transfer_to_object`). Only the `TransferRef`-based `transfer_with_ref` path clears it. This lets a stale `TombStone` written by a *former* owner survive across one or more legitimate ownership changes, and later be used by that former owner to seize the object away from its current, legitimate owner.

### Finding Description
`object::burn` marks an object as "soft burnt" for indexers without moving ownership, recording the caller as `original_owner` in a `TombStone`: [1](#0-0) 

The only reachable code path that clears a `TombStone` after `burn` other than `unburn` is `transfer_with_ref`: [2](#0-1) 

However, all of the ordinary (ungated) transfer entrypoints — `transfer_call`, `transfer`, `transfer_raw`, `transfer_to_object` — go through `transfer_raw_inner`, which only updates `ObjectCore.owner` and never checks or clears `TombStone`: [3](#0-2) 

Because `burn()` never sets `allow_ungated_transfer = false`, a softly-burnt object remains freely transferable by its current owner using these ungated paths. That means:

1. Owner **A** calls `object::burn`, creating `TombStone { original_owner: A }` while still owning the object.
2. **A** transfers the object (via `transfer`/`transfer_raw`) to owner **B**. `ObjectCore.owner` becomes `B`, but the stale `TombStone { original_owner: A }` is never cleared.
3. At any later point, if **B** (or any subsequent owner) sends the object to the public `BURN_ADDRESS` constant via an ordinary transfer (a common, natural user action for "burning" a token/object), `ObjectCore.owner` becomes `BURN_ADDRESS`.
4. **A** now calls `object::unburn(A, object)`. In `unburn`, the check is purely on `ObjectCore.owner == BURN_ADDRESS` plus `TombStone.original_owner == A` — both true — so `transfer_raw_inner` reassigns ownership back to **A**, the original (and now unrelated/former) owner: [4](#0-3) 

**A** never legitimately owned the object at the time it was sent to `BURN_ADDRESS` — **B** (or a later holder) did — yet **A** recovers full ownership, stealing the object out from under the current/true burner.

### Impact Explanation
This breaks the custody invariant that object ownership transfer/burn must preserve the intended controller. A completely disconnected former owner can reclaim ownership of any object/token-object that passes through the burn address, effectively stealing NFTs, code objects, or any object-held value (including objects holding fungible asset stores) away from their legitimate current owner. This is a direct unauthorized owner-reassignment / theft primitive against any live, mainnet object that uses the standard `object::burn`/`unburn` lifecycle combined with ordinary ungated transfers, which is the default behavior for most objects.

### Likelihood Explanation
No privileged role or admin assumption is required — any object owner can trigger `object::burn` on their own object, then transfer it normally afterward (a completely ordinary, unprivileged action; nothing warns them a stale `TombStone` remains). The victim (a later, unrelated owner) only needs to send the object to the well-known `BURN_ADDRESS` constant via standard ungated transfer, which is a natural, expected user action for permanently destroying an object. No special timing or race condition is needed; the exploit is deterministic and repeatable.

### Recommendation
Clear any pre-existing `TombStone` on ungated transfer just as `transfer_with_ref` already does, i.e., add the same `TombStone` removal logic to `transfer_raw_inner` (or `transfer_raw`) so that a soft-burn marker cannot outlive an ownership change. Alternatively, disallow ordinary ungated transfer of an object while `TombStone` exists (forcing transfer through `unburn` first), so `TombStone.original_owner` can never become stale relative to the current owner.

### Proof of Concept
```
// Setup: Alice creates & owns Object O with allow_ungated_transfer = true (default)

// Step 1: Alice soft-burns while she still owns it
object::burn<T>(&alice, O);
// -> TombStone { original_owner: alice } created; ObjectCore.owner still == alice

// Step 2: Alice legitimately sells/transfers O to Bob via ordinary transfer
object::transfer<T>(&alice, O, bob_addr);
// -> ObjectCore.owner == bob; TombStone { original_owner: alice } still exists (never cleared)

// Step 3: Bob, the real owner, decides to permanently destroy O by sending to the burn address
object::transfer<T>(&bob, O, object::burn_address()); // ordinary ungated transfer
// -> ObjectCore.owner == BURN_ADDRESS

// Step 4: Alice, who no longer has any legitimate claim, reclaims ownership for herself
object::unburn<T>(&alice, O);
// unburn(): object_core.owner == BURN_ADDRESS -> matches branch 2
//           TombStone.original_owner == alice -> assertion passes
//           transfer_raw_inner(O, alice) -> ObjectCore.owner reassigned to alice

// Result: Alice now owns O again, even though Bob was the true, legitimate owner
// who sent it to the burn address; Bob's intended permanent burn (and Bob's asset)
// is stolen by Alice.
``` [5](#0-4)

    /// Transfer to the destination address using a LinearTransferRef.
    public fun transfer_with_ref(self: LinearTransferRef, to: address) {
        assert!(!exists<Untransferable>(self.self), error::permission_denied(EOBJECT_NOT_TRANSFERRABLE));

        // Undo soft burn if present as we don't want the original owner to be able to reclaim by calling unburn later.
        if (exists<TombStone>(self.self)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(self.self);
        };

        let object = borrow_global_mut<ObjectCore>(self.self);
        assert!(
            object.owner == self.owner,
            error::permission_denied(ENOT_OBJECT_OWNER),
        );
        event::emit(
            Transfer {
                object: self.self,
                from: object.owner,
                to,
            },
        );
        object.owner = to;
    }

    inline fun transfer_raw_inner(object: address, to: address) {
        let object_core = borrow_global_mut<ObjectCore>(object);
        if (object_core.owner != to) {
            event::emit(
                Transfer {
                    object,
                    from: object_core.owner,
                    to,
                },

    /// Add a TombStone to the object.  The object will then be interpreted as hidden via indexers.
    /// This only works for objects directly owned and for simplicity does not apply to indirectly owned objects.
    /// Original owners can reclaim burnt objects any time in the future by calling unburn.
    /// Please use the test only [`object::burn_object_with_transfer`] for testing with previously burned objects.
    public entry fun burn<T: key>(owner: &signer, object: Object<T>) {
        let original_owner = signer::address_of(owner);
        assert!(is_owner(object, original_owner), error::permission_denied(ENOT_OBJECT_OWNER));
        let object_addr = object.inner;
        assert!(!exists<TombStone>(object_addr), EOBJECT_ALREADY_BURNT);
        move_to(&create_signer(object_addr), TombStone { original_owner });
    }

    /// Allow origin owners to reclaim any objects they previous burnt.
    public entry fun unburn<T: key>(
        original_owner: &signer,
        object: Object<T>,
    ) {
        let object_addr = object.inner;
        assert!(exists<TombStone>(object_addr), error::invalid_argument(EOBJECT_NOT_BURNT));

        // The new owner of the object can always unburn it, but if it's the burn address, we go to the old functionality
        let object_core = borrow_global<ObjectCore>(object_addr);
        if (object_core.owner == signer::address_of(original_owner)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(object_addr);
        } else if (object_core.owner == BURN_ADDRESS) {
            // The old functionality
            let TombStone { original_owner: original_owner_addr } = move_from<TombStone>(object_addr);
            assert!(
                original_owner_addr == signer::address_of(original_owner),
                error::permission_denied(ENOT_OBJECT_OWNER)
            );
            transfer_raw_inner(object_addr, original_owner_addr);
        } else {
            abort error::permission_denied(ENOT_OBJECT_OWNER);
        };
    }
