### Title
Dogecoin address validation lacks base58check verification, allowing typo'd/corrupted addresses to pass as valid - ([File: packages/intents-sdk/src/lib/validateAddress.ts])

### Summary
`validateDogeAddress` only checks a bare regex `/^[DA][1-9A-HJ-NP-Za-km-z]{25,33}$/` with no base58 checksum verification, unlike every other base58-based chain in the same file (Bitcoin, Litecoin, Tron, Dash all verify `sha256(sha256(payload))` checksum bytes). `OmniBridge.validateWithdrawal` relies on this function as the sole address-format gate before signing a withdrawal intent to Dogecoin.

### Finding Description
The broken equality: "the destination address `validateAddress` approves" should equal "an address that is base58check-valid and therefore corresponds to a derivable Dogecoin key/script." For Dogecoin this equality does not hold, because `validateDogeAddress` (`packages/intents-sdk/src/lib/validateAddress.ts:329-331`) never decodes the base58 payload or verifies its 4-byte checksum, unlike its siblings `validateBtcBase58Address` [1](#0-0) , `validateLitecoinBase58Address` [2](#0-1) , `validateTronBase58Address` [3](#0-2) , and `validateDashAddress` [4](#0-3) , all of which reject an address whose checksum doesn't match.

Call path: `OmniBridge.validateWithdrawal` calls `validateAddress(args.destinationAddress, assetInfo.blockchain)` and only rejects on `false` [5](#0-4) . For Dogecoin, `caip2ToChainKind`/`isUtxoChain` does **not** classify Doge as a UTXO chain (`UTXO_CHAINS = [ChainKind.Btc, ChainKind.Zcash]`) [6](#0-5) , so the additional UTXO-connector safeguards in `validateWithdrawal` (the `omniBridgeAPI.getFee(...)` call and its `insufficient_utxo` / `min_amount` checks) are skipped entirely for Doge withdrawals [7](#0-6) . That means `validateAddress` is the only address-format check exercised on the Doge path. `deriveOmniWithdrawIntentParams` then encodes the unchanged string into `recipient` via `omniAddress(params.omniChainKind, destinationAddress)` with no further checksum validation [8](#0-7) , and this recipient is signed into the withdrawal intent unchanged.

Attacker/user input: any 26–34 character string starting with `D` or `A` using the base58 alphabet — including a real address with one character altered (a typo or single corrupted byte) — passes the regex despite failing checksum verification.

### Impact Explanation
A withdrawal intent gets signed and submitted whose `recipient` field is a syntactically-plausible but checksum-invalid Dogecoin address. Once the UTXO/Doge connector attempts the on-chain payout, the funds are very likely unspendable or unroutable (no key corresponds to a corrupted base58check payload), and — because intents transfers are final once relayed — there is no recovery path. This matches the Critical category: "funds delivered to a wrong address/chain/contract with no recovery." It is repeatable for every Dogecoin withdrawal call, since nothing in the SDK enforces checksum correctness for this specific chain.

### Likelihood Explanation
Preconditions are minimal: the asset must resolve to `Chains.Dogecoin` via `caip2ToChainKind`, and `skipMinAmountValidation` is not required. The caller only needs to supply a string matching the loose regex — trivially producible by flipping one character of a legitimate address (a realistic typo scenario) or by a malicious counterparty supplying such a string as `destinationAddress` in an integrator flow. No special privileges, timing, or race conditions are needed, and the defect is deterministic and always reproducible for Dogecoin destinations, unlike for BTC/LTC/TRON/Dash which correctly reject such inputs.

### Recommendation
Implement full base58check verification for `validateDogeAddress`, mirroring `validateBtcBase58Address`/`validateLitecoinBase58Address`/`validateDashAddress`: decode with `base58.decode`, require a 25-byte payload (1-byte version + 20-byte hash160 + 4-byte checksum), validate the version byte against Dogecoin's mainnet prefixes (`0x1e` for P2PKH `D...`, `0x16` for P2SH `A...`), and verify `sha256(sha256(payload)).subarray(0,4)` matches the trailing checksum bytes before returning `true`.

    expect(validateAddress(corrupted, Chains.Dogecoin)).toBe(true);

function validateBtcBase58Address(address: string): boolean {
	const decoded: Uint8Array = base58.decode(address);

	// version (1) + hash160 (20) + checksum (4) = 25 bytes
	if (decoded.length !== 25) return false;

	const version = decoded[0];
	// 0x00 = P2PKH mainnet, 0x05 = P2SH mainnet
	if (version !== 0x00 && version !== 0x05) return false;

	const payload = decoded.subarray(0, 21);
	const checksum = decoded.subarray(21, 25);
	const expectedChecksum = sha256(sha256(payload)).subarray(0, 4);

	for (let i = 0; i < 4; i++) {
		if (checksum[i] !== expectedChecksum[i]) return false;
	}
	return true;

function validateTronBase58Address(address: string): boolean {
	try {
		const decoded = base58.decode(address);

		if (decoded.length !== 25) return false;

		// The first 21 bytes are the address data, the last 4 bytes are the checksum.
		const data = decoded.slice(0, 21);
		const checksum = decoded.slice(21);

		const expectedChecksum = sha256(sha256(data)).slice(0, 4);
		for (let i = 0; i < 4; i++) {
			if (checksum[i] !== expectedChecksum[i]) return false;
		}

		return data[0] === 0x41;
	} catch {
		return false;
	}
}

function validateLitecoinBase58Address(
	address: string,
	expectedVersion: number,
): boolean {
	let decoded: Uint8Array;

	try {
		decoded = base58.decode(address);
	} catch {
		return false;

	// version (1) + payload (20) + checksum (4)
	if (decoded.length !== 25) return false;

	for (let i = 0; i < 4; i++) {
		if (checksum[i] !== expectedChecksum[i]) return false;
	}

	return true;
}

export function validateDashAddress(address: string): boolean {
	try {
		const decoded: Uint8Array = base58.decode(address);

		// version (1) + payload (20) + checksum (4)
		if (decoded.length !== 25) return false;

		const version = decoded[0];
		if (
			version !== 0x4c && // P2PKH
			version !== 0x10 // P2SH
		) {
			return false;
		}

		const payload = decoded.subarray(0, 21);
		const checksum = decoded.subarray(21, 25);

		const hash1 = sha256(payload);
		const hash2 = sha256(hash1);
		const expectedChecksum = hash2.subarray(0, 4);

		for (let i = 0; i < 4; i++) {
			if (checksum[i] !== expectedChecksum[i]) return false;
		}

		return true;
	} catch {
		return false;
	}
