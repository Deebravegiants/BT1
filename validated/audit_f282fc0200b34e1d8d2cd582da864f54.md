Audit Report

## Title
Unauthenticated LOOP plugin metrics/pprof proxy allows internal service access via `/plugins/:name/...` - (File: core/web/router.go)

## Summary
`loopRoutes` is registered directly on the top-level authenticated-by-default API group in `NewRouter` without any `auth.Authenticate(...)` wrapper, unlike `debugRoutes`, `sessionRoutes`, and `v2Routes` which explicitly gate behind session/token authentication. This lets any unauthenticated network client reach `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol`, which proxy live requests to internal-only LOOP plugin debug/metrics servers.

## Finding Description
`NewRouter` registers `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` in sequence on the same `api` group [1](#0-0) . `debugRoutes` wraps its handler in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` before exposing `/debug/vars` [2](#0-1) , and `sessionRoutes`/`v2Routes` similarly gate sensitive operations behind `auth.Authenticate` [3](#0-2) . In contrast, `loopRoutes` registers `GET /discovery`, `GET /plugins/:name/metrics`, `GET /plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` directly on the passed-in `r` group with no auth middleware at all [4](#0-3) .

`pluginMetricHandler` takes the unauthenticated, user-supplied `:name` path parameter, looks it up in the LOOP registry, and if found, proxies a live HTTP GET to `http://<loopHostName>:<PrometheusPort>/metrics`, returning the raw response body to the caller [5](#0-4) . `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` do the same for `/debug/pprof/*profile` and `/debug/pprof/symbol`, forwarding attacker-controlled query parameters (`debug`, `gc`, `seconds`) and, for the symbol endpoint, the raw POST body, straight to the internal backend [6](#0-5) . The code's own comment ("unlike discovery, this endpoint is internal btw the node and plugin") confirms these were intended to be internal-only, yet they are exposed on the public router with no authentication check.

## Impact Explanation
An unauthenticated client reaching the node's HTTP listener can enumerate registered LOOP plugins via `/discovery` and then pull live pprof profiles (heap, goroutine, profile, trace, allocs, etc.) and Prometheus metrics for any registered plugin process, with no credentials required. pprof/metrics endpoints routinely leak runtime memory contents, internal state, and configuration data, and the `seconds` parameter on `profile`/`trace` can be abused for extended blocking captures. This is a concrete node-API authentication bypass exposing internal diagnostic surface, matching the "node API authentication bypass" impact category.

## Likelihood Explanation
High feasibility for any client with network access to the node's HTTP port — no session, token, or elevated role is needed, and the plugin name is directly attacker-suppliable via the URL and validated only against the live registry, which will contain entries under any normal LOOPP deployment.

## Recommendation
Wrap `loopRoutes` in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or `auth.AuthenticateByToken`) middleware used by `debugRoutes`/`v2Routes`, or move these plugin metrics/pprof proxy endpoints off the public-facing router onto a separate internal-only listener not reachable by external clients.

## Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered.
2. Without any session cookie or Authorization header, send `GET /discovery` — observe the JSON list of registered plugin names and metrics paths.
3. Send `GET /plugins/<name>/metrics` unauthenticated — observe the plugin's internal Prometheus metrics returned.
4. Send `GET /plugins/<name>/debug/pprof/heap?debug=1` unauthenticated — observe a live heap dump forwarded from the plugin's internal debug server, confirming the auth bypass.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
