The reported bug class (bypassing a cool-off/lockup period by transferring a fungible LP token that represents a redeemable claim to a new address) requires a transferable token representing deposited value. In NEAR core-contracts, the closest analog is `staking-pool`'s `stake_shares`/`unstaked` balance, but these are strictly internal accounting fields keyed by `account_id` inside `Account` [1](#0-0)  with no `transfer`/`ft_transfer` method exposed anywhere in `staking-pool/src` [2](#0-1) . All deposit, stake, unstake, and withdraw operations act only on `env::predecessor_account_id()` and the cool-off (`unstaked_available_epoch_height`) is set and checked against that same bound account [3](#0-2) [4](#0-3) , so there is no mechanism to move the underlying claim (shares/unstaked balance) to a different address and thereby reset or evade the unlock timer. `lockup/src` and `multisig/src` similarly have no transferable share/token representing a claim that could be handed off to bypass a timing restriction. Since the root cause in the external report depends on a transferable LP-token abstraction that does not exist in this codebase, there is no reachable analog vulnerability in core-contracts.

    pub(crate) fn internal_withdraw(&mut self, amount: Balance) {
        assert!(amount > 0, "Withdrawal amount should be positive");

        let account_id = env::predecessor_account_id();
        let mut account = self.internal_get_account(&account_id);
        assert!(
            account.unstaked >= amount,
            "Not enough unstaked balance to withdraw"
        );
        assert!(
            account.unstaked_available_epoch_height <= env::epoch_height(),
            "The unstaked balance is not yet available due to unstaking delay"
        );
        account.unstaked -= amount;
        self.internal_save_account(&account_id, &account);

        env::log(
            format!(
                "@{} withdrawing {}. New unstaked balance is {}",
                account_id, amount, account.unstaked
            )
            .as_bytes(),
        );

        Promise::new(account_id).transfer(amount);
        self.last_total_balance -= amount;
    }
