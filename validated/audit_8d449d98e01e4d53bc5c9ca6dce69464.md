### Title
Missing input validation in `EvmHost.dispatch()` allows relayer fees to be permanently frozen for unroutable requests - (File: `evm/src/core/EvmHost.sol`)

### Summary
`EvmHost.dispatch(DispatchPost)` and `EvmHost.dispatch(DispatchGet)` are permissionless, `payable` entry points that collect a relayer fee (native token swapped via Uniswap, or fee-token pulled from the caller) and store a `FeeMetadata` commitment, but perform **no validation** of the caller-supplied `post.dest`, `post.to`, or `post.timeout` fields before doing so. [1](#0-0) 

### Finding Description
`dispatch(DispatchPost memory post)` immediately charges the fee (via Uniswap swap of `msg.value` or `safeTransferFrom` of the fee token), computes `timeoutTimestamp`, hashes the request, and stores `_requestCommitments[commitment] = FeeMetadata({sender: post.payer, fee: post.fee})` — all without ever checking that `post.dest` is one of the whitelisted `_hostParams.stateMachines`, that `post.to` is non-empty, or that `post.timeout` is sane: [2](#0-1) 

The same pattern exists in `dispatch(DispatchGet)`. [3](#0-2) 

Per the protocol's own documentation, `timeout = 0` means the message **never expires** ("ie Messages will never expire"), so the only recovery path for a stuck request is the explicit timeout-proof flow: [4](#0-3) 

That timeout flow, however, is gated on a valid `StateCommitment` existing for the destination state machine at some height (`HandlerV2.handlePostRequestTimeouts` requires `state.stateRoot != 0` and a non-membership proof against that state root): [5](#0-4) 

Because `dispatch()` never checks `post.dest` against the configured `stateMachines` whitelist (`_hostParams.stateMachines`), a caller can dispatch (and pay for) a request whose `dest` is not a real/consensus-verified chain, or whose `to`/`body` is malformed such that no honest relayer will ever deliver it. If such a request is also created with `timeout = 0` (documented as the "no timeout" default), there is no state commitment that will ever exist for that destination, so the timeout-recovery path in `HandlerV2` can never be satisfied either — the escrowed relayer fee becomes permanently unrecoverable in the host contract.

This is directly analogous to the referenced Sherlock finding: a fee-charging, request-creating entry point accepts attacker/user-controlled parameters with no sanity checks on the destination/timeout, so mistaken or malicious inputs are charged and silently accepted rather than reverted.

### Impact Explanation
Relayer fees paid via `dispatch()` for a request with an invalid/unsupported `dest` and `timeout = 0` are permanently locked in the `EvmHost` contract: the message can never be delivered (no relayer/consensus client exists for a bogus destination) and can never be timed out (no `StateCommitment` will ever be produced for that destination, so `handlePostRequestTimeouts` cannot process it). This is a permanent freezing-of-funds condition, satisfying the Medium/High impact bar (concrete freezing of relayer-fee funds, and a route that is structurally unable to deliver or refund messages).

### Likelihood Explanation
`dispatch()` is a fully permissionless, externally callable function reachable by any EOA or integrating contract (including third-party `IApp` implementations built on `HyperApp`/`IntentGatewayV2`/`WrappedHyperFungibleTokenUpgradeable`, all of which forward user-controlled `dest`/`timeout` values into `DispatchPost`/`DispatchGet` without re-validating them against the host's supported chain list). A single mistaken transaction (typo'd `StateMachine` id, wrong chain enum, or `timeout=0` combined with a decommissioned/unsupported destination) is sufficient to trigger the freeze — no privileged actor or complex multi-step attack is required.

### Recommendation
In `EvmHost.dispatch(DispatchPost)` and `dispatch(DispatchGet)`, validate `post.dest`/`get.dest` against the configured `_hostParams.stateMachines` (and `hyperbridge()`), reject empty `to`/`body` where required, and consider disallowing `timeout == 0` requests whose destination is not currently in the supported-state-machines list, reverting with a clear error (e.g. `UnsupportedStateMachine()`) rather than silently accepting payment and storing an unroutable commitment.

### Proof of Concept
1. Caller invokes `EvmHost.dispatch(DispatchPost({dest: <bytes for an unsupported/nonexistent state machine>, to: ..., body: ..., timeout: 0, fee: X, payer: msg.sender}))` with `msg.value` sufficient to cover fee `X`. [6](#0-5) 
2. The host swaps/collects the fee `X` and stores `_requestCommitments[commitment] = FeeMetadata({sender: post.payer, fee: X})`, with `timeoutTimestamp = 0` since `post.timeout == 0`. [7](#0-6) 
3. No relayer can ever deliver the request (destination is not a real consensus-verified chain), and `HandlerV2.handlePostRequestTimeouts` can never succeed because `host.stateMachineCommitment(message.height)` will never be populated for that destination (`state.stateRoot == bytes32(0)` reverts with `StateCommitmentNotFound`). [8](#0-7) 
4. The fee `X` remains locked in `EvmHost` indefinitely, with no code path to refund `post.payer`.

    function dispatch(DispatchPost memory post) external payable notFrozen returns (bytes32 commitment) {
        if (msg.value > 0) {
            address[] memory path = new address[](2);
            address uniswapV2 = _hostParams.uniswapV2;
            path[0] = IUniswapV2Router02(uniswapV2).WETH();
            path[1] = feeToken();
            IUniswapV2Router02(uniswapV2).swapETHForExactTokens{value: msg.value}(
                post.fee, path, address(this), block.timestamp
            );
        } else if (post.fee > 0) {
            IERC20(feeToken()).safeTransferFrom(_msgSender(), address(this), post.fee);
        }

        // adjust the timeout
        uint64 timeoutTimestamp = post.timeout == 0 ? 0 : uint64(block.timestamp) + uint64(post.timeout);
        PostRequest memory request = PostRequest({
            source: host(),
            dest: post.dest,
            nonce: uint64(_nextNonce()),
            from: abi.encodePacked(_msgSender()),
            to: post.to,
            timeoutTimestamp: timeoutTimestamp,
            body: post.body
        });

        // make the commitment
        commitment = request.hash();
        _requestCommitments[commitment] = FeeMetadata({sender: post.payer, fee: post.fee});
        emit PostRequestEvent({
            source: string(request.source),
            dest: string(request.dest),
            from: _msgSender(),
            to: abi.encodePacked(request.to),
            nonce: request.nonce,
            timeoutTimestamp: request.timeoutTimestamp,
            body: request.body,
            fee: post.fee
        });
    }

    function handlePostRequestTimeouts(IHost host, PostRequestTimeoutMessage calldata message)
        external
        notFrozen(host)
    {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            PostRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            // known request? also serves as source check
            bytes32 requestCommitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(requestCommitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(REQUEST_RECEIPTS_STORAGE_PREFIX, requestCommitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(PostRequestTimeout(request, _msgSender()), meta, requestCommitment);
