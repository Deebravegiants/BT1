### Title
Unauthenticated `magic_action` QR codes let any bystander force WiFi reset or mirror recalibration - (`src/plans/mod.rs`)

### Summary
The operator QR-code parser (`qr_scan::operator::Data::try_parse` in `src/plans/qr_scan/operator.rs`) recognizes plain, undocumented-but-public `magic_action:reset_wifi_credentials` / `magic_action:reset_mirror_calibration` strings and turns them into `Data::MagicResetWifi` / `Data::MagicResetMirror`. `MasterPlan::handle_magic_operator_qr_code` executes `network::reset()` or `reset_mirror_calibration()` immediately upon seeing these variants, *before* any backend/operator authentication (`verify_operator_qr_code`) is performed. Since operator-code scanning happens continuously while the orb is idle (`scan_initial_qr_codes`) and again at the start of every signup attempt (`scan_remaining_qr_codes`), any unprivileged person able to present a QR code to the camera can trigger these privileged actions.

### Finding Description
`qr_scan::operator::Data::try_parse` first tries to parse the code as a normal signed/backend-verifiable operator QR, and if that fails, matches it against the static regex `MAGIC_QR_CODE` (`^magic_action:(?P<magic_action>[\w]+)$`), producing `Data::MagicResetWifi` or `Data::MagicResetMirror` for the two recognized action strings [1](#0-0) .

These variants are consumed by `handle_magic_operator_qr_code`, which is called directly after `scan_operator_qr_code` returns, in both `scan_initial_qr_codes` (continuous idle scanning in self-serve mode, i.e. before any button press or signup session) and `scan_remaining_qr_codes` (start of every signup attempt) [2](#0-1) [3](#0-2) .

`handle_magic_operator_qr_code` executes the privileged action unconditionally, with no backend call and no check of who scanned it - the only gate is `verify_operator_qr_code`, which is invoked strictly *after* this function returns, so it is never reached for magic codes: [4](#0-3) 

`reset_mirror_calibration` re-enables/recalibrates the mirror motors, and `reset_wifi_and_ensure_network` calls `network::reset()` (which runs `wpa-supplicant-interface restore-default-config` + `reconfigure`, wiping the current WiFi configuration and disconnecting the device) followed by a blocking wait for a new WiFi QR-code scan: [5](#0-4) [6](#0-5) 

There is no `#[cfg(...)]` gate, feature flag, or authentication step protecting the `MagicResetWifi`/`MagicResetMirror` branches - they are compiled and reachable unconditionally in production, unlike the CLI-only `operator_qr_code_override` path which is only usable via test/CLI builders.

### Impact Explanation
Any person able to show a piece of paper or phone screen with `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration` to the Orb's camera - during idle scanning or at the very start of any signup attempt - can:
- Force `network::reset()`, wiping the WiFi configuration and disconnecting the Orb from its network. Reconnection requires a legitimate operator to re-scan a WiFi-credential QR code, so this is a persistent denial-of-service against the physical unit until manually remediated.
- Force a mirror recalibration cycle, which moves mirror hardware and disrupts/delays the scanning pipeline for any nearby legitimate user.

Both effects wedge/restart the idle→signup state machine for the physical Orb, denying service to legitimate users queued for signup, matching the "signup-state wedge" / availability-impact category. This requires no operator credentials, tokens, or backend interaction.

### Likelihood Explanation
Feasibility is high: the magic strings are fixed, publicly discoverable (present in the open-source repository, `src/plans/qr_scan/operator.rs`), require no cryptographic material, and can be rendered as a static QR code by anyone. The vulnerable scan points (idle scanning in self-serve mode, and the operator-scan step at the start of every signup) are reachable by any bystander with camera line-of-sight, repeatedly and at will, with no rate limiting beyond normal QR retry/backoff.

### Recommendation
Gate the `MagicResetWifi`/`MagicResetMirror` actions behind actual operator authentication - e.g. only accept them when they are embedded inside (or immediately following) a backend-validated operator QR-code, or require a signed/HMAC'd magic payload verified against a backend/operator secret before executing `network::reset()` or `reset_mirror_calibration()`. Alternatively, restrict recognition of `magic_action:*` codes to builds/configurations explicitly enabled for field technicians (e.g. a dedicated maintenance mode requiring physical/hardware confirmation), rather than unconditionally in the standard signup/idle QR-scanning path.

### Proof of Concept
Integration test in `src/plans/mod.rs` (mirroring the existing `handle_magic_operator_qr_code` test usage pattern):
1. Build a `MasterPlan` with `operator_qr_code_override` unset, using the fake `qr_code` agent port to inject the string `"magic_action:reset_wifi_credentials"`.
2. Call `scan_operator_qr_code` then `handle_magic_operator_qr_code` without any operator session or prior authentication established (fresh `Orb`, no signup in progress, no button press).
3. Assert that `network::reset()` (or a mock/spy on `MasterPlan::reset_wifi_and_ensure_network`) is invoked and returns `Ok(None)` from `handle_magic_operator_qr_code`, confirming the action executed purely from the QR content with zero authorization checks.
4. Repeat with `"magic_action:reset_mirror_calibration"` asserting `reset_mirror_calibration` (mirror enable/recalibrate/disable sequence) is invoked under the same unauthenticated conditions.

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    /// Resets the mirror calibration.
    pub async fn reset_mirror_calibration(&self, orb: &mut Orb) -> Result<()> {
        let calibration: Calibration = (&*orb.config.lock().await).into();
        calibration.store(CALIBRATION_FILE_PATH).await?;
        orb.enable_mirror()?;
        orb.recalibrate(calibration).await?;
        orb.disable_mirror();
        Ok(())
    }

    /// Resets the network and requests a new one.
    pub async fn reset_wifi_and_ensure_network(&self, orb: &mut Orb) -> Result<()> {
        network::reset().await?;
        wifi::Plan.ensure_network_connection(orb).await?;
        orb.reset_rgb_camera().await?;
        Ok(())
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
