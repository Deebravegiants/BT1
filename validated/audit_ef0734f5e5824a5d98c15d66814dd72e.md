### Title
Owner can frontrun `send()` calls by instantly changing relayer fees with no timelock - ([File: sdk/packages/lz-endpoint/contracts/HyperbridgeLzEndpoint.sol])

### Summary
`HyperbridgeLzEndpoint` exposes `setRelayerFee(dstEid, fee)` and `setDefaultRelayerFee(fee)` as plain `onlyOwner` setters that take effect immediately, with no timelock, no bounds check relative to the previous value, and no per-call fee cap for the caller.

### Finding Description
`setRelayerFee` and `setDefaultRelayerFee` update `_relayerFees[dstEid]` / `_defaultRelayerFee` synchronously and are read by `relayerFee(dstEid)`, which falls back to the default when no per-destination override exists: [1](#0-0) 

These values are consumed by the endpoint's `send()` path when computing the relayer fee an unprivileged caller (any OApp/message dispatcher using the LayerZero-compatible endpoint) must pay to dispatch a cross-chain message through ISMP. Because the setter is a single `onlyOwner` call with immediate effect and no timelock, the owner can observe a pending `send()` transaction in the mempool and frontrun it with a `setRelayerFee`/`setDefaultRelayerFee` call that raises the fee arbitrarily before the user's transaction is mined — the same pattern as the reported `OptionsConfig.setMinFee` frontrunning issue (immediate, unbounded, timelock-free fee parameter change reachable by a privileged single-key owner right before an unprivileged user's fee-paying transaction executes).

### Impact Explanation
A user dispatching a message via `send()` expects to pay the fee quoted/observed at submission time. If the owner frontruns with a higher `_relayerFees[dstEid]`/`_defaultRelayerFee` value, the user's transaction either (a) pays a much higher fee than expected if fees are pulled from the fee token balance/allowance, or (b) reverts due to insufficient `msg.value`, wasting gas and forcing a resubmission at the new, possibly inflated, price. For high-value or high-frequency dispatchers this is a direct, repeatable value-extraction vector with no economic bound (fee can be set to any `uint256`).

### Likelihood Explanation
Likelihood is limited by the fact that this requires the endpoint owner to actively monitor the mempool and act each time — it is a privileged single-key action, not something an ordinary attacker can trigger, and does not require malicious governance/consensus compromise (it is a single onlyOwner call, not a cross-chain governance action). This mirrors exactly the "Medium" severity classification of the original report, which also concerned a single `onlyOwner` setter with no timelock.

### Recommendation
Introduce a timelock or delayed-activation mechanism for `setRelayerFee`/`setDefaultRelayerFee` (e.g., a minimum delay between fee change proposal and effect), and/or allow callers of `send()` to specify a maximum acceptable fee that causes the call to revert if the on-chain fee exceeds it at execution time, protecting users from unexpected fee spikes.

### Proof of Concept
1. Owner observes a pending `send()` call from an unprivileged OApp targeting `dstEid = X`, expecting `relayerFee(X)` = current low value.
2. Owner submits `setRelayerFee(X, veryHighFee)` with higher gas price so it lands first. [2](#0-1) 
3. The pending `send()` transaction now executes against the inflated fee, causing the caller to overpay (if paying from token balance) or revert (if `msg.value` was sized for the old fee).

```text
    /**
     * @notice Sets the relayer fee for a specific destination chain
     * @param dstEid The destination endpoint ID
     * @param fee The relayer fee in feeToken units
     */
    function setRelayerFee(uint32 dstEid, uint256 fee) external onlyOwner {
        _relayerFees[dstEid] = fee;
    }

    /**
     * @notice Sets the default relayer fee used when no per-destination fee is configured
     * @param fee The default relayer fee in feeToken units
     */
    function setDefaultRelayerFee(uint256 fee) external onlyOwner {
        _defaultRelayerFee = fee;
    }

    /**
     * @notice Returns the relayer fee for a destination, falling back to the default
     * @param dstEid The destination endpoint ID
     */
    function relayerFee(uint32 dstEid) public view returns (uint256) {
        uint256 fee = _relayerFees[dstEid];
        return fee > 0 ? fee : _defaultRelayerFee;
    }
```
