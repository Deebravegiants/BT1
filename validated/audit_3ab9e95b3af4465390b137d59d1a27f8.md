Audit Report

## Title
Unauthenticated disclosure of plugin memory/profiling statistics via `/plugins/:name/debug/pprof/*` and `/plugins/:name/metrics` routes - (File: `core/web/router.go`)

## Summary
`NewRouter` in `core/web/router.go` registers `loopRoutes` directly on the base `api` route group, which only applies rate-limiting and session-cookie middleware — no authentication is enforced on `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, or `/plugins/:name/debug/pprof/symbol`. This is inconsistent with every other sensitive route family (`debugRoutes`, `authv2`/`metricRoutes`), which are explicitly wrapped in `auth.Authenticate(...)`.

## Finding Description
`NewRouter` builds the `api` group with only rate limiting and session middleware and then calls `loopRoutes(app, api)` alongside `debugRoutes`, `v2Routes`, etc: [1](#0-0) . `loopRoutes` registers its endpoints with zero auth middleware: [2](#0-1) . This is inconsistent with `debugRoutes`, which wraps `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`: [3](#0-2) , and with `metricRoutes` (the node's own pprof), which is only mounted inside the already-authenticated `authv2` group: [4](#0-3) . The handler forwards the caller-supplied `profile` path parameter and query values straight to the internal LOOP plugin process with no authorization check: [5](#0-4) .

## Impact Explanation
Any client that can reach the node's HTTP API (which the report characterizes, and is generally treated, as internet-facing since it hosts the operator UI/API on the configured `HTTPPort`) can retrieve heap, goroutine, allocation, and other pprof profiles, as well as Prometheus metrics, for every registered LOOP plugin without any session, API token, or role — this is an information-disclosure vulnerability (memory contents, goroutine stacks, internal state) with no authentication bypass of write/state-changing operations, matching the confidentiality-only nature described.

## Likelihood Explanation
High: the routes are unconditionally registered whenever LOOP plugins are present, require no special network position beyond reaching the node's web server, and need no credentials, matching how any of the node's other unauthenticated routes (e.g., `/health`, `/readyz`) are reachable.

## Recommendation
Wrap `loopRoutes(app, api)` with the same authentication middleware used elsewhere (`auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`), or move the `/plugins/:name/metrics` and `/plugins/:name/debug/pprof/*` endpoints into the `authv2` group alongside `metricRoutes`, while keeping `/discovery` accessible only to the internal Prometheus scraper if it must remain unauthenticated.

## Proof of Concept
Against a running node with at least one LOOP plugin registered, send:
```
GET /plugins/<registered-plugin-name>/debug/pprof/heap HTTP/1.1
Host: <node-host>:<port>
```
No `Cookie`, `X-API-KEY`/`X-API-SECRET`, or session token is required. The request reaches `pluginPPROFHandler` in `core/web/loop_registry.go`, is forwarded to the internal LOOP process's `/debug/pprof/heap` endpoint, and the raw profile bytes are returned in the response body. A Go integration test can be constructed by building the router via `NewRouter` with a mock `chainlink.Application`/`LoopRegistry` containing a registered plugin, issuing an unauthenticated `httptest` request to `/plugins/<name>/debug/pprof/heap`, and asserting a `200 OK` with non-empty profile data is returned.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
