Audit Report

## Title
CORS origin allowlist bypass via improper wildcard/suffix hostname matching - (File: core/services/gateway/network/httpserver.go)

## Summary
The Gateway's `isAllowedOrigin` function performs an unanchored `strings.HasSuffix` comparison when matching wildcard CORS allowlist entries, without verifying a domain-label (`.`) boundary. This allows an attacker who controls a domain that merely ends with the configured allowed suffix (e.g., `evilremix.com` against an allowlist of `*.remix.com`) to have their Origin treated as trusted, causing the Gateway to reflect it back in `Access-Control-Allow-Origin`.

## Finding Description
`splitURL` extracts scheme/host/port from the raw Origin header and each configured allowlist entry using `url.Parse`/`net.SplitHostPort` [1](#0-0) . `isAllowedOrigin` then compares scheme and port exactly, does an exact host match, and for entries beginning with `*.` strips the prefix and performs `strings.HasSuffix(originHost, allowedHost)` with no check that the preceding character in `originHost` is a `.` [2](#0-1) . Consequently, for an allowlist entry `*.remix.com` (`allowedHost = "remix.com"`), an Origin of `https://evilremix.com` satisfies `strings.HasSuffix("evilremix.com", "remix.com") == true` and is wrongly treated as an authorized subdomain. `handleRequest` then reflects the raw, attacker-controlled Origin header value into `Access-Control-Allow-Origin` along with permissive `Access-Control-Allow-Methods`/`-Headers` [3](#0-2) . There is no other origin-boundary check, canonicalization, or PSL-based validation anywhere in the file that would catch this.

## Impact Explanation
This is a concrete gateway request/response impersonation vector: a page served from an attacker-registered domain ending in the allowed suffix can issue cross-origin `fetch`/XHR calls to the Gateway and receive a spoofed trusted `Access-Control-Allow-Origin`, letting the attacker's page read authenticated/credentialed Gateway responses in a victim's browser. This maps to the in-scope "gateway request impersonation / cross-user response corruption" impact category.

## Likelihood Explanation
Exploitation requires only that the Gateway operator enable CORS with a wildcard entry in `CORSAllowedOrigins` [4](#0-3)  — a supported, documented configuration option (used in sample configs) rather than a misuse of the feature — and that the attacker register/control any domain literally ending in the allowed suffix. No authentication or special network position is needed, making this feasible and repeatable for an unprivileged actor.

## Recommendation
Enforce a proper subdomain boundary in the wildcard branch, e.g. replace the bare suffix check with `originHost == allowedHost || strings.HasSuffix(originHost, "."+allowedHost)` in `isAllowedOrigin` at core/services/gateway/network/httpserver.go:187.

## Proof of Concept
1. Start the Gateway HTTP server with `CORSEnabled: true` and `CORSAllowedOrigins: []string{"https://*.remix.com"}` (mirrors the pattern used in existing tests such as `TestHTTPServer_HandleRequest_CORSEnabled_FromAllowedOriginWildcards` in `core/services/gateway/network/httpserver_test.go`).
2. Send a POST request to the Gateway path with header `Origin: https://evilremix.com`.
3. Observe the response contains `Access-Control-Allow-Origin: https://evilremix.com`, `Access-Control-Allow-Methods: GET, POST, OPTIONS`, and `Access-Control-Allow-Headers: Content-Type`, confirming the untrusted origin was accepted — this can be added as a Go test analogous to `TestHTTPServer_HandleRequest_CORSEnabled_FromNotAllowedOriginWildcards` but asserting the headers ARE present (proving the bypass) rather than absent.

func (s *httpServer) splitURL(rawURL string) (string, string, string, error) {
	// lowercase the URL to avoid case sensitivity issues
	parsedURL, err := url.Parse(strings.ToLower(rawURL))
	if err != nil {
		return "", "", "", fmt.Errorf("error parsing URL: %w", err)
	}

	host, port, err := net.SplitHostPort(parsedURL.Host)
	if err != nil {
		// if there's no port, the host itself is returned
		if parsedURL.Host != "" {
			return parsedURL.Scheme, parsedURL.Host, "", nil
		}
		return "", "", "", fmt.Errorf("error splitting host and port: %w", err)
	}

	return parsedURL.Scheme, host, port, nil
}
