**Rationale:**

The `CurrentTimeMicroseconds` struct in `types/src/on_chain_config/timestamp.rs` is a pure Rust deserialization mirror of the on-chain resource — it has no write logic and cannot itself be "submitted" by an attacker. [1](#0-0) 

The only code path that mutates the actual on-chain `CurrentTimeMicroseconds` resource is `aptos_framework::timestamp::update_global_time`, which is gated by `system_addresses::assert_vm(account)` and enforces strict monotonicity (`assert!(now < timestamp, ...)`) for any non-NIL proposer. [2](#0-1) 

This function is only invoked by the AptosVM itself during block-prologue execution (not by any unprivileged entry function, transaction, view, authenticator, API, or bytecode path reachable by a normal user), as documented in the block-metadata prologue flow used by the simulation session. [3](#0-2) 

The Move formal spec further codifies this as a high-level requirement: the clock can only advance, and only the VM account can call `update_global_time`. [4](#0-3) 

`vesting.move`'s cliff-unlock check (`vest`) reads the time via `timestamp::now_seconds()`, which simply returns the stored `microseconds` field — it does not accept an externally supplied `CurrentTimeMicroseconds` value from any caller. [5](#0-4) 

Since there is no unprivileged entrypoint (transaction, package init, view function, API endpoint, or bytecode) that can write a decreasing value into `CurrentTimeMicroseconds` — the only writer is VM-only and enforces strict monotonicity — an attacker cannot reach the vesting cliff check with a rolled-back timestamp. Achieving a decreasing timestamp would require compromising consensus/block-proposer behavior, which is explicitly excluded from this review's scope ("Ignore malicious peer or node behavior"). No custody boundary is crossed by unprivileged input.

    /// Updates the wall clock time by consensus. Requires VM privilege and will be invoked during block prologue.
    public fun update_global_time(
        account: &signer,
        proposer: address,
        timestamp: u64
    ) acquires CurrentTimeMicroseconds {
        // Can only be invoked by AptosVM signer.
        system_addresses::assert_vm(account);

        let global_timer = borrow_global_mut<CurrentTimeMicroseconds>(@aptos_framework);
        let now = global_timer.microseconds;
        if (proposer == @vm_reserved) {
            // NIL block with null address as proposer. Timestamp must be equal.
            assert!(now == timestamp, error::invalid_argument(EINVALID_TIMESTAMP));
        } else {
            // Normal block. Time must advance
            assert!(now < timestamp, error::invalid_argument(EINVALID_TIMESTAMP));
            global_timer.microseconds = timestamp;
        };
    }
