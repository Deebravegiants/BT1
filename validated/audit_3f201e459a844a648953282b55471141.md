Audit Report

## Title
Unauthenticated `/discovery`, `/plugins/:name/metrics`, and `/plugins/:name/debug/pprof/*` routes expose internal LOOP plugin pprof/metrics data - ([File: core/web/router.go])

## Summary
`loopRoutes(app, api)` in `core/web/router.go` is registered directly on the base `api` router group, which only applies rate-limiting and cookie-session middleware, not authentication. This lets any network client reach the LOOP plugin discovery, Prometheus metrics, and full `net/http/pprof` proxy endpoints without any credentials.

## Finding Description
`NewRouter` builds the base `api` group with only `rateLimiter` and `sessions.Sessions` middleware attached — no `auth.Authenticate(...)` call: [1](#0-0) 

`loopRoutes` is called directly on this unauthenticated group and registers all its handlers without any per-route or per-group auth wrapper: [2](#0-1) 

By contrast, the sibling `debugRoutes` group (also exposing `expvar`) is explicitly wrapped with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`: [3](#0-2) , and the analogous `metricRoutes` (which exposes the standard `net/http/pprof` handlers for the node itself) is only invoked *inside* the authenticated `authv2` group: [4](#0-3) [5](#0-4) 

This shows the `loopRoutes` omission is a scoped inconsistency rather than an intentional design choice — every other route exposing pprof/debug-level data in this file is gated behind session or token authentication, while `loopRoutes` is not.

The handlers themselves proxy live requests to the LOOP plugin's internal HTTP server and stream back raw pprof profiling data (`heap`, `goroutine`, `profile`, `trace`, `cmdline`, `symbol`) and Prometheus metrics text, with no auth check performed inside the handlers either: [6](#0-5) [7](#0-6) 

## Impact Explanation
An unauthenticated network client reaching the node's API port can pull heap dumps and goroutine stack traces of the LOOP plugin process via `/plugins/:name/debug/pprof/heap` and `/goroutine`, which can leak secrets resident in process memory. It can also trigger CPU-intensive `/debug/pprof/profile` and `/trace` captures on-demand, and enumerate internal plugin topology via `/discovery` and `/plugins/:name/metrics`. This falls into the key/secret disclosure and unauthorized information-exposure impact classes recognized as in-scope for the Chainlink node API.

## Likelihood Explanation
No credentials, session cookie, or API token are required — any client capable of reaching the node's HTTP API (the same precondition as reaching any other authenticated `/v2` route) can issue these requests directly and repeatedly, since the `api` group itself carries no authentication middleware and `loopRoutes` adds none.

## Recommendation
Wrap `loopRoutes(app, api)` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `authv2`/`metricRoutes`, or move the route registration onto the authenticated `authv2` group, consistent with how `metricRoutes` is already gated at `core/web/router.go:446`.

## Proof of Concept
Against a running Chainlink node with a LOOP plugin registered, an unauthenticated client can issue, with no `Authorization` header or session cookie:
```
curl -i http://<node-host>:<port>/discovery
curl -i http://<node-host>:<port>/plugins/<plugin-name>/metrics
curl -i http://<node-host>:<port>/plugins/<plugin-name>/debug/pprof/heap
```
All three succeed because `loopRoutes` (registered on the unauthenticated `api` group at `core/web/router.go:91`) applies no authentication middleware, unlike the sibling `authv2`/`debugRoutes` groups.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
