## Analog Found

### Title
Protocol pause on `HyperbridgeLzEndpoint` can be bypassed via permissionless `retryPayload` - (File: sdk/packages/lz-endpoint/contracts/HyperbridgeLzEndpoint.sol)

### Summary
`HyperbridgeLzEndpoint` gates message delivery to destination OApps through `onAccept`, which enforces `whenNotPaused` before calling `lzReceive` on the receiver. However, the contract also exposes a second, fully permissionless entrypoint — `retryPayload` — that performs the exact same privileged action (calling `lzReceive` on the destination OApp) without any pause check, allowing anyone to bypass an owner-initiated pause.

### Finding Description
`onAccept` is the intended ISMP delivery path for LayerZero-routed cross-chain messages. It is protected by `onlyHost` and `whenNotPaused`, and on success calls `ILayerZeroReceiver(receiverAddr).lzReceive(...)`. If that call reverts, the payload hash is cached in `_inboundPayloadHashes` for later recovery. [1](#0-0) 

The recovery function `retryPayload` re-executes that same delivery (`lzReceive`) for any previously-stored payload, but is declared without `whenNotPaused` and is explicitly documented as "Permissionless: anyone may push a stuck payload through": [2](#0-1) 

Because a stuck/cached payload only needs to have previously reverted once inside `onAccept` (e.g., due to a transient revert unrelated to the pause state — insufficient gas, temporary receiver-side check, etc.) before the owner pauses the endpoint, any address can later call `retryPayload` while the endpoint is paused and force delivery of that message to the destination OApp, exactly mirroring the "router pause bypassed by calling the core contract directly" pattern from the referenced ArrakisV2Router/ArrakisV2 report — here the "router" is `onAccept` (paused) and the "core" bypass path is `retryPayload` (unpaused).

The pause mechanism itself is defined via OpenZeppelin `Pausable`: [3](#0-2) 

`lzCompose` (execution of queued compose messages) is similarly missing any pause check, compounding the same class of bypass for composed message execution: [4](#0-3) 

### Impact Explanation
When the endpoint owner pauses the contract (e.g., during an active incident, discovered vulnerability in a connected OApp, or a compromised source chain), the intent is to halt all inbound message delivery to protect downstream OApps (OFTs, bridges, etc.) that rely on `lzReceive`. `retryPayload` lets an unprivileged caller continue delivering previously-failed messages during the pause window, defeating the emergency stop and potentially allowing malicious or unwanted mints/transfers/state changes in the receiving OApp to proceed despite the pause. This is a High-severity control bypass affecting the core promise of the pause mechanism for any OApp relying on it, including token bridges built on top of this endpoint.

### Likelihood Explanation
Exploitation only requires: (1) a message that previously failed `lzReceive` inside `onAccept` for any reason (common in practice — gas griefing, temporary receiver reverts, reentrancy guards, etc.) prior to pause, and (2) a permissionless call to `retryPayload` while paused. No special privileges, proofs, or timing constraints beyond having a stored payload hash are needed, making this trivially reachable by any address, including a malicious relayer or bystander.

### Recommendation
Add the `whenNotPaused` modifier to `retryPayload` (and to `lzCompose`), so that all paths which invoke `lzReceive`/`lzCompose` on downstream OApps are consistently gated by the same pause state as `onAccept`.

### Proof of Concept
1. A message `M` (guid `g`, nonce `n`, from `sender` to `receiver`) is submitted via ISMP, `onAccept` is called by the host, and `ILayerZeroReceiver(receiver).lzReceive(...)` reverts (e.g., a transient revert), so the payload hash is stored in `_inboundPayloadHashes[receiver][srcEid][sender][n]` and `InboundPayloadStored` is emitted (`HyperbridgeLzEndpoint.sol:389-395`).
2. Endpoint owner detects an incident and calls `pause()` (`HyperbridgeLzEndpoint.sol:247-249`), setting `_paused = true`.
3. Any unprivileged address (attacker) calls `retryPayload(receiver, origin, g, message)` (`HyperbridgeLzEndpoint.sol:416-433`). Since this function lacks `whenNotPaused`, the call succeeds even though the endpoint is paused, and `ILayerZeroReceiver(receiver).lzReceive(...)` executes, delivering the message and triggering whatever state change (e.g., token mint in a connected OFT) the pause was meant to prevent.

```text
    function onAccept(IncomingPostRequest calldata incoming) external override onlyHost whenNotPaused {
        PostRequest calldata request = incoming.request;

        // Verify source is this adapter on another chain
        if (keccak256(request.from) != keccak256(abi.encodePacked(address(this)))) revert UnknownSource();

        // Decode the LZ message from the ISMP body
        (
            bytes32 guid,
            uint32 srcEid,
            bytes32 sender,
            uint64 nonce,
            bytes32 receiver,
            bytes memory message
        ) = abi.decode(request.body, (bytes32, uint32, bytes32, uint64, bytes32, bytes));

        // Reject `expectedEid == 0` so unconfigured sources don't collide with `srcEid = 0`.
        uint32 expectedEid = _stateMachineToEid[keccak256(request.source)];
        if (expectedEid == 0 || expectedEid != srcEid) revert UnknownSource();

        // Validate and advance the nonce. The nonce is committed BEFORE (and independently of)
        // OApp execution: a reverting `lzReceive` must not roll back this write. Otherwise the
        // message would be retried forever at the same nonce and every later nonce would be
        // permanently rejected, bricking the (receiver, srcEid, sender) channel.
        address receiverAddr = address(uint160(uint256(receiver)));
        uint64 expectedNonce = _inboundNonce[receiverAddr][srcEid][sender] + 1;
        if (nonce != expectedNonce) revert InvalidNonce(expectedNonce, nonce);
        _inboundNonce[receiverAddr][srcEid][sender] = nonce;

        // Deliver to the OApp. Isolate the external call so a deterministic revert (zero
        // recipient, over-cap mint, blocklisted recipient, malformed payload, paused OApp, etc.)
        // does not revert `onAccept`. On failure the payload is retained for later retry/recovery
        // via retryPayload/clear/skip/nilify/burn.
        Origin memory origin = Origin({srcEid: srcEid, sender: sender, nonce: nonce});
        try ILayerZeroReceiver(receiverAddr).lzReceive(origin, guid, message, address(0), "") {
            // delivered successfully
        } catch {
            bytes32 payloadHash = keccak256(abi.encode(guid, message));
            _inboundPayloadHashes[receiverAddr][srcEid][sender][nonce] = payloadHash;
            emit InboundPayloadStored(receiverAddr, srcEid, sender, nonce, payloadHash);
        }
    }
```

```text
    /**
     * @notice Retries an inbound delivery whose OApp `lzReceive` previously reverted in {onAccept}.
     * @dev Mirrors {onAccept}'s direct call to the OApp (the adapter is the caller, so the OApp's
     * `onlyEndpoint` check still passes). Permissionless: anyone may push a stuck payload through
     * once it is executable again. On success the stored payload hash is cleared; if delivery
     * reverts again the whole call reverts and the payload remains recoverable.
     * @param receiver The destination OApp
     * @param origin The (srcEid, sender, nonce) of the stored payload
     * @param guid The original message guid
     * @param message The original message payload (must match the stored hash)
     */
    function retryPayload(
        address receiver,
        Origin calldata origin,
        bytes32 guid,
        bytes calldata message
    ) external payable {
        bytes32 stored = _inboundPayloadHashes[receiver][origin.srcEid][origin.sender][origin.nonce];
        if (stored == bytes32(0) || stored == NIL_PAYLOAD_HASH || stored != keccak256(abi.encode(guid, message))) {
            revert InvalidPayloadHash();
        }

        // Clear first; if the retry reverts, this deletion rolls back with the rest of the tx and
        // the payload remains recoverable.
        delete _inboundPayloadHashes[receiver][origin.srcEid][origin.sender][origin.nonce];

        ILayerZeroReceiver(receiver).lzReceive{value: msg.value}(origin, guid, message, msg.sender, "");
        emit InboundPayloadResolved(receiver, origin.srcEid, origin.sender, origin.nonce);
    }
```
