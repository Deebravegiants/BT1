### Title
Relayer can sweep an entire backlog of consensus rewards in one message after `cost_per_block` is paused and re-enabled - (File: `modules/pallets/consensus-incentives/src/impls.rs`)

### Summary
`pallet-consensus-incentives` only advances its `LastRewardedHeight` watermark when a *non-zero* reward is actually paid out. Whenever `StateMachinesCostPerBlock` for a state machine is `0` (or removed), every incoming `ConsensusMessage` still advances the state machine's height via BEEFY/consensus verification, but the reward pallet's `process_message` hits an early return and never updates the watermark. When the cost is later restored to a non-zero value, the very next relayer to submit a valid consensus message is paid for the *entire* unpaid block span accumulated while the reward was zero — a windfall proportional to however long the reward was paused, for the price of a single message submission.

### Finding Description
`process_message` in [1](#0-0)  computes the reward from `calculate_reward`, and — critically — only calls `LastRewardedHeight::<T>::mutate(...)` to advance the watermark *after* the zero-check:

```
if reward.is_zero() {
    return Ok(());
}
...
LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
    *watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
});
``` [2](#0-1) 

`calculate_reward` derives the reward strictly from `(latest_height - baseline) * block_cost`, where `baseline` is `LastRewardedHeight` (falling back to `previous_commitment_height`): [3](#0-2) 

`block_cost` is fully governance-controlled via `update_cost_per_block` (settable to `0`) or `remove_incentives` (removes the entry entirely, also short-circuiting the `if let Some(block_cost)` branch), both public dispatchables gated only by `IncentivesOrigin`: [4](#0-3) 

State-machine height advancement (via consensus proofs, e.g. BEEFY/SP1) is entirely decoupled from this reward pallet — the `IsmpHost`'s `latest_commitment_height` keeps climbing regardless of whether `StateMachinesCostPerBlock` is set, because consensus verification is a separate, unprivileged, permissionless flow driven by `handle_incoming_message`/`FeeHandler::on_executed` on every submitted `ConsensusMessage` [5](#0-4) .

This is the direct analog of the reported bug: exactly as mint rewards silently keep accruing while Recovery Mode suppresses distribution and get swept in bulk the instant RM ends, here the height watermark silently falls behind while the reward is `0`/unset, and the entire backlog is paid out in bulk to whichever relayer happens to submit the next consensus message once the cost is restored.

### Impact Explanation
Any permissionless relayer that submits the first `ConsensusMessage` after `cost_per_block` transitions from `0`/absent back to a positive value receives a reward transfer from `T::TreasuryAccount` sized by the *entire* elapsed block span since the watermark was frozen — potentially days or weeks of accumulated "should-have-been-zero" reward budget — for one message. This directly drains the treasury account disproportionately to the relayer's actual marginal work, and lets an opportunistic relayer front-run the reactivation to claim the whole backlog before any other relayer can, causing unbacked-value treasury drain (Medium/High impact per the reward-accounting scope).

### Likelihood Explanation
Pausing/removing a state machine's cost-per-block (maintenance, cost re-pricing, temporarily disabling underfunded incentives) is a normal governance operation exposed by `update_cost_per_block(0, ...)` or `remove_incentives`, not itself malicious. Once such a legitimate pause-then-resume occurs, exploitation requires nothing more than any relayer submitting an ordinary, already-permissionless consensus message — no special privilege, collusion, or malicious governance action is needed to trigger the sweep itself.

### Recommendation
Advance `LastRewardedHeight` to `state_machine_height.height` unconditionally whenever `calculate_reward` is evaluated (i.e., move the watermark update out from behind the `reward.is_zero()` early return, and also update it when `StateMachinesCostPerBlock` is absent/zero), so no unpaid backlog can accumulate while the reward is temporarily zero or unset. Alternatively, cap the payable span retroactively to blocks produced only while `cost_per_block > 0`, e.g. by recording the height at which the rate changed.

### Proof of Concept
1. Governance calls `update_cost_per_block(sm, 100)`, relayers get rewarded normally, `LastRewardedHeight[sm] = H0`.
2. Governance calls `update_cost_per_block(sm, 0)` (or `remove_incentives(sm)`) to pause rewards for state machine `sm`.
3. Over the next `N` consensus updates, `latest_commitment_height` for `sm` advances from `H0` to `H0+N` via ordinary BEEFY/SP1 proof submissions — each call into `process_message` hits `reward.is_zero()` and returns early, leaving `LastRewardedHeight[sm]` stuck at `H0`.
4. Governance calls `update_cost_per_block(sm, 100)` again to resume incentives.
5. Any relayer submits the next valid `ConsensusMessage`; `calculate_reward` computes `(H0+N+k - H0) * 100`, and the relayer is paid the full backlog `≈ N * 100` from the treasury in a single message, instead of the intended per-message reward for just the new blocks it produced.

	fn process_message(
		state_machine_height: StateMachineHeight,
		state_machine_id: StateMachineId,
		relayer_account: T::AccountId,
	) -> Result<(), Error<T>> {
		if let Some(block_cost) = StateMachinesCostPerBlock::<T>::get(state_machine_id) {
			let reward = Self::calculate_reward(&state_machine_id, block_cost)?;

			if reward.is_zero() {
				return Ok(());
			}

			T::Currency::transfer(
				&T::TreasuryAccount::get().into_account_truncating(),
				&relayer_account,
				reward,
				Preservation::Expendable,
			)
			.map_err(|_| Error::<T>::RewardTransferFailed)?;

			Self::deposit_event(Event::<T>::RelayerRewarded {
				relayer: relayer_account.clone(),
				amount: reward,
				state_machine_height,
			});

			T::ReputationAsset::mint_into(&relayer_account, reward.saturated_into())
				.map_err(|_| Error::<T>::ReputationMintFailed)?;

			LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
				*watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
			});
		}
		Ok(())
	}

	/// Calculate the reward for a message based on the state machine id
	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)
	}

impl<T: Config> FeeHandler for Pallet<T>
where
	<T as frame_system::Config>::AccountId: From<[u8; 32]>,
{
	fn on_executed(
		messages: Vec<MessageWithWeight>,
		events: Vec<IsmpEvent>,
	) -> DispatchResultWithPostInfo {
		let maybe_relayer_account = messages.get(0).and_then(|first_message| {
			if let Message::Consensus(consensus_msg) = &first_message.message {
				let data = sp_io::hashing::keccak_256(&consensus_msg.consensus_proof);
				Signature::decode(&mut &consensus_msg.signer[..])
					.ok()
					.and_then(|sig| sig.verify_and_get_sr25519_pubkey(&data, None).ok())
					.map(|pub_key| pub_key.into())
			} else {
				None::<[u8; 32]>
			}
		});

		if let Some(relayer_account) = maybe_relayer_account {
			// When a batch contains multiple `StateMachineUpdated` events for the
			// same `state_machine_id` (sequential consensus updates for the same
			// chain), `calculate_reward` reads the same persisted
			// `(latest_commitment_height, previous_commitment_height)` pair on
			// every iteration and pays the same block-span reward N times.
			// Collapse the per-state-machine event stream to the single highest
			// `latest_height` so each state machine receives one reward per
			// batch, sized by the actual span of its commitment advance.
			let mut highest_per_state_machine: BTreeMap<StateMachineId, u64> = BTreeMap::new();
			for event in events {
				if let IsmpEvent::StateMachineUpdated(update) = event {
					highest_per_state_machine
						.entry(update.state_machine_id)
						.and_modify(|h| {
							if update.latest_height > *h {
								*h = update.latest_height;
							}
						})
						.or_insert(update.latest_height);
				}
			}

			for (state_machine_id, latest_height) in highest_per_state_machine {
				let state_machine_height =
					StateMachineHeight { id: state_machine_id.clone(), height: latest_height };

				let _ = Self::process_message(
					state_machine_height,
					state_machine_id,
					relayer_account.clone().into(),
				);
			}
		}

	#[pallet::call]
	impl<T: Config> Pallet<T> {
		/// Update cost per block for a state machine
		#[pallet::call_index(0)]
		#[pallet::weight(T::WeightInfo::update_cost_per_block())]
		pub fn update_cost_per_block(
			origin: OriginFor<T>,
			state_machine_id: StateMachineId,
			cost_per_block: <T as pallet_ismp::Config>::Balance,
		) -> DispatchResult {
			T::IncentivesOrigin::ensure_origin(origin)?;

			StateMachinesCostPerBlock::<T>::mutate(state_machine_id.clone(), |maybe_cost| {
				*maybe_cost = Some(cost_per_block);
			});

			Self::deposit_event(Event::<T>::StateMachineCostPerBlockUpdated {
				state_machine_id,
				cost_per_block,
			});

			Ok(())
		}

		/// Update cost per block for a state machine
		#[pallet::call_index(1)]
		#[pallet::weight(T::WeightInfo::update_cost_per_block())]
		pub fn remove_incentives(
			origin: OriginFor<T>,
			state_machine_id: StateMachineId,
		) -> DispatchResult {
			T::IncentivesOrigin::ensure_origin(origin)?;

			StateMachinesCostPerBlock::<T>::remove(state_machine_id.clone());

			Self::deposit_event(Event::<T>::StateMachineCostPerBlockRemoved { state_machine_id });

			Ok(())
		}
