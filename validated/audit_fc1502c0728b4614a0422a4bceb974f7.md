### Title
GET request timeout can be delivered after a GET response has already been serviced, causing double-payment/loss of relayer fee accounting - ([File: evm/src/core/HandlerV2.sol])

### Summary
`handleGetRequestTimeouts` only proves *non-membership* of a response receipt in a state trie snapshot at `message.height`, but the response can be delivered on this chain (via `handleGetResponses` → `EvmHost.dispatchIncoming(GetResponse,...)`) *after* that snapshot height and before the timeout message is executed. Because `EvmHost.dispatchIncoming(GetResponse, relayer)` never deletes `_requestCommitments[commitment]`, and `dispatchTimeOut` never checks `_responseReceipts[commitment]`, both the "successful delivery" path and the "timeout" path can independently consume the same `FeeMetadata` for the same request commitment, moving funds twice from a single escrowed fee.

### Finding Description
The GET-request lifecycle keeps its escrowed fee in `_requestCommitments[commitment]` from `dispatch(DispatchGet)` (`evm/src/core/EvmHost.sol:1001`) and only reads/pays it in two independent, mutually-unaware places:

1. `dispatchIncoming(GetResponse, relayer)` (`evm/src/core/EvmHost.sol:824-847`) pays the **relayer** `_requestCommitments[commitment].fee` after `onGetResponse` succeeds, but never clears `_requestCommitments[commitment]`. [1](#0-0) 

2. `dispatchTimeOut(GetRequestTimeout, meta, commitment)` (`evm/src/core/EvmHost.sol:856-877`) deletes `_requestCommitments[commitment]` as "replay protection" and then, if the `onGetTimeout` callback succeeds, refunds the escrowed fee to `meta.sender` (the original payer). [2](#0-1) 

The permissionless entrypoint `HandlerV2.handleGetRequestTimeouts` (`evm/src/core/HandlerV2.sol:293-321`) gates the timeout purely on:
- `request.timeout() > state.timestamp` (the request's nominal timeout has elapsed relative to a *finalized* state height), and
- a non-membership proof of the *response receipt* against that same finalized state root.

Neither check verifies that the response was never delivered *on the destination host itself* after the state snapshot used for the non-membership proof. Because Hyperbridge messages are asynchronous and relayed independently, a relayer can:
- deliver the actual `GetResponse` via `handleGetResponses` → `dispatchIncoming(GetResponse,...)`, which pays the relayer fee out of `_requestCommitments[commitment]` but leaves the entry in storage (no deletion), and
- separately obtain (or have already obtained) a state snapshot at an earlier height where the response receipt trie leaf was still absent, and use it in `handleGetRequestTimeouts` to also trigger `dispatchTimeOut`, which reads the still-present `_requestCommitments[commitment]` and refunds the same fee a second time to `meta.sender`.

This is the analog of the CVE's "use of an object's state after it should have been retired": the request's escrowed-fee resource is consumed via the response path but the record backing it is never invalidated with respect to the timeout path, so the timeout path treats stale state as still live and pays out again.

### Impact Explanation
This is a direct loss/duplication of protocol-held funds: the fee token escrowed for a single GET request can be paid out twice — once to the relayer (successful delivery) and once as a refund to the payer (timeout) — for the same commitment, draining the fee-token balance of `EvmHost` beyond what was ever collected for that request. This matches the required impact bar ("concrete theft ... of funds") and is reachable from ordinary permissionless relayer submissions of `handleGetResponses` and `handleGetRequestTimeouts`, with no privileged role required.

### Likelihood Explanation
Both `handleGetResponses` and `handleGetRequestTimeouts` are explicitly documented and implemented as permissionless — "anyone can call them to relay messages" — and take proofs against distinct, relayer-chosen `StateMachineHeight` values. Any GET request whose timeout window overlaps with a delay in the response actually reaching this chain (or a relayer that races the two proofs, using an earlier finalized height for the timeout's non-membership proof) can trigger this. No compromise of consensus or governance is required; a single opportunistic relayer/attacker choosing message ordering is sufficient.

### Recommendation
- Make `dispatchIncoming(GetResponse, ...)` and `dispatchTimeOut(GetRequestTimeout, ...)` mutually exclusive on the same commitment: e.g., have `dispatchIncoming(GetResponse,...)` also delete `_requestCommitments[commitment]` (or set a sentinel) once the response is delivered, and have `dispatchTimeOut` check `_responseReceipts[commitment]` is empty before paying out, reverting/no-op'ing otherwise.
- Require `handleGetRequestTimeouts` to prove non-membership against a `state.timestamp` that is *newer* than any point at which the response could have already landed, or otherwise pin timeout eligibility to storage state on this chain (`host.responseReceipts`) rather than solely on a possibly-stale non-membership proof.

### Proof of Concept
1. Attacker (or any user) calls `EvmHost.dispatch(DispatchGet)` with a nonzero `fee`, escrowing `fee` fee-tokens tied to `commitment`.
2. Relayer A relays the real response: `HandlerV2.handleGetResponses` → `EvmHost.dispatchIncoming(GetResponse, relayerA)`. `onGetResponse` succeeds; `relayerA` is paid `_requestCommitments[commitment].fee`. `_requestCommitments[commitment]` is left untouched in storage.
3. Relayer B (can be the same actor) submits `HandlerV2.handleGetRequestTimeouts` using a state snapshot height that is earlier than the response's arrival (or any finalized height whose child-trie proof shows no response receipt was present at that height), satisfying `request.timeout() > state.timestamp` and the non-membership proof.
4. `EvmHost.dispatchTimeOut(GetRequestTimeout, meta, commitment)` deletes `_requestCommitments[commitment]`, calls `onGetTimeout` on the source module (which, per interface docs, must tolerate being called even though the response was already fulfilled), and on success refunds `meta.fee` to `meta.sender`.
5. Net effect: the fee token escrowed once for the request has now been paid out twice (to the relayer for delivery and to the payer for the "timeout"), at the expense of `EvmHost`'s aggregate fee-token balance. [3](#0-2) [4](#0-3) [5](#0-4)

    function dispatchIncoming(PostRequest memory request, address relayer) external restrict(_hostParams.handler) {
        address destination = _bytesToAddress(request.to);
        uint256 size;
        assembly {
            size := extcodesize(destination)
        }
        if (size == 0) {
            // instead of reverting the entire batch, early return here.
            return;
        }

        // replay protection
        bytes32 commitment = request.hash();
        _requestReceipts[commitment] = relayer;

        (bool success,) = address(destination)
            .call(abi.encodeWithSelector(IApp.onAccept.selector, IncomingPostRequest(request, relayer)));

        if (!success) {
            // so that it can be retried
            delete _requestReceipts[commitment];
            return;
        }
        emit PostRequestHandled({commitment: commitment, relayer: relayer});
    }

    /**
     * @dev Dispatch an incoming GET response to source module
     * @param response - get response
     */
    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    /**
     * @dev Dispatch an incoming GET timeout to the source module.
     * @notice Does not refund any protocol fees.
     * @param timeout - timed-out get request bundled with the relayer that submitted the timeout proof
     * @param meta - fee metadata for the original request
     * @param commitment - request commitment
     */
    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetResponses(IHost host, GetResponseMessage calldata message) external notFrozen(host) {
        uint256 timestamp = block.timestamp;
        uint256 delay = timestamp - host.stateMachineCommitmentUpdateTime(message.proof.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        uint256 responsesLength = message.responses.length;
        MerkleMountainRange.Leaf[] memory leaves = new MerkleMountainRange.Leaf[](responsesLength);

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // don't check for timeouts because it's checked on Hyperbridge

            // known request? also serves as source check
            FeeMetadata memory meta = host.requestCommitments(leaf.response.request.hash());
            if (meta.sender == address(0)) revert UnknownMessage();
            leaves[i] = MerkleMountainRange.Leaf(leaf.index, leaf.response.hash());
        }

        bytes32 root = host.stateMachineCommitment(message.proof.height).overlayRoot;
        if (root == bytes32(0)) revert StateCommitmentNotFound();
        bool valid = MerkleMountainRange.VerifyProof(root, message.proof.multiproof, leaves, message.proof.leafCount);
        if (!valid) revert InvalidProof();

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // duplicate response?
            if (host.responseReceipts(leaf.response.request.hash()).relayer != address(0)) revert DuplicateMessage();
            host.dispatchIncoming(leaf.response, _msgSender());
        }
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
