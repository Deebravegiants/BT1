## Finding

Chainlink node's LOOP plugin proxy routes (`/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) are registered on the top-level `api` router group, which only applies rate-limiting and session middleware — **not** `auth.Authenticate`. This is unlike every other functional route group (`debugRoutes`, `v2Routes`, `sessionRoutes`), which explicitly wrap their groups with `auth.Authenticate(...)`. [1](#0-0) [2](#0-1) [3](#0-2) 

Additionally, `pluginPPROFHandler` builds the forwarded internal URL by directly concatenating the unsanitized `profile` wildcard path parameter into the target URL string, with no path-confinement/allowlist check: [4](#0-3) 

### Title
Unauthenticated LOOP plugin proxy routes allow SSRF/path-traversal forwarding to internal loop host - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
The bug class in the external report is a shared "test"/debug code path that accepts an attacker-controlled path/string with no confinement check, reachable by a low-privilege caller through an allowlisted entry point, resulting in disclosure beyond intended scope. The closest concrete analog in this repository is the `loopRoutes` registration, which mounts plugin proxy handlers without the `auth.Authenticate` middleware that every sibling route group uses, and the `pluginPPROFHandler`, which builds the proxied request URL by string-concatenating the raw `profile` URL wildcard parameter (`gc.Param("profile")`) with no `path.Clean`/allowlist/confinement.

### Finding Description
`NewRouter` calls `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` on the same `api` group [5](#0-4) . `debugRoutes` explicitly requires session authentication before exposing `/debug/vars` [2](#0-1) , and the pprof endpoints under `v2Routes`/`metricRoutes` are likewise gated behind the authenticated `authv2` subgroup [6](#0-5) . In contrast, `loopRoutes` registers `discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler` directly on `api` with no additional `auth.Authenticate` wrapper [3](#0-2) .

`pluginPPROFHandler` then takes the caller-supplied wildcard `profile` parameter and appends it verbatim to a hard-coded base URL string via `fmt.Sprintf`, without any `path.Clean`, prefix/allowlist check, or confinement to the `net/http/pprof` handler set: `pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)` [4](#0-3) . The resulting request is then issued to the internal `loopHostName` from the node process itself via `doRequest`, and the response body is streamed straight back to the caller [7](#0-6) .

This mirrors the reported root cause pattern precisely: a shared code path (`lib.lftest.test()` / here, the plugin proxy handler) accepts a caller-controlled string with no confinement check (`os.path.isfile(stdout)` / here, raw string concatenation into a URL path) and is reachable via a route/mechanism that lacks the authorization gating applied to sibling routes (sudoers allowlist bypassing build-time gating / here, missing `auth.Authenticate` on `loopRoutes`).

### Impact Explanation
Any unauthenticated network client that can reach the node's HTTP API can invoke `GET /plugins/:name/debug/pprof/*profile` and `GET /plugins/:name/metrics`. Because `profile` is concatenated unsanitized into the forwarded URL, an attacker can supply path-traversal or arbitrary-path segments (e.g. `../../some/other/endpoint`) to make the chainlink node itself issue crafted HTTP requests to the internal `loopHostName:PrometheusPort` on behalf of the attacker — an SSRF-style pivot into the node-internal network reachable only from localhost/inside the LOOP process boundary, without any credentials. This bypasses the authentication boundary that protects the equivalent `/debug/pprof` and `/v2/build_info`/metric routes elsewhere in the router, and could expose internal plugin diagnostic data or be used to probe/attack other services on the loop host.

### Likelihood Explanation
High for reachability: no authentication, no session, and no role check are required — only network access to the node's configured HTTP listener and knowledge of a registered plugin name (enumerable via the also-unauthenticated `discoveryHandler`) [8](#0-7) . The lack of `path.Clean`/allowlisting on `profile` means exploitation requires only crafting the wildcard segment of the URL.

### Recommendation
1. Wrap `loopRoutes` (or at minimum `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler`/`pluginMetricHandler`) with `auth.Authenticate(app.AuthenticationProvider(), ...)` consistent with `debugRoutes` and the `authv2` metric routes.
2. In `pluginPPROFHandler`, validate `gc.Param("profile")` against an explicit allowlist of supported pprof sub-paths (`cmdline`, `profile`, `symbol`, `trace`, `allocs`, `block`, `goroutine`, `heap`, `mutex`, `threadcreate`) or use `path.Clean` plus a strict prefix/equality check before constructing `pluginURL`, mirroring how `newFileFetcher` in `fetcher.go` already confines paths via `strings.HasPrefix(fullPath, basePath+...)` [9](#0-8) .

### Proof of Concept
```
# Enumerate a registered plugin name (unauthenticated)
curl http://<node>:<port>/discovery

# Unauthenticated pprof proxy forwarding with attacker-controlled path segment
curl "http://<node>:<port>/plugins/<plugin-name>/debug/pprof/../../../some/internal/path?seconds=1"
```
No session cookie, API token, or credentials are supplied; the request is accepted because `loopRoutes` is mounted without `auth.Authenticate`, and the `profile` wildcard is forwarded unsanitized to the internal loop host.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
