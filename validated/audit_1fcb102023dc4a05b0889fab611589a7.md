### Title
Bad-debt write-down clamps `supply_index` up to a non-zero floor, resurrecting wiped supplier shares into phantom claims that drain fresh deposits - (File: contracts/pool/src/interest.rs)

### Summary
`apply_bad_debt_to_supply_index` socializes bad debt by scaling the supply index toward zero, but then clamps the result up to `SUPPLY_INDEX_FLOOR_RAW` (= `RAY / 1000`). Every supplier's `scaled_amount` shares — which a complete wipeout should have reduced to zero value — instead retain `scaled * RAY/1000` of value. Those resurrected claims are withdrawable and are paid out of subsequent fresh deposits, i.e., a use-after-free analog: balances that were economically freed by the write-down remain dereferenceable.

### Finding Description
The pool socializes unpaid debt in `seize.rs` by computing the bad debt in RAY and calling `apply_bad_debt_to_supply_index`, then burning the debt shares [1](#0-0) . The write-down caps the reduction at total supplied value, but the final line restores a non-zero index: `cache.set_supply_index(new_supply_index.max(Ray::from(SUPPLY_INDEX_FLOOR_RAW)))` [2](#0-1) .

When `bad_debt >= total_supplied_value` (a full wipeout, reachable via permissionless `clean_bad_debt` on an insolvent account or a seizure that exhausts collateral), `new_supply_index` computes to 0 and is lifted to `RAY/1000`. Supplier scaled positions are never burned by the write-down — the socialization only mutates the index — so every pre-wipeout supplier retains a claim of `floor(scaled_amount * RAY/1000)` token value. The pool test `test_raw_cache_seizure_residual_would_drain_fresh_cash_without_supply_guard` demonstrates exactly this: after a seize wipeout clamps to the floor, a wiped supplier withdraws a non-zero amount equal to a fresh depositor's entire deposit, leaving cash unable to cover the honest claim [3](#0-2) . `test_bad_debt_wipeout_leaves_market_usable_at_realistic_scale` confirms the production path commits the floored index and the market stays open to new supply [4](#0-3) . Withdrawal pays `resolve_withdrawal`'s floor-valued claim against cash, guarded only by `require_reserves`, which checks the pool's cash balance — so phantom claims are satisfied as long as any fresh cash exists [5](#0-4) .

The reachable path for an unprivileged address: call `clean_bad_debt(caller, account_id)` on a dust-collateral insolvent account whose market's bad debt meets or exceeds remaining supplied value (or be an existing supplier in a market that is later wiped out), wait for or make a fresh `supply` into that market, then `withdraw` the stranded scaled balance for real tokens.

### Impact Explanation
Theft of user funds / protocol insolvency: wiped suppliers' economically-zeroed shares are revived at 0.1% of face value and paid from fresh deposits. A first withdrawer after a wipeout can extract up to the entire fresh cash of the market, directly stealing later suppliers' principal.

### Likelihood Explanation
Requires a bad-debt wipeout where unpaid debt ≥ total supplied value in one `(hub, token)` book — a tail-risk market event, but `clean_bad_debt` is permissionless and the floor residual persists indefinitely until withdrawn. Once triggered, any holder of pre-wipeout scaled shares (or the wiped account's residual) can claim.

### Recommendation
On a write-down that would drive the index below `SUPPLY_INDEX_FLOOR_RAW`, either let the index reach its true (floor-bounded but claim-consistent) value and explicitly burn/void residual scaled supply positions, or clamp the index only when it stays above zero naturally — i.e., when `remaining > 0`. At minimum, gate withdrawals so a position whose claim exists only because of the floor clamp cannot draw cash: compare the scaled claim against `cash` pro-rata against total supplied scaled value rather than paying `unscale_supply_floor` unconditionally.

### Proof of Concept
Follow the existing test `test_raw_cache_seizure_residual_would_drain_fresh_cash_without_supply_guard` in `contracts/pool/tests/interest.rs`: supplier Alice holds `scaled_a` shares; bad debt ≥ total supplied is applied via `apply_bad_debt_to_supply_index`, clamping `supply_index` to `SUPPLY_INDEX_FLOOR_RAW`. Bob then supplies `c = unscale_supply_floor(scaled_a)` tokens. Alice withdraws her full scaled position and receives exactly `c` — Bob's entire deposit — leaving pool cash below Bob's claim. In production this maps to `clean_bad_debt` → fresh `supply` → `withdraw`, all callable by unprivileged addresses.

#[test]
fn test_raw_cache_seizure_residual_would_drain_fresh_cash_without_supply_guard() {
    let t = TestSetup::new();
    t.as_contract(|| {
        let alice_scaled_raw = 1_000 * RAY;
        let borrowed_scaled_raw = 1_000 * RAY;
        let mut cache = t.fresh_cache(PoolStateRaw {
            supplied: alice_scaled_raw,
            borrowed: borrowed_scaled_raw,
            revenue: 0,
            borrow_index: RAY,
            supply_index: RAY,
            last_timestamp: 0,
            cash: 0,
        });
        let alice_scaled = Ray::from(alice_scaled_raw);
        let borrow_scaled = Ray::from(borrowed_scaled_raw);

        let bad_debt = cache.unscale_borrow_ceil_ray(borrow_scaled);
        apply_bad_debt_to_supply_index(&mut cache, bad_debt);
        cache.burn_debt(borrow_scaled);

        assert_eq!(
            cache.supply_index().raw(),
            SUPPLY_INDEX_FLOOR_RAW,
            "seize wipeout clamps supply_index UP to RAY/1000, leaving unburned shares a residual"
        );

        let alice_stranded = cache.unscale_supply_floor(alice_scaled);
        assert!(alice_stranded > 0, "wiped survivor keeps a stranded claim");
        assert_eq!(
            cache.cash(),
            0,
            "empty market: claim masked by require_reserves"
        );

        let deposit = alice_stranded;
        let bob_scaled = cache.calculate_scaled_supply(deposit);
        cache.mint_supply(bob_scaled);
        cache.credit_cash(deposit);

        let total_owed = cache.unscale_supply_floor(cache.supplied());
        assert!(
            total_owed > cache.cash(),
            "post-deposit books insolvent: owed {} > cash {}",
            total_owed,
            cache.cash()
        );

        let (burn, gross) = cache.resolve_withdrawal(i128::MAX, alice_scaled);
        cache.require_reserves(gross);
        cache.burn_supply(burn);
        cache.debit_cash(gross);

        assert!(gross > 0, "wiped position pays out real cash");
        assert_eq!(gross, deposit, "Alice extracts exactly Bob's fresh deposit");

        let bob_claim = cache.unscale_supply_floor(bob_scaled);
        assert!(
            cache.cash() < bob_claim,
            "cash {} cannot cover Bob's honest claim {}: fresh depositor lost funds",
            cache.cash(),
            bob_claim
        );
    });

#[test]
fn test_bad_debt_wipeout_leaves_market_usable_at_realistic_scale() {
    let t = TestSetup::new();
    let client = t.client();

    client.supply(&t.sup(0, 10_000_000_000i128));

    t.env.as_contract(&t.pool, || {
        let mut cache = Cache::load(&t.env, &hub(&t.asset));
        let total_supplied_value = cache.supplied().mul(&t.env, cache.supply_index());
        crate::interest::apply_bad_debt_to_supply_index(&mut cache, total_supplied_value);
        cache.commit();
    });

    let floored = t.state_snapshot().supply_index;
    assert_eq!(floored, common::constants::SUPPLY_INDEX_FLOOR_RAW);
    assert_eq!(RAY / floored, 1_000);

    let opened = client.supply(&t.sup(0, 10_000_000_000_000i128));
    assert!(opened.get(0).unwrap().position.scaled_amount > 0);
}
