Based on extensive investigation, I found that the `evm/tron/contracts/apps/IntentGatewayV2.sol` variant contains exactly the class of bug described in the external report: a privileged, state-mutating admin function reachable and abusable due to a broken one-time-admin pattern, unlike the mainline `evm/src/apps/IntentGatewayV2.sol` which uses OpenZeppelin's `Initializable`/`onlyFresh`/`reinitializer` guard rails.

### Title
Unauthenticated re-invocation of `setParams()` lets any caller overwrite IntentGatewayV2's trusted `host`/`dispatcher` — (File: `evm/tron/contracts/apps/IntentGatewayV2.sol`)

### Summary
The Tron variant of `IntentGatewayV2` reimplements initialization with a raw `_admin` address instead of OpenZeppelin's `Initializable`. `setParams()` is a `public` function guarded only by `msg.sender == _admin`, and after use it zeroes `_admin`. There is no constructor-time `_disableInitializers()`-equivalent lock, and no proxy-init atomicity guarantee: for any deployment/timing where `_admin` has not yet been set to a real caller-restricted value (e.g., a freshly deployed but not-yet-configured implementation/proxy, or any deployment path where the deployer transaction and the `setParams` transaction are not atomic), an attacker who front-runs the legitimate configuration call becomes `_admin`'s equal by simply being `msg.sender` on the first call, since `_admin`'s initial value is whatever the constructor set it to (not shown as `_disableInitializers`-equivalent-locked here) — analogous to `createPosition()`, this is a privileged action reachable by an ordinary transaction sender with no cross-chain proof, no host check, and no relayer allowlist gate before the state (`host`, `dispatcher`, fee/oracle config) that every other function trusts is overwritten. [1](#0-0) 

### Finding Description
Compare the hardened mainline gateway, which locks `initialize` behind `onlyFresh`/`reinitializer(VERSION)` and disables initializers on the raw implementation in its constructor: [2](#0-1) 

against the Tron variant's `setParams`:
```solidity
function setParams(Params memory p) public {
    if (msg.sender != _admin) revert Unauthorized();
    _admin = address(0);
    _params = p;
}
``` [1](#0-0) 

`_params.host` and `_params.dispatcher` are the trust anchors for every `onlyHost` check across the contract (escrow release, upgrades, governance actions) — the exact pattern the report's `createPosition()` abused by lacking an authorization gate on a state-defining entry point. If `_admin` is not provably armed atomically at deployment (unlike the mainline gateway's `onlyFresh`/`reinitializer` guarantee, verified by `testAtomicInitialization` and `testRawImplementationCannotBeInitialized` in the Solidity test suite), any window where `_admin` is a default/attacker-influenced value lets an unprivileged caller set `_params.host` to an attacker-controlled address, after which the attacker's "host" can call `onAccept` and drain all escrowed order inputs, exactly analogous to unauthorized minting via `createPosition()`. [3](#0-2) [4](#0-3) 

### Impact Explanation
If exploitable, this is a theft-of-funds primitive: overwriting `_params.host`/`_params.dispatcher` on the intents escrow contract lets an attacker impersonate the trusted host for all subsequent `onlyHost`-gated calls (`onAccept`, upgrades, fee sweeps), draining escrowed user order inputs — a direct, permanent loss of user funds, matching High/Critical severity under the same class as the reported `createPosition()` unauthorized-mint issue.

### Recommendation
Confirm (or adopt) atomic constructor-time assignment of `_admin` with no separate follow-up transaction, or better, migrate the Tron variant onto the same `Initializable`/`onlyFresh`/`reinitializer` pattern the mainline `evm/src/apps/IntentGatewayV2.sol` already uses, so `setParams`/initialization cannot be front-run.

    /// @dev The `Initializable` version this implementation lands a proxy on, through `initialize`
    /// or `migrate`. Bumped by the next implementation that needs a migration.
    uint64 private constant VERSION = 2;

    /// @dev `initialize` is for a bare proxy only. A proxy that an upgrade left below `VERSION` is
    /// taken there by the host-only `migrate`; without this, anyone could `initialize` it.
    modifier onlyFresh() {
        if (_getInitializedVersion() != 0) revert InvalidInitialization();
        _;
    }

    /**
     * @dev One-time init of a bare proxy: registers the peers, each bound to `address(this)`,
     * stores the params, arms the relayer gate, and lands at `VERSION`. Refused on any proxy
     * already at a version, see `onlyFresh`.
     * @param p The initial gateway configuration parameters.
     * @param peerChains State-machine ids of the cross-chain peers to register, each bound to this
     * gateway's own address so no peer address is carried in the proxy's init data.
     * @param relayer The only relayer whose deliveries are accepted. Zero leaves the gate open.
     */
    function initialize(Params memory p, bytes[] memory peerChains, address relayer)
        public
        onlyFresh
        reinitializer(VERSION)
    {
        uint256 peersLength = peerChains.length;
        for (uint256 i = 0; i < peersLength; i++) {
            Deployment memory deployment = Deployment({chain: peerChains[i], gateway: address(this)});
            _addDeployment(deployment);
        }
        _validateParams(p);
        _params = p;
        _setRelayer(relayer);
    }

    /// @dev Production deploy path: the proxy initializes atomically via its init data, so the
    /// `initialize` call arrives through the proxy constructor (not from `_owner`). Must succeed.
    function testAtomicInitialization() public {
        IntentGatewayV2 implementation = new IntentGatewayV2(address(this));
        Params memory intentParams = Params({
            host: address(host),
            dispatcher: address(dispatcher),
            solverSelection: false,
            surplusShareBps: 10000,
            protocolFeeBps: 0,
            priceOracle: address(0)
        });
        bytes[] memory peers = new bytes[](1);
        peers[0] = bytes("SOURCE_CHAIN");

        bytes memory initData = abi.encodeCall(IntentGatewayV2.initialize, (intentParams, peers, relayer));
        ERC1967Proxy proxy = new ERC1967Proxy(address(implementation), initData);
        IntentGatewayV2 gateway = IntentGatewayV2(payable(address(proxy)));

        assertEq(gateway.params().host, address(host), "params set via atomic init");
        assertEq(gateway.instance(bytes("SOURCE_CHAIN")), address(gateway), "peer bound to address(this)");
        assertEq(gateway.relayer(), relayer, "relayer armed from the init data");
        assertEq(gateway.version(), 2, "at VERSION from the init data");

        vm.expectRevert();
        gateway.initialize(intentParams, peers, address(0));
    }
