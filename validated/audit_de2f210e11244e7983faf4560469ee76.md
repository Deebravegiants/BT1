## Title
Unbounded digest-array allocation in `Codec.DecodeHeader` from an untrusted SCALE compact length - (File: `evm/src/consensus/Codec.sol`)

### Summary
`Codec.DecodeHeader` reads an untrusted SCALE compact-encoded digest count directly from attacker-supplied bytes and immediately allocates a memory array of that size with no upper bound, mirroring the XWiki class of bug (an untrusted "huge number" field driving unbounded allocation).

### Finding Description
`Codec.DecodeHeader` decodes `length = ScaleCodec.decodeUintCompact(slice)` from the raw header bytes and then executes `Digest[] memory digests = new Digest[](length);` with no ceiling check on `length` before allocating. [1](#0-0) 

`decodeUintCompact` allows the encoded value to range up to a 64-bit-scale magnitude (mode 3 branch reads up to 8 bytes), so an attacker fully controls how large `length` becomes purely from the bytes they supply for `para.header`. [2](#0-1) 

This is reached from `EcdsaBeefy.verifyParachainHeaderProof`, which calls `Codec.DecodeHeader(para.header)` for every entry in the attacker/relayer-supplied `ParachainProof.parachains[]` array — and critically, this decode happens **before** the merkle-multi-proof membership check (`MerkleMultiProof.VerifyProof(headsRoot, proof.proof, leaves, proof.leafCount)`) that would otherwise validate the header actually belongs to the finalized parachain-heads root. [3](#0-2) 

Because the membership check is deferred to after the loop, anyone who can produce (or replay) a genuine, publicly-observable BEEFY-signed relay chain commitment (which is not secret data and does not require any protocol privilege) can pair it with an arbitrary `ParachainProof.parachains` array containing forged `para.header` bytes whose SCALE compact digest-count field encodes an oversized value, forcing `DecodeHeader` to attempt an oversized `Digest[]` memory allocation before the forged header is ever proven to be a genuine member of the parachain-heads root.

Contrast this with the pattern already hardened elsewhere in this same codebase: `modules/pallets/call-decompressor/src/lib.rs::decompress` explicitly bounds a claimed size against `MaxCallSize` specifically because an unsigned/fee-less caller could otherwise trigger unbounded expansion "before any size check", and `modules/consensus/pharos/verifier/src/state_proof.rs::decode_validator_set_from_storage` explicitly caps an attacker-controlled count against `MAX_VALIDATORS` before using it to index/iterate. [4](#0-3) [5](#0-4) 

`Codec.DecodeHeader` has no equivalent bound.

### Impact Explanation
In the EVM execution model, memory allocation cost is metered and grows quadratically with the number of 32-byte words allocated. An oversized `length` forces the `verify()` call to spend all of its supplied gas expanding memory for `new Digest[](length)`, causing an out-of-gas revert of that specific call. Because `EcdsaBeefy.verify` is `pure` and invoked per-transaction with a caller-supplied gas limit, the direct on-chain effect of this bug is bounded to wasting the gas of whoever submits (or simulates) the malicious proof — it does not corrupt persistent contract state, since `verify` performs no storage writes and a failed/OOG call reverts entirely.

The genuinely concerning use of this pattern is as a griefing/availability vector against automated relayer infrastructure: a relayer's software commonly dry-runs (`eth_call`/gas estimation) proof-construction candidates before submitting a transaction. If an RPC node used for that estimation has a generous or unlimited call-gas cap, a crafted `para.header` byte string can drive a single simulated call into extremely expensive (potentially multi-second/very-high-memory) execution, degrading that RPC node or stalling relayer proof-processing pipelines that iterate over untrusted parachain-header candidates. This is a resource-consumption/availability concern rather than a fund-theft or state-corruption one.

### Likelihood Explanation
Triggering this requires only (1) a legitimately-signed BEEFY relay commitment, which is public data obtainable by anyone observing the relay chain, and (2) crafting a `ParachainProof.parachains[]` array with a forged `para.header` whose compact-length field is oversized — no signatures or private data are needed for the forged header itself, since the merkle membership check that would reject it runs only after `DecodeHeader` has already executed for every entry. This makes the trigger trivially constructible by any unprivileged party who can call the consensus client's `verify` function (directly, or via any code path — e.g., message-handling — that decodes untrusted parachain proof data through this same function).

### Recommendation
Add an explicit upper bound on the decoded digest `length` (and equivalently on `decodeDigestItem`'s inner `length` for the digest payload) in `Codec.DecodeHeader`/`Codec.decodeDigestItem` before allocating, analogous to `MAX_VALIDATORS` in the pharos verifier and `MaxCallSize` in `call-decompressor`. A reasonable bound is a small constant (e.g., 16–32) reflecting the maximum number of digest items ever emitted by a real Substrate header, rejecting any header whose claimed digest count exceeds it. Additionally, consider moving the merkle-membership check (`MerkleMultiProof.VerifyProof`) in `verifyParachainHeaderProof` ahead of, or interleaved with, per-header decoding so that unverified header bytes are never fully decoded before their authenticity is established.

### Proof of Concept
1. Obtain any real, currently valid BEEFY `RelayChainProof` for the target consensus client (public relay-chain data; no privileged access needed).
2. Construct a `ParachainProof` whose `parachains[0].header` bytes are: `parentHash(32) || compact(blockNumber) || stateRoot(32) || extrinsicsRoot(32) || compact(digestCount = <huge value, e.g. mode-3 encoding of 2^32>) || ...` (no further bytes are required for the OOG-triggering step, since the array allocation for `Digest[](length)` occurs before any subsequent byte is read).
3. Call `EcdsaBeefy.verify(previousState, abi.encode(relay, parachain))` (or the corresponding entrypoint that eventually calls `verifyParachainHeaderProof`) supplying a modest gas limit.
4. Observe the call reverts with out-of-gas during `Codec.DecodeHeader`'s `new Digest[](length)` allocation — before the `MerkleMultiProof.VerifyProof` membership check that would otherwise have rejected the unauthenticated forged header ever runs. [1](#0-0) [6](#0-5)

    function DecodeHeader(bytes memory encoded) internal pure returns (Header memory) {
        ByteSlice memory slice = ByteSlice(encoded, 0);
        bytes32 parentHash = Bytes.toBytes32(Bytes.read(slice, 32));
        uint256 blockNumber = ScaleCodec.decodeUintCompact(slice);
        bytes32 stateRoot = Bytes.toBytes32(Bytes.read(slice, 32));
        bytes32 extrinsicsRoot = Bytes.toBytes32(Bytes.read(slice, 32));

        uint256 length = ScaleCodec.decodeUintCompact(slice);
        Digest[] memory digests = new Digest[](length);

        for (uint256 i = 0; i < length; i++) {
            uint8 kind = Bytes.readByte(slice);
            Digest memory digest;
            if (kind == DIGEST_ITEM_OTHER) {
                digest.isOther = true;
            } else if (kind == DIGEST_ITEM_CONSENSUS) {
                digest.isConsensus = true;
                digest.consensus = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_SEAL) {
                digest.isSeal = true;
                digest.seal = decodeDigestItem(slice);

                digest.isPreRuntime = true;
                digest.preruntime = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_RUNTIME_ENVIRONMENT_UPDATED) {
                digest.isRuntimeEnvironmentUpdated = true;
            }
            digests[i] = digest;
        }

    // @dev Decodes a SCALE encoded compact unsigned integer
    function decodeUintCompact(ByteSlice memory data) internal pure returns (uint256 v) {
        uint8 b = readByte(data); // read the first byte
        uint8 mode = b & 3; // bitwise operation

        uint256 value;
        if (mode == 0) {
            // [0, 63]
            value = b >> 2; // right shift to remove mode bits
        } else if (mode == 1) {
            // [64, 16383]
            uint8 bb = readByte(data); // read the second byte
            uint64 r = bb; // convert to uint64
            r <<= 6; // multiply by * 2^6
            r += b >> 2; // right shift to remove mode bits
            value = r;
        } else if (mode == 2) {
            // [16384, 1073741823]
            uint8 b2 = readByte(data); // read the next 3 bytes
            uint8 b3 = readByte(data);
            uint8 b4 = readByte(data);

            uint32 x1 = uint32(b) | (uint32(b2) << 8); // convert to little endian
            uint32 x2 = x1 | (uint32(b3) << 16);
            uint32 x3 = x2 | (uint32(b4) << 24);

            x3 >>= 2; // remove the last 2 mode bits
            value = uint256(x3);
        } else if (mode == 3) {
            // [1073741824, 4503599627370496]
            uint8 l = (b >> 2) + 4; // remove mode bits
            require(l <= 8, "unexpected prefix decoding Compact<Uint>");
            return ScaleCodec.decodeUint256(read(data, l));
        } else {
            revert("Code should be unreachable");
        }
        return (value);
    }

    // @dev Verifies that some parachain header has been finalized, given the current trusted consensus state.
    function verifyParachainHeaderProof(bytes32 headsRoot, ParachainProof memory proof)
        internal
        pure
        returns (IntermediateState[] memory)
    {
        uint256 len = proof.parachains.length;
        MerkleMultiProof.Leaf[] memory leaves = new MerkleMultiProof.Leaf[](len);
        IntermediateState[] memory intermediates = new IntermediateState[](len);

        for (uint256 i = 0; i < len; i++) {
            Parachain memory para = proof.parachains[i];
            Header memory header = Codec.DecodeHeader(para.header);
            if (header.number == 0) revert IllegalGenesisBlock();

            leaves[i] = MerkleMultiProof.Leaf(
                para.index,
                keccak256(bytes.concat(ScaleCodec.encode32(uint32(para.id)), ScaleCodec.encodeBytes(para.header)))
            );

            StateCommitment memory commitment = header.stateCommitment();
            intermediates[i] =
                IntermediateState({stateMachineId: para.id, height: header.number, commitment: commitment});
        }

        if (len > 0) {
            bool valid = MerkleMultiProof.VerifyProof(headsRoot, proof.proof, leaves, proof.leafCount);
            if (!valid) revert InvalidMmrProof();
        }

        return intermediates;
    }
