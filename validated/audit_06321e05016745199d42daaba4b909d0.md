Audit Report

## Title
Permissionless "relayer" path in `pallet-whitelist` permanently consumes a deferred governance call even when the inner dispatch fails, allowing an unprivileged account to grief an approved-but-not-yet-executed governance action - (File: `substrate/frame/whitelist/src/lib.rs`)

## Summary
`pallet-whitelist`'s `DeferredDispatch` mechanism allows any signed account to relay a deferred, whitelisted governance call via `dispatch_whitelisted_call`/`dispatch_whitelisted_call_with_preimage`. Both paths funnel into `clean_and_dispatch`, which unconditionally removes `WhitelistedCall`, un-requests the preimage, and removes the `DeferredDispatch` entry *before* checking whether `call.dispatch(...)` succeeds, so a failed inner call still permanently discards the governance-approved action with no retry path and no cost to the caller.

## Finding Description
`dispatch_whitelisted_call` reaches the signed relayer path through the `Err(dispatch_origin)` branch, calling `ensure_signed_deferred_dispatch`, whose only checks are that a `DeferredDispatch` entry exists, has not expired, and the hash is still in `WhitelistedCall` — there is no check on whether the inner call will actually succeed: [1](#0-0) 

Both entry points delegate cleanup and dispatch to `clean_and_dispatch`, which removes all relevant state unconditionally and only records the `Result` in an event afterward, never gating cleanup on `result.is_ok()`: [2](#0-1) 

The relayer pays no fee (`Pays::No`), and this call path is reached by any `ensure_signed` origin: [3](#0-2) 

The pallet's own test explicitly documents and asserts this exact behavior: a `BadOrigin` failure in the inner dispatch still results in `DeferredDispatchExecuted` being emitted and all state (whitelist entry, preimage request) being cleaned up, with an inline comment confirming it is by design ("Even though the inner call failed, the deferred entry was still consumed by the relayer... regardless of the inner call's outcome"): [4](#0-3) 

This is a genuinely new, non-upstream mechanism — the `prdoc/pr_11336.prdoc` entry confirms this was intentionally added ("Extends pallet-whitelist with automatic deferred dispatch... executed later by any signed origin once the call is whitelisted. The relaying signed origin is not charged.") [5](#0-4) , and the event documentation itself explicitly states this "consume regardless of success" semantics is intended: [6](#0-5) .

`pallet_whitelist` with this configuration is wired into real runtimes, not just test mocks, per the grep results across `polkadot/runtime/rococo/src/governance/mod.rs`, `cumulus/parachains/runtimes/assets/asset-hub-westend/src/governance/mod.rs`, `substrate/bin/node/runtime/src/lib.rs`, and the staking-async runtimes.

## Impact Explanation
Once governance (`WhitelistOrigin`) whitelists a deferred call hash, any signed account — not necessarily the intended relayer — can call `dispatch_whitelisted_call`/`dispatch_whitelisted_call_with_preimage` and trigger cleanup regardless of whether the inner call actually succeeds. If timed to fail (e.g., a call whose success depends on preconditions not yet satisfied, or one that is structurally incompatible with `Root` origin as demonstrated by the pallet's own `remark_with_event` test), the deferred entry, whitelist entry, and preimage request are all destroyed with zero cost to the caller. The governance-approved action is silently discarded and must be redone from scratch through the full governance approval flow. This is a denial-of-service/griefing vector against on-chain governance execution — a concrete, code-confirmed impact rather than a speculative one, and it is triggerable by any unprivileged signed account once the (normal, non-attacker-controlled) governance preconditions are met.

## Likelihood Explanation
Exploitation requires governance to have already deferred and whitelisted a call (a normal governance operation, not an attacker precondition), and a window where the call would fail if dispatched at that moment (e.g., before some other precondition-setting call executes, or due to origin incompatibilities as shown in the pallet's own test). Given the relay call is open to any signed account and free (`Pays::No`), an attacker monitoring `DispatchDeferred`/`CallWhitelisted` events can race legitimate relayers to trigger the relay at a moment known or suspected to cause failure, at no cost and with no penalty for being wrong, making this repeatable and low-cost to attempt whenever such a window exists.

## Recommendation
- In `clean_and_dispatch`, gate removal of `WhitelistedCall`, preimage un-request, and `DeferredDispatch` on `result.is_ok()`, so a failed dispatch leaves state intact for a subsequent relay attempt within the expiration window.
- Alternatively/additionally, require a bond or fee from the relayer that is only refunded on successful dispatch, removing the zero-cost griefing incentive introduced by allowing any signed account to consume a deferred, whitelisted call.
- Consider adding an explicit "retry" semantics so a failed relay does not permanently foreclose the governance-approved action.

## Proof of Concept
The pallet's existing `test_deferred_dispatch_failed_inner_call` test already demonstrates the unsafe behavior end-to-end: an unprivileged signed account (`RuntimeOrigin::signed(1)`) relays a deferred `remark_with_event` call that fails with `DispatchError::BadOrigin` when dispatched as `Root`, yet `DeferredDispatchExecuted` is still emitted and `Preimage::is_requested` becomes `false` afterward — proving the deferred/whitelist state is destroyed regardless of dispatch success: [4](#0-3) 

To demonstrate the griefing angle specifically, extend this test so that (1) governance whitelists a call that would only succeed under a precondition set by a separate, not-yet-executed governance call, (2) an unprivileged account not intended to be the relayer calls `dispatch_whitelisted_call` before that precondition is met, causing failure, and (3) assert the entry is permanently gone and the legitimate relayer's subsequent attempt fails with `DeferredDispatchNotFound`/`CallIsNotWhitelisted`.

		pub fn dispatch_whitelisted_call(
			origin: OriginFor<T>,
			call_hash: T::Hash,
			call_encoded_len: u32,
			call_weight_witness: Weight,
		) -> DispatchResultWithPostInfo {
			let relayer = match T::DispatchWhitelistedOrigin::try_origin(origin) {
				Ok(_) if WhitelistedCall::<T>::contains_key(call_hash) => None,
				Ok(_) => {
					Self::defer_dispatch(call_hash)?;
					return Ok(Some(T::WeightInfo::defer_dispatch(0)).into());
				},
				Err(dispatch_origin) => {
					Some(Self::ensure_signed_deferred_dispatch(dispatch_origin, call_hash)?)
				},
			};

			let call_data = T::Preimages::fetch(&call_hash, Some(call_encoded_len))
				.map_err(|_| Error::<T>::UnavailablePreImage)?;

			let call = <T as Config>::RuntimeCall::decode_all_with_depth_limit(
				frame::deps::frame_support::MAX_EXTRINSIC_DEPTH,
				&mut &call_data[..],
			)
			.map_err(|_| Error::<T>::UndecodableCall)?;

			ensure!(
				call.get_dispatch_info().call_weight.all_lte(call_weight_witness),
				Error::<T>::InvalidCallWeightWitness
			);

			// Relayer isn't charged; the privileged direct path still pays.
			let pays_fee = if relayer.is_some() { Pays::No } else { Pays::Yes };

			let call_actual_weight = Self::clean_and_dispatch(call_hash, call);
			if let Some(who) = relayer {
				Self::deposit_event(Event::<T>::DeferredDispatchExecuted { call_hash, who });
			}

			let actual_weight = call_actual_weight.map(|w| {
				w.saturating_add(T::WeightInfo::dispatch_whitelisted_call(call_encoded_len))
			});
			Ok(PostDispatchInfo { actual_weight, pays_fee })
		}

	fn ensure_signed_deferred_dispatch(
		origin: T::RuntimeOrigin,
		call_hash: T::Hash,
	) -> Result<T::AccountId, DispatchError> {
		let who = ensure_signed(origin)?;

		let expire_at =
			DeferredDispatch::<T>::get(call_hash).ok_or(Error::<T>::DeferredDispatchNotFound)?;

		ensure!(
			T::BlockNumberProvider::current_block_number() < expire_at,
			Error::<T>::DeferredDispatchExpired
		);

		ensure!(WhitelistedCall::<T>::contains_key(call_hash), Error::<T>::CallIsNotWhitelisted);

		Ok(who)
	}

	/// Clean whitelisting/preimage and dispatch call.
	///
	/// Returns the inner call's actual weight.
	fn clean_and_dispatch(call_hash: T::Hash, call: <T as Config>::RuntimeCall) -> Option<Weight> {
		WhitelistedCall::<T>::remove(call_hash);
		T::Preimages::unrequest(&call_hash);
		DeferredDispatch::<T>::remove(call_hash);

		let result = call.dispatch(frame_system::Origin::<T>::Root.into());

		let call_actual_weight = match result {
			Ok(call_post_info) => call_post_info.actual_weight,
			Err(call_err) => call_err.post_info.actual_weight,
		};
		Self::deposit_event(Event::<T>::WhitelistedCallDispatched { call_hash, result });

		call_actual_weight
	}

#[test]
fn test_deferred_dispatch_failed_inner_call() {
	new_test_ext().execute_with(|| {
		// This call requires a signed origin, whitelisting dispatches calls with root.
		let call = RuntimeCall::System(frame_system::Call::remark_with_event { remark: vec![1] });
		let call_hash = <Test as frame_system::Config>::Hashing::hash_of(&call);
		let call_len = call.encoded_size() as u32;
		let encoded_call = call.encode();
		let call_weight = call.get_dispatch_info().call_weight;

		run_to_block(1);

		// Defer dispatch (no preimage yet)
		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::root(),
			call_hash,
			call_len,
			call_weight
		));

		assert!(events().iter().any(|event| {
			match event {
				Event::<Test>::DispatchDeferred { call_hash: hash } => hash == &call_hash,
				_ => false,
			}
		}));

		assert_ok!(Whitelist::whitelist_call(RuntimeOrigin::root(), call_hash));

		assert_ok!(Preimage::note(encoded_call.into()));

		assert!(Preimage::is_requested(&call_hash));

		// Try to dispatch with signed origin
		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::signed(1),
			call_hash,
			call_len,
			call_weight,
		));

		let emitted_events = events();

		assert!(emitted_events.iter().any(|event| {
			matches!(event, Event::<Test>::CallWhitelisted { call_hash: hash } if hash == &call_hash)
		}));

		// Dispatches with Root when executing whitelisted calls. However,
		// remark_with_event requires RawOrigin::Signed(_)
		assert!(emitted_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::WhitelistedCallDispatched {
					call_hash: hash,
					result: Err(DispatchErrorWithPostInfo { error: DispatchError::BadOrigin, .. })
				} if hash == &call_hash
			)
		}));

		// Even though the inner call failed, the deferred entry was still consumed by the relayer,
		// so `DeferredDispatchExecuted` is emitted regardless of the inner call's outcome.
		assert!(emitted_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::DeferredDispatchExecuted { call_hash: hash, who: 1 }
				if hash == &call_hash
			)
		}));
		assert!(!Preimage::is_requested(&call_hash));
	});

title: Add deferred dispatch support

doc:
  - audience: Runtime Dev
    description: |
      Extends `pallet-whitelist` with automatic deferred dispatch to aid governance
      sequencing. When `dispatch_whitelisted_call` or 
      `dispatch_whitelisted_call_with_preimage` is invoked by a whitelisted origin but
      the call hash is not yet whitelisted, the dispatch is no longer rejected. Instead,
      it is deferred with an expiration block and can be executed later by any signed
      origin once the call is whitelisted. The relaying signed origin is not charged.

      Adds the permissionless `remove_deferred_dispatch` extrinsic for cleaning up
      expired deferred entries, with fees refunded on success. Introduces new config
      types `DeferredDispatchExpiration` and `BlockNumberProvider` to control deferral
      timeout and block numbering.
