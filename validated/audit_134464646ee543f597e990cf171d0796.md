Audit Report

## Title
Stale/Rotated Workflow Signer Keys Remain Valid For HTTP Trigger Authentication Due To Cross-Shard "First-Writer-Wins" Metadata Merge - (File: core/services/gateway/handlers/capabilities/v2/workflow_metadata_handler.go)

## Summary
`WorkflowMetadataHandler.syncMetadata` rebuilds the `authorizedKeys` map used by `Authorize()` from each shard's `WorkflowMetadataAggregator.Aggregate()` output, iterating `h.shards` in a fixed order. [1](#0-0)  While a single shard's aggregator correctly sorts observations newest-first by `sequence`, [2](#0-1)  the cross-shard merge in `syncMetadata` only writes `authorizedKeys[workflowID]` the first time a `workflowID`/`workflowReference` pair is seen; any later shard reporting the same reference with rotated `AuthorizedKeys` is merely appended to the fan-out list without overwriting the stale key set. [3](#0-2) 

## Finding Description
`WorkflowMetadataAggregator.Collect` keys observations by the digest of the full `WorkflowMetadata` object (including `AuthorizedKeys`), so a key rotation produces a new digest while the old observation/digest persists in `agg.observations` until `reapObservations` removes it after `cleanupInterval` has elapsed with no renewed observation from a node. [4](#0-3) [5](#0-4) 

`syncMetadata` iterates `h.shards` in a static order, and for each shard calls `agg.Aggregate()`, which returns that shard's own observations sorted newest-first. [6](#0-5)  Crucially, there is no global comparison of `sequence` numbers across shards — "Case 1" logic only checks whether a `workflowReference` already exists in `workflowIDToRef`, and if so, merely appends the current shard to `workflowShards[workflowID]` without touching `authorizedKeys[workflowID]`. [3](#0-2)  This means whichever shard happens to be processed first for a given workflow (a function of `h.shards` order, not recency) permanently determines the authorized key set for that sync cycle, even if another shard already converged to newer, rotated keys.

`Authorize()` is the sole authentication gate for HTTP-trigger JSON-RPC requests and looks up signer keys directly from this map, so a stale entry directly translates into acceptance of a revoked signer. [7](#0-6)  No other check (JWT verification, replay cache) mitigates this, since JWT verification only confirms the signature matches a claimed signer address — it says nothing about whether that signer is still supposed to be authorized. [8](#0-7) 

## Impact Explanation
This is a genuine authentication/authorization staleness bug on the gateway's internet-facing HTTP trigger path: a caller who holds a formerly-authorized-but-now-rotated-out private key can still get their JWT-signed request accepted for up to a full `cleanupInterval` window (default 10 minutes, `CleanUpPeriodMs`) after rotation, and this window can recur on every `syncMetadata` cycle for as long as any shard's aggregator still reports the stale digest — because shard-processing order (not recency) decides the winner. This falls under the "node API authentication or role bypass" impact category.

## Likelihood Explanation
No malicious node or peer is required — the condition arises from ordinary asynchronous propagation of key-rotation metadata across the DON's shard aggregators, driven by the periodic `MetadataPullIntervalMs`/`MetadataAggregationIntervalMs` cadence. [9](#0-8)  The only requirement is that an attacker retain the previously-authorized private key and submit a request during the propagation/cleanup window — a realistic scenario precisely in the key-rotation/compromise-response case that rotation is meant to defend against.

## Recommendation
In `syncMetadata`, collect all per-shard aggregated observations for a given `workflowID`/`workflowReference` before writing to `authorizedKeys`, and select the one with the highest global `sequence` (or most recent timestamp) rather than the first one encountered while iterating `h.shards`. Additionally, align/shorten `cleanupInterval` with the metadata pull/aggregation cadence so stale key observations are reaped promptly after a rotation.

## Proof of Concept
1. Register workflow `W` with `AuthorizedKeys=[K_old]`, reaching quorum on shard A and shard B (digest `D_old`).
2. Rotate to `AuthorizedKeys=[K_new]`; nodes converge to digest `D_new`, but shard A's aggregator still holds `D_old` (not yet reaped) while shard B has converged to `D_new`.
3. Call `syncMetadata`: since shard A precedes shard B in `h.shards`, `authorizedKeys[W]` is set to `{K_old}` via Case 3; shard B's `D_new` observation hits Case 1 and is dropped/merged without updating `authorizedKeys[W]`.
4. An attacker holding `K_old`'s private key signs and submits an HTTP-trigger JSON-RPC request for `W`; `Authorize()` finds `K_old` still present in `h.authorizedKeys[W]` and accepts it.
5. A Go unit test can directly construct two `WorkflowMetadataAggregator` instances (simulating shard A/B), seed conflicting digests via `Collect`, invoke `syncMetadata`, and assert `authorizedKeys[W]` still contains `K_old` after `D_new` has reached quorum on shard B.

func (h *WorkflowMetadataHandler) Authorize(workflowID string, token string, req *jsonrpc.Request[json.RawMessage]) (*gateway.AuthorizedKey, error) {
	claims, signer, err := utils.VerifyRequestJWT(token, *req)
	if err != nil {
		h.lggr.Errorw("Failed to verify JWT", "error", err)
		return nil, err
	}

	if h.jwtCache.isReplay(claims.ID) {
		h.lggr.Warnw("JWT token has already been used", "workflowID", workflowID, "signer", signer.Hex(), "jti", claims.ID)
		return nil, errors.New("JWT token has already been used. Please generate a new one with new id (jti)")
	}

	keys, exists := h.authorizedKeys[workflowID]
	if !exists {
		h.lggr.Errorw("Workflow ID not found in authorized keys", "workflowID", workflowID)
		return nil, fmt.Errorf("workflow ID %s not found", workflowID)
	}
	key := gateway.AuthorizedKey{
		KeyType:   gateway.KeyTypeECDSAEVM,
		PublicKey: strings.ToLower(signer.Hex()),
	}
	if _, exists = keys[key]; !exists {
		h.lggr.Errorw("Signer not found in authorized keys", "signer", signer.Hex())
		return nil, fmt.Errorf("signer '%s' is not authorized for workflow '%s'. Ensure that the signer is registered in the workflow definition", signer.Hex(), workflowID)
	}
	h.jwtCache.recordUsage(claims.ID)

	return &key, nil
}

func (agg *WorkflowMetadataAggregator) reapObservations(ctx context.Context) {
	agg.mu.Lock()
	defer agg.mu.Unlock()
	now := time.Now()
	var expiredCount int
	for node, digestObservedAt := range agg.observedAt {
		for digest, observedAt := range digestObservedAt {
			if now.Sub(observedAt) > agg.cleanupInterval {
				delete(agg.observedAt[node], digest)
				if len(agg.observedAt[node]) == 0 {
					delete(agg.observedAt, node)
				}
				_, ok := agg.observations[digest]
				if !ok {
					agg.lggr.Warnw("Observation digest not found in observations", "digest", digest, "node", node)
					continue
				}
				agg.observations[digest].nodes.Remove(node)
				if len(agg.observations[digest].nodes) == 0 {
					delete(agg.observations, digest)
				}
				expiredCount++
			}
		}
	}
	if expiredCount > 0 {
		agg.metrics.IncrementMetadataObservationsCleanUpCount(ctx, int64(expiredCount), agg.lggr)
		agg.lggr.Debugw("Removed expired callbacks", "count", expiredCount)
	}
	agg.metrics.RecordMetadataObservationsCount(ctx, int64(len(agg.observations)), agg.lggr)

// Collect adds an observation from a workflow node to the aggregator.
func (agg *WorkflowMetadataAggregator) Collect(obs *gateway_common.WorkflowMetadata, nodeAddress string) error {
	if obs.WorkflowSelector.WorkflowID == "" || obs.WorkflowSelector.WorkflowName == "" ||
		obs.WorkflowSelector.WorkflowOwner == "" || obs.WorkflowSelector.WorkflowTag == "" {
		return errors.New("observation is missing required fields")
	}
	if nodeAddress == "" {
		return errors.New("node address cannot be empty")
	}
	agg.mu.Lock()
	defer agg.mu.Unlock()
	digest, err := obs.Digest()
	if err != nil {
		return err
	}
	_, ok := agg.observedAt[nodeAddress]
	if !ok {
		agg.observedAt[nodeAddress] = make(map[string]time.Time)
	}
	agg.observedAt[nodeAddress][digest] = time.Now()

	_, ok = agg.observations[digest]
	if !ok {
		agg.sequenceCounter++
		agg.observations[digest] = &NodeObservations{
			observation: obs,
			nodes:       make(StringSet),
			sequence:    agg.sequenceCounter,
		}
	}
	agg.observations[digest].nodes.Add(nodeAddress)
	return nil
}
