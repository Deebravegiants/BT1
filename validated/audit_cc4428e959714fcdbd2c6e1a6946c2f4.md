Audit Report

## Title
Unauthenticated exposure of LOOP plugin discovery, metrics, and pprof debug endpoints - (File: core/web/router.go)

## Summary
`loopRoutes` in `core/web/router.go` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` route group without any `auth.Authenticate(...)` wrapper, unlike every other sensitive route group in the same file (`debugRoutes`, `sessionRoutes`, `v2Routes`). This allows any unauthenticated network client to enumerate LOOP plugins, pull raw Prometheus metrics, and pull `pprof` profiles/heap dumps/goroutine traces from plugin processes.

## Finding Description
`NewRouter` builds the `api` group with only rate limiting and session middleware, then calls `loopRoutes(app, api)` alongside `debugRoutes`, `sessionRoutes`, and `v2Routes`: [1](#0-0) 

`debugRoutes` and `sessionRoutes` correctly scope their sensitive endpoints behind `auth.Authenticate(...)`: [2](#0-1) [3](#0-2) 

`v2Routes` similarly wraps its `authv2` group with `auth.Authenticate`: [4](#0-3) 

However, `loopRoutes` registers its four handlers directly on the unauthenticated `api` group with no auth middleware at all: [5](#0-4) 

The handlers themselves perform no authentication or authorization checks — `discoveryHandler` returns plugin names/target addresses, `pluginMetricHandler` and `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` proxy directly to the plugin's internal Prometheus/pprof ports based solely on the `:name` path parameter, which is looked up in the registry with no further access control: [6](#0-5) [7](#0-6) [8](#0-7) [9](#0-8) 

The inline comments "unlike discovery, this endpoint is internal btw the node and plugin" show the developer's intent that these are internal-trust-boundary endpoints, but there is no code-level enforcement (no auth middleware, no localhost-only bind, no separate listener) at the route-registration layer in `NewRouter`/`loopRoutes`.

## Impact Explanation
An unauthenticated client with network access to the node's main web server port can enumerate all registered LOOP plugins and internal Prometheus targets via `/discovery`, pull raw plugin metrics via `/plugins/:name/metrics`, and pull `pprof` heap/goroutine/profile/trace data via `/plugins/:name/debug/pprof/*`, all without any session, token, or role check. This is a genuine authentication-bypass gap on node API routes (matching the "node API authentication... bypass" impact category), since these routes were clearly intended to be gated the same way other sensitive routes are, but the code never attaches that gate. `pprof` profile/trace/heap data can expose internal memory contents and process state, and the `?seconds=N` proxying enables attacker-controlled long-running requests against the plugin's internal port.

## Likelihood Explanation
No credentials or special network position are required beyond reaching the node's already-public HTTP listener (the same port serving the authenticated `/v2/*` API and UI). A single unauthenticated `GET`/`POST` request triggers the exposure, and it is fully repeatable/scriptable, as shown by the four handlers in `core/web/loop_registry.go` all being reachable through `loopRoutes` with no auth middleware in `core/web/router.go`.

## Recommendation
Wrap the `loopRoutes` group in an authenticated route group (e.g., `r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))`), consistent with `debugRoutes`/`v2Routes`, and consider gating with `auth.RequiresAdminRole` given the sensitivity of pprof/metrics data. Alternatively, bind these plugin-discovery/metrics/pprof endpoints to a separate internal-only listener not exposed on the public API/UI port.

## Proof of Concept
Against a running node with any registered LOOP plugin:
```
curl http://<node-host>:<web-port>/discovery
curl http://<node-host>:<web-port>/plugins/<plugin-name>/metrics
curl http://<node-host>:<web-port>/plugins/<plugin-name>/debug/pprof/heap
curl "http://<node-host>:<web-port>/plugins/<plugin-name>/debug/pprof/profile?seconds=30"
```
No `Authorization` header, session cookie, or API key/secret is required for any of these four requests to return `200 OK` with plugin data, because `loopRoutes` (`core/web/router.go:230-236`) is registered on the `api` group without any `auth.Authenticate` wrapper, in contrast to `debugRoutes` and `v2Routes` in the same file.

```go
// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}
```

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")

	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))

	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
```

```go
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
```
