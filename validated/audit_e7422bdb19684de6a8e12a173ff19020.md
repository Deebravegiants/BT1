### Title
Unauthenticated exposure of internal LOOP plugin metrics and pprof/debug endpoints - (File: core/web/router.go)

### Summary
The Chainlink node's main HTTP router registers the LOOP registry's diagnostic endpoints (`/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) without any authentication/authorization middleware, unlike all other functional route groups in the same router.

### Finding Description
`NewRouter` builds an `api` group protected only by a rate limiter and cookie-session middleware, then calls `loopRoutes(app, api)`: [1](#0-0) [2](#0-1) 

Every other route group explicitly wraps its handlers with `auth.Authenticate(...)` — e.g. `debugRoutes` requires a session, and `v2Routes`/`sessionRoutes` require token or session auth: [3](#0-2) [4](#0-3) [5](#0-4) 

`loopRoutes`, by contrast, attaches the `LoopRegistryServer` handlers directly to the unauthenticated `api` group with no `auth.Authenticate` wrapper. The handler implementations themselves (`discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`) perform no session/token/role check — they only validate that the requested plugin name exists in the registry before proxying the request to the internal LOOP process: [6](#0-5) [7](#0-6) 

This mirrors the PowerDNS Recursor advisory pattern: an internal-only diagnostic web interface (there, the internal webserver; here, LOOP plugin metrics/pprof proxying) is reachable without the ACL/auth checks applied to the rest of the API surface.

### Impact Explanation
Any unauthenticated network client that can reach the node's HTTP listener can enumerate registered LOOP plugins via `/discovery`, pull Prometheus metrics for any plugin via `/plugins/:name/metrics`, and pull full Go `pprof` profiles (heap, goroutine, CPU/execution traces, `debug/pprof/symbol`) via `/plugins/:name/debug/pprof/*profile`. `pprof` data can leak sensitive internal state (memory contents, stack traces, function addresses, potentially embedded secrets/keys held in process memory), and repeated profile/trace requests can be used for resource-exhaustion/DoS against the plugin process. This is an information-disclosure and reconnaissance vector on unprivileged nodes, comparable in class to the CVE's ACL bypass on an internal admin/metrics surface.

### Likelihood Explanation
The routes are registered unconditionally in `NewRouter`, which is used for the node's primary HTTP listener; there is no config flag observed in this router construction gating `loopRoutes` behind an internal-only listener or auth. Any client with network access to the node's web server port can trigger this without credentials, making likelihood high wherever the node's HTTP port is reachable (e.g., misconfigured firewalling, cloud deployments where the API port is inadvertently exposed).

### Recommendation
Wrap `loopRoutes` handlers with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or a dedicated internal-only network binding/allowlist) used by `debugRoutes`, and add role checks (e.g., `auth.RequiresAdminRole`) consistent with other sensitive debug endpoints such as `/debug/vars`.

### Proof of Concept
1. Start a chainlink node with at least one LOOP plugin registered.
2. Without any session cookie or API token, issue: `curl http://<node-host>:<port>/discovery` — returns the list of registered plugins and their metrics paths.
3. `curl http://<node-host>:<port>/plugins/<plugin-name>/metrics` — returns the plugin's raw Prometheus metrics.
4. `curl http://<node-host>:<port>/plugins/<plugin-name>/debug/pprof/heap` — returns a full heap profile of the internal plugin process, all without authentication.

func sessionRoutes(app chainlink.Application, r *gin.RouterGroup) {
	config := app.GetConfig()
	rl := config.WebServer().RateLimit()
	unauth := r.Group("/", rateLimiter(
		rl.UnauthenticatedPeriod(),
		rl.Unauthenticated(),
	))
	sc := NewSessionsController(app)
	unauth.POST("/sessions", sc.Create)
	auth := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
	auth.DELETE("/sessions", sc.Destroy)
}

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
