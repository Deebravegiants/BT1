## Title
Stale `TombStone` metadata survives ordinary object transfers, letting a former owner reclaim an object from a later, legitimate owner's genuine burn — `aptos-move/framework/aptos-framework/sources/object.move`

### Summary
Aptos's `object.move` "soft burn" mechanism attaches a `TombStone{original_owner}` resource to an object without moving its ownership. Reclaiming from the burn address only happens later, when someone eventually sends the object to `BURN_ADDRESS` via an *ordinary* transfer. The ordinary-transfer path (`transfer`, `transfer_call`, `transfer_raw`, `transfer_to_object`, all routed through `transfer_raw_inner`) never clears an existing `TombStone`, whereas `transfer_with_ref` (the `TransferRef`/`LinearTransferRef` path) explicitly does. As a result, a `TombStone` created by one owner can survive multiple subsequent legitimate ownership changes and let that original address reclaim the object from a completely different, later owner's own burn action.

### Finding Description
`object::burn` does not move the object to `BURN_ADDRESS`; it only stamps a `TombStone` recording the current owner: [1](#0-0) 

`object::unburn` allows reclaiming the object whenever the current owner is `BURN_ADDRESS` and the `TombStone.original_owner` matches the caller — regardless of how many ordinary transfers happened in between: [2](#0-1) 

The regular transfer entry points (`transfer`, `transfer_call`, `transfer_raw`, `transfer_to_object`) all funnel through `transfer_raw_inner`, which updates `owner` but never checks or clears `TombStone`: [3](#0-2) 

By contrast, `transfer_with_ref` (used for `TransferRef`/`LinearTransferRef`-mediated transfers such as marketplace flows) explicitly clears any pre-existing `TombStone` before moving ownership: [4](#0-3) 

There is no check anywhere in the ordinary-transfer path (`verify_ungated_and_descendant`, `transfer_raw_inner`) that blocks transferring an object that already carries a `TombStone`, and no code path clears `TombStone.original_owner` when ownership changes via `transfer`/`transfer_call`/`transfer_raw`. This creates a stale-authorization invariant break directly analogous to the Optimism bug: a control record (`TombStone.original_owner`, akin to the proven `l2OutputIndex`) is bound to a point-in-time owner and is never invalidated/updated when the underlying custody state (the object's `owner`) legitimately changes, so a privileged action tied to that stale record (`unburn`) can later be exercised against the wrong custodian.

### Impact Explanation
This is a genuine ownership/custody takeover, not merely a liveness issue:
1. Alice owns object `O` and calls `object::burn(alice, O)` — this only adds `TombStone{original_owner: alice}`; `O` is still owned by Alice.
2. Alice sells/transfers `O` to Bob via `object::transfer` (ordinary ungated transfer). Ownership moves to Bob; the `TombStone` is **not** cleared.
3. Time later, Bob — the legitimate current owner, unaware the object was ever tombstoned by a prior owner — decides to permanently destroy `O` using the well-documented "old functionality" of sending it to `BURN_ADDRESS` via an ordinary transfer (`object::transfer(bob, O, BURN_ADDRESS)`).
4. Alice calls `object::unburn(alice, O)`. Since `owner == BURN_ADDRESS` and `TombStone.original_owner == alice`, the function transfers `O` back to Alice — not Bob.

Alice, who no longer had any claim to `O` at the time Bob burned it, steals the object from Bob. If `O` holds fungible-asset stores, token metadata, or other value, this is a direct "theft/owner reassignment of ... token objects or other object-held value," matching the custody impact gate. This can be triggered any time an object with any burn history changes hands through ordinary transfer functions, which is the default path for essentially all object transfers on Aptos (NFTs, token objects, etc.).

### Likelihood Explanation
The precondition is simply that an object was ever burned (soft-tombstoned) at some point in its ownership history and then transferred normally (not via `TransferRef`) — a very common pattern since `object::burn`/`unburn` and plain `object::transfer` are both public, permissionless entry functions with no privileged-role requirement. No leaked keys, no governance assumption, and no reliance on `TransferRef` capability are needed; only two unprivileged signers (the original tombstoner and the eventual burner) are required, and the attacker (original tombstoner) does not even need to coordinate with the victim — they only need to have burned the object once before selling it and wait for the new owner to eventually send it to `BURN_ADDRESS`.

### Recommendation
Clear `TombStone` on every ordinary ownership change, not just in `transfer_with_ref`. Concretely, `transfer_raw_inner` should also remove any existing `TombStone` when `object_core.owner` is updated (mirroring the logic already present in `transfer_with_ref`), so that a `TombStone.original_owner` can never refer to anyone other than the address that most recently and knowingly sent the object to `BURN_ADDRESS`. Alternatively, disallow ordinary transfers entirely while a `TombStone` exists (forcing burn-and-reclaim to go exclusively through `unburn`), removing the ability for the tombstone to "follow" the object through unrelated ownership changes.

### Proof of Concept
```
// Alice owns object O (allow_ungated_transfer = true, the default)
object::burn(&alice, O);                 // TombStone{original_owner: alice}; owner still alice
object::transfer(&alice, O, bob_addr);   // ordinary transfer; TombStone NOT cleared; owner = bob

// ... time passes, Bob legitimately owns O ...
object::transfer(&bob, O, BURN_ADDRESS); // Bob intentionally destroys O the "old" way; owner = BURN_ADDRESS
                                          // TombStone{original_owner: alice} still present, untouched

object::unburn(&alice, O);
// owner == BURN_ADDRESS branch taken; original_owner_addr (alice) == signer::address_of(alice) -> true
// transfer_raw_inner(O, alice) executes: ownership of O returns to Alice, not Bob.
```

    /// Transfer to the destination address using a LinearTransferRef.
    public fun transfer_with_ref(self: LinearTransferRef, to: address) {
        assert!(!exists<Untransferable>(self.self), error::permission_denied(EOBJECT_NOT_TRANSFERRABLE));

        // Undo soft burn if present as we don't want the original owner to be able to reclaim by calling unburn later.
        if (exists<TombStone>(self.self)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(self.self);
        };

        let object = borrow_global_mut<ObjectCore>(self.self);
        assert!(
            object.owner == self.owner,
            error::permission_denied(ENOT_OBJECT_OWNER),
        );
        event::emit(
            Transfer {
                object: self.self,
                from: object.owner,
                to,
            },
        );
        object.owner = to;
    }

    inline fun transfer_raw_inner(object: address, to: address) {
        let object_core = borrow_global_mut<ObjectCore>(object);
        if (object_core.owner != to) {
            event::emit(
                Transfer {
                    object,
                    from: object_core.owner,
                    to,
                },
            );
            object_core.owner = to;
        };
    }

    /// Allow origin owners to reclaim any objects they previous burnt.
    public entry fun unburn<T: key>(
        original_owner: &signer,
        object: Object<T>,
    ) {
        let object_addr = object.inner;
        assert!(exists<TombStone>(object_addr), error::invalid_argument(EOBJECT_NOT_BURNT));

        // The new owner of the object can always unburn it, but if it's the burn address, we go to the old functionality
        let object_core = borrow_global<ObjectCore>(object_addr);
        if (object_core.owner == signer::address_of(original_owner)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(object_addr);
        } else if (object_core.owner == BURN_ADDRESS) {
            // The old functionality
            let TombStone { original_owner: original_owner_addr } = move_from<TombStone>(object_addr);
            assert!(
                original_owner_addr == signer::address_of(original_owner),
                error::permission_denied(ENOT_OBJECT_OWNER)
            );
            transfer_raw_inner(object_addr, original_owner_addr);
        } else {
            abort error::permission_denied(ENOT_OBJECT_OWNER);
        };
    }
