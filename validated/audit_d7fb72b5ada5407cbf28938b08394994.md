This confirms the analysis: `composeMultiPayloads` performs pure array concatenation of already-independent, already-signed `MultiPayload` objects — it never parses, decodes, or mutates the `nonce`, `payload`, `signature`, or any other field of any of the payloads it composes.

**The claimed equality never breaks.** The new intent's `nonce` is generated and baked into `intentPayload` via `defaultIntentPayloadFactory`/`VersionedNonceBuilder.encodeNonce` before signing occurs: [1](#0-0) 

That `intentPayload` is then signed by `this.intentSigner.signIntent(intentPayload)`, producing `multiPayload` — a self-contained, already-signed object whose `nonce` is fixed and verified via the signature over that exact payload: [2](#0-1) 

Only *after* signing does `composeMultiPayloads` run, and it strictly appends/prepends the caller-supplied `signedIntents.before`/`.after` arrays around `multiPayload` without touching any of the three arrays' contents: [3](#0-2) 

The `sendSignedIntents`/`publishIntents` relayer call also just forwards the array as-is: [4](#0-3) 

For the `raw_ed25519` case specifically, `prepareSwapSignedData` (in `internal-utils`, a separate helper unrelated to `signAndSendIntent`/`composeMultiPayloads`) is a pure passthrough: it decodes the externally-signed wallet message bytes into a UTF-8 string and copies the signature/public key verbatim — it does not construct, parse, or alter `nonce` at all: [5](#0-4) 

The `nonce` for `raw_ed25519` lives inside the already-signed `payload` string, is hashed as-is via `computeSignedRawEd25519Hash`/`computeRawEd25519Hash` (`sha256(payload)`), and any bit-flip would simply invalidate the ed25519 signature against `intents.near`'s own verification, not silently "alter" an accepted nonce: [6](#0-5) 

Existing tests explicitly assert order-preserving, value-preserving composition (`prependIntent1, prependIntent2, newPayload` / `newPayload, appendIntent1, appendIntent2`), confirming no reordering, no mutation, no dedup collapse of distinct `MultiPayload` objects: [7](#0-6) [8](#0-7) 

The only dedup logic in the codebase (`mergeIntentPayloads`'s `Array.from(new Set(...))`) only affects the *new* intent's own `intents` array coming from `intentPayloadFactory` output, not the pre-signed `signedIntents.before/after` payloads, and it operates on object references, not on nonces: [9](#0-8) 

Because `intents.near` verifies each `MultiPayload`'s signature independently against its own unmodified `payload` (including its embedded `nonce`), an attacker supplying a crafted `signedIntents.before`/`.after` entry can only ever get their **own** pre-signed intent (with whatever nonce/content they themselves signed) bundled atomically alongside the caller's separately-signed intent — they cannot rewrite the nonce, diff, or any field of the SDK caller's own signed `token_diff`/`ft_withdraw` intent, since that intent was already fully formed and signed before composition happens.

function composeMultiPayloads(
	newPayload: MultiPayload,
	signedIntents?: SignedIntentsComposition,
): MultiPayload[] {
	if (!signedIntents) {
		return [newPayload];
	}

	const result: MultiPayload[] = [];

	// Add "before" intents first
	if (signedIntents.before && signedIntents.before.length > 0) {
		result.push(...signedIntents.before);
	}

	// Add the new payload
	result.push(newPayload);

	// Add "after" intents last
	if (signedIntents.after && signedIntents.after.length > 0) {
		result.push(...signedIntents.after);
	}

	return result;
}

import { sha256 } from "@noble/hashes/sha2";
import type { MultiPayload } from "@defuse-protocol/contract-types";

/**
 * Compute the SHA-256 hash of a Raw Ed25519 payload
 * This simply hashes the UTF-8 encoded payload string
 *
 * @param payload - The message string to hash
 * @returns 32-byte hash as Uint8Array
 */
export function computeRawEd25519Hash(payload: string): Uint8Array {
	const data = new TextEncoder().encode(payload);
	return sha256(data);
}

/**
 * Compute hash from a signed Raw Ed25519 payload
 *
 * @param signedPayload - The signed Raw Ed25519 payload
 * @returns 32-byte hash as Uint8Array
 */
export function computeSignedRawEd25519Hash(
	signedPayload: Extract<MultiPayload, { standard: "raw_ed25519" }>,
): Uint8Array {
	return computeRawEd25519Hash(signedPayload.payload);
