### Title
Unauthenticated "magic" operator QR-codes trigger privileged system resets before any operator identity verification - (File: `src/plans/mod.rs`)

### Summary
The `MasterPlan` QR scanning flow parses and executes "magic" operator QR-codes (`magic_action:reset_wifi_credentials` and `magic_action:reset_mirror_calibration`) and immediately performs the corresponding state-resetting action *before* the operator QR-code is validated against the backend. Any person able to present a QR-code to the Orb's camera — with no operator credential, no backend authorization, and no access control check of any kind — can force a Wi-Fi network reset or mirror-calibration reset, directly mirroring the reported bug class of a state-mutating function callable by anyone.

### Finding Description
The operator QR-code schema recognizes two "magic" actions purely from regex matching of the scanned string, with no authentication: [1](#0-0) 

These magic codes are dispatched in `handle_magic_operator_qr_code`, which performs `reset_mirror_calibration` or `reset_wifi_and_ensure_network` directly: [2](#0-1) 

Critically, in both callers of this handler (`scan_initial_qr_codes` and `scan_remaining_qr_codes`), `handle_magic_operator_qr_code` is invoked immediately after the raw QR-code scan and **before** `verify_operator_qr_code`, which is the only step that checks the QR-code against the signup backend: [3](#0-2) [4](#0-3) 

The backend verification (`verify_operator_qr_code`), which is the actual access-control gate confirming the scanned code belongs to a registered/authorized operator, only runs afterward: [5](#0-4) 

Because the magic-action branch returns early (`Ok(None)`) without ever calling `verify_operator_qr_code`, the reset actions execute unconditionally for anyone who shows the orb a QR-code encoding `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration` — there is no operator identity check, no backend authorization call, and no `openAccess`-style restriction analogous to what the external report flags as missing for `resetGame()`.

### Impact Explanation
An unprivileged, unauthenticated user (anyone who can hold a printed/displayed QR-code in front of the Orb) can:
- Force `network::reset()` and reconfiguration of the Wi-Fi connection via `reset_wifi_and_ensure_network`, disrupting connectivity and orb availability for legitimate operators/signups.
- Force `reset_mirror_calibration`, which rewrites the calibration file and re-triggers mirror calibration, disrupting biometric capture operation.

This is a denial-of-service / operational-disruption vector directly analogous to the `resetGame()` finding: a state-mutating action reachable without any authorization check, causing loss of expected state/availability. This matches the operator-authorization trust boundary called out as in-scope ("signup authorization" access-control class).

### Likelihood Explanation
Likelihood is high: triggering the bug only requires presenting a QR-code containing plain text (`magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration`) to the Orb's camera during the normal operator-QR-scanning phase of every signup cycle — no credentials, no physical device access, and no special privileges are needed.

### Recommendation
Move the magic-action handling to occur only after (or gated by) successful backend verification of the operator identity (`verify_operator_qr_code`), or otherwise require the magic action to itself be authenticated/signed and checked against the backend before executing `reset_mirror_calibration` / `reset_wifi_and_ensure_network`. At minimum, rate-limit and log/alert on magic-action triggers, and consider removing unauthenticated magic QR support in production builds.

### Proof of Concept
1. Generate a QR-code with payload `magic_action:reset_wifi_credentials` (or `magic_action:reset_mirror_calibration`).
2. During the Orb's idle/operator-scan phase, present this QR-code to the camera.
3. `scan_operator_qr_code` returns `qr_scan::operator::Data::MagicResetWifi` (or `MagicResetMirror`).
4. `handle_magic_operator_qr_code` immediately calls `reset_wifi_and_ensure_network` (or `reset_mirror_calibration`) — see [6](#0-5)  — with no prior call to `verify_operator_qr_code`, causing the network/mirror reset to execute for an entirely unauthenticated actor.

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }

    /// Checks if `qr_code` is a valid operator QR-code through the backend.
    #[allow(clippy::cast_possible_truncation)]
    async fn verify_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: &qr_scan::user::Data,
        qr_capture_start: Instant,
    ) -> Result<Option<(u64, backend::operator_status::LocationData)>> {
        if qr_code.signup_extension() || self.operator_qr_code_override.is_some() {
            return Ok(Some((0, backend::operator_status::LocationData {
                team_operating_country: "DEV".to_string(),
                session_coordinates: Coordinates { latitude: 0.0f64, longitude: 0.0f64 },
                stationary_location_coordinates: None,
            })));
        }
        let http_start = Instant::now();
        match backend::operator_status::request(qr_code).await {
            Ok(backend::operator_status::Status { valid: true, location_data, reason: _ }) => {
                let location_data = location_data
                    .expect("to always have a result from the backend if valid == true");
                orb.ui.qr_scan_success(QrScanSchema::Operator);
                dd_incr!("main.count.global.distr_code_validated");
                tracing::info!("Operator QR-code validated: {qr_code:?}");
                dd_timing!("main.time.signup.distr_qr_code_capture", qr_capture_start);
                return Ok(Some((http_start.elapsed().as_millis() as u64, location_data)));
            }
            Ok(backend::operator_status::Status { valid: false, .. }) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
                dd_incr!("main.count.signup.result.failure.distr_qr_code", "type:invalid_qr");
            }
            Err(_) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
            }
        }
        Ok(None)
    }
