### Title
Missing contract-existence check lets `EvmHost` mark GET responses and timeouts as delivered when the destination has no code - ([File: evm/src/core/EvmHost.sol])

### Summary
`EvmHost.dispatchIncoming(PostRequest, ...)` explicitly guards against calling a destination with no code by checking `extcodesize` before issuing the low-level `.call`, and returns early without mutating state if the target is not a contract: [1](#0-0) 

However, the sibling functions `dispatchIncoming(GetResponse, ...)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)` perform the identical low-level `.call` pattern to an address decoded from relayed proof data, but omit the `extcodesize` check entirely: [2](#0-1) [3](#0-2) 

### Finding Description
This mirrors the reported bug class exactly: Solidity's low-level `.call` returns `success = true` when the target address has no code (per EVM design, and as noted in the Solidity docs quoted in the original report). `dispatchIncoming(PostRequest)` was hardened against this by an explicit `extcodesize` check, proving the team is aware of the hazard, but the three other dispatch paths that also perform an unguarded `.call` to an externally/relayer-supplied address were not given the same treatment.

In `dispatchIncoming(GetResponse, ...)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)`, the destination is decoded via `_bytesToAddress(...)` from `response.request.from` / `timeout.request.from` — fields that are part of the original cross-chain request payload and thus attacker/relayer influenced in the sense that a relayer submits the proof that ultimately reaches these functions through `HandlerV2`. If that decoded address has no deployed code (e.g., the destination self-destructed, was never deployed, or is an EOA), the `.call` silently "succeeds" with empty returndata even though no `onGetResponse`/`onGetTimeout`/`onPostRequestTimeout` handler ever ran.

Because these functions treat a vacuous `.call` success identically to a genuine successful callback, they proceed to:
- permanently delete replay-protection state (`_requestReceipts`/`_requestCommitments`), and
- pay out the relayer fee via `IERC20(feeToken()).safeTransfer(...)`,

even though the destination module never actually received or processed the message. Unlike `dispatchIncoming(PostRequest)`, which returns early to allow the message to be retried later, these three functions permanently consume the message on a no-op call, since receipts/commitments are deleted before any possibility of retry.

### Impact Explanation
This is a "route unable to deliver messages" condition per the fitting Hyperbridge criterion: any GET response or GET/POST timeout whose destination module address has no code at delivery time is irrecoverably marked as handled — deleting the commitment/receipt state that would otherwise allow retry — without the destination application ever executing its callback logic. Any relayer can trigger this path by submitting a valid proof for a message whose destination has become codeless (e.g., after a destination contract self-destructs, or is a proxy pointed at nothing), silently starving the destination module of a message it was entitled to receive while relayer fees are still paid out as if delivery succeeded.

### Likelihood Explanation
The condition requires the destination `from` address encoded in the request to have no code at the time the response/timeout proof is relayed. This is plausible whenever destination modules can self-destruct, are deployed via CREATE2 patterns not yet initialized, or in any scenario where a request/response pairing spans a window in which the destination's code presence changes. Given the codebase's own precedent of explicitly guarding `dispatchIncoming(PostRequest)` against exactly this scenario, the missing checks on the other three paths represent a real gap rather than a theoretical one, though it is likely a lower-probability trigger than the PostRequest path since GET/timeout flows always target the address that itself dispatched the original request.

### Recommendation
Add the same `extcodesize`-based existence check (or higher-level equivalent, e.g. `address.code.length == 0`) to `dispatchIncoming(GetResponse, ...)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)` before performing the low-level `.call`, mirroring the guard already present in `dispatchIncoming(PostRequest, ...)`, and return early (preserving state so the message can be retried) rather than treating a codeless target's vacuous success as a completed delivery.

### Proof of Concept
1. A contract `C` dispatches a `DispatchGet` request via `EvmHost.dispatch(DispatchGet)`, setting `request.from = address(C)`.
2. `C` subsequently self-destructs (or, for the POST-timeout path, the original POST request's `from` module self-destructs) before the GET response or timeout is relayed back.
3. A relayer submits a valid membership/timeout proof to `HandlerV2`, which invokes `EvmHost.dispatchIncoming(GetResponse, relayer)` (or the relevant `dispatchTimeOut`).
4. `_bytesToAddress(response.request.from)` now points to a codeless address; `.call(...)` returns `(true, "")` without executing any handler.
5. `EvmHost` proceeds as if delivery succeeded: deletes the receipt/commitment and transfers the relayer fee via `safeTransfer`, permanently discarding the message with no possibility of retry and no actual application-level processing — unlike the explicit early-return safety net present in `dispatchIncoming(PostRequest)`.

    function dispatchIncoming(PostRequest memory request, address relayer) external restrict(_hostParams.handler) {
        address destination = _bytesToAddress(request.to);
        uint256 size;
        assembly {
            size := extcodesize(destination)
        }
        if (size == 0) {
            // instead of reverting the entire batch, early return here.
            return;
        }

        // replay protection
        bytes32 commitment = request.hash();
        _requestReceipts[commitment] = relayer;

        (bool success,) = address(destination)
            .call(abi.encodeWithSelector(IApp.onAccept.selector, IncomingPostRequest(request, relayer)));

        if (!success) {
            // so that it can be retried
            delete _requestReceipts[commitment];
            return;
        }
        emit PostRequestHandled({commitment: commitment, relayer: relayer});

    /**
     * @dev Dispatch an incoming GET response to source module
     * @param response - get response
     */
    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    /**
     * @dev Dispatch an incoming GET timeout to the source module.
     * @notice Does not refund any protocol fees.
     * @param timeout - timed-out get request bundled with the relayer that submitted the timeout proof
     * @param meta - fee metadata for the original request
     * @param commitment - request commitment
     */
    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }
