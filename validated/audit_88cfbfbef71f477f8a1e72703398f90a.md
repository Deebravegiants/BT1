### Title
Unauthenticated "Magic QR Code" allows any presenter to wipe Wi-Fi credentials and mirror calibration, causing a signup-blocking DOS - (File: `src/plans/qr_scan/operator.rs`, `src/plans/mod.rs`)

### Summary
The Notional report describes an unauthenticated actor gaining privileged control over an uninitialized implementation contract and using that control to self-destruct it, bricking the proxy until redeployment. The closest reachable analog in `orb-core` is the "magic QR code" mechanism: a plain-text QR code matching `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration` is accepted and executed by the orb during operator QR-code scanning **before any backend/operator authentication check** runs, letting any unauthenticated bystander wipe the orb's Wi-Fi configuration or mirror calibration.

### Finding Description
`qr_scan::operator::Data::try_parse` recognizes a `MAGIC_QR_CODE` regex (`magic_action:<action>`) and maps `reset_wifi_credentials` / `reset_mirror_calibration` strings directly to `Data::MagicResetWifi` / `Data::MagicResetMirror` variants with no signature, credential, or identity check whatsoever [1](#0-0) .

These variants are dispatched from `handle_magic_operator_qr_code`, which is called immediately after a QR code is scanned and *before* `verify_operator_qr_code` (the function that performs the actual backend authorization call to validate the operator) [2](#0-1) :

```
let Some(operator_qr_code) =
    self.handle_magic_operator_qr_code(orb, operator_qr_code).await?
...
let Some((duration_since_shot_ms, operator_location_data)) = self
    .verify_operator_qr_code(orb, &operator_qr_code, qr_capture_start)
    .await?
```

`handle_magic_operator_qr_code` executes privileged device actions with no additional check [3](#0-2) :
- `MagicResetMirror` → `reset_mirror_calibration`, which overwrites the on-disk calibration file and reprograms the mirror actuator [4](#0-3) .
- `MagicResetWifi` → `reset_wifi_and_ensure_network`, which calls `network::reset()` (restores the *default* `wpa_supplicant.conf` and forces a reconfigure, dropping the current Wi-Fi connection) and then blocks waiting for a new Wi-Fi QR code to be scanned [5](#0-4) . The underlying `network::reset()` implementation confirms this destroys the existing network configuration [6](#0-5) .

This path is reachable in both the normal operator-driven flow (`scan_remaining_qr_codes`) and the unattended self-serve idle flow (`scan_initial_qr_codes`), meaning even in kiosk/self-serve mode where no operator is physically supervising the device, any person who can present a QR code to the camera can trigger these actions [7](#0-6) .

### Impact Explanation
An unprivileged, unauthenticated bystander who presents a crafted QR code (`magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration`) to the orb's camera can:
- Disconnect the orb from its configured Wi-Fi network by restoring the default `wpa_supplicant` config, requiring a new Wi-Fi credential QR to restore connectivity — during which time the orb cannot reach the backend to validate operators/users, blocking all signups (denial of service), analogous to the original report's "prevent all interactions until [something] is deployed" impact.
- Overwrite the stored mirror calibration file with default values, degrading eye-tracking accuracy and biometric capture quality for all subsequent signups until manually recalibrated.

This is a device/service-availability DOS reachable by an unprivileged actor with physical proximity to the orb and no credentials, matching the analog class permitted by the rules (signup authorization bypass with concrete availability impact).

### Likelihood Explanation
Likelihood is high in self-serve/kiosk configurations, since the magic QR code is checked and acted upon in `scan_initial_qr_codes`/`scan_remaining_qr_codes` prior to any backend authentication of the "operator" QR code — an attacker only needs to print or display two short static strings; no valid operator ID, distributor ID, or backend cooperation is required.

### Recommendation
Require operator authentication (the same backend `operator_status::request` validation used for normal operator QR codes) before honoring `MagicResetWifi`/`MagicResetMirror` actions, or restrict these actions to a physically-secured maintenance mode (e.g., requiring a signed/authenticated magic code, or gating behind a debug/maintenance CLI flag rather than an openly scannable QR code).

### Proof of Concept
1. Print a QR code containing the literal string `magic_action:reset_wifi_credentials`.
2. Present it to the orb during operator QR-code scanning (works in both self-serve idle scanning and normal button-press flows, since `handle_magic_operator_qr_code` is invoked before `verify_operator_qr_code`).
3. Observe `network::reset()` is invoked, restoring default Wi-Fi config and dropping the current connection; the orb blocks in `wifi::Plan::ensure_network_connection` waiting for a fresh Wi-Fi QR, halting all signup processing until a legitimate Wi-Fi credential is re-provisioned.
4. Repeat with `magic_action:reset_mirror_calibration` to observe the calibration file being overwritten with defaults with no authentication.

static MAGIC_QR_CODE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")
});

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
