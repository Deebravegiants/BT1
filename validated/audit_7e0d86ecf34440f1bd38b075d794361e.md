**Rationale:**

The `inner_instructions` parameter (`enable_cpi_recording`) in `simulate_transaction` is a metadata/telemetry toggle, not a state-mutation toggle. In `runtime/src/bank.rs`, `simulate_transaction_unchecked` always sets `enable_log_recording`, `enable_return_data_recording`, and `enable_transaction_balance_recording` to `true` unconditionally; only `enable_cpi_recording` is attacker-controlled, and it exclusively gates whether `deconstruct_transaction` in `svm/src/transaction_processor.rs` populates the `InnerInstructionsList` for the RPC response. [1](#0-0) 

Simulation is executed via `load_and_execute_transactions`, the same function used for real leader execution, so the CPI chain, lamport transfers, and balance math are computed identically regardless of the flag — `enable_cpi_recording` only decides whether the trace is *extracted and surfaced*, not whether it's *executed differently*. Critically, simulation never reaches `load_execute_and_commit_transactions`/commit path; results are discarded after computation, so there is no persisted state to diverge from. [2](#0-1) [3](#0-2) 

The invariant check `transaction_accounts_lamports_sum` runs unconditionally after execution regardless of the recording flags, ensuring lamport conservation is enforced identically whether or not CPI recording is enabled — so toggling `inner_instructions=true` cannot mask an accounting bug; if one existed, it would surface as `UnbalancedTransaction` in both the simulated and real execution paths since both use the same `execute_loaded_transaction`/`deconstruct_transaction` machinery. [4](#0-3) 

The RPC test `test_rpc_simulate_transaction_with_inner_instructions` confirms `preBalances`/`postBalances` are byte-identical whether `innerInstructions` is `false` or `true`, empirically demonstrating the flag has no effect on balance computation. [5](#0-4) [6](#0-5) 

There is no code path by which an attacker toggling `inner_instructions` can cause simulated and committed lamport balances to diverge — the flag only affects response payload contents, not execution semantics, and simulation never persists to committed state regardless.
