### Title
`pallet_ismp_demo::IsmpModuleCallback::on_accept` builds a `String` from an unvalidated, attacker-controlled ISMP request body via `String::from_utf8_unchecked` - ([File: modules/pallets/demo/src/lib.rs])

### Summary
`pallet-ismp-demo` is wired into the production Gargantua runtime's ISMP router (`ProxyModule::on_accept` dispatches to `pallet_ismp_demo::PALLET_ID`), so any unprivileged relayer who delivers a proven ISMP POST request targeting this pallet from an `Evm` source reaches `IsmpModuleCallback::on_accept`, which decodes the request body with `unsafe { String::from_utf8_unchecked(request.body) }` without checking UTF-8 validity first.

### Finding Description
The abomonation advisory's core issue is transmuting untrusted bytes into a Rust type without validating the invariants that type requires, which is undefined behavior (UB) when the invariant is violated. `String::from_utf8_unchecked` has exactly this contract: the caller must guarantee the bytes are valid UTF-8, otherwise it is instant UB per the Rust standard library documentation, since `String` internals (and every subsequent operation on it, e.g. string comparisons, slicing, `Debug`/`Display` formatting, or SCALE re-encoding when embedded in an event) assume the UTF-8 invariant holds.

In this codebase: [1](#0-0) 

the `on_accept` handler is reached whenever an ISMP POST request from `StateMachine::Evm(_)` is delivered to `pallet_ismp_demo::PALLET_ID`, and `request.body` — fully attacker-controlled data carried inside the POST request — is passed straight into `String::from_utf8_unchecked` with no prior `str::from_utf8`/`String::from_utf8` validation: [2](#0-1) 

This pallet is not test-only scaffolding kept out of production; it is configured into the Gargantua parachain runtime and reachable through the router's `on_accept` dispatch: [3](#0-2) [4](#0-3) 

Delivery of the POST request itself only requires a relayer submitting a valid ISMP state/consensus proof (`handle_unsigned`/message-handling path) for a message whose `to` field encodes `pallet_ismp_demo::PALLET_ID` and whose `source` is `StateMachine::Evm(_)` — the body content is otherwise unconstrained, so an attacker fully controls the byte sequence that gets forced into a `String` via UB-triggering unsafe code.

### Impact Explanation
`String::from_utf8_unchecked` on invalid UTF-8 is immediate undefined behavior in the Rust language model — not merely a logic bug. In a Substrate runtime (WASM), the practical consequences of UB here include: the `Event::Request { data: ... }` being emitted with an invalid `String` value that is subsequently encoded/decoded by SCALE codec and consumed by indexers, RPC clients, or downstream `Debug`/`Display` calls, any of which the compiler is licensed to miscompile around this UB (e.g., unsound length calculations, unexpected memory reads, or panics during runtime execution that can halt block production). Since this runs inside on-chain STF logic invoked by any unprivileged relayer's message delivery, it constitutes a state-transition/runtime soundness break — the same bug class as the abomonation advisory (unchecked transmute of untrusted bytes into a type with invariants), reachable via a single relayed ISMP POST request. This satisfies "unsound state commitment / unauthorized app action" impact criteria since a malformed value can propagate into on-chain event storage and downstream indexing/relayer accounting that trusts the emitted `String`.

### Likelihood Explanation
High likelihood of triggering: any relayer or message dispatcher able to get a valid consensus/state proof accepted (a normal, unprivileged operation for any of the configured consensus clients such as BSC, sync-committee, GRANDPA, Beefy, etc.) can craft an ISMP POST request from an `Evm` source with an arbitrary, non-UTF-8 body targeting `pallet_ismp_demo::PALLET_ID`. No signature or privileged origin is required beyond normal message relaying, and the destination module lookup (`ModuleId::from_bytes`) only requires matching the pallet's `to` bytes, which are public/well-known constants (`PALLET_ID = ModuleId::Pallet(PalletId(*b"ismp-ast"))`).

### Recommendation
Replace `unsafe { String::from_utf8_unchecked(request.body) }` with `String::from_utf8(request.body)` and propagate/handle the `Err` case (e.g., reject the message or store the body as raw bytes / use `String::from_utf8_lossy` if display-only lossy conversion is acceptable), removing the unsafe block entirely so untrusted input can never violate `String`'s validity invariant.

### Proof of Concept
1. As any relayer, obtain (or construct, if a consensus client accepts it) a valid consensus/state proof for an EVM source chain that has emitted an ISMP POST request with:
   - `source = StateMachine::Evm(<chain_id>)`
   - `dest = HostStateMachine` (the Gargantua parachain's own state machine id)
   - `to = pallet_ismp_demo::PALLET_ID.to_bytes()` (i.e. `b"ismp-ast"`-derived `PalletId` bytes)
   - `body = vec![0xFF, 0xFE, 0x00]` (invalid UTF-8 byte sequence)
2. Submit this proof/message through the normal ISMP `handle`/`handle_unsigned` message-delivery extrinsic path so `Ismp::dispatch_request`/router delivery calls `ProxyModule::on_accept` → `pallet_ismp_demo::PALLET_ID` branch → `IsmpModuleCallback::on_accept`.

impl<T: Config> IsmpModule for IsmpModuleCallback<T> {
	fn on_accept(&self, request: PostRequest) -> Result<Weight, anyhow::Error> {
		let source_chain = request.source;

		match source_chain {
			StateMachine::Evm(_) => Pallet::<T>::deposit_event(Event::Request {
				source: source_chain,
				data: unsafe { String::from_utf8_unchecked(request.body) },
			}),
			StateMachine::Polkadot(_) | StateMachine::Kusama(_) => {
				let payload =
					<Payload<T::AccountId, <T as Config>::Balance> as codec::Decode>::decode(
						&mut &*request.body,
					)
					.map_err(|_| IsmpError::Custom("Failed to decode request data".to_string()))?;
				<T::NativeCurrency as Mutate<T::AccountId>>::mint_into(
					&payload.to,
					payload.amount.into(),
				)
				.map_err(|_| IsmpError::Custom("Failed to mint funds".to_string()))?;
				Pallet::<T>::deposit_event(Event::<T>::BalanceReceived {
					from: payload.from,
					to: payload.to,
					amount: payload.amount,
					source_chain,
				});
			},
			source => Err(IsmpError::Custom(format!("Unsupported source {source:?}")))?,
		}

		Ok(weight())
	}
