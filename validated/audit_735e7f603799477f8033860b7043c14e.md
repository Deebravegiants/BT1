### Title
Accrual-time `i128` RAY-value overflow permanently freezes a saturated market — all repay, withdraw, and liquidation paths revert — (File: common/src/rates/scaling.rs)

### Summary
The integer-overflow bug class (CVE-2020-15975) maps onto the pool's `i128` RAY-domain arithmetic. `scaled_to_original` multiplies scaled shares by the index via `Ray::mul`, which panics with `GenericError::MathOverflow` when `borrowed * borrow_index` or `supplied * supply_index` no longer fits `i128`. Because every mutating pool verb accrues interest first, once a market's RAY-denominated debt value crosses the representable ceiling the market freezes permanently: `repay`, `withdraw`, `borrow`, `liquidate`, `clean_bad_debt`, and `recapitalize` all revert inside `accrue_step`/`calculate_utilization`, and the borrow-index ceiling (`MAX_BORROW_INDEX_RAY` = 10^36) never engages because value overflow hits first. The codebase's own test `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap` demonstrates this end-to-end.

### Finding Description
`Cache::calculate_utilization` (`contracts/pool/src/cache/scale.rs:19-27`) computes `scaled_to_original(borrowed, borrow_index)` on every accrual chunk, and `accrue_chunk` (`contracts/pool/src/interest.rs:39-53`) runs inside `global_sync`, which every op invokes before touching positions. `Ray::mul` panics on overflow (`common/src/math/fp_core.rs:108-118` widens only the *product*, not the *result* — the quotient still must fit `i128`). The debt value `borrowed * borrow_index` therefore has a hard `i128::MAX` ceiling. With a whale-scale market (≈10^27 base units supplied, i.e. ~1e9 18-decimal tokens — within the admitted cap domain per `docs/reference/formulas.md:429`) driven to ~98% utilization on a steep curve segment, sustained accrual pushes `borrowed * borrow_index` past `i128::MAX` while `borrow_index < MAX_BORROW_INDEX_RAY`. From that point every call that triggers `global_sync` reverts with `MathOverflow`, and nothing can reduce `borrowed` or the index — `clean_bad_debt` and `recapitalize` also accrue first. The freeze is irreversible.

### Impact Explanation
Permanent freezing of funds: all suppliers' deposits and all borrowers' collateral locked in that market become unrecoverable; liquidators cannot clear positions, and bad debt cannot be written down or recapitalized. `docs/reference/formulas.md:431-437` and `invariants.md` INV-IDX-01 acknowledge the limit exists ("Value overflow can occur before the index ceiling and block repayment/withdrawal"), but the docs treat it as an arithmetic bound, not a mitigation — there is no ceiling alarm, no governance recovery path, and no op that skips accrual.

### Likelihood Explanation
An unprivileged attacker can drive the condition deliberately: supply a very large position in a cheap high-supply token, borrow it to ~98% utilization (the borrower's own collateral requirements apply, but the attacker can use a second account's collateral in other markets), then keep utilization pinned high while `update_indexes` accrues. The required capital is large (cap-domain scale) and the attacker locks their own funds, but the attack is reachable through only `supply`, `borrow`, and `update_indexes` — no privilege needed — and the damage extends to all other suppliers in the market. Medium likelihood: capital-intensive and slow, but deterministic once funded.

### Recommendation
- Make accrual overflow-safe: clamp `borrowed * borrow_index` at `i128::MAX` (saturating, like `mul_div_floor_saturating` already used for caps) so index growth stops at the representable bound instead of trapping.
- Add a utilization/rate dampener or hard debt ceiling well below the RAY-value cliff (e.g., enforce `borrowed * borrow_index_max < i128::MAX` at borrow time).
- Provide a non-accruing emergency path (e.g., `clean_bad_debt`/`recapitalize` variant that skips `global_sync`) so a frozen market can still be wound down.

### Proof of Concept
See `tests/test-harness/tests/controller/large_positions_and_long_horizons.rs:320-361`: supplies `BILLION * 10^18` of an 18-decimal market, borrows 98% against collateral in another market, advances time yearly, and asserts that `update_indexes` reverts with `MATH_OVERFLOW` before `MAX_BORROW_INDEX_RAY` is reached — after which `try_withdraw_raw` and `try_repay` also revert with `MATH_OVERFLOW`, leaving all funds locked.

```rust
pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}
```

```rust
pub fn mul_div_half_up(env: &Env, x: i128, y: i128, d: i128) -> i128 {
    // The zero check runs first so debug and release builds agree on a zero
    // divisor: both surface `DivisionByZero` rather than tripping the assert.
    require_nonzero_divisor(env, d);
    debug_assert!(
        x >= 0 && y >= 0 && d > 0,
        "mul_div_half_up: non-negative x, y and positive d"
    );
    try_mul_div_half_up(env, x, y, d)
        .unwrap_or_else(|| panic_with_error!(env, GenericError::MathOverflow))
}
```

```rust
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
    std::println!(
        "ray-value cliff reached after {years} years at 98 percent utilization on the XLM curve; last index x{:.1}",
        last.borrow_index as f64 / RAY as f64
    );
```
