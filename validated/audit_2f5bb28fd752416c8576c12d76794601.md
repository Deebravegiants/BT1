### Title
Unauthenticated Magic QR Codes Reset WiFi Credentials and Mirror Calibration Before Operator Verification - (File: `src/plans/mod.rs`)

### Summary
`handle_magic_operator_qr_code` executes privileged reset actions (`MagicResetWifi`, `MagicResetMirror`) for any QR code matching the `magic_action:...` pattern *before* the operator QR code is verified against the backend. This mirrors the `Vesting.sol` bug class: state that is supposed to be gated behind a privileged check (operator legitimacy) gets overwritten/erased by an unprivileged caller simply by presenting crafted, unauthenticated input.

### Finding Description
In `src/plans/mod.rs`, both `scan_initial_qr_codes` and `scan_remaining_qr_codes` call `self.handle_magic_operator_qr_code(orb, operator_qr_code)` immediately after scanning a QR code, and only call `self.verify_operator_qr_code(...)` (the backend authorization check that confirms the scanned code belongs to a valid, registered operator) afterward: [1](#0-0) [2](#0-1) 

`handle_magic_operator_qr_code` parses the QR code via `qr_scan::operator::Data::try_parse`, which recognizes any `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration` string, with no signature, authentication, or operator-identity check at all: [3](#0-2) 

When such a magic code is detected, the orb immediately performs the privileged reset actions and never proceeds to `verify_operator_qr_code`: [4](#0-3) 

`reset_wifi_and_ensure_network` calls `network::reset()`, which overwrites/erases the existing `wpa_supplicant.conf` (i.e., the currently configured WiFi credentials) and forces a reconfiguration/disconnection: [5](#0-4) [6](#0-5) 

This is directly analogous to the `benRevocable` overwrite bug: a security/config state that should only be settable by a privileged/authorized party (an authenticated operator) is instead overwritten by any unprivileged party who can merely present a crafted string, because the authorization check (`verify_operator_qr_code`) runs strictly after the state-mutating action, not before it.

### Impact Explanation
Any person who can present a QR code to the orb's camera — without being a registered/authenticated operator — can:
- Erase the orb's configured WiFi credentials and force it to re-enter WiFi-setup mode (`network::reset()` + `wifi::Plan.ensure_network_connection`), causing a denial-of-service on connectivity and enabling an attacker-controlled captive/rogue-AP takeover of the orb's network path if they subsequently also control a QR code for network join.
- Reset mirror calibration (`reset_mirror_calibration`), silently altering the biometric-capture optical geometry used during signups, without any operator authorization. Because this action is fully unauthenticated and executed unconditionally, it degrades the assurance that only vetted operators can alter capture-affecting hardware state, undermining the fraud/liveness enforcement model that assumes an authenticated operator oversees each signup session.

### Likelihood Explanation
High. No secret, signature, or backend validation is required — only the ability to display a QR code containing the literal string `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration` to the orb's camera during the idle/operator-scanning phase, which is the earliest, fully unauthenticated stage of the flow.

### Recommendation
Move `verify_operator_qr_code` (or an equivalent operator-authorization check) before executing any magic/privileged action, or otherwise require that magic QR codes be signed/verified by the backend before being honored. Do not perform any state-mutating action (`network::reset()`, `reset_mirror_calibration`) based solely on locally-parsed, unauthenticated QR content.

### Proof of Concept
1. Print a QR code with content `magic_action:reset_wifi_credentials`.
2. Present it to the orb during idle/operator QR scanning.
3. Observe `handle_magic_operator_qr_code` matches `Data::MagicResetWifi` and calls `reset_wifi_and_ensure_network`, which invokes `network::reset()` and erases the WiFi configuration — all before any operator-identity verification against the backend occurs. [7](#0-6)

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }

                "reset_wifi_credentials" => Some(Data::MagicResetWifi),

                _ => None,
            };
        }
        None

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
