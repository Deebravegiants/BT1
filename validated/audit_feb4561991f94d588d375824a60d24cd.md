### Title
Stack-exhaustion DoS via unbounded recursive decode of nested calls in `pallet_call_decompressor` — already mitigated ([File: modules/pallets/call-decompressor/src/lib.rs])

### Summary
The QPDF CVE-2017-11624 bug class is a stack-consumption denial of service caused by unbounded recursive parsing of adversary-supplied nested structures. The directly analogous reachable path in this codebase is `pallet_call_decompressor::decompress_call`/`validate_unsigned`, an unsigned, permissionless extrinsic that decodes an attacker-supplied compressed `RuntimeCall` (which can wrap `pallet_ismp::Call::handle_unsigned` messages) using SCALE codec decoding.

### Finding Description
`decode_and_execute` and `validate_unsigned` in [1](#0-0)  and [2](#0-1)  decode an unsigned, attacker-submitted `RuntimeCall` from decompressed bytes. Because `RuntimeCall` can recursively nest (e.g. `pallet_sudo::Call::sudo { call: Box<RuntimeCall> }`), naive SCALE decoding of deeply nested calls can exhaust the call stack during decode, crashing the node — exactly the QPDF-class bug (stack consumption via nested recursive parsing reachable through consecutive/nested parse calls).

This exact bug class was already identified in this codebase and mitigated by bounding the decode recursion depth with `codec::DecodeLimit::decode_all_with_depth_limit` and `MAX_EXTRINSIC_DECODE_DEPTH_LIMIT = 4` [3](#0-2) , applied consistently on both the unsigned mempool validation path and the dispatch/execution path [4](#0-3) [5](#0-4) . A regression test `decompress_stack_exhaustion_poc` constructs 1000 nested `pallet_sudo::Call::sudo` calls, compresses them, and confirms the pallet rejects the payload with `ErrorDecodingCall` instead of crashing [6](#0-5) .

### Impact Explanation
If unmitigated, this would allow an unprivileged, fee-less attacker (since `decompress_call`/`validate_unsigned` run as an unsigned extrinsic path) to crash validating nodes by submitting a small compressed payload that decompresses to a deeply/recursively nested `RuntimeCall`, causing stack overflow during SCALE decode — a network-wide denial of service. However, this is already mitigated in the current code with an explicit depth limit and a passing regression test proving the fix holds.

### Likelihood Explanation
Low/none in the current state of the code — the mitigation (`MAX_EXTRINSIC_DECODE_DEPTH_LIMIT` + `decode_all_with_depth_limit`) is applied at both call-sites (`validate_unsigned` and `decode_and_execute`), and a dedicated PoC test asserts the attack is rejected cleanly rather than panicking.

### Recommendation
No further action needed for this pallet; the existing depth-limited decode plus the `decompress_stack_exhaustion_poc` regression test already close this bug class. Any new call site that decodes attacker-controlled, nested/recursive SCALE-encoded data (especially unsigned/permissionless paths) should be reviewed to ensure it uses `decode_all_with_depth_limit` (or otherwise relies on parity-scale-codec's built-in default recursion-depth guard) rather than an unguarded `decode()`/`decode_all()`.

### Proof of Concept
See the existing regression test [6](#0-5) , which builds 1000 nested `RuntimeCall::Sudo(pallet_sudo::Call::sudo{...})` wrappers, compresses them with zstd, and calls `decompress_call`, asserting the mitigated code path returns `ErrorDecodingCall` rather than crashing the node.

#[test]
fn decompress_stack_exhaustion_poc() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		use crate::runtime::RuntimeCall;
		use codec::Encode;

		let inner_call = RuntimeCall::System(frame_system::Call::remark { remark: Vec::new() });

		let mut nested_calls =
			RuntimeCall::Sudo(pallet_sudo::Call::sudo { call: Box::new(inner_call) });

		for _ in 1..1000 {
			nested_calls =
				RuntimeCall::Sudo(pallet_sudo::Call::sudo { call: Box::new(nested_calls) });
		}

		let encoded = nested_calls.encode();
		let mut buffer = vec![0u8; 1000000];
		let compressed = zstd_safe::compress(&mut buffer[..], encoded.as_slice(), 3).unwrap();
		let final_compressed_call = buffer[..compressed].to_vec();

		let res = pallet_call_decompressor::Pallet::<Test>::decompress_call(
			RuntimeOrigin::none(),
			final_compressed_call.to_vec(),
			encoded.len() as u32,
		)
		.err()
		.unwrap();

		assert_eq!(
			res,
			DispatchError::Module(ModuleError {
				index: 10,
				error: [3, 0, 0, 0],
				message: Some("ErrorDecodingCall")
			})
		);
	});
}
