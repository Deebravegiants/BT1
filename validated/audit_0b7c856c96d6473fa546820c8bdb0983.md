No vulnerability found for this question.

**Analysis:**

The `burn` function's authorization model is intentional and correct: any signer who is the *current* owner of an object at call time is authorized to burn it [1](#0-0) . This mirrors the authorization model used everywhere else in `object.move` (`transfer`, `transfer_raw`, etc.) — ownership itself is the capability, and Aptos's object model treats "current owner" as authoritative, not "long-term historical owner." There is no separate notion of "true long-term custody" that the framework is supposed to track; `is_owner` checking `ObjectCore.owner` at call time is the designed authority check [2](#0-1) .

The premise of "a since-reverted or malicious sub-transaction path" leaving someone as owner does not correspond to any real Move/Aptos execution semantic. Move transactions are atomic: either the whole transaction (and all its internal function calls) commits, or it aborts and all state changes—including any transient ownership change—are discarded. There is no mechanism by which an attacker could become owner via a "sub-transaction" that reverts while leaving behind a lingering, exploitable ownership state visible to `burn`.

The "ownership churn" scenario (transfer to attacker → burn → transfer back) is not a boundary violation: if a legitimate owner voluntarily transfers the object to the attacker, the attacker *becomes* the true, current owner per the system's design — that is a legitimate transfer, not custody corruption. When the attacker then calls `burn`, `TombStone.original_owner` correctly records the attacker's address [3](#0-2)  because the attacker genuinely was the owner at burn time — this is exactly the invariant the design intends to preserve, not break.

Additionally, in the current `burn` implementation, ownership (`ObjectCore.owner`) is not even changed — only a `TombStone` marker is added, so the object remains owned by the same address before and after burning [4](#0-3) . `unburn` then checks that the caller matches either the current owner or (for the legacy burn-to-`BURN_ADDRESS` path) the recorded `original_owner`, which correctly reflects the owner at the time burn was invoked [5](#0-4) . The formal spec also encodes this invariant explicitly [6](#0-5) .

Since exploiting this "vulnerability" requires already being the legitimate current owner (obtained either by design-intended transfer or by having genuine authority), and no atomicity-breaking or authorization-bypassing path exists, this does not cross a real custody boundary. It requires pre-existing ownership permission, which the Decision Standard explicitly excludes.

    public entry fun unburn<T: key>(
        original_owner: &signer,
        object: Object<T>,
    ) {
        let object_addr = object.inner;
        assert!(exists<TombStone>(object_addr), error::invalid_argument(EOBJECT_NOT_BURNT));

        // The new owner of the object can always unburn it, but if it's the burn address, we go to the old functionality
        let object_core = borrow_global<ObjectCore>(object_addr);
        if (object_core.owner == signer::address_of(original_owner)) {
            let TombStone { original_owner: _ } = move_from<TombStone>(object_addr);
        } else if (object_core.owner == BURN_ADDRESS) {
            // The old functionality
            let TombStone { original_owner: original_owner_addr } = move_from<TombStone>(object_addr);
            assert!(
                original_owner_addr == signer::address_of(original_owner),
                error::permission_denied(ENOT_OBJECT_OWNER)
            );
            transfer_raw_inner(object_addr, original_owner_addr);
        } else {
            abort error::permission_denied(ENOT_OBJECT_OWNER);
        };
    }

    spec burn<T: key>(owner: &signer, object: Object<T>) {
        pragma aborts_if_is_partial;
        let object_address = object.inner;
        aborts_if !exists<ObjectCore>(object_address);
        aborts_if owner(object) != signer::address_of(owner);
        ensures exists<TombStone>(object_address);
        ensures is_owner(object, signer::address_of(owner));
    }

    spec burn_object_with_transfer<T: key>(owner: &signer, object: Object<T>) {
        pragma aborts_if_is_partial;
        let object_address = object.inner;
        aborts_if !exists<ObjectCore>(object_address);
        aborts_if owner(object) != signer::address_of(owner);
        aborts_if is_burnt(object);
    }

    spec unburn<T: key>(original_owner: &signer, object: Object<T>) {
        pragma aborts_if_is_partial;
        let object_address = object.inner;
        aborts_if !exists<ObjectCore>(object_address);
        aborts_if !is_burnt(object);
        let tomb_stone = borrow_global<TombStone>(object_address);
        let original_owner_address = signer::address_of(original_owner);
        let object_current_owner = borrow_global<ObjectCore>(object_address).owner;
        aborts_if object_current_owner != original_owner_address && tomb_stone.original_owner != original_owner_address;
    }
