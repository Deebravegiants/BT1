### Title
Unauthenticated Magic QR-codes trigger privileged Wi-Fi/network reset and mirror recalibration before operator authentication - (File: `src/plans/mod.rs`)

### Summary
`handle_magic_operator_qr_code()` executes privileged, state-changing hardware actions — resetting the Wi‑Fi configuration and forcing the Orb to join a new attacker-supplied network, or resetting mirror calibration — as soon as a QR code matching `magic_action:reset_wifi_credentials` or `magic_action:reset_mirror_calibration` is scanned, and this happens **before** `verify_operator_qr_code()` performs the backend authorization check that is otherwise required for any operator-controlled action. This mirrors the `arbitraryCall()` root cause in the referenced report: a privileged operation is reachable via a path that lacks the very check present in the "normal" flow, allowing an unauthenticated party to trigger it.

### Finding Description
`qr_scan::operator::Data::try_parse()` recognizes two "magic" QR-code payloads, `MagicResetWifi` and `MagicResetMirror`, via a plain regex match on the scanned text with no cryptographic or backend validation: [1](#0-0) 

Both `scan_initial_qr_codes()` and `scan_remaining_qr_codes()` scan an operator QR-code and immediately call `handle_magic_operator_qr_code()` **before** calling `verify_operator_qr_code()`, which is the function that performs the actual backend authentication of the operator: [2](#0-1) [3](#0-2) 

`handle_magic_operator_qr_code()` acts on the magic payload directly, with no requirement that the code has been through `verify_operator_qr_code()`: [4](#0-3) 

- `MagicResetWifi` calls `reset_wifi_and_ensure_network()`, which resets the current wpa_supplicant configuration (disconnecting from whatever network the Orb currently trusts) and then immediately scans for a new hotspot QR-code (MECARD format) to join: [5](#0-4) [6](#0-5) [7](#0-6) 
- `MagicResetMirror` calls `reset_mirror_calibration()`, resetting the mirror's calibration data unconditionally: [8](#0-7) 

Unlike the `require(incentives[who] == 0)` check that `arbitraryCall()` fails to add for the callee, there is no equivalent guard here ensuring the scanned QR-code belongs to a backend-verified operator before these hardware-level, state-mutating actions run.

### Impact Explanation
Any person able to present a printed/displayed QR code to the Orb's camera — with no credentials, no prior pairing, and no operator status — can:
1. Force the Orb to drop its currently configured, trusted Wi‑Fi network and then join an attacker-controlled network by subsequently presenting a MECARD Wi‑Fi QR-code, enabling network-level man-in-the-middle positioning against the Orb's backend traffic, or
2. Cause a persistent denial of service by resetting Wi‑Fi and never providing valid credentials, blocking all future signups until manual re-provisioning, or
3. Silently reset the mirror's physical calibration, degrading biometric capture quality/reliability for subsequent legitimate signups.

This is reachable without any of the standard preconditions (valid operator QR, backend authorization, self-serve session state) that gate every other operator-privileged action in this file.

### Likelihood Explanation
Likelihood is high: the trigger is a plain string pattern (`magic_action:reset_wifi_credentials` / `magic_action:reset_mirror_calibration`) that can be generated and printed by anyone, and the scan path (`scan_initial_qr_codes`/`scan_remaining_qr_codes`) that reaches `handle_magic_operator_qr_code()` runs during normal idle/signup QR scanning, requiring no special orb state beyond it being ready to scan an operator QR-code.

### Recommendation
Move the magic-action handling to occur only after `verify_operator_qr_code()` succeeds (i.e., only allow `MagicResetWifi`/`MagicResetMirror` execution for a QR-code payload that has been validated as belonging to an authorized operator by the backend), or introduce an explicit authenticated-operator check inside `handle_magic_operator_qr_code()` before performing `reset_wifi_and_ensure_network()` or `reset_mirror_calibration()`.

### Proof of Concept
1. Generate a QR code containing the literal text `magic_action:reset_wifi_credentials`.
2. Present it to the Orb's camera during idle/operator QR scanning (no operator credentials needed).
3. `scan_operator_qr_code()` returns `qr_scan::operator::Data::MagicResetWifi` (parsed purely from the regex match, `src/plans/qr_scan/operator.rs:49-58`).
4. `handle_magic_operator_qr_code()` is invoked before `verify_operator_qr_code()` and calls `reset_wifi_and_ensure_network()`, which resets the Wi‑Fi configuration (`src/network/mod.rs:101-123`) and starts scanning for a new Wi‑Fi MECARD QR-code to join (`src/plans/wifi/mod.rs:43-68`).
5. Present a second QR code containing attacker Wi‑Fi credentials in MECARD format (`WIFI:T:WPA;S:attacker-ap;P:password;;`); the Orb joins the attacker-controlled network via `network::join()`.

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

/// Joins WiFi network using the given `credentials`.
pub async fn join(credentials: Credentials) -> Result<()> {
    spawn_blocking(move || {
        let mut cmd = Command::new(WPA_SUPPLICANT_INTERFACE_BIN);
        cmd.arg("join");
        match credentials.auth_type {
            AuthType::Wep | AuthType::Nopass => {
                cmd.arg("--auth").arg("NONE");
            }
            AuthType::Wpa | AuthType::Sae => {
                cmd.arg("--auth").arg("WPA-PSK");
            }
        }
        cmd.arg("--ssid").arg(hex_string(credentials.ssid.as_bytes()));
        if let Some(password) = &credentials.password {
            cmd.arg("--password").arg(wpa_passphrase(&credentials.ssid, password));
        }
        cmd.status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;
        Ok(())
    })
    .await?
}

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
