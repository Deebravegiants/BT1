### Title
Supplier can withdraw at the pre-write-down supply index to escape bad-debt socialization before `clean_bad_debt`/`liquidate` - (File: contracts/pool/src/interest.rs)

### Summary
The Carapace bug class — "exit before the pool marks the loss and locks capital" — maps directly onto XOXNO Lending. Bad debt is only socialized when `seize_positions` runs inside `liquidate`/`clean_bad_debt`, via `apply_bad_debt_to_supply_index` lowering the market's `supply_index` [1](#0-0) . Nothing forces that write-down to run before a supplier withdraws: `withdraw` gates only on the caller's own health factor, exit flags, cash availability and the max-utilization cap [2](#0-1) [3](#0-2) . An unprivileged supplier can therefore watch for a soon-to-be-socialized bad-debt account, withdraw their full supply at the still-unimpaired index, and let remaining suppliers absorb the entire write-down.

### Finding Description
`clean_bad_debt` is permissionless (collateral ≤ $5 dust gate) and liquidation-time socialization is likewise callable by anyone [4](#0-3) . Until `seize_positions` executes, the debt sits on the books at full value and `supply_index` is unimpaired. `resolve_withdrawal` pays the supplier `shares × supply_index` with no check that pending unbacked debt exists [5](#0-4) . Because withdraws are paid from `cash`, a supplier who exits first receives full nominal value even though the pool's backing is already impaired economically; the subsequent `apply_bad_debt_to_supply_index` write-down lands entirely on whoever did not front-run [6](#0-5) . There is no mechanism that assesses pending bad debt before permitting withdrawal — the exact fix recommended in the original report is absent.

### Impact Explanation
Early exiters dodge their pro-rata share of socialized bad debt; the loss is concentrated on later/honest suppliers, whose claims are written down further than their fair share — a transfer of loss equivalent to theft of user funds. In the extreme, withdrawals drain `cash` before the write-down, leaving residual suppliers holding claims the pool cannot pay (backing shortfall until `recapitalize`).

### Likelihood Explanation
Requires an account with bad debt awaiting cleanup and enough idle cash to pay out the withdrawing supplier — realistic whenever liquidation lags or dust-threshold cleanup accumulates. The withdrawal itself is a single `withdraw` call by a debt-free account; no privileges needed. Constrained by the $5-collateral dust gate for permissionless cleanup (bounds per-account size) and by the max-utilization gate when liquidity is scarce.

### Recommendation
Assess pending socializable debt before permitting withdrawal, mirroring the report's fix: e.g., have the controller's `withdraw` path evaluate whether the touched markets have pending bad-debt write-downs (or require `update_indexes`/cleanup ordering), or apply a conservative "worst-case supply index" when pricing a withdrawal while unbacked debt exists. Alternatively, socialize bad debt eagerly inside `liquidate` before the transaction commits so no observable pre-write-down window exists.

### Proof of Concept
1. BOB supplies 100 ETH; ALICE supplies 8 USDC collateral and borrows 0.002 ETH.
2. USDC price crashes; ALICE's collateral falls below the $5 dust threshold with unbacked ETH debt — the fixture in `test_keeper_clean_bad_debt_decreases_supply_index` [7](#0-6) .
3. Before anyone calls `clean_bad_debt`, BOB calls controller `withdraw` (amount 0 → withdraw-all sentinel) and receives `bob_shares × supply_index` at the unimpaired index, paid from `cash`.
4. `clean_bad_debt(account_id)` then runs `apply_bad_debt_to_supply_index`, writing the full loss down only against remaining suppliers — BOB bears zero share of the loss instead of his pro-rata slice [1](#0-0) .

pub(crate) fn apply_bad_debt_to_supply_index(cache: &mut Cache, bad_debt: Ray) {
    let total_supplied_value = cache.supplied().mul(cache.env(), cache.supply_index());

    if total_supplied_value == Ray::ZERO {
        return;
    }

    let capped = bad_debt.min(total_supplied_value);
    let remaining = total_supplied_value.checked_sub(cache.env(), capped);

    let reduction_factor = remaining.div_floor(cache.env(), total_supplied_value);
    let new_supply_index = cache
        .supply_index()
        .mul_floor(cache.env(), reduction_factor);

    cache.set_supply_index(new_supply_index.max(Ray::from(SUPPLY_INDEX_FLOOR_RAW)));
}

pub(crate) fn accounting(
    env: &Env,
    is_liquidation: bool,
    entry: &PoolWithdrawEntry,
) -> WithdrawOutcome {
    require_nonneg_amount(env, entry.protocol_fee);
    let (mut cache, position) = ops::load_leg(env, &entry.action);

    let (burned, gross_amount) = resolve_close_or_partial(&cache, entry.action.amount, position);
    // Burn first: `protocol_fee_shares` caps the fee mint at `i128::MAX - supplied`.
    let remaining = burn_position(env, &mut cache, position, burned);
    let net_transfer = withhold_liquidation_fee(
        env,
        &mut cache,
        gross_amount,
        is_liquidation,
        entry.protocol_fee,
    );

    // A footprint-only close must not add a utilization gate to same-market
    // net settlement: it burns no shares and moves no cash.
    let empty_close = position.raw() == 0 && entry.action.amount == i128::MAX;
    gate_and_debit(env, &mut cache, net_transfer, is_liquidation || empty_close);

    let snapshot = cache.commit();
    let mutation = cache.position_mutation(remaining, gross_amount);
    WithdrawOutcome {
        cache,
        mutation,
        snapshot,
        net_transfer,
    }
}

fn settle_withdraw(
    env: &Env,
    account: &mut Account,
    recipient: &Address,
    aggregated: &AggregatedPayments,
    cache: &mut Context,
) -> Vec<HubPayment> {
    let mut entries: Vec<PoolWithdrawEntry> = Vec::new(env);
    for (hub_asset, amount) in aggregated.iter() {
        enforce_spoke_asset_flags(
            env,
            cache,
            account.spoke_id,
            &hub_asset,
            FreezePolicy::AllowOnExit,
        );
        let position = get_supply_position_or_panic(env, account, &hub_asset);
        let requested = if amount == 0 {
            WITHDRAW_ALL_SENTINEL
        } else {
            amount
        };
        entries.push_back(PoolWithdrawEntry {
            action: make_pool_action(&position, requested, hub_asset.clone()),
            protocol_fee: 0,
        });
    }

    let results = apply_withdraw_batch(
        env,
        account,
        recipient,
        WithdrawKind::Normal,
        events::PositionAction::Withdraw,
        &entries,
        cache,
    );
    let mut paid: Vec<HubPayment> = Vec::new(env);
    for_each_leg(env, &entries, &results, |entry, result| {
        paid.push_back((entry.action.hub_asset, result.actual_amount));
    });
    paid
}
