Audit Report

## Title
Web API Trigger staleness check can be bypassed via signed-to-unsigned timestamp conversion - ([File: core/services/gateway/handlers/capabilities/handler.go])

## Summary
`HandleLegacyUserMessage` validates message freshness using `uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp)`, where `payload.Timestamp` is attacker-controlled and only checked for `== 0` beforehand, never for being negative. A negative `int64` timestamp cast to `uint` wraps to a value near `2^64`, which will always satisfy the comparison in the non-stale direction, silently defeating the intended freshness/anti-replay check.

## Finding Description
The code path is confirmed exactly as cited: [1](#0-0)  shows `HandleLegacyUserMessage` decoding `webapicap.TriggerRequestPayload` from the client-supplied `msg.Body.Payload`, rejecting only `payload.Timestamp == 0`, and then performing the freshness comparison via `uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp)` with an explicit `//nolint:gosec // G115` suppression acknowledging the signed-to-unsigned conversion risk. No prior validation rejects negative timestamps, and the signature/message-decoding logic that runs before this point does not constrain the value of `payload.Timestamp` at all — it is a plain integer field decoded from JSON supplied by the caller. Consequently, an attacker who can reach this handler (which is the standard, documented path for submitting a `web_api_trigger` message, as exercised by `core/scripts/gateway/web_api_trigger/invoke_trigger.go`) can set `Timestamp` to a negative number, causing `uint(payload.Timestamp)` to wrap to a huge value and the staleness check to be bypassed unconditionally.

## Impact Explanation
This breaks the only freshness/anti-replay gate present in this handler at the time the check runs — note the adjacent `// TODO: apply allowlist and rate-limiting here` comment at line 384 confirms allowlist/rate-limiting is not yet implemented in this code path, making the staleness check one of the few active validations at this stage. Bypassing it allows a stale or arbitrarily-aged trigger payload to be forwarded onward to DON nodes as if fresh, which is a concrete validation-bypass impact on the gateway's unprivileged message-ingestion path (in the class of unauthorized/unvalidated job-trigger forwarding), though it does not by itself grant authentication bypass, fund movement, or secret disclosure.

## Likelihood Explanation
High likelihood: any actor able to sign and submit a `web_api_trigger` message to the gateway (a normal, documented, unprivileged capability, as shown by the reference script) can trivially set `Timestamp` to a negative integer with no additional privilege, and reliably bypass the check every time.

## Recommendation
Reject non-positive timestamps explicitly and perform the comparison in signed arithmetic:
```go
if payload.Timestamp <= 0 {
    // reject as invalid
}
now := time.Now().Unix()
if now - int64(h.config.MaxAllowedMessageAgeSec) > payload.Timestamp {
    // reject as stale
}
```

## Proof of Concept
1. Construct a `web_api_trigger` message with `TriggerRequestPayload.Timestamp = -1`, sign it with a valid key, and submit it to the gateway following the flow in `core/scripts/gateway/web_api_trigger/invoke_trigger.go`.
2. `payload.Timestamp == 0` check passes (value is `-1`).
3. `uint(payload.Timestamp)` wraps to `18446744073709551615`, so `uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp)` is always false, and the "stale message" branch at `core/services/gateway/handlers/capabilities/handler.go` L372-383 is never taken — the message proceeds to `common.ValidatedRequestFromMessage` and onward, bypassing the intended freshness gate. This can be confirmed with a Go unit test calling `handler.HandleLegacyUserMessage` with a crafted message containing a negative `Timestamp`.

```go
func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
```
