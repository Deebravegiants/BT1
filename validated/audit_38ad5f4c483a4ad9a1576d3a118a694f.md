Audit Report

## Title
CORS Origin Allowlist Bypass via Suffix-Only Wildcard Host Matching - (File: `core/services/gateway/network/httpserver.go`)

## Summary
The gateway HTTP server's `isAllowedOrigin` function uses `strings.HasSuffix(originHost, allowedHost)` to validate wildcard-configured allowed origins (e.g., `*.remix.com`), without checking for a `.` boundary before the matched suffix. This allows an attacker who controls a domain like `evilremix.com` to satisfy the check against an allowlist entry of `*.remix.com`, bypassing the operator's intended origin restriction.

## Finding Description
In `isAllowedOrigin`, wildcard entries are handled by stripping the `*.` prefix and then checking suffix containment: [1](#0-0) . This is separator-unaware: `strings.HasSuffix("evilremix.com", "remix.com")` evaluates to `true`, even though `evilremix.com` is not a subdomain of `remix.com`. The exact host/scheme/port splitting happens in `splitURL` [2](#0-1)  and is invoked from `isAllowedOrigin` [3](#0-2) . No other check (scheme/port equality, exact host match) compensates for the missing separator check in the wildcard branch. When the check passes, `handleRequest` reflects the attacker-controlled Origin header with credentialed CORS response headers: [4](#0-3) .

## Impact Explanation
If an operator configures a wildcard CORS allow-entry such as `https://*.remix.com` (a legitimate, intended configuration, not a misconfiguration), an attacker who registers or controls `evilremix.com`/`attacker-remix.com` can serve a malicious webpage that issues a credentialed cross-origin request to the gateway's `/` endpoint (`HTTPRequestHandler.ProcessRequest`). The browser will accept the reflected `Access-Control-Allow-Origin` header and permit the attacker's script to read the JSON-RPC response, bypassing the intended origin scoping. This maps to the in-scope "gateway request impersonation / allowlist bypass" category since it defeats a security boundary (CORS origin allowlist) that gates cross-origin read access to gateway responses.

## Likelihood Explanation
The trigger requires only that the deployment enables CORS with at least one wildcard entry in `CORSAllowedOrigins`, and that the attacker registers a domain sharing the literal suffix — both realistic and low-cost preconditions. No credentials, roles, or victim social engineering beyond normal browsing to an attacker page are required; the flaw fires on every request via the `Origin` header, making it deterministic and repeatable.

## Recommendation
Enforce a separator-aware subdomain match in the wildcard branch of `isAllowedOrigin`:
```go
if strings.HasPrefix(allowedHost, "*.") {
    allowedHost = allowedHost[2:]
    if originHost == allowedHost || strings.HasSuffix(originHost, "."+allowedHost) {
        return true
    }
}
```

## Proof of Concept
1. Configure the gateway with `CORSEnabled: true` and `CORSAllowedOrigins: ["https://*.remix.com"]`.
2. Send an HTTP request to the gateway's configured path with header `Origin: https://evilremix.com`.
3. Observe that `isAllowedOrigin` returns `true` (via `strings.HasSuffix("evilremix.com", "remix.com")`), and the response includes `Access-Control-Allow-Origin: https://evilremix.com`.
4. This can be directly reproduced as a Go unit test calling `s.isAllowedOrigin("https://evilremix.com")` with `CORSAllowedOrigins: []string{"https://*.remix.com"}` and asserting it incorrectly returns `true`, or as an `httptest`-based integration test against `handleRequest` checking the `Access-Control-Allow-Origin` response header.

func (s *httpServer) isAllowedOrigin(origin string) bool {
	originScheme, originHost, originPort, err := s.splitURL(origin)
	if err != nil {
		s.lggr.Debug("error parsing origin URL", err)
		return false
	}
	for _, allowed := range s.config.CORSAllowedOrigins {
		// probably better to do this once when server starts and store it in a map
		// this is an easier solution so we don't have to apply more changes to the code
		// just need to be careful when specifying allowed origins in the config file
		allowedScheme, allowedHost, allowedPort, err := s.splitURL(allowed)
		if err != nil {
			s.lggr.Debug("error parsing allowed origin URL", err)
			continue
		}
		// skip if the scheme doesn't match at all
		if originScheme != allowedScheme {
			continue
		}
		// skip if the port doesn't match at all
		if originPort != allowedPort {
			continue
		}
		// check for exact host match (e.g., remix.com)
		if originHost == allowedHost {
			return true
		}
		// check for wildcard host match (e.g., *.remix.com)
		if strings.HasPrefix(allowedHost, "*.") {
			allowedHost = allowedHost[2:]
			if strings.HasSuffix(originHost, allowedHost) {
				return true
			}
		}
	}
	return false
}
