Audit Report

## Title
Unbounded linear scan + blocking retry loop over the allowlisted-requests slice in Vault gateway authorization enables per-request CPU/latency DoS - (File: core/capabilities/vault/allow_list_based_auth.go)

## Summary
`allowListBasedAuth.findAllowlistedItemWithRetry` retrieves the entire in-memory allowlisted-requests slice via `GetAllowlistedRequests` and performs an O(n) scan (`fetchAllowlistedItem`) plus an O(n) debug-string build (`allowedRequestsStrs`) on every attempt, retried up to 11 times with 3-second sleeps between attempts when a digest is not found. This code and flow are confirmed exactly as described, and the allowlist can grow into the thousands per `Test_InitialStateSyncV2`.

## Finding Description
The code path is accurately cited: `findAllowlistedItemWithRetry` loops `r.retryCount+1` (11) times, each iteration fetching `allowedRequests` and building `allowedRequestsStrs` via `fmt.Sprintf` for every entry, then scanning linearly with `fetchAllowlistedItem`, sleeping `allowListBasedAuthRetryInterval` (3s) between attempts if not found [1](#0-0) . This is reachable from `GatewayHandler.HandleGatewayMessage` for `secretsCreate`/`secretsUpdate`/`secretsDelete`/`secretsList` via `GatewayVaultRequestProcessor.ProcessRequest` → `authorizeAndStamp` → `AuthorizeRequest` [2](#0-1) . The allowlist slice is populated on-chain and pruned only every 5 seconds by `syncAllowlistedRequests`, and the test suite explicitly exercises allowlists exceeding 1,000 entries [3](#0-2) .

However, the finding omits an important existing mitigation: the gateway `vault` handler (`core/services/gateway/handlers/vault/handler.go`) applies a `nodeRateLimiter` (per-sender and global rate limits, e.g. `PerSenderRPS`/`PerSenderBurst`) before any request reaches the authorizer [4](#0-3) , with defaults such as `PerSenderRPS: 10, PerSenderBurst: 10` configured in the gateway job spec [5](#0-4) . This significantly constrains the rate at which any single unprivileged sender can trigger the expensive authorization path, undermining the "repeatable indefinitely" and unbounded-DoS framing of the report, though it does not eliminate the underlying O(n) inefficiency or the blocking 33-second worst-case latency per unauthorized request within the allowed rate.

## Impact Explanation
The underlying inefficiency is real: each unauthorized/invalid vault request triggers up to 11 full O(n) scans and O(n) debug-string builds of a growable, on-chain-controlled slice, with up to ~30 seconds of blocking sleep time per request. This is a genuine performance/availability concern, but it is a moderate-severity resource-inefficiency issue rather than a clear-cut "DoS" in the sense of node crash, complete unavailability, or bypass of authentication/authorization/fund-movement controls. It does not map cleanly to a high-severity in-scope Chainlink bounty impact category (auth bypass, key/secret exfiltration, unauthorized fund movement, gateway impersonation, allowlist bypass) — it is a resource-consumption/CPU-time inefficiency, mitigated by rate limiting at the gateway layer that the report does not account for.

## Likelihood Explanation
An unprivileged client can reach the vault gateway endpoint, but the existing per-sender and global rate limiters (`nodeRateLimiter`, default `PerSenderRPS: 10`) throttle how frequently a single attacker can invoke this expensive path, meaning the amplification is bounded per attacker per second rather than truly unbounded, reducing the practical severity of the described DoS.

## Recommendation
- Replace the linear scan with an indexed lookup keyed by digest for O(1) authorization.
- Avoid building the full debug-string slice on every attempt in production paths; gate it behind trace-level logging or only compute on final failure.
- Consider failing fast rather than always executing all 11 retries × full scan for structurally invalid requests.
- Even with per-sender rate limiting in place, reducing the worst-case per-request cost is worthwhile as the allowlist grows.

## Proof of Concept
Send a `secretsList` (or other vault method) request through the gateway with a non-allowlisted digest and observe `AuthorizeRequest` block for up to ~30 seconds performing repeated O(n) scans as allowlist size grows (as demonstrated by `Test_InitialStateSyncV2`'s 1,000+ entry allowlist); repeat within the per-sender rate limit (default 10 RPS/burst) to sustain elevated CPU usage on the authorization path, though not exceeding the gateway's configured rate-limiting bounds.

func (r *allowListBasedAuth) findAllowlistedItemWithRetry(ctx context.Context, req jsonrpc.Request[json.RawMessage], requestDigest string, requestDigestBytes32 [32]byte) (*workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest, []string, error) {
	for attempt := 0; attempt <= r.retryCount; attempt++ {
		allowedRequests := r.workflowRegistrySyncer.GetAllowlistedRequests(ctx)
		allowedRequestsStrs := make([]string, 0, len(allowedRequests))
		for _, rr := range allowedRequests {
			allowedReqStr := fmt.Sprintf("AuthorizedOwner: %s, RequestDigest: %s, ExpiryTimestamp: %d", rr.Owner.Hex(), hex.EncodeToString(rr.RequestDigest[:]), rr.ExpiryTimestamp)
			allowedRequestsStrs = append(allowedRequestsStrs, allowedReqStr)
		}
		r.lggr.Debugw("AllowListBasedAuth loaded allowlisted requests", "method", req.Method, "requestID", req.ID, "attempt", attempt+1, "allowedRequests", allowedRequestsStrs)

		allowlistedRequest := r.fetchAllowlistedItem(allowedRequests, requestDigestBytes32)
		if allowlistedRequest != nil {
			return allowlistedRequest, allowedRequestsStrs, nil
		}
		if attempt == r.retryCount {
			return nil, allowedRequestsStrs, nil
		}

		r.lggr.Debugw("AllowListBasedAuth request digest not yet allowlisted, retrying",
			"method", req.Method,
			"requestID", req.ID,
			"digestHexStr", requestDigest,
			"attempt", attempt+1,
			"maxAttempts", r.retryCount+1,
			"retryInterval", r.retryInterval)
		if err := sleepWithContext(ctx, r.retryInterval); err != nil {
			r.lggr.Debugw("AllowListBasedAuth retry canceled", "method", req.Method, "requestID", req.ID, "error", err)
			return nil, nil, err
		}
	}

	return nil, nil, nil // unreachable: loop always returns
}

func (r *allowListBasedAuth) fetchAllowlistedItem(allowListedRequests []workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest, digest [32]byte) *workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest {
	for _, item := range allowListedRequests {
		if item.RequestDigest == digest {
			return &item
		}
	}
	return nil
}

func (h *GatewayHandler) HandleGatewayMessage(ctx context.Context, gatewayID string, req *jsonrpc.Request[json.RawMessage]) (err error) {
	reqLggr := h.requestLogger(req, gatewayID)
	reqLggr.Debugw("received message from gateway", "req", req)

	var response *jsonrpc.Response[json.RawMessage]
	var authResult *AuthResult

	switch req.Method {
	case vaulttypes.MethodSecretsCreate, vaulttypes.MethodSecretsUpdate:
		publicKey, pkErr := h.getMasterPublicKey(ctx)
		if pkErr != nil {
			response = h.gatewayErrorResponse(ctx, gatewayID, req, pkErr)
			break
		}
		authorized, pipelineErr := h.requestProcessor.ProcessRequest(ctx, req, publicKey)
		if pipelineErr != nil {
			response = h.gatewayErrorResponse(ctx, gatewayID, req, pipelineErr)
			break
		}
		authResult = authorized.AuthResult
	case vaulttypes.MethodSecretsDelete, vaulttypes.MethodSecretsList:
		authorized, pipelineErr := h.requestProcessor.ProcessRequest(ctx, req, nil)
		if pipelineErr != nil {
			response = h.gatewayErrorResponse(ctx, gatewayID, req, pipelineErr)
			break
		}
		authResult = authorized.AuthResult
	case vaulttypes.MethodPublicKeyGet:
		response = h.handlePublicKeyGet(ctx, gatewayID, req)
	default:
		response = h.errorResponse(ctx, gatewayID, req, api.UnsupportedMethodError, errors.New("unsupported method: "+req.Method))
	}

func (w *workflowRegistry) syncAllowlistedRequests(ctx context.Context) {
	ticker := w.getTicker(defaultTickIntervalForAllowlistedRequests)
	w.lggr.Debug("starting syncAllowlistedRequests")
	for {
		select {
		case <-ctx.Done():
			w.lggr.Debug("shutting down syncAllowlistedRequests, %s", ctx.Err())
			return
		case <-ticker:
			newAllowListedRequests, totalAllowlistedRequests, head, err := w.getAllowlistedRequests(ctx, w.contractReader)
			if err != nil {
				w.lggr.Errorw("failed to call getAllowlistedRequests", "err", err)
				continue
			}
			w.allowListedMu.Lock()
			// Prune expired requests
			activeAllowlistedRequests := []workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest{}
			expiredRequestsCount := 0
			for _, request := range w.allowListedRequests {
				if int64(request.ExpiryTimestamp) > time.Now().Unix() {
					activeAllowlistedRequests = append(activeAllowlistedRequests, request)
				} else {
					expiredRequestsCount++
				}
			}

			// Add new requests
			activeAllowlistedRequests = append(activeAllowlistedRequests, newAllowListedRequests...)
			w.allowListedRequests = activeAllowlistedRequests
			w.lastSeenAllowlistedRequestsCount = totalAllowlistedRequests
			w.lggr.Debugw("synced allowlisted requests",
				"newRequestsNum", len(newAllowListedRequests),
				"expiredRequestsNum", expiredRequestsCount,
				"activeRequestsNum", len(w.allowListedRequests),
				"lastSeenOnchainRequestsNum", w.lastSeenAllowlistedRequestsCount,
				"blockHeight", head.Height,
			)
			w.allowListedMu.Unlock()
		}
	}
}
