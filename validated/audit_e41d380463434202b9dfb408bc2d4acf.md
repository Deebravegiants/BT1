### Title
Unbounded digest-count allocation in `Codec.DecodeHeader` before proof verification — untrusted parachain headers can force an out-of-gas revert in the BEEFY consensus-update path - ([File: evm/src/consensus/Codec.sol])

### Summary
`Codec.DecodeHeader` reads a SCALE compact-encoded digest count directly from caller-supplied header bytes and immediately allocates a memory array of that size (`new Digest[](length)`) with no check that `length` is consistent with the remaining bytes in the buffer. This is called on every parachain header supplied in a `ParachainProof` *before* that header is proven to be part of the MMR-committed parachain-heads root, so an unauthenticated, attacker-chosen digest count drives the allocation.

### Finding Description
`DecodeHeader` decodes the digest count via `ScaleCodec.decodeUintCompact(slice)` and allocates `Digest[] memory digests = new Digest[](length)` before validating that `length` corresponds to actual remaining data: [1](#0-0) 

The compact integer format allows `length` to be encoded as a value up to ~2^30 (mode 2, `require(l <= 8, ...)` only bounds the mode-3 8-byte case, mode 2 is unconstrained) from just a few bytes of header, i.e. exactly the CVE-2019-11938 pattern of "a short message declaring a container size larger than the payload." [2](#0-1) 

`EcdsaBeefy.verifyParachainHeaderProof` calls `Codec.DecodeHeader(para.header)` on every entry of `proof.parachains` inside the loop, and only performs the `MerkleMultiProof.VerifyProof(headsRoot, ...)` membership check *after* the loop completes: [3](#0-2) 

Because `para.header` is decoded before its membership in the trusted MMR/parachain-heads root is checked, the bytes are fully attacker-controlled at the time `DecodeHeader` allocates memory: any caller of `verify()` (the permissionless entry point for consensus updates, reachable by any relayer submitting a `ConsensusMessage`/`RelayChainProof`) can supply a tiny `para.header` blob whose digest-count compact integer claims hundreds of millions of digest entries, forcing Solidity to attempt a correspondingly large memory allocation and triggering quadratic memory-expansion gas costs, causing the call to revert with an out-of-gas condition long before the actual (bounded) `Bytes.read`/`readByte` calls would fail on insufficient underlying bytes.

### Impact Explanation
This lets an unprivileged relayer force the consensus-update verification path (`verify()`/`verifyParachainHeaderProof`) to revert via disproportionate, attacker-controlled gas consumption from a small payload, before the header has been authenticated against the trusted MMR root. If this verification is invoked as part of a larger batched transaction that also carries legitimate message deliveries (a normal pattern for relayer transactions that update consensus state and deliver messages together), the crafted digest count can grief that whole transaction, denying delivery of otherwise-valid messages/state updates — matching the accepted impact category of "a route unable to deliver messages."

### Likelihood Explanation
Likelihood is limited by the fact that the attacker must construct calldata for a `RelayChainProof`/`ParachainProof` that otherwise passes the earlier stages (signature/supermajority and MMR-leaf checks) far enough to reach `verifyParachainHeaderProof`, and the resulting revert primarily burns the submitting relayer's own gas rather than corrupting shared state. It becomes materially impactful only when combined with a batched transaction carrying other relayer work, or when used to systematically grief a specific consensus client's update path.

### Recommendation
Bound `length` in `Codec.DecodeHeader` against the number of bytes actually remaining in `slice` (e.g. `require(length <= (self.data.length - self.offset))`, or an explicit sane maximum such as the number of known Substrate digest kinds) before allocating `Digest[] memory digests = new Digest[](length)`. Apply the same remaining-bytes bound in `decodeDigestItem`'s length read. Additionally, verify parachain header membership in the MMR/parachain-heads root before decoding header contents, so unauthenticated bytes are never parsed ahead of proof verification.

### Proof of Concept
1. Construct a `RelayChainProof`/`ParachainProof` where `proof.parachains[0].header` is a short byte string: 32 bytes parent hash + compact block number + 32 bytes state root + 32 bytes extrinsics root + a digest-count compact integer encoded in mode 2 (4 bytes) claiming e.g. `length = 0x3FFFFFFF` (~1.07 billion) digests, with no actual digest bytes following.
2. Call `EcdsaBeefy.verify(previousState, proof)` (or the SP1 variant sharing `Codec.DecodeHeader`) with valid enough upstream data to reach `verifyParachainHeaderProof`.
3. Observe that `Codec.DecodeHeader` attempts `new Digest[](0x3FFFFFFF)` and the call reverts with out-of-gas, before the subsequent `MerkleMultiProof.VerifyProof` membership check ever runs — demonstrating the header bytes are parsed, and their attacker-controlled length used for allocation, prior to authentication.

    // @dev Deserializes a substrate header
    function DecodeHeader(bytes memory encoded) internal pure returns (Header memory) {
        ByteSlice memory slice = ByteSlice(encoded, 0);
        bytes32 parentHash = Bytes.toBytes32(Bytes.read(slice, 32));
        uint256 blockNumber = ScaleCodec.decodeUintCompact(slice);
        bytes32 stateRoot = Bytes.toBytes32(Bytes.read(slice, 32));
        bytes32 extrinsicsRoot = Bytes.toBytes32(Bytes.read(slice, 32));

        uint256 length = ScaleCodec.decodeUintCompact(slice);
        Digest[] memory digests = new Digest[](length);

        for (uint256 i = 0; i < length; i++) {
            uint8 kind = Bytes.readByte(slice);
            Digest memory digest;
            if (kind == DIGEST_ITEM_OTHER) {
                digest.isOther = true;
            } else if (kind == DIGEST_ITEM_CONSENSUS) {
                digest.isConsensus = true;
                digest.consensus = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_SEAL) {
                digest.isSeal = true;
                digest.seal = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_PRERUNTIME) {
                digest.isPreRuntime = true;
                digest.preruntime = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_RUNTIME_ENVIRONMENT_UPDATED) {
                digest.isRuntimeEnvironmentUpdated = true;
            }
            digests[i] = digest;
        }

        return Header(parentHash, blockNumber, stateRoot, extrinsicsRoot, digests);
    }

    // @dev Decodes a SCALE encoded compact unsigned integer
    function decodeUintCompact(ByteSlice memory data) internal pure returns (uint256 v) {
        uint8 b = readByte(data); // read the first byte
        uint8 mode = b & 3; // bitwise operation

        uint256 value;
        if (mode == 0) {
            // [0, 63]
            value = b >> 2; // right shift to remove mode bits
        } else if (mode == 1) {
            // [64, 16383]
            uint8 bb = readByte(data); // read the second byte
            uint64 r = bb; // convert to uint64
            r <<= 6; // multiply by * 2^6
            r += b >> 2; // right shift to remove mode bits
            value = r;
        } else if (mode == 2) {
            // [16384, 1073741823]
            uint8 b2 = readByte(data); // read the next 3 bytes
            uint8 b3 = readByte(data);
            uint8 b4 = readByte(data);

            uint32 x1 = uint32(b) | (uint32(b2) << 8); // convert to little endian
            uint32 x2 = x1 | (uint32(b3) << 16);
            uint32 x3 = x2 | (uint32(b4) << 24);

            x3 >>= 2; // remove the last 2 mode bits
            value = uint256(x3);
        } else if (mode == 3) {
            // [1073741824, 4503599627370496]
            uint8 l = (b >> 2) + 4; // remove mode bits
            require(l <= 8, "unexpected prefix decoding Compact<Uint>");
            return ScaleCodec.decodeUint256(read(data, l));
        } else {
            revert("Code should be unreachable");
        }
        return (value);
    }

        uint256 len = proof.parachains.length;
