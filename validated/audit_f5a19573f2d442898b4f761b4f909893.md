Based on the codebase, `core/web/router.go` wires all v2 API routes through authentication middleware, but the LOOP plugin proxy endpoints registered via `loopRoutes` are a clear exception — this mirrors the CVE-2026-8335 pattern where one endpoint lacks the auth check enforced everywhere else.

### Title
Missing authentication on LOOP plugin pprof/metrics proxy endpoints - (File: core/web/router.go)

### Summary
The chainlink node's web router applies session/token authentication (`auth.Authenticate`) to essentially every sensitive `/v2/*` route, and even wraps the node's *own* pprof endpoints (`metricRoutes`) inside the authenticated `authv2` group. However, `loopRoutes`, which exposes proxy endpoints forwarding to internal LOOP (LOOPP) plugin processes' `/metrics` and `/debug/pprof/*` endpoints, is registered directly on the unauthenticated top-level `api` group with no auth middleware at all.

### Finding Description
In `NewRouter`, routes are set up as: [1](#0-0) 

`loopRoutes` is called on `api` — the outer group that only has rate limiting and session middleware, not authentication: [2](#0-1) 

Compare this to the node's own pprof/debug endpoints (`metricRoutes`), which are deliberately nested inside `authv2`, a group requiring `auth.AuthenticateByToken`/`AuthenticateBySession`: [3](#0-2) [4](#0-3) 

The handlers registered by `loopRoutes` proxy requests unauthenticated to internal LOOP plugin processes' pprof and metrics HTTP servers: [5](#0-4) [6](#0-5) 

The `pluginPPROFHandler` forwards arbitrary query parameters (`debug`, `gc`, `seconds`) directly to the plugin's `/debug/pprof/*` profile endpoints, including CPU profile capture controlled by a client-supplied `seconds` duration: [7](#0-6) 

### Impact Explanation
Any unauthenticated client that can reach the node's HTTP port can hit `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/metrics` without providing any session or API token — unlike every comparable debug/metrics surface in the same router, which is gated behind `auth.Authenticate`. This allows an unauthenticated actor to:
- Retrieve internal metrics and pprof profiling data (goroutine stacks, heap samples, potentially leaking sensitive in-memory state) from LOOP plugin processes.
- Trigger long-running CPU profile captures via the attacker-controlled `seconds` parameter, tying up plugin resources for a client-chosen duration — a denial-of-service vector reachable without credentials.

This is analogous to the Aix-DB report: a specific endpoint that should require the same authentication enforced on all sibling endpoints (here, `metricRoutes`) instead has none.

### Likelihood Explanation
High for reachability: `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` are registered unconditionally on the base router group with no build-tag or dev-only gating, so they are reachable on any node with LOOP plugins configured and exposed to the network, exactly like every other `/v2` production route.

### Recommendation
Move `loopRoutes(app, api)` registration to occur under an authenticated group (e.g., `authv2` or a group wrapped with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`), consistent with how `metricRoutes` handles the node's own pprof/debug surface.

### Proof of Concept
1. Start a chainlink node with at least one LOOP plugin registered (e.g., a Solana/Cosmos LOOPP relayer) and its web server exposed.
2. Without any session cookie or `X-Chainlink-EA-AccessKey`/token headers, issue:
   `GET /plugins/<plugin-name>/debug/pprof/profile?seconds=60`
3. Observe the request succeeds and returns a CPU profile from the internal plugin process — confirming no authentication is enforced, in contrast to `/debug/pprof/*` under `authv2`, which returns `401 Unauthorized` for the same unauthenticated request.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
