Audit Report

## Title
Non-constant-time Bearer token comparison on Prometheus metrics endpoint enables timing side-channel token recovery - ([File: core/web/router.go])

## Summary
The `prometheusHandler` middleware guarding the `/metrics` HTTP endpoint compares the client-supplied `Authorization` header against the configured `Prometheus.AuthToken` secret using Go's native `!=` string operator, which is not constant-time. This differs from the rest of the codebase's authentication paths, which correctly use `subtle.ConstantTimeCompare` or bcrypt.

## Finding Description
`prometheusHandler` is wired up as the gin handler for the metrics path via `e.GET(p.MetricsPath, prometheusHandler(p.Token, h))` [1](#0-0) . Inside the handler, the expected value is constructed as `"Bearer " + token` and compared directly against the request header using `!=`: `bearer := "Bearer " + token` followed by `if header != bearer { ... }` [2](#0-1) . Go's `!=` on strings performs a byte-by-byte comparison that returns as soon as a mismatch is found, making comparison time dependent on the number of correctly-guessed leading bytes. This contrasts with `AuthenticateUserByToken` in `core/sessions/session.go`, which uses `subtle.ConstantTimeCompare` [3](#0-2) , and `AuthenticateExternalInitiator` in `core/bridges/external_initiator.go`, which does the same [4](#0-3) . No other middleware or wrapper mitigates this before the comparison — if `token != ""`, an unauthenticated request straight to `/metrics` reaches this code path directly [5](#0-4) .

## Impact Explanation
This exposes the `Prometheus.AuthToken` secret to a timing side-channel attack, allowing an unauthenticated network client to potentially recover the token byte-by-byte and gain unauthorized access to the node's `/metrics` endpoint. This maps to the "key/secret disclosure" impact class, though the disclosed secret only grants access to operational metrics data rather than fund movement or job execution capability, limiting the practical severity.

## Likelihood Explanation
Exploitability requires network reachability to the metrics port plus the ability to perform enough timed requests to statistically distinguish sub-microsecond/microsecond-level timing differences caused by early-exit byte comparison over a small number of possible byte values per position. This is feasible on a low-jitter LAN path but significantly harder over the public internet due to network jitter dominating the signal. The underlying root cause (non-constant-time comparison of a secret against attacker input) is real and verifiable in the current code.

## Recommendation
Replace the `header != bearer` string comparison with `subtle.ConstantTimeCompare([]byte(header), []byte(bearer)) != 1` (padding/normalizing lengths first, or comparing HMACs of both values) to match the constant-time pattern already used in `AuthenticateUserByToken` and `AuthenticateExternalInitiator`.

## Proof of Concept
1. Configure a node with `[Prometheus] AuthToken = "<secret>"`.
2. Send repeated GET requests to `/metrics` with `Authorization: Bearer <guess>`, varying one trailing byte at a time.
3. Statistically measure response latency for each guess over many trials; correct-prefix guesses take measurably longer to reject than incorrect-prefix guesses due to the early-exit `!=` comparison in `prometheusHandler` (`core/web/router.go:693`).
4. Iterate byte-by-byte to reconstruct the full `AuthToken`.

```go
func prometheusHandler(token string, h http.Handler) gin.HandlerFunc {
	return func(c *gin.Context) {
		if token == "" {
			h.ServeHTTP(c.Writer, c.Request)
			return
		}

		header := c.Request.Header.Get("Authorization")

		if header == "" {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}

		bearer := "Bearer " + token

		if header != bearer {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}
```

```go
func AuthenticateUserByToken(token *auth.Token, user *User) (bool, error) {
	hashedSecret, err := auth.HashedSecret(token, user.TokenSalt.ValueOrZero())
	if err != nil {
		return false, err
	}
	return subtle.ConstantTimeCompare([]byte(hashedSecret), []byte(user.TokenHashedSecret.ValueOrZero())) == 1, nil
}
```
