Audit Report

## Title
Cross-user response hijacking via attacker-controlled MessageID collision in the WebAPI capabilities gateway handler - (File: `core/services/gateway/handlers/capabilities/handler.go`)

## Summary
The `handler.savedCallbacks` map in the gateway's legacy WebAPI capabilities handler is keyed solely by the caller-supplied JSON-RPC `ID` (`msg.Body.MessageID`), with no duplicate-key check on insertion. Any unprivileged caller hitting the gateway's public `UserServerConfig` endpoint can submit a `web_api_trigger` request whose `ID` collides with another concurrent in-flight request, silently overwriting the earlier caller's stored `Callback`, so that the DON's eventual response for the original request is delivered to the second caller instead.

## Finding Description
`gateway.ProcessRequest` sets `msg.Body.MessageID = req.ID` from the raw, attacker-controlled JSON-RPC request and only validates its length/null-suffix, not uniqueness: [1](#0-0) [2](#0-1) 

This flows into `handler.HandleLegacyUserMessage`, which unconditionally writes `h.savedCallbacks[msg.Body.MessageID] = &savedCallback{...}`, overwriting any existing entry for that key without any collision check: [3](#0-2) 

When a DON node later responds, `handleWebAPITriggerMessage` looks the entry up purely by `MessageID`, deletes it, and dispatches the response to whichever `Callback` currently occupies that slot: [4](#0-3) 

The identical unguarded pattern exists in the legacy `dummyHandler` used elsewhere in the gateway: [5](#0-4) [6](#0-5) 

This is a genuine regression relative to the codebase's own established pattern for this exact problem. The newer `common.RequestCache`, used by other gateway handlers (e.g. vault, confidentialrelay), explicitly scopes its key to `globalID{sender, id}` and rejects duplicates with `"request already exists"`: [7](#0-6) . Similarly, `OutgoingConnectorHandler.responses.new(messageID)` on the sibling outgoing-connector path explicitly detects and rejects ID reuse. The capabilities/legacy handler's `savedCallbacks` map has no equivalent protection, confirming this is a real gap rather than an intentional design choice — the maintainers clearly recognize and mitigate this bug class elsewhere but missed it here.

No other guard exists: `HandleLegacyUserMessage` only checks payload decode, timestamp staleness, and method name before writing to the map — there is a `// TODO: apply allowlist and rate-limiting here` comment confirming that authorization/rate-limiting is not yet implemented on this path, but even that would not by itself prevent the ID-collision issue since the bug is purely about map-key partitioning, not about who is calling. [8](#0-7)  The gateway's request ID validation only bounds length to 200 chars and gives no uniqueness enforcement: [9](#0-8) 

## Impact Explanation
Any unprivileged external caller reaching the public gateway endpoint can cause another concurrent caller's trigger-response payload — potentially containing workflow/node-produced data intended only for the original requester — to be delivered to itself, and can simultaneously cause the original caller's request to silently vanish (its callback slot reassigned, so it eventually times out with `RequestTimeoutError`). This is a concrete cross-user response confusion/corruption bug on the gateway's user-facing request/response correlation path, matching the in-scope "gateway request impersonation / cross-user response corruption" impact category.

## Likelihood Explanation
Exploitation requires only: (1) an in-flight `MessageID`/JSON-RPC `ID` to collide with — trivially achievable by an attacker choosing a fixed/predictable ID (e.g., `"1"`) and racing a low-traffic or targeted gateway instance, and (2) sending two `web_api_trigger` requests with that same ID within the `defaultCallbackMaxAgeSec` (120s) window: [10](#0-9) . No node compromise, no signature break, no elevated privilege is needed — the entire flaw is in unprivileged HTTP-reachable map-key handling.

## Recommendation
- Key `savedCallbacks` by a composite of `MessageID` plus a caller-scoped/connection-scoped identifier (mirroring `common.RequestCache`'s `globalID{sender, id}` pattern), or reject/error on insertion if the key already exists (mirroring `OutgoingConnectorHandler.responses.new(messageID)`'s duplicate detection).
- Apply the identical fix to `handler.dummy.go`'s `HandleLegacyUserMessage`/`savedCallbacks`, which has the same unguarded overwrite pattern.
- Consider migrating this legacy handler to reuse `common.RequestCache` directly instead of maintaining a separate, unprotected `savedCallbacks` map.

## Proof of Concept
1. Configure a gateway with the `web-api-capabilities` handler for a DON.
2. Send Client A's request: `{"jsonrpc":"2.0","id":"X","method":"web_api_trigger","params":{...donID, valid signature, payloadA...}}` to the gateway's user server endpoint — observe `savedCallbacks["X"] = CallbackA` set in `HandleLegacyUserMessage` (`handler.go:412`).
3. Before any DON node replies, send Client B's request with the same `"id":"X"` and a different valid signed payload — observe `savedCallbacks["X"]` overwritten with `CallbackB`.
4. Have a DON test node respond only to A's original signed message (`MessageID = "X"`); observe in `handleWebAPITriggerMessage` (`handler.go:148-162`) that `savedCallbacks["X"]` now resolves to `CallbackB`, and B's HTTP client receives A's DON-originated response data while A's request eventually times out.

func ValidatedMessageFromReq(req *jsonrpc.Request[json.RawMessage]) (*api.Message, error) {
	if req.Version != "2.0" {
		return nil, errors.New("incorrect jsonrpc version")
	}
	if req.Method == "" {
		return nil, errors.New("empty method field")
	}
	if req.Params == nil {
		return nil, errors.New("missing params attribute")
	}
	var m api.Message
	err := json.Unmarshal(*req.Params, &m)
	if err != nil {
		return nil, fmt.Errorf("failed to unmarshal request params: %w", err)
	}
	m.Body.Method = req.Method
	m.Body.MessageID = req.ID
	err = m.Validate()
	if err != nil {
		return nil, err
	}
	return &m, nil
}

	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {

		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)

			),
			ErrorCode: api.UserMessageParseError,
		})

	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

func (d *dummyHandler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback Callback) error {
	d.mu.Lock()
	d.savedCallbacks[msg.Body.MessageID] = &savedCallback{msg.Body.MessageID, callback}
	don := d.don
	d.mu.Unlock()
	params, err := json.Marshal(msg)
	if err != nil {
		return err
	}
	rawParams := json.RawMessage(params)
	req := &jsonrpc.Request[json.RawMessage]{
		Version: "2.0",
		ID:      msg.Body.MessageID,
		Method:  msg.Body.Method,
		Params:  &rawParams,
	}
	for _, member := range d.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

func (d *dummyHandler) HandleNodeMessage(ctx context.Context, resp *jsonrpc.Response[json.RawMessage], nodeAddr string) error {
	var msg api.Message
	err := json.Unmarshal(*resp.Result, &msg)
	if err != nil {
		return err
	}
	msg.Body.MessageID = resp.ID
	err = msg.Validate()
	if err != nil {
		return err
	}
	if nodeAddr != msg.Body.Sender {
		return fmt.Errorf("node address %s does not match message sender %s", nodeAddr, msg.Body.Sender)
	}
	d.mu.Lock()
	savedCb, found := d.savedCallbacks[msg.Body.MessageID]
	delete(d.savedCallbacks, msg.Body.MessageID)
	d.mu.Unlock()

	if found {
		// Send first response from a node back to the user, ignore any other ones.
		codec := api.JSONRPCCodec{}
		return savedCb.SendResponse(UserCallbackPayload{RawResponse: codec.EncodeLegacyResponse(&msg), ErrorCode: api.NoError})
	}
	return nil
}

type globalID struct {
	sender string
	id     string
}

type pendingRequest[T any] struct {
	handlers.Callback
	responseData *T
	timeoutTimer *time.Timer
	mu           sync.Mutex
}

func NewRequestCache[T any](timeout time.Duration, maxCacheSize uint32) RequestCache[T] {
	return &requestCache[T]{cache: make(map[globalID]*pendingRequest[T]), timeout: timeout, maxCacheSize: maxCacheSize}
}

func (c *requestCache[T]) NewRequest(lggr logger.Logger, request *api.Message, callback handlers.Callback, responseData *T) error {
	if request == nil {
		return errors.New("request is nil")
	}
	if responseData == nil {
		return errors.New("responseData is nil")
	}
	key := globalID{request.Body.Sender, request.Body.MessageID}
	c.mu.Lock()
	defer c.mu.Unlock()
	_, ok := c.cache[key]
	if ok {
		return errors.New("request already exists")
	}
	if len(c.cache) >= int(c.maxCacheSize) {
		return errors.New("request cache is full")
	}
	codec := api.JSONRPCCodec{}
	timer := time.AfterFunc(c.timeout, func() {
		err := c.deleteAndSendOnce(key, handlers.UserCallbackPayload{RawResponse: codec.EncodeLegacyResponse(request), ErrorCode: api.RequestTimeoutError})
		if err != nil {
			lggr.Errorw("failed to send timeout response", "error", err)
		}
	})
	c.cache[key] = &pendingRequest[T]{Callback: callback, responseData: responseData, timeoutTimer: timer}
	return nil
}
