### Title
Simplex Uniswap V4 venue pricing uses manipulable live pool spot price with no TWAP, allowing flash-loan price manipulation to drain solver funding positions - ([File: sdk/packages/simplex/src/funding/uniswapV4/UniswapV4FundingPlanner.ts])

### Summary
Hyperbridge's Simplex intent-solver prices "venue" (curveless) trading pairs directly from a Uniswap V4 pool's instantaneous spot price (`sqrtPriceX96`/current tick), with no TWAP or manipulation-resistant sampling. The only defense is an *optional*, per-chain static `referencePrice`/`maxDeviationBps` guard that the operator may simply not configure. This mirrors the exact bug class from the Deus DAO exploit, where a spot AMM balance used as a collateral-value oracle was manipulated via flash loan to extract value.

### Finding Description
`UniswapV4FundingPlanner.getExoticTokenPrice` selects the position with the highest pool liquidity and calls `computeDirectPoolPriceUsd`, which derives the USD price directly from the SDK pool's `token0Price`/`token1Price`, themselves computed from the live `sqrtPriceX96` read via `UniswapV4LiquidityState.refresh()`: [1](#0-0) [2](#0-1) 

The pool state itself is read fresh, uncached, straight off `getSlot0` every call — a pure spot read with no time-weighting: [3](#0-2) 

This price feeds directly into `FXFiller.getVenueUsdPrice`/`venuePriceMemo`, which is used to size order legs for curveless pairs (`resolveLegRates`), documented explicitly: [4](#0-3) 

The project's own internal documentation confirms this is a known, unaddressed weakness: "`computeDirectPoolPriceUsd` returns the raw pool mid derived from `sqrtPriceX96`... there is no size or impact term... `checkPriceGuard` is the only defense on this path, and it checks deviation from a static reference, not execution cost": [5](#0-4) 

Critically, the price guard is entirely **optional** — a chain with no `referencePrice`/`maxDeviationBps` configured is left completely unguarded, and `checkPriceGuard` returns `true` (pass) whenever no guard exists for the chain: [6](#0-5) [7](#0-6) 

Documentation explicitly states: "The two fields must be set together; omit both to leave the chain unguarded": [8](#0-7) 

This is structurally identical to the Deus DAO root cause: a spot AMM price (there, the Solidex USDC/DEI pool balance) used directly as an oracle for a financial decision (there, collateral valuation; here, cross-chain fill pricing), manipulable within a single transaction via a flash loan, with no TWAP or robust guard mandated.

### Impact Explanation
An unprivileged attacker can flash-loan-manipulate the referenced Uniswap V4 pool's spot price within one block/transaction, then submit (or have ready) a cross-chain intent order that the Simplex solver prices and fills using `getExoticTokenPrice`'s manipulated result. Because the solver both derives the fill amount from this spot price and funds fills directly from the same Uniswap V4 LP position (which the manipulation also perturbs), the attacker can force the solver to deliver more output tokens than the input is worth, or to swap through its own now-distorted pool at a bad rate, directly draining the solver's LP/vault capital for profit — concrete theft of funds, on any operator who has not configured (or has loosely configured) the optional price guard.

### Likelihood Explanation
Likelihood is High for any Simplex deployment using Uniswap V4 pool-based pricing without a price guard (guard is optional and off by default), and Medium even with a guard configured, since the guard only bounds deviation from a static reference and does not account for pool depth, fee tier, or execution cost, and is checked once at quote time rather than being manipulation-resistant (e.g., TWAP). The attack requires only capital for a flash loan and the ability to submit an intent order — both fully permissionless actions reachable from a single transaction, matching the analog's original attack shape exactly.

### Recommendation
Replace or supplement the live spot-price read (`getSlot0`) with a TWAP oracle (e.g., Uniswap V4's built-in oracle extension or an external TWAP) for venue-priced pairs. Make the price guard (`referencePrice`/`maxDeviationBps`) mandatory rather than optional for any pool-priced pair, and additionally bound execution against pool depth/fee tier (accounting for slippage/impact) rather than only checking mid-price deviation against a static reference.

### Proof of Concept
1. Attacker identifies a Simplex-configured chain/pair using Uniswap V4 pool-based pricing (`[vault.uniswapV4]`) with no `referencePrice`/`maxDeviationBps` set, per `docs/content/developers/evm/simplex/pricing.mdx` (guard optional).
2. Attacker flash-loans a large amount of the pool's stable or exotic side and swaps against the referenced Uniswap V4 pool to shift `sqrtPriceX96` in the direction favorable to them (identical in spirit to the Solidex USDC/DEI manipulation in the Deus DAO attack tx `0xe374495036fac18aa5b1a497a17e70f256c4d3d416dd1408c026f3f5c70a3a9c`).
3. In the same block, attacker submits (or has a bot submit) an intent order on the affected pair; `FXFiller.getVenueUsdPrice` → `UniswapV4FundingPlanner.getExoticTokenPrice` reads the just-manipulated `slot0` and returns a distorted USD price.
4. Solver fills the order at the distorted price, funding the output from its Uniswap V4 LP position (`UniswapV4FundingPlanner`), transferring value to the attacker.
5. Attacker reverses the pool manipulation and repays the flash loan, retaining the profit extracted from the solver's position — mirroring steps 2–7 of the Deus DAO attack sequence.

	async getExoticTokenPrice(chain: string, exoticToken: string): Promise<Decimal | null> {
		const state = this.stateByChain.get(chain)
		if (!state || !state.isHydrated()) return null

		try {
			await state.refresh()
		} catch (err) {
			this.logger.error({ err, chain }, "Failed to refresh state for price query")
			return null
		}

		const tokenLower = exoticToken.toLowerCase()
		let bestPrice: Decimal | null = null
		let bestLiquidity = 0n

		for (const pos of state.allPositions()) {
			if (pos.currency0.toLowerCase() !== tokenLower && pos.currency1.toLowerCase() !== tokenLower) continue
			const sdkPool = state.getSdkPool(pos.tokenId)
			if (!sdkPool) continue

			const result = this.computeDirectPoolPriceUsd(pos, sdkPool, chain)
			if (result && result.exoticToken.toLowerCase() === tokenLower) {
				const poolLiquidity = state.getPoolLiquidity(pos.tokenId)
				if (poolLiquidity > bestLiquidity) {
					bestPrice = result.priceUsd
					bestLiquidity = poolLiquidity
				}
			}
		}

		if (bestPrice) {
			this.logger.debug({ chain, token: tokenLower, priceUsd: bestPrice.toString() }, "Exotic token price computed")
		}
		return bestPrice
	}

	private computeDirectPoolPriceUsd(
		pos: HydratedV4Position,
		sdkPool: V4Pool,
		chain: string,
	): { exoticToken: string; priceUsd: Decimal } | null {
		const usdc = this.configService.getUsdcAsset(chain).toLowerCase()
		const usdt = this.configService.getUsdtAsset(chain).toLowerCase()
		const c0 = pos.currency0.toLowerCase()
		const c1 = pos.currency1.toLowerCase()

		if (c0 === usdc || c0 === usdt) {
			// currency0 is stable → exotic is currency1
			// token1Price = "token0 per token1" = USD per exotic
			return {
				exoticToken: c1,
				priceUsd: new Decimal(sdkPool.token1Price.toFixed(18)),
			}
		}

		if (c1 === usdc || c1 === usdt) {
			// currency1 is stable → exotic is currency0
			// token0Price = "token1 per token0" = USD per exotic
			return {
				exoticToken: c0,
				priceUsd: new Decimal(sdkPool.token0Price.toFixed(18)),
			}
		}

		return null
	}

	async refresh(): Promise<void> {
		const client = this.clientManager.getPublicClient(this.chain)
		const chainId = chainIdFromIdentifier(this.chain)

		// Group positions by poolId to avoid duplicate pool state fetches
		const poolIds = new Set(this.tokenIdToPoolId.values())

		// Fetch slot0 + liquidity for each unique pool via StateView
		const poolStateMap = new Map<string, { sqrtPriceX96: bigint; tick: number; poolLiquidity: bigint }>()

		for (const poolId of poolIds) {
			const [slot0Result, poolLiquidity] = await Promise.all([
				client.readContract({
					address: this.stateView,
					abi: UNISWAP_V4_STATE_VIEW_ABI,
					functionName: "getSlot0",
					args: [poolId as HexString],
				}) as Promise<[bigint, number, number, number]>,
				client.readContract({
					address: this.stateView,
					abi: UNISWAP_V4_STATE_VIEW_ABI,
					functionName: "getLiquidity",
					args: [poolId as HexString],
				}) as Promise<bigint>,
			])

			poolStateMap.set(poolId, {
				sqrtPriceX96: slot0Result[0],
				tick: slot0Result[1],
				poolLiquidity,
			})
		}

		// Refresh per-position liquidity and rebuild SDK Pool objects
		for (const pos of this.positions.values()) {
			const key = pos.tokenId.toString()
			const poolId = this.tokenIdToPoolId.get(key)
			const poolState = poolId ? poolStateMap.get(poolId) : undefined
			if (!poolId || !poolState) {
				throw new Error(
					`UniswapV4 refresh: missing pool state for tokenId ${key} (poolId=${poolId ?? "undefined"})`,
				)
			}

			// Read current position liquidity
			const liquidity = (await client.readContract({
				address: pos.positionManager,
				abi: UNISWAP_V4_POSITION_MANAGER_ABI,
				functionName: "getPositionLiquidity",
				args: [pos.tokenId],
			})) as bigint

			pos.liquidity = liquidity
			const prevOnChain = this.lastOnChainLiquidity.get(key) ?? liquidity
			const decrease = prevOnChain > liquidity ? prevOnChain - liquidity : 0n
			const prevConsumed = this.consumed.get(key) ?? 0n
			const newConsumed = prevConsumed > decrease ? prevConsumed - decrease : 0n
			this.consumed.set(key, newConsumed)
			this.lastOnChainLiquidity.set(key, liquidity)
			pos.remainingLiquidity = liquidity > newConsumed ? liquidity - newConsumed : 0n
			pos.sqrtPriceX96 = poolState.sqrtPriceX96
			pos.currentTick = poolState.tick

			// Build SDK Pool (without tick data provider — we only need amount calcs)
			const currency0 = currencyFromHydratedDecimals(chainId, pos.currency0, pos.decimals0)
			const currency1 = currencyFromHydratedDecimals(chainId, pos.currency1, pos.decimals1)

			const sdkPool = new V4Pool(
				currency0,
				currency1,
				pos.fee,
				pos.tickSpacing,
				pos.hooks,
				poolState.sqrtPriceX96.toString(),
				poolState.poolLiquidity.toString(),
				poolState.tick,
			)

	/**
	 * Queries funding venues for `token1Address`'s USD price on a chain.
	 * Uniswap V4 is preferred; falls back to other venues. Returns null when no
	 * venue can price the token there.
	 */
	private async getVenueUsdPrice(chain: string, token1Address: string): Promise<Decimal | null> {
		if (this.fundingVenues.length === 0) return null

		// Prefer V4, fall back to others
		const v4 = this.fundingVenues.filter((v) => v.name === "UniswapV4")
		const venues = v4.length > 0 ? v4 : this.fundingVenues

		for (const venue of venues) {
			const usdPrice = await venue.getExoticTokenPrice(chain, token1Address)
			if (usdPrice?.isPositive()) return usdPrice
		}
		return null
	}

	/** Per-evaluation memo over `getVenueUsdPrice`, keyed by (chain, token1). */
	private venuePriceMemo(): (chain: string, token1Address: string) => Promise<Decimal | null> {
		const cache = new Map<string, Decimal | null>()
		return async (chain: string, token1Address: string) => {
			const key = `${chain}:${token1Address}`
			const cached = cache.get(key)
			if (cached !== undefined) return cached
			const price = await this.getVenueUsdPrice(chain, token1Address)
			cache.set(key, price)
			return price
		}
	}

	/**
	 * Validates a live venue quote against the static reference price for the chain.
	 * Returns true (pass) when no guard is configured, or no reference exists for the
	 * chain. Returns false when the quote (token1 per USD) deviates from the reference
	 * by more than `maxDeviationBps`, in which case the order must not be filled.
	 */
	private checkPriceGuard(orderId: string | undefined, chain: string, venueToken1PerUsd: Decimal): boolean {
		const guard = this.priceGuard?.get(chain)
		if (!guard || guard.reference.lte(0)) return true

		const deviationBps = venueToken1PerUsd.minus(guard.reference).abs().div(guard.reference).mul(10000)
		if (deviationBps.gt(guard.maxDeviationBps)) {
			this.logger.warn(
				{
					orderId,
					chain,
					venuePrice: venueToken1PerUsd.toString(),
					referencePrice: guard.reference.toString(),
					deviationBps: deviationBps.toFixed(2),
					maxDeviationBps: guard.maxDeviationBps,
				},
				"Rejecting order: Uniswap venue quote outside price-guard band",
			)
			return false
		}
		return true
	}

```text
## Uniswap price guards

Pool-based pricing trusts the live pool, which leaves the solver exposed to a manipulated, stale, or thin pool returning a bad quote. To bound that risk, give a position a **`referencePrice`** and **`maxDeviationBps`**. Whenever the pool quote on that chain drifts more than `maxDeviationBps` above or below the reference, the solver refuses to fill — the order is rejected before any bid is submitted.

`referencePrice` is expressed in **exotic tokens per USD**, the same units as the bid/ask curves. The two fields must be set together; omit both to leave the chain unguarded.
```
