### Title
Unchecked RAY market-value overflow permanently freezes an overgrown market - ([File: common/src/rates/simulate.rs](common/src/rates/simulate.rs))

### Summary
`accrue_step` computes `borrowed_original` and `supplied_original` through `scaled_to_original`, which multiplies scaled RAY shares by the index and panics on an unrepresentable result. [1](#0-0) [2](#0-1)  Once a validly configured market grows enough that either scaled balance times its live index exceeds the `i128`/RAY domain, every subsequent accrual attempt fails before it can stamp `last_timestamp`, so the failure repeats indefinitely. [3](#0-2) 

### Finding Description
The controller exposes `update_indexes(caller, assets)` permissionlessly after `caller.require_auth()`, and forwards the requested `Vec<HubAssetKey>` to the pool. [4](#0-3) [5](#0-4)  Pool accrual loops over elapsed time chunks and calls `accrue_chunk`, which unconditionally evaluates both scaled market totals through `accrue_step`. [6](#0-5)  `scaled_to_original` performs `scaled.mul(index)` without a market-level bound that guarantees the resulting RAY value fits. [2](#0-1) 

The index ceiling does not prevent this state because the borrowed or supplied share quantity can already be large enough that `shares * index / RAY` overflows before the index reaches `MAX_BORROW_INDEX_RAY`. [7](#0-6)  The protocol's own stress test reaches this cliff with an 18-decimal market and sustained high utilization: `update_indexes` fails with `MathOverflow` while `borrow_index < MAX_BORROW_INDEX_RAY`. [8](#0-7) 

### Impact Explanation
The affected hub asset becomes permanently frozen because `last_timestamp` is never advanced past the failing accrual calculation. [3](#0-2)  The repository's executable proof then shows both `withdraw` and `repay` fail with the same `MathOverflow`, since those operations accrue the market before mutating positions. [9](#0-8)  This permanently freezes supplier funds and borrower repayment/liquidation processing in that market, satisfying the permanent-freezing impact class. [10](#0-9) 

### Likelihood Explanation
Likelihood is conditional on a large, validly admitted market remaining at high utilization long enough for index growth to push a scaled total outside the representable RAY domain. [11](#0-10)  A normal unprivileged caller cannot choose the ledger timestamp, but once time places the market across the boundary, any authorized user can trigger the state through `controller.update_indexes(caller, [hub_asset])`; thereafter no recovery path within the market's normal entrypoints succeeds. [4](#0-3) [12](#0-11)  The severity is High rather than Medium because the demonstrated consequence is permanent freezing of all exits and repayments for the affected market. [9](#0-8) 

### Recommendation
Bound scaled shares and accrued market values against a checked `MAX_RAY_VALUE`-style domain before permitting new supply or debt, rather than relying on token caps and index ceilings to imply value representability. [7](#0-6)  `accrue_step` should also detect the value-overflow condition explicitly and preserve a recovery path, such as stopping accrual at a representable bound and allowing repayment, withdrawal, liquidation, or bad-debt settlement to proceed under a clearly defined degraded mode. [1](#0-0)  At minimum, entry and cap checks should reject configurations whose admitted shares can later overflow `scaled_to_original` before `MAX_BORROW_INDEX_RAY`, and regression coverage should include the existing whale-market test. [2](#0-1) [10](#0-9) 

### Proof of Concept
The repository already contains a deterministic reproduction: `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap` creates `BIG18`, supplies `1_000_000_000` whole tokens, borrows 98% of that supply, advances yearly, and repeatedly calls `try_update_indexes_for(&["BIG18"])`. [11](#0-10)  The update eventually returns `MathOverflow` while the stored borrow index remains below `MAX_BORROW_INDEX_RAY`, proving the cap did not prevent the overflow. [13](#0-12)  Subsequent `try_withdraw_raw(BOB, "BIG18", 1)` and `try_repay(ALICE, "BIG18", 1.0)` both return `MathOverflow`, demonstrating the permanent market freeze. [9](#0-8)

```rust
    borrowed: Ray,
```

```rust
pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}
```

```rust
/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
```
