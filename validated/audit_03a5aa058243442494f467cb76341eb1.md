Audit Report

## Title
Unbounded, Unauthenticated Growth of the Vault Gateway `activeRequests` Map via `vault.publicKey_get` Flooding — (File: `core/services/gateway/handlers/vault/handler.go`)

## Summary
`HandleJSONRPCUserMessage` explicitly bypasses authorization for `vaulttypes.MethodPublicKeyGet` and, whenever `getCachedPublicKey()` returns `nil`, inserts every incoming request into `h.activeRequests` via `newActiveRequest`, keyed by the fully attacker-controlled `req.ID` [1](#0-0) . Unlike `common.RequestCache`, which enforces a `maxCacheSize` bound at insertion time [2](#0-1) , `newActiveRequest` only rejects duplicate IDs, with no cap on total map size [3](#0-2) . The only reclamation mechanism is a 5-second ticker that removes entries older than `requestTimeout` (default 30s) [4](#0-3) [5](#0-4) .

## Finding Description
The comment in the code itself acknowledges the assumption underlying the lack of authorization: "Public key requests don't require authorization... we cache this value quite aggressively so don't need to worry about DoS" [6](#0-5) . This assumption only holds once `cachedPublicKeyGetResponse` is populated; before the first successful fetch, or during any period where the node-side vault fails to respond, `getCachedPublicKey()` returns `nil` [7](#0-6) , and every unauthenticated `publicKey_get` request is stored in the unbounded `activeRequests` map.

Verifying the ingress path: `gateway.ProcessRequest` in `core/services/gateway/gateway.go` decodes the raw JSON-RPC request, checks only that `req.ID` is ≤200 characters, and dispatches directly to `h.HandleJSONRPCUserMessage` with no gateway-wide per-sender or global rate limiter applied to this call [8](#0-7) . This confirms there is no upstream throttling protecting the vault handler's unauthenticated code path — in contrast to the HTTP capability handler (`core/services/gateway/handlers/capabilities/v2/http_handler.go`), which explicitly wires global and per-node rate limiters for its ingress paths. The vault handler's `nodeRateLimiter` field only throttles node→gateway responses in `HandleNodeMessage`, not user-initiated requests [9](#0-8) .

## Impact Explanation
This is an in-scope resource-exhaustion / denial-of-service vector against the gateway process. An attacker who can sustain a flood of unique-ID `publicKey_get` requests during any window where the public key cache is empty (startup, cache never warming due to node unavailability, or a race where the attacker's own flood competes with legitimate fetch attempts) can grow `h.activeRequests` without bound between 5-second prune ticks, consuming gateway memory and degrading service for all DON participants relying on that gateway instance.

## Likelihood Explanation
The `publicKey_get` method is unauthenticated by design, and the vulnerable code path is reachable via a single unprivileged HTTP request with no credentials required. The likelihood of the cache being empty depends on operational conditions (startup, node/vault unavailability, or an attacker deliberately preventing successful cache population by overwhelming the same code path used for legitimate cache refills), which is a realistic occurrence window rather than a purely theoretical one.

## Recommendation
- Add a `maxActiveRequests` bound to `h.activeRequests` in `core/services/gateway/handlers/vault/handler.go`, following the `maxCacheSize` pattern already used in `common.RequestCache`, rejecting new entries once the cap is reached.
- Apply a per-IP/per-sender rate limiter specifically to the unauthenticated `publicKey_get` path, since it bypasses `requestProcessor.ProcessRequest`'s authorization/rate-limiting gate.
- Consider eviction/limiting at insertion time rather than relying solely on the time-based prune loop for unauthenticated paths.

## Proof of Concept
1. Start (or force) a state where `h.cachedPublicKeyGetResponse` is `nil` (e.g., before the first successful `fetchVaultPublicKey`, or during node unavailability).
2. Send a high-rate flood of JSON-RPC requests to the gateway's public HTTP endpoint with `method: "vault.publicKey_get"`, a unique `id` (≤200 chars) per request, and no `Auth` field.
3. Each request enters `HandleJSONRPCUserMessage` → `newActiveRequest`, inserting an unbounded entry into `h.activeRequests`, with no authorization check and no cap on total map size.
4. Sustain the flood at a rate exceeding the 5-second prune tick's reclamation capacity (default `requestTimeout` 30s) to demonstrate unbounded growth of `h.activeRequests` and rising gateway memory usage.

// removeExpiredRequests removes expired requests from the pending requests map
func (h *handler) removeExpiredRequests(ctx context.Context) {
	h.mu.RLock()
	var expiredRequests []*activeRequest
	now := h.clock.Now()
	for _, userRequest := range h.activeRequests {
		if now.Sub(userRequest.createdAt) > h.requestTimeout {
			expiredRequests = append(expiredRequests, userRequest)
		}
	}
	h.mu.RUnlock()

	for _, er := range expiredRequests {
		responses := er.copiedResponses()
		var nodeResponses strings.Builder
		for nodeKey, nodeResponse := range responses {
			_, _ = fmt.Fprintf(&nodeResponses, "%s ---::: %v               ", nodeKey, nodeResponse)
		}
		nodeResponsesStr := nodeResponses.String()
		err := h.sendResponse(ctx, er, h.errorResponse(er.req, api.RequestTimeoutError, errors.New("request expired without getting quorum of responses from nodes. Available responses: "+nodeResponsesStr), []byte(nodeResponsesStr)))
		if err != nil {
			h.lggr.Errorw("error sending response to user", "requestID", er.req.ID, "error", err)
		}
	}
}

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

	if h.cachedPublicKeyGetResponse == nil {
