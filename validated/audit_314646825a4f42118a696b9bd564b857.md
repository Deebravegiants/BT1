### Title
Flash-funded Aquarius reserve donation inflates LP fair-value oracle price, enabling undercollateralized borrow - (File: contracts/price-aggregator/src/providers/aquarius.rs / common/src/oracle/lp_stable.rs)

### Summary
The MerlinLabs/PancakeBunny class is "use flash-loaned capital to distort the on-chain value measure that decides how much the protocol credits/mints". XOXNO Lending maps this onto its Aquarius LP fair-value pricing: the price-aggregator values an LP share from the pool's **live reserves and total shares**, and LP oracle configurations waive the dual-leg tolerance/smoothing checks applied to plain feeds. A dominant LP in an Aquarius pool can donate (or imbalance-add) reserves to raise the computed LP price, then borrow against the inflated collateral at the controller — the exact "inflate measured value, extract the excess" shape of the MerlinLabs incident.

### Finding Description
`read()` in `contracts/price-aggregator/src/providers/aquarius.rs` derives the LP share price on every call from the pool's *current* reserves via `aquarius_pool_reserves_call`, `aquarius_total_shares_call`, and the two leg prices, with no TWAP, no smoothing, and no cross-source tolerance check [1](#0-0) . Per `docs/explanation/decisions.md`, LP configurations "waive smoothing and tolerance checks" — the sanity-band machinery that bounds ordinary feed deviation does not apply.

For a stable pool, `fair_stable_lp_price_wad` computes `price = min(price_a, price_b) * D / total_shares`, where `D` is the StableSwap invariant solved from WAD-normalized reserves [2](#0-1) . At meaningful amplification, `D` grows approximately linearly when reserves are inflated by a direct token donation to the pool contract (a donation raises reserves while `total_shares` is unchanged, since no LP mint occurred). The only on-read guard is `min_pool_value_wad`, a floor — a donation only pushes the pool value *up*, so it can never trip the floor [3](#0-2) .

For a constant-product pool, `fair_lp_price_wad` computes `2 * sqrt(value_a * value_b) / total_shares` [4](#0-3) . This correctly neutralizes *swaps* (which preserve `reserve_a * reserve_b`), but not donations: injecting the cheap leg raises `value_a * value_b` and hence the LP price by `sqrt(1 + D/V)` — sub-linear but unbounded and, crucially, cheap for a dominant LP.

The attacker path, all from one unprivileged address:
1. Become the dominant liquidity provider (share fraction `p ≈ 1`) of an Aquarius pool whose share token is listed as collateral in a XOXNO market — or acquire such a position; fund it via `flash_loan`/`flash_position` if needed.
2. `supply` the LP share token as collateral (controller `supply` → pool `supply`).
3. Donate amount `E` of the cheaper leg directly to the Aquarius pool (an ordinary token transfer to the pool address; no XOXNO privileged call). Reserves rise, `total_shares` does not.
4. `borrow` the maximum against the now-inflated collateral value. The controller prices collateral via the Context-cached strict price, which is this same manipulated read.
5. Redeem LP shares, recovering `p * E` of the donation, and repay the flash loan. Net donation cost is `(1 - p) * E` while the borrow gain against a stable pool is `≈ LTV * p * E` — profitable whenever `LTV * p > 1 - p` (e.g., `p = 0.9`, `LTV = 0.7`).

### Impact Explanation
The borrowed assets exceed the true collateral value; the position is born undercollateralized and immediately liquidate-able only at a loss to the pool. Once the attacker defaults, `seize_positions` socializes the shortfall via `apply_bad_debt_to_supply_index`, i.e. supplier principal is written down — theft of user funds / protocol insolvency, matching the loss profile of the MerlinLabs incident (users' deposits drained through mis-valued collateral accounting).

### Likelihood Explanation
Requires an LP-token market configured with an `AquariusLp`/`AquariusStableLp` source and an Aquarius pool shallow enough that one actor can dominate LP share supply — precisely the conditions `min_pool_value_wad` is meant to screen at listing, but that floor only bounds total pool value, not attacker share concentration. All steps use allowed unprivileged actions: own Aquarius liquidity/trades, a direct token transfer, and controller `supply`/`borrow`/`flash_loan`. Flash-loan funding removes the capital requirement for both the LP position and the donation within one transaction window, since the price read is instantaneous (live reserves, no smoothing).

### Recommendation
- Bound per-read deviation for LP sources: reintroduce a tolerance check by comparing the derived LP fair price against a stored reference/EMA, or price the LP using *minimum* of current-vs-reference reserves per leg (the same "use the cheaper evaluation" spirit already used for `min(price_a, price_b)` in the stable formula).
- Use manipulation-resistant reserve inputs: prefer time-weighted reserves or value the LP as `sum_i reserve_i * min_price_i` / conservative worst-leg valuation rather than `D * min_price`, which lets a donation of the cheap leg raise `D` directly.
- Screen attacker-controllable pools at governance admission: require `min_pool_value_wad` *and* a max single-holder concentration heuristic, or restrict LP collateral listings to pools with fee-on-transfer/locked liquidity.

### Proof of Concept
Conceptual Soroban sequence (single attacker address, optionally inside one `flash_position` callback):

```rust
// Attacker holds >=90% of Aquarius stable pool P shares; share token S is
// collateral in a XOXNO market with source AquariusStableLp.
// 1. Supply collateral
controller.supply(hub_key, shares_amount);            // credits S collateral

// 2. Donate cheap-leg token to Aquarius pool (reserves += E, shares unchanged)
token_cheap.transfer(&attacker, &aquarius_pool, E);

// 3. Aggregator re-read at borrow time:
//    fair_stable_lp_price_wad now returns min_p * (D + ~E_wad) / total_shares
//    -> collateral value inflated by ~min_p * E / total_shares per unit.

// 4. Borrow more than the true collateral supports
controller.borrow(hub_key_asset, inflated_ltv_amount); // pool transfers out real tokens

// 5. Recover donation
aquarius_pool.withdraw(...);                           // redeem p fraction of reserves incl. E
// default the borrow -> seize_positions -> supply_index write-down (bad debt)
```
