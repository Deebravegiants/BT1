Confirmed: `EcdsaBeefy.sol` has no equivalent of the `StaleMmrLeaf` freshness check that `SP1Beefy.sol` explicitly added and tested against.

### Title
Stale/replayed MMR leaf acceptance in `EcdsaBeefy` allows authority-set rotation suppression and stale parachain state commitments - (File: evm/src/consensus/EcdsaBeefy.sol)

### Summary
`SP1Beefy.sol` was hardened with an explicit `StaleMmrLeaf` check enforcing `mmrLeaf.parentNumber + 1 == commitment.blockNumber`, with an accompanying comment and regression test explaining that an MMR is append-only so *any* historical leaf still proves inclusion against the current (larger) signed root, and that accepting a stale leaf lets an attacker/relayer "advance the trusted height while replaying an older leaf's `nextAuthoritySet`" [1](#0-0) . The Solidity comment for `SP1Beefy.verifyConsensus` and its Rust counterpart both explicitly document this exact "far-ahead height with a stale leaf" bug class and its fix [2](#0-1) [3](#0-2) . The sibling `EcdsaBeefy.sol` consensus client — which performs the exact same "advance height + optionally rotate authority set from the mmr leaf + derive parachain heads root from the mmr leaf" logic — contains no such check.

### Finding Description
In `EcdsaBeefy.verifyMmrUpdateProof`, the contract:
1. Verifies the signed commitment's supermajority and authority-set membership for `commitment.blockNumber` [4](#0-3) .
2. Calls `verifyMmrLeaf`, which merely proves that the *submitted* `relay.latestMmrLeaf` (with an attacker/relayer-supplied `parentNumber`) is included at `leafIndex(parentNumber)` in the mmr represented by `mmrRoot` — it never checks that this leaf is the one appended at `commitment.blockNumber` [5](#0-4) .
3. Unconditionally sets `trustedState.latestHeight = latestHeight` (the signed commitment's block number) regardless of which leaf was supplied, and only rotates the authority set if the *submitted* leaf's `nextAuthoritySet.id` happens to be greater than the currently trusted one [6](#0-5) .
4. Uses the leaf's `extra` field (parachain heads root) — taken from whatever leaf was submitted — to verify all parachain header inclusion proofs [7](#0-6) [8](#0-7) .

Because MMR accumulators are append-only, a genuine inclusion proof for *any* historical leaf remains constructible and valid against the current (larger) signed `mmrRoot`, provided the caller supplies the correct current total leaf count to `MerkleMountainRange.VerifyProof`. Nothing in `EcdsaBeefy` ties the submitted leaf's `parentNumber` to `commitment.blockNumber` the way `SP1Beefy` now does. A relayer can therefore submit a validly-signed, fresh `commitment` (advancing `latestHeight` to the newest block) together with a genuine but stale historical `latestMmrLeaf` (with correct proof against the current root).

### Impact Explanation
- **Authority-set rotation suppression**: if the trusted state is mid-rotation (`trustedState.nextAuthoritySet.id` already reflects an upcoming set), submitting an older leaf whose `nextAuthoritySet.id` is not greater than the trusted one skips rotation entirely while `latestHeight` still advances to the newest signed height. This can permanently strand the light client on a retired/soon-to-be-retired authority set while future proofs for the real chain state are rejected as "stale" (since `latestHeight` already advanced past them), mirroring the exact freeze scenario the `SP1Beefy` fix and its comment describe: "stranding the client on a set the relay chain has retired" [9](#0-8) .
- **Stale state commitments accepted as current**: parachain header proofs are verified against the stale leaf's `extra` (heads root) while the client's `latestHeight` is bumped to the newest block, meaning `IntermediateState`s delivered to `EvmHost`/downstream ISMP handlers can be attributed to a height that does not match the actual finalized state referenced by the accepted proof, undermining the state-commitment integrity the consensus client is relied upon for by relayers submitting cross-chain messages.

### Likelihood Explanation
Any permissionless relayer can submit a `verify()` call with an arbitrary combination of a fresh signed `RelayChainProof.signedCommitment` and an older, independently-fetched `latestMmrLeaf` plus its genuine MMR inclusion proof against the current root — both are just historical, publicly obtainable chain data. No signing-key compromise or malicious validator/collator collusion is required, only crafting the `proof` argument passed to the public `EcdsaBeefy.verify` entry point.

### Recommendation
Add the same freshness pin used in `SP1Beefy.sol` to `EcdsaBeefy.verifyMmrUpdateProof`/`verifyMmrLeaf`: require `relay.latestMmrLeaf.parentNumber + 1 == commitment.blockNumber` (reverting with a `StaleMmrLeaf`-style error otherwise), matching the mitigation and regression tests already present for `SP1Beefy` (`testRejectsStaleMmrLeaf` in `evm/tests/foundry/SP1BeefyTest.sol` and `rejects_sp1_proof_carrying_a_stale_mmr_leaf` in `modules/consensus/beefy/verifier/src/test.rs`).

### Proof of Concept
1. Let the trusted `BeefyConsensusState` have `latestHeight = H0`, `currentAuthoritySet.id = N`, `nextAuthoritySet.id = N+1`.
2. Fetch a genuine, currently-signed BEEFY commitment for a much later block `H1 >> H0` with `validatorSetId = N` (or `N+1`), satisfying supermajority — this yields the current `mmrRoot`.
3. Instead of fetching the MMR leaf for `H1`, fetch the MMR leaf for an old block `H0 < Hstale < H1` whose `beefy_next_authority_set.id <= N+1` (e.g., still `N+1`, before the *next* rotation to `N+2` that occurred by `H1`).
4. Construct a valid `MerkleMountainRange` inclusion proof for the `Hstale` leaf against the current `mmrRoot` (using the real, current total leaf count) — this is always possible since MMRs are append-only accumulators.
5. Call `EcdsaBeefy.verify(previousState, abi.encode(RelayChainProof{signedCommitment: <H1 commitment>, latestMmrLeaf: <Hstale leaf>, proof: <mmr proof>}, parachainProof))`.
6. The call succeeds: `newState.latestHeight == H1` but `newState.nextAuthoritySet` is never rotated to the set that was actually next as of `H1` (since `Hstale`'s `nextAuthoritySet.id` isn't greater than the trusted one), and any parachain headers proven against `Hstale`'s `extra` root are accepted as intermediate states while the consensus client believes it is at height `H1`.     function verifyMmrUpdateProof(BeefyConsensusState memory trustedState, RelayChainProof memory relayProof)
        internal
        pure
        returns (BeefyConsensusState memory, bytes32)
    {
        uint256 sigLen = relayProof.signedCommitment.votes.length;
        uint256 latestHeight = relayProof.signedCommitment.commitment.blockNumber;
        Commitment memory commitment = relayProof.signedCommitment.commitment;
        if (
            commitment.validatorSetId != trustedState.currentAuthoritySet.id
                && commitment.validatorSetId != trustedState.nextAuthoritySet.id
        ) {
            revert UnknownAuthoritySet();
        }

        bool isCurrentAuthorities = commitment.validatorSetId == trustedState.currentAuthoritySet.id;
        AuthoritySetCommitment memory authoritySet =
            isCurrentAuthorities ? trustedState.currentAuthoritySet : trustedState.nextAuthoritySet;
        if (!checkParticipationThreshold(sigLen, authoritySet.len)) revert SuperMajorityRequired();

        uint256 payloadLength = commitment.payload.length;
        bytes32 mmrRoot;
        for (uint256 i = 0; i < payloadLength; i++) {
            if (commitment.payload[i].id == MMR_ROOT_PAYLOAD_ID && commitment.payload[i].data.length == 32) {
                mmrRoot = Bytes.toBytes32(commitment.payload[i].data);
            }
        }
        if (mmrRoot == bytes32(0)) revert MmrRootHashMissing();

        // verify the commitment
        bytes32 commitmentHash = keccak256(Codec.Encode(commitment));
        MerkleMultiProof.Leaf[] memory authorities = new MerkleMultiProof.Leaf[](sigLen);
        for (uint256 i = 0; i < sigLen; i++) {
            Vote memory vote = relayProof.signedCommitment.votes[i];
            address authority = ECDSA.recover(commitmentHash, vote.signature);
            authorities[i] =
                MerkleMultiProof.Leaf({index: vote.authorityIndex, hash: keccak256(abi.encodePacked(authority))});
        }

        bool valid = MerkleMultiProof.VerifyProof(authoritySet.root, relayProof.proof, authorities, authoritySet.len);
        if (!valid) revert InvalidAuthoritiesProof();

    function verifyMmrLeaf(BeefyConsensusState memory trustedState, RelayChainProof memory relay, bytes32 mmrRoot)
        internal
        pure
    {
        bytes32 hash = keccak256(
            Codec.Encode(
                PartialBeefyMmrLeaf({
                    version: relay.latestMmrLeaf.version,
                    parentNumber: relay.latestMmrLeaf.parentNumber,
                    parentHash: relay.latestMmrLeaf.parentHash,
                    nextAuthoritySet: relay.latestMmrLeaf.nextAuthoritySet,
                    extra: relay.latestMmrLeaf.extra
                })
            )
        );
        uint256 leafCount = leafIndex(trustedState.beefyActivationBlock, relay.latestMmrLeaf.parentNumber) + 1;
        MerkleMountainRange.Leaf[] memory leaves = new MerkleMountainRange.Leaf[](1);
        leaves[0] = MerkleMountainRange.Leaf({index: relay.latestMmrLeaf.leafIndex, hash: hash});
        bool valid = MerkleMountainRange.VerifyProof(mmrRoot, relay.mmrProof, leaves, leafCount);

        if (!valid) revert InvalidMmrProof();
    }

    // @dev Verifies that some parachain header has been finalized, given the current trusted consensus state.
    function verifyParachainHeaderProof(bytes32 headsRoot, ParachainProof memory proof)
        internal
        pure
        returns (IntermediateState[] memory)
    {
        uint256 len = proof.parachains.length;
        MerkleMultiProof.Leaf[] memory leaves = new MerkleMultiProof.Leaf[](len);
        IntermediateState[] memory intermediates = new IntermediateState[](len);

        for (uint256 i = 0; i < len; i++) {
            Parachain memory para = proof.parachains[i];
            Header memory header = Codec.DecodeHeader(para.header);
            if (header.number == 0) revert IllegalGenesisBlock();

            leaves[i] = MerkleMultiProof.Leaf(
                para.index,
                keccak256(bytes.concat(ScaleCodec.encode32(uint32(para.id)), ScaleCodec.encodeBytes(para.header)))
            );

            StateCommitment memory commitment = header.stateCommitment();
            intermediates[i] =
                IntermediateState({stateMachineId: para.id, height: header.number, commitment: commitment});
        }

        if (len > 0) {
            bool valid = MerkleMultiProof.VerifyProof(headsRoot, proof.proof, leaves, proof.leafCount);
            if (!valid) revert InvalidMmrProof();
        }

        return intermediates;
    }
