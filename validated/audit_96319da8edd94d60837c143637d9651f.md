### Title
Unauthenticated exposure of LOOP plugin pprof/metrics/discovery diagnostic endpoints - (File: core/web/router.go)

### Summary
The `loopRoutes` function registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` on the top-level `api` router group, which enforces only rate limiting and session cookie parsing — not authentication. Any unauthenticated network client that can reach the node's HTTP API can trigger pprof profiling (CPU/heap/goroutine profiles, `debug/pprof/profile` with a `seconds` parameter, `trace`) and read Prometheus service-discovery metadata for all registered LOOP plugins.

### Finding Description
`NewRouter` builds an `api` group with only `rateLimiter` and `sessions.Sessions` middleware [8](#0-7) , then calls `loopRoutes(app, api)` [9](#0-8) , which registers the plugin diagnostic routes directly on that unauthenticated group with no `auth.Authenticate` wrapper: [2](#0-1) 

This is unlike every comparable diagnostic surface in the same file: the node's own pprof handlers are only reachable through `authv2` (session/token authenticated) via `metricRoutes(authv2)` [10](#0-9) , and `/debug/vars` requires `auth.AuthenticateBySession` [7](#0-6) .

The handlers themselves perform no additional authorization check — they only validate that the named plugin exists in the registry before forwarding the request to the plugin's internal `debug/pprof` HTTP endpoint [3](#0-2) , or reading `debug/pprof/symbol` with a request body [4](#0-3) . Query parameters including `debug`, `gc`, and `seconds` are passed straight through to the plugin's pprof server [11](#0-10) .

### Impact Explanation
This matches the CVE-2019-17631 bug class exactly: unprivileged access to diagnostic operations (triggering profiling/GC-adjacent operations, creating diagnostic dumps) without any privilege check. An unauthenticated remote actor can:
- Force expensive CPU/blocking/trace profiling on internal LOOP plugin processes for attacker-chosen durations (`seconds` param, capped only by `PPROFOverheadSeconds` overhead logic), creating a resource-exhaustion/DoS vector against the node's plugin processes.
- Enumerate registered plugin names and internal Prometheus scrape targets/labels via `/discovery`, leaking internal topology information.
- Pull `/plugins/:name/metrics` data that may include internal operational metrics not intended for public exposure.

### Likelihood Explanation
High. The routes are mounted on the base `api` group with no authentication gate, so any network-reachable client to the node's web server can hit these endpoints directly — no credentials, tokens, or session required.

### Recommendation
Wrap `loopRoutes` registration with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` (consistent with how `metricRoutes` and `debugRoutes` are protected), or move these routes under the existing `authv2` group, ideally gated by `auth.RequiresAdminRole` given their diagnostic/resource-impact nature.

### Proof of Concept
Against a running chainlink node with LOOP plugins enabled, from an unauthenticated client (no cookies/API keys):
```
curl http://<node>:<port>/discovery
curl http://<node>:<port>/plugins/<pluginName>/metrics
curl "http://<node>:<port>/plugins/<pluginName>/debug/pprof/profile?seconds=60"
```
All three succeed without any `401 Unauthorized` response, since the route group lacks `auth.Authenticate` middleware.

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
