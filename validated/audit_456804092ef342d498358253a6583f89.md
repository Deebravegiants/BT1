Audit Report

## Title
Unauthorized Disclosure of External Initiator `outgoingToken` Secret to Any Authenticated User (Including View-Only Role) - (File: `core/web/external_initiators_controller.go`)

## Summary
`GET /v2/external_initiators` is registered in the router without any `Requires*Role` middleware, while the sibling `Create` and `Destroy` routes on the same resource are explicitly wrapped with `auth.RequiresEditRole`. The `Index` handler serializes every external initiator's `OutgoingToken` — a secret credential used by the node to authenticate outbound calls to the initiator — into the JSON:API response, exposing it to any authenticated user regardless of role.

## Finding Description
The route table shows the asymmetry directly: `authv2.GET("/external_initiators", paginatedRequest(eia.Index))` has no role wrapper, whereas `POST` and `DELETE` on the same path are wrapped in `auth.RequiresEditRole` [1](#0-0) . The `Index` handler fetches all external initiators from the ORM and maps each into an `ExternalInitiatorResource` without any redaction [2](#0-1) . The presenter unconditionally includes `OutgoingToken` in its JSON output for both the struct definition and constructor [3](#0-2) . This is a genuine secret: `OutgoingToken` is generated via `utils.NewSecret(utils.DefaultSecretSize)` at creation time and used by the node to authenticate itself when calling out to the initiator's URL, as seen in `bridges.NewExternalInitiator`. No other middleware, redaction, or validation intercepts this path — the `authv2` group only requires authentication (session or API token), not any specific role, and `Index` performs no additional role check itself, unlike `Create`/`Destroy` on the same controller.

## Impact Explanation
Any authenticated node user — including one with only the `view` role, typically provisioned for read-only dashboards/monitoring — can enumerate all configured external initiators and obtain their `outgoingToken` values via a simple GET request. This is a secret-disclosure / broken access control issue (CWE-284/CWE-200): a low-privileged user gains a credential that lets them impersonate the node toward the external initiator service, which is an unintended privilege escalation relative to the `view` role's intended read-only, non-sensitive scope. This maps to the in-scope Chainlink impact category of node API authentication/role bypass and key/secret exfiltration.

## Likelihood Explanation
High. No special conditions are required beyond having any valid authenticated session or API token for the node — the endpoint is reachable directly with a simple `GET /v2/external_initiators` and is documented as reachable at `viewOnlyAllowed: true` in the auth test table.

## Recommendation
Gate `GET /v2/external_initiators` with `auth.RequiresEditRole` to match `Create`/`Destroy`, or, if broader read access to the initiator list is desired, remove `OutgoingToken` (and any other secret fields) from `ExternalInitiatorResource` used by `Index`, following the pattern already used by `BridgeTypesController`, which withholds `IncomingToken` from `Index`/`Show` and only returns it once at `Create`.

## Proof of Concept
1. Provision or use an existing Chainlink node API user with role `view`.
2. Authenticate as that user (session cookie or API token).
3. Issue `GET /v2/external_initiators`.
4. Observe the JSON:API response includes `outgoingToken` for every configured external initiator, confirmed by the unwrapped route registration [4](#0-3)  and the presenter's unconditional serialization of `OutgoingToken` [5](#0-4) .

```go
func (eic *ExternalInitiatorsController) Index(c *gin.Context, size, page, offset int) {
	ctx := c.Request.Context()
	externalInitiators, count, err := eic.App.BridgeORM().ExternalInitiators(ctx, offset, size)
	resources := make([]presenters.ExternalInitiatorResource, 0, len(externalInitiators))
	for _, initiator := range externalInitiators {
		resources = append(resources, presenters.NewExternalInitiatorResource(initiator))
	}

	paginatedResponse(c, "externalInitiators", size, page, resources, count, err)
}
```

```go
type ExternalInitiatorResource struct {
	JAID
	Name          string         `json:"name"`
	URL           *models.WebURL `json:"url"`
	AccessKey     string         `json:"accessKey"`
	OutgoingToken string         `json:"outgoingToken"`
	CreatedAt     time.Time      `json:"createdAt"`
	UpdatedAt     time.Time      `json:"updatedAt"`
}

func NewExternalInitiatorResource(ei bridges.ExternalInitiator) ExternalInitiatorResource {
	return ExternalInitiatorResource{
		JAID:          NewJAID(strconv.FormatInt(ei.ID, 10)),
		Name:          ei.Name,
		URL:           ei.URL,
		AccessKey:     ei.AccessKey,
		OutgoingToken: ei.OutgoingToken,
		CreatedAt:     ei.CreatedAt,
		UpdatedAt:     ei.UpdatedAt,
	}
}
```
