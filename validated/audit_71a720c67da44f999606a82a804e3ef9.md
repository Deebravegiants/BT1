### Title
Unauthenticated "magic" QR codes let anyone reset Wi‑Fi and mirror calibration - (File: `src/plans/qr_scan/operator.rs`, `src/plans/mod.rs`)

### Summary
The Orb's operator QR‑code parser recognizes special "magic action" codes (`magic_action:reset_wifi_credentials`, `magic_action:reset_mirror_calibration`) and the signup flow executes the corresponding privileged action — resetting the Wi‑Fi configuration or the mirror calibration — as soon as such a code is scanned, with no verification that the presenter is a legitimate/trusted operator. This mirrors the reported `setMinimumDistribution` issue: a function intended for trusted participants only is reachable by any unprivileged party because the required authorization check is missing (or, here, is completely bypassed for this code path).

### Finding Description
`qr_scan::operator::Data::try_parse` decodes a scanned code either into a `Normal(user::Data)` variant or into `MagicResetWifi` / `MagicResetMirror` when it matches the `magic_action:...` pattern:

<cite repo="Alyssadaypin/orb-core--004" path="src/plans/qr_scan/operator.rs" start="24="33" /> [1](#0-0) 

The `MasterPlan` first scans the operator QR‑code and immediately dispatches it to `handle_magic_operator_qr_code`, *before* any backend identity check happens: [2](#0-1) 

Only the `Normal(qr_code)` branch is forwarded to `verify_operator_qr_code`, which performs the actual backend validation of the operator's identity via `backend::operator_status::request`: [3](#0-2) 

For the two `Magic*` variants, the plan never calls `verify_operator_qr_code` at all — it directly invokes `reset_mirror_calibration` or `reset_wifi_and_ensure_network` and returns `Ok(None)`, which simply causes the outer loop to prompt for another operator QR‑code scan: [4](#0-3) [5](#0-4) 

`network::reset()` wipes and reloads the persisted `wpa_supplicant` configuration (disconnecting the Orb from its configured Wi‑Fi network) via the privileged `wpa-supplicant-interface` helper: [6](#0-5) 

There is no comment, feature flag, or code path that requires the presenter of the magic QR code to be an authenticated/trusted operator — the regex match on the scanned text is the only "authorization" check, exactly analogous to `MultiDistributor.setMinimumDistribution` lacking an owner/whitelist check before mutating protected state.

### Impact Explanation
Any person who can show a QR code to the Orb's camera during the idle/operator-scanning phase (i.e., an unprivileged bystander, not necessarily the enrolled operator) can:
- Force a Wi‑Fi reset, disconnecting the device from its network and requiring re‑provisioning via a new Wi‑Fi QR code — a denial-of-service against the signup service that can be repeated indefinitely.
- Force a mirror recalibration mid-operation, degrading or disrupting biometric capture for legitimate signups.

This is a concrete availability/DoS impact reachable with no privileges, matching the "trusted participants only" violation described in the reference report, translated to the Orb's operator QR-code trust boundary.

### Likelihood Explanation
High. The magic QR codes are static, publicly-guessable strings (`magic_action:reset_wifi_credentials`, `magic_action:reset_mirror_calibration`); anyone with a printed/displayed QR code encoding this text can trigger the action during the routine operator-QR scan step of every signup attempt, with no rate limiting, and no interaction with the backend required.

### Recommendation
Require backend/operator authentication before executing `MagicResetWifi`/`MagicResetMirror` (e.g., only accept magic actions embedded within an already-validated operator QR-code, or require a signed/backend-issued magic token), analogous to protecting `setMinimumDistribution` behind an owner/whitelist check. At minimum, gate these actions behind the same `verify_operator_qr_code` backend validation used for normal operator codes, and add unit/integration tests asserting that unauthenticated magic codes are rejected.

### Proof of Concept
1. Encode the string `magic_action:reset_wifi_credentials` (or `magic_action:reset_mirror_calibration`) into a QR code.
2. Present it to the Orb's camera during the "Operator QR-code scanning" phase (no login/operator credential entry is otherwise required to reach this phase).
3. Observe `handle_magic_operator_qr_code` matches `Data::MagicResetWifi`/`Data::MagicResetMirror` and immediately calls `reset_wifi_and_ensure_network`/`reset_mirror_calibration` (`src/plans/mod.rs:988-1007`) without ever calling `verify_operator_qr_code` — the Wi‑Fi connection is dropped / mirror calibration is reset, with no operator authentication involved.

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

    /// Checks if `qr_code` is a valid operator QR-code through the backend.
    #[allow(clippy::cast_possible_truncation)]
    async fn verify_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: &qr_scan::user::Data,
        qr_capture_start: Instant,
    ) -> Result<Option<(u64, backend::operator_status::LocationData)>> {
        if qr_code.signup_extension() || self.operator_qr_code_override.is_some() {
            return Ok(Some((0, backend::operator_status::LocationData {
                team_operating_country: "DEV".to_string(),
                session_coordinates: Coordinates { latitude: 0.0f64, longitude: 0.0f64 },
                stationary_location_coordinates: None,
            })));
        }
        let http_start = Instant::now();
        match backend::operator_status::request(qr_code).await {
            Ok(backend::operator_status::Status { valid: true, location_data, reason: _ }) => {
                let location_data = location_data
                    .expect("to always have a result from the backend if valid == true");
                orb.ui.qr_scan_success(QrScanSchema::Operator);
                dd_incr!("main.count.global.distr_code_validated");
                tracing::info!("Operator QR-code validated: {qr_code:?}");
                dd_timing!("main.time.signup.distr_qr_code_capture", qr_capture_start);
                return Ok(Some((http_start.elapsed().as_millis() as u64, location_data)));
            }
            Ok(backend::operator_status::Status { valid: false, .. }) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
                dd_incr!("main.count.signup.result.failure.distr_qr_code", "type:invalid_qr");
            }
            Err(_) => {
                orb.ui.qr_scan_fail(QrScanSchema::Operator);
            }
        }
        Ok(None)
    }

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
