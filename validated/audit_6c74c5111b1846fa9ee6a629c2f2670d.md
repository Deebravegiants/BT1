The Zest v2 codebase is a Clarity/Stacks lending protocol without any `LendingLedger`, `GaugeController`, or `VotingEscrow` contracts — there is no gauge-based reward/emissions system with a block-based time estimation mechanism analogous to the report. The protocol's interest accrual and timestamp logic uses `stacks-block-time`, a native Clarity 4 keyword providing the exact, consensus-verified block timestamp directly [1](#0-0) , rather than approximating time from block numbers as described in the report's "parallel time system" bug class. This is explicitly the opposite design choice from the vulnerable pattern (block-based estimation of time), and vault interest accrual (`next-index`, `next-liquidity-index`) computes `time-delta` directly from `stacks-block-time` minus `last-update`, both of which are precise timestamps rather than estimated ones [2](#0-1) [3](#0-2) . There is no reward-per-block gauge/voting-escrow subsystem in scope to which this bug class could map.

## Timestamp for Current Block: `stacks-block-time`

`stacks-block-time` is a new Clarity keyword that returns the timestamp of the
current block in seconds since the Unix epoch. This is the same timestamp that
is in the block header, which is verified by the signers to be (see
https://github.com/stacks-network/stacks-core/blob/fe868ea6a1bf993793f1e09c3d397b5dde49b93d/stackslib/src/net/api/postblock_proposal.rs#L494-L512):

- Greater than the timestamp of its parent block
- At most 15 seconds into the future

This same timestamp can also be retrieved for previous blocks using
`(get-stacks-block-info? time height)`, which exists since Clarity 3, but cannot
be used for the current block.

Note that `stacks-block-time` will properly account for the context of an
`at-block` expression. If the `at-block` sets the context to a block that is
from before Clarity 4 has activated, attempting to use `stacks-block-time` in
that context will result in a runtime error.

(define-private (next-index)
  (let ((states (var-get pause-states))
        (idx (var-get index)))
    (if (get accrue states)
        idx
