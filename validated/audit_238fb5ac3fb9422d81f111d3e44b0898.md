Audit Report

## Title
Legacy gateway user messages (`api.Message.Sign`) lack a deadline/expiry field, allowing indefinite signature replay - (File: core/services/gateway/api/message.go)

## Summary
The legacy signed-message envelope `api.Message` signs only `MessageID`, `Method`, `DonID`, `Receiver`, and `Payload` via `GetRawMessageBody`, with no timestamp/expiry field bound into the signature, and `Message.Validate()` (invoked by `gateway.ProcessRequest` for every legacy request) performs only format/signature checks with no freshness enforcement. This is confirmed by direct inspection of `core/services/gateway/api/message.go` and `core/services/gateway/gateway.go`. Freshness enforcement is left to individual downstream handlers, and at least one consumer of these validated messages, `triggerConnectorHandler.HandleGatewayMessage` in `core/capabilities/webapi/trigger/trigger.go`, performs no timestamp or freshness check whatsoever before acting on the message.

## Finding Description
`Message.Sign` computes a signature over `GetRawMessageBody`, which concatenates only `MessageID`, `Method`, `DonID`, `Receiver`, and `Payload`. [1](#0-0)  `Message.Validate()`, called from `gateway.ProcessRequest` for every legacy (DON-ID-addressed) request, checks only field lengths/null-byte suffixes and recovers the signer — no timestamp or expiry check exists. [2](#0-1) [3](#0-2) 

Downstream, `hc.ValidatedMessageFromReq` (used by both `OutgoingConnectorHandler.HandleGatewayMessage` and `triggerConnectorHandler.HandleGatewayMessage`) performs the same signature-only validation. Critically, `triggerConnectorHandler.HandleGatewayMessage` proceeds directly to `processTrigger`, which dispatches the trigger to registered workflows based only on sender allowlisting, topic matching, and a per-sender rate limiter — there is no timestamp check and no deduplication of `MessageID`/`TriggerEventId` visible in this path. [4](#0-3) [5](#0-4) 

By contrast, the WebAPI *target* handler (`core/services/gateway/handlers/capabilities/handler.go`) does enforce `MaxAllowedMessageAgeSec` against an application-defined `payload.Timestamp` field, and the gateway's `common.RequestCache` deduplicates in-flight requests by `(sender, MessageID)` while the request is outstanding. [6](#0-5)  These are opt-in, handler-specific and short-lived (cache entries are removed on completion/timeout, restoring replayability afterward for the same `MessageID`), not a property of `api.Message` itself. Newer JSON-RPC-based flows (node/gateway handshake `AuthHeaderElems.Timestamp`, and Vault's `AllowListBasedAuth`/`RequestReplayGuard` with `ExpiryTimestamp` and persistent digest tracking) demonstrate the codebase already recognizes and implements the deadline+replay-guard pattern elsewhere, confirming that the legacy `api.Message` primitive is inconsistent with the project's own established security pattern for signed requests.

## Impact Explanation
A captured, validly-signed legacy `api.Message` can be replayed indefinitely against any handler that does not itself implement freshness/dedup logic. The concrete, demonstrated case is `triggerConnectorHandler.HandleGatewayMessage`: a replayed trigger message would re-invoke `processTrigger`, re-emitting a `TriggerEvent` to any workflow subscribed to the matching topic, from the same sender. Since `TriggerEventID` is derived from `body.Sender + payload.TriggerEventId` (both static/replayable values) rather than any freshness-bound nonce, an attacker or compromised relay hop that has previously observed one valid signed trigger message could resubmit it to cause a duplicate workflow execution/trigger firing without needing the original signer to re-sign anything. This maps to the "unauthorized job/workflow run" impact category. The impact is bounded by the fact that this requires capturing a legitimately-signed message in transit or via a compromised intermediate hop (gateway, transport, or a malicious/compromised node/DON member relaying it), which is a meaningfully different and narrower precondition than a fully unprivileged network attacker being able to forge the message from nothing.

## Likelihood Explanation
Medium-low. Exploitation is not achievable by a purely unprivileged remote attacker with no prior access — it requires having captured or been relayed a validly-signed message (e.g., via a compromised/malicious gateway node, a logging leak, or MITM on a link that isn't independently protected by transport security). The websocket handshake between node and gateway is itself protected by a separate, correctly-implemented timestamp+challenge mechanism (`AuthHeaderElems.Timestamp` with tolerance), so an attacker cannot simply open a new connection and inject arbitrary `api.Message`s without first establishing a valid, authenticated connector session or intercepting traffic on an already-authenticated one. The WebAPI target handler already mitigates the equivalent risk for its own payloads via `MaxAllowedMessageAgeSec`, narrowing exposure primarily to the trigger and outgoing-connector paths that lack any handler-level freshness check.

## Recommendation
Add a `Timestamp`/`Deadline` field to `MessageBody`, include it in the signed data in `GetRawMessageBody`, and enforce a maximum message age centrally in `Message.Validate()` (used by `gateway.ProcessRequest` for all legacy requests) rather than relying on each handler (target, trigger, outgoing-connector) to separately reimplement freshness/dedup logic. This mirrors the pattern already used for the node-gateway handshake (`AuthHeaderElems.Timestamp` + tolerance) and Vault's `ExpiryTimestamp`/`RequestReplayGuard`. Additionally, consider persistent (not just in-flight) `MessageID`/`TriggerEventId` deduplication for trigger dispatch, since `common.RequestCache`'s dedup window closes once a request completes or times out.

## Proof of Concept
1. A legitimate node/client signs an `api.Message` with `Method: web_api_trigger` via `Message.Sign`/`SignKS`, and it is relayed by the gateway to `triggerConnectorHandler.HandleGatewayMessage` on the subscribing node. [7](#0-6) 
2. An attacker who has captured the raw signed JSON-RPC request bytes (e.g., via a compromised relay hop or logging) resubmits the identical bytes to the gateway/connector at a later time.
3. `hc.ValidatedMessageFromReq` recomputes the signer from the unchanged raw body and succeeds regardless of elapsed time, since `GetRawMessageBody` contains no expiry field. [8](#0-7) 
4. `processTrigger` re-emits the `TriggerEvent` for any workflow matching the topic, since there is no timestamp check and no persistent dedup on `TriggerEventID`, resulting in a duplicate trigger/workflow execution. A Go unit test extending `trigger_test.go` that calls `HandleGatewayMessage` twice with the identical signed request and asserts two `TriggerResponse` events are emitted would demonstrate this concretely.

func (h *triggerConnectorHandler) processTrigger(ctx context.Context, gatewayID string, body *api.MessageBody, sender ethCommon.Address, payload webapicap.TriggerRequestPayload) error {
	// Pass on the payload with the expectation that it's in an acceptable format for the executor
	wrappedPayload, err := values.WrapMap(payload)
	if err != nil {
		return fmt.Errorf("error wrapping payload %w", err)
	}
	topics := payload.Topics

	// empty topics is error for V1
	if len(topics) == 0 {
		return errors.New("empty Workflow Topics")
	}

	h.mu.Lock()
	triggers := slices.Collect(maps.Values(h.registeredWorkflows))
	h.mu.Unlock()

	// workflows that have matched topics
	matchedWorkflows := 0
	// workflows that have matched topic and passed all checks
	fullyMatchedWorkflows := 0
	for _, trigger := range triggers {
		for _, topic := range topics {
			if trigger.allowedTopics[topic] {
				matchedWorkflows++
				if !trigger.allowedSenders[sender.String()] {
					err = fmt.Errorf("unauthorized Sender %s, messageID %s", sender.String(), body.MessageID)
					h.lggr.Debugw(err.Error())
					continue
				}
				if !trigger.rateLimiter.Allow(body.Sender) {
					err = fmt.Errorf("request rate-limited for sender %s, messageID %s", sender.String(), body.MessageID)
					continue
				}
				fullyMatchedWorkflows++
				TriggerEventID := body.Sender + payload.TriggerEventId

				// Emit trigger execution started event
				workflowExecutionID, genErr := events.GenerateExecutionID(trigger.workflowID, TriggerEventID)
				if genErr != nil {
					h.lggr.Errorw("failed to generate execution ID", "err", genErr)
					workflowExecutionID = ""
				}
				emitErr := events.EmitTriggerExecutionStarted(ctx, map[string]string{}, TriggerEventID, workflowExecutionID)
				if emitErr != nil {
					h.lggr.Errorw("failed to emit trigger execution started event", "err", emitErr)
				}

				tr := capabilities.TriggerResponse{
					Event: capabilities.TriggerEvent{
						TriggerType: TriggerType,
						ID:          TriggerEventID,
						Outputs:     wrappedPayload,
					},
				}
				trigger.chWriteMu.Lock()
				if trigger.ch == nil {
					trigger.chWriteMu.Unlock()
					return nil
				}
				select {
				case <-ctx.Done():
					trigger.chWriteMu.Unlock()
					return nil
				case trigger.ch <- tr:
					trigger.chWriteMu.Unlock()
					// Sending n topics that match a workflow with n allowedTopics, can only be triggered once.
					break
				}
			}
		}
	}
	if matchedWorkflows == 0 {
		return errors.New("no Matching Workflow Topics")
	}

	if fullyMatchedWorkflows > 0 {
		return nil
	}
	return err
}

func (h *triggerConnectorHandler) HandleGatewayMessage(ctx context.Context, gatewayID string, req *jsonrpc.Request[json.RawMessage]) error {
	msg, err := hc.ValidatedMessageFromReq(req)
	if err != nil {
		h.lggr.Errorw("error validating message from request", "err", err, "request", req)
		return nil
	}
	body := &msg.Body
	sender := ethCommon.HexToAddress(body.Sender)
	var payload webapicap.TriggerRequestPayload
	err = json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw("error decoding payload", "err", err)
		err = h.sendResponse(ctx, gatewayID, body, ghcapabilities.TriggerResponsePayload{Status: "ERROR", ErrorMessage: fmt.Errorf("error %s decoding payload", err.Error()).Error()})
		if err != nil {
			h.lggr.Errorw("error sending response", "err", err)
		}
		return nil
	}

	switch body.Method {
	case ghcapabilities.MethodWebAPITrigger:
		resp := h.processTrigger(ctx, gatewayID, body, sender, payload)
		var response ghcapabilities.TriggerResponsePayload
		if resp == nil {
			response = ghcapabilities.TriggerResponsePayload{Status: "ACCEPTED"}
		} else {
			response = ghcapabilities.TriggerResponsePayload{Status: "ERROR", ErrorMessage: resp.Error()}
			h.lggr.Errorw("Error processing trigger", "gatewayID", gatewayID, "body", body, "response", resp)
		}
		err = h.sendResponse(ctx, gatewayID, body, response)
		if err != nil {
			h.lggr.Errorw("Error sending response", "body", body, "response", response, "err", err)
		}
		return nil

	default:
		h.lggr.Errorw("unsupported method", "id", gatewayID, "method", body.Method)
		err = h.sendResponse(ctx, gatewayID, body, ghcapabilities.TriggerResponsePayload{Status: "ERROR", ErrorMessage: fmt.Errorf("unsupported method %s", body.Method).Error()})
		if err != nil {
			h.lggr.Errorw("error sending response", "err", err)
		}
	}
	return nil
}

func (c *requestCache[T]) NewRequest(lggr logger.Logger, request *api.Message, callback handlers.Callback, responseData *T) error {
	if request == nil {
		return errors.New("request is nil")
	}
	if responseData == nil {
		return errors.New("responseData is nil")
	}
	key := globalID{request.Body.Sender, request.Body.MessageID}
	c.mu.Lock()
	defer c.mu.Unlock()
	_, ok := c.cache[key]
	if ok {
		return errors.New("request already exists")
	}
	if len(c.cache) >= int(c.maxCacheSize) {
		return errors.New("request cache is full")
	}
	codec := api.JSONRPCCodec{}
	timer := time.AfterFunc(c.timeout, func() {
		err := c.deleteAndSendOnce(key, handlers.UserCallbackPayload{RawResponse: codec.EncodeLegacyResponse(request), ErrorCode: api.RequestTimeoutError})
		if err != nil {
			lggr.Errorw("failed to send timeout response", "error", err)
		}
	})
	c.cache[key] = &pendingRequest[T]{Callback: callback, responseData: responseData, timeoutTimer: timer}
	return nil
}
