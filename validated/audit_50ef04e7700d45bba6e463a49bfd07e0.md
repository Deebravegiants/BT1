No vulnerability found for this question.

**Rationale:**

The `as_script_cache` delegate does key the script cache by `[u8; 32]` [1](#0-0) , but that key is not an attacker-chosen value — it is computed by the VM itself as `sha3_256(serialized_script)` over the exact bytes of the script being loaded, both when caching the deserialized script and when caching the verified script [2](#0-1) [3](#0-2) . The same hashing scheme is used by the lazy loader path [4](#0-3) .

For the described attack to work, an attacker would need to submit two distinct scripts whose bytes produce a colliding SHA3-256 digest. This is not an implementation flaw in `ScriptCache`, `UnsyncScriptCache`, or the `AptosCodeStorageAdapter` delegate — the cache correctly serves whatever `Verified`/`Deserialized` entry is stored under a key derived from the actual bytes hashed [5](#0-4) . Finding a SHA3-256 collision is a cryptographic break, not a custody-boundary logic bug reachable via unprivileged transaction input, and no such collision is known to be computationally feasible. The move-VM spec explicitly documents that the hash is used for script identity precisely because two different scripts cannot practically produce the same hash [6](#0-5) .

Additionally, `AptosCodeStorageAdapter`'s script cache (`UnsyncCodeStorage`) is freshly constructed per adapter/state-view instance [7](#0-6) , and in the block-executor's per-transaction `LatestView`, script caching is scoped per version/thread-safe map [8](#0-7) , so there's no cross-transaction key reuse under normal (non-colliding) operation. Since the premise requires breaking a cryptographic hash function rather than exploiting a custody-boundary logic error in unprivileged input handling, this does not meet the decision standard for a valid finding.

impl<K, D, V> ScriptCache for UnsyncScriptCache<K, D, V>
where
    K: Eq + Hash + Clone,
    V: Deref<Target = Arc<D>>,
{
    type Deserialized = D;
    type Key = K;
    type Verified = V;

    fn insert_deserialized_script(
        &self,
        key: Self::Key,
        deserialized_script: Self::Deserialized,
    ) -> Arc<Self::Deserialized> {
        use hashbrown::hash_map::Entry::*;

        match self.script_cache.borrow_mut().entry(key) {
            Occupied(entry) => entry.get().deserialized().clone(),
            Vacant(entry) => entry
                .insert(Code::from_deserialized(deserialized_script))
                .deserialized()
                .clone(),
        }
    }

    fn insert_verified_script(
        &self,
        key: Self::Key,
        verified_script: Self::Verified,
    ) -> Arc<Self::Verified> {
        use hashbrown::hash_map::Entry::*;

        match self.script_cache.borrow_mut().entry(key) {
            Occupied(mut entry) => {
                if !entry.get().is_verified() {
                    let new_script = Code::from_verified(verified_script);
                    let verified_script = new_script.verified().clone();
                    entry.insert(new_script);
                    verified_script
                } else {
                    entry.get().verified().clone()
                }
            },
            Vacant(entry) => entry
                .insert(Code::from_verified(verified_script))
                .verified()
                .clone(),
        }
    }

    fn get_script(&self, key: &Self::Key) -> Option<Code<Self::Deserialized, Self::Verified>> {
        self.script_cache.borrow().get(key).cloned()
    }

    fn num_scripts(&self) -> usize {
        self.script_cache.borrow().len()
    }
}
