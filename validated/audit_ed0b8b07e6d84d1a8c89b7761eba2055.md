### Title
Substrate header digest decoder desyncs on `Other` digest items, causing type-confused misparsing of consensus digests used to derive BEEFY-relayed state commitments - ([File: evm/src/consensus/Codec.sol])

### Summary
`Codec.DecodeHeader` in the EVM BEEFY consensus client decodes a Substrate block header's `Digest` list by reading a 1-byte `kind` discriminant and then only advancing the cursor past that item's variable-length payload for the `Consensus`, `Seal`, and `PreRuntime` variants. The `Other` variant (`kind == 0`), which in real Substrate `DigestItem` encoding also carries a compact-length-prefixed `Vec<u8>` payload, is handled by only flipping a boolean flag without consuming its payload bytes. This desynchronizes the byte cursor for every digest item that follows, causing subsequent bytes to be walked and type-confused as if they were a fresh `kind` byte, engine id, and payload — mirroring the ChakraCore CVE-2017-11862 pattern where a node-walking routine failed to handle a destructuring node variant, leaving the walker in an inconsistent state that led to type confusion of subsequent data.

### Finding Description
`Codec.DecodeHeader` [1](#0-0)  loops over each digest item, reading a `kind` byte and then dispatching:

```
if (kind == DIGEST_ITEM_OTHER) {
    digest.isOther = true;
} else if (kind == DIGEST_ITEM_CONSENSUS) {
    digest.isConsensus = true;
    digest.consensus = decodeDigestItem(slice);
} else if (kind == DIGEST_ITEM_SEAL) {
    ...
} else if (kind == DIGEST_ITEM_PRERUNTIME) {
    ...
} else if (kind == DIGEST_ITEM_RUNTIME_ENVIRONMENT_UPDATED) {
    digest.isRuntimeEnvironmentUpdated = true;
}
``` [2](#0-1) 

Only `Consensus`, `Seal`, and `PreRuntime` call `decodeDigestItem`, which reads the 4-byte engine id, a SCALE-compact length, and that many payload bytes, correctly advancing the slice offset [3](#0-2) . `RuntimeEnvironmentUpdated` is a genuine unit variant in Substrate with no payload, so skipping consumption there is correct. However `Other` is *not* a unit variant upstream — it is `DigestItem::Other(Vec<u8>)`, i.e. SCALE-encoded as a compact length followed by that many bytes. `DecodeHeader` never reads or skips this payload for the `Other` branch, so the cursor is left pointing at the compact-length byte(s) of the `Other` item's own payload.

On the next loop iteration, `Bytes.readByte(slice)` reads that length byte (or the first payload byte) as if it were the *next* digest's `kind` discriminant. Depending on its numeric value, this single stray byte can be re-interpreted as `Consensus`/`Seal`/`PreRuntime`/`RuntimeEnvironmentUpdated`, causing `decodeDigestItem` to walk arbitrary payload bytes as a 4-byte engine id + compact length + data blob that has no relation to any real digest item — a textbook type confusion at the decode boundary, structurally identical to the ChakraCore bug where a node type (destructuring) was not walked, corrupting the interpretation of subsequent AST/byte structures.

This decoder is reached from `EcdsaBeefy.verifyParachainHeaderProof`, which calls `Codec.DecodeHeader(para.header)` on parachain header bytes supplied inside the untrusted `proof` argument passed into `EcdsaBeefy.verify(previousState, proof)` [4](#0-3) . The decoded `header` is then converted via `header.stateCommitment()` into the `StateCommitment` recorded as an `IntermediateState` for that state machine height — the on-chain source of truth later used to verify request/response membership and non-membership storage proofs for that height.

### Impact Explanation
If a finalized parachain header (or any header a relayer submits as part of a consensus/state update, this being an unprivileged, permissionless dispatch path) contains an `Other` digest item, the decoder desyncs and every digest item after it — including the `Consensus` digest that is expected to carry the ISMP state root / timestamp — is misparsed. The resulting `StateCommitment` recorded on-chain for that height can then be built from bytes that were never intended to be a state root, corrupting the trusted state commitment used for all subsequent membership/non-membership proof verification at that height. This satisfies the "unsound state commitment" / "forged message delivery" bar: a corrupted commitment can make legitimate proofs fail (denial of message delivery) or, depending on which bytes end up type-confused into the root field, could let a relayer influence which value is accepted as the finalized state root for that height.

### Likelihood Explanation
Exploitability depends on whether an `Other` digest item is present in a header before the digest the client relies on. This is not something the submitting relayer can freely fabricate (the header content itself must match a hash committed inside the BEEFY-signed MMR leaf), so the bug is not directly attacker-forgeable on demand — but it is a real, silent decode-correctness bug in the security-critical proof-verification path (`Codec.DecodeHeader`), triggered any time the underlying chain's runtime emits an `Other` digest item (a standard, legal `DigestItem` variant that pallets/runtimes may legitimately emit), producing a corrupted state commitment without reverting.

### Recommendation
In `Codec.DecodeHeader`, treat `DIGEST_ITEM_OTHER` the same as `Consensus`/`Seal`/`PreRuntime`: read and discard its compact-length-prefixed `Vec<u8>` payload (or store it) so the cursor stays synchronized, e.g. call a length-only variant of `decodeDigestItem` for it. Additionally, add an explicit `else revert(...)` branch for any unrecognized `kind` byte instead of silently falling through with `digest` left as all-`false`/unconsumed, so unknown digest kinds cause a defined failure rather than silent cursor desync.

### Proof of Concept
1. Construct a SCALE-encoded Substrate header whose `Digest` list is `[DigestItem::Other(vec![4,0,0,0,0])  /* len byte 5 encoded as compact = 0x14, i.e. one byte with value 4<<2|... */, DigestItem::Consensus(ENGINE_ID, real_ismp_root_bytes)]`.
2. Encode: `kind=0x00` (Other) followed by a compact length whose raw byte value equals `4` (`DIGEST_ITEM_CONSENSUS`) followed by 4 payload bytes.
3. Feed this header through `Codec.DecodeHeader`: the `Other` branch consumes only the `kind=0x00` byte; the next `readByte` reads the compact-length byte (value `4`), which the loop interprets as `kind == DIGEST_ITEM_CONSENSUS`, then `decodeDigestItem` reads the following 4 bytes as an engine id and misreads the real `Consensus` digest's own encoding as payload data.
4. Observe that `header.stateCommitment()` no longer extracts the real ISMP state root from the true `Consensus` digest, demonstrating the type-confused misparse without any revert.

    // @dev Deserializes a substrate header
    function DecodeHeader(bytes memory encoded) internal pure returns (Header memory) {
        ByteSlice memory slice = ByteSlice(encoded, 0);
        bytes32 parentHash = Bytes.toBytes32(Bytes.read(slice, 32));
        uint256 blockNumber = ScaleCodec.decodeUintCompact(slice);
        bytes32 stateRoot = Bytes.toBytes32(Bytes.read(slice, 32));
        bytes32 extrinsicsRoot = Bytes.toBytes32(Bytes.read(slice, 32));

        uint256 length = ScaleCodec.decodeUintCompact(slice);
        Digest[] memory digests = new Digest[](length);

        for (uint256 i = 0; i < length; i++) {
            uint8 kind = Bytes.readByte(slice);
            Digest memory digest;
            if (kind == DIGEST_ITEM_OTHER) {
                digest.isOther = true;
            } else if (kind == DIGEST_ITEM_CONSENSUS) {
                digest.isConsensus = true;
                digest.consensus = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_SEAL) {
                digest.isSeal = true;
                digest.seal = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_PRERUNTIME) {
                digest.isPreRuntime = true;
                digest.preruntime = decodeDigestItem(slice);
            } else if (kind == DIGEST_ITEM_RUNTIME_ENVIRONMENT_UPDATED) {
                digest.isRuntimeEnvironmentUpdated = true;
            }
            digests[i] = digest;
        }

        return Header(parentHash, blockNumber, stateRoot, extrinsicsRoot, digests);
    }

    /// @dev Decodes a SCALE-encoded digest item (4-byte consensus id + length-prefixed data).
    function decodeDigestItem(ByteSlice memory slice) internal pure returns (DigestItem memory) {
        bytes4 id = Bytes.toBytes4(read(slice, 4), 0);
        uint256 length = ScaleCodec.decodeUintCompact(slice);
        bytes memory data = Bytes.read(slice, length);
        return DigestItem(id, data);
    }
