### Title
Stale delegate grants are resurrected by returning a position NFT to the original owner - (`contracts/controller/src/storage/account.rs`)

### Summary
`ControllerKey::Delegates(account_id)` stores a single `DelegateGrant` stamped with the granting owner. Ownership changes only make the grant read as inactive; they do not delete or invalidate it. If the NFT later returns to the original owner, the old delegate becomes authorized again without that owner granting it anew. An active position manager can then borrow or withdraw through the account and direct proceeds to itself.

### Finding Description
Account authority is resolved dynamically from `PositionNft::owner_of(account_id)` rather than from an owner field stored in controller account metadata. [1](#0-0)  Delegate validity is likewise resolved dynamically by comparing the stored `DelegateGrant.granted_by` to the current NFT owner. [2](#0-1) 

The stored delegate entry is keyed only by `account_id`, with no ownership epoch, nonce, expiry, or generation. [3](#0-2)  A new owner's `add_delegate` overwrites the stale grant, and a new owner's `remove_delegate` deletes it, but an NFT transfer itself performs neither operation. [4](#0-3)  Consequently, a round trip `Alice -> attacker -> Alice` silently restores Alice's original delegate list.

Once restored, `is_owner_or_delegate` authorizes the stored delegate whenever it is still an active position manager. [5](#0-4)  `borrow` then permits the delegate to select an arbitrary external recipient with `to`, subject only to post-borrow solvency. [6](#0-5)  `withdraw` uses the same authorization check and also permits a delegate-selected recipient. [7](#0-6) 

### Impact Explanation
A restored delegate can draw the account's maximum solvent borrow to itself, leaving the returned owner with the debt and encumbered collateral. For a debt-free or sufficiently healthy account, the delegate can instead withdraw transferable collateral directly to itself within the post-withdrawal solvency check. This is theft of the victim's borrowing capacity or collateral by an authority that had lapsed and was never re-granted by the current ownership period.

### Likelihood Explanation
Exploitation requires a position whose former owner granted an active position manager, followed by an ownership change that does not overwrite or purge the stale controller grant. The account NFT can be acquired through a transfer, sale, marketplace interaction, or delegated NFT transfer, and the intermediate holder can send it back to the former owner without needing that recipient's authorization. If the previously delegated manager is attacker-controlled or attacker-influenced, it can immediately call `borrow` or `withdraw`; otherwise, the victim may unexpectedly restore authority to a manager it believed was revoked by the ownership change.

### Recommendation
Bind each delegate grant to the NFT ownership epoch rather than only to `(account_id, granted_by)`. Add a monotonically increasing per-token transfer generation in `PositionNft`, increment it on every successful transfer or burn, and store that generation in `DelegateGrant`. `get_delegates` should return a grant only when both `granted_by == owner` and the stored generation equals the NFT's current generation. Alternatively, expose an ownership-change callback or have the NFT maintain a controller-readable ownership nonce that is included in the delegate storage key, ensuring every ownership transition permanently invalidates prior grants even if the token returns to a former owner.

### Proof of Concept
1. Alice owns funded account `A`, represented by position NFT token ID `A`.
2. Alice authorizes active position manager `M` through `controller.add_delegate(Alice, A, M)`. This stores `DelegateGrant { granted_by: Alice, delegates: [M] }` under `ControllerKey::Delegates(A)`.
3. Alice transfers token `A` to attacker-controlled address `B`. During `B`'s ownership, `get_delegates(A, B)` returns empty because `granted_by` is still `Alice`, but the stale entry remains in storage.
4. `B` calls the position NFT's standard `transfer(B, Alice, A)`. `B` is the current owner, so no authorization from Alice is required for the incoming transfer.
5. The controller now resolves `Alice` as owner again. `get_delegates(A, Alice)` returns the pre-transfer `[M]` grant.
6. `M` calls:
   ```rust
   controller.borrow(
       M,
       A,
       vec![(debt_asset, maximum_solvency_preserving_amount)],
       Some(M),
   );
   ```
   The owner-or-delegate check passes because `M` is active and present in the resurrected grant. The pool pays `M`, while account `A`—again owned by Alice—retains the debt.
7. If `A` has sufficient debt-free collateral, `M` can alternatively call `withdraw(M, A, withdrawals, Some(M))` and receive the collateral payout directly.

/// Returns grants stamped by `owner`, or an empty list. Ownership changes
/// invalidate a previous owner's grants without deleting them.
pub(crate) fn get_delegates(env: &Env, account_id: u64, owner: &Address) -> Vec<Address> {
    get_user::<DelegateGrant>(env, &ControllerKey::Delegates(account_id))
        .filter(|grant| grant.granted_by == *owner)
        .map(|grant| grant.delegates)

/// Adds a delegate, enforcing `MAX_DELEGATES`; returns false for duplicates.
/// Overwrites stale grants with a list stamped by the current owner.
pub(crate) fn add_delegate(
    env: &Env,
    account_id: u64,
    owner: &Address,
    delegate: &Address,
) -> bool {
    let mut delegates = get_delegates(env, account_id, owner);
    if delegates.contains(delegate) {
        return false;
    }
    assert_with_error!(
        env,
        delegates.len() < MAX_DELEGATES,
        GenericError::RegistryCapReached
    );
    delegates.push_back(delegate.clone());
    set_delegates(env, account_id, owner, &delegates);
    true
}

/// Removes a live delegate and reports whether it changed the list.
/// Deletes stale grants but returns false, preventing those grants from
/// reactivating if the NFT returns to their original owner.
pub(crate) fn remove_delegate(
    env: &Env,
    account_id: u64,
    owner: &Address,
    delegate: &Address,
) -> bool {
    let key = ControllerKey::Delegates(account_id);
    let Some(grant) = get_user::<DelegateGrant>(env, &key) else {
        return false;
    };
    if grant.granted_by != *owner {
        env.storage().persistent().remove(&key);
        return false;
    }
    let mut delegates = grant.delegates;
    let Some(index) = delegates.first_index_of(delegate) else {
        return false;
    };
    delegates.remove(index);
    set_delegates(env, account_id, owner, &delegates);
    true
}

/// A delegate list stamped with the owner who granted it. The grant is live only while
/// `granted_by` owns the account's NFT: after an NFT transfer, `get_delegates` reads it as
/// empty for the new owner. The new owner's next `add_delegate` or `remove_delegate`
/// overwrites or deletes the stale entry. If the NFT returns to `granted_by` before such a
/// write, the original delegate list is live again.
#[contracttype]
#[derive(Clone, Debug, Eq, PartialEq)]
pub struct DelegateGrant {
    pub granted_by: Address,
    pub delegates: Vec<Address>,
}

/// Accepts the owner or a registered, active manager delegated by that owner.
pub(crate) fn is_owner_or_delegate(
    env: &Env,
    account_id: u64,
    caller: &Address,
    owner: &Address,
) -> bool {
    if caller == owner {
        return true;
    }
    let active_manager =
        storage::get_position_manager(env, caller).is_some_and(|config| config.is_active);
    active_manager && storage::get_delegates(env, account_id, owner).contains(caller)
}

/// Requires the owner or a registered, active manager delegated by that owner.
pub(crate) fn require_owner_or_delegate(
    env: &Env,
    account_id: u64,
    caller: &Address,
    owner: &Address,
) {
    if is_owner_or_delegate(env, account_id, caller, owner) {
        return;
    }
    panic_with_error!(env, GenericError::NotAuthorized);
}

/// Borrows to `to` or the authorized owner/delegate, then checks solvency.
/// Persists supply alongside debt when the check restamps supply LTVs.
pub(crate) fn process_borrow(
    env: &Env,
    caller: &Address,
    account_id: u64,
    borrows: &Vec<HubPayment>,
    to: Option<Address>,
) {
    validation::require_authorized_caller(env, caller);

    let mut account = storage::get_account(env, account_id);
    require_owner_or_delegate(env, account_id, caller, &account.owner);

    let recipient = to.unwrap_or_else(|| caller.clone());
    let mut cache = Context::new(env);
    require_external_recipient(env, &mut cache, &recipient);
    let aggregated = payments::aggregate_positive_payments(env, borrows);

    validate_position_entry_gates(
        env,
        &account,
        &aggregated,
        &mut cache,
        AccountPositionType::Borrow,
    );
    settle_borrow(env, &mut account, &recipient, &aggregated, &mut cache);

    let restamped = enforce_post_pool_solvency(env, &mut cache, &mut account);
    let sides = if restamped {
        PositionSides::Both
    } else {
        PositionSides::Debt
    };
    finalize_position_flow(env, account_id, &account, &mut cache, sides, false);
