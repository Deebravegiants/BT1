### Title
Malformed WiFi-credential QR payload leaks raw network password into cleartext debug logs - (File: src/network/mecard.rs / src/plans/qr_scan/wifi.rs)

### Summary
`Credentials::parse` in `src/network/mecard.rs` silently discards field-level parser errors for the `P:` (password) field inside its `parse_fields!` macro, leaving the raw, unconsumed password text in the `input` slice that later fails on `tag(";")`/`eof`. The resulting `nom::error::Error<&str>` carries that raw text verbatim, and `src/plans/qr_scan/wifi.rs` logs it unredacted via `tracing::debug!`, which is emitted by default because `DEFAULT_LOG_LEVEL` is `"debug"`.

### Finding Description
In `Credentials::parse` [1](#0-0) , each field parser (`AuthType::parse`, `parse_ssid`, `parse_password`, `parse_hidden`) is tried with `if let Ok((next_input, parsed)) = $parse(input)`. If `parse_password` fails (e.g. an unterminated quoted value causing `parse_string`'s closing `tag("\"")` to fail [2](#0-1) ), the `Err` is silently dropped and `input` is left un-advanced, still containing the raw password text (e.g. `P:"AbCdEfSensitiveToken;;`).

Since `ssid` was already successfully parsed in an earlier loop pass, the mandatory-SSID check at line 116 does not fire [3](#0-2) . Execution proceeds to `tag(";")(input)` [4](#0-3) , which fails against the un-consumed `P:"..."` tail, producing a `nom::Err::Error` whose `input` field is that raw unconsumed string.

This error bubbles up to `Credentials::try_parse` in `src/plans/qr_scan/wifi.rs`, which logs it directly: [5](#0-4) 

Unlike the well-formed path — where `Password`'s custom `Debug` impl redacts the value to `"***"` [6](#0-5)  and is safely printed by `plans/wifi/mod.rs`'s `tracing::info!` [7](#0-6)  — the malformed-password path never constructs a `Password` value at all, so the redaction never applies; the raw text travels only as a `&str` slice inside nom's error type, whose derived `Debug` prints it verbatim.

This debug log is not suppressed by default: `src/logger.rs` sets `DEFAULT_LOG_LEVEL = "debug"` [8](#0-7)  and the logger is initialized with `Logger::try_with_env_or_str(DEFAULT_LOG_LEVEL)` [9](#0-8) , writing to the daemon log format that is persisted (e.g., journald) [10](#0-9) .

### Impact Explanation
An attacker who presents a crafted WiFi-setup QR code to the orb's camera during network pairing (`Plan::ensure_network_connection` calling `qr_scan::Plan::new(...).run(orb)` [11](#0-10) ) can cause the exact raw, attacker/target-controlled "password" substring to be written into the orb's on-device debug/system logs in cleartext, bypassing the `Password` redaction mechanism entirely. If that payload legitimately encodes a real WiFi network credential (e.g., a pre-shared key belonging to a facility or another party), that secret ends up unredacted in persisted logs that can be pulled off the device for diagnostics — a network credential disclosure.

### Likelihood Explanation
Fully reachable by an unprivileged attacker: no operator access is required, just presenting a QR code to the camera during the WiFi-pairing UI flow. The malformed input (unterminated quote in the `P:` field, with SSID present) is trivial to construct and deterministically reproduces the leak every time.

### Recommendation
- In `parse_string`/`parse_password`, avoid leaving partially-consumed sensitive input in scope for outer error reporting; on failure, ensure the error type does not retain a raw slice through a sensitive field's position, or wrap field-specific parse failures in a redacting error type before propagation.
- In `src/plans/qr_scan/wifi.rs`, do not log the raw nom error's `input` field at any level; log only the error `code`/kind, or sanitize/redact any content resembling a `P:`/password field before logging.
- Consider not defaulting the logger to `"debug"` level for potentially sensitive parse-failure paths, or route such diagnostics through a redaction layer before they reach persisted logs.

fn parse_string(input: &str) -> IResult<&str, String> {
    const SPECIAL_CHARS: &[char] = &['\\', ';', ',', '"', ':'];
    let non_special = verify(anychar, |c| SPECIAL_CHARS.iter().all(|s| c != s));
    let special = pair(tag("\\"), verify(anychar, |c| SPECIAL_CHARS.iter().any(|s| c == s)));
    let unescaped = alt((non_special, map(special, |(_, c)| c)));
    let (input, quote) = opt(tag("\""))(input)?;
    let (input, string) = fold_many0(unescaped, String::new, |mut acc, item| {
        acc.push(item);
        acc
    })(input)?;
    if quote.is_some() {
        let (input, _) = tag("\"")(input)?;
        Ok((input, string))
    } else if string.len() % 2 == 0 && string.chars().all(|c| c.is_ascii_hexdigit()) {
        // The value is in hex string format.
        let string = string.as_bytes().chunks(2).fold(
            String::with_capacity(string.len() / 2),
            |mut acc, pair| {
                // The following sequence of unwraps can't fail because of the
                // condition above.
                let string = str::from_utf8(pair).unwrap();
                let octet = u8::from_str_radix(string, 16).unwrap();
                let chr = char::from_u32(octet.into()).unwrap();
                acc.push(chr);
                acc
            },
        );
        Ok((input, string))
    } else {
        Ok((input, string))
    }
}

fn format_newstyle_daemon(w: &mut dyn Write, record: &Record<'_>) -> Result<(), std::io::Error> {
    /// Removes newlines and carriages returns, replacing them spaces.
    fn sanitize_args(args: Arguments<'_>) -> String {
        let s = std::fmt::format(args);
        s.trim().replace(['\n', '\r'], " ")
    }
    let priority = match record.level() {
        Level::Error => b"<3>",
        Level::Warn => b"<4>",
        Level::Info => b"<5>",
        Level::Debug => b"<6>",
        Level::Trace => b"<7>",
    };
    w.write_all(priority)?;
    write!(w, "[{}:{}] ", record.file().unwrap_or("<unnamed>"), record.line().unwrap_or(0),)?;
    w.write_all(sanitize_args(*record.args()).as_bytes())?;
    w.write_all(b"\n")?;
    Ok(())
}
