Based on my review, there's a concrete analog of this bug class in the chainlink gateway's capabilities handler package.

### Title
Missing allowlist/authorization check on legacy Web API trigger ingress path in the Gateway capabilities handler - (`core/services/gateway/handlers/capabilities/handler.go`)

### Summary
The Gateway's legacy Web API capabilities handler exposes a `HandleLegacyUserMessage` ingress path (method `MethodWebAPITrigger`) that forwards inbound trigger requests to all DON member nodes, but explicitly does **not** enforce an allowlist check before doing so — the code has a literal `// TODO: apply allowlist and rate-limiting here` comment sitting right before the method dispatch. This mirrors the reported bug class: one ingress path in the system enforces authorization (the newer v2 HTTP trigger handler, which checks JWT signatures against per-workflow authorized keys), while a sibling/legacy ingress path for functionally equivalent trigger requests skips that check entirely and still queues the message as trusted.

### Finding Description
`HandleLegacyUserMessage` in [1](#0-0)  processes inbound "web API trigger" messages. It validates payload decoding, checks for a non-zero timestamp, and checks message staleness against `MaxAllowedMessageAgeSec`, but the allowlist/authorization gate is explicitly marked unimplemented: [2](#0-1) 

After that point, the message is transformed into a request and broadcast to every DON member as a trusted trigger: [3](#0-2) 

Contrast this with the sibling/successor ingress path for the same conceptual capability — the v2 HTTP trigger handler — which enforces per-workflow JWT-based key authorization (`h.authorizeRequest`) before dispatching to nodes: [4](#0-3) 

This is structurally the same class of flaw as the OpenClaw advisory: a secondary/legacy ingress channel into the same trusted-event pipeline omits the allowlist/authorization enforcement that the primary channel applies.

### Impact Explanation
Any unprivileged caller able to reach the Gateway's legacy `web-api-capabilities` handler (over the DON's user-facing endpoint) can have arbitrary trigger payloads accepted and fanned out to every node in the DON as a legitimate workflow trigger, without any per-workflow-owner or per-sender allowlist check. This could inject attacker-controlled trigger data into workflow executions that downstream nodes treat as authenticated, analogous to the Discord bot accepting reaction "events" from non-allowlisted guild members as trusted system events.

### Likelihood Explanation
Likelihood depends on whether the legacy `web-api-capabilities` handler (as opposed to the v2 HTTP trigger handler) is still wired up and reachable in current production Gateway job configurations. The code path is fully implemented and reachable via `HandleLegacyUserMessage` [5](#0-4) , gated only by staleness/timestamp checks, not by any allowlist. The `TODO` comment indicates this is a known, unresolved gap rather than an intentionally-scoped trust boundary.

### Recommendation
Implement the allowlist enforcement referenced by the `TODO` comment in `HandleLegacyUserMessage` — mirroring the authorization step (`authorizeRequest`/authorized-key check) already implemented in the v2 `httpTriggerHandler.HandleUserTriggerRequest` — before the handler saves the callback and broadcasts the message to DON members. If the legacy handler is deprecated/unused in production, it should be explicitly disabled or removed rather than left reachable with an authorization TODO.

### Proof of Concept
Not applicable in ask-only mode — no ability to execute against a live Gateway deployment. The finding is based on static code review of `HandleLegacyUserMessage` and comparison with `HandleUserTriggerRequest`'s authorization enforcement, as cited above.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JSONRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) { //nolint:gosec // G115: comparing unix timestamps, both fit within uint
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageID,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageID] = &savedCallback{id: msg.Body.MessageID, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

func (h *httpTriggerHandler) HandleUserTriggerRequest(ctx context.Context, req *jsonrpc.Request[json.RawMessage], callback handlers.Callback, requestStartTime time.Time) error {

	if err != nil {
		return err
	}

	workflowID, err := h.resolveWorkflowID(ctx, triggerReq, req.ID, callback)
	if err != nil {
		return err
	}

	key, err := h.authorizeRequest(ctx, workflowID, req, callback)
	if err != nil {
		return err
	}
