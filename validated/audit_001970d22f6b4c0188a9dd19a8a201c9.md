**Analysis:** `IsOnlyMutatingGCFields` in [1](#0-0)  stomps only the GC-related fields (owner references, finalizers, self-link, managed fields) onto a copy of the new object, then runs `equalities.DeepEqual(copied, old)` on the **entire object**, not just the metadata. If any other field differs between `obj` and `old` — including `Spec.SignerName` in a `ClusterTrustBundle` — the `DeepEqual` comparison will detect that mismatch and return `false`, since only the four GC-related fields were overwritten with the old values.

This is exactly validated by the existing table test `TestIsOnlyMutatingGCFields`, specifically the `"and other"` case, which changes both `OwnerReferences` and `Spec.RestartPolicy` simultaneously and expects `false`: [2](#0-1) . This is structurally identical to the attack scenario in the question (bundling an owner-reference change with a `Spec.SignerName`-relevant change) and it already asserts that `IsOnlyMutatingGCFields` returns `false` in that case.

In the consumer, `ctbattest`'s `Validate` only skips the attest check when `IsOnlyMutatingGCFields` returns `true`: [3](#0-2) . Since any bundled change to `Spec.SignerName` (or any other non-GC field) causes the function to return `false`, the attest authorization check via `certauthorization.IsAuthorizedForSignerName` will still execute and cannot be bypassed by an attacker mixing GC-field mutations with signer-relevant changes in the same update. There is no masking or short-circuiting on partial-field DeepEqual — the comparison is whole-object, so the proposed bypass path does not exist in this code.

```go
func IsOnlyMutatingGCFields(obj, old runtime.Object, equalities conversion.Equalities) bool {
	if old == nil || reflect.ValueOf(old).IsNil() {
		return false
	}

	// make a copy of the newObj so that we can stomp for comparison
	copied := obj.DeepCopyObject()
	copiedMeta, err := meta.Accessor(copied)
	if err != nil {
		return false
	}
	oldMeta, err := meta.Accessor(old)
	if err != nil {
		return false
	}
	copiedMeta.SetOwnerReferences(oldMeta.GetOwnerReferences())
	copiedMeta.SetFinalizers(oldMeta.GetFinalizers())
	copiedMeta.SetSelfLink(oldMeta.GetSelfLink())
	copiedMeta.SetManagedFields(oldMeta.GetManagedFields())

	return equalities.DeepEqual(copied, old)
```
