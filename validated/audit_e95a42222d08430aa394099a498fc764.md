### Title
TWAP collateral pricing enables over-borrowing during rapid price declines - (File: contracts/price-aggregator/src/providers/reflector.rs)

### Summary
The price aggregator supports Reflector `OracleReadMode::Twap(records)` feeds and computes their price as an arithmetic mean over historical observations. Because the resulting price can remain materially above the current market price during a sudden decline, an attacker can supply the declining asset as collateral and borrow against its stale average valuation. The controller values collateral and debt with this oracle price when enforcing post-borrow solvency, allowing debt whose true market value exceeds the collateral’s liquidation value.

### Finding Description
`OracleReadMode::Twap(records)` is an explicitly supported Reflector read mode [1](#0-0) . The aggregator dispatches a Reflector source with that mode to `read_twap` [2](#0-1) . `read_twap` obtains a history of prior Reflector observations, requires the samples to span the requested window, computes their equal-weight mean, and normalizes that mean as the returned price [3](#0-2) . It deliberately uses the oldest sample’s timestamp rather than the newest one [4](#0-3) , so an average composed of declining observations remains acceptable while its oldest sample is within the configured staleness budget [5](#0-4) .

The controller consumes this aggregate price directly when valuing positions. `Context::fetch_prices` retrieves the resolved aggregator feed and caches it for the transaction [6](#0-5) . Risk accounting multiplies each collateral position by `feed.price` to compute weighted collateral and multiplies each debt position by `feed.price` to compute total debt [7](#0-6) . `process_borrow` transfers the requested borrowed assets to the recipient before calling `enforce_post_pool_solvency` [8](#0-7) , so a stale above-market collateral valuation can authorize an economically unsafe borrow and pay the attacker before the protocol detects the loss.

### Impact Explanation
An unprivileged borrower can extract borrowed assets whose current market value exceeds the true value of the collateral securing them. Once the oracle catches up to the lower spot price, the account is undercollateralized or liquidatable only for less than the borrowed value. The shortfall becomes bad debt borne by suppliers through the protocol’s bad-debt handling, constituting protocol insolvency and theft of user funds.

The same stale valuation also delays liquidation of existing positions. Liquidation requires the oracle-derived health factor to be below `1.0` [9](#0-8) . An elevated TWAP keeps an actually unsafe position above that threshold until fresher observations move the average downward, during which collateral value can fall further.

### Likelihood Explanation
This requires a listed collateral asset to be priced by a Reflector TWAP source and a market decline fast enough that the historical mean remains above the current tradable price while still satisfying configured staleness, tolerance, and sanity checks. The code explicitly permits this configuration: Reflector `Twap` reads count as smoothed [10](#0-9) , and the oracle accepts prices that pass staleness, deviation, positivity, and sanity-bound checks [11](#0-10) . The attack is reachable through the permissionless `supply` and owner-authorized `borrow` entrypoints [12](#0-11) .

### Recommendation
Do not use TWAP alone for collateral valuation and liquidation decisions. Require a fresh spot-market leg alongside the smoothed leg and bound the usable result to the more conservative of the two for collateral, while keeping the smoother value for debt if desired. At minimum, reduce the TWAP window, require a current spot observation timestamp in addition to the oldest-window timestamp, and tighten sanity bands/tolerance so a falling market cannot leave a stale mean materially above executable market value.

### Proof of Concept
1. Assume collateral token `C` is listed with a Reflector oracle source configured as `OracleReadMode::Twap(3)`, while debt token `D` has a valid price source.
2. Reflector history contains recent declining observations for `C`, for example `100`, `90`, and `80` USD-equivalent values. `read_twap` returns approximately `90` as the collateral price even though the currently executable market price has continued falling to `75` [13](#0-12) .
3. The attacker calls `supply(caller, 0, spoke_id, [(C, 100 units)])`. The controller stores the position as collateral [14](#0-13) .
4. The attacker calls `borrow(caller, account_id, [(D, amount)], Some(attacker))`. The controller borrows `D` from the pool and sends it to the attacker [15](#0-14) .
5. The post-borrow solvency check values `100 C` at approximately `9,000` USD using the stale mean instead of `7,500` USD at spot [16](#0-15) . With an `80%` risk weight, the protocol believes the position supports about `7,200` USD of debt even though its true liquidation value is only about `6,000` USD.
6. When the oracle later reflects the lower price, the account is undercollateralized. Liquidation may recover part of the debt, but the remaining deficit is left to the pool and ultimately to suppliers.

/// Computes an arithmetic mean of the Reflector observations, despite the
/// `Twap` name implying a time-weighted average. Rejects a history that is
/// empty, oversized, future-dated, mis-ordered, tightly spaced, or short of
/// the window `records` implies. Returns the mean with the oldest timestamp.
fn read_twap(
    session: &Session,
    feed: &ReflectorFeedRef,
    decimals: u32,
    records: u32,
) -> Result<OracleObservation, OracleError> {
    let env = session.env();
    let now_secs = session.now_secs();

    validate_twap_records(env, records);

    let asset = to_reflector_asset(env, &feed.asset);
    let Some(history) = reflector_prices(env, &feed.contract, &asset, records) else {
        return Err(OracleError::ReflectorHistoryEmpty);
    };
    if history.is_empty() {
        return Err(OracleError::ReflectorHistoryEmpty);
    }
    // A skipped round is normal; the span check below proves coverage.
    if history.len() > records.saturating_add(1) {
        return Err(OracleError::TwapInsufficientObservations);
    }

    let resolution = try_reflector_resolution(env, &feed.contract)
        .filter(|resolution| *resolution >= MIN_ORACLE_RESOLUTION_SECONDS)
        .ok_or(OracleError::InvalidOracleResolution)?;

    let newest_ts = history.first().map_or(0, |price_data| price_data.timestamp);
    let mut oldest_ts = u64::MAX;
    let mut previous_ts = None;
    for price_data in history.iter() {
        if is_future_at(now_secs, price_data.timestamp) {
            return Err(OracleError::PriceFeedStale);
        }
        if previous_ts.is_some_and(|newer: u64| {
            newer
                .checked_sub(price_data.timestamp)
                .is_none_or(|spacing| spacing < u64::from(resolution))
        }) {
            return Err(OracleError::TwapInsufficientObservations);
        }
        previous_ts = Some(price_data.timestamp);
        oldest_ts = price_data.timestamp;
    }

    // Same span `attest` checks at admission; the loop proves the ordering.
    if newest_ts.saturating_sub(oldest_ts) < twap_required_span(records, resolution) {
        return Err(OracleError::TwapInsufficientObservations);
    }

    let raw_price = try_twap_mean_price(&history).ok_or(OracleError::InvalidPrice)?;
    let price_wad =
        try_normalize_positive_price(raw_price, decimals).ok_or(OracleError::InvalidPrice)?;
    Ok(OracleObservation {
        price_wad,
        timestamp: oldest_ts,
    })

/// Borrows the aggregated amounts to `recipient` and merges the debt results.
fn settle_borrow(
    env: &Env,
    account: &mut Account,
    recipient: &Address,
    aggregated: &AggregatedPayments,
    cache: &mut Context,
) {
    let pool_addr = cache.cached_pool_address();
    let mut entries: Vec<PoolBorrowEntry> = Vec::new(env);
    for (hub_asset, amount) in aggregated.iter() {
        let position = account.get_or_create_debt_position(&hub_asset);
        entries.push_back(PoolBorrowEntry {
            action: make_pool_action(&position, amount, hub_asset.clone()),
        });
    }
    let results = pool_borrow_call(env, &pool_addr, recipient, &entries);
    for_each_leg(env, &entries, &results, |entry, result| {
        merge_debt_leg(
            env,
            account,
            events::PositionAction::Borrow,
            &entry.action.hub_asset,
            LegDirection::Entry {
                asset_decimals: result.asset_decimals,
            },
            &LegOutcome::from(&result),
            cache,
        );
    });
}
