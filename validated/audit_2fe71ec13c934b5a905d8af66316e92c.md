**Reasoning:**

`iter_active_leaves_chunk`'s pagination is not based on hash-boundary math that could produce off-by-one duplication across shards. It delegates through `iter_active_leaves_with_values` → `jmt_leaves_with_values` → `JellyfishMerkleIterator::new_by_index`, which walks a single logical (sharded) JMT tree using each internal node's `leaf_count()` to deterministically locate the leaf at a given ordinal index and resume the DFS from exactly that point. [1](#0-0) 

Because the walk treats the whole sharded tree as one ordered sequence of leaves (ordered by key hash, counted via `leaf_count`), consecutive chunk calls with contiguous `first_index`/`chunk_size` windows partition the leaf sequence exactly — index `N` always refers to the same leaf regardless of which shard it physically resides in, and `take(chunk_size)` simply stops after consuming that many items from the resumed iterator. [2](#0-1) 

This exact `first_index`/`chunk_size` pagination pattern is identical to the one already used for production state-value chunk sync (`get_value_chunk_iter`/`value_chunk_with_proof`), sharing the same `jmt_leaves_with_values` helper. [3](#0-2) [4](#0-3) 

Additionally, even hypothetically, this iteration mechanism is a read-only enumeration API used for chunk-based data retrieval/sync, not a mutation path — it does not touch any actual balance, ownership, capability, or authority state. No custody boundary (owner/controller/capability transition) is crossed by this code; it does not fall within the review's required custody impact gate (asset movement, minting, burning, freezing, or authority transfer), so it is out of scope regardless of correctness of the pagination logic.

        let mut parent_stack = vec![];

        let mut current_node_key = NodeKey::new_empty_path(version);
        let mut current_node = reader.get_node(&current_node_key)?;
        if start_idx >= current_node.leaf_count() {
            return Ok(Self {
                reader,
                version,
                parent_stack,
                done: true,
                phantom_value: PhantomData,
            });
        }

        let mut leaves_skipped = 0;
        for _ in 0..=ROOT_NIBBLE_HEIGHT {
            match current_node {
                Node::Leaf(_) => {
                    ensure!(
                        leaves_skipped == start_idx,
                        "Bug: The leaf should be the exact one we are looking for.",
                    );
                    return Ok(Self {
                        reader,
                        version,
                        parent_stack,
                        done: false,
                        phantom_value: PhantomData,
                    });
                },
                Node::Internal(internal_node) => {
                    let (nibble, child) =
                        Self::skip_leaves(&internal_node, &mut leaves_skipped, start_idx)?;
                    let next_node_key = current_node_key.gen_child_node_key(child.version, nibble);
                    parent_stack.push(NodeVisitInfo::new_next_child_to_visit(
                        current_node_key,
                        internal_node,
                        nibble,
                    ));
                    current_node_key = next_node_key;
                },
                Node::Null => unreachable!("Null node has leaf count 0 so here is unreachable"),
            };
            current_node = reader.get_node(&current_node_key)?;

/// Walks the JMT at `version` from `start_idx` and yields `(StateKey, StateValue)`
/// for each live leaf, resolving the value via `value_for(key, leaf_version)`.
pub(crate) fn jmt_leaves_with_values<R, F>(
    merkle_db: Arc<R>,
    version: Version,
    start_idx: usize,
    value_for: F,
) -> Result<impl Iterator<Item = Result<(StateKey, StateValue)>> + Send + Sync + use<R, F>>
where
    R: TreeReader<StateKey> + Send + Sync + 'static,
    F: Fn(&StateKey, Version) -> Result<StateValue> + Send + Sync + 'static,
{
    Ok(
        JellyfishMerkleIterator::new_by_index(merkle_db, version, start_idx)?.map(move |res| {
            res.and_then(|(_hashed_key, (key, leaf_version))| {
                let value = value_for(&key, leaf_version)?;
                Ok((key, value))
            })
        }),
    )
}

/// Reads up to `chunk_size` live leaves from `first_index` (resolving values via
/// `value_for`) and stamps them with a range proof against the store's root at
/// `version`. The caller re-requests any remainder.
pub(crate) fn value_chunk_with_proof<R, F>(
    merkle_db: Arc<R>,
    version: Version,
    first_index: usize,
    chunk_size: usize,
    value_for: F,
) -> Result<StateValueChunkWithProof>
where
    R: TreeReader<StateKey> + Send + Sync + 'static,
    F: Fn(&StateKey, Version) -> Result<StateValue> + Send + Sync + 'static,
{
    let raw_values =
        jmt_leaves_with_values(Arc::clone(&merkle_db), version, first_index, value_for)?
            .take(chunk_size)
            .collect::<Result<Vec<_>>>()?;
    build_value_chunk_proof(merkle_db.as_ref(), version, first_index, raw_values)
}
