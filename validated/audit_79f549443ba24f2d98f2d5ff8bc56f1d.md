Audit Report

## Title
Unauthenticated LOOP plugin pprof proxy allows path injection into internal SSRF request - (File: core/web/loop_registry.go)

## Summary
`LoopRegistryServer.pluginPPROFHandler` builds the outbound proxy URL by splicing the raw gin wildcard parameter `profile` directly into a `fmt.Sprintf` format string, with no allowlist or path canonicalization, before forwarding the request via `l.doRequest`. This endpoint, along with the rest of `loopRoutes`, is registered on the base `api` group in `core/web/router.go` without any `auth.Authenticate(...)` wrapper, unlike the standard-library pprof group (`metricRoutes`, unused/dead code here) and every other sensitive route group.

## Finding Description
`pluginPPROFHandler` takes `gc.Param("profile")` — fully attacker-controlled from the URL path — and concatenates it into the format string itself (not as a `%s` argument):
```go
pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
``` [1](#0-0) 

There is no validation restricting `profile` to the known pprof sub-paths (`cmdline`, `profile`, `symbol`, `trace`, `allocs`, `block`, `goroutine`, `heap`, `mutex`, `threadcreate`), and no `path.Clean`/allowlist is applied before the value is used to build the outbound URL passed to `l.doRequest`, which performs `http.DefaultClient.Do` against it. [2](#0-1) 

`loopRoutes` is registered directly on the unauthenticated base `api` group in `router.go`, with no `auth.Authenticate(...)` middleware, in contrast to `debugRoutes` (wrapped in `auth.Authenticate`) and `authv2` (wrapped in `auth.Authenticate` plus role checks): [3](#0-2) [4](#0-3) [5](#0-4) 

I confirmed `metricRoutes` (the standard-library `/debug/pprof/*` handler group cited in the report as being "deliberately placed inside the authenticated `authv2` group") is defined but never called anywhere in `router.go` — it is dead code, not actually wired into `authv2` or any other group. This detail in the original report's Recommendation/analogy is incorrect, but it does not change the core finding: the LOOP-proxy pprof route is unauthenticated and vulnerable to path splicing.

The plugin name itself is validated against `l.registry.Get(pluginName)` (line 152), but the `profile` value used to build the target URL is not validated at all. `loopHostName` defaults to `"localhost"` unless overridden by the `CL_LOOPP_HOSTNAME` env var, and `p.EnvCfg.PrometheusPort` is an internal per-plugin port — so the practical "SSRF" surface is redirection to other paths/ports reachable from `localhost` on the node's own host, which is a real but narrower internal-request-confusion issue than external SSRF.

## Impact Explanation
An unauthenticated network client that can reach the node's HTTP API can invoke `/plugins/:name/debug/pprof/*profile` for any registered LOOP plugin (discoverable via the also-unauthenticated `/discovery` endpoint) and inject arbitrary path segments (including `../` traversal or `%`-format-string content) into the outbound request path. Because `l.doRequest` returns the response body directly to the caller (`gc.Data(http.StatusOK, ...)`), this allows an unauthenticated actor to make the node fetch and relay content from other paths on `localhost:<PrometheusPort>` (or crash/produce malformed output via unexpected `%` verbs in `fmt.Sprintf`). This is a legitimate in-scope issue: an authentication bypass on a data-returning endpoint plus request-path injection into an internal request, consistent with the "node API authentication...bypass" and cross-user/cross-boundary response corruption impact categories.

## Likelihood Explanation
High. The route requires no credentials, no special network position, and only a registered plugin name obtainable from `/discovery`. Any client that can reach the node's web port can trigger this repeatably with a single crafted GET request.

## Recommendation
1. Restrict `profile` to an explicit allowlist of pprof sub-paths before constructing the outbound URL, rejecting non-matching values.
2. Build the target URL via `url.URL{Scheme, Host, Path: path.Join(...)}` with `path.Clean`, never inserting user input into a `fmt.Sprintf` format string.
3. Wrap `loopRoutes` in `auth.Authenticate(...)`, consistent with `debugRoutes`.

## Proof of Concept
1. `GET /discovery` (unauthenticated) to obtain a valid `pluginName`.
2. `GET /plugins/<pluginName>/debug/pprof/../../../<arbitrary-path>?<injected>` (unauthenticated).
3. Observe `pluginPPROFHandler` builds `http://localhost:<PrometheusPort>/debug/pprof/../../../<arbitrary-path>?<injected>` and `doRequest` forwards it via `http.DefaultClient.Do`, returning the response body to the unauthenticated caller — confirmable via a Go unit test invoking `pluginPPROFHandler` with a fake `gin.Context` and asserting the constructed `pluginURL`, or an integration test against a running node with a registered mock plugin.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```
