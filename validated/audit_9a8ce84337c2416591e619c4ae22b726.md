I found a concrete unauthenticated-endpoint issue in the LOOP plugin routes, which is a genuine analog to the reported bug class (unprivileged access to debug/pprof-style endpoints due to insufficient authentication).

### Title
Unauthenticated access to plugin pprof/metrics proxy endpoints allows unprivileged remote profiling and DoS - ([File: core/web/router.go])

### Summary
The `loopRoutes` handlers, which proxy pprof and Prometheus metrics requests to LOOP plugin subprocesses, are registered on the base API router group without any authentication middleware, unlike the functionally similar `debugRoutes` which explicitly requires `auth.Authenticate`.

### Finding Description
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` router group with no `auth.Authenticate` wrapper: [1](#0-0) 

Compare this to `debugRoutes`, which serves a comparable capability (`/debug/vars`) but is explicitly wrapped with session authentication: [2](#0-1) 

The handlers behind these unauthenticated routes forward attacker-controlled query parameters (`debug`, `gc`, `seconds`) and request bodies directly to an internal plugin's `/debug/pprof/*` and `/debug/pprof/symbol` endpoints, and return the raw response to the caller: [3](#0-2) 

The `seconds` parameter is parsed directly from the unauthenticated request and used to set the CPU-profile capture duration, meaning an unauthenticated client can trigger a long-running expensive profiling/tracing operation on the node's internal plugin process: [4](#0-3) 

This mirrors the reported bug class: sensitive debug/admin-style endpoints (profiling, metrics, potential DoS triggers) reachable by an unprivileged client because the route registration omits the authentication middleware applied to comparable endpoints elsewhere in the same router file.

### Impact Explanation
An unauthenticated network client that can reach the node's HTTP API can:
- Enumerate registered LOOP plugins and their names via `/discovery` and `/plugins/:name/metrics`, leaking internal topology/plugin names/labels.
- Trigger CPU/goroutine/heap profiling (`/plugins/:name/debug/pprof/*`) with an attacker-controlled `seconds` duration, causing sustained CPU load on the plugin process — a denial-of-service vector analogous to the referenced CVE's unauthenticated `/restart_program` style impact.
- Repeated/concurrent profiling requests could degrade plugin availability and, by extension, node operation, without needing any session cookie or API token.

This does not expose private keys or secrets directly, but it is an authentication-bypass-class issue (missing auth middleware on a sensitive route) with a direct availability/DoS impact and information disclosure of plugin topology.

### Likelihood Explanation
Likelihood is moderate-to-high for any deployment where the Chainlink node's WebServer HTTP port is reachable by an untrusted network segment or the public internet (a supported/common configuration per `ListenIP = '0.0.0.0'` default seen in `core/config/docs/core.toml`). No credentials, session, or token are required — any client that can send an HTTP GET/POST to the node's port can invoke these handlers.

### Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token-based) middleware used for `debugRoutes`, and/or gate access behind `auth.RequiresAdminRole` given the operational sensitivity of profiling and metrics-proxying to internal plugin processes. At minimum, bound/validate the `seconds` parameter and rate-limit the endpoint group similarly to other unauthenticated routes.

### Proof of Concept
```
# No cookie, no API token/secret required
curl -s "http://<node-host>:6688/plugins/<plugin-name>/debug/pprof/profile?seconds=60"
curl -s "http://<node-host>:6688/discovery"
curl -s "http://<node-host>:6688/plugins/<plugin-name>/metrics"
```
Both requests succeed without authentication because `loopRoutes` (core/web/router.go:230-236) is mounted on the unauthenticated `api` group, unlike `debugRoutes` (core/web/router.go:180-183). [5](#0-4)

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
