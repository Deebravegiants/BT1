### Title
Unauthenticated "magic" QR-codes trigger privileged mirror-calibration and Wi-Fi reset actions during signup - ([File: src/plans/qr_scan/operator.rs], [File: src/plans/mod.rs])

### Summary
The Orb parses any camera-scanned QR-code payload for a `magic_action:<action>` pattern in the operator-QR schema and, if matched, immediately executes a privileged device action (`reset_mirror_calibration` or `reset_wifi_and_ensure_network`) — with no operator authentication, signature, or backend authorization check. This mirrors the analog vulnerability class in the referenced report: unvalidated externally supplied data reaching an unconstrained, side-effecting operation, enabling unintended/unauthorized action execution and denial-of-service on the claim/signup flow.

### Finding Description
`qr_scan::operator::Data::try_parse` matches the raw QR-code string against a `MAGIC_QR_CODE` regex (`magic_action:(?P<magic_action>[\w]+)`) and returns `Data::MagicResetWifi` / `Data::MagicResetMirror` purely from string content, with no cryptographic signature, backend call, or any authorization check. [1](#0-0) 

These variants are then dispatched in `handle_magic_operator_qr_code`, which unconditionally performs the privileged action as soon as the magic QR-code is scanned, before any `verify_operator_qr_code` backend check is ever invoked: [2](#0-1) 

The two privileged actions are:
- `reset_mirror_calibration`, which overwrites the persisted mirror calibration file and re-applies it to the hardware: [3](#0-2) 
- `reset_wifi_and_ensure_network`, which wipes the current `wpa_supplicant` configuration and forces network reconfiguration: [4](#0-3) [5](#0-4) 

Crucially, this code path is reachable in the self-serve/unattended flow via `scan_initial_qr_codes`, which calls `scan_operator_qr_code` and immediately `handle_magic_operator_qr_code` on whatever is scanned — before the operator QR-code is validated against the backend (`verify_operator_qr_code` is only called after the magic-action branch returns `None` and the loop continues): [6](#0-5) [7](#0-6) 

This is structurally analogous to the reported `Vault.setHooks`/`_claimPrize` bug: an attacker-controlled input (there, a user-set hook address; here, a QR-code string shown to the camera) reaches a sensitive execution path (there, an arbitrary external call; here, a hardware/network reconfiguration routine) without any capability check, gas/rate bound, or authorization gate — enabling an unprivileged party to trigger unintended state changes and disrupt the claim/signup transaction.

### Impact Explanation
Anyone able to present a QR-code to the Orb's camera during the operator/self-serve QR scanning phase (i.e., an unprivileged party, not a verified operator) can:
1. Force a mirror recalibration reset (`magic_action:reset_mirror_calibration`), degrading or breaking the auto-focus/eye-tracking system used during biometric capture, causing repeated signup failures until an operator manually recalibrates the device (denial-of-service on the signup pipeline).
2. Force a Wi-Fi credential wipe and reconnection cycle (`magic_action:reset_wifi_credentials`), disconnecting the Orb from its network mid-operation and blocking backend communication needed for QR/operator verification, user enrollment, and biometric data upload — a denial-of-service that can be repeated indefinitely by re-presenting the same static QR-code string.

Neither action requires any operator credential, PIN, signed payload, or backend confirmation — the trigger is purely regex-matched plaintext content of a scanned code.

### Likelihood Explanation
High. The QR content (`magic_action:reset_wifi_credentials` / `magic_action:reset_mirror_calibration`) is publicly documented in the source/tests and trivially reproducible by printing a QR-code containing that exact string. No special access, hardware, or privileged position is required — only physical proximity to present the code to the Orb's camera during the operator-QR scanning phase, which occurs at the start of every signup attempt (and is the *only* phase in self-serve/unattended mode, where no human operator is present to notice or gate the action).

### Recommendation
Require the magic-action QR-code to be authenticated the same way as a normal operator QR-code (e.g., signed, backend-verified, or gated behind an already-verified operator session) before executing `reset_mirror_calibration` or `reset_wifi_and_ensure_network`. At minimum, move the magic-action dispatch to occur only *after* `verify_operator_qr_code` succeeds, and add rate-limiting/cooldown and audit logging so a single unauthenticated scan cannot repeatedly disrupt hardware state or connectivity.

### Proof of Concept
1. Generate a QR-code containing exactly the string `magic_action:reset_wifi_credentials` (or `magic_action:reset_mirror_calibration`).
2. Present it to the Orb during the operator QR-code scanning phase of `scan_initial_qr_codes` (self-serve) or `scan_remaining_qr_codes`.
3. Observe that `qr_scan::operator::Data::try_parse` matches the `MAGIC_QR_CODE` regex and returns `Data::MagicResetWifi`/`MagicResetMirror` [8](#0-7) .
4. Observe `handle_magic_operator_qr_code` immediately invoke `reset_wifi_and_ensure_network`/`reset_mirror_calibration` with no preceding authorization check [9](#0-8) , disrupting network connectivity or mirror calibration for the device without any operator credential.

static MAGIC_QR_CODE: Lazy<Regex> = Lazy::new(|| {
    Regex::new(
        r"(?x)
        ^
        magic_action
        :
        (?P<magic_action>[\w]+)
        $
    ",
    )
    .expect("bad regex")
});

/// Operator QR-code data.
#[derive(Clone, Debug)]
pub enum Data {
    /// Normal Operator QR-code.
    Normal(user::Data),
    /// Action to reconfigure WiFi.
    MagicResetWifi,
    /// Action to reset mirror calibration.
    MagicResetMirror,
}

impl Schema for Data {
    fn ui() -> ui::QrScanSchema {
        ui::QrScanSchema::Operator
    }

    fn try_parse(code: &str) -> Option<Self> {
        let normal = user::Data::try_parse(code)
            .filter(
                |d| if d.signup_extension() { d.signup_extension_config.is_some() } else { true },
            )
            .map(Data::Normal);
        if normal.is_some() {
            return normal;
        }
        if let Some(captures) = MAGIC_QR_CODE.captures(code) {
            return match captures
                .name("magic_action")
                .expect("magic_action group must be present")
                .as_str()
            {
                "reset_wifi_credentials" => Some(Data::MagicResetWifi),
                "reset_mirror_calibration" => Some(Data::MagicResetMirror),
                _ => None,
            };
        }
        None
    }

    async fn handle_magic_operator_qr_code(
        &self,
        orb: &mut Orb,
        qr_code: qr_scan::operator::Data,
    ) -> Result<Option<qr_scan::user::Data>> {
        match qr_code {
            qr_scan::operator::Data::Normal(qr_code) => {
                tracing::info!("Operator QR-code detected: {qr_code:?}");
                Ok(Some(qr_code))
            }
            qr_scan::operator::Data::MagicResetMirror => {
                tracing::info!("Magic QR-code detected: Reset Mirror");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_mirror");
                let result = self.reset_mirror_calibration(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset mirror calibration: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
            qr_scan::operator::Data::MagicResetWifi => {
                tracing::info!("Magic QR-code detected: Reset Wi-Fi");
                dd_incr!("main.count.signup.during.general.magic_qr.reset_wifi");
                let result = self.reset_wifi_and_ensure_network(orb).await;
                if let Err(err) = &result {
                    tracing::error!("Failed to reset wifi: {err}");
                }
                orb.ui.magic_qr_action_completed(result.is_ok());
                Ok(None)
            }
        }
    }

/// Restores the default wpa_supplicant.conf configuration file.
/// Then forces wpa_supplicant to re-read its configuration file,
/// thus disconnecting from the current network.
pub async fn reset() -> Result<()> {
    spawn_blocking(move || {
        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("restore-default-config")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))?;

        Command::new(WPA_SUPPLICANT_INTERFACE_BIN)
            .arg("reconfigure")
            .status()
            .wrap_err("running `wpa-supplicant-interface`")?
            .success()
            .then_some(())
            .ok_or_else(|| eyre!("`wpa-supplicant-interface` terminated unsuccessfully"))
    })
    .await?
}
